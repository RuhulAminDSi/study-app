১. HTTP এবং HTTPS-এর পার্থক্য কী?
উত্তর:
 HTTP (HyperText Transfer Protocol) হলো Web Browser এবং Web Server-এর মধ্যে Data আদান-প্রদানের একটি Protocol। HTTP-তে Data Plain Text আকারে আদান-প্রদান হয়, ফলে Data Intercept হলে সহজে পড়া যায়।
HTTPS (HyperText Transfer Protocol Secure) হলো HTTP-এর Secure Version। HTTPS-এ SSL/TLS Certificate ব্যবহার করে Data Encrypt করা হয়, ফলে Data নিরাপদভাবে আদান-প্রদান হয়।
২. Web Application Security বলতে কী বুঝো?
উত্তর:
 Web Application Security হলো Web Application-কে বিভিন্ন Cyber Attack, Unauthorized Access, Data Breach এবং Vulnerability থেকে সুরক্ষিত রাখার প্রক্রিয়া।
এর উদ্দেশ্য:
• Confidentiality নিশ্চিত করা
• Integrity বজায় রাখা
• Availability নিশ্চিত করা
• User Data সুরক্ষিত রাখা
৩. SQL Injection কী?
উত্তর:
 SQL Injection হলো একটি Web Security Vulnerability যেখানে আক্রমণকারী Malicious SQL Query Input-এর মাধ্যমে Database-এর উপর অননুমোদিত Access নেওয়ার চেষ্টা করে।
এর মাধ্যমে Hacker:
• Data দেখতে পারে
• Data পরিবর্তন করতে পারে
• Data মুছে ফেলতে পারে
• Authentication Bypass করতে পারে
৪. Scrum কী?
উত্তর:
 Scrum হলো Agile Software Development Framework যা Iterative এবং Incremental পদ্ধতিতে Software Development পরিচালনা করে।
Scrum-এর প্রধান Role:
• Product Owner
• Scrum Master
• Development Team
Scrum-এর গুরুত্বপূর্ণ Event:
• Sprint Planning
• Daily Scrum
• Sprint Review
• Sprint Retrospective
৫. Black Hat Hacker এবং White Hat Hacker-এর পার্থক্য কী?
উত্তর:White Hat Hacker:
• Ethical Hacker নামে পরিচিত।
• অনুমতি নিয়ে Security Testing করে।
• Vulnerability খুঁজে বের করে সমাধান দিতে সাহায্য করে।
• প্রতিষ্ঠানের Security উন্নত করার জন্য কাজ করে।
Black Hat Hacker:
• অনুমতি ছাড়া System-এ প্রবেশ করে।
• Data চুরি, ক্ষতি বা Financial Fraud করার উদ্দেশ্যে কাজ করে।
• Cyber Crime-এর সঙ্গে জড়িত থাকে।
সংক্ষেপে:
White Hat Hacker Security রক্ষা করে, আর Black Hat Hacker Security ভঙ্গ করে।
৬. What does hackers do with stolen data?
উত্তর:
Hackers চুরি করা Data বিভিন্নভাবে ব্যবহার করতে পারে, যেমন:
• Identity Theft করা
• Financial Fraud করা
• Bank Account বা Credit Card অপব্যবহার করা
• Phishing Attack পরিচালনা করা
• Dark Web-এ Data বিক্রি করা
• Account Takeover করা
• Corporate Espionage করা
• Ransomware বা Extortion-এর জন্য ব্যবহার করা
