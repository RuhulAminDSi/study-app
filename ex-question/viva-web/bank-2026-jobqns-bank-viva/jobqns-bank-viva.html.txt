১. Bangla QR কী? এর কাজ কী? QR-এর Full Form কী?
 উত্তর:

২. ICT এবং IT-এর মধ্যে পার্থক্য কী?
 উত্তর:
 IT (Information Technology) মূলত Computer, Software, Database এবং Network-এর মাধ্যমে তথ্য সংরক্ষণ ও প্রক্রিয়াকরণ নিয়ে কাজ করে।

সংক্ষেপে: ICT = IT + Communication Technology।

৫. Binary এবং Decimal কী? ৩-এর Binary কত?
 উত্তর:
 Binary হলো Base-2 Number System, যেখানে শুধুমাত্র 0 এবং 1 ব্যবহৃত হয়।
 Decimal হলো Base-10 Number System, যেখানে 0 থেকে 9 পর্যন্ত Digit ব্যবহৃত হয়।
৩-এর Binary = 11₂।

৯. DROP, DELETE এবং TRUNCATE-এর মধ্যে পার্থক্য কী?
 উত্তর:
 DROP: পুরো Table (Structure + Data) মুছে দেয়।
 DELETE: শুধুমাত্র Row মুছে দেয়, Structure থাকে এবং WHERE Clause ব্যবহার করা যায়।
 TRUNCATE: Table-এর সব Row দ্রুত মুছে দেয়, কিন্তু Structure থাকে; WHERE Clause ব্যবহার করা যায় না।

৯। UPS আর IPS কীভাবে কাজ করে? (Real-life উদাহরণসহ)
 UPS (Uninterruptible Power Supply):
বিদ্যুৎ চলে গেলে UPS-এর Battery সঙ্গে সঙ্গে Power Supply দিতে শুরু করে। এতে Computer Restart হয় না এবং User নিরাপদে Data Save করতে পারে। সাধারণত Backup Time ১০–৩০ মিনিট।
Real-life উদাহরণ:
অফিসে কাজ করার সময় হঠাৎ বিদ্যুৎ চলে গেলে UPS সঙ্গে সঙ্গে Computer চালু রাখে, ফলে গুরুত্বপূর্ণ File Save করা যায়।
IPS (Instant Power Supply):
IPS মূলত Battery-তে বিদ্যুৎ সংরক্ষণ করে এবং বিদ্যুৎ চলে গেলে পুরো বাসা বা অফিসের নির্দিষ্ট Load-এ দীর্ঘ সময় বিদ্যুৎ সরবরাহ করে। এটি Inverter-এর মাধ্যমে DC-কে AC-তে রূপান্তর করে।
Real-life উদাহরণ:
বাসা বা অফিসে বিদ্যুৎ চলে গেলে IPS-এর মাধ্যমে Fan, Light, Wi-Fi Router এবং Computer দীর্ঘ সময় চালানো যায়।
UPS এবং IPS-এর মূল পার্থক্য:
• UPS: Switching Time প্রায় 0 ms, Computer ও Server-এর জন্য ব্যবহৃত হয়, Backup Time কম।
• IPS: Switching Time তুলনামূলক বেশি (কয়েক milliseconds), Backup Time বেশি এবং একাধিক Electrical Device চালাতে পারে।

 ৬. Static IP & Dynamic IP কী?
 Static IP
একটি Fixed IP Address।
পরিবর্তন হয় না।

Dynamic IP

Static IP Server-এর জন্য উপযোগী, Dynamic IP Client-এর জন্য উপযোগী।
৭. DHCP কী? কিভাবে কাজ করে?

Acknowledge (ACK) – Server IP Assign করে এবং Lease নিশ্চিত করে।
DHCP Server UDP Port 67 ব্যবহার করে।
DHCP Client UDP Port 68 ব্যবহার করে।

 Ring Topology: প্রতিটি Device শুধুমাত্র দুইটি পাশের Device-এর সাথে Connected থাকে এবং একটি Ring তৈরি করে।

একটি Device বা Link নষ্ট হলে পুরো Network প্রভাবিত হতে পারে।
Troubleshooting তুলনামূলক কঠিন।

৯. Circuit Switching ও Packet Switching এর পার্থক্য কি?
 উত্তর:
 Circuit Switching:
যোগাযোগের আগে Dedicated Path তৈরি হয়।
Delay কম এবং Continuous Communication-এর জন্য উপযুক্ত।
Bandwidth Reserved থাকে।
Packet Switching:
Data ছোট ছোট Packet আকারে পাঠানো হয়।
Dedicated Path প্রয়োজন হয় না।
Bandwidth Efficient এবং Internet-এ ব্যবহৃত হয়।
১০. কোনটা Better?
 উত্তর:
 বর্তমান সময়ে Packet Switching বেশি Better, কারণ এটি Bandwidth Efficient, কম খরচে কাজ করে এবং Internet-এ ব্যাপকভাবে ব্যবহৃত হয়। তবে Real-time Voice Communication-এর জন্য অনেক ক্ষেত্রে Circuit Switching উপযোগী।
১১. ATM Network কি?
 উত্তর:
 ATM (Asynchronous Transfer Mode) হলো একটি High-speed Switching Technology, যেখানে Data নির্দিষ্ট আকারের 53-byte Cell আকারে প্রেরণ করা হয়। এটি Voice, Video এবং Data একসাথে বহন করতে পারে।

৪. Big Data কী?
উত্তর: Big Data হলো এমন বিশাল পরিমাণ Data যা Traditional Database System দিয়ে সহজে সংরক্ষণ, প্রক্রিয়াকরণ বা বিশ্লেষণ করা যায় না। Big Data সাধারণত Volume, Velocity, Variety (3Vs) দ্বারা চিহ্নিত হয়। বর্তমানে আরও Veracity এবং Value যুক্ত করে 5Vs বলা হয়।
৫. AI কী?
উত্তর: Artificial Intelligence (AI) হলো Computer Science-এর একটি শাখা, যেখানে এমন System তৈরি করা হয় যা মানুষের মতো শিখতে, সিদ্ধান্ত নিতে, সমস্যা সমাধান করতে এবং ভাষা বুঝতে পারে।
৬. LLM কী?
উত্তর: LLM (Large Language Model) হলো AI-এর একটি বিশেষ ধরনের Model, যা বিশাল পরিমাণ Text Data ব্যবহার করে Train করা হয়। এটি মানুষের ভাষা বুঝতে, প্রশ্নের উত্তর দিতে, লেখা তৈরি করতে, অনুবাদ করতে এবং সংক্ষিপ্তসার তৈরি করতে পারে।
৭. AI আর LLM-এর মধ্যে পার্থক্য কী?
উত্তর:
 AI: এটি একটি বৃহৎ ক্ষেত্র, যেখানে Machine Learning, Computer Vision, Robotics, NLP ইত্যাদি অন্তর্ভুক্ত।
 LLM: এটি AI-এর একটি Subset, যা শুধুমাত্র Natural Language Processing (NLP) এবং Text Generation-এর জন্য তৈরি।
অর্থাৎ, সব LLM হলো AI, কিন্তু সব AI হলো LLM নয়।

১০. এই স্ক্যাম নিয়ে কী জানেন?
উত্তর: Hackers Bangladesh Bank-এর Network-এ Malware ব্যবহার করে প্রবেশ করে এবং SWIFT System থেকে ভুয়া Payment Instruction পাঠায়। মোট প্রায় ১ বিলিয়ন মার্কিন ডলার স্থানান্তরের চেষ্টা করা হয়। এর মধ্যে প্রায় ৮১ মিলিয়ন মার্কিন ডলার Philippines-এর বিভিন্ন ব্যাংক অ্যাকাউন্টে স্থানান্তরিত হয়। একটি Transfer Request-এ বানান ভুল ("Foundation" শব্দের ভুল বানান) থাকায় সন্দেহ সৃষ্টি হয় এবং বাকি লেনদেন বন্ধ হয়ে যায়। ঘটনাটি বিশ্বব্যাপী অন্যতম বড় Cyber Banking Attack হিসেবে পরিচিত।

উত্তর: Software Development Life Cycle (SDLC) হলো একটি Structured Process, যার মাধ্যমে Software পরিকল্পনা, Design, Development, Testing, Deployment এবং Maintenance করা হয়। এর উদ্দেশ্য হলো নির্ধারিত সময় ও খরচের মধ্যে মানসম্মত Software তৈরি করা।

১৩. Black Box Testing কী?
উত্তর: Black Box Testing হলো এমন একটি Testing Method যেখানে Software-এর Internal Code বা Logic না দেখে শুধুমাত্র Input এবং Output যাচাই করা হয়। Tester শুধুমাত্র Software-এর Functionality পরীক্ষা করেন।
১৪. Gray Box Testing কী?
উত্তর: Gray Box Testing হলো Black Box এবং White Box Testing-এর সমন্বয়। এখানে Tester-এর System-এর Internal Structure সম্পর্কে আংশিক ধারণা থাকে এবং সেই জ্ঞান ব্যবহার করে Functional Testing করা হয়। এটি Integration Testing এবং Security Testing-এ বেশি ব্যবহৃত হয়।

অতিরিক্ত Follow-up প্রশ্নের জন্য সংক্ষিপ্ত উত্তর:
➤ Data Center এবং Cloud-এর মধ্যে পার্থক্য কী?
Data Center হলো Physical Infrastructure, আর Cloud Computing হলো Internet-এর মাধ্যমে সেই Infrastructure-এর Service প্রদান।
➤ Phishing থেকে কীভাবে নিরাপদ থাকা যায়?
Unknown Link-এ ক্লিক না করা, Strong Password ব্যবহার করা, Multi-Factor Authentication (MFA) চালু রাখা এবং সন্দেহজনক Email যাচাই করা।
➤ OOP-এর সুবিধা কী?
Code Reusability, Maintainability, Scalability, Security এবং Modular Development নিশ্চিত করে।
➤ Cloud-এর একটি উদাহরণ বলুন।
Amazon Web Services (AWS), Microsoft Azure এবং Google Cloud Platform (GCP)।
