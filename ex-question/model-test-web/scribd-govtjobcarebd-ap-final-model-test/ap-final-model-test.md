- **Font-encoded text layer.** Scribd serves the English text through a font whose glyphs are mapped to other characters (for example "Gsscstgdt ^ra`rgoobr" = "Assistant Programmer"). I used the images only to place the question numbers that the text layer drops (Q4, Q53, Q54, Q67, Q71, Q86, Q90, Q94, Q100).
