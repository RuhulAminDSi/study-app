- The text layer uses a remapped font, like the same publisher's AP model test. I decoded it with a character map built from known words (`BUET PATTERN IT JOB RECRUITMENT EXAM`, `Exam is conducted for 1:30 hours in ECE building, BUET`) and checked the digits against the contact number, which decodes to the same number the publisher prints elsewhere. A few capitals did not occur often enough to map and are corrected by context below (MCX → MCQ, GJ → GK, JAYA → JAVA).
- Scribd's own summary of the document reads the MCQ part as 60 marks; the sheet itself says "MCQ 60/40 each carries .50 marks", which is 30 or 20 marks. The text below follows the sheet.

### Govt Job Care BD — BUET Pattern IT Job Recruitment Exam (pattern, suggestion)

> BUET PATTERN IT JOB RECRUITMENT EXAM
> Exam is conducted for 1:30 hours in ECE building, BUET
> Some of the upcoming recruitment exams for example:
> Bangladesh Computer Council, Bangladesh Power Development Board, Bangladesh Telecommunication Company Limited, All gas fields, Electricity generation or distribution Company exams etc.
>
> Section ‐ A :
> MCQ 60/40 each carries .50 marks
> Written 12 questions each carries 5 marks
>
> MCQ part: Bangla, English, Mathematics, GK, about that.
> Written part: Computer Architecture, Computer Programming (C/C++/JAVA), Microprocessor, Database, Networking, Digital System and Design, Operating System, Software Engineering

- **Imitates:** BUET-run recruitment tests for BCC, BPDB, BTCL, the gas companies and power generation/distribution companies
- **Blueprint as printed:** 90 minutes; MCQ (60 or 40 items × 0.5) on the non-technical subjects only; written = 12 technical questions × 5 marks = 60 marks
