#### কী, নরমালাইজেশন, ইনডেক্সিং ও কনকারেন্সি

১০৪. কী (Key) ফিল্ড কী? Primary Key, Foreign Key, Super Key, Composite Primary Key, Alternate Key, Surrogate Key ও Candidate Key এর পার্থক্য ও সংজ্ঞা লিখুন।
১০৫. Database Normalization কী? নরমালাইজেশনের প্রয়োজনীয়তা ও প্রকারভেদ (1NF, 2NF, 3NF, BCNF) ব্যাখ্যা করুন।
১০৬. ডেটাবেজে ইন্ডেক্সিং (Indexing) কী ও এর সুবিধা? Dense Index ও Sparse Index এর মধ্যে পার্থক্য লিখুন।
১০৭. সর্টিং (Sorting) ও ইন্ডেক্সিং (Indexing) এর মধ্যে পার্থক্য লিখুন।
১০৮. Hash Function কী? Static Hashing এবং Dynamic Hashing এর কার্যপদ্ধতি আলোচনা করুন।
১০৯. B+ Tree Index Files এর গঠন ও সার্চিং কার্যপদ্ধতি বর্ণনা করুন।
১১০. RAID কী এবং RAID-এর বিভিন্ন লেভেল (Levels of RAID) আলোচনা করুন।
১১১. Database System Architectures: Centralized, Distributed এবং Client-Server ডেটাবেজ সিস্টেম সচিত্র বর্ণনা করুন।
১১২. Heterogeneous এবং Homogeneous Database System কী?
১১৩. Data Warehousing, Data Analysis এবং Data Mining কী? এদের পারস্পরিক সম্পর্ক লিখুন।
১১৪. Data Encryption কী? এনক্রিপশনের সুবিধা, প্রকারভেদ এবং প্রচলিত বিভিন্ন এনক্রিপশন অ্যালগরিদমের নাম লিখুন।
১১৫. Private Key ও Public Key এর ব্যাখ্যা এবং Plaintext ও Ciphertext এর পার্থক্য লিখুন।
১১৬. Database Transaction কী? ট্রানজেকশনের ACID Properties সম্পর্কে বিস্তারিত আলোচনা করুন।
১১৭. Concurrency Control কী? Lock-Based Protocols এবং Timestamp-Based Protocols ব্যাখ্যা করুন।
১১৮. Database Failure কী ও এর শ্রেণিবিভাগ? ফেইলিউর অবস্থা হতে ডেটাবেজ পুনরুদ্ধারে Log-Based Recovery মেকানিজম ব্যাখ্যা করুন।

#### SQL কুয়েরি ও প্র্যাকটিস সমস্যা

১১৯. Query Language কী ও কত প্রকার? SQL-এর বিভিন্ন Clause (GROUP BY, HAVING, ORDER BY) আলোচনা করুন।
১২০. ডেটাবেজ সাব-ল্যাঙ্গুয়েজ: DDL, DML, DCL, TCL এবং DQL এর সংজ্ঞা, কমান্ড ও পার্থক্য লিখুন।
১২১. ডেটাবেজ ভিউ (View) কী? ইহা কী কাজে লাগে এবং Table ও View এর মধ্যে পার্থক্য লিখুন।
