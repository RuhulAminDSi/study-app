## Content

### ৫. Software Engineering (continued)

১৩৮. Software Verification (যাচাইকরণ) এবং Software Validation (বৈধকরণ) এর মধ্যে পার্থক্য লিখুন।
১৩৯. সফটওয়্যার টেস্টিং (Software Testing) কী? সফটওয়্যার ডেভেলপমেন্টে টেস্টিংয়ের গুরুত্ব আলোচনা করুন।
১৪০. হোয়াইট বক্স টেস্টিং (White Box Testing) এবং ব্ল্যাক বক্স টেস্টিং (Black Box Testing) এর মধ্যে পার্থক্য লিখুন।
১৪১. সফটওয়্যার টেস্টিং স্ট্র্যাটেজি: Alpha testing, Beta testing, Regression testing এবং Smoke testing এর ব্যাখ্যা দিন।
১৪২. Feasibility Study বা ফিজিবিলিটি এনালাইসিস কী? এর বিভিন্ন ধাপসমূহ ও প্রয়োজনীয়তা বর্ণনা করুন।
১৪৩. ব্রেক ইভেন পয়েন্ট (Break-even Point) কী? সফটওয়্যার বিজনেসে এর গুরুত্ব লিখুন।
১৪৪. Modularization কী? সফটওয়্যারকে মডিউলে বিভক্ত করার সুবিধা ও অসুবিধা আলোচনা করুন।
১৪৫. CASE (Computer-Aided Software Engineering) টুলস বলতে কী বোঝায়?
১৪৬. MVC (Model-View-Controller) ফ্রেমওয়ার্ক সম্পর্কে আলোচনা করুন এবং এর সুবিধাসমূহ লিখুন।
১৪৭. সফটওয়্যার ইঞ্জিনিয়ারিংয়ে Maintenance Cost কী কী উপাদানের ওপর নির্ভরশীল?

### ৬. ওয়েব টেকনোলজি ও ইন্টারনেট (Web Technology & Internet)

১৪৮. HTML কী? উদাহরণসহ একটি সাধারণ HTML ডকুমেন্টের গঠন বর্ণনা করুন।
১৪৯. HTML List Tag সম্পর্কে আলোচনা করুন এবং নিম্নোক্ত নেস্টেড লিস্টের HTML কোড লিখুন:
   1. Fruits [ (a) Mango, (b) Orange ]
   2. Vegetables [ Green capsicum, Yellow capsicum, Red capsicum ]
১৫০. Customer Name, Product Name এবং Manufacturer ফিল্ড সংবলিত একটি HTML Table তৈরির কোড লিখুন (Rowspan/Colspan সহ)।
১৫১. HTML এ Form কী? টেক্সটবক্স, চেকবক্স, রেডিও অপশন ও সাবমিট বাটন সংবলিত একটি HTML ফর্ম তৈরির কোড লিখুন।
১৫২. CSS কী ও কত প্রকার? CSS এর বেসিক সিনট্যাক্স লিখুন।
১৫৩. CSS Box Model এ 'Padding' এবং 'Margin' এর মধ্যকার পার্থক্য লিখুন।
১৫৪. PHP কী? ক্লায়েন্ট সাইড স্ক্রিপ্টিং ও ওয়েব ডেভেলপমেন্টে JavaScript এর প্রয়োজনীয়তা আলোচনা করুন।
১৫৫. ফর্ম ডেটা পাঠানোর ক্ষেত্রে GET এবং POST Method এর মধ্যে পার্থক্য লিখুন। কখন কোন পদ্ধতি নিরাপদ?
১৫৬. ওয়েবসাইট কী? Linear Sequence ওয়েব স্ট্রাকচার এবং Tree ওয়েব স্ট্রাকচার সচিত্র বর্ণনা করুন।
১৫৭. ওয়েব হোস্টিং ও ওয়েব পোর্টাল কী? ওয়েব হোস্টিং এর প্রয়োজনীয়তা ব্যাখ্যা করুন।
