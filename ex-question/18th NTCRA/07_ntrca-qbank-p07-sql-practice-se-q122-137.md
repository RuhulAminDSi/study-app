### ৪. DBMS — SQL (continued)

১২২. SQL স্টেটমেন্ট `DELETE`, `DROP` এবং `TRUNCATE` এর মধ্যকার মূল পার্থক্যগুলো লিখুন।
১২৩. Database Trigger কী এবং ডেটাবেজে ট্রিগারের সুবিধা কী কী?
১২৪. SQL Join কী? বিভিন্ন প্রকার Join (Inner, Left, Right, Full Outer Join) উদাহরণসহ লিখুন।
১২৫. SQL ব্যবহার করে `Student(std_id, std_name, std_address, GPA)` টেবিল তৈরি করুন এবং যে সকল ছাত্রের GPA-5 তাদের সকল রেকর্ড প্রদর্শনের SQL Query লিখুন।
১২৬. প্রদত্ত টেবিল: `Employee(Emp_Id, Emp_Name, Salary, City, Dept)` এবং `Job(Emp_ID, Post, Branch)`। নিচের প্রশ্নগুলোর SQL লিখুন:
   - টেবিলটিতে নতুন একজনের তথ্য ইনসার্ট করুন।
   - যাদের স্যালারি ২০,০০০ এর উপরে এবং পোস্ট 'Manager' তাদের নাম, ব্রাঞ্চ, সিটি ও স্যালারি দেখান।
   - ঐ সকল ডিপার্টমেন্টের এভারেজ স্যালারি বের করুন যাদের গড় স্যালারি ৩০,০০০ এর নিচে।
   - CSE dept-এর যেসকল এমপ্লয়ির স্যালারি IT dept-এর যেকোনো কর্মীর স্যালারির সাথে মিলে তাদের নাম বের করুন।
   - যাদের স্যালারি ২০,০০০ এর কম তাদের স্যালারির সাথে ১,০০০ বৃদ্ধি করে প্রদর্শন করুন।
   - Employee টেবিল হতে ৩য় সর্বোচ্চ স্যালারি (3rd Maximum Salary) বের করার কোয়েরি লিখুন।
১২৭. রেস্টুরেন্ট ডেটাবেজ কুয়েরি: `Restaurant(rid, rname, rcity)`, `Dishes(did, dname, dtype)`, `Customer(cid, cname, ccity)`, `Serves(rid, did)`:
   (ক) যেসকল রেস্টুরেন্ট 'Burger' সার্ভ করে তাদের নাম বের করুন।
   (খ) 'Saiful' নামক ব্যক্তি এলার্জি এড়িয়ে খেতে পারেন এমন খাবারের তালিকা তৈরিতে কুয়েরি লিখুন।
   (গ) ঢাকার সকল রেস্টুরেন্টে পাওয়া যায় এমন খাবারের তালিকা তৈরির কুয়েরি লিখুন।
১২৮. টেবিল: `course(course_id, course_name, chief_id)` ও `instructor(instructor_id, course_id, salary, joining_date)`। প্রতিটি কোর্সের নাম এবং সংশ্লিষ্ট প্রশিক্ষকদের গড় স্যালারি প্রদর্শনের জন্য SQL লিখুন।

### ৫. সফটওয়্যার ইঞ্জিনিয়ারিং ও সিস্টেম অ্যানালাইসিস (Software Engineering)

১২৯. Computer Software কী? System Software এবং Application Software এর পার্থক্য লিখুন।
১৩০. Software Engineering বলতে কী বোঝায়? সফটওয়্যার ইঞ্জিনিয়ারিংয়ের প্রয়োজনীয়তা বর্ণনা করুন।
১৩১. Software Development Life Cycle (SDLC) কী? SDLC এর বিভিন্ন ধাপ ও টুলস বিস্তারিত আলোচনা করুন।
১৩২. Software Process Model কী? বিভিন্ন মডেলের উপযোগিতা আলোচনা করুন।
১৩৩. Waterfall Model বর্ণনা করুন। এই মডেলের সুবিধা ও সীমাবদ্ধতাগুলো কী কী?
১৩৪. Prototyping Model এর কার্যপদ্ধতি ও ধাপসমূহ বর্ণনা করুন।
১৩৫. সফটওয়্যার ডেভেলপমেন্টে Spiral Model এর কার্যপদ্ধতি ও গুরুত্ব লিখুন।
১৩৬. Agile Model সম্পর্কে বিস্তারিত আলোচনা করুন। চিরাচরিত মডেলগুলোর তুলনায় Agile মডেলের শ্রেষ্ঠত্ব কোথায়?
১৩৭. Iterative Model, Incremental Model, V-Model এবং RAD (Rapid Application Development) মডেল সংক্ষেপে আলোচনা করুন।
