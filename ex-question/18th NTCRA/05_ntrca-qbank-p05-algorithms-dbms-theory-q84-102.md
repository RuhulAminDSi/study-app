### ৩. Data Structure & Algorithms (continued)

৮৪. Greedy Algorithm কাকে বলে? Greedy Algorithm দিয়ে সমাধান করা যায় এমন দুটি ক্লাসিক সমস্যা বর্ণনা করুন।
৮৫. Divide and Conquer কৌশল কী? এই কৌশলের মাধ্যমে সমাধানযোগ্য দুটি বাস্তব সমস্যা আলোচনা করুন।
৮৬. Tower of Hanoi সমস্যা সমাধানের জন্য রিকার্সিভ অ্যালগরিদমটি লিখুন।
৮৭. Polish Notation কী ও কত প্রকার? নিচের Infix Notation গুলোকে Prefix ও Postfix Notation-এ রূপান্তর করুন:
   - `A ↑ B * C - D + E / F / (G + H)`
   - `(A + B) * C - (D - E) ↑ (F + G)`
   - `A - B / (C * D ↑ E)`
৮৮. Big-O Notation কী? অ্যালগরিদমের Time ও Space Complexity কীভাবে নির্ণয় করা হয়? জনপ্রিয় Sorting অ্যালগরিদমসমূহের জটিলতা উল্লেখ করুন।

### ৪. ডেটাবেজ ম্যানেজমেন্ট সিস্টেম (Database Management System - DBMS)

#### ডেটাবেজ থিওরি, আর্কিটেকচার ও মডেল

৮৯. Database ও DBMS কী? Type of DBMS and Core components of a database environment.
৯০. Conventional File Processing System (CFPS) বনাম DBMS এর তুলনামূলক পার্থক্য ও ডেটাবেজ ব্যবহারের উদ্দেশ্য লিখুন।
৯১. DBMS এবং RDBMS এর মধ্যকার পার্থক্য লিখুন।
৯২. Database 3-tier Architecture চিত্রসহ বিস্তারিত বর্ণনা করুন।
৯৩. Data Abstraction কী? ডেটা অ্যাবস্ট্রাকশনের বিভিন্ন লেভেল (Physical, Logical, View Level) আলোচনা করুন।
৯৪. Database Schema ও Database Instance কাকে বলে? স্কিমার প্রকারভেদ লিখুন।
৯৫. Data Model কী ও কত প্রকার? Relational Data Model এর সুবিধা ও অসুবিধাগুলো লিখুন।
৯৬. রিলেশনশিপ (Relationship) বলতে কী বোঝায়? দুটি টেবিলের মধ্যে রিলেশন তৈরির পদ্ধতি এবং রিলেশনশিপের প্রকারভেদ (One-to-One, One-to-Many, Many-to-Many) লিখুন।
৯৭. রিলেশনশিপের ডিগ্রি (Degree of Relationship) কাকে বলে ও কত প্রকার?
৯৮. Database User, Manager এবং Database Administrator (DBA)-এর দায়িত্ব ও কার্যাবলী লিখুন।
৯৯. Entity ও Entity Set কী? Strong Entity Set এবং Weak Entity Set এর মধ্যে পার্থক্য লিখুন।
১০০. Attribute কাকে বলে এবং Attribute এর প্রকারভেদ আলোচনা করুন।
১০১. E-R Diagram এর উপাদান ও ব্যবহৃত প্রতীকসমূহের সচিত্র বর্ণনা দিন। DFD ও ERD এর তুলনা লিখুন।
১০২. Mapping Cardinalities বিস্তারিত বর্ণনা করুন।
