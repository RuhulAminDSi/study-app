২৬. ৩টি সংখ্যার মধ্যে বৃহত্তম ও ক্ষুদ্রতম সংখ্যা নির্ণয়ের ফ্লোচার্ট ও C প্রোগ্রাম লিখুন।
২৭. একটি বৃত্তের ক্ষেত্রফল ও পরিধি নির্ণয়ের জন্য C ভাষায় একটি প্রোগ্রাম লিখুন।
২৮. একটি ত্রিভুজের তিনটি বাহু দেওয়া আছে; এর ক্ষেত্রফল নির্ণয়ের জন্য ফ্লোচার্টসহ C প্রোগ্রাম তৈরি করুন।
২৯. চতুর্ভুজ এবং ত্রিভুজের ক্ষেত্রফল বের করার জন্য C প্রোগ্রাম লিখুন।
৩০. `ax² + bx + c = 0` দ্বিঘাত সমীকরণের মূল (`x` চলকের মান) নির্ণয়ের ফ্লোচার্ট ও C কোড লিখুন। [১৬তম NTRCA]
৩১. ২টি সংখ্যার ল.সা.গু (LCM) ও গ.সা.গু (GCD) নির্ণয়ের ফ্লোচার্ট এবং C প্রোগ্রাম লিখুন। [মার্ক ৫]
৩২. রিকার্সিভ ফাংশন ব্যবহার করে ২টি সংখ্যার ল.সা.গু ও গ.সা.গু নির্ণয়ের C প্রোগ্রাম লিখুন।
৩৩. ইনপুটকৃত কোনো পূর্ণসংখ্যার ফ্যাক্টোরিয়াল (Factorial) বের করার অ্যালগরিদম ও C প্রোগ্রাম লিখুন।
৩৪. একটি বর্ষ লিপ ইয়ার (Leap Year) কি না তা জানার জন্য C ভাষায় প্রোগ্রাম লিখুন। [মার্ক ৫]
৩৫. মৌলিক সংখ্যা (Prime Number) চেক করার জন্য একটি C প্রোগ্রাম লিখুন। [মার্ক ৫]
৩৬. কোনো সংখ্যা জোড় নাকি বিজোড় (Odd or Even) তা নির্ণয়ের প্রোগ্রাম লিখুন। [মার্ক ৫]
৩৭. পজিটিভ নাকি নেগেটিভ সংখ্যা তা পরীক্ষা করার C কোড লিখুন।
৩৮. `if...else` কন্ডিশনাল স্টেটমেন্ট ব্যবহার করে একটি আদর্শ C প্রোগ্রাম লিখুন।
৩৯. লুপ ব্যবহার করে ১ থেকে ১০০ পর্যন্ত সংখ্যাগুলো প্রদর্শন করার প্রোগ্রাম লিখুন।
