### ১. সি প্রোগ্রামিং (continued)

৪১. ১ থেকে ১০০ পর্যন্ত সংখ্যাগুলোর গুণফল বের করার C প্রোগ্রাম লিখুন।
৪২. `১ + ৩ + ৫ + ... + ১০০` পর্যন্ত সকল বিজোড় পূর্ণ সংখ্যার যোগফল বের করার C কোড লিখুন।
৪৩. লুপ ব্যবহার করে ১০১ থেকে ১০০১ পর্যন্ত সকল ক্রমিক সংখ্যার যোগফল নির্ণয়ের প্রোগ্রাম লিখুন।
৪৪. `S = 2² + 4² + 6² + ... + 20²` ধারাটির যোগফল নির্ণয়ের C প্রোগ্রাম লিখুন।
৪৫. `1² + 2² + 3² + ... + N²` ধারাটির যোগফল নির্ণয়ের প্রোগ্রাম লিখুন।
৪৬. `1 + 1/2 + 1/3 + 1/4 + ... + 1/N` সিরিজটির যোগফল বের করার প্রোগ্রাম লিখুন।
৪৭. প্রথম দশটি ফিবোনাচ্চি সংখ্যা (Fibonacci Numbers) প্রদর্শনের জন্য C প্রোগ্রাম লিখুন। [১৭তম NTRCA]
৪৮. এমন একটি C Program লিখুন যা একটি Array তে কতগুলো ডেটা রেখে ফলাফল হিসেবে বিপরীত দিক (Reversed Order) থেকে প্রিন্ট করবে। [১৭তম NTRCA]
৪৯. একটি Array-তে সংখ্যা ইনপুট নিয়ে তাদের যোগফল, গুণফল ও গড় বের করার C প্রোগ্রাম লিখুন। [১৬তম NTRCA]
৫০. বাইনারি সার্চিং (Binary Search) পদ্ধতিতে কোনো নির্দিষ্ট উপাদান খোঁজার C কোড লিখুন।
৫১. দুটি ইনপুটের ক্ষেত্রে বিটওয়াইজ AND, OR এবং XOR অপারেশনের মান নির্ণয়ের প্রোগ্রাম লিখুন।

### ২. অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং কনসেপ্ট (OOP & C++)

৫২. Object-Oriented Programming (OOP) বলতে কী বোঝায়? OOP কেন দরকার এবং এর মৌলিক ধারণাগুলো (Pillars) লিখুন। [১৫তম ও ১৭তম NTRCA]
৫৩. Class এবং Object কাকে বলে? কীভাবে Object তৈরি করতে হয় এবং এদের মধ্যে উদাহরণসহ পার্থক্য লিখুন। [১৫তম ও ১৭তম NTRCA]
৫৪. Data Abstraction ও Data Encapsulation বলতে কী বোঝায়? উভয়ের মধ্যে পার্থক্য লিখুন। [মার্ক ৩]
৫৫. Data Abstraction কী? Data Abstraction-এর বিভিন্ন স্তরগুলো (Levels of Abstraction) বর্ণনা করুন।
৫৬. Constructor ও Destructor ফাংশন কাকে বলে? উদাহরণসহ এদের সিনট্যাক্স ও পার্থক্য লিখুন। [মার্ক ৩]
৫৭. Inheritance কী? Inheritance-এর বিভিন্ন প্রকারভেদ, সুবিধা ও অসুবিধা আলোচনা করুন। [১৭তম NTRCA]
৫৮. Polymorphism কী? উদাহরণসহ বিভিন্ন প্রকার Polymorphism আলোচনা করুন। [মার্ক ৫]
৫৯. Compile-time Polymorphism ও Run-time Polymorphism-এর মধ্যে পার্থক্য লিখুন।
৬০. Function Overloading ও Operator Overloading বলতে কী বোঝেন? উদাহরণ দিন।
৬১. Method Overloading এবং Method Overriding-এর মধ্যকার পার্থক্য লিখুন। [১৫তম NTRCA]
৬২. Friend Function কী? Friend Function-এর বৈশিষ্ট্য এবং সুবিধা ও অসুবিধাগুলো লিখুন। [১৬তম NTRCA]
