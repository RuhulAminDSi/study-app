## Content

1. Write an essay on Artificial Intelligence and human civilization.
2. বাংলাদেশের অর্থনৈতিক উন্নয়নে নীল অর্থনীতির ভূমিকা সম্পর্কে একটি রচনা লিখুন।
3. নিচের অনুচ্ছেদটি ইংরেজিতে অনুবাদ করুন:

   > বর্তমান বিশ্বে তথ্য ও যোগাযোগ প্রযুক্তি মানুষের জীবনযাত্রাকে দ্রুত পরিবর্তন করছে। শিক্ষা, চিকিৎসা, ব্যবসা-বাণিজ্য ও সরকারি সেবায় প্রযুক্তির ব্যবহার কাজকে সহজ, দ্রুত ও কার্যকর করেছে। তবে প্রযুক্তির সুফল নিশ্চিত করার পাশাপাশি সাইবার নিরাপত্তা, ব্যক্তিগত তথ্যের সুরক্ষা এবং ডিজিটাল বৈষম্য কমানোর বিষয়েও গুরুত্ব দিতে হবে। দক্ষ মানবসম্পদ ও সঠিক পরিকল্পনার মাধ্যমে বাংলাদেশ প্রযুক্তিনির্ভর একটি উন্নত অর্থনীতি গড়ে তুলতে পারে।

4. What is RAID? Explain Different RAID Levels and How Capacity is Measured in RAID Systems.
5. Differentiate between a Program and a Process. Explain the different states of a Process with a suitable Process State Diagram.
6. Write a C program to replace a specified character in a string with another character.
7. Construct a Min Heap by inserting the following elements in order: 35, 12, 43, 8, 51, 20, 5. Differentiate Min Heap and Max Heap.
8. Given two tables `COURSE (Course_ID, Course_name, Chief_ID)` and `INSTRUCTOR (Instructor_ID, Course_ID, Salary, Joining_date)`, write a database query to find the average salary for different courses.
9. What is Inheritance in Object-Oriented Programming (OOP)? Why is it used? Which inheritance is not possible in Java, and how can it be acquired?
10. What is a Zero-Day Vulnerability? Differentiate between a Zero-Day Vulnerability and a Zero-Day Exploit.
