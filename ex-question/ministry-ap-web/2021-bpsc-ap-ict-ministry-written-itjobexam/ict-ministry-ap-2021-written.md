### BPSC — ICT Division (ICT Ministry), Assistant Programmer (59 posts) — Written, 2021 — Exam taker: BPSC (per title) — time and marks not printed — technical part only

**1. (ক)** IR 4.0 বলতে কি বুঝায়? IR 4.0 এর গুরুত্বপূর্ণ উপাদানগুলো লিখুন।
> Printed answer: definition of the Fourth Industrial Revolution plus a list of elements (cloud, IoT, big data, sensors, AR, RFID …).

**(খ)** Big data বলতে কি বুঝায়? Big data এর বৈশিষ্ট্যগুলো লিখুন। [held: bit to exabyte]

**2. (ক)** Procedural Oriented ও Object Oriented Programming Language মধ্যে পার্থক্য কি? উভয় Language এর ২টি করে উদাহরণ দিন। [held: bit to exabyte]

**(খ)** Recursion কি? Recursion পদ্ধতিতে একটি Integer সংখ্যার Factorial নির্ণয়ের জন্য C-Language এ একটি Program লিখুন।
> Printed answer: cross-reference only ("[See BPSC, Assistant Network Engineer, Written Exam: 2020]").

**3. (ক)** Data transfer rate এর ভিত্তিতে নিম্নোক্ত memory/storage device গুলাকে বেশী থেকে কম ক্রমানুসারে সাজান।
(i) Flash drive (ii) SSD (iii) Cache memory (iv) DVD (v) RAM (vi) Magnetic HD
> Printed answer: Cache memory → RAM → SSD → Flash drive → Magnetic HD → DVD

**(খ)** Computer network এর OSI 7-Layer গুলো উদাহরণসহ লিখুন। [held: bit to exabyte]

**4. (ক)** Software এর alpha-version and β-version কি?

**(খ)** Software Requirement Specification (SRS) বলতে কি বুঝায়? Software Development এর কোন ধাপে SRS তৈরি করা হয়? [held: bit to exabyte]
> Printed answer: SRS is made in the "Feasibility Study" step.
> Answer issue: the SRS is produced in the requirements analysis/specification phase (after the feasibility study); the printed answer's own definition says it is "signed off at the end of requirements engineering phase".

**(গ)** Unit testing, Integration testing এবং Beta testing বলতে কি বুঝায়? [held: bit to exabyte]

**5. (ক)** Entity-Relationship (ER) Diagram কেন ব্যবহার করা হয়? একটি উদাহরন এর মাদ্ধ্যমে ব্যাখ্যা করুন।

**(খ)** Relational Database Design এ Primary Key ও Foreign Key বলতে কি বুঝায়? উদাহরণসহ লিখুন।

**6. (ক)** Wi-Fi Network সম্পর্কে সংক্ষিপ্ত বিবরণ দিন। Wi-Fi Sensor Network এবং Ad Hoc Network এর মধ্যে পার্থক্য লিখুন। [held: bit to exabyte]

**(খ)** Authentication বলতে কি বুঝায়? Two Factor Authentication কি? উদাহরণসহ ব্যাখ্যা করুন।

**7. (ক)** Cloud Computing এর সার্ভিসগুলো লিখুন। [held: bit to exabyte]

**(খ)** Algorithm কি? Algorithm প্রকাশের তিনটি পদ্ধতির নাম লিখুন। [held: bit to exabyte]

**(গ)** Universal logic gate কি? 3-input 17 এর একটি Universal logic gate এর Logic symbol 47 এবং Truth Table দেখান। [held: bit to exabyte]

**8. (ক)** কোন প্রতিষ্ঠানের Web page development এ HTML এবং CSS এর ভূমিকা কি? শুধুমাত্র HTML এবং CSS ব্যবহার করে কোন ধরনের Web Page Development করা যেতে পারে?
> Printed answer: HTML gives structure, CSS layout; only static web pages.

**(খ)** PHP কি? Web Development এ Java Script এর প্রয়োজনীয়তা সম্পর্কে বিবরণ দিন।
