## Content

### DoICT (Department of ICT), Assistant Programmer — MCQ (screening), 24.12.2021 per listing (26-12-2021 per URL), 2020 circular — Exam taker: not shown — 100 MCQ — Computer & ICT items 1–15 (site order)

**1.** মেইন মেমরী কোনটি?
RAM / ROM / HDD / Floppy
> Printed answer: RAM

**2.** একটি IPv6 Address এর দৈর্ঘ্য কত?
32 bits / 128 bits / 64 bits / 256 bits
> Printed answer: 128 bits

**3.** 'b'এর ASCII Value কত?
66 / 98 / 3000 / 1
> Printed answer: 98

**4.** নিচের কোনটি ইমেইল প্রটোকল?
SMTP / IOT / SB / OTG
> Printed answer: SMTP

**5.** Object oriented Programming এর বৈশিষ্ট্য কোনটি?
Polymorphism / Friend Function / Structure / Loop
> Printed answer: Polymorphism

**6.** Sequence Control Register আর কি নামে পরিচিত?
Program Counter / Instruction Counter / Sequence Register / Controlling Register
> Printed answer: Program Counter

**7.** নিচের কোনটি Invalid Variable mean?
Average / No# of- student / xyz / y23x
> Printed answer: No# of- student

**8.** Intel 8086 micro process এর বহি”স্থ Address Bus এর Width কত বিট হয়? [held: duranta 1758501721]
8 bit / 16 bits / 20 bits / 32 bits
> Printed answer: 20 bits

**9.** নিচের কোনটি Database এর Aggregate ফাংশন? [held: duranta 1758501721]
Where / Sum / Select / From
> Printed answer: Sum

**10.** ACL ( Access Control List) এর দুটি প্রধান ধরন হল-
Standard and Extended / Standard and Specialized / Standard and Specialized / Extended and EEE
> Printed answer: Standard and Extended

**11.** FTP প্রোটোকল নিচের কোনটি ব্যবহার করে?
IP / TCP / UDP / SMTP
> Printed answer: TCP

**12.** C কী ধরনের প্রোগ্রামিং ভাষা-
Low Level language / Mid Level Language / High Level language / None of these
> Printed answer: High Level language
> Answer issue: Bangladeshi exam keys usually expect "Mid Level Language" for C; strictly C is a high-level language with low-level features. The site's key and the common coaching key differ.

**13.** E-mail Service এর সাথে কোনটি সম্পৃক্ত?
Telnet / SSH / DHCP / SMTP
> Printed answer: SMTP

**14.** কম্পিউটার নিম্নলিখিতভাবে Internet এর সাথে সংযুক্ত করা যায়-
Phase -Line modem / DSL / Cable modem / All of these
> Printed answer: All of these

**15.** Complete Binary Tree যার height n, তার মধ্যে node কতটি? [held: duranta 1758501721]
n / 2n / 2n+1 / 2n+1-1
> Printed answer: 2n+1-1 (i.e. 2^(n+1) − 1)
