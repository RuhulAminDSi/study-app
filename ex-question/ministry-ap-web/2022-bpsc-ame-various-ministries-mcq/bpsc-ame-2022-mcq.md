## Content

### BPSC — various ministries (general pool), Assistant Maintenance Engineer — Screening MCQ, 24.05.2022 — Exam taker: BPSC (not shown on page) — 100 MCQ — Computer & ICT items 1–15 (site order)

**1.** How long is an IPv6 address?
32 Bit / 128 Bits / 64 Bits / 132 Bits
> Printed answer: 128 Bits

**2.** Which is the relationship between paging and virtual memory? [held: duranta 1758501721]
Virtual memory came before paging / When pages are created in disks, it is called a virtual memory? / Virtual memory can never be implemented without paging / Both have the same concepts
> Printed answer: Virtual memory can never be implemented without paging

**3.** Which of the following search algorithm requires less memory? [held: duranta 1758501721]
Optimal Search / Breadth -First Search / Depth - First Search / Linear Search
> Printed answer: Linear Search

**4.** Which of the following pairs is an example of intra-domain routing protocols?
RIP, FTP / BGP, SMTP / ALOHA, RIP / OSPF, RIP
> Printed answer: OSPF, RIP

**5.** A stack is also called-
Last In First Out / First Last Out / Last In Last Out / First In First Out
> Printed answer: Last In First Out

**6.** Which of the following algorithms can not be designed without recursion?
Fibonacci series / Tower of Hanoi / None of A and B / Both A and B
> Printed answer: None of A and B

**7.** An example of a hierarchical data structure is a ____of environment.
state / situation / rank / size
> Printed answer: state

**8.** "There must not be any partial dependency" Which of the following normal Forms holds this condition/ [held: duranta 1758501721]
INF / 2NF / 3NF / BCNF
> Printed answer: 2NF

**9.** Which of the following will not be treated as a cloud service?
A VM rented from open based organization / A mobile connecting to weather and map services / ALMS service taken from a free service provider / An web portal hosted for Public Service Commission
> Printed answer: An web portal hosted for Public Service Commission

**10.** Travelling Salesperson Problem is an example of -
Polynomial -time / Np-Complete / NP / NP- Hard
> Printed answer: NP- Hard
> Answer issue: the optimisation TSP is NP-hard; its decision version is NP-complete, so both "NP-Complete" and "NP-Hard" are defensible.

**11.** Which of the following pairs of statements are not treated as identical by the compiler?
int foo (int*i); int foo(inti[]) / a[i]=5; i[i]=5 / char c [10];char*c; / void bar(int); void bar (int x)
> Printed answer: char c [10];char*c;

**12.** Which of the following pairs is an example of routing protocols?
ALOHA, SMTP / BGP< RIP / OSPF, FTP / FTP,SMTP
> Printed answer: BGP< RIP

**13.** Which of the following data structures follows the LIFO principle? [held: duranta 1758501721]
Stack / Linked List / Queue / Graph
> Printed answer: Stack

**14.** If we have a very small amount of additional memory, but a large number of items to sort, which of the following sorting algorithms should we use? [held: duranta 1758501721]
Merge sort / Heap sort / Buble sort / Bogo sort
> Printed answer: Heap sort

**15.** Which of the following pairs is an example of transport layer protocols of the OSI model?
IP, ICMP / ARP,IP / TCP,IP / UDP, IP
> Printed answer: UDP, IP
> Answer issue: IP is a network-layer protocol, so no option is a pair of transport-layer protocols; the intended answer was presumably "TCP, UDP", which is not offered.
