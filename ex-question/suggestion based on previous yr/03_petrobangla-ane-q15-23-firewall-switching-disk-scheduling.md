## Content

15. : Draw a diagram of LAN including network Firewall. Why is firewall important in network security? List major types of network firewalls. Differentiate between Traditional Firewall and next generation Firewall.
16. : Write down the basic difference of the following:
    a. Public vs Private IP address
    b. L2 vs L3 Switch
17. Security of Key Storage: Secure storage prevents unauthorized key access.
18. Differentiate between Domain and Boadcast Domain in computer network. What is the function of DNS and DHCP?
19. Do you prefer packet switching compared to circuit switching in communication network? If yes, why? How does packet switching work step by step? What applications use packet switching?
20. What is BIOS
21. What is Packet Switching, Circuit Switching. Differentiate between them. Which is better. Given Real life Example of its.
22. Consider a disk pack with the following specifications- 16 surfaces, 128 tracks per surface, 256 sectors per track and 512 bytes per sector. Answer the following questions –
    i. What is the capacity of disk pack?
    ii. What is the number of bits required to address the sector?
    iii. If the format overhead is 32 bytes per sector, what is the formatted disk space?
23. Process arrival time and execution time of Operating system tasks table is given-

    | Process | Arrival Time | Execution Time |
    |---|---|---|
    | A | 0 | 10 |
    | B | 3 | 7 |
    | C | 5 | 3 |
    | D | 8 | 5 |

    Find out average waiting time for FCFS, preemptive SJF, and Round Robin where time quantum is 3.
