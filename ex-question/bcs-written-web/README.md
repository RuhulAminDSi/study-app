# BCS written papers from the web: ICT (281), Computer Science (971) and Lecturer ICT

This folder collects BCS technical written papers found on the web: ICT (281), Computer Science (971) and General Education Lecturer ICT. It was searched on 2026-10-16, in English and Bangla, for every round from the 10th to the 49th, including the special rounds.

Each paper has its own folder, which holds:

- the downloaded files, kept as untrusted data
- a `.md` transcription
- a `.records.json` sidecar (written only where the questions are new)
