**3.** Find the output from the following: take input and looks the output: Suppose
Input: 6789
Output: 9876

```c
#include <stdio.h>
int main()
{
    int number, rev = 0, remainder;
    printf("\nEnter a number: ");
    scanf("%d",&number);
    printf("\nReversed Number: ");
    while(number != 0)
    {
        remainder = number%10;
        rev = rev*10 + remainder;
        number /= 10;
    }
    printf("%d",rev);
    return 0;
}
```

**5.** Employee & department table given. 2 query's.
(i) Write the employee name who got same salary named Rahim but not same job of Rahim.
(ii) 2. Write the employee's name who's average salary is more than company's average salary

> Printed answer: (i) self-join on equal salary, `e.job <> r.job`, `r.name = 'Rahim'`; (ii) `GROUP BY name HAVING AVG(salary) > (SELECT AVG(salary) FROM employees)`.
