3: Which of the following modifiers cannot be applied to a method in C++?[সাধারণ পুলের 
আওতায় সহকারী প্রাগ্রামার ২২] 
ক) Protected খ) Private গ) Public ঘ) Abstract 
Answer: ঘ) Abstract 
Explanation: In C++, abstract is not a modifier. Instead, an abstract class is defined by including 
at least one pure virtual function. The keywords private, protected, and public are valid method 
access modifiers. 
Public: 
Members declared as public are accessible from anywhere in the program, both inside and 
outside the class. 
This is typically used for interfaces and functions that need to be exposed to external code. 
Private: 
Members declared as private are only accessible from within the same class. 
They cannot be accessed directly from outside the class or by derived classes. 
This promotes data hiding and encapsulation, ensuring that internal implementation details are 
not directly manipulated by external code. 
By default, class members are private if no access modifier is specified.  
Protected: 
Members declared as protected are accessible within the same class and by derived classes 
(classes that inherit from the current class). 
They are not accessible directly from outside the class by non-derived classes. 
This allows for controlled access in inheritance hierarchies, where derived classes need to access 
base class members for specific functionalities.

1. The bandwidth of a channel is 1 MHz. The SNR for this channel is 63. What are the bit

Answer: L

C = B × log₂(1 + SNR) 
Where B = 1 MHz, SNR = 63 
log₂(1 + 63) = log₂(64) = 6 
So, C = 1 × 6 = 6 Mbps 
Therefore, the maximum bit rate achievable without error due to noise is 6 Mbps.
