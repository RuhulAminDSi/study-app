**10.** Suppose a circular array QUEUE has 6 memory locations.what are the values of front and REAR after the following operation ?
(i) Initially QUEUE  is empty .
(ii) A, C and D are added to the queue ;
(iii) F is inserted.
(iv) Two letters are deleted;
(v) K, L and M are added to the queue;
(vi) Two letters are deleted and
(vii) R is added to the queue.

> Printed answer: array snapshots ending A C K R.

> Answer issue: the printed snapshots delete from the rear (A C D F → A C), which is stack behaviour. For a circular queue of 6 cells (1-based), deletions remove A, C then D, F: FRONT = 1, REAR = 3 → REAR = 4 → FRONT = 3 → K, L, M go to cells 5, 6, 1 so REAR = 1 → FRONT = 5 → R goes to cell 2. Final FRONT = 5, REAR = 2 (queue holds K, L, M, R).
