### BTCL Junior Assistant Manager (Technical) 05.04.2024 (Set-04)

Bangladesh Telecommunications Company Limited (BTCL) — Exam Date: 05.04.2024 — Post Name: JAM (Technical) — Exam taker: not printed — time: not printed — marks as printed: "Non: 15, dept: 20+5 Dept Written: 40" — pages 1–5. Document type: exam paper. Non-departmental part: not included in this document.

**1.** ৪বিট অ্যাডার দিয়ে ৪ বিট সাবট্রাক্টর ডিজাইন। (Design 4 bit Subtractor using 4 bit Adder)

> Printed answer: four full adders with each Bᵢ XORed with control line K, K also fed to Cin (K=1 subtract, K=0 add).

**2.** ৫৫ থেকে ২৭ ২'s complement এর মাধ্যমে বিয়োগ (Subtract from 55 to 27 using 2's complement)

> Printed answer: takes the 2's complements of both numbers and gets "−28".
> Answer issue: 55 − 27 = 28. In 8 bits: 00110111 + 11100101 (2's complement of 27) = 1 00011100; drop the carry → 00011100 = +28. (If the wording means 27 − 55, the result is −28 = 11100100, but the printed working does not show that.)

**3.**

```text
Department (dept_id,Salary, Dept_name)
Employee(dept_id, emp_name)
```

যাদের স্যালারির গড় ৫০০০০ থেকে বেশি তাদের নাম,আইডি দেখাও (Find Name, ID whose average salary is greater than 50000)

> Printed answer: join `Employee` to a derived table of `AVG(Salary)` per `dept_id` from `Department`, filter `avg_salary > 50000`.

**4.** Paging এবং Segmentation এঁর মধ্যে পার্থক্য (What is the difference between Paging and Segmentation)

> Printed answer: comparison table (fixed vs variable size, OS vs compiler, internal vs external fragmentation, page number + offset vs segment number + offset).

**5.** ৩ সংখার মধ্যে বড় সংখ্যা নির্ণয়ের ফ্লোচার্ট (Draw a flowchart to find largest number among three numbers)
তিনটি সংখ্যার মধ্যে ক্ষুদ্রতম সংখ্যা নির্ণয়ের ফ্লোচার্ট।

> Printed answer: two flowcharts (largest; smallest).

**6.** মাইক্রোকম্পিউটার এর উপাদান গুলো নাম সহ আর্কিটেকচার অংকন। (Draw a microcomputer architecture figuring out its components)

> Printed answer: block diagram — input device, microprocessor (ALU, control unit, register array), memory unit, output device.

**7.** ট্রি এর তিনটি বাস্তব উদাহরণ।(Give real example of tree)

> Printed answer: company organogram (CEO → GM → DGM → Manager → DM → AM), Bangladesh → division → district → upazila…, drive → folder → file.

**8.** নোড সংখ্যা N হলে edge সংখ্যা কত হবে। (What is the number of edge if node is N)

> Printed answer: complete undirected graph n(n−1)/2, directed at most n(n−1), tree n−1.

**9.** excel এর vlookup ফর্মুলা ব্যাখ্যা কর। (Explain vlookup formulae in excel)

> Printed answer: `VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])`, example `VLOOKUP(CSE103, A2:B6,2, FALSE)` on a course-code table.
