#### Part B — Written

- Non-IT: 1 Focus Writing in Bangla (10), 2 Focus Writing in English (10; "The Role of Sustainable Banking in Achieving the UN Sustainable Development Goals (SDGs) in Bangladesh."), 3 Translate into English (10), 4 Translate into Bangla (10), 5 General Knowledge (10; 5 items 5.1–5.5) — 5 questions, 50 marks.

**6.1** An organization has been assigned the IPv4 network address 192.168.1.0/24. As part of the network deployment, the network administrator is required to divide the address space into four equal-sized subnets to support different departments. Determine the Network Address, Subnet Mask (both CIDR and dotted-decimal notation)

> Printed answer: /26 = 255.255.255.192; networks 192.168.1.0, .64, .128, .192 (broadcasts .63, .127, .191, .255).

**6.2** Differentiate between a Fuse and a Miniature Circuit Breaker (MCB). Which one is more suitable for modern office electrical installations and why?

> Printed answer: fuse melts and must be replaced; MCB trips and resets — MCB preferred.

**6.3** Explain the working principle of a PN junction diode. Draw its symbol and describe the difference between forward bias and reverse bias.

> Printed answer: depletion region narrows in forward bias (P to +) and current flows; widens in reverse bias, almost no current.

**6.4** Differentiate between a Computer Virus and a Computer Worm based on how they spread and replicate across host networks.

> Printed answer: comparison table — a worm self-replicates over the network without a host file; a virus attaches to an executable and needs a host.

**6.5** Draw the circuit schematic diagrams to build an Exclusive-OR (XOR) logic function using only universal NAND gates.

> Printed answer: XOR = ((A′B)′ · (AB′)′)′ built with five NAND gates (two used as inverters).

**6.6** What is the difference between a Multiplexer and a Demultiplexer? Explain one practical application of each in digital systems.

> Printed answer: MUX = data selector (2ⁿ inputs → 1 output), DEMUX = data distributor (1 → 2ⁿ); MUX for CPU data selection/communication, DEMUX for signal routing/memory address decoding.

**6.7** Explain the concepts of Inheritance and Polymorphism in Java. Write a Java program to demonstrate method overriding.

> Printed answer: `Animal.sound()` overridden in `Dog`; `Animal a = new Dog(); a.sound();` prints "Dog barks".

**6.8** Describe any two key differences between the HTTP GET and HTTP POST methods used for communication between a web browser and a web server.

> Printed answer: GET retrieves with data in the URL and can be bookmarked; POST sends data in the request body.

**6.9** A physical server has 32 CPU cores, 96 GB RAM, and 4 TB storage. Each virtual machine (VM) requires 4 CPU cores, 16 GB RAM, and 500 GB storage. Calculate the maximum number of VMs that can be hosted on the server without overcommitting resources. Identify which hardware resource limits the number of VMs.

> Printed answer: CPU 8, RAM 6, storage 8 → maximum 6 VMs, limited by RAM.

**6.10** What is JDBC? Explain the steps required to connect a Java application to a MySQL database.

> Printed answer: Java Database Connectivity API; import, load driver, get connection, create statement, execute, process ResultSet, close.

**6.11** Describe the SQL Injection and Cross-Site Scripting (XSS) web security threats and suggest preventive measures for each.

> Printed answer: SQLi — prepared/parameterised queries, input validation, least privilege; XSS — input validation, output encoding, CSP, HttpOnly cookies.

**6.12** Describe the functions of a Switch and a Router and explain two key differences between these networking devices.

> Printed answer: switch — same LAN, MAC addresses, layer 2; router — between networks, IP addresses, layer 3.

**6.13** A system has three processes with the following arrival times and CPU burst times:

| Process | Arrival Time (ms) | Burst Time (ms) |
|---|---|---|
| P1 | 0 | 5 |
| P2 | 1 | 3 |
| P3 | 2 | 2 |

Using the First-Come, First-Served (FCFS) CPU scheduling algorithm, calculate the average waiting time and the average turnaround time.

> Printed answer: waiting 0, 4, 6 → 3.33 ms; turnaround 5, 7, 8 → 6.67 ms.

**6.14** An institute wants to create a database table named STUDENT to store student information. The table should include the columns Roll Number, Name, Department, Email, and Admission Date. Specify the most appropriate SQL data type for each column and identify which column should be defined as the Primary Key, giving a brief justification for your choice.

> Printed answer: INT, VARCHAR(100), VARCHAR(50), VARCHAR(100), DATE; primary key Roll Number (unique, not null).

**6.15** A software company has been hired to develop an Online Library Management System for a university. The librarian wants the system to be delivered in phases so that feedback from users can be incorporated after each release. As a software developer, identify the most suitable Software Development Life Cycle (SDLC) model for this project. Justify your choice by mentioning two advantages of the selected model.

> Printed answer: Incremental (iterative) model — phased delivery with user feedback; features added with lower risk.
