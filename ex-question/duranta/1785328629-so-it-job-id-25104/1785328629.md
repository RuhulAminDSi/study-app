### Bangladesh Bank — Banker's Selection Committee Secretariat (BSCS) — Senior Officer (IT), Grade-9 (Job ID-25104) — 25/07/2026 — Exam taker: not printed — Time 2 hours, Marks 200 (IT: 15×10 = 150) — pages 1–12

- Non-IT: 1 Focus Writing in Bangla (10; 4th Industrial Revolution and digital transformation of banking), 2 Focus Writing in English (10; "The Importance of Digital Literacy in Expanding Cashless Transactions in Bangladesh"), 3 Translate into English (10), 4 Translate into Bangla (10), 5 General Knowledge (10; 5 items 5.1–5.5) — 5 questions, 50 marks.

**6.** Why do modern processor designs favor a multi-stage pipelined approach over a single-cycle implementation?

> Printed answer: comparison table (single-cycle: one long cycle, low throughput; pipelined: overlapped instructions, shorter cycle, higher throughput, hazards handled by forwarding/stalling/branch prediction).

**7.** Explain the operational difference between Hashing and Encryption.

> Printed answer: hashing is one-way fixed-length digest for integrity/passwords (SHA-256); encryption is reversible with a key for confidentiality (AES, RSA).

**8.** Explain the difference between a "Compulsory Miss" (Cold Miss) and a "Capacity Miss" in cache memory.

> Printed answer: compulsory = first reference to a block; capacity = cache too small for the working set, reduced by a larger cache.

**9.** Consider the following relation:
Employee(EmpID, Name, Department, Salary)
Write an SQL query to retrieve the Department, the total number of employees, and the average salary for each department. The output should display one record for each department.

> Printed answer: `SELECT Department, COUNT(EmpID) AS TotalEmployees, AVG(Salary) AS AverageSalary FROM Employee GROUP BY Department;`

**10.** Explain the difference between Unit Testing and Integration Testing.

> Printed answer: unit = single component by developers (JUnit, pytest); integration = interfaces and data flow between modules, after unit testing.

**11.** Why is a Circular Queue preferred over a Linear Queue in many operating systems? Explain with one example.

> Printed answer: reuses freed slots and avoids false overflow; example — Round Robin ready queue.

**12.** What do the following specific HTTP status codes mean? Write down the exact standard text phrase for each:
(a) 200: ______________________
(b) 403: ______________________
(c) 503: ______________________

> Printed answer: 200 OK, 403 Forbidden, 503 Service Unavailable.

**13.** Simplify the following boolean expression using a 4-variable K-map.
F(A, B, C, D) = Σm(0,3,5,7,8,10,11,12,13,14,15)
Draw the K-map clearly, show your groupings (loops), and write the final simplified Sum-of-Products (SOP) expression.

> Printed answer: F = AD′ + BD + CD + B′C′D′ (checked: these four terms cover exactly the eleven minterms).

**14.** Five channels, each with a 100-kHz bandwidth, are to be multiplexed together. What is the minimum bandwidth of the link if there is a need for a guard band of 10 kHz between the channels to prevent interference?

> Printed answer: 5 × 100 + 4 × 10 = 540 kHz.

**15.** An organization is granted the IPv4 network block 14.24.74.0/24 and needs to segment it into two subnets:
- Subnet A (requires 120 addresses)
- Subnet B (requires 60 addresses)

Allocating sequentially from the requirement first to maximize remaining address space, state only the Network Address (with its CIDR mask) and the Broadcast Address for both subnets.

> Printed answer: A = 14.24.74.0/25, broadcast 14.24.74.127; B = 14.24.74.128/26, broadcast 14.24.74.191.

**16.** A startup company wants to launch a new web application. They do not want to manage any underlying hardware, operating systems, or even the runtime environment; they only want to focus on writing and deploying their code.
Based on your understanding of Cloud Service Models, which model (IaaS, PaaS, or SaaS) is most appropriate for them? Provide two real-world examples of platforms that provide this specific type of service.

> Printed answer: PaaS — Google App Engine, Heroku (also Azure App Service, AWS Elastic Beanstalk).

**17.** Define the following terms used in tree data structures:
(i) Tree
(ii) Leaf Node
(iii) Internal Node
(iv) Height of a Tree
Provide a suitable example to illustrate each term.

> Printed answer: example tree A(B(D, E), C(F)); leaves D, E, F; internal A, B, C; height 2 (edges).

**18.** Consider the following Java program and determine the integer value printed by the execution of the main() method.

```java
class Test {
    static int x = 5;
    public static int fun(int n) {
        if (n <= 1) {
            return 1;
        }
        x = x + 2;
        return fun(n - 1) + x;
    }
    public static void main(String[] args) {
        System.out.println(fun(3));
    }
}
```

> Printed answer: 19 (checked: x becomes 7 then 9; fun(2) = 1 + 9 = 10; fun(3) = 10 + 9 = 19, since Java evaluates fun(n − 1) before reading x).

**19.** An array contains one million sorted integers. Which searching algorithm would you choose to find a given element? Justify your answer.

> Printed answer: binary search, about log₂(10⁶) ≈ 20 comparisons, O(log n).

**20.** Consider the grammar:
E → E + E | E * E | id
Show that the grammar is ambiguous for the string:
id + id * idT

> Printed answer: two parse trees / leftmost derivations, id + (id * id) and (id + id) * id.
