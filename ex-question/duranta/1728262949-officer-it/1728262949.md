**1.** You are required to convert a 32 bit digital number to an analogue voltage over the voltage range of 0 to 3.3V with a Digital to Analogue converter (DAC). What is the resolution of the analogue output ?

> Printed answer: Resolution = 3.3 / 2^12 = 0.00080586 Volt = 0.080586mV.
> Answer issue: the printed answer uses 12 bits although the question says 32 bits, and its unit conversion is wrong (0.00080586 V = 0.806 mV, not 0.0806 mV). For a 32-bit DAC: 3.3 / 2^32 ≈ 7.68 × 10⁻¹⁰ V (≈ 0.77 nV; 3.3 / (2^32 − 1) gives the same to three figures). If the paper meant 12 bits: 3.3 / 4096 ≈ 0.806 mV.

**2.** Find the sets X and Y If XUY = {1,2,3,5,6,8,9,10}, X∩Y= {1,5}, Y−X= {2,6,9,10}

> Printed answer: X = (X∩Y) ∪ {3,8} = {1,3,5,8} (explained in Bangla); Y is not stated — it is {1,2,5,6,9,10}.

**3.** Convert the infix expression P = 12/(7-3)+2 to postfix expression and evaluate it.

**4.** Explain how encapsulation and inheritance are advantageous in Object Oriented Programming?

> Printed answer: data hiding / access modifiers / getters-setters for encapsulation; reusability, hierarchy, maintainability, extensibility for inheritance, with a Vehicle → Car / Motorcycle example.

**5.** If you throw two unbiased dice (each with six sides) together, what is the proabability that sum of two upward faces will be 7? Explain your answer.

> Printed answer: n(S) = 36, six favourable pairs, P = 6/36 = 1/6.

**6.** How many total bits are required of a Direct-Mapped cache with 16 KB of data and 4-word blocks, assuming a 32-bit address (word addressable) and 32-bit words?  [BUET MSC 21] [Officer IT'24] [B.B AME'2023]

> Printed answer: 2^10 blocks, tag = 32 − (10+2+2) = 18, valid 1 → 2^10 × (4×32 + 18 + 1) = 2^10 × 147, written as "147KB" and then "147Kb".
> Answer issue: the result is 147 **Kbits** (150,528 bits ≈ 18.4 KB), not 147 KB. The printed tag also subtracts 2 byte-offset bits, which assumes byte addressing; with the question's literal "word addressable", tag = 32 − 10 − 2 = 20 and the total is 2^10 × 149 = 149 Kbits.

**7.** Give the necessary condition for deadlock occur. Is it possible to have deadlock involving only a single process ? Explain your answer?

> Printed answer: mutual exclusion, hold and wait, no preemption, circular wait; no — a single process cannot form a circular wait.

**(10).** Using an explanation of the difference between flow-control and congestion control, Discuss the impact of a stable end-to-end latency.

> Printed answer: flow control protects the receiver, congestion control protects the network; stable latency gives a predictable RTT, better window sizing, early congestion detection and lower loss.

**(11).** Explain the difference between a singly linked list and a doubly linked list.

> Printed answer: six-row comparison table (one vs two pointers, one-way vs two-way traversal, memory use, insertion/deletion cost).

**(12).** Describe and estimate the costs of procedure to insert a new item into an existing binary max heap.

> Printed answer: gives the Max-Heapify pseudocode (O(log n)) and says inserting an element at the end takes O(1).
> Answer issue: insertion into a binary max heap appends at the end (O(1)) and then sifts the item **up** (heap-increase-key), costing O(log n) comparisons/swaps in the worst case; Max-Heapify (sift-down) is the delete/build step, not insertion.

**(13).** What is the worst-case time and space complexity of quicksort algorithm. Explain how this worst case behavior can occur?

> Printed answer: O(n²) time, O(n) stack space worst case (O(log n) best); occurs on an already-sorted array with an end pivot, shown with a recursion tree on n = 7.

**(14).** Write a function which receives an array of integers as parameter and print the numbers divisible by 3 in the array.

> Printed answer: C++ `printDivisibleBy3(int arr[], int size)`; for {10, 12, 15, 23, 30, 33, 40} prints 12 15 30 33.

**(15).** Consider you are given a database of a pet society with the following relations:
Animals (ID: integer, Name: string, PrevOwner: string, DateAdmitted: date, Type: string
Adopter (PSIN: integer, Name: string, Address: string, OtherAnimals: integer
Adoption(AnimalID: integer, PSIN: integer, AdoptDate: date, chipNo: integer)
Give a sql query that list total number of adoptions on June 30, 2024 for each animal type

> Printed answer: `SELECT A.Type, COUNT(*) … FROM Animals A JOIN Adoption AD ON A.ID = AD.AnimalID WHERE AD.AdoptDate = '2024-06-30' GROUP BY A.Type;`
