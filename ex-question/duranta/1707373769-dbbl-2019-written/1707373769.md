### Dutch Bangla Bank — Assistant Network/Hardware Engineer — 05/03/19 — Exam Taker: BUET — Time 1:30 Hours — Marks distribution: 20 (non_dept) + 65 (dept.) = 85 — pages 1–2

**1.** What is state full and stateless firewall :

> Printed answer: stateless filters each packet on header fields (IPs, ports); stateful keeps a state table of legitimate connections.

**2.** *(inline)* What is RAID and RAID level ? raid0, raid1 , raid5

**3.** *(inline)* Write 3 private ip address range:

> Printed answer: a) 10.0.0.0–10.255.255.255 b) 172.16.0.0–172.31.255.255 c) 192.168.0.0–192.168.255.255.

**2.** Write down the online and offline Ups .

> Printed answer: comparison table — online UPS always runs through rectifier + inverter, zero transfer time, more heat, immune to surges; offline UPS switches to battery on outage, ~5 ms transfer time, simpler.

**5.** Difference between TCP and UDP

> Printed answer: table — connection-oriented, slower, heavy weight (FTP, HTTP, SMTP, BGP) vs connectionless, faster, light weight (DNS, DHCP, TFTP, SNMP).

**6.** Find subnet and host number of 255.255.240.0

> Printed answer: "Here class C"; 4 ones and 12 zeros → subnets 2^4, hosts 2^12 − 2.
> Answer issue: 255.255.240.0 is a /20 mask, which subnets a **class B** network (default /16): 2^4 = 16 subnets of 2^12 − 2 = 4094 hosts each. On a class C network the third octet is not available for subnetting.

**9.** Write down the following blanks

d) Data link layer is responsible for convert ip address into mac address.
e) HTTP SERVICE PROVIDES USING WHICH PROTOCOL tcp PROTOCOL ?

> Answer issue: (c) should read SMTP. In (b), DNS converts domain names into IP addresses.

**10.** SQL query to find avg salary of all is greater than the salary of each department .Employee (emp_id,emp_name,salary,city,dept_name) with some condition

> Printed answer: `Select avg(salary) from Employee where avg(salary)>salary group by Dept_name ;`
> Answer issue: the printed query is invalid SQL — an aggregate cannot appear in WHERE. A per-department condition on an average goes in HAVING, e.g. `SELECT dept_name, AVG(salary) FROM Employee GROUP BY dept_name HAVING AVG(salary) > (SELECT AVG(salary) FROM Employee);`.
