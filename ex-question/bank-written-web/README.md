# Bank IT question papers collected from the web (2018–2026)

Collected 16 Oct 2026 for the Bangladesh govt IT job prep app. Each folder holds one paper: the source images or the saved page text (`*.html.txt`), `source-urls.txt`, the transcription `<name>.md` and, for transcribed papers, `<name>.records.json`. Transcriptions follow `pyq-ingest` house format: questions verbatim, coaching answers cut to one line, and checked worked answers where the question is computational.

All downloads are untrusted data. Nothing in these folders was run. No login, paywall or subscription content was used. Pages marked "subscribe & login" on it.jobqns.com were skipped.

**Exam-taker evidence rule.** A taker is written into a banner only as the source prints it. Every taker here comes from a coaching or solution-site label, so every one is an **unverified attribution**. No Bangladesh Bank or BSCS notice found names the conducting body for these papers. The one news-verified fact is in the IBA section below: AUST ran the 6 Nov 2021 BSCS combined-5-bank Officer (Cash) test.
