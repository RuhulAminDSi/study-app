### Bangladesh Bank — Assistant Director (General) — Preliminary MCQ, ICT section (Q91–100) — 17 July 2026 — Exam taker: not stated — 100 MCQ × 1 mark, 1 hour

- Non-IT: English Q1–20, Bangla Q21–40, Mathematics Q41–60, Analytical Q61–80, Financial & Banking Q81–90 — 90 questions, 90 marks.

**91.** A type of malicious software that infects computer systems, encrypts files, or locks users out of their devices is called –

- A) Ransomware
- B) Trojan horse
- C) XSS injection
- D) Denial of Service (DoS)

> Printed key: A) Ransomware

**92.** Which of the following is a core banking software?

- A) QuickBook
- B) Unix
- C) SAP
- D) T24

> Printed key: D) T24

**93.** Which protocol is used to send an email from a client to a mail server?

- A) HTTP
- B) FTP
- C) SMTP
- D) TCP/IP

> Printed key: C) SMTP

**94.** Which of the following is a volatile memory that loses its contents when power is off?

- A) Flash drive
- B) RAM
- C) Hard disk
- D) ROM

> Printed key: B) RAM

**95.** What type of cyberattack specifically uses deceptive emails, websites, or text messages to trick individuals into revealing sensitive information like passwords and credit card numbers?

- A) Man-in-the-middle
- B) Phishing
- C) Eavesdropping
- D) SQL injection

> Printed key: B) Phishing

**96.** What is the name of the firmware embedded on the motherboard that initializes hardware components during the booting process before loading the operating system?

- A) BIOS / UEFI
- B) CMOS Battery
- C) Kernel
- D) Chipset Driver

> Printed key: A) BIOS/UEFI

**97.** Which of the following is a high-level programming language?

- A) Machine code
- B) C++
- C) Assembly language
- D) C

> Printed key: B) C++
> Answer issue: C (option D) is also a high-level language; the item has two correct options.

**98.** Which device is used to connect multiple computers within the same wired local network to share data?

- A) Switch
- B) Router
- C) Modem
- D) Repeater

> Printed key: A) Switch

**99.** The keyboard keys ‘Shift’, ‘Ctrl’, and ‘Alt’ are called –

- A) Function Key
- B) Numeric Key
- C) Decoder Key
- D) Modifier Key

> Printed key: D) Modifier Key

**100.** What type of file uses the ‘.ini’ extension?

- A) Hypertext File
- B) Image File
- C) System File
- D) Video File

> Printed key: C) System File
