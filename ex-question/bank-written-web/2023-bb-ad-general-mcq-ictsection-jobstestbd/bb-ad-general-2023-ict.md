### Bangladesh Bank — Assistant Director (General) — Preliminary MCQ, "Basic computer knowledge" section (Q91–100) — 20 October 2023 — Exam taker: not stated — 100 MCQ, 1 hour, 100 marks

**91.** What kind of storage device can be affected by fragmentation? ক. Optical খ. Laser গ. Solid-state ঘ. Magnetic

> Printed key: ক. Optical
> Answer issue: fragmentation affects magnetic disks (ঘ), not optical media.

**92.** Which of the following is considered to measure the printing quality? ক. ppm খ. dpi গ. cpi ঘ. cps

> Printed key: খ. dpi

**93.** Which of the following commands is given to invoke ‘Task Manager’? ক. Ctrl+Alt+Del খ. Ctrl+Alt+F4 গ. Ctrl+Del+F12 ঘ. Alt+Del+F4

> Printed key: ক. Ctrl+Alt+Del

**94.** Webcam is a type of ___ device in a computer system. ক. System খ. Analogue গ. Input ঘ. Output

> Printed key: গ. Input

**95.** Which of the following tools is used in business intelligence? ক. OLAP খ. Data Mining গ. Web Mining ঘ. All of these

> Printed key: ঘ. All of these

**96.** What is the name given to the sequence of steps which a computer follows? ক. Instructions খ. Algorithm গ. Flowcharts ঘ. Software

> Printed key: খ. Algorithm

**97.** What is the meaning of ‘BCC’ in an email? ক. Blind Carbon Copy খ. Blind Close Copy গ. Bearer Carbon Copy ঘ. Blind Close Contact

> Printed key: ক. Blind Carbon Copy

**98.** In MS-Word, which of the following shortcut keys are used for aligning text to center? ক. Ctrl+M খ. Ctrl+C গ. Ctrl+E ঘ. None of the above

> Printed key: গ. Ctrl+E

**99.** What will be the result of the formula =Min (Average (B1, B2), Product (B3:B4)) where value of B1=20, B2=24, B3=15, B4=20? ক. 20 খ. 22 গ. 300 ঘ. None of the above

> Printed key: খ. 22

**100.** In MS-Excel, ‘#Name?’ error occurs when – ক. Function name is wrong খ. Argument is wrong গ. Cell reference is invalid ঘ. All of the above

> Printed key: গ. Cell reference is invalid
> Answer issue: #NAME? appears when a function or name is misspelled/unrecognised (ক), not for an invalid cell reference (that is #REF!).
