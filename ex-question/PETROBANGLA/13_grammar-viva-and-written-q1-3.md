**2. Given IP: 168.20.96.63, Subnet mask: 255.255.192.0 Find network address, broadcast address and number of host.**
Answer:
Given, Subnet mask = 255.255.192.0 = 11111111.11111111.11000000.00000000
Where, network bit =18 and host bit = 32-18 = 14
Now, Network address = 168.20.64.0 and Broadcast address = 168.20.127.255 and Total usable host = 2^14-2 = 16384-2 = 16382

**3. What is black box testing? Consider a program which computes the square root of an input integer between 0 and 5000. Determine the equivalence class test cases. Determine the test cases using boundary value analysis also.**
Answer:
Black Box Testing is a software testing method in which the functionalities of software applications are tested without having knowledge of internal code structure, implementation details and internal paths. Black Box Testing mainly focuses on input and output of software applications and it is entirely based on software requirements and specifications. It is also known as Behavioral Testing.
