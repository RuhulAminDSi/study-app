**6. (a) A list of numbers 3, 5, 7, 11, 13, 17 is stored in sequence. Which of the following data structure will have the least data movement when the number 11 is removed from the list? FIFO, QUEUE, HEAP, Linked list and stack. Justify your answer.**

**Answer:**

- **Linked List** will have the least data movement when the number 11 is removed form the list.
- **FIFO, QUEUE** and **HEAP** needs more data movement because to remove 11 there is a number of PUSH and POP operation.
- **HEAP** needs refresh the tree on every insert and delete operation occurred.
