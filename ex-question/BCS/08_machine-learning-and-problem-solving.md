- **User Feedback**
  - **Incremental Approach:** Users can provide feedback early and throughout the development process. This feedback can be used to refine requirements and improve the system incrementally, ensuring that the final product better meets user needs.
  - **Waterfall Approach:** User feedback is typically gathered only after the system has been fully developed and is in the testing phase. This can result in a mismatch between the delivered system and user expectations, requiring extensive modifications.
- **Resource Allocation**
  - **Incremental Approach:** Resources can be allocated more efficiently, with teams focusing on delivering one increment at a time. This approach can help in managing workloads and optimizing team productivity.
  - **Waterfall Approach:** All resources are often tied up in each phase, leading to potential bottlenecks. If one phase takes longer than expected, it can delay the entire project.

**24. What is machine learning? Differentiate among supervised learning vs unsupervised learning vs reinforcement learning.**

**Answer:** [See 45th BCS, Written (CSE-971), Exam: 31.01.2024]

**Machine learning** is a subset of AI focused on building systems that can learn from data without being explicitly programmed. It involves algorithms and statistical models that allow computers to improve their performance on a task as they are exposed to more data over time. Common techniques include supervised learning, unsupervised learning, and reinforcement learning.

| Supervised ML | Unsupervised ML | Reinforcement ML |
| --- | --- | --- |
| Learns by using labelled data | Trained using unlabelled data without any guidance. | Works on interacting with the environment |
| Labelled data type | Unlabelled data type | No-predefined data type |
| Extra supervision | No supervision | No supervision |
| Calculate outcomes | Discover underlying patterns | Learn a series of action |
| Use Risk Evaluation, Forecast Sales | Recommendation System, Anomaly Detection | Self Driving Cars, Gaming, Healthcare |
