**উত্তর (খ) RL = RS: Explanation (ব্যাখ্যা):** ম্যাক্সিমাম পাওয়ার ট্রান্সফার থিওরেম অনুযায়ী, একটি source-এর সাথে connected load-এর সর্বাধিক power transfer তখনই ঘটে যখন load resistance (RL) source-এর internal resistance (RS) এর সমান হয়। যদি R<sub>L</sub>= 0 (ক) হয়, লোড জুড়ে voltage শূন্য হয়, তাই পাওয়ার শূন্য।
যদি R<sub>L</sub>= ∞ (গ) হয়, লোডের মাধ্যমে current শূন্য হয়, তাই পাওয়ার শূন্য।
**R<sub>L</sub> = R<sub>S</sub>** হলে maximum power transfer হয়।

**25. Which mode in 8255 PPI allows handshake I/O?** [৮২৫৫ পিপিআই-এর কোন মোডে হ্যান্ডশেক I/O করা যায়?] [বিভিন্ন অহসিসিট মাস্টার্স -৪র্থ এডিশন- পাওয়ার নং- ১৪৬]

| | |
|---|---|
| (ক) Mode-0 | (খ) Mode-1 |
| (গ) Mode-2 | (ঘ) None of the above |

**উত্তর (খ) Mode-1: Explanation (ব্যাখ্যা):** 8255 Programmable Peripheral Interface (PPI)-এর তিনটি প্রধান operating mode রয়েছে:

- **Mode 0 (ক): Basic Input/Output mode।** handshaking ছাড়া সরল I/O।
- **Mode 1 (খ): Strobed Input/Output mode।** এই মোডে ডাটা ট্রান্সফারের জন্য **handshake signals** (যেমন STB, IBF, OBF, ACK) ব্যবহার করা হয়, যা peripheral devices-এর সাথে synchronized communication করতে দেয়।
- **Mode 2 (গ): Bi-directional Bus mode।** এটি handshaking সহ একটি bidirectional mode, কিন্তু এটি শুধুমাত্র Port A-এর জন্য available।

সুতরাং, **Mode-1** হল সেই মোড যা handshake I/O প্রদান করে।
