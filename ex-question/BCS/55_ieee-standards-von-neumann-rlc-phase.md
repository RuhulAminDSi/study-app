**উত্তর (ক) 802.5 [Ethernet]**

**Explanation (ব্যাখ্যা):** IEEE 802.5 হল টোকেন রিং নেটওয়ার্কের জন্য standard, ইথারনেটের জন্য নয়।

- **IEEE 802.11 (খ)** হল Wireless LAN (WLAN)-এর জন্য সঠিক standard।
- **IEEE 802.16 (গ)** হল WiMAX-এর standard।
- **IEEE 802.15.4 (ঘ)** হল Low-Rate Wireless Personal Area Networks (LR-WPAN)-এর standard, যা Zigbee-এর ভিত্তি।

**83. Von Neumann architecture uses ________ memory for data and instructions.** [ভন নিউম্যান আর্কিটেকচার ডেটা এবং instruction এর জন্য _________ মেমোরী ব্যবহার করে]

| অপশন | উত্তর |
|---|---|
| (ক) | separate |
| (খ) | same |
| (গ) | no |
| (ঘ) | None of the above |

**উত্তর (খ) same:**

**Explanation (ব্যাখ্যা):** ভন নিউম্যান আর্কিটেকচার (প্রিপলটন আর্কিটেকচার নামকও পরিচিত) হল একটি কম্পিউটার আর্কিটেকচার মডেল যা প্রোগ্রাম নির্দেশাবলী এবং ডেটা উভয়ের জন্য একটি একক, একীভূত মেমোরি (একই মেমোরি) ব্যবহার করে। এটি হ্যান্ডার্ড আর্কিটেকচারের বিপরীত, যা নির্দেশ এবং ডেটার জন্য আলাদা মেমোরি ব্যবহার করে। এই নকশার মূল পরিণতি হল ভন নিউম্যান বটলনেক, যেখানে নির্দেশ এবং ডেটার জন্য shared bus performance সীমিত করতে পারে।

**84. The phase difference between voltage and current in a series RLC circuit with R=100Ω, XL=300Ω, and XC=100Ω is:** [R=100Ω, XL=300Ω, এবং XC=100Ω সহ একটি সিরিজ RLC সার্কিটে ভোল্টেজ এবং কারেন্টের মধ্যে ফেজ পার্থক্য হল:] [বিভিন্ন অহিসিটি মস্টার -৪র্থ এডিশন- পাঠা নং- ১০৭৩]

| অপশন | উত্তর |
|---|---|
| (ক) | 0° |
| (খ) | 45° |
| (গ) | 60° |
| (ঘ) | 90° |

**উত্তর (গ) 60°:** প্রদত্ত তথ্য:

- রোধ, R = 100 Ω
- আবেক ধ্রুবাঙ্ক (Inductive reactance), X_L = 300 Ω
- ধারক বিভ্যাঙ্ক (Capacitive reactance), X_C = 100 Ω

সমাধান:

নেট বিভ্যাঙ্ক নির্ণয়: X = X_L − X_C = 300 − 100 = 200 Ω

ফেজ অ্যাঙ্গেলের সূত্র: tan φ = X / R = 200 / 100 = 2

ফেজ অ্যাঙ্গেল নির্ণয়: φ = tan⁻¹(2) ≈ 63.43°

অপশনের সাথে মিলনো: গণনাকৃত মান 63.43°, যা 60°-এর সবচেয়ে কাছাকাছি।
