**100. In Java, which keyword prevents a method from being overridden?** [জাভাতে, কোন কীওয়ার্ড একটি পদ্ধতিকে ওভাররাইড করা থেকে বিরত রাখে?] [বিভিন্ন অহিসিটি মস্টার -৪র্থ এডিশন- পাঠা নং- ৩০১]

| অপশন | উত্তর |
|---|---|
| (ক) | const |
| (খ) | final |
| (গ) | static |
| (ঘ) | synchronized |

**উত্তর (খ) final:**

**Explanation (ব্যাখ্যা):** জাভাতে, final কীওয়ার্ড ব্যবহারকারীকে সীমাবদ্ধ করে ব্যাখ্যা হয় যে অর্থ এটি একটি মেথডে প্রদান করা হয়, এর অর্থ হল মেথডটি একটি সাবক্লাস দ্বারা **override** করা যাবে না। inheritance hierarchy-এ একটি মেথডের expected behavior পরিবর্তন করা প্রতিরোধ করতে এটি ব্যবহৃত হয়।

- const (ক) is a reserved keyword in Java but is not used.
- static (গ) is used to create class-level methods and variables, not to prevent overriding.
- synchronized (ঘ) is used to control thread access to a method or block, not to prevent overriding.
