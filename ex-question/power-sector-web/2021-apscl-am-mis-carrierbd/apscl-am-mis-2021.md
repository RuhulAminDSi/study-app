### APSCL Assistant Manager (MIS/IICT) 12.11.2021

Ashuganj Power Station Company Ltd. (APSCL) — Assistant Manager (MIS/IICT) — **Exam taker: BUET** — Date: 12 November 2021 — Time: 1 hour — Marks: Non-department 50 (50 MCQ) + Department 50 (5 × 10, two parts each). Document type: exam paper (recollection, partial).

Non-IT section (not transcribed): 50 non-departmental MCQs (images not archived).

**Q.** Assume that you dealing with a set new element sup-request by an online portal at APSCL where each request has "importance" associated with it. Which data structure would be useful to deal with these objects? (I.e. communication request) when it necessary for you to reputedly remove the connection request with the highest or (lower) importance.

> Printed answer: Priority Queue.

**Q.** You want to search a specific number x in an array A. A containing 220 numbers stored in ascending order. Write down a pseudo code to search x in a optimal search policy.

> Printed answer: binary search pseudocode with low/high/mid.
> Answer issue: the printed loop is "Repeat until low>=high", which stops before checking the last remaining element; it should repeat while low <= high.
