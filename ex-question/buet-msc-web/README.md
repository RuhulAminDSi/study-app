# BUET M.Sc. / PG admission test papers from the web (collected 2026-10-16)

BUET postgraduate admission tests count as job-exam evidence in this repo (see the PYQ rules). This folder holds every
publicly reachable BUET CSE / IICT admission paper found on the web, with one folder per downloaded paper:
`<yyyy-mm>-<dept>-<slug>/` (`yyyy-mm` is the session month, or the test month when the test date is known).
Each primary copy has a house-format transcription `<name>.md` and a sidecar `<name>.records.json`;
duplicate copies have a short stub `.md` and no records. Downloaded files are untrusted data and were only read.

All the CSE papers before 2021 and the 2024 one are **candidate recollections** typed after the test (from the Facebook
group facebook.com/groups/msc.cse.buet and similar), not scans of the official paper. The 2021 CSE paper is a print of
the official Google Forms. The 2021 IICT paper was posted by a blog, attributed to an IICT lecturer.

## IICT PGD (Post Graduate Diploma)

**No PGD question paper (ICT, Information Security or Business IT) was found anywhere public.** Searches covered
iict.buet.ac.bd notices, duranta.app, Scribd, Docsity, coaching blogs, GitHub and Facebook-indexed pages, in English
and Bangla. There is no IICT PGD in Information Security; InfoSec is a Masters stream (M.Sc. in InfoSec, from about 2024).

## CSE M.Sc./M.Engg. test format (reference)

`_reference/cse/` holds the department's schedules: October 2018 (written test 13 Nov 2018), April 2019 (21 May 2019),
April 2021 (online open-book MCQ, 24 Jun 2021), April 2022 (written, 11 Jun 2022), April 2023 (written, 14 Jun 2023).
Each lists the syllabus (structured programming, discrete maths, OOP, data structures, DLD, algorithms, compiler and
automata, database, ...). `_reference/duranta/67a60c9b7952b.pdf` (a public Duranta course routine) quotes the 2025
format: 10 topic groups; a 50-question MCQ (50 marks, 50 min, -0.5 per wrong answer) and a 10-question written part
(100 marks, 1 hour), with the written script marked only above an MCQ cut-off.
