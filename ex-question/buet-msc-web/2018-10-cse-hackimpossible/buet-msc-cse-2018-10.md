### BUET M.Sc. CSE October 2018

BUET, Department of CSE: M.Sc./M.Engg. admission test, October 2018 session, held 13/11/2018 (date from the official schedule) - **Exam taker: BUET** - marks and time not recalled. Document type: exam paper (recollection).

**1.** Draw the maximum heap structure from a given array.

**2.** Write the time complexity of binary searches.

**3.** Why left empty strings have to be eliminated to build a parser

**4.** Draw DFA of words ending with two a’s only, that is ‘aa’ for grammar {a,b}

**5.** String compare code in C given, write the output.

**6.** Code snippet in C given, will it compile? If it compiles, what will be output?

**7.** C++ code given, write what is necessary in the class for the code to compile? (Constructor)

**8.** Java code given, find length of each string in string list without using for loop.

**9.** Find the number of integers not divisible by 3, 5 or 7 which are <= 100

> Note: worked out by inclusion-exclusion: 100 - (33+20+14) + (6+4+2) - 0 = 45.

**10.** Rafiq wants to go to Dhaka. He meets 3 persons at platform. Each only lies or only tells truth. Conversation given. Find which train Rafiq will take.

**11.** Minimize function of the given logic cirsuit.

**12.** Truth table given. Find out which circuit it refers to.

**13.** Why branching poses a problem for pipelining? How can you tackle this pipelining hazard?

**14.** Connection diagram given, assign IP adresses to each device.

**15.** Write a class to keep data of employees, project and employee info of a company.

**16.** What are the bottlenecks of the greedy algorithm?

**17.** Find the critical path of scheduling of the given company.

**18.** Pin diagram of a microprocessor given, name it with reasons.

**19.** Flow diagram of processor given. CISC or RISC? Explain in one sentence.

**20.** (i) Write command to create a directory tree. (ii) delete folder with all its component. (iii) find word in two files.

**21.** Four conditions of deadlock

**22.** Write down the full form of DDL, DML, DCL and TCL. Classify the following commands into DDL/DML/DCL/TCL SELECT, INSERT, GRANT, ALTER, MODIFY, COMMIT, ROLLBACK..etc

**23.** Assembly code

**24.** E-R diagram

**25.** What do you understand Business logic design? How will you do it?

**26.** Suppose you have to design 1000 functions in java. each functions contains 600 lines of codes. How would you do it with “Cumulo”(I have forgotten the name) framework.

**27.** Write down the port no of the following protocols, (HTTPS, SSH, SMTP etc)
