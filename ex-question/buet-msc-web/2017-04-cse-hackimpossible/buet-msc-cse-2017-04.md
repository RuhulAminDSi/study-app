## Content

### BUET M.Sc. CSE April 2017

BUET, Department of CSE: M.Sc./M.Engg. admission test, April 2017 session - **Exam taker: BUET** - 30 questions x 10 marks = 300 - Time: 1 hour 30 minutes. Document type: exam paper (recollection, 27 of 30 questions).

**1.** *(10 marks)* Why intermediate code generator is required between syntax analysis and semantic analysis?

**2.** *(10 marks)* What are the advantages of IDE algorithm?

> Note: almost certainly IDA* (iterative-deepening A*), as the `bit to exabyte` copy has it.

**3.** *(10 marks)* Draw a logic diagram of MOD-12 Up counter using only T FF?

**4.** *(10 marks)* Draw a B+ tree using the indexes- 12,14,19,30,21,22,13,34,18,23,38,40 where n=5?

**5.** *(10 marks)* A student can be identified by ID who has attributes name, Address, Grade. A Course can be identified by C_ID and its attributes are C_Name, Credit etc. A student can Enroll in multiple course similarly a course can be enrolled by many students. Draw an E-R diagram showing the relationship between Student and course with full and partial participation. Create database table for student and Course entity.

**6.** *(10 marks)* What is superscalar microprocessor explain briefly?

**7.** *(10 marks)* Write the regular expression which takes one or more alphanumeric character followed by even number of digits?

**8.** *(10 marks)* What is the problem of using small page size in memory? What are its advantages?

**9.** *(10 marks)* Write a pseudo code for heapsort algorithm using stack? You do not need to implement stack.

**10.** *(10 marks)* Write a pseudo code to identify a given sequence is palindrome or not using stack and queue. You do not need to write code to implement stack and queue?

**11.** *(10 marks)* Write a function that takes an integer number and separate each digit. You must have to use recursion.

**12.** *(10 marks)* Tables of 4 destination IP addresses are given associated with each interface. Another table was given with 4 different IP address with the blank field of interface. Fill the interfaces column for each destination IP using 1st table.

**13.** *(10 marks)* Consider an IP address (for ex 223.16.37.0/29). Find the subnet address and the last address for this network. If we want 12 addresses in the subnet than what will be the value of the subnet mask?

**14.** *(10 marks)* What are the differences between microprocessor and micro-controller?

**15.** *(10 marks)* Explain First order predicate logic?

**16.** *(10 marks)* Explain briefly the waterfall model?

**17.** *(10 marks)* Explain Super-scalar in Java?

> Note: printed as is; the intended topic is unclear (possibly a Java concept misremembered).

**18.** *(10 marks)* Pre order and in order sequence are given for a binary tree. Draw the binary tree?

**19.** *(10 marks)* Find the canonical sum of product of a function using K-Map? [ Function look like this A{w,x,y,z)=Summation of F{9,6,7,8}+M{3,4,5,6}]

**20.** *(10 marks)* Explanation of Hazard in computer Architecture.

**21.** *(10 marks)* One diagram in hazard in computer architecture.

**22.** *(10 marks)* C++ related some 5 MCQ(Protected, private, inheritance etc.)

**23.** *(10 marks)* Pipe lining in computer architecture related 4 fill in the blanks.

**24.** *(10 marks)* Design independent on software components with each of the team of project ( 5 statement True /false identification)

**25.** *(10 marks)* Prove that the value of n always the sum of value greater than 8 and 9 for n>=14 (similar question but I can't remind exactly)

> Note: as recalled the claim is garbled; the standard exercise of this shape is a strong-induction proof that every amount n >= some bound can be formed from given stamp values (with 8 and 9 the bound is 56).

**26.** *(10 marks)* Proof of Another Discrete math problem for a given function

**27.** *(10 marks)* Define multitasking, multi programming, and multi threading?
