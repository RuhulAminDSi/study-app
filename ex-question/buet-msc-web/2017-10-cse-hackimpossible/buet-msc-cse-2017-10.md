### BUET M.Sc. CSE October 2017

BUET, Department of CSE: M.Sc./M.Engg. admission test, October 2017 session - **Exam taker: BUET** - 30 questions x 10 marks = 300 - Time: 1 hour 30 minutes. Document type: exam paper (recollection).

**1.** *(10 marks)* A strange question stating that if an algorithm needs 21 steps for a 7×7 matrix multiplication, how many steps would it need for a nxn matrix multiplication

**2.** *(10 marks)* Explain the algorithm of how computers perform division

**3.** *(10 marks)* Bottlenecks of greedy AI algorithms

**4.** *(10 marks)* why are AI algorithms designed after goal not after problem

**5.** *(10 marks)* 5 short questions related to pointer arithmetic of C, this included multidimensional array.

**6.** *(10 marks)* Using pointer insert a number in a sorted list, it was forbidden to use array notation like array[] , all should be done by pointer notation

**7.** *(10 marks)* Rewrite a java swing code by lambda expressions

**8.** *(10 marks)* Thread in C++ , calculate factorial ( not pthread)

**9.** *(10 marks)* ER diagram

**10.** *(10 marks)* A huge SQL DDL code including constraints

**11.** *(10 marks)* Fill the blanks from computer architecture

**12.** *(10 marks)* short question from cache , functional position of cache in computer architecture , write through and write back cache , merits and demerits

**13.** *(10 marks)* What is super-scalar processor , why pentium is a super-scalar processor but 80386 is not

**14.** *(10 marks)* Advantages of AVR-XXXX (forgot the number) over 80386

**15.** *(10 marks)* Implement a queue by linked list , write the procedures of enqueue and dequeue and determine time complexity

**16.** *(10 marks)* How can you search a number in O(1) average complexity

**17.** *(10 marks)* A math from Operating System , page size and ....

**18.** *(10 marks)* Deadlock conditions

**19.** *(10 marks)* A very easy K Map with don't cares

**20.** *(10 marks)* Convert a 100 MHz clock to 50 MHz and 25 MHz by only using D flip-flops

**21.** *(10 marks)* Waterfall model of software engineering , advantages disadvantages

**22.** *(10 marks)* Use case diagram of a e-commerce service

**23.** *(10 marks)* Context Free Grammar of Even length non empty palindromes comprising of { a , b , c }

**24.** *(10 marks)* Meaning and usefulness of three operand operations, which data structures should be used for them

**25.** *(10 marks)* A lengthy logic question, two villagers one is liar one is truthful, they say something about direction , which one is telling the truth

**26.** *(10 marks)* Prove that in a group of 50 students of different height there is a increasing sub-sequence of height of length at least 8

> Note: as recalled the claim is too strong: with 50 > 7x7 distinct heights, Erdos-Szekeres guarantees an increasing *or* a decreasing subsequence of length 8, not necessarily an increasing one.

**27.** *(10 marks)* Some question about PAT , NAT

**28.** *(10 marks)* Should we compress before encrypting or encrypt after compressing, why ?

**29.** *(10 marks)* A Information System Design question

**30.** *(10 marks)* Another Information System Design question
