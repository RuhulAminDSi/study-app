১স্থানিক সংখ্যা পদ্ধতি

MCQ
সংজ্ঞা ভিত্তি (radix) r-এর স্থানিক (positional, weighted) পদ্ধতিতে অঙ্ক 0 … r − 1; i-তম স্থানের মান rⁱ: N = Σ dᵢ · rⁱ (ভগ্নাংশে i < 0)। বাঁয়ের বিট = MSB, ডানের বিট = LSB।
পদ্ধতিভিত্তিঅঙ্কউদাহরণকোথায় দেখি
বাইনারি20, 1(1011)₂ = 11সব হার্ডওয়্যার, বিট মাস্ক
অক্টাল80 – 7(157)₈ = 111ইউনিক্স পারমিশন: chmod 755
ডেসিমাল100 – 9(111)₁₀মানুষের ইনপুট/আউটপুট
হেক্সাডেসিমাল160 – 9, A – F(6F)₁₆ = 111অ্যাড্রেস, MAC, রং #FF8800

১ নিবল = 4 বিট · ১ বাইট = 8 বিট · n বিটে 2ⁿ টি বিন্যাস; N টি মানের জন্য ⌈log₂ N⌉ বিট লাগে (যেমন ১০০০টি মান → ১০ বিট)।

প্রচলিত ভুল ধারণা "সব সংখ্যা পদ্ধতি স্থানিক": ভুল। রোমান সংখ্যা (XIV) অস্থানিক। কম্পিউটারের চারটি পদ্ধতি স্থানিক।

৩চিহ্নযুক্ত সংখ্যার উপস্থাপন

হাই-ইল্ড
সংজ্ঞা হার্ডওয়্যারে "−" চিহ্ন নেই, তাই MSB-কে চিহ্ন বিট (sign bit) ধরা হয় (0 = +, 1 = −)। ধনাত্মক সংখ্যা তিন পদ্ধতিতেই একই; পার্থক্য শুধু −N লেখায়:
  • চিহ্ন-মান (Sign-magnitude, SM): চিহ্ন বিট 1, মান অপরিবর্তিত
  • ১-এর পরিপূরক (1's complement): +N-এর প্রতিটি বিট উল্টাও (= (2ⁿ − 1) − N)
  • ২-এর পরিপূরক (2's complement): বিট উল্টে 1 যোগ (= 2ⁿ − N)
সমাধানকৃত উদাহরণ ✍ 8 বিটে −45 (+45 = 0010 1101): SM = 1010 1101 · 1's = 1101 0010 · 2's = 1101 0010 + 1 = 1101 0011

পরীক্ষার ফাঁদ −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1 পরিসর শুধু 2's complement-এর; SM ও 1's complement-এ একটি বিন্যাস −0-তে যায়, তাই সেগুলো −(2ⁿ⁻¹ − 1)-এ থামে।
মনে রাখার কৌশল 2's complement-এ একটি ঋণাত্মক সংখ্যা বেশি: −128 = 1000 0000-এর কোনো +128 জোড়া নেই; একে ঋণাত্মক করলে আবার নিজেকেই পাওয়া যায়।

৪সব CPU কেন 2's complement ব্যবহার করে

হাই-ইল্ড
  • একটিই শূন্য (±0 যাচাইয়ের ঝামেলা নেই)
  • A − B = A + B′ + 1: একই অ্যাডার
  • MSB-এর ক্যারি আউট শুধু ফেলে দাও
  • চিহ্ন সম্প্রসারণ = MSB কপি
ভারযুক্ত দৃষ্টিভঙ্গি MSB-এর মান −2ⁿ⁻¹:
1101 0011 = −128 + 64 + 16 + 2 + 1 = −45
মনে রাখার কৌশল: শর্টকাট ডান দিক থেকে: প্রথম 1 পর্যন্ত (সেটিসহ) বিট হুবহু লেখো, বাকিগুলো উল্টাও: 0110 1000 (104) → 1001 1000 (−104) ✓

৫চিহ্ন সম্প্রসারণ (Sign Extension)

2's complement সংখ্যাকে বেশি বিটে নিতে নতুন প্রতিটি উচ্চ বিটে চিহ্ন বিট কপি করো; মান বদলায় না।
−5: 1011 → 1111 1011 · +5: 0101 → 0000 0101
(x86: MOVSX চিহ্ন-সম্প্রসারণ, MOVZX শূন্য-সম্প্রসারণ)

পরীক্ষার ফাঁদ ঋণাত্মক সংখ্যার সামনে 0 বসালে মান বদলে যায়: 1011 (−5) → 0000 1011 = +11। শূন্য-সম্প্রসারণ শুধু চিহ্নহীন সংখ্যার জন্য।

৬ওভারফ্লো শনাক্তকরণ

নিয়ম ওভারফ্লো: একই চিহ্নের দুটি সংখ্যা যোগে ফল বিপরীত চিহ্নের হলে (ভিন্ন চিহ্নে কখনো ওভারফ্লো হয় না)। হার্ডওয়্যারে: V = Cn−1 ⊕ Cn, অর্থাৎ MSB-তে আসা ক্যারি XOR MSB থেকে বের হওয়া ক্যারি।

৮পরিপূরকের সাহায্যে বিয়োগ: M − N

লিখিত পরীক্ষার প্রিয়
r's পরিপূরক দিয়ে
  1. N-কে M-এর সমান অঙ্কে আনো
  2. M + N-এর r's পরিপূরক
  3. শেষ ক্যারি → বাদ দাও (+)
  4. ক্যারি নেই → −(যোগফলের r's)
(r − 1)'s পরিপূরক দিয়ে
  1. M + N-এর (r − 1)'s পরিপূরক
  2. শেষ ক্যারি → LSB-তে 1 যোগ (এন্ড-অ্যারাউন্ড ক্যারি)
  3. ক্যারি নেই → −(যোগফলের (r − 1)'s)
সমাধানকৃত উদাহরণ ১: ডেসিমাল ✍ 72532 − 3250: 03250-এর 10's complement = 96750; 72532 + 96750 = 169282 → ক্যারি বাদ → 69282।
3250 − 72532: 03250 + 27468 = 30718, ক্যারি নেই → −(30718-এর 10's complement) = −69282।
সমাধানকৃত উদাহরণ ২: বাইনারি ✍ X = 1010100 (84), Y = 1000011 (67)
কাজহিসাবফল

X − Y, 1's1010100 + 0111100 = 1 0010000 → + 1 (এন্ড-অ্যারাউন্ড)0010001 = 17
Y − X, 2's1000011 + 0101100 = 1101111, ক্যারি নেই−0010001 = −17
Y − X, 1's1000011 + 0101011 = 1101110, ক্যারি নেই−0010001 = −17
পরীক্ষার ফাঁদ আগে N-এর সামনে 0 বসাও (3250 → 03250)। 1's/9's-এ এন্ড-অ্যারাউন্ড ক্যারি ভুলে গেলে উত্তর ১ কম হয়।
আইটি সংযোগ ALU বিয়োগ করে B উল্টে ও carry-in = 1 দিয়ে: SUB আসলে 2's complement দিয়ে ADD (অ্যাডার-সাবট্রাক্টর, পৃ. ৪)।
