## ১. মূল ধারণা
- **বুলিয়ান বীজগণিত (Boolean algebra):** শুধু দুটি মান, 0 ও 1, নিয়ে কাজ করা বীজগণিত। অপারেশন তিনটি: AND (·), OR (+), NOT (′)।
- প্রবর্তক **জর্জ বুল (১৮৫৪)**। সুইচিং সার্কিটে প্রয়োগ করেন **ক্লদ শ্যানন (১৯৩৮)**।

| অপারেশন | প্রতীক | নিয়ম | C-তে |
|---|---|---|---|
| AND | A · B বা AB | সব ইনপুট 1 হলেই কেবল 1 | `&&` |
| OR | A + B | সব ইনপুট 0 হলেই কেবল 0 | `\|\|` |
| NOT | A′ (Ā) | 0 ↔ 1 উল্টায় | `!` |

- **অগ্রাধিকার ক্রম:** ( ) → NOT → AND → OR। তাই A + BC′ = A + (B·(C′))।
- n টি চলক থাকলে সত্যক সারণিতে **2ⁿ** টি সারি, আর মোট **2^(2ⁿ)** টি ফাংশন সম্ভব (n = 2 হলে ১৬টি, n = 3 হলে ২৫৬টি)।
- ⚠ **ফাঁদ:** বুলিয়ানে 1 + 1 = 1 (OR), কিন্তু বাইনারি পাটিগণিতে 1 + 1 = 10।

## ২. হান্টিংটনের স্বতঃসিদ্ধ (১৯০৪) ও দ্বৈততা নীতি
ছয়টি স্বতঃসিদ্ধ:
১. আবদ্ধতা।
২. অভেদ: A + 0 = A, A·1 = A।
৩. বিনিময়।
৪. বণ্টন (দুটি রূপই: A(B + C) = AB + AC এবং A + BC = (A + B)(A + C))।
৫. পূরক: A + A′ = 1, A·A′ = 0।
৬. অন্তত দুটি ভিন্ন উপাদান (0 ≠ 1)।

বাকি সব সূত্র এই ছয়টি থেকে প্রমাণ করা যায়।

- **দ্বৈততা নীতি (duality):** + ↔ · এবং 0 ↔ 1 বদলাও, লিটারাল যেমন আছে তেমনই থাকবে। কোনো অভেদ সত্য হলে তার দ্বৈত রূপও সত্য।
  - A + 0 = A ↔ A·1 = A
  - A + AB = A ↔ A(A + B) = A
  - A + BC-এর দ্বৈত রূপ **A(B + C)**।
- 💡 **কৌশল:** দ্বৈত মানে অপারেটর উল্টাও, অক্ষর রাখো। পূরক মানে অপারেটর উল্টাও, প্রতিটি অক্ষরও উল্টাও।

## ৩. সূত্র ও উপপাদ্য (★ = শুধু বুলিয়ানে)
| # | সূত্র | রূপ | দ্বৈত রূপ |
|---|---|---|---|
| ১ | অভেদ | A + 0 = A | A·1 = A |
| ২ | শূন্য | A + 1 = 1 ★ | A·0 = 0 |
| ৩ | সমঘাতী | A + A = A ★ | A·A = A ★ |
| ৪ | পূরক | A + A′ = 1 ★ | A·A′ = 0 ★ |
| ৫ | দ্বি-পূরক | (A′)′ = A | নিজেই দ্বৈত |
| ৬ | বিনিময় | A + B = B + A | AB = BA |
| ৭ | সংযোগ | A + (B + C) = (A + B) + C | A(BC) = (AB)C |
| ৮ | বণ্টন | A(B + C) = AB + AC | **A + BC = (A + B)(A + C)** ★ |
| ৯ | শোষণ | A + AB = A ★ | A(A + B) = A ★ |
| ১০ | অপ্রয়োজনীয় লিটারাল | **A + A′B = A + B** ★ | A(A′ + B) = AB ★ |
| ১১ | কনসেনসাস | AB + A′C + BC = AB + A′C ★ | (A + B)(A′ + C)(B + C) = (A + B)(A′ + C) ★ |
| ১২ | ডি মরগান | (A + B)′ = A′B′ ★ | (AB)′ = A′ + B′ ★ |

- **প্রমাণ:**
  - A + AB = A(1 + B) = A।
  - A + A′B = (A + A′)(A + B) = A + B।
- 💡 **কনসেনসাস:** A একবার সাধারণ, একবার পূরক রূপে আছে। A বাদ দিয়ে বাকিগুলো AND করলে আসে BC। এই "সেতু" পদটি অপ্রয়োজনীয়।

## ৪. ডি মরগানের উপপাদ্য
- (A + B)′ = A′B′ এবং (AB)′ = A′ + B′। n টি চলকে: (A + B + C + …)′ = A′B′C′… এবং (ABC…)′ = A′ + B′ + C′ + …
- **ফাংশনের পূরক, F′:** প্রতিটি AND পদে বন্ধনী দাও, + ↔ · বদলাও (এটিই দ্বৈত রূপ), তারপর প্রতিটি লিটারালের পূরক নাও।
- ✍ **উদাহরণ:**
  - F = AB′ + A′C → F′ = (A′ + B)(A + C′) = A′C′ + AB।
  - F = x(y′z + yz′) → F′ = x′ + yz + y′z′।
  - (A + BC)′ = A′(B′ + C′) = A′B′ + A′C′।
- ⚠ **ফাঁদ:** (A + B)′ ≠ A′ + B′। অপারেটর না বদলে শুধু অক্ষর উল্টানোই সবচেয়ে সাধারণ ভুল।

## ৫. বীজগাণিতিক সরলীকরণ (প্রতিটি ধাপে সূত্রের নাম লেখো)
১. AB + AB′ + A′B = A + A′B = **A + B** (লিটারাল ৬টি → ২টি)।
২. (A + B)(A + B′) = A + BB′ = **A**।
৩. A′B′C + A′BC + AB′C = A′C + AB′C = C(A′ + B′) = **A′C + B′C**।
৪. XY + X′Z + YZ = **XY + X′Z** (কনসেনসাস: YZ = XYZ + X′YZ লিখে শোষণ)।
৫. A′BC + AB′C′ + ABC′ + ABC = **BC + AC′** (লিটারাল ১২টি → ৪টি)।

💡 **এই ক্রমে খোঁজো:** X + X′ জোড়া → এক পদের ভেতরে আরেক পদ (শোষণ) → X + X′Y → কনসেনসাস।

## ৬. মিনটার্ম, ম্যাক্সটার্ম ও ক্যানোনিকাল রূপ
| ABC | মিনটার্ম | mᵢ | ম্যাক্সটার্ম | Mᵢ |
|---|---|---|---|---|
| 000 | A′B′C′ | m0 | A + B + C | M0 |
| 001 | A′B′C | m1 | A + B + C′ | M1 |
| 010 | A′BC′ | m2 | A + B′ + C | M2 |
| 011 | A′BC | m3 | A + B′ + C′ | M3 |
| 100 | AB′C′ | m4 | A′ + B + C | M4 |
| 101 | AB′C | m5 | A′ + B + C′ | M5 |
| 110 | ABC′ | m6 | A′ + B′ + C | M6 |
| 111 | ABC | m7 | A′ + B′ + C′ | M7 |

- **ক্যানোনিকাল SOP** (গুণফলের যোগফল) = Σm। **ক্যানোনিকাল POS** (যোগফলের গুণফল) = ΠM।
- **মূল সম্পর্ক:**
  - mᵢ′ = Mᵢ।
  - Σm(…) = ΠM(বাদ পড়া সূচক), আর F′ = Σm(বাদ পড়া)।
  - #m + #M = 2ⁿ।
- **স্ট্যান্ডার্ড বনাম ক্যানোনিকাল:** স্ট্যান্ডার্ড রূপে (যেমন A + B′C) কোনো পদে চলক বাদ থাকতে পারে। ক্যানোনিকাল রূপে প্রতিটি পদে সব চলক থাকে।
- ✍ **উদাহরণ:** A + B′C = Σm(1, 4, 5, 6, 7) = ΠM(0, 2, 3), তাই F′ = Σm(0, 2, 3)।
- ⚠ **ফাঁদ:** ৩ চলকের F = Σm(1, 3, 5)-এর ম্যাক্সটার্ম 8 − 3 = ৫টি।

## ৭. কার্নো ম্যাপের নিয়ম (কার্নো, ১৯৫৩)
- ঘরগুলো **গ্রে কোড ক্রমে 00, 01, 11, 10** সাজানো, তাই পাশাপাশি দুটি ঘর ঠিক একটি চলকে ভিন্ন।
- ৪ চলকে ঘরের নম্বর (সারি AB, কলাম CD):

  | AB\CD | 00 | 01 | 11 | 10 |
  |---|---|---|---|---|
  | 00 | 0 | 1 | 3 | 2 |
  | 01 | 4 | 5 | 7 | 6 |
  | 11 | 12 | 13 | 15 | 14 |
  | 10 | 8 | 9 | 11 | 10 |

- **গ্রুপের নিয়ম:**
  ১. SOP-এর জন্য 1 গ্রুপ করো, POS-এর জন্য 0। X যেকোনো গ্রুপে যেতে পারে।
  ২. গ্রুপের আকার 1, 2, 4, 8 বা 16, এবং গ্রুপ সবসময় আয়তক্ষেত্র।
  ৩. গ্রুপ যত বড় সম্ভব, সংখ্যায় যত কম সম্ভব।
  ৪. গ্রুপ একে অপরের উপর পড়তে পারে।
  ৫. কিনারা ঘুরে আসে, চার কোণাও প্রতিবেশী।
- 2ᵏ ঘরের গ্রুপে k টি চলক বাদ যায়।
- **প্রাইম ইমপ্লিক্যান্ট (PI):** যে গ্রুপ আর বড় করা যায় না। **অপরিহার্য PI:** কোনো 1-কে একমাত্র এটিই ঢাকে, তাই উত্তরে এটি থাকতেই হবে।
- ⚠ **ফাঁদ:** প্রতিবেশী মানে এক বিট পার্থক্য। m1 ও m2 প্রতিবেশী **নয়**।

## ৮. কার্নো ম্যাপের উদাহরণ
- **(ক)** Σm(0, 1, 2, 5, 8, 9, 10) = **B′C′ + B′D′ + A′C′D**।
  - গ্রুপ: 0, 1, 8, 9-এর চতুষ্ক; চার কোণা 0, 2, 8, 10; এবং 1, 5-এর জোড়া।
  - তিনটি গ্রুপই অপরিহার্য।
- **(খ)** Σm(1, 3, 7, 11, 15) + d(0, 2, 5) = **CD + A′B′**। CD + A′D-ও সমান ন্যূনতম।
- **(গ)** 0 গ্রুপ করে: ΠM(0, 1, 2, 3, 6) = **A(B′ + C)**।
- ⚠ **ফাঁদ:** X তখনই নাও যখন তাতে গ্রুপ বড় হয়। ডোন্ট-কেয়ার ঢাকা বাধ্যতামূলক নয়।

## ১০. ন্যূনতম রূপ → গেট ও কোড
- SOP → NAND-NAND; POS → NOR-NOR (লজিক গেট নোট দেখো)। খরচ ≈ গেট + গেট ইনপুট।
- **আইটি সংযোগ:**
  - `!(age < 18 || age > 60)` == `age >= 18 && age <= 60`
  - `x || (x && y)` == `x`
  - SQL-এ `dept = 'IT' OR (dept = 'IT' AND pay > 50000)` == `dept = 'IT'`

## লিখিত প্রশ্ন (৮ নম্বর)
K-map ব্যবহার করে F(A, B, C, D) = Σm(0, 2, 5, 7, 8, 10, 13, 15) সরল করো এবং শুধু NAND গেট দিয়ে বাস্তবায়ন করো।

**আদর্শ উত্তর:**
১. চার কোণা (0, 2, 8, 10) থেকে আসে B′D′, আর মাঝের চারটি ঘর (5, 7, 13, 15) থেকে BD।
২. F = **B′D′ + BD** = B ⊙ D।
৩. NAND-NAND রূপে: F = ((B′D′)′(BD)′)′, যেখানে B′ ও D′ তৈরি হয় NAND ইনভার্টার দিয়ে।
৪. মোট **৫টি NAND গেট**।
