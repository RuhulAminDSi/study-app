1Combinational vs Sequential

MCQ + Written
Definition A sequential circuit is combinational logic plus memory: its outputs depend on the present inputs and on the present state, i.e. on the past history of inputs. The memory elements are latches or flip-flops, connected through a feedback path.
CombinationalSequential
Output frominputs onlyinputs + state
Memory, feedbacknoneyes (FFs)
Clocknot neededusually
Described bytruth tablestate table
Examplesadder, MUXregister, counter
Memory trick "Sequential = remembers". Ask: can the same input give two different outputs? If yes, the circuit has state, so it is sequential.

  • Fundamental mode (async): level inputs, only one changes at a time, and only when the circuit is stable
  • Pulse mode (async): inputs are pulses, one at a time, no clock
  • Critical race: two state bits change together and the result depends on which wins; cure: a one-bit-change state assignment

Clock: f = 1/T · duty cycle = tH/T × 100% · T = 20 ns → f = 50 MHz. A flip-flop is a bistable multivibrator (2 stable states → 1 bit); monostable = one-shot pulse; astable = no stable state, a clock oscillator (555 timer).

3The SR Latch: the Basic Memory Cell

high-yield
Definition A latch is two cross-coupled NOR or NAND gates, each output feeding the other's input: two stable states, Q = 1 (set) and Q = 0 (reset), with Q̄ = Q′.
SRQ⁺Action
00Qhold (no change)
010reset
101set
11?forbidden: Q = Q̄ = 0
S̄R̄Q⁺Action
11Qhold (no change)
100reset
011set
00?forbidden: Q = Q̄ = 1

NOR: Q = (R + Q̄)′, Q̄ = (S + Q)′ · NAND: Q = (S̄ · Q̄)′, Q̄ = (R̄ · Q)′ · each uses 2 gates

Exam trap Why is S = R = 1 (NOR) "forbidden"? ① Q and Q̄ become equal, so Q̄ is no longer the complement; ② if both inputs then return to 0 together, the latch races and the final state is unpredictable. For the NAND latch the bad input is 00, and 11 is hold.
Memory trick "NOR hates two 1s, NAND hates two 0s." NOR inputs are active-HIGH (idle at 0); NAND inputs are active-LOW (idle at 1, drawn with bars).

4Gated (Clocked) Latches

Gated SR latch: two steering NANDs in front of a NAND latch (4 NAND gates). EN = 0 → hold; EN = 1 → behaves as an SR latch (S = R = 1 still forbidden).

Gated D latch: S = D, R = D′ (add 1 inverter), so S = R = 1 can never occur. EN = 1 → Q = D (transparent); EN = 0 → Q is latched.

ENDQ⁺Mode
0XQlatched (hold)
100transparent
111transparent
IT link SR latch = switch debouncer. The 74LS373 octal transparent latch, enabled by ALE, separates the 8085's multiplexed AD0–AD7 bus.

DLD · Sequential CircuitsFlip-flops

5Level vs Edge Triggering

high-yield
Latch vs flip-flop A latch is level-triggered: it follows its input for the whole time EN is active. A flip-flop is edge-triggered: it samples its input only at the clock edge, rising (positive, 0 → 1) or falling (negative, 1 → 0).
Symbol trick ▷ on the clock pin = edge-triggered; a bubble + ▷ = falling edge; no ▷ = level (latch). A ┐ mark on the outputs = master-slave (pulse-triggered).

7Excitation Tables (for Design)

written favourite
Definition The characteristic table answers "given the inputs, what is Q⁺?" (analysis). The excitation table answers the reverse: "to move from Q to Q⁺, which inputs are needed?" (design of counters and state machines).
Q → Q⁺S   RJ   KDT
0 → 00   X0   X00
0 → 11   01   X11
1 → 00   1X   101
1 → 1X   0X   010

JK has the most X's (don't-cares), so JK designs need the simplest input logic; D needs no excitation table at all (D = Q⁺) but usually more gates.

Memory trick D column = Q⁺ column. T column = Q ⊕ Q⁺ (1 whenever it changes). JK: when Q = 0 only J matters (J = Q⁺, K = X); when Q = 1 only K matters (K = Q⁺′, J = X).
Exam trap Don't mix them: "J = K = 1 → toggle" is characteristic; "0 → 1 needs J = 1, K = X" is excitation (K = X, not K = 0).

8Race-Around & the Master-Slave Flip-Flop

high-yield

Race-around condition: in a level-triggered JK with J = K = 1, if the clock pulse width tp is longer than the propagation delay tpd, the output toggles again and again during one pulse, so the final state is unknown.

Avoided when tp < tpd < T, which is hard to guarantee. Real cures: master-slave or edge-triggered flip-flops.

  1. CLK = 1: the master follows J, K; the slave is disabled, so Q is frozen
  2. CLK → 0: the master freezes, the slave copies it → Q changes once, after the falling edge; Q cannot change during the pulse → no race-around

Drawback: 1s-catching: a glitch on J/K while CLK = 1 is caught by the master; edge-triggered FFs (7474 D, 74LS76 JK) avoid it.

9Flip-Flop Conversions

Method: ① characteristic table of the FF you want (its inputs + Q → Q⁺) ② add the excitation columns of the FF you have ③ K-map each available input in terms of the wanted inputs and Q ④ draw the logic in front of the available FF.

(8 rows compressed.) S = 1 only for Q = 0, J = 1 → S = JQ′; R = 1 only for Q = 1, K = 1 → R = KQ. S·R = 0 always, so no forbidden input.

10Timing Parameters & Maximum Clock

high-yield
  • Setup tsu: D stable before the edge
  • Hold th: D stable after the edge
  • tpd: clock-to-Q delay (tPLH, tPHL)
  • tw: min. CLK pulse width
Max clock Tmin = tpd(FF) + tcomb(max) + tsu (+ skew) → fmax = 1 / Tmin
Hold check: tpd(FF) + tcomb(min) ≥ th · Example ✍ 10 + 15 + 5 = 30 ns → fmax ≈ 33.3 MHz

Async inputs PRE′ (Q = 1), CLR′ (Q = 0): active-LOW, override the clock; both 0 not allowed (7474: dual +ve-edge D with PRE′/CLR′).

Exam trap tsu / th violated → metastability (Q stuck between 0 and 1). Fix: a 2-FF synchroniser.

DLD · Sequential CircuitsCounters I

12Ripple (Asynchronous) & Synchronous Counters

high-yield
Definition A counter steps through a fixed sequence of states on clock pulses. Modulus (mod) = number of distinct states. n FFs → up to 2ⁿ states (count 0 … 2ⁿ − 1); a mod-N counter needs ⌈log₂N⌉ FFs and divides the clock frequency by N.
FFsQ → CLKQ̄ → CLK
−ve edgeUPDOWN
+ve edgeDOWNUP

Ripple delay: the last FF settles after n · tpd → fmax = 1/(n · tpd). 4-bit, tpd = 10 ns → 40 ns → 25 MHz. Ripple also causes decoding glitches.

Mod-N by reset: a NAND detects state N and drives the asynchronous CLR′. Mod-6: NAND(Q2, Q1) at 110. Mod-10 (decade): NAND(Q3, Q1) at 1010. State N appears only for a few ns.

Synchronous counter: all FFs share CLK. T0 = 1, T1 = Q0, T2 = Q0Q1, T3 = Q0Q1Q2 (a bit toggles when all lower bits are 1). Down: use Q̄s. fmax = 1/(tpd + tAND + tsu), independent of n.

Ripple (asynchronous)Synchronous
ClockingFF0 only; each Q clocks the nextone common CLK
Speedslow (n · tpd), glitchesfast (one tpd), no glitches
Hardwaresimplest, no extra gatesextra AND gates
ICs7490 (÷10), 7492 (÷12), 7493 (÷16)74161, 74163, 74193
Exam trap 7490 = ÷2 + ÷5, counts BCD only with QA wired to CKB; 7493 = ÷2 + ÷8. 74161 clears asynchronously, 74163 synchronously (at the next edge); 74192/193 = up/down. A mod-N counter counts 0 to N − 1.

13Ring & Johnson Counters

high-yield
Ring counter A shift register with Q of the last FF → D of the first, preset to 1000. One 1 circulates: 1000 → 0100 → 0010 → 0001. n FFs → n states.
Johnson counter (twisted-ring, switch-tail): Q̄ of the last FF → D of the first, start 0000. n FFs → 2n states.
n FFsRingJohnsonBinary
Statesn2n2ⁿ
Unused2ⁿ − n2ⁿ − 2n0
Mod-10 FFs1054
Decodingnone2-in ANDn-in AND
foutf/nf/2nf/2ⁿ

Johnson decoding: one 2-input AND per state, e.g. 0000 → Q0′Q3′, 1000 → Q0Q1′, 1111 → Q0Q3, 0001 → Q2′Q3. Neither counter is self-starting: a wrong power-up state circulates forever, so add preset / correction logic.

Memory trick "Ring = n, Johnson = 2n (the twist doubles)." 4 FFs: ring mod-4, Johnson mod-8, binary mod-16.

  2. State table 0 → … → 5 → 0; 110, 111 unused = X

  4. K-maps with X at m6, m7:

15State Diagrams: Mealy vs Moore

high-yield
Definition A finite state machine (FSM) = states + inputs + outputs + next-state logic + output logic. A state diagram draws states as circles and transitions as arrows; a state table lists present state, input → next state, output. k states need ⌈log₂k⌉ FFs (binary code).
MealyMoore
Output depends onpresent state + inputpresent state only
Output writtenon the arrow: x/zin the circle: S/z
Number of statesfewerusually more (often one more)
Responsesame cycle; may glitch with inputa clock later; glitch-free

Sequence detector for 101 (overlapping): Mealy and Moore

Worked design (Mealy, D flip-flops) ✍ Assign S0 = 00, S1 = 01, S2 = 10 (Q1Q0); 11 unused = X.
Q1Q0xQ1⁺Q0⁺z
000 / 100 / 010 / 0
010 / 110 / 010 / 0
100 / 100 / 010 / 1

K-maps (11 = X): D1 = x′Q0 · D0 = x · z = xQ1
Trace: x = 0 1 0 1 0 1 1 0 1 → z = 0 0 0 1 0 1 0 0 1

State reduction: two states are equivalent if, for every input, they give the same output and go to the same (or equivalent) next states; merge them (row matching, implication chart). Fewer states → fewer FFs and gates.

State assignment: binary (fewest FFs), Gray (neighbouring states differ by 1 bit: simpler logic, race-free in async designs), one-hot (k FFs, one 1; fast, used in FPGAs). The Moore detector above has z = Q1Q0 if S3 = 11.

Exam trap Overlapping 101 detector: after 101 the last 1 starts the next match (S2 –1→ S1). Non-overlapping goes back to S0. "Output depends only on state" = Moore.
