1What Is a Logic Gate?

MCQ + Written
Definition A logic gate is an electronic circuit that takes one or more binary inputs and produces one binary output according to a fixed Boolean function. Gates are the building blocks of every digital system: ALU, memory, CPU control.
Gate = Boolean operator made of transistors
Boolean operationSymbolGateOutput is 1 when …
Logical productA·BANDall inputs are 1
Logical sumA+BORat least one input is 1
ComplementA′NOTthe input is 0
Counting rules
n inputs → 2ⁿ rows in the truth table
n variables → 2^(2ⁿ) different Boolean functions
(n = 2 → 4 rows, 16 functions)
Memory trick Write the input columns like binary counting: 00, 01, 10, 11. You can never miss a row.

2Logic Levels: Positive vs Negative Logic

A gate does not "see" 0 and 1; it sees voltage ranges.

  • Positive logic: HIGH = 1, LOW = 0 (the default)
  • Negative logic: HIGH = 0, LOW = 1

Same circuit, different labels → a different function.

TTL (5 V) levelInputOutput
LOW (0)VIL ≤ 0.8 VVOL ≤ 0.4 V
HIGH (1)VIH ≥ 2.0 VVOH ≥ 2.4 V

Noise margin = 2.4 − 2.0 = 0.8 − 0.4 = 0.4 V. CMOS thresholds scale with the supply (roughly 30% / 70% of VDD).

Exam trap A positive-logic AND gate behaves as an OR gate in negative logic; positive NAND = negative NOR (De Morgan in disguise).

The only single-input gate. The bubble ○ on any symbol means NOT. Two NOTs in a row cancel: (A′)′ = A.

Multi-input gates

  • n-input AND: 1 only for 11…1 (one row out of 2ⁿ)
  • n-input OR: 0 only for 00…0
  • AND, OR are associative: (A·B)·C = A·(B·C), so 2-input gates can be cascaded
Gating (enable / inhibit)
AND: control 1 → passes data, 0 → forces 0
OR: control 0 → passes data, 1 → forces 1
XOR: control 1 → inverts data
Memory trick AND = "all", OR = "any". AND looks for one 0 to kill the output; OR looks for one 1 to set it.

4NAND, NOR, XOR, XNOR

high-yield
NAND = NOT + AND

Y = (AB)′ · 0 only when all inputs are 1

NOR = NOT + OR

Y = (A+B)′ · 1 only when all inputs are 0

XOR (exclusive-OR)

A⊕B = A′B + AB′ · 1 when inputs differ

XNOR (equivalence)

A⊙B = AB + A′B′ · 1 when inputs are equal

Master truth table (all 2-input gates)

ABANDORNANDNORXORXNOR
00001101
01011010
10011010
11110001
Complement pairs: AND↔NAND, OR↔NOR, XOR↔XNOR
XOR properties

A ⊕ 0 = A  (pass)

A ⊕ 1 = A′  (invert)

A ⊕ A = 0

A ⊕ A′ = 1

commutative & associative

(A ⊕ B)′ = A′ ⊕ B = A ⊕ B′

n-input XOR = 1 when the number of 1s is odd → odd-parity function; used for parity generators/checkers, comparators, adders, controlled inverters.

Exam trap NAND and NOR are not associative: (A NAND B) NAND C ≠ A NAND (B NAND C). A 3-input NAND is (ABC)′, not a cascade of two 2-input NANDs.
Memory trick "N" in front = put a bubble on the output = flip that gate's column. XOR = "different → 1", XNOR = "same → 1".

DLD · Logic GatesUniversal gates

5Universal Gates: NAND & NOR

written favourite
Definition A gate is universal if NOT, AND and OR (hence any Boolean function) can be built from it alone. NAND and NOR are universal; AND, OR, XOR are not.

Only NAND

Only NOR (mirror image): NOR(A, A) = A′ (1 gate) · NOR then NOR-inverter = OR (2) · invert both inputs, then NOR: (A′ + B′)′ = AND (3).

FunctionNOTANDORXORXNOR
Min. 2-input NAND gates12345
Min. 2-input NOR gates13254
NAND and NOR swap the AND/OR and XOR/XNOR counts (duality)

XOR with 4 NAND gates (the minimum)

① P = (AB)′ = A′ + B′

② Q = (A·P)′ = (A(A′+B′))′ = (AB′)′

③ R = (B·P)′ = (A′B)′

④ Y = (Q·R)′ = AB′ + A′B = A ⊕ B

Exam trap Many textbooks draw XOR with 5 NAND or 6 NOR (inverters + SOP). Those work but are not minimal; MCQs ask the minimum: 4 NAND, 5 NOR.

6De Morgan's Theorems

high-yield
The two laws  (A · B)′ = A′ + B′    (A + B)′ = A′ · B′
n variables: (A·B·C…)′ = A′ + B′ + C′ + …  ·  (A + B + C + …)′ = A′·B′·C′…

Proof by truth table

AB(AB)′A′+B′(A+B)′A′B′
001111
011100
101100
110000

Equivalent symbols

Memory trick "Break the bar, change the sign". In symbols: bubble pushing: move bubbles from output to all inputs (or back) and swap AND ↔ OR.

Worked example (written-answer format)

Q Simplify F = (A + B)′ + (A′ + B′)′ and name the gate it equals. 4 marks
  1. De Morgan on each term: (A + B)′ = A′B′ and (A′ + B′)′ = A″B″ = AB
  2. So F = A′B′ + AB
  3. This is 1 when A = B → F = A ⊙ B (XNOR)
  4. Circuit: one XNOR gate replaces 2 NOR + 2 NOT + 1 OR → fewer gates, lower cost & delay

7Duality Principle

Rule Every Boolean identity stays true if you swap + ↔ · and 0 ↔ 1 (variables are not complemented).
IdentityIts dual
A + 0 = AA · 1 = A
A + A′ = 1A · A′ = 0
A(B + C) = AB + ACA + BC = (A + B)(A + C)
(A + B)′ = A′B′(AB)′ = A′ + B′
Exam trap The dual is not the complement. Complement also flips every variable (A → A′); the dual does not.

8From Truth Table to Gate Circuit

Minterm (m) AND term with every variable, = 1 for exactly one row. SOP = OR of minterms = Σm
Maxterm (M) OR term with every variable, = 0 for exactly one row. POS = AND of maxterms = ΠM
  1. Write the truth table (2ⁿ rows)
  2. Rows with F = 1 → minterms (SOP)
  3. Simplify (Boolean laws or K-map)
  4. Draw AND-OR (or NAND-NAND)
  5. Check every row again

Worked example: 3-input majority voter

F = 1 when at least two of A, B, C are 1 (e.g. 2-out-of-3 approval).

Canonical SOP: F = Σm(3, 5, 6, 7) = A′BC + AB′C + ABC′ + ABC

Canonical POS: F = ΠM(0, 1, 2, 4)

Simplify (add ABC twice, A + A′ = 1):

F = AB + BC + CA

= (A + B)(B + C)(C + A) in POS form

Two-level rules
SOP (AND-OR) → replace every gate by NAND = NAND-NAND
POS (OR-AND) → replace every gate by NOR = NOR-NOR
Why: F = ((AB)′(BC)′(CA)′)′ = AB + BC + CA by De Morgan

Fewer literals → fewer gates. Systematic minimisation (K-map, don't-cares) → see the Boolean Algebra lesson.

Exam trap The minterm list and the maxterm list are complements: together they cover all 2ⁿ row numbers (here {3,5,6,7} ∪ {0,1,2,4}).

  • Noise margin = how much noise a level tolerates (TTL: 0.4 V)
  • Integration scale (typical convention): SSI < 12 gates · MSI 12–99 · LSI 100–9,999 · VLSI ≥ 10,000

11Where Gates Work

Classic circuits
Half adder: S = A ⊕ B, C = AB
Even-parity bit for A, B, C: P = A ⊕ B ⊕ C
Equality (1-bit comparator): A ⊙ B

Written question Implement a 2-input XOR gate using the minimum number of NAND gates only. Draw the circuit and prove it algebraically. 8 marks
  1. Circuit: G1 = NAND(A, B) → P; G2 = NAND(A, P) → Q; G3 = NAND(B, P) → R; G4 = NAND(Q, R) → Y (diagram on sheet 5). 2
  2. P = (AB)′ = A′ + B′ (De Morgan); Q = (A(A′ + B′))′ = (AA′ + AB′)′ = (AB′)′; R = (A′B)′ 3
  3. Y = (Q · R)′ = Q′ + R′ = AB′ + A′B = A ⊕ B ✓ (De Morgan + double complement) 2
  4. Check: AB = 00 → P = 1, Q = 1, R = 1, Y = 0 ✓; AB = 10 → P = 1, Q = 0, Y = 1 ✓. 4 gates = minimum. 1
