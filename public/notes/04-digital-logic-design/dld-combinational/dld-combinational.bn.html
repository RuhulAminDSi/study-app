৬রিপল-ক্যারি (প্যারালাল) অ্যাডার

সংজ্ঞা n-বিট প্যারালাল অ্যাডারে n টি ফুল অ্যাডার পরপর জোড়া থাকে: প্রতিটির Cout পরেরটির Cin (C₀ = 0)। সব বিট একসাথে দেওয়া হয়, কিন্তু ক্যারি LSB থেকে MSB-তে ঢেউয়ের মতো (ripple) এগোয়।
বিলম্ব (Delay) প্রতি ধাপে ক্যারির পথ = ২ গেট-স্তর (AND → OR); সবচেয়ে খারাপ ক্ষেত্রে n টি ধাপই পার হয়: t ≈ n × tcarry ≈ 2n গেট-বিলম্ব। 16 বিট × 10 ns = 160 ns।

IC 7483 (নতুন পিন-বিন্যাস 74283): ৪-বিট বাইনারি অ্যাডার (fast carry); ৮ বিটের জন্য দুটি জোড়ো (C₄ → পরের C₀)।

সস্তা (n টি FA) কিন্তু ধীর: বিলম্ব n-এর সাথে রৈখিকভাবে বাড়ে।

৮৪-বিট অ্যাডার-সাবট্র্যাক্টর (XOR কৌশল)

প্রতিটি Bi মোড লাইন M-এর সাথে একটি XOR দিয়ে যায়; C₀ = M:

M = 0 → B ⊕ 0 = B, C₀ = 0 → A + B

M = 1 → B ⊕ 1 = B′, C₀ = 1 → A + B′ + 1 = A − B (2's complement)

সাইনড ওভারফ্লো: V = C₄ ⊕ C₃

আনসাইনড: C₄ = 1 → A ≥ B; C₄ = 0 → ফল ঋণাত্মক।

সমাধানকৃত উদাহরণ ✍ 7 − 5: 0111 + 1010 + 1 = 1 0010 → 2 (C₄ বাদ) · 5 − 7: 0101 + 1000 + 1 = 0 1110 = −2 · 6 + 5 = 1011: C₃ = 1, C₄ = 0 → V = 1, ওভারফ্লো
