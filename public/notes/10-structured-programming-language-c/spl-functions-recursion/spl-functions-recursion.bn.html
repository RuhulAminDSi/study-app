C · ফাংশন ও রিকার্শনফাংশন

১ফাংশন: প্রোটোটাইপ, ডেফিনিশন, কল

মৌলিক, সবসময় আসে ★
সংজ্ঞা ফাংশন (Function) হলো নামযুক্ত, স্বয়ংসম্পূর্ণ কোড ব্লক, যা একটি কাজ করে এবং বহুবার কল করা যায়। একটি C প্রোগ্রাম কতগুলো ফাংশনের সমষ্টি; এক্সিকিউশন শুরু হয় main থেকে। সাধারণ রূপ: return_type name(type p1, type p2) { body; return value; }। সুবিধা: পুনঃব্যবহার ও মডুলারিটি। দুই প্রকার: লাইব্রেরি ফাংশন (printf, sqrt) ও ইউজার-ডিফাইনড ফাংশন।
#include <stdio.h> int add(int a, int b); /* prototype */ int main(void) { int s = add(5, 3); /* call */ printf("%d\n", s); /* 8 */ return 0; /* success */ } int add(int a, int b) { /* definition */ return a + b; }
পরিভাষাঅর্থ
প্রোটোটাইপডিক্লারেশন: নাম, রিটার্ন টাইপ, প্যারামিটার টাইপ; শেষে ;, বডি নেই
ডেফিনিশনহেডার + বডি; প্রতি ফাংশনে ঠিক একটি
কলadd(5, 3): ভেতরে যায়, একটি মান ফেরত পায়
অ্যাকচুয়াল প্যারামিটারকলে দেওয়া আর্গুমেন্ট: 5, 3
ফরমাল প্যারামিটারহেডারের ভেরিয়েবল: a, b
নিয়মযা মনে রাখতে হবে
রিটার্ন মানপ্রতি কলে সর্বোচ্চ একটি মান; বেশি লাগলে পয়েন্টার প্যারামিটার বা struct ফেরত
void ফাংশনকিছু ফেরত দেয় না; আগেভাগে বেরোতে শুধু return; লেখা যায়
mainint ফেরত দেয়: 0 = সফল; void main() মানসম্মত নয়
প্রোটোটাইপনাম ঐচ্ছিক (int add(int, int);); একেবারে না থাকলে: C89 int ধরত, C99+ নিষেধ
মনে রাখার কৌশল "প্রোটোটাইপ = ভিজিটিং কার্ড; ডেফিনিশন = মানুষটি।" কার্ড অনেক বিলানো যায়, মানুষ কিন্তু একজনই।
পরীক্ষার ফাঁদ আর্গুমেন্ট মূল্যায়নের ক্রম অনির্দিষ্ট: f(i++, i++) আনডিফাইনড বিহেভিয়ার। স্ট্যান্ডার্ড C-তে এক ফাংশনের ভেতরে আরেকটি ডিফাইন করা যায় না।
সমাধানকৃত উদাহরণ ✍ আউটপুট int sq(int x){return x*x;} → printf("%d", sq(3) + sq(4)); ছাপে 25। অ্যাকচুয়াল 3, 4; ফরমাল x।

C · ফাংশন ও রিকার্শনপ্যারামিটার পাসিং

২প্যারামিটার পাসিং: ভ্যালু ও অ্যাড্রেস দিয়ে

সবচেয়ে বেশি আসে ★
সংজ্ঞা কল বাই ভ্যালু (Call by Value)-তে কলি ফাংশন প্রতিটি আর্গুমেন্টের একটি কপি পায় তার ফরমাল প্যারামিটারে, তাই ভেতরের পরিবর্তন কলারের কাছে পৌঁছায় না। C সব আর্গুমেন্ট ভ্যালুতে পাঠায়। কলারের ভেরিয়েবল বদলাতে হলে তার অ্যাড্রেস পাঠাতে হয়: ফরমাল প্যারামিটার হয় পয়েন্টার, আর ফাংশন *p দিয়ে লেখে। একে সাধারণত কল বাই রেফারেন্স (Call by Reference) বলা হয়, কিন্তু C-তে এটি অনুকরণ মাত্র — অ্যাড্রেসটিই কপি হয়। আসল রেফারেন্স (int &a) শুধু C++-এ।
void byVal(int a) { a = a + 5; } void byPtr(int *a) { *a = *a + 5; } int x = 10; byVal(x); /* x is still 10 */ byPtr(&x); /* x becomes 15 */
void swap(int *p, int *q) { int t = *p; *p = *q; *q = t; } int a = 10, b = 20; swap(&a, &b); /* a = 20, b = 10 */
বিষয়কল বাই ভ্যালুঅ্যাড্রেস (পয়েন্টার) দিয়েC++ রেফারেন্স
কী পাঠানো হয়মানের কপিঅ্যাড্রেসের কপিভেরিয়েবলের অ্যালিয়াস
ফরমাল / কলint a / f(x)int *a / f(&x)int &a / f(x)
কলারের ভেরিয়েবল বদলায়?নাহ্যাঁ, *a দিয়েহ্যাঁ
C-তে আছে?একমাত্র পদ্ধতিহ্যাঁ (পয়েন্টারের মান)না — শুধু C++
অ্যারে পয়েন্টারে রূপ নেয় (decay) void f(int a[]) ≡ void f(int *a): শুধু ০ নম্বর উপাদানের অ্যাড্রেস যায়, অ্যারে কপি হয় না, ভেতরের পরিবর্তন কলার দেখে। f-এর ভেতরে sizeof(a) = পয়েন্টারের আকার, তাই দৈর্ঘ্যও পাঠাও। বিস্তারিত: পরের লেসন।
স্ট্রাকচার কপি হয় struct আর্গুমেন্ট পুরোটা কপি হয় — বড় হলে ধীর, তাই const struct T *p পাঠাও; const প্রতিশ্রুতি দেয় যে ডেটা বদলাবে না। স্ট্রাকচার বিস্তারিত: লেসন ৪।
মনে রাখার কৌশল "ভ্যালু = ফটোকপি; অ্যাড্রেস = বাড়ির চাবি।" ফটোকপিতে দাগ দিলে আসলটা নিরাপদ; চাবি পেলে আসল বাড়িই এলোমেলো।
প্রচলিত ভুল ধারণা "C-তে কল বাই রেফারেন্স আছে" — না: পয়েন্টারও কপি হয়। কলির ভেতরে p = &y; লিখলে কলারের পয়েন্টার সরে না।
সমাধানকৃত উদাহরণ ✍ ভ্যালুতে swap void swap(int a,int b){int t=a;a=b;b=t;}, x=10,y=20; swap(x,y); printf("%d %d",x,y); → 10 20।

৩স্কোপের নিয়ম, লিংকেজ ও আয়ু

MCQ + আউটপুট ★
সংজ্ঞা কোনো আইডেন্টিফায়ারের স্কোপ (Scope) হলো প্রোগ্রাম টেক্সটের সেই অংশ, যেখানে তার নাম ব্যবহার করা যায়। লোকাল (ব্লকের ভেতরে, বা প্যারামিটার) ভেরিয়েবলের ব্লক স্কোপ; গ্লোবাল (সব ফাংশনের বাইরে) ভেরিয়েবলের ফাইল স্কোপ, ফাইলের শেষ পর্যন্ত। C স্ট্যান্ডার্ডে চার ধরনের স্কোপ: ব্লক, ফাইল, ফাংশন ও ফাংশন প্রোটোটাইপ।
int global = 100; /* file scope */ void show(void) { int local = 5; /* block scope */ { int local = 7; /* shadows it */ printf("%d ", local); /* 7 */ } printf("%d %d", local, global); } /* prints 7 5 100 */ /* in main(): local is unknown → error */
স্কোপ (C স্ট্যান্ডার্ড)কার জন্যকোথা থেকে … কোথা পর্যন্ত দৃশ্যমান
ব্লকলোকাল, ফাংশন প্যারামিটারডিক্লারেশনের স্থান → সমাপ্তি }

মনে রাখার কৌশল "স্কোপ = যে ঘরে নাম ধরে ডাকা যায়; আয়ু = মানুষটি কতদিন বাঁচে।" static লোকাল সারা প্রোগ্রাম বাঁচে, কিন্তু সাড়া দেয় শুধু নিজের ঘরে।
পরীক্ষার ফাঁদ ঢাকা পড়া (shadowed) গ্লোবালকে সেই ব্লকে নাম দিয়ে ধরা যায় না: C-তে ::x নেই (শুধু C++)। ডিক্লারেশনের লাইনের আগে ব্যবহার চলে না।
সমাধানকৃত উদাহরণ ✍ আউটপুট int x=1; void f(){int x=2; {x=3;} printf("%d",x);} ছাপে 3: ভেতরের ব্লক f-এর x-এ লেখে; গ্লোবাল থাকে 1।

সর্বোচ্চ গুরুত্ব ★
সংজ্ঞা স্টোরেজ ক্লাস (Storage Class) স্পেসিফায়ার কম্পাইলারকে ভেরিয়েবলের সংরক্ষণের স্থান, ডিফল্ট প্রাথমিক মান, স্কোপ, আয়ু ও লিংকেজ জানায়। C-তে চারটি প্রচলিত: auto, register, static, extern (C11-এ _Thread_local; typedef শুধু ব্যাকরণগতভাবে)। কিওয়ার্ড ছাড়া লোকাল ভেরিয়েবল auto; কিওয়ার্ড ছাড়া গ্লোবালের লিংকেজ এক্সটার্নাল।

void counter(void) { static int count = 0; /* once */ count++; printf("%d ", count); } /* main: counter(); counter(); counter(); prints: 1 2 3 */ /* without static: 1 1 1 */
static লোকাল: তিনটি তথ্য ① এটি তৈরি ও একবারই ইনিশিয়ালাইজ হয়, main শুরুর আগে — প্রতি কলে static int count = 0; লাইন আবার চলে না। ② এর ইনিশিয়ালাইজার ধ্রুবক রাশি হতে হবে: static int n = f(); C-তে কম্পাইল এরর। ③ কলের মাঝে মান ধরে রাখে, তবু স্কোপ ব্লকেই: main count-কে নাম ধরে পায় না। ফাংশন এর অ্যাড্রেস নিরাপদে ফেরত দিতে পারে — এটি কখনো মরে না।
মনে রাখার কৌশল "A-R অল্পায়ু, S-E দীর্ঘায়ু।" Auto ও Register ব্লক শেষে মরে, শুরু গারবেজে; Static ও Extern পুরো রান বাঁচে, শুরু শূন্যে।
পরীক্ষার ফাঁদ শূন্য ডিফল্ট = শুধু স্ট্যাটিক স্টোরেজ (static, গ্লোবাল)। ইনিশিয়ালাইজ না করা auto ও malloc মেমোরিতে গারবেজ (calloc দেয় 0)।
সমাধানকৃত উদাহরণ ✍ আউটপুট int f(){static int s=5; s+=2; return s;} → f(); f(); printf("%d", f()); ছাপে 11 (7, 9, 11)।

C · ফাংশন ও রিকার্শনextern · static · register

৫extern, static লিংকেজ ও register

ফাঁদে ভরা ★
সংজ্ঞা extern int g; একটি ডিক্লারেশন (Declaration): এটি বলে "g আছে, অন্য কোথাও ডিফাইন করা" এবং কোনো স্টোরেজ বরাদ্দ করে না। সব ফাংশনের বাইরে একমাত্র ডেফিনিশন (Definition) int g = 5; মেমোরি বরাদ্দ করে ও শূন্য ডিফল্ট বহন করে। প্রোগ্রাম g-কে বহুবার ডিক্লেয়ার করতে পারে, কিন্তু ডিফাইন ঠিক একবার; লিংকার প্রতিটি extern-কে সেই এক ডেফিনিশনের সঙ্গে জোড়ে।
কিওয়ার্ড ও স্থানপ্রভাব
লোকাল ভেরিয়েবলে staticআয়ু হয় পুরো প্রোগ্রাম; স্কোপ অপরিবর্তিত (ব্লক); লিংকেজ নেই
গ্লোবাল ভেরিয়েবলে staticইন্টারনাল লিংকেজ: শুধু নিজের সোর্স ফাইলে দৃশ্যমান
ফাংশনে staticফাংশনটি নিজের ফাইলে সীমাবদ্ধ (হেল্পার ফাংশন, নামের সংঘাত এড়ায়)
ভেরিয়েবলে externশুধু ডিক্লারেশন; বাইরের ডেফিনিশনকে নির্দেশ করে
ফাইল স্কোপে extern int g = 5;ইনিশিয়ালাইজার থাকায় এটি ডেফিনিশন (বৈধ; কম্পাইলার সতর্ক করে)
কিওয়ার্ডহীন ফাংশনডিফল্টে extern: প্রোটোটাইপ দিয়ে অন্য ফাইল থেকে কল করা যায়
register গতির জন্য ভেরিয়েবলকে CPU রেজিস্টারে রাখার অনুরোধ (লুপ কাউন্টার)। কম্পাইলার উপেক্ষা করতে পারে (আধুনিক অপটিমাইজার নিজেই রেজিস্টার বাছে)। শুধু লোকাল ও প্যারামিটারে; এর & নেওয়া যায় না — মেমোরিতে থাকলেও কম্পাইল এরর; ডিফল্ট মান গারবেজ।
void loop(void) { register int i; for (i = 0; i < 1000; i++) ; /* fast counter */ int *p = &i; /* ✗ error: address of register */ } register int r; /* ✗ not at file scope */
প্রচলিত ভুল ধারণা — সংশোধিত ① "extern ভেরিয়েবল তৈরি করে, মান 0" — না: স্টোরেজ ও শূন্য ডিফল্ট অন্যত্র থাকা ডেফিনিশনের। ② "static গ্লোবাল যেকোনো জায়গায় ব্যবহারযোগ্য" — না: ফাংশনের বাইরে এর মানে ফাইলে সীমাবদ্ধ। ③ "register রেজিস্টারের নিশ্চয়তা দেয়" — না: এটি শুধু ইঙ্গিত। ④ "register ভেরিয়েবলে &r চলে" — কম্পাইল এরর। ⑤ দুই ফাইলেই int g = 1; → মাল্টিপল ডেফিনিশন লিংক এরর।
মনে রাখার কৌশল "extern = 'অন্য কোথাও থাকে'; বাইরের static = 'প্রবেশ নিষেধ' সাইনবোর্ড।" ডিক্লারেশন = গুজব; ডেফিনিশন = জন্ম।
সমাধানকৃত উদাহরণ ✍ বৈধ? একটি ফাইলে: extern int n; extern int n; int n = 3; → বৈধ: দুটি ডিক্লারেশন, একটি ডেফিনিশন।

৬রিকার্শন ও কল স্ট্যাক

লিখিত + আউটপুট ★
সংজ্ঞা রিকার্শন (Recursion): ফাংশন নিজেকে কল করে, প্রত্যক্ষভাবে (f → f) বা পরোক্ষভাবে (f → g → f)। প্রতিটি রিকার্সিভ ফাংশনে লাগে একটি বেস কেস (Base Case), যা আর রিকার্স না করে ফেরত দেয়, এবং একটি রিকার্সিভ কেস, যা বেস কেসের দিকে এগোয়। প্রতিটি কল পায় নিজস্ব স্ট্যাক ফ্রেম (Stack Frame) (অ্যাক্টিভেশন রেকর্ড: প্যারামিটার, লোকাল, রিটার্ন অ্যাড্রেস)। বেস কেসে পৌঁছানো না গেলে ফ্রেম জমতে জমতে স্ট্যাক ওভারফ্লো (রান-টাইম ক্র্যাশ)।
long fact(int n) { if (n == 0 || n == 1) /* base case */ return 1; return n * fact(n - 1); /* recursive */ } /* fact(5) = 5*4*3*2*1 = 120 */ int fib(int n) { /* 0 1 1 2 3 5 8 */ if (n <= 1) return n; /* fib(0)=0, fib(1)=1 */ return fib(n - 1) + fib(n - 2); }
প্রকারঅর্থউদাহরণ
প্রত্যক্ষ (Direct)ফাংশন নিজেকে কল করেfact, fib
পরোক্ষ (Indirect)A কল করে B-কে, B কল করে A-কেisEven ↔ isOdd
টেইল (Tail)রিকার্সিভ কলটিই শেষ কাজ; পরে আর কিছু বাকি নেইreturn gcd(b, a % b);
নন-টেইল (Head)কল ফেরার পরও কাজ বাকি থাকেreturn n * fact(n - 1);
ট্রি (Multiple)প্রতি ফ্রেমে একাধিক রিকার্সিভ কলfib, টাওয়ার অব হ্যানয়
int isOdd(int n); /* prototype */ int isEven(int n) { return n == 0 ? 1 : isOdd(n - 1); } int isOdd(int n) { return n == 0 ? 0 : isEven(n - 1); } /* isEven(4) → 1 (indirect) */
long factT(int n, long acc) { if (n <= 1) return acc; return factT(n - 1, n * acc); /* tail */ } /* factT(5, 1) = 120: the frame has no pending work, so an optimiser can reuse it (a loop in disguise) */
মনে রাখার কৌশল "রাশিয়ান পুতুল": নামার পথে পুতুল খোলো (কল), সবচেয়ে ছোটটি নিরেট (বেস কেস), ওঠার পথে বন্ধ করো (রিটার্ন)।
পরীক্ষার ফাঁদ টেইল-কল অপটিমাইজেশন কম্পাইলার করতে পারে (যেমন gcc -O2); C স্ট্যান্ডার্ড বাধ্য করে না। C-তে main নিজেকে কল করতে পারে (C++-এ নয়)।
সমাধানকৃত উদাহরণ ✍ গভীরতা fact(5) → n = 5, 4, 3, 2, 1-এর ফ্রেম: সর্বোচ্চ গভীরতা 5; ফল 120। fact(-1) বেস কেসে পৌঁছায় না → ওভারফ্লো।

প্রায়ই আসে ★
সংজ্ঞা রিকার্শন ট্রি (Recursion Tree) প্রতিটি কলের জন্য একটি নোড আঁকে। সাধারণ fib(n) প্রতি ফ্রেমে দুটি কল করে এবং একই মান বারবার হিসাব করে: কলসংখ্যা C(n) = C(n−1) + C(n−2) + 1, C(0) = C(1) = 1, যার সমাধান C(n) = 2·F(n+1) − 1। fib(5)-এর জন্য: 2·8 − 1 = 15টি কল। সময় O(2ⁿ) (সূক্ষ্ম: Θ(φⁿ), φ ≈ 1.618); স্ট্যাকের গভীরতা মাত্র n।

আউটপুট প্রশ্ন ★
পদ্ধতি যেকোনো রিকার্সিভ আউটপুট প্রশ্নে: ① প্রতিটি আর্গুমেন্টসহ নিচের দিকে কল চেইন লেখো; ② কোথায় বেস কেস কাজ করে চিহ্নিত করো; ③ এক ফ্রেম করে রিটার্ন মান ওপরে নিয়ে যাও; ④ রিকার্সিভ কলের আগের printf নামার পথে ছাপে, পরেরটি ওঠার পথে (উল্টো ক্রমে)।
void p(int n) { if (n == 0) return; printf("%d", n); /* before: down */ p(n - 1); printf("%d", n); /* after: up */ } p(3); /* prints 321123 */
① অঙ্কের যোগফল
int sd(int n) { return n == 0 ? 0 : n % 10 + sd(n / 10); }
sd(1234) = 4 + 3 + 2 + 1 + 0 = 10; ৫টি কল (1234, 123, 12, 1, 0)।
② ঘাত (Power)
int pw(int b, int e) { return e == 0 ? 1 : b * pw(b, e - 1); }
pw(2, 10) = 1024, ১১টি কলে। e অর্ধেক করলে (pw(b*b, e/2)) হয় O(log e)।
③ GCD (ইউক্লিড)
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
gcd(48, 18): (48,18) → (18,12) → (12,6) → (6,0) → 6। LCM = 48·18 / 6 = 144।
④ দুই ধাপে নামা
int f(int n) { return n <= 1 ? 1 : n * f(n - 2); }
f(7) = 7·5·3·1 = 105, 7! = 5040 নয়: আর্গুমেন্ট ২ করে কমে।
⑤ রিকার্শনে বাইনারি
void bin(int n) { if (n > 1) bin(n / 2); printf("%d", n % 2); }
bin(10) ছাপে 1010: অঙ্কগুলো বেরোয় ওঠার পথে।
⑥ রিকার্শনের ভেতরে static
int g(int n) { static int s = 0; s += n; if (n > 0) g(n - 1); return s; }
g(3) → একটিই শেয়ার্ড s: 3+2+1+0 = 6; দ্বিতীয়বার g(3) দেয় 12।
মনে রাখার কৌশল "আগে প্রিন্ট = সিঁড়ি দিয়ে নামা; পরে প্রিন্ট = আবার ওঠা।" নামা সোজা পড়ে, ওঠা উল্টো।
পরীক্ষার ফাঁদ static লোকাল সব ফ্রেমে শেয়ার্ড — একটিই কপি, প্রতি কলে আলাদা নয়। auto লোকাল প্রতিটি ফ্রেমে নতুন কপি পায়।
সমাধানকৃত উদাহরণ ✍ যোগফল int s(int n){return n==0?0:n+s(n-1);} → s(100) = 5050, ১০১টি কল গভীর।

প্রধান ফাঁদ C-তে আসল কল বাই রেফারেন্স নেই · extern কিছু বরাদ্দ করে না · static গ্লোবাল ফাইলে সীমাবদ্ধ · register উপেক্ষিত হতে পারে · f(i++, i++) আনডিফাইনড · static লোকাল সব ফ্রেমে শেয়ার্ড · অ্যারে প্যারামিটারের sizeof = পয়েন্টারের আকার।

লিখিত প্রশ্ন একটি টেবিলসহ (স্টোরেজ, ডিফল্ট মান, স্কোপ, আয়ু) C-এর চারটি স্টোরেজ ক্লাস ব্যাখ্যা করো। static লোকাল যে মান ধরে রাখে তা দেখাতে একটি প্রোগ্রাম এবং একটি রিকার্সিভ ফ্যাক্টরিয়াল ফাংশন লেখো; fact(4)-এর স্ট্যাক ট্রেস করো। ১০ নম্বর
  1. টেবিল (৪) — auto: স্ট্যাক, গারবেজ, ব্লক, ব্লক · register: পেলে CPU রেজিস্টার, গারবেজ, ব্লক, ব্লক, & নয় · static: data/BSS, 0, ব্লক বা ফাইল, পুরো প্রোগ্রাম · extern: অন্যত্র থাকা ডেফিনিশনের ডিক্লারেশন, 0, ফাইল, পুরো প্রোগ্রাম। ৪
  2. static প্রোগ্রাম (২) — static int count = 0; count++;-সহ counter() তিনবার কল করলে ছাপে 1 2 3; static ছাড়া 1 1 1। ২
  3. ফ্যাক্টরিয়াল (২) — বেস কেস n == 0 || n == 1 হলে 1; নইলে n * fact(n - 1)। ২
  4. ট্রেস (২) — push fact(4), fact(3), fact(2), fact(1); fact(1) = 1; pop: 2·1 = 2, 3·2 = 6, 4·6 = 24। ২
