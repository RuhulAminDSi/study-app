1Header Files and the Build Pipeline

MCQ favourite ★
Definition A header file (.h) holds declarations shared by source files: function prototypes, macros, constants and type definitions (typedef, struct). #include pastes the file's whole text in place of the line before compilation. A header holds no compiled code: the bodies of printf, sqrt … live in the library, joined in by the linker.
HeaderWhat it gives you · names to recognise
<stdio.h>standard I/O: printf, scanf, puts, fgets, getchar, fopen, FILE, EOF
<conio.h>console I/O, not standard C (Turbo C/DOS, MSVC): clrscr, getch, getche
<math.h>maths on double: sqrt, pow, fabs, ceil, floor, sin, log (gcc: link with -lm)
<string.h>strings and memory blocks: strlen, strcpy, strcat, strcmp, strstr, memcpy
<stdlib.h>general utilities: malloc, calloc, free, atoi, rand, exit, abs, qsort
<ctype.h>character tests and case: isalpha, isdigit, isspace, toupper, tolower
<time.h>date and time: time, clock, difftime, CLOCKS_PER_SEC
<limits.h>integer limits: INT_MAX, INT_MIN, CHAR_BIT, LONG_MAX
<float.h>floating-point limits: FLT_MAX, DBL_MAX, FLT_EPSILON, FLT_DIG
<stddef.h> · <stdbool.h>NULL, size_t, ptrdiff_t · bool, true, false (C99)
/* myheader.h */ #ifndef MYHEADER_H /* include guard */ #define MYHEADER_H int add(int a, int b); /* prototype */ #define MAX 100 #endif /* main.c */ #include <stdio.h> /* system dirs */ #include "myheader.h" /* own dir 1st */
<…> vs "…" <stdio.h> is searched in the standard (system) include directories only — use it for library headers. "my.h" is searched in the own folder first, then the system directories — use it for your own headers. An include guard stops a second copy, so no "redefinition" errors; #pragma once does the same (non-standard, widely supported).
Memory trick "Angle brackets = the library shelf; quotes = your own desk, checked first, then the shelf."
Exam trap A header does not link its library: with <math.h> gcc still needs -lm, else "undefined reference". conio.h, clrscr(), getch() are not ISO C.
Worked example ✍ which header? INT_MAX → limits.h · toupper → ctype.h · malloc → stdlib.h · fabs → math.h but abs → stdlib.h.

2Preprocessor Directives and Macros

output questions ★
Definition The preprocessor runs before the compiler and handles every line that starts with # (a directive). It does pure text work — file inclusion, macro substitution, conditional compilation — after comments are stripped. A directive ends at the end of its line: no semicolon (continue a long one with \).

Predefined macros: __FILE__ file name (string) · __LINE__ line number (int) · __DATE__ "Oct 14 2026" · __TIME__ "hh:mm:ss" · __STDC__ 1 on a conforming compiler · __STDC_VERSION__ 199901L (C99), 201112L (C11).

# and ## # stringizes: #define STR(x) #x, STR(Dhaka) → "Dhaka". ## pastes tokens: #define CAT(a,b) a##b, CAT(var,1) → var1. Safer than a function-like macro: an inline function (C99).
Memory trick "Brackets inside, brackets outside": wrap every parameter and the whole body — ((x)*(x)).
Exam trap #define PI 3.14; pastes the ; too. SQUARE(i++) increments i twice: undefined. #define SQ (x) with a space is object-like.
Worked example ✍ output #define SQ(x) (x)*(x): 100/SQ(5) → 100/(5)*(5) = 20×5 = 100, not 4. Fully bracketed: 4.

3Pointers: &, *, Kinds and const

most tested ★
Definition A pointer is a variable that stores the memory address of another object: type *name;. & (address-of) gives an address; * (indirection, "value at") gives the object at an address. A pointer's own size is fixed by the machine — 4 bytes on 32-bit, 8 on 64-bit — whatever it points to; its type decides how many bytes * reads and how far +1 moves.
int a = 10; int *p; /* declare */ p = &a; /* address of a */ printf("%d", *p); /* 10 */ *p = 20; /* a is now 20 */ int **q = &p; /* ptr to ptr */ printf("%d", **q);/* 20 */ int *x, y; /* x ptr, y int! */

Look-alikes int *p[3]: array of 3 pointers. int (*p)[3]: one pointer to an array of 3 ints. int (*fp)(int): function pointer. Passing &x to a function: previous lesson.
Memory trick "& asks where; * asks what's there." Read right to left: int *const p = "p is a const pointer to int".
Exam trap In int *x, y; only x is a pointer: * binds to the name. A NULL or wild dereference compiles, then fails at run time.
Worked example ✍ trace int a = 5, *p = &a, **q = &p; **q += *p; → both name a, so a = 5 + 5 = 10.

4Pointer Arithmetic

numeric MCQs ★
Definition Adding an integer n to a pointer moves it n elements, not n bytes: address(p + n) = address(p) + n × sizeof(*p). Subtracting two pointers into the same array gives the number of elements between them (type ptrdiff_t). Results are defined only inside one array, plus the position one past the end.

Walking an array with a pointer for (p = a; p < a + n; p++) sum += *p; — comparing with a + n (one past the end) is legal, but reading *(a + n) is not. Pointers into different arrays must not be subtracted or ordered with <; == is always allowed. Print a pointer difference with %td.
Memory trick "The type is the ruler." A pointer counts in elements; its type says how long one step is.
Exam trap *p++ moves the pointer, not the value: postfix ++ binds tighter than *. Two int pointers 12 bytes apart differ by 3.
Worked example ✍ address double *d holds 2000: d + 5 = 2000 + 5×8 = 2040. As char *: 2005.

51D Arrays and the Array–Pointer Link

highest-yield ★
Definition An array is a fixed-size collection of elements of the same type in contiguous memory, indexed 0 … n−1; int arr[5] reserves 5 × 4 = 20 bytes. C does no bounds checking: arr[5] compiles and is undefined behaviour. In most expressions the name decays to a pointer to element 0, so arr[i] ≡ *(arr + i) ≡ *(i + arr) ≡ i[arr].
ExpressionTypeValue
arr, &arr[0]int *1000

int a[n];VLA: C99; optional in C11
int sum(int a[], int n) { /* int *a */ int s = 0; for (int i = 0; i < n; i++) s += a[i]; /* *(a + i) */ return s; /* sizeof(a) = 8 here */ } int arr[5] = {1, 2, 3, 4, 5}; int n = sizeof arr / sizeof arr[0]; sum(arr, n); /* passes &arr[0] */
When the name does NOT decay ① under sizeof → whole array size; ② under & → pointer to the whole array; ③ a string literal initialising a char array. The name is not a modifiable lvalue: arr++, arr = p fail; p++ is fine. A function gets only the address, so its changes to a[i] reach the caller.
Memory trick "Array name = a fixed signpost to element 0; a pointer = a signpost you can carry."
Exam trap An array parameter is a pointer: sizeof(a) inside the function gives 8 (or 4), not the array size. Always pass n.
Worked example ✍ output int a[5]={1,2,3,4,5}; int *p=(int *)(&a+1); printf("%d",*(p-1)); → 5.

62D Arrays and the Address Formula

written + numeric ★
Definition int m[R][C] is an array of R rows, each an array of C ints. Memory is one straight line, and C stores the elements in row-major order: all of row 0, then row 1, … Only the first (row) size may be left out — int m[][3] = {…};, void f(int m[][3], int rows) — because the column size is required to find where each row starts.
int m[2][3] = { {1, 2, 3}, {4, 5, 6} }; for (int i = 0; i < 2; i++) { for (int j = 0; j < 3; j++) printf("%d ", m[i][j]); printf("\n"); } /* 1 2 3 4 5 6 */ int (*row)[3] = m; /* ptr to a row */
ExpressionMeansValue
m→ row 01000
m + 1→ row 1 (+12 B)1012
*m + 1&m[0][1] (+4 B)1004
*(m + 1) + 2&m[1][2]1020
*(*(m + 1) + 2)m[1][2]6
sizeof m · m[0]all · one row24 · 12
Address formula M rows, N columns, W bytes per element, base address B, lower bounds Lr, Lc (both 0 in C).
Row-major: LOC(A[i][j]) = B + W × [N × (i − Lr) + (j − Lc)]
Column-major: LOC(A[i][j]) = B + W × [M × (j − Lc) + (i − Lr)]
C, C++, Pascal and NumPy (default) are row-major; Fortran, MATLAB and R are column-major.
Worked example ✍ A[1..10][1..15], W = 2, B = 100: find A[4][8] M = 10, N = 15. Row-major: 100 + 2 × [15 × 3 + 7] = 100 + 2 × 52 = 204. Column-major: 100 + 2 × [10 × 7 + 3] = 100 + 2 × 73 = 246. In C, int A[5][4] at 1000: &A[3][2] = 1000 + 4 × (3×4 + 2) = 1056.
Worked example ✍ pointer to a row int a[2][3] = {{1,2,3},{4,5,6}}; int (*r)[3] = a; → r[1][1] = 5, *(*(r + 1)) = 4 (first element of row 1), *(*r + 2) = 3. r + 1 moves 12 bytes because *r is a whole row of 3 ints.
Memory trick "Row-major reads like a book": finish a line, then the next. Column-major reads a newspaper column.
Exam trap int m[][] = {…}; is an error. m + 1 jumps a row, *m + 1 one element. Check whether bounds start at 0 or 1.
Worked example ✍ size int a[2][3][4] holds 24 ints = 96 bytes; a[1] is a 3×4 block of 48 bytes.

7Strings and the Null Character

MCQ + output ★
Definition C has no string type: a string is a char array ending in the null character '\0' (ASCII 0). Every string function — strlen, printf("%s"), strcpy — walks until it meets '\0'. So the literal "Hello" occupies 6 bytes: 5 letters + the terminator, added by the compiler.
DeclarationBytesNote
char s1[] = {'H','i','\0'};3'\0' by hand
char s2[] = "Hello";6'\0' added
char s3[10] = "Hello";10rest '\0'
char s4[5] = "Hello";5no '\0'
Common misconception The terminator is '\0', value 0 — not ' ' (space, 32), '0' (digit, 48) or '\n' (10). NULL is a pointer; '\0' a character.
Pointchar s[] = "Dhaka";char *p = "Dhaka";

Assign new texts = "Khulna"; ✗ → strcpyp = "Khulna"; ✓ re-points
sizeof68 (pointer, 64-bit)
char s[] = "abc"; printf("%zu %zu", sizeof s, strlen(s)); /* 4 3 */ printf("%zu", sizeof("abc")); /* 4 */ char *p = "Hello"; printf("%c %s", *(p + 1), p + 2); /* e llo */ printf("%c", "Hello"[4]); /* o */ char *names[] = {"Ali", "Rina"}; /* 2 ptrs */
'A' vs "A" 'A' is a character constant of type int in C: sizeof('A') = 4 (1 in C++). "A" is {'A','\0'}: sizeof("A") = 2. char *names[] = array of pointers; char g[2][5] = fixed 5-byte rows.
Memory trick "Every string carries an invisible full stop": bytes needed = letters + 1.
Exam trap s1 == s2 compares addresses, not text → strcmp. char t[] = {'H','i'}; has no '\0': %s runs on.
Worked example ✍ own strlen size_t len(const char *s){ const char *p = s; while (*p) p++; return p - s; } → difference = count.

8string.h Functions and String Input

frequently tested ★
Definition <string.h> declares the functions for '\0'-terminated strings and raw memory blocks. None of them knows the destination's size: the caller must leave room, including the byte for '\0'. Comparison is lexicographic by character code.

Why gets() went No size parameter: a long line writes past the array over neighbouring memory — a buffer overflow (the 1988 Morris worm exploited one in fingerd). Deprecated in C99 (TC3), removed in C11. More I/O: later lesson.
Memory trick "strcmp = dictionary order by ASCII": uppercase (65–90) sorts before lowercase (97–122).
Exam trap if (strcmp(a, b)) is true when the strings differ. Only the sign is guaranteed, not −1/+1.
Worked example ✍ mixed input scanf("%d",&n); fgets(s,50,stdin); → fgets gets the leftover '\n': an empty line.

Written question Explain the relationship between arrays and pointers in C. Show how arr[i] is evaluated, why sizeof gives different results for an array and a pointer, derive the row-major address of A[i][j], and write a pointer-based function that returns the length of a string. 10 marks
  1. Decay (2) — an array name in an expression becomes &arr[0]; arr[i] is defined as *(arr + i), and arr + i adds i × sizeof(int) bytes. 2
  2. sizeof (2) — no decay under sizeof/&: int arr[5] → 20; a pointer (or array parameter) → 8 on 64-bit; the name cannot be assigned or incremented. 2

  4. Function (3) — size_t len(const char *s){ const char *p = s; while (*p) p++; return p - s; }: walk to '\0', pointer difference = length. 3
