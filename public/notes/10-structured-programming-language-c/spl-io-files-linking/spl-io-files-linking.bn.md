## ১. স্ট্যান্ডার্ড স্ট্রিম ও ফরম্যাটেড আউটপুট (printf)

**স্ট্রিম (stream)** হলো বাইটের যেকোনো উৎস বা গন্তব্য — কীবোর্ড, স্ক্রিন, ফাইল, পাইপ — দেখার C-র একক উপায়, যা একটি `FILE *` দিয়ে ধরা হয়। প্রতিটি হোস্টেড C প্রোগ্রাম শুরু হয় **আগে থেকেই খোলা তিনটি স্ট্রিম** নিয়ে, যা `<stdio.h>`-এ ঘোষিত:

- **stdin** (fd 0) — কীবোর্ড; টার্মিনালে লাইন-বাফারড।
- **stdout** (fd 1) — স্ক্রিন; টার্মিনালে লাইন-বাফারড, ফাইলে রিডাইরেক্ট করলে **পুরো বাফারড**।
- **stderr** (fd 2) — স্ক্রিন; **আনবাফারড**, সঙ্গে সঙ্গে দেখায়।

*(ডুডল: কীবোর্ড → stdin → প্রোগ্রাম (printf · scanf) → "স্ক্রিন"-এর দিকে দুটি তীর: সবুজটি stdout (fd 1), লালটি stderr (fd 2); নোট: `> out.txt` সরায় শুধু stdout।)*

- ⚠️ **পরীক্ষার ফাঁদ:** (১) **stderr** কোনো লগ ফাইল নয়: এটিও স্ক্রিনে যায়, কিন্তু `prog > out.txt` কেবল stdout সরায়, তাই এরর তখনো দেখা যায়। (২) stdout-এর বাফারে থাকা লেখা **প্রোগ্রাম ক্র্যাশ করলে হারিয়ে যায়** — `fflush(stdout)` জোর করে বের করে দেয়।

| স্পেসিফায়ার | আর্গুমেন্ট | ছাপে |
|---|---|---|
| `%d` `%i` | int | -42 |
| `%u` | unsigned int | 42 |
| `%ld` `%lld` | long, long long | 123456789 |
| `%f` | **double (float উন্নীত হয়)** | 3.140000 |
| `%Lf` | long double | 3.140000 |
| `%e` `%g` | double: সূচক / ছোট রূপ | 3.14e+00 · 3.14 |
| `%c` | char (int হিসেবে যায়) | A |
| `%s` | char * স্ট্রিং | Dhaka |
| `%p` | void * পয়েন্টার | 0x7ffd… |
| `%x` `%X` `%o` | unsigned: হেক্স / অক্টাল | ff · FF · 377 |
| `%zu` | **size_t** | 5 |
| `%%` | কিছু না | একটি % চিহ্ন |

**একটি কনভার্শনের গঠন:** `% [ফ্ল্যাগ] [প্রস্থ] [.প্রিসিশন] [দৈর্ঘ্য] অক্ষর`

- ফ্ল্যাগ: `-` বাঁয়ে সাজায় · `+` সবসময় চিহ্ন দেখায় · `0` শূন্য দিয়ে ভরে · `#` বিকল্প রূপ (%x-এ 0x, %o-তে শুরুতে 0) · স্পেস = ধনাত্মক সংখ্যার আগে ফাঁকা।
- **প্রস্থ (width)** = **ন্যূনতম**, কখনো কাটে না; `*` দিলে আর্গুমেন্ট থেকে নেয়।
- **.প্রিসিশন**: %f/%e-এ দশমিকের পরের অঙ্ক; %s-এ সর্বোচ্চ অক্ষর।
- **দৈর্ঘ্য (length)**: hh, h, l, ll, L, z — আর্গুমেন্টের আকার।
- **printf ফেরত দেয়** ছাপা অক্ষরের সংখ্যা (এররে ঋণাত্মক) — তাই `printf("%d", printf("Hello"))` ছাপে **Hello5**।

**সমাধানকৃত উদাহরণ ✍ আউটপুট বলো** (_ = একটি স্পেস):

| কল | আউটপুট |
|---|---|
| `printf("%5d\|", 42)` | `___42\|` |
| `printf("%-5d\|", 42)` | `42___\|` |
| `printf("%05d", 42)` | `00042` |
| `printf("%+d", 42)` | `+42` |
| `printf("%.2f", 3.14159)` | `3.14` |
| `printf("%8.3f\|", 3.14159)` | `___3.142\|` |
| `printf("%#x %X %o", 255, 255, 255)` | `0xff FF 377` |
| `printf("%.3s", "Bangladesh")` | `Ban` |
| `printf("%2d", 12345)` | `12345` (প্রস্থ কখনো কাটে না) |

- ⚠️ **ফাঁদ:** (১) **printf**-এ %f দিয়েই float *ও* double দুটোই চলে — float double-এ উন্নীত হয়; পার্থক্যটা কেবল scanf-এ। (২) `printf("%d", 3.5)` **অনির্ধারিত আচরণ (undefined behaviour)** — printf নিজে রূপান্তর করে না। (৩) `strlen` ফেরত দেয় **size_t**: ছাপো **%zu** দিয়ে, %d বা %lu নয়।
- 🟣 **কৌশল:** "**ফ্ল্যাগ, প্রস্থ, ডট, দৈর্ঘ্য, অক্ষর**" — সবসময় এই ক্রমে। "**মাইনাস বাঁয়ে সরায়, শূন্য ভরে, প্লাস দেখায়।**"

## ২. ফরম্যাটেড ইনপুট (scanf) ও ক্যারেক্টার / লাইন I/O

**scanf** stdin থেকে অক্ষর পড়ে, ফরম্যাট অনুযায়ী রূপান্তর করে এবং **প্রতিটি ফল একটি পয়েন্টারের মাধ্যমে জমা রাখে** — তাই অ্যারে নয় এমন প্রতিটি আর্গুমেন্টে `&` লাগে। এটি ফেরত দেয় **যতগুলো আইটেম বসানো হলো সেই সংখ্যা**, অথবা প্রথম রূপান্তরের আগেই ইনপুট ব্যর্থ হলে **EOF**। %d, %f ও %s শুরুর ফাঁকা জায়গা (white space) বাদ দেয়; **%c দেয় না**।

| টাইপ | printf | scanf | পার্থক্য কেন |
|---|---|---|---|
| float | %f | %f | scanf পায় একটি `float *` — 4 বাইট |
| double | %f (C99 থেকে %lf-ও) | **%lf** | `double *` 8 বাইট; %f ভরত কেবল 4 |
| long double | %Lf | %Lf | বড় হাতের L |
| short / long | %hd / %ld | %hd / %ld | আকার পয়েন্টারের সঙ্গে মিলতে হবে |
| char | %c | %c, বা `" %c"` | স্পেসটি আগের রয়ে যাওয়া '\n' বাদ দেয় |
| স্ট্রিং | %s | %s, **& ছাড়া** | অ্যারের নামই ঠিকানা; ফাঁকা জায়গায় থামে |

*(ডুডল: `42 3.5⏎` টাইপ করার পর কীবোর্ড বাফার — ঘর 4, 2, স্পেস, 3, ., 5, \n। `%d` নেয় 42, `%f` স্পেস বাদ দিয়ে নেয় 3.5, আর লাল '\n' পড়ে থাকে পরের %c-র জন্য। ক্যাপশন: `scanf("%d %f", &n, &x)` এন্টার কী-র আগেই থামে।)*

| ফাংশন | কাজ |
|---|---|
| `getchar()` / `putchar(c)` | একটি অক্ষর ইন / আউট; getchar ফেরত দেয় **int**, যাতে EOF আঁটে |
| `gets(s)` | **C11-এ বাতিল** — আকারের সীমা নেই, বাফার ওভারফ্লো |
| `fgets(s, n, stdin)` | সর্বোচ্চ **n − 1** অক্ষর, **'\n' রেখে দেয়**, '\0' যোগ করে |
| `puts(s)` / `fputs(s, fp)` | puts '\n' যোগ করে; fputs কিছুই না |
| `getch()` / `getche()` | এন্টার ছাড়া একটি কী — **conio.h**, শুধু DOS/Turbo C, স্ট্যান্ডার্ড নয় |

**সমাধানকৃত উদাহরণ ✍ scanf কী ফেরত দেয়?** `int a = 0, b = 0, r = scanf("%d %d", &a, &b);`
(ক) ইনপুট `10 20` → r = **2**, a = 10, b = 20। (খ) ইনপুট `10 abc` → r = **1**, b থাকে 0 এবং "abc" পরের পড়ার জন্য **বাফারেই থেকে যায়**। (গ) ইনপুট `abc` → r = **0**। (ঘ) ইনপুট শেষ (Windows-এ Ctrl+Z / Linux-এ Ctrl+D) → r = **EOF**। নিরাপদ লুপ: `while (scanf("%d", &x) == 1) sum += x;` — ভুল ইনপুটে *এবং* ইনপুট শেষে দুই ক্ষেত্রেই থামে।

**scanf-এর তিনটি কৌশল:** `%9s` — প্রস্থের সীমা, `char s[10]`-এ সর্বোচ্চ 9 অক্ষর · `%[^\n]` — স্ক্যানসেট, স্পেসসহ পুরো লাইন · `%*d` — পড়ে **ফেলে দেয়**, রিটার্ন মানে গোনা হয় না।

- ⚠️ **ফাঁদ:** (১) & ছাড়া `scanf("%d", x)` একটি মানকে ঠিকানা হিসেবে পাঠায় — অনির্ধারিত আচরণ, সাধারণত ক্র্যাশ। (২) যেখানে char আনসাইনড, সেখানে `char c = getchar();` কখনো EOF-এর সমান হয় না — **int** রাখো। (৩) স্ট্যান্ডার্ড C-তে `fflush(stdin)` অনির্ধারিত। (৪) %s কেবল **একটি শব্দ** পড়ে।
- 🟣 **কৌশল:** "**printf নেয় মান, scanf নেয় ঠিকানা।**" আর "**lf = long float = double**": scanf-এ float আর double-এর মাঝে ফারাক শুধু ওই `l`।

## ৩. ফাইল অ্যাক্সেস: FILE *, fopen মোড, টেক্সট বনাম বাইনারি

ফাইল ব্যবহার করা হয় একটি **FILE স্ট্রাকচারের পয়েন্টার** দিয়ে (`<stdio.h>`-এ ঘোষিত), যেটি রাখে **বাফার**, **বর্তমান অবস্থান (position)** এবং **ফাইল-শেষ ও এরর ফ্ল্যাগ**। প্রতিটি ফাইলের কাজের তিন ধাপ: `fopen(name, mode)` দিয়ে **খোলা**, যা **ব্যর্থ হলে NULL ফেরত দেয়**; **প্রসেস** করা; `fclose(fp)` দিয়ে **বন্ধ**, যা বাফার খালি করে 0 ফেরত দেয় (ব্যর্থ হলে EOF)।

*(ডুডল: প্রোগ্রাম (fp রাখে) → FILE বক্স (বাফার · অবস্থান · EOF/এরর ফ্ল্যাগ) → ডিস্ক ফাইলের সিলিন্ডার। "fp = fopen(...) — NULL কিনা যাচাই করো"; "fclose(fp) বাফার ডিস্কে লিখে দেয়"।)*

| মোড | ফাইল থাকলে | না থাকলে | অনুমতি |
|---|---|---|---|
| "r" | শুরু থেকে খোলে | **NULL** | পড়া |
| "w" | **শূন্যে কেটে ফেলে** | তৈরি করে | লেখা |
| "a" | রাখে; **প্রতিটি** লেখা যায় শেষে | তৈরি করে | যোগ (append) |
| "r+" | খোলে, কাটে **না** | **NULL** | পড়া + লেখা |
| "w+" | কেটে ফেলে | তৈরি করে | লেখা + পড়া |
| "a+" | রাখে; যেকোনো জায়গা পড়ে, শেষে লেখে | তৈরি করে | পড়া + যোগ |

**বাইনারি**-র জন্য **b** যোগ করো: "rb", "wb", "ab", "r+b" (= "rb+"), "w+b", "a+b"। C11 যোগ করেছে **x** ("wx"): আগের ফাইল ওভাররাইট না করে ব্যর্থ হয়। মনে রাখো `printf(…)` ≡ `fprintf(stdout, …)` এবং `scanf(…)` ≡ `fscanf(stdin, …)`।

| স্তর | পড়া | লেখা | শেষে / এররে সংকেত |
|---|---|---|---|
| অক্ষর | fgetc(fp), getc(fp) | fputc(c, fp), putc(c, fp) | EOF |
| লাইন / স্ট্রিং | fgets(s, n, fp) | fputs(s, fp) | NULL · EOF |
| ফরম্যাটেড | fscanf(fp, fmt, …) | fprintf(fp, fmt, …) | সংখ্যা বা EOF · ঋণাত্মক |
| ব্লক (বাইনারি) ★ | fread(ptr, size, n, fp) | fwrite(ptr, size, n, fp) | যতগুলো হলো; শেষে বা এররে **< n** |

```c
/* copy in.txt to out.txt */
FILE *in  = fopen("in.txt", "r");
FILE *out = fopen("out.txt", "w");
if (in == NULL || out == NULL) {
    perror("fopen");
    return 1;
}
int c;              /* int, not char */
while ((c = fgetc(in)) != EOF)
    fputc(c, out);
fclose(in);
fclose(out);
```

- **টেক্সট বনাম বাইনারি।** **টেক্সট মোডে** লাইব্রেরি লাইনের শেষ বদলাতে পারে — Windows-এ '\n' লেখা হয় "\r\n" হিসেবে আর পড়ার সময় আবার '\n'। **বাইনারি মোড** বাইট হুবহু সরায়। Linux/UNIX-এ দুই মোড একই। `fprintf(fp, "%d", 12345)` লেখে **5টি অক্ষর**; `fwrite(&n, sizeof n, 1, fp)` লেখে **sizeof(int) বাইট** (বেশিরভাগ সিস্টেমে 4)।
- ⚠️ **ফাঁদ:** (১) **"w" পুরোনো লেখা মুছে দেয়**; রাখতে চাইলে "a"। (২) **"r+"** কখনো ফাইল তৈরি করে না। (৩) fopen ব্যর্থতা জানায় **NULL** দিয়ে, EOF বা −1 নয়। (৪) fclose ভুলে গেলে **বাফারের ডেটা হারাতে পারে**। (৫) "a"/"a+"-এ fseek-এর পরেও লেখা যায় শেষে।
- 🟣 **কৌশল:** "**r পড়ে, w মোছে, a জোড়ে — আর + দেয় বাকি অর্ধেক।**" "**b মানে বাইট।**" ফাইল না থাকলে ব্যর্থ হয় কেবল দুটি r-মোড; সব w- ও a-মোড ফাইল তৈরি করে।

## ৪. র‍্যান্ডম অ্যাক্সেস: fseek, ftell, rewind ও EOF-এর নিয়ম

প্রতিটি খোলা স্ট্রিমের একটি **ফাইল পজিশন ইন্ডিকেটর** থাকে — যে বাইট অফসেটে পরের পড়া বা লেখা হবে। ধারাবাহিক (sequential) I/O একে নিজে নিজে সামনে নেয়; **র‍্যান্ডম অ্যাক্সেস** একে সরাসরি সরায় `fseek(fp, offset, whence)` দিয়ে, ফলে বাইনারি ফাইলের *k*-তম রেকর্ড আগের *k* − 1টি না পড়েই পড়া যায়।

*(ডুডল: পাঁচটি রেকর্ড rec 0 … rec 4 হিসেবে আঁকা একটি ফাইল। বাইট 0 থেকে সবুজ তীর = SEEK_SET (0); "এখান থেকে" বেগুনি তীর = SEEK_CUR (1); শেষ থেকে লাল তীর = SEEK_END (2), অফসেট ≤ 0। রেকর্ড k শুরু হয় বাইট k × sizeof(record)-এ।)*

| কল | ফল · রিটার্ন |
|---|---|
| `fseek(fp, off, whence)` | শুরুবিন্দু + off-এ যায় · সফল হলে **0** |
| `ftell(fp)` | বর্তমান অফসেট, **long** হিসেবে · এররে −1L |
| `rewind(fp)` | 0-তে ফেরে **এবং** এরর ফ্ল্যাগ মোছে · void |
| `feof(fp)` | কোনো পড়া শেষে **ইতিমধ্যে ঠেকলে** অশূন্য |
| `ferror(fp)` / `clearerr(fp)` | এরর ফ্ল্যাগ আছে? / দুটি ফ্ল্যাগই মোছে |
| `fflush(fp)` | আউটপুট বাফার এখনই লিখে দেয় |
| `remove(n)` / `rename(o, n)` | ফাইল মোছে / নাম বদলায় · সফল হলে 0 |

**সমাধানকৃত উদাহরণ ✍ ছাত্রদের রেকর্ডের বাইনারি ফাইল।** `struct student { int roll; char name[16]; float cgpa; };` — 4 + 16 + 4 = **24 বাইট** (এখানে প্যাডিং লাগে না; প্যাডিংয়ের নিয়ম স্ট্রাকচার লেসনে)।
- (ক) ফাইলের আকার: `fseek(fp, 0, SEEK_END); long n = ftell(fp);` → n = 240 ⇒ 240 ÷ 24 = **১০টি রেকর্ড**।
- (খ) **৫ম** রেকর্ড পড়া (k = 4): `fseek(fp, 4 * sizeof(struct student), SEEK_SET)` → বাইট **96**, তারপর `fread(&s, sizeof s, 1, fp)` ফেরত দেয় 1।
- (গ) এখন `ftell(fp)` = 96 + 24 = **120**।
- (ঘ) জায়গাতেই হালনাগাদ: **"rb+"** দিয়ে খোলো, `fseek(fp, -24L, SEEK_CUR)`, তারপর `fwrite(&s, sizeof s, 1, fp)`।
- (ঙ) শেষ রেকর্ড: `fseek(fp, -24L, SEEK_END)` → বাইট 216।

```c
/* WRONG: the last line prints twice */
while (!feof(fp)) {
    fgets(line, 80, fp);
    fputs(line, stdout);
}
/* RIGHT: test the read itself */
while (fgets(line, sizeof line, fp) != NULL)
    fputs(line, stdout);
```

- **EOF একটি মান, বাইট নয়।** EOF হলো `<stdio.h>`-এর একটি ম্যাক্রো, একটি **ঋণাত্মক int** (সাধারণত −1), যা কিছু না থাকলে ইনপুট ফাংশন ফেরত দেয়। ফাইলে কোনো EOF অক্ষর জমা থাকে না; ফাইল শুধু শেষ হয়। তাই **fgetc ফেরত দেয় int**: এতে 256টি বাইট-মান *এবং* EOF — সবই আঁটতে হবে।
- ⚠️ **ফাঁদ:** (১) **feof() সামনে দেখে না**: কোনো পড়া ব্যর্থ হওয়ার পরেই এটি সত্য হয়, তাই `while (!feof(fp))` লুপ একবার বেশি চলে। (২) ftell দিয়ে বাইটের হিসাবের জন্য **বাইনারি** মোড লাগে (টেক্সট স্ট্রিমে এর মান কেবল fseek-কে ফেরত দেওয়ার কাজে লাগে)। (৩) একই স্ট্রিমে লেখা আর পড়ার মাঝে fseek বা fflush ডাকো।
- 🟣 **কৌশল:** "**SET, CUR, END = 0, 1, 2 — শুরু, এখানে, শেষ।**" আর "**আগে পড়ো, পরে জিজ্ঞেস করো**": fgetc/fgets/fread-এর ফেরত মান যাচাই করো; feof() জিজ্ঞেস করো কেবল *কেন* থামল জানতে।

## ৫. পরিবর্তনশীল দৈর্ঘ্যের আর্গুমেন্ট তালিকা (stdarg.h)

**ভেরিয়াডিক ফাংশন (variadic function)** পরিবর্তনশীল সংখ্যক আর্গুমেন্ট নেয়, যা ঘোষণা করা হয় **অন্তত একটি নামযুক্ত প্যারামিটারের** পরে একটি এলিপসিস `...` দিয়ে: `int printf(const char *fmt, ...);`। `<stdarg.h>`-এর ম্যাক্রোগুলো নামহীন আর্গুমেন্ট একটা একটা করে পড়ে; কতগুলো এল তা ফাংশনের নিজের **জানার কোনো উপায় নেই**।

```c
#include <stdarg.h>
int sum(int count, ...) {
    va_list ap;
    int total = 0;
    va_start(ap, count);
    for (int i = 0; i < count; i++)
        total += va_arg(ap, int);
    va_end(ap);
    return total;
}
sum(4, 10, 20, 30, 40)   → 100
sum(2, 5, 15)            → 20
```

| ম্যাক্রো / টাইপ | কাজ |
|---|---|
| `va_list ap` | আর্গুমেন্টগুলোর ওপর কার্সর |
| `va_start(ap, last)` | **শেষ নামযুক্ত** প্যারামিটারের পর থেকে শুরু |
| `va_arg(ap, T)` | পরেরটি T টাইপ হিসেবে আনে |
| `va_copy(d, s)` | কার্সরের কপি (C99) |
| `va_end(ap)` | পরিষ্কার করে — প্রতি va_start-এ একটি |

- ⚠️ **ফাঁদ:** নামহীন আর্গুমেন্টে **ডিফল্ট আর্গুমেন্ট প্রোমোশন** হয়: char, short → **int**; float → **double**। তাই `va_arg(ap, float)` ও `va_arg(ap, char)` অনির্ধারিত — double / int চাও। শেষ আর্গুমেন্টের পরে পড়াও অনির্ধারিত।
- **কলি (callee) সংখ্যা জানে কীভাবে:** একটি **count** আর্গুমেন্ট (ওপরের sum) · শেষে একটি **সেন্টিনেল** (NULL, −1) · একটি **ফরম্যাট স্ট্রিং** — printf % চিহ্ন গোনে। সংখ্যা ভুল হলে va_arg আবর্জনা পড়ে।

## ৬. কমান্ড-লাইন প্যারামিটার (argc, argv)

`int main(int argc, char *argv[])` (বা `char **argv`) কমান্ডের পরে টাইপ করা শব্দগুলো পায়। **argc** = কতগুলো শব্দ, **প্রোগ্রামের নামসহ**; **argv[0]** = প্রোগ্রামের নাম; argv[1] … argv[argc − 1] = আর্গুমেন্টগুলো, **সবসময় স্ট্রিং হিসেবে**; এবং **argv[argc] = NULL**।

*(ডুডল: `$ ./prog one two ⇒ argc = 3`। চারটি ঘরের অ্যারে argv[0]…argv[3]; প্রথম তিনটি নির্দেশ করে "./prog\0", "one\0", "two\0" স্ট্রিংকে; argv[3] হলো NULL, যা তালিকা শেষ করে। ক্যাপশন: argv হলো স্ট্রিং-পয়েন্টারের একটি অ্যারে।)*

**সমাধানকৃত উদাহরণ ✍ `$ ./sum 10 20 30`** — argc = **4**; argv[1] হলো **স্ট্রিং** "10", তাই যোগফলের জন্য রূপান্তর লাগে: `for (i = 1; i < argc; i++) s += atoi(argv[i]);` → **60**। (খ) `$ ./prog "hello world"` → argc = **2**: শেলের উদ্ধৃতিচিহ্ন একে একটি আর্গুমেন্ট বানায়। (গ) শুধু `$ ./prog` → argc = 1, argv[1] = NULL — ছোঁয়ার আগে `argc < 2` যাচাই করো। (ঘ) `atoi("12ab")` চুপচাপ 12 দেয় — **strtol** এরর জানাতে পারে।

- ⚠️ **ফাঁদ:** (১) বাস্তবে argc কখনো 0 নয় — নামটাও গোনা হয়। (২) `argv[1] + argv[2]` যোগ করে **পয়েন্টার**, সংখ্যা নয়। (৩) argc/argv নাম শুধু প্রথা; স্ট্যান্ডার্ড যা ঠিক করে দেয় তা হলো **টাইপ**।
- 🟣 **কৌশল:** "**argc নামও গোনে; argv শেষ হয় NULL-এ।**" stdarg-এর জন্য: "**start, arg, arg, …, end**" — আর "**ছোটরা বড় হয়**": char → int, float → double।

## ৭. এরর হ্যান্ডলিং: রিটার্ন মান, errno, perror, assert, exit

C-তে **এক্সেপশন (exception) নেই**। লাইব্রেরি ফাংশন ব্যর্থতা জানায় তার **রিটার্ন মান** দিয়ে এবং অনেকে **errno**-তে একটি কোড রেখে; প্রোগ্রামকে **যাচাই** করতে হয়, **stderr**-এ জানাতে হয় এবং **ব্যর্থতার এক্সিট স্ট্যাটাস** দিয়ে শেষ করতে হয়। যাচাই বাদ দিলে আপনা-আপনি কিছুই ঘটে না।

| কল | ব্যর্থতার চেহারা |
|---|---|
| fopen, malloc, calloc, fgets | **NULL** |
| scanf, fscanf | চাওয়ার চেয়ে কম আইটেম, বা **EOF** |
| fgetc, getchar, fclose, fputs | **EOF** |
| printf, fprintf | একটি **ঋণাত্মক** মান |
| fseek / ftell | অশূন্য / **−1L** |
| fread, fwrite | **n**-এর চেয়ে কম আইটেম |
| sqrt(−1) · strtol ওভারফ্লো | errno = **EDOM** · **ERANGE** |

*(ডুডল: একটি ফ্লোচার্ট — `fp = fopen(...)` → হীরক "fp == NULL ?" — হ্যাঁ (লাল): perror → stderr, তারপর exit(EXIT_FAILURE); না (সবুজ): ব্যবহার, তারপর fclose, তারপর return 0। ক্যাপশন: যাচাই করো, জানাও, বেরিয়ে যাও — প্রতিটি লাইব্রেরি কলে।)*

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <string.h>
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
    perror("data.txt");
    fprintf(stderr, "code %d: %s\n",
            errno, strerror(errno));
    exit(EXIT_FAILURE);
}
```

- **errno · perror · strerror।** `errno` (`<errno.h>`) ব্যর্থ কল একটি ধনাত্মক কোডে বসায়, আর লাইব্রেরি একে **কখনো 0-তে ফেরায় না** — যাচাই করতে চাইলে কলের আগে নিজে `errno = 0` করো। ISO C সংজ্ঞায়িত করে কেবল **EDOM, ERANGE, EILSEQ**; ENOENT ইত্যাদি POSIX-এর। `perror("data.txt")` stderr-এ ছাপে **data.txt: No such file or directory**; `strerror(errno)` (`<string.h>`) সেই লেখাটি স্ট্রিং হিসেবে দেয়।

**assert, exit, abort — প্রোগ্রাম যেভাবে শেষ হয়**
- `assert(expr)` (`<assert.h>`): মিথ্যা হলে stderr-এ এক্সপ্রেশন, ফাইল ও লাইন ছাপে, তারপর **abort()** ডাকে।
- `<assert.h>`-এর আগে `#define NDEBUG` ⇒ সব assert **উধাও** — এটি শুধু ডিবাগের হাতিয়ার।
- `exit(status)` (`<stdlib.h>`): সব স্ট্রিম ফ্লাশ ও বন্ধ করে, atexit() হ্যান্ডলার চালায়, স্ট্যাটাস OS-কে ফেরত দেয়।
- main-এ `return n;` ≡ `exit(n)` · **EXIT_SUCCESS** = 0 · **EXIT_FAILURE** ≠ 0 (সাধারণত 1)।
- `abort()`: অস্বাভাবিক সমাপ্তি (SIGABRT), atexit হ্যান্ডলার চলে না, ফ্লাশের নিশ্চয়তা নেই।
- শেল স্ট্যাটাস পড়ে `$?` (Linux) বা `%ERRORLEVEL%` (Windows) দিয়ে।

**সমাধানকৃত উদাহরণ ✍ শূন্য দিয়ে ভাগ।** b = 0 হলে পূর্ণসংখ্যার `a / b` **অনির্ধারিত আচরণ** — কোনো রিটার্ন কোড নেই, errno নেই, সাধারণত ক্র্যাশ (SIGFPE) — তাই **আগে যাচাই**: `if (b == 0) { fputs("divide by zero\n", stderr); return EXIT_FAILURE; }`। IEEE 754 ফ্লোটিং পয়েন্ট আলাদা: 1.0 / 0.0 = **inf**।

- ⚠️ **ফাঁদ:** (১) errno অর্থবহ কেবল ব্যর্থ কলের **ঠিক পরে**। (২) **assert** ইনপুট যাচাই নয় — রিলিজ বিল্ডে উধাও হয়। (৩) এরর জানাও **stderr**-এ, stdout-এ নয়। (৪) **0 = সাফল্য**, অশূন্য = ব্যর্থতা — উল্টো নয়।
- 🟣 **কৌশল:** "**যাচাই, জানাও, বেরোও।**" রিটার্ন মান যাচাই করো, stderr-কে জানাও (perror), EXIT_FAILURE দিয়ে বেরোও। "**বাগের জন্য assert, ব্যবহারকারীর জন্য if।**"

## ৮. C-তে গ্রাফিক্স (graphics.h, Turbo C)

**graphics.h** হলো DOS-এর Turbo C/C++-এর জন্য Borland-এর **BGI** (Borland Graphics Interface) — **ISO C-র অংশ নয়** (gcc-তে এমন হেডার নেই; WinBGIm-এর মতো পোর্ট আছে, আধুনিক কোড SDL বা OpenGL ব্যবহার করে)। স্ক্রিন হলো পিক্সেলের গ্রিড, যার **মূলবিন্দু (0, 0) ওপরে-বাঁয়ে** এবং **y বাড়ে নিচের দিকে**; VGA হাই মোডে (640 × 480, 16 রং) `getmaxx()` = 639 ও `getmaxy()` = 479।

*(ডুডল: স্ক্রিন একটি আয়তক্ষেত্র — ওপরে-বাঁয়ে (0,0), ডানে x-এর তীর, নিচের দিকে y-এর তীর, নিচে-ডানে (639, 479); ভেতরে rectangle(60,52,120,112), তার মধ্যে একটি বৃত্ত এবং একটি হেলানো line()। ক্যাপশন: স্ক্রিন স্থানাঙ্কে y নির্দেশ করে নিচে।)*

| ফাংশন | কাজ |
|---|---|
| `initgraph(&gd, &gm, path)` | গ্রাফিক্স মোডে ঢোকে; `gd = DETECT` নিজে শনাক্ত করে |
| `graphresult()` · `closegraph()` | ঠিক থাকলে **grOk** (0) · টেক্সট মোডে ফেরা |
| `putpixel(x,y,c)` · `line(x1,y1,x2,y2)` | একটি পিক্সেল · একটি রেখা |
| `circle(x,y,r)` · `rectangle(l,t,r,b)` | কেন্দ্র + ব্যাসার্ধ · **দুই কোণ** |
| `setcolor(c)` · `setbkcolor(c)` | ১৬টি রং: BLACK 0 · BLUE 1 · RED 4 · WHITE 15 |
| `setfillstyle(p,c)` + `floodfill(x,y,b)` | সীমানার রং b পর্যন্ত একটি অঞ্চল ভরাট |
| `outtextxy(x,y,s)` · `cleardevice()` | একটি পিক্সেলে লেখা · স্ক্রিন মোছা |

```c
#include <graphics.h>
#include <conio.h>    /* getch() */
int main(void) {
  int gd = DETECT, gm;
  initgraph(&gd, &gm, "C:\\TC\\BGI");
  if (graphresult() != grOk) return 1;
  setcolor(RED);  rectangle(100,100,200,200);
  setcolor(BLUE); circle(150, 150, 50);
  outtextxy(110, 220, "Graphics Example");
  getch(); closegraph(); return 0;
}
```

- ⚠️ **ফাঁদ:** (১) **getch()** আছে **conio.h**-এ, graphics.h-এ নয় — এটি শুধু একটি কী চাপা পর্যন্ত ছবিটা ধরে রাখে। (২) rectangle নেয় **দুই কোণ**, প্রস্থ-উচ্চতা নয়। (৩) বড় y মানে স্ক্রিনে **নিচে**। (৪) BGI একটি DOS লাইব্রেরি, স্ট্যান্ডার্ড C নয়।

## ৯. স্ট্যান্ডার্ড লাইব্রেরি ফাংশন ও হেডার

**C স্ট্যান্ডার্ড লাইব্রেরি** হলো কম্পাইলারের সঙ্গে আসা আগে-কম্পাইল-করা কোড। **হেডার ঘোষণা করে** (প্রোটোটাইপ, ম্যাক্রো, টাইপ); **লাইব্রেরি আর্কাইভ সংজ্ঞা দেয়** (যে মেশিন কোড লিংকার যোগ করে)। C89-এ স্ট্যান্ডার্ড হেডার **১৫টি**, C99-এ **২৪টি**, C11-এ **২৯টি**।

| হেডার | হাই-ইল্ড সদস্য |
|---|---|
| `<stdio.h>` | printf, scanf, fopen, fgets, fread, perror, EOF, FILE, NULL |
| `<stdlib.h>` | malloc, calloc, realloc, free, atoi, strtol, **rand, srand, exit, abs**, qsort, system |
| `<string.h>` | strlen, strcpy, strcat, strcmp, strchr, strstr, memcpy, memset, strerror |
| `<math.h>` | sqrt, pow, fabs, ceil, floor, sin, cos, log, log10, exp — সবই ফেরত দেয় **double** |
| `<ctype.h>` · `<time.h>` | isalpha, isdigit, toupper, tolower · time, clock, difftime |
| `<limits.h>` · `<stddef.h>` | INT_MAX, CHAR_BIT · size_t, NULL, offsetof |

**সমাধানকৃত উদাহরণ ✍ আউটপুট:** `strlen("Dhaka")` = **5** কিন্তু `sizeof("Dhaka")` = **6** · `pow(2, 10)` = **1024.000000** · `floor(-2.1)` = **−3.0** · `srand(time(NULL))`-এর পর `rand() % 6 + 1` = একটি ছক্কার দান।

- 🟣 **কৌশল:** "**abs থাকে stdlib-এ, fabs থাকে math-এ।**" "**হেডার ঘোষণা করে, লাইব্রেরি সংজ্ঞা দেয়**" — #include কম্পাইলারকে জানায় ফাংশনটি আছে; কোড আনে শুধু লিংকার।

## ১০. সোর্স থেকে এক্সিকিউটেবল: কম্পাইলিং ও লিংকিং

একটি C প্রোগ্রাম তৈরি হয় চার ধাপে, আর **লিংকার (linker)** শেষ ধাপ: এটি অবজেক্ট ফাইল ও লাইব্রেরি জুড়ে একটি এক্সিকিউটেবল বানায় **সিম্বল রিজলভ করে** — প্রতিটি বাইরের নামের ব্যবহারকে ঠিক একটি সংজ্ঞার সঙ্গে মিলিয়ে — এবং ঠিকানা **রিলোকেট** করে। এরপর **লোডার** এক্সিকিউটেবলটি মেমোরিতে বসিয়ে চালু করে।

*(ডুডল: hello.c → প্রিপ্রসেসর (-E → hello.i) → কম্পাইলার (-S → hello.s) → অ্যাসেম্বলার (-c → hello.o) → লিংকার ★ (নাম মেলায়; নিচ থেকে libc · libm · .a / .so যুক্ত হয়) → a.out / .exe। "gcc ডিফল্টে চারটিই চালায়: gcc hello.c -o hello"; তারপর লোডার প্রোগ্রামটি মেমোরিতে বসিয়ে main ডাকে।)*

| ধাপ | ইন → আউট | কী করে · সাধারণ এরর |
|---|---|---|
| প্রিপ্রসেসর | .c → .i | #include, #define, #if; কমেন্ট বাদ দেয় (প্রিপ্রসেসর লেসন) · হেডার ফাইল না পাওয়া |
| কম্পাইলার | .i → .s | সিনট্যাক্স ও টাইপ যাচাই, অ্যাসেম্বলি কোড · সেমিকোলন বাদ, টাইপ অমিল |
| অ্যাসেম্বলার | .s → .o / .obj | **অমীমাংসিত** বাইরের সিম্বলসহ মেশিন কোড |
| লিংকার ★ | .o + libs → exe | রিজলভ ও রিলোকেট করে · **undefined reference**, multiple definition |

| দিক | স্ট্যাটিক লিংকিং | ডাইনামিক (শেয়ার্ড) লিংকিং |
|---|---|---|
| লাইব্রেরি ফাইল | .a (Linux) · .lib (Windows) | .so (Linux) · .dll (Windows) |
| কখন যুক্ত | লিংকের সময়: **কেবল দরকারি অবজেক্ট মডিউল** কপি হয় | লোডের সময় ডাইনামিক লিংকার দিয়ে (বা রানটাইমে: dlopen, LoadLibrary) |
| আকার · মেমোরি | বড় ফাইল; প্রতিটি প্রোগ্রামের নিজস্ব কপি | ছোট ফাইল; মেমোরিতে **একটি কপি ভাগাভাগি** |
| লাইব্রেরি হালনাগাদ | প্রতিটি প্রোগ্রাম আবার লিংক | .so/.dll একবার বদলালেই হয় |
| ঝুঁকি | রানটাইমে নেই — স্বয়ংসম্পূর্ণ | লাইব্রেরি না থাকা বা ভুল সংস্করণ ("DLL hell") |

```c
/* util.h */ extern int counter;
              int add(int a, int b);
/* util.c */ int counter = 0;
              int add(int a, int b)
              { counter++; return a + b; }
/* main.c */ #include "util.h"
gcc -c main.c      → main.o
gcc -c util.c      → util.o
gcc main.o util.o -o prog
gcc prog.c -o prog -lm   (libm)
```

- **extern ও লিংকেজ।** `extern` এমন একটি নাম ঘোষণা করে যার সংজ্ঞা **অন্য কোথাও**; সংজ্ঞা থাকতে হবে ঠিক **একটি** ফাইলে। ফাইল স্কোপে `static` দেয় **ইন্টারনাল লিংকেজ**: নামটি লিংকার ও অন্য ফাইলের কাছে অদৃশ্য (স্টোরেজ ক্লাস লেসন)। `-lm` গণিত লাইব্রেরি libm যুক্ত করে; একে সোর্স ফাইলের **পরে** রাখো।
- ⚠️ **ফাঁদ:** (১) `#include <math.h>` দেয় কেবল প্রোটোটাইপ; "**undefined reference to sqrt**" একটি **লিংকার** এরর, সারে -lm দিয়ে। (২) স্ট্যাটিক লিংকিং পুরো লাইব্রেরি কপি করে **না**। (৩) সেমিকোলন বাদ পড়া **কম্পাইল** এরর, লিংক এরর নয়।
- 🟣 **কৌশল:** "**Please Compile And Link**" — Preprocess, Compile, Assemble, Link; ফ্ল্যাগ **-E -S -c** প্রথম তিনটির পরে থামায়। "**স্ট্যাটিক = সঙ্গে স্যুটকেস, ডাইনামিক = পৌঁছে ধার।**"

## লিখিত প্রশ্ন (১০ নম্বর)

একটি C প্রোগ্রাম লেখো যা কমান্ড লাইন থেকে একটি ফাইলের নাম নেয়, ফাইলের পূর্ণসংখ্যাগুলো পড়ে তাদের যোগফল ছাপে এবং প্রতিটি এরর ঠিকভাবে সামলায়। argc/argv এবং তোমার প্রতিটি যাচাই ব্যাখ্যা করো।

**আদর্শ উত্তর:**

১. **আর্গুমেন্ট (২)** — `int main(int argc, char *argv[])`; argc প্রোগ্রামের নামও গোনে, তাই একটি ফাইলের নাম মানে **argc == 2**, আর argv[1] হলো নামটি। `argc != 2` হলে stderr-এ ব্যবহারবিধি ছাপো এবং `return EXIT_FAILURE;`।
২. **খোলা (২)** — `FILE *fp = fopen(argv[1], "r");` এবং `if (fp == NULL) { perror(argv[1]); return EXIT_FAILURE; }` — perror errno থেকে কারণটি যোগ করে, stderr-এ।
৩. **পড়া (৩)** — `long sum = 0; int x; while (fscanf(fp, "%d", &x) == 1) sum += x;` — লুপটি **রিটার্ন মান** যাচাই করে (feof নয়), তাই ফাইল শেষে ও ভুল ডেটায় থামে; তারপর `if (ferror(fp))` হলে পড়ার এরর জানাও।
৪. **শেষ (১)** — `fclose(fp); printf("Sum = %ld\n", sum); return EXIT_SUCCESS;` — fclose স্ট্রিম ফ্লাশ করে ছেড়ে দেয়; স্ট্যাটাস 0 শেলকে জানায় কাজ সফল।
৫. **ব্যাখ্যা (২)** — argv রাখে স্ট্রিং, argv[argc] হলো NULL; C-তে এক্সেপশন নেই বলে প্রতিটি লাইব্রেরি কল যাচাই করা হয়েছে: fopen-এর NULL, fscanf-এর আইটেম সংখ্যা, ferror-এর ফ্ল্যাগ।

```c
#include <stdio.h>
#include <stdlib.h>
int main(int argc, char *argv[]) {
    if (argc != 2) { fprintf(stderr, "usage: %s file\n", argv[0]); return EXIT_FAILURE; }
    FILE *fp = fopen(argv[1], "r");
    if (fp == NULL) { perror(argv[1]); return EXIT_FAILURE; }
    long sum = 0; int x;
    while (fscanf(fp, "%d", &x) == 1) sum += x;
    if (ferror(fp)) { perror("read"); fclose(fp); return EXIT_FAILURE; }
    fclose(fp);
    printf("Sum = %ld\n", sum);
    return EXIT_SUCCESS;
}
```

**আরও অনুশীলন (লিখিত):** ① একটি ভেরিয়াডিক `average(int n, ...)` যা double ফেরত দেয়, এবং `va_arg(ap, float)` কেন ভুল ② একটি প্রোগ্রাম যা বাইনারি ফাইলে একটি struct রেকর্ড যোগ করে এবং fseek/fread দিয়ে k-তম রেকর্ড ফেরত পড়ে ③ প্রতিটির gcc ফ্ল্যাগসহ কম্পাইলেশনের চারটি ধাপ, এবং টেবিলে স্ট্যাটিক বনাম ডাইনামিক লিংকিং ④ বিভিন্ন প্রস্থ/প্রিসিশন/ফ্ল্যাগ মিলিয়ে printf-এর আউটপুট অনুমান।

**পরীক্ষার আগে ✓** যেকোনো প্রস্থ, প্রিসিশন ও ফ্ল্যাগে printf-এর আউটপুট বলতে পারি · ছয়টি fopen মোড এবং আগের ফাইলে প্রত্যেকটি কী করে বলতে পারি · রেকর্ড k-এর জন্য fseek অফসেট বের করতে পারি · চারটি বিল্ড ধাপের নাম বলতে ও স্ট্যাটিক-ডাইনামিক লিংকিংয়ের তুলনা করতে পারি।
