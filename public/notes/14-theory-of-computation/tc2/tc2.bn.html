১কনটেক্সট-ফ্রি ভাষা

হাই-ইল্ড
সংজ্ঞা কোনো ভাষাকে কনটেক্সট-ফ্রি (context-free) বলা হয় যখন একটি কনটেক্সট-ফ্রি গ্রামার তা তৈরি করতে পারে এবং একটি পাশডাউন অটোমাটন তা চিনতে পারে — চমস্কির টাইপ ২। একটি স্ট্যাক একসময়ে মাত্র একটি নেস্টেড কাঠামো ধরে রাখতে পারে, তার বেশি নয়।
কনটেক্সট-ফ্রি ভাষাভাষাটি কী বলেগ্রামার
{aⁿ bⁿ | n ≥ 0}যত a তত bS → aSb | ε
{w wᴿ | w ∈ {a,b}*}{a,b}-এর সব প্যালিন্ড্রোমS → aSa | bSb | a | b | ε
{aⁿ bᵐ cᵐ | n,m ≥ 0}প্রথম ব্লক ফ্রি, পরের দুটি জোড়S → AB · A → aA|ε · B → bBc|ε
{ (ⁿ )ⁿ | n ≥ 0 }সুষম বন্ধনীS → (S) | SS | ε
{aⁿ bⁿ cⁿ}কনটেক্সট-ফ্রি নয়দুটি স্ট্যাক লাগে

কারণ কী ইউনিয়ন: নতুন শুরু প্রতীক দিয়ে যেকোনো একটি গ্রামার বেছে নাও · কনক্যাটেনেশন: S₁ → S₂, তারপর L₂-এর নিয়ম · স্টার: S → SS | ε, তারপর L-এর নিয়ম · কমপ্লিমেন্ট: PDA-র গ্রহণকারী অবস্থা উল্টালে কোনো CFG পাওয়া যায় না · রেগুলারের সাথে ইন্টারসেকশন: আগে PDA, তার উপর ফিনিট অটোমাটন।
পরীক্ষার ফাঁদ "ইন্টারসেকশনে বদ্ধ নয়" — এর প্রমাণও মনে রাখতে হয়: L₁ = {aⁿ bⁿ cᵐ} ও L₂ = {aᵐ bⁿ cⁿ} দুটিই কনটেক্সট-ফ্রি, কিন্তু L₁ ∩ L₂ = {aⁿ bⁿ cⁿ} নয়। তাই উত্তর হলো সাধারণভাবে নয় — তবু CFL ∩ রেগুলার সবসময় CFL।
মনে রাখার কৌশল রেগুলার = ∪ ∩ ¬ * · CFL = ∪ · *। রেগুলার ভাষার যে একমাত্র বন্ধতা CFL-এর নেই, তা হলো ইন্টারসেকশন।
সমাধানকৃত উদাহরণ ✍ {aⁿ bᵐ cᵐ | n,m ≥ 0}-এর গ্রামার
V = {S, A, B}, Sigma = {a, b, c}, S = S P = { S -> A B , A -> a A | e , B -> b B c | e } derivation of "aabbcc": S => AB => aAB => aaAB => aaB => aabBc => aabbBcc => aabbcc

A নিয়ম a-ব্লককে মুক্ত রাখে, B নিয়ম b ও c জোড়া লাগায় — তাই n, m আলাদা হতে পারে।

২কনটেক্সট-ফ্রি গ্রামার: ৪-টাপল

হাই-ইল্ড
সংজ্ঞা কনটেক্সট-ফ্রি গ্রামার (context-free grammar) হলো G = (V, Σ, P, S) — ভেরিয়েবল, টার্মিনাল, প্রোডাকশন ও শুরু প্রতীক। এটি বারবার একটি ভেরিয়েবলকে তার কোনো প্রোডাকশনের ডান পাশ দিয়ে বদলে লিখে L(G) তৈরি করে। এটি কনটেক্সট-ফ্রি ঠিক তখনই, যখন বাম পাশে ঠিক একটিমাত্র ভেরিয়েবল — পাশে আর কিছু নেই।
অংশকীউদাহরণ G-তে
Vভেরিয়েবলের সসীম সেট; S ∈ VV = {S, A, B}
Σটার্মিনালের সসীম সেট; V ∩ Σ = ∅Σ = {a, b}
Pপ্রোডাকশনের সেট A → α, α ∈ (V ∪ Σ)*P = { S → aSb, S → ε }
Sশুরু প্রতীক, S ∈ VS = S

{aⁿ bⁿ | n ≥ 0}-এর গ্রামার

G = ( {S}, {a, b}, P, S ) P = { S -> a S b , S -> e } leftmost derivation of "aaabbb": S => aSb => aaSbb => aaaSbbb => aaabbb

প্রতিবার S → aSb বামে আরেকটি a, ডানে আরেকটি b জড়ায়; S → ε তা থামিয়ে দেয়। n বার ব্যবহারে পাওয়া যায় aⁿbⁿ, আর n = 0 হলে ε — তাই ভাষা {aⁿ bⁿ | n ≥ 0}, n ≥ 1 নয়।

সংকেতঅর্থ
a, b, 0, 1টার্মিনাল — আসল অক্ষর
S, A, Tভেরিয়েবল — বদলানোর জায়গা
A → αএকটি প্রোডাকশন
A ⇒ βএক ধাপ ডেরিভেশন
A ⇒* wশূন্য বা তার বেশি ধাপ, w সব টার্মিনাল
εখালি স্ট্রিং, |ε| = 0
মনে রাখার কৌশল চারটি অক্ষরের ক্রম: Variable, Σymbol, Production, Start — "V–Σ–P–S"।
পরীক্ষার ফাঁদ শর্তটি বাম পাশে, ডান পাশে নয়। A → aSb কনটেক্সট-ফ্রি; AB → aSb নয়, ডান পাশ যেমনই হোক।
IT link প্রতিটি প্রোগ্রামিং ভাষার সঙ্গে একটি CFG থাকে BNF-তে, যা তার সিনট্যাক্সের সংজ্ঞাই; পার্সার জেনারেটর সেই গ্রামার থেকেই যাচাইয়ের টেবিল বানায়।
V ∩ Σ = ∅ — কোনো ভেরিয়েবল কখনো টার্মিনালও হয় না, তাই চারটি অংশ কোনোদিন মিশে যায় না

৩ডেরিভেশন, পার্স ট্রি ও অ্যাম্বিগুয়াস

হাই-ইল্ড
ডেরিভেশন S থেকে শুরু করে একবারে একটি ভেরিয়েবল বদলাতে থেকে যাও, যতক্ষণ না কেবল টার্মিনাল থাকে। লেফটমোস্ট ডেরিভেশনে সবসময় বাঁকে জেতা ভেরিয়েবলটি বদলায়, রাইটমোস্ট-এ ডানে জেতাটি। দুটো একই স্ট্রিংয়ে পৌঁছায় — শুধু কাজের ক্রম আলাদা, তাই পার্সার বানানো হয় লেফটমোস্ট।
LEFTMOST RIGHTMOST S S S => aSb S => aSb S => aaSbb S => aSbb S => aaaSbbb S => aaSbb S => aaabbb S => aaabbb
পার্স ট্রি = আঁকা ডেরিভেশন প্রতিটি ভেরিয়েবল একটি নোড; প্রয়োগ প্রতিটি প্রোডাকশন একটি নোড, যার শিশুগুলো ওই নিয়মের ডান পাশের প্রতীকগুলো বাম থেকে ডানে। তাই পাতা = স্ট্রিং — বাম থেকে ডানে পড়ে। আর n টি টার্মিনালের ট্রিতে ঠিক n − 1টি অভ্যন্তরীণ নোড থাকে।

অ্যাম্বিগুয়াস (Ambiguity): এক স্ট্রিং, দুটি ট্রি

সংজ্ঞা কোনো গ্রামার অ্যাম্বিগুয়াস (ambiguous) যখন তার ভাষার কোনো একটি স্ট্রিংয়ের দুই বা তার বেশি ভিন্ন লেফটমোস্ট ডেরিভেশন থাকে — সমতুল্যভাবে দুটি পার্স ট্রি। একটিও স্ট্রিং না থাকলে তা অস্পষ্টতামুক্ত (unambiguous)। একটি খারাপ স্ট্রিংই যথেষ্ট।
সমাধানকৃত উদাহরণ ✍ প্রচলিত অ্যাম্বিগুয়াস গ্রামার
E -> E + E | E * E | id tree 1: (id+id)*id tree 2: id+(id*id) * + / \ / \ + id id * / \ / \ id id id id

চারটি টার্মিনাল একই ক্রমে, কিন্তু গ্রুপিং দুটি — তাই id+id*id অ্যাম্বিগুয়াস। ঠিক করতে প্রতি অপারেটরের জন্য একটি বাড়তি স্তর দরকার: E → E + T | T, T → T * F | F, F → id।

মনে রাখার কৌশল "অ্যাম্বিগুয়াস = অ্যাল্টারনেটিভ ট্রি"। এক স্ট্রিং দুইভাবে বানানো গেলে পার্সার বুঝতে পারে না তা মানে কী।
পরীক্ষার ফাঁদ অ্যাম্বিগুয়াসের সাথে ε-প্রোডাকশন, ভেরিয়েবলের সংখ্যা বা অসীম ভাষার কোনো সম্পর্ক নেই। আর এটি ননডিটারমিনিজমও নয়: PDA প্রতিটি CFL-তেই ননডিটারমিনিস্টিক।

৪কাজের গ্রামার: সুষম বন্ধনী

লিখিত প্রিয়
সংজ্ঞা Σ = { (, ) }-এর উপর সুষম বন্ধনীর ভাষা হলো { (ⁿ )ⁿ | n ≥ 0 }: প্রতিটি ( পরে একটি ) দিয়ে বন্ধ, আর নেস্টিং ঠিক থাকে। এটি কনটেক্সট-ফ্রি, আর অটোমাটা নোটের PDA ঠিক ( খোলার সময় push, ) এলে pop করে এটিই গ্রহণ করে।

গ্রামারটি

V = {S}, Sigma = { ( , ) }, S = S P = { S -> SS , দুটি গ্রুপ পাশাপাশি S -> (S) , এক গ্রুপের ভিতরে আরেকটি S -> e } খালি গ্রুপ leftmost derivation of "(())()": S => SS => (S)S => ((S))S => (())S => (())(S) => (())()

এটিকে গ্রহণের প্রমাণ হিসেবে পড়ো: প্রতিটি ( ঠিক একটি ) দিয়ে বন্ধ, আর কোনো ) আগে আসে না। উল্টো দিকটাও সত্য — S → SS প্রথম গ্রুপ বানিয়ে বাকিটা জুড়ে দেয়, S → (S) একটি নেস্টিং স্তর সামলায়।

প্রোডাকশনএটি কোন ভাবনা ধরেযা শেষ করতে পারে
S → εবেস কেস: খালি গ্রুপε, আর কিছু নয়
S → (S)একটি গ্রুপকে এক জোড়ায় মোড়ানো( ), ( () ), ( (()) ) …

৫CFG সরলীকরণ: CNF ও GNF

হাই-ইল্ড
  1. অব্যবহৃত প্রতীক সরাও: আগে নন-জেনারেটিং ভেরিয়েবল, তারপর অনপ্রাপ্য ভেরিয়েবল।
  2. ε-প্রোডাকশন A → ε সরাও: সব নালেবল ভেরিয়েবল খুঁজে তার ε-নিয়ম বাদ দাও।
  3. ইউনিট প্রোডাকশন A → B সরাও সেই জায়গায় B-র নিজের নিয়ম বসিয়ে (বারবার — চেইন ঘটে)।
  4. চমস্কি নরমাল ফর্মে রূপান্তর — CYK ও পার্সার জেনারেটর এটাই চায়।
  5. গ্রেবাখ নরমাল ফর্মে রূপান্তর, যেখানে প্রতিটি নিয়ম টার্মিনাল দিয়ে শুরু হয়।
নরমাল ফর্মপ্রতিটি প্রোডাকশনযা দেয়

GNFA → aαএক প্রতীকেই পূর্বানুমান

সমাধানকৃত রূপান্তর ✍ S → aSb | ε থেকে CNF
original S -> a S b | e step 1 বাঁ টার্মিনালটি বাঁধো, তারপর ডানেরটি: S -> A S B step 2 ডানে এখনো ৩ প্রতীক, তাই পুচুরটি ভাঙো: S -> A X , X -> S B , A -> a , B -> b result S -> A X | e , X -> S B , A -> a , B -> b

S → ε কেন টেকে যায়: CNF-তে এটি তখনই বৈধ যখন ε ∈ L এবং S কোনো ডান পাশে নেই। এখানে S আছে, X → SB-এর ভিতরে। তাই নিখুঁত রূপে একটি নতুন শুরু প্রতীক S₀ → S যোগ করতে হয়, বাকি চারটি নিয়ম একই থাকে।

পরীক্ষার ফাঁদ S → ASB CNF নয় — ঠিক ২ ভেরিয়েবল বা ১ টার্মিনাল, তিন প্রতীক কখনো নয়। আর A → aα হলো গ্রেবাখ, CNF নয়।
মনে রাখার কৌশল CNF = দুই বা এক, GNF = টার্মিনাল দিয়ে শুরু। ডান পাশের প্রতীক গুনো: ২ বা ১ ⇒ CNF; "a তারপর ভেরিয়েবল" ⇒ GNF; "aB" ⇒ রেগুলার।

৬CFL-এর পাম্পিং লেমা, CYK ও স্টেপ গণনা

হাই-ইল্ড
কনটেক্সট-ফ্রি ভাষার পাম্পিং লেমা L কনটেক্সট-ফ্রি হলে এমন দৈর্ঘ্য p আছে যাতে |s| ≥ p এমন প্রতিটি s ∈ L-কে s = uvxyz করে ভাঙা যায়, যেখানে |vxy| ≤ p, |vy| ≥ 1 এবং প্রতিটি i ≥ 0-এর জন্য uvⁱxyⁱz ∈ L। মানে, ছোট একটা জানালার ভিতরে এমন একটি ভারসাম্যপূর্ণ অংশ আছে যা যতবার খুশি পুনরাবৃত্তি করা যায়। রেগুলার সংস্করণের মতো এটিও খণ্ডনের হাতিয়ার।
শর্তকী বলে
|vxy| ≤ pপাম্পযোগ্য জানালাটি ছোট
|vy| ≥ 1v ও y একসঙ্গে খালি নয়
uvⁱxyⁱz ∈ L, ∀i ≥ 0v ও y একসঙ্গে পুনরাবৃত্তি হয়
পরীক্ষার ফাঁদ রেগুলার লেমা পাম্প করে xyⁿz; CFL লেমা পাম্প করে uvⁱxyⁱz — দুটি সূচক, এবং সেগুলো সমান। u(vxy)ⁿz লেখা ভুল। আর লেমা মেনে চললেই কোনো ভাষা কনটেক্সট-ফ্রি প্রমাণ হয় না।
সমাধানকৃত খণ্ডন ✍ {aⁿ bⁿ cⁿ | n ≥ 0} কনটেক্সট-ফ্রি নয়

পাম্পিং দৈর্ঘ্য p নাও আর s = aᵖbᵖcᵖ নাও। |vxy| ≤ p ও |vy| ≥ 1 শর্তে যেকোনো ভাঙায় y পুরোপুরি a-ব্লকের ভিতরে (y = aᵏ, k ≥ 1) অথবা পুরোপুরি b-ব্লকের ভিতরে (y = bᵏ)। একা y পাম্প করলে মিল ভেঙে যায়, আর v ও y একসঙ্গে পাম্প করলেও তা ফেরত আসে না, কারণ তারা ভিন্ন ব্লকে। শর্ত ভাঙে ⇒ L কনটেক্সট-ফ্রি নয়। এক বাক্যে: এখানে তিনটি একসঙ্গে গণনা দরকার, আর এক স্ট্যাক একটিই ধরে।

CYK ও স্টেপ গণনা CYK একটি নির্দিষ্ট CNF গ্রামারের জন্য O(n³) সময়ে সিদ্ধান্ত নেয় (সাধারণত O(n³·|G|)): O(n²) উপস্ট্রিংয়ের উপর নিচ থেকে ওপরের টেবিল, প্রতিটির জন্য O(n) স্প্লিট পয়েন্ট। আর CNF-তে দৈর্ঘ্য n ≥ 1 স্ট্রিং ডেরিভ করতে ঠিক 2n − 1 ধাপ লাগে — একটি ভেরিয়েবলকে n টি করতে n − 1 ধাপ A → BC, তারপর প্রতিটির জন্য একটি করে n ধাপ A → a।
মনে রাখার কৌশল "n − 1 ভাগ, তারপর n টার্মিনাল = মোট 2n − 1" — আর CYK ঘনঘন (cubic): উপস্ট্রিং, স্প্লিট পয়েন্ট ও নিয়মের তিনটি লুপ।
রেগুলার লেমার মতো এখানেও কোনো উপায়ে কনটেক্সট-ফ্রি প্রমাণ করা যায় না — শুধু খণ্ডন করা যায়

৭CFG ↔ PDA এবং CFG-র প্রয়োগ

লিখিত প্রিয়
সমতার উপপাদ্য (হাই-ইল্ড) কনটেক্সট-ফ্রি ⇔ কোনো PDA তা চিনে। "যদি" দিকটা সহজ — গ্রামারটিকে একটি লেফটমোস্ট ডেরিভেশন হিসেবে পড়ো। "কেবল যদি" দিকটাই চমকপ্রদ: PDA-র অবস্থাগুলোই ভেরিয়েবল হয়ে যায়, তাই মেশিনটি নিজেই নিজের গ্রামার লিখে ফেলে।
  1. শুরু প্রতীক S স্ট্যাকে, বটম মার্কার Z₀-এর উপরে push করো।
  2. স্ট্যাকের উপরে ভেরিয়েবল A থাকলে এবং P-তে A → α থাকলে, A বের করে α বিপরীত ক্রমে push করো, যাতে α-র বামতম প্রতীক আগে বেরোয়।
  3. স্ট্যাকের উপরে টার্মিনাল a থাকলে পরের ইনপুটের সাথে মেলাও: সমান হলে pop ও ইনপুট এগোও, নয়তো প্রত্যাখ্যান।
  4. ইনপুট শেষ এবং স্ট্যাকে শুধু Z₀ আছে — তবেই গ্রহণ।
  5. উল্টো দিক: প্রতিটি অবস্থা-জোড়া p, q ও স্ট্যাক প্রতীক X-এর জন্য একটি ভেরিয়েবল [pXq], প্রতিটি ট্রানজিশনে [pXq] → a, আর প্রতিটি গ্রহণকারী অবস্থা q-এর জন্য S₀ → [q₀ Z₀ q]।

  1. A → aα হলো গ্রেবাখ, A → aB রাইট-লিনিয়ার
  2. অ্যাম্বিগুয়াস = এক স্ট্রিং, দুটি ডেরিভেশন
  3. CFL লেমা পাঁচ খণ্ডে ভাঙে: uvxyz
  4. CYK ইনপুট দৈর্ঘ্যের ঘনঘন
  5. CNF-এর স্টেপ গণনা 2n − 1
  6. CFL ∩ রেগুলার = CFL
শীর্ষ ফাঁদ ডানে তিন প্রতীক মানে CNF নয় · "ইন্টারসেকশনে বদ্ধ নয়"-এর সাথে রেগুলার-ভাষার যোগসূত্র দরকার · CFL পাম্পিং লেমায় v ও y একই সূচকে পাম্প হয় · লেমা মেনে চললেই কনটেক্সট-ফ্রি প্রমাণ হয় না · PDA প্রোডাকশনের ডান পাশ বিপরীত ক্রমে ঢোকায় · n ≥ 0 ভাষায় ε থাকে।
