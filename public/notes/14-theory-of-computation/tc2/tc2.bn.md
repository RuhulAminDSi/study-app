## ১. কনটেক্সট-ফ্রি ভাষা

কোনো ভাষাকে **কনটেক্সট-ফ্রি** (context-free) বলা হয় যখন একটি **কনটেক্সট-ফ্রি গ্রামার** তা **তৈরি** করতে পারে এবং একটি **পাশডাউন অটোমাটন** তা চিনতে পারে — চমস্কির **টাইপ ২**। একটি স্ট্যাক একসময়ে মাত্র একটি নেস্টেড কাঠামো ধরে রাখতে পারে, তার বেশি নয়।

| কনটেক্সট-ফ্রি ভাষা | ভাষাটি কী বলে | গ্রামার |
|---|---|---|
| {aⁿ bⁿ \| n ≥ 0} | যত a তত b | S → aSb \| ε |
| {w wᴿ \| w ∈ {a,b}\*} | {a,b}-এর সব প্যালিন্ড্রোম | S → aSa \| bSb \| a \| b \| ε |
| {aⁿ bᵐ cᵐ \| n,m ≥ 0} | প্রথম ব্লক ফ্রি, পরের দুটি জোড় | S → aSb \| T · T → bTc \| ε |
| {(ⁿ )ⁿ \| n ≥ 0} | সুষম বন্ধনী | S → (S) \| SS \| ε |
| {aⁿ bⁿ cⁿ} | **কনটেক্সট-ফ্রি নয়** | দুটি স্ট্যাক লাগে |

**বন্ধতার (closure) পূর্ণ ছক**

| ভাষার উপর ক্রিয়া | CFL বদ্ধ? | কারণ |
|---|---|---|
| ইউনিয়ন | **হ্যাঁ** | নতুন শুরু প্রতীক দিয়ে যেকোনো একটি গ্রামার বেছে নাও |
| কনক্যাটেনেশন | **হ্যাঁ** | S₁ → S₂, তারপর L₂-এর নিয়ম |
| ক্লিন স্টার | **হ্যাঁ** | S → SS \| ε, তারপর L-এর নিয়ম |
| কমপ্লিমেন্ট | **না** | PDA-র গ্রহণকারী অবস্থা উল্টালে কোনো CFG পাওয়া যায় না |
| ইন্টারসেকশন | **না** | নিচের ফাঁদ দেখো |
| **রেগুলার** ভাষার সাথে ইন্টারসেকশন | **হ্যাঁ** | আগে PDA চালাও, তার উপর ফিনিট অটোমাটন |

- ⚠️ **ফাঁদ:** "ইন্টারসেকশনে বদ্ধ নয়" — এর প্রমাণও মনে রাখতে হয়: L₁ = **{aⁿ bⁿ cᵐ}** ও L₂ = **{aᵐ bⁿ cⁿ}** দুটিই কনটেক্সট-ফ্রি, কিন্তু L₁ ∩ L₂ = **{aⁿ bⁿ cⁿ}** **নয়**। তাই উত্তর হলো *সাধারণভাবে নয়* — তবু CFL ∩ **রেগুলার** সবসময় CFL।
- 💡 **কৌশল:** রেগুলার = **∪ ∩ ¬ \*** · CFL = **∪ · \***। রেগুলার ভাষার যে একমাত্র বন্ধতা CFL-এর নেই, তা হলো **ইন্টারসেকশন**।
- 📌 **এক স্ট্যাকই সীমা:** মেশিন খোলার অর্ধেকে push করে আর বন্ধের অর্ধেকে pop করে, তাই হাতে থাকে ঠিক **একটি** অসমাপ্ত নেস্টিং। এই জন্যই aⁿbⁿ ও w wᴿ কনটেক্সট-ফ্রি, কিন্তু aⁿbⁿcⁿ এবং দুই ভারসাম্য রাখা যায় না।
- ✍ **সমাধানকৃত উদাহরণ — {aⁿ bᵐ cᵐ | n,m ≥ 0}-এর গ্রামার:** V = {S, T}, Σ = {a, b, c}, S = S, P = { S → a S b | T , T → b T c | ε }। `aabbcc`-এর ডেরিভেশন: S ⇒ aSb ⇒ aaSbb ⇒ aaTbb ⇒ aabTcb ⇒ aabbTcc ⇒ aabbcc। প্রথম নিয়ম **a**-ব্লককে মুক্ত রাখে, দ্বিতীয় নিয়ম **b** ও **c** জোড়া লাগায় — তাই n, m আলাদা হতে পারে। তিনটিই ব্লক জোড়া লাগাতে হলে এক স্ট্যাক যথেষ্ট নয়।

## ২. কনটেক্সট-ফ্রি গ্রামার: ৪-টাপল

**কনটেক্সট-ফ্রি গ্রামার** (context-free grammar) হলো G = (**V**, **Σ**, **P**, **S**) — ভেরিয়েবল, টার্মিনাল, প্রোডাকশন ও শুরু প্রতীক। এটি বারবার একটি ভেরিয়েবলকে তার কোনো প্রোডাকশনের ডান পাশ দিয়ে বদলে লিখে L(G) তৈরি করে। এটি কনটেক্সট-ফ্রি ঠিক তখনই, যখন **প্রতিটি প্রোডাকশনের বাম পাশে ঠিক একটিমাত্র ভেরিয়েবল থাকে** — পাশে আর কিছু নেই।

| অংশ | কী | উদাহরণ G-তে |
|---|---|---|
| **V** | **ভেরিয়েবলের** সসীম সেট; S ∈ V | V = {S, A, B} |
| **Σ** | **টার্মিনালের** সসীম সেট; V ∩ Σ = ∅ | Σ = {a, b} |
| **P** | **প্রোডাকশনের** সেট A → α, α ∈ (V ∪ Σ)\* | P = { S → aSb, S → ε } |
| **S** | **শুরু প্রতীক**, S ∈ V | S = S |

**{aⁿ bⁿ | n ≥ 0}-এর গ্রামার**

```
G = ( {S}, {a, b}, P, S )
P = { S -> a S b ,  S -> e }

leftmost derivation of "aaabbb":
S => aSb => aaSbb => aaaSbbb => aaabbb
```

প্রতিবার **S → aSb** **বামে আরেকটি a, ডানে আরেকটি b জড়ায়**; **S → ε** তা থামিয়ে দেয়। n বার ব্যবহারে পাওয়া যায় **aⁿbⁿ**, আর n = 0 হলে **ε** — তাই ভাষা **{aⁿ bⁿ | n ≥ 0}**, **n ≥ 1 নয়**।

| সংকেত | অর্থ |
|---|---|
| a, b, 0, 1 | **টার্মিনাল** — আসল অক্ষর |
| S, A, T | **ভেরিয়েবল** — বদলানোর জায়গা |
| A → α | একটি **প্রোডাকশন** |
| A ⇒ β | এক ধাপ **ডেরিভেশন** |
| A ⇒\* w | শূন্য বা তার বেশি ধাপ, w সব টার্মিনাল |
| ε | খালি স্ট্রিং, \|ε\| = 0 |

- 💡 **কৌশল:** চারটি অক্ষরের ক্রম — **V**ariable, **Σ**ymbol, **P**roduction, **S**tart। "V–Σ–P–S"।
- ⚠️ **ফাঁদ:** শর্তটি **বাম** পাশে, ডান পাশে নয়। `A → aSb` কনটেক্সট-ফ্রি; `AB → aSb` নয়, ডান পাশ যেমনই হোক।
- 📌 **ব্যবহারে:** প্রতিটি প্রোগ্রামিং ভাষার সঙ্গে একটি CFG থাকে **BNF**-তে, যা তার সিনট্যাক্সের **সংজ্ঞাই**; পার্সার জেনারেটর সেই গ্রামার থেকেই যাচাইয়ের টেবিল বানায়।
- 📎 **ছবিটা এক বাক্যে:** একটি প্রোডাকশন হলো একটি বাক্স — বামে ভেরিয়েবল, ডানে তার বিকল্প। প্রতিটি নোড থেকে বেরোয়ে আসা তীর একটি প্রোডাকশনই লেখে। কনটেক্সট-ফ্রি মানে সেই বাম বাক্সে কখনো একের বেশি অক্ষর থাকে না।

## ৩. ডেরিভেশন, পার্স ট্রি ও অ্যাম্বিগুয়াস

**S** থেকে শুরু করে একবারে একটি ভেরিয়েবল বদলাতে থেকে যাও, যতক্ষণ না কেবল টার্মিনাল থাকে। **লেফটমোস্ট** ডেরিভেশনে সবসময় বাঁকে জেতা ভেরিয়েবলটি বদলায়, **রাইটমোস্ট**-এ ডানে জেতাটি। দুটো একই স্ট্রিংয়ে পৌঁছায় — শুধু **কাজের ক্রম** আলাদা, তাই পার্সার বানানো হয় লেফটমোস্ট।

```
LEFTMOST          RIGHTMOST
S                  S
S => aSb           S => aSb
S => aaSbb         S => aSbb
S => aaaSbbb       S => aaSbb
S => aaabbb        S => aaabbb
```

             S                     শুরু প্রতীক, মূল নোড
            /|\
           a S b                  S -> aSb : তিন শিশু a, S, b
            /|\
           a S b                  নতুন S আবার একইভাবে বাড়ে
            /|\
           a S b                  আরেকবার
              |
              ε                   S -> ε : কোনো শিশা নেই এমন পাতা

        পাতা বাম থেকে ডানে: a a a b b b   =   ডেরিভেড স্ট্রিং

**পার্স ট্রি = আঁকা ডেরিভেশন।** প্রতিটি ভেরিয়েবল একটি নোড; প্রয়োগ প্রতিটি প্রোডাকশন একটি নোড, যার শিশুগুলো ওই নিয়মের ডান পাশের প্রতীকগুলো বাম থেকে ডানে। তাই **পাতা = স্ট্রিং** — বাম থেকে ডানে পড়ে। আর n টি টার্মিনালের ট্রিতে ঠিক **n − 1**টি অভ্যন্তরীণ নোড থাকে।

**অ্যাম্বিগুয়াস (Ambiguity): এক স্ট্রিং, দুটি ট্রি।** কোনো গ্রামার **অ্যাম্বিগুয়াস** (ambiguous) যখন তার ভাষার **কোনো** একটি স্ট্রিংয়ের **দুই বা তার বেশি ভিন্ন লেফটমোস্ট ডেরিভেশন** থাকে — সমতুল্যভাবে দুটি পার্স ট্রি। একটিও স্ট্রিং না থাকলে তা **অস্পষ্টতামুক্ত** (unambiguous)। একটি খারাপ স্ট্রিংই যথেষ্ট।

**সমাধানকৃত উদাহরণ — প্রচলিত অ্যাম্বিগুয়াস গ্রামার**

```
E -> E + E | E * E | id      (id+id*id-এর দুটি ট্রি আছে)

tree 1: (id+id)*id          tree 2: id+(id*id)
        *                          +
       / \                        / \
      +   id                    id   *
     / \                            / \
   id   id                        id  id
```

চারটি টার্মিনাল একই ক্রমে, কিন্তু গ্রুপিং দুটি — তাই **id+id\*id** অ্যাম্বিগুয়াস। ঠিক করতে প্রতি অপারেটরের জন্য একটি বাড়তি স্তর দরকার: **E → E + T | T**, **T → T \* F | F**, **F → id**।

- 💡 **কৌশল:** "অ্যাম্বিগুয়াস = **অ্যাল্টারনেটিভ** ট্রি"। এক স্ট্রিং **দুইভাবে** বানানো গেলে পার্সার বুঝতে পারে না তা মানে কী।
- ⚠️ **ফাঁদ:** অ্যাম্বিগুয়াসের সাথে ε-প্রোডাকশন, ভেরিয়েবলের সংখ্যা বা অসীম ভাষার কোনো সম্পর্ক নেই। আর এটি ননডিটারমিনিজমও নয়: PDA প্রতিটি CFL-তেই ননডিটারমিনিস্টিক।

## ৪. কাজের গ্রামার: সুষম বন্ধনী

Σ = { (, ) }-এর উপর **সুষম বন্ধনী**র ভাষা হলো {(ⁿ )ⁿ | n ≥ 0}: প্রতিটি ( পরে একটি ) দিয়ে বন্ধ, আর নেস্টিং ঠিক থাকে। এটি কনটেক্সট-ফ্রি, আর অটোমাটা নোটের PDA ঠিক ( খোলার সময় push, ) এলে pop করে এটিই গ্রহণ করে।

```
V = {S},  Sigma = { ( , ) },  S = S
P = { S -> SS ,      দুটি গ্রুপ পাশাপাশি
      S -> (S) ,      এক গ্রুপের ভিতরে আরেকটি
      S -> e }        খালি গ্রুপ

leftmost derivation of "(())()":
S => SS => (S)S => ((S))S => (())S => (())(S) => (())()
```

             S                    S -> SS : দুটি শিশু
            / \
           S   S                  প্রতিটি S -> (S) : ( , S , )
          /|\  /|\
         ( S )( S )              প্রতিটি S -> ε
          |     |
          ε     ε                পাতা: ( ( ) ) ( )   =   (())()

| প্রোডাকশন | এটি কোন ভাবনা ধরে | যা শেষ করতে পারে |
|---|---|---|
| S → ε | বেস কেস: খালি গ্রুপ | ε, আর কিছু নয় |
| S → (S) | **একটি** গ্রুপকে এক জোড়ায় মোড়ানো | ( ), ( () ), ( (()) ) … |
| S → SS | দুটি সুষম গ্রুপ জোড়া লাগানো | ()(), (())(), (()()) … |

- 💡 **কৌশল:** **SS = পাশাপাশি, (S) = ভিতরে, ε = কিছু নয়।** একই তিন-নিয়মের আকারেই সুষম **{}**, সুষম **[ ]**, আর তৃতীয় জোড়া যোগ করলে সুষম **{ } [ ]** তৈরি হয়।
- ⚠️ **ফাঁদ:** লিখবে **S → SS**, কখনো **S → SS | SS** নয়। বিকল্পগুলোর ক্রম অর্থহীন — CFG-র প্রোডাকশন একটি **সেট**, প্রোগ্রাম নয়: যেকোনো নিয়ম যেকোনো সময়ে চলতে পারে। {aⁿbⁿcⁿ} এভাবে বানানো যায় না — এক স্ট্যাক দিয়ে দ্বিতীয় গণনা চলতেই একটি বন্ধনী বন্ধ করা যায় না।
- 📌 **ব্যবহারে:** এডিটরের ব্র্যাকেট ম্যাচার একটি PDA — খোলার প্রতীকে push, মিলের প্রতীকে pop, খালি স্ট্যাক থেকে pop নয়। আর যেকোনো k ধরনের জোড়া বন্ধনীর সুষম স্ট্রিং (Dyck ভাষা) ও সুষম XML/HTML ট্যাগ-নেস্টিংও কনটেক্সট-ফ্রি।

## ৫. CFG সরলীকরণ: CNF ও GNF

1. **অব্যবহৃত প্রতীক সরাও:** আগে **নন-জেনারেটিং** ভেরিয়েবল, তারপর **অনপ্রাপ্য** ভেরিয়েবল।
2. **ε-প্রোডাকশন A → ε সরাও:** সব **নালেবল** ভেরিয়েবল খুঁজে তার ε-নিয়ম বাদ দাও।
3. **ইউনিট প্রোডাকশন A → B সরাও** সেই জায়গায় B-র নিজের নিয়ম বসিয়ে (বারবার — চেইন ঘটে)।
4. **চমস্কি নরমাল ফর্মে** রূপান্তর — CYK ও পার্সার জেনারেটর এটাই চায়।
5. **গ্রেবাখ নরমাল ফর্মে** রূপান্তর, যেখানে প্রতিটি নিয়ম টার্মিনাল দিয়ে শুরু হয়।

| নরমাল ফর্ম | প্রতিটি প্রোডাকশন | যা দেয় |
|---|---|---|
| **CNF** | **A → BC** বা **A → a**; S → ε কেবল ε ∈ L হলে | CYK, yacc/bison |
| **GNF** | **A → aα** | এক প্রতীকেই পূর্বানুমান |
| রাইট-লিনিয়ার | A → aB | একটি **রেগুলার** টাইপ ৩ গ্রামার |

**সমাধানকৃত রূপান্তর — S → aSb | ε থেকে CNF**

```
original   S -> a S b | e
step 1     বাঁ টার্মিনালটি বাঁধো, তারপর ডানেরটি:  S -> A S B
step 2     ডানে এখনো ৩ প্রতীক, তাই পুচুরটি ভাঙো:
           S -> A X   ,  X -> S B   ,  A -> a   ,  B -> b
result     S -> A X | e ,  X -> S B ,  A -> a ,  B -> b
```

        S -> aSb | e        (মূল)
               |
               v
        S -> ASB | e         ভুল: তীরের ডানে তিন প্রতীক
               |
               v
        S -> AX | e , X -> SB , A -> a , B -> b    ঠিক: দুই, অথবা এক

**S → ε কেন টেকে যায়:** CNF-তে এটি তখনই বৈধ যখন ε ∈ L **এবং** S কোনো ডান পাশে নেই। এখানে S **আছে**, **X → SB**-এর ভিতরে। তাই নিখুঁত রূপে একটি নতুন শুরু প্রতীক **S₀ → S** যোগ করতে হয়, বাকি চারটি নিয়ম একই থাকে।

- ⚠️ **ফাঁদ:** `S → ASB` CNF **নয়** — ঠিক **২**টি ভেরিয়েবল বা **১**টি টার্মিনাল, তিন প্রতীক কখনো নয়। আর `A → aα` হলো **গ্রেবাখ**, CNF নয়।
- 💡 **কৌশল:** **CNF = দুই বা এক, GNF = টার্মিনাল দিয়ে শুরু।** ডান পাশের প্রতীক গুনো: ২ বা ১ ⇒ CNF; "a তারপর ভেরিয়েবল" ⇒ GNF; "aB" ⇒ রেগুলার।

## ৬. CFL-এর পাম্পিং লেমা, CYK ও স্টেপ গণনা

L কনটেক্সট-ফ্রি হলে এমন দৈর্ঘ্য **p** আছে যাতে |s| ≥ p এমন প্রতিটি s ∈ L-কে **s = uvxyz** করে ভাঙা যায়, যেখানে **|vxy| ≤ p**, **|vy| ≥ 1** এবং **প্রতিটি i ≥ 0-এর জন্য uvⁱxyⁱz ∈ L**। মানে, ছোট একটা জানালার ভিতরে এমন একটি ভারসাম্যপূর্ণ অংশ আছে যা যতবার খুশি পুনরাবৃত্তি করা যায়। রেগুলার সংস্করণের মতো এটিও **খণ্ডনের** হাতিয়ার।

| শর্ত | কী বলে |
|---|---|
| \|vxy\| ≤ p | পাম্পযোগ্য জানালাটি **ছোট** |
| \|vy\| ≥ 1 | v ও y একসঙ্গে **খালি নয়** |
| uvⁱxyⁱz ∈ L, ∀i ≥ 0 | v ও y **একসঙ্গে** পুনরাবৃত্তি হয় |

- ⚠️ **ফাঁদ:** রেগুলার লেমা পাম্প করে **xyⁿz**; CFL লেমা পাম্প করে **uvⁱxyⁱz** — **দুটি** সূচক, এবং সেগুলো **সমান**। u(vxy)ⁿz লেখা ভুল। আর লেমা মেনে চললেই কোনো ভাষা কনটেক্সট-ফ্রি **প্রমাণ** হয় না।

**সমাধানকৃত খণ্ডন — {aⁿ bⁿ cⁿ | n ≥ 0} কনটেক্সট-ফ্রি নয়।** পাম্পিং দৈর্ঘ্য p নাও আর s = **aᵖbᵖcᵖ** নাও। |vxy| ≤ p ও |vy| ≥ 1 শর্তে যেকোনো ভাঙায় y পুরোপুরি **a-ব্লকের** ভিতরে (y = aᵏ, k ≥ 1) অথবা পুরোপুরি **b-ব্লকের** ভিতরে (y = bᵏ)। একা y পাম্প করলে মিল ভেঙে যায়, আর v ও y **একসঙ্গে** পাম্প করলেও তা ফেরত আসে না, কারণ তারা ভিন্ন ব্লকে। শর্ত ভাঙে ⇒ **L কনটেক্সট-ফ্রি নয়**। এক বাক্যে: এখানে তিনটি একসঙ্গে গণনা দরকার, আর এক স্ট্যাক একটিই ধরে।

```
|  u  |  v  |  x  |  y  |   z   |     s = u v x y z
               ^^^^              পাম্পযোগ্য জানালা, |vxy| <= p
            ^         ^           v ও y একসঙ্গে, |vy| >= 1, সমান সূচকে পাম্প
```

**CYK ও স্টেপ গণনা।** **CYK** একটি **নির্দিষ্ট CNF** গ্রামারের জন্য **O(n³)** সময়ে সদস্যপতা নির্ণয় করে (সাধারণত O(n³·|G|)): O(n²) উপস্ট্রিংয়ের উপর নিচ থেকে ওপরের টেবিল, প্রতিটির জন্য O(n) স্প্লিট পয়েন্ট। আর CNF-তে দৈর্ঘ্য **n ≥ 1** স্ট্রিং ডেরিভ করতে ঠিক **2n − 1** ধাপ লাগে — একটি ভেরিয়েবলকে n টি করতে **n − 1** ধাপ A → BC, তারপর প্রতিটির জন্য একটি করে **n** ধাপ A → a।

- 💡 **কৌশল:** **"n − 1 ভাগ, তারপর n টার্মিনাল = মোট 2n − 1"** — আর **CYK ঘনঘন (cubic)**: উপস্ট্রিং, স্প্লিট পয়েন্ট ও নিয়মের তিনটি লুপ।
- 📌 **লেমা যা প্রমাণ করে না:** রেগুলার লেমার মতো এখানেও কোনো উপায়ে কনটেক্সট-ফ্রি প্রমাণ করা যায় না — শুধু খণ্ডন করা যায়।

## ৭. CFG ↔ PDA এবং CFG-র প্রয়োগ

**সমতার উপপাদ্য:** **কনটেক্সট-ফ্রি ⇔ কোনো PDA তা চিনে।** "যদি" দিকটা সহজ — গ্রামারটিকে একটি লেফটমোস্ট ডেরিভেশন হিসেবে পড়ো। "কেবল যদি" দিকটাই চমকপ্রদ: PDA-র **অবস্থাগুলোই ভেরিয়েবল হয়ে যায়**, তাই মেশিনটি নিজেই নিজের গ্রামার লিখে ফেলে।

1. **শুরু প্রতীক S** স্ট্যাকে, বটম মার্কার Z₀-এর উপরে push করো।
2. স্ট্যাকের **উপরে ভেরিয়েবল** A থাকলে এবং P-তে A → α থাকলে, A বের করে α **বিপরীত** ক্রমে push করো, যাতে α-র বামতম প্রতীক আগে বেরোয়।
3. স্ট্যাকের **উপরে টার্মিনাল** a থাকলে পরের ইনপুটের সাথে মেলাও: সমান হলে pop ও ইনপুট এগোও, নয়তো প্রত্যাখ্যান।
4. ইনপুট শেষ **এবং** স্ট্যাকে শুধু Z₀ আছে — তবেই গ্রহণ।
5. **উল্টো দিক:** প্রতিটি অবস্থা-জোড়া p, q ও স্ট্যাক প্রতীক X-এর জন্য একটি ভেরিয়েবল **[pXq]**, প্রতিটি ট্রানজিশনে **[pXq] → a**, আর প্রতিটি গ্রহণকারী অবস্থা q-এর জন্য **S₀ → [q₀ Z₀ q]**।

| প্রয়োগ | CFG কীভাবে ব্যবহৃত হয় |
|---|---|
| **প্রোগ্রামিং ভাষা** | C, Java, Pascal-এর সিনট্যাক্স BNF/EBNF-তে সংজ্ঞায়িত — গ্রামারটিই **সংজ্ঞা** |
| **কম্পাইলার** | **পার্সার জেনারেটর** (yacc, bison, ANTLR) গ্রামার পড়ে টেবিল বানায় |
| **মার্কআপ ভাষা** | XML / HTML-এর নেস্টিং একটি CFG; ভ্যালিডেটর হলো ট্যাগ-স্ট্রিমের উপর PDA |
| **প্রাকৃতিক ভাষা** | বাক্যের কাঠামো একটি গ্রামার; প্রতিটি NLP পাইপলাইনের শুরুতে পার্সিং |
| **এক্সপ্রেশন** | precedence climbing = প্রতি অপারেটরের জন্য একটি বাড়তি গ্রামার স্তর |
| **কোয়েরি ভাষা** | SQL-এর `SELECT … WHERE …` একটি রিকার্সিভ-ডিসসেন্ট গ্রামার |

```
        P : S -> aSb | e                গ্রামারটিই মেশিনটি চালায়
              |
              v
        stack: Z0 -> S Z0 -> a S b Z0   উপরের ভেরিয়েবল বেরে ডান পাশ
              |                          বিপরীত ক্রমে ঢোকাও
              v
        input "aaabbb" শেষ, স্ট্যাক খালি  =>  গ্রহণ
```

- 💡 **কৌশল:** **শুরু প্রতীক** push, **স্ট্যাকের উপরেরটি** বদলাও, **খালি স্ট্যাকে** গ্রহণ। উল্টো রূপান্তরের ভেরিয়েবলগুলো **[pXq]** — "p থেকে, X-এর উপর, q-তে"।
- ⚠️ **ফাঁদ:** CFG → PDA-তে ডান পাশ **বিপরীত** ক্রমে push হয়: স্ট্যাক last-in-first-out। α লেখার ক্রমে ঢোকালে PDA স্ট্রিংটি **উল্টো** দিকে বানাবে।
- 📌 **ব্যবহারে:** ব্র্যাকেট মিলানো, `if`/`for` নেস্টিং যাচাই আর JSON ভ্যালিডেশন — সবই পাতা ৪-এর একই PDA, শুধু ইনপুট বদলে।

## পরীক্ষার আগের রাতের পাতা

CFL = CFG বানায়, PDA পড়ে · CFL হলো চমস্কি **টাইপ ২** · CFG = **(V, Σ, P, S)** · CF ⇔ প্রতি বাম পাশে একটি ভেরিয়েবল · V ∩ Σ = ∅; S ∈ V; P ⊆ V × (V ∪ Σ)\* · A ⇒ এক ধাপ · A ⇒\* w · ε = খালি · S → aSb | ε ⇒ **{aⁿ bⁿ | n ≥ 0}** · S → aSa | bSb | a | b | ε ⇒ প্যালিন্ড্রোম · S → SS | (S) | ε ⇒ সুষম বন্ধনী · লেফটমোস্ট = আগে বাঁকের ভেরিয়েবল · পার্স ট্রির পাতা = স্ট্রিং · অ্যাম্বিগুয়াস ⇔ ≥ ২ লেফটমোস্ট ডেরিভেশন · E → E+E | E\*E | id অ্যাম্বিগুয়াস · বদ্ধ: ∪, কনক্যাটেনেশন, ক্লিন স্টার · বদ্ধ নয়: ∩ ও কমপ্লিমেন্ট · তবে CFL ∩ **রেগুলার** **CFL** · {aⁿbⁿcᵐ} ∩ {aᵐbⁿcⁿ} = {aⁿbⁿcⁿ} = CF নয় · CNF: A → BC বা A → a (+ S → ε) · GNF: A → aα · A → aB = রেগুলার · CFL পাম্পিং: s = **uvxyz**, |vxy| ≤ p, |vy| ≥ 1 · uvⁱxyⁱz ∈ L ∀ i ≥ 0 — সমান সূচক · নির্দিষ্ট CNF গ্রামারে CYK: **O(n³)** · n ≥ 1 দৈর্ঘ্যের CNF ডেরিভেশন: **2n − 1** · CFG ⇔ PDA; PDA → CFG-তে **[pXq]**।

**MCQ-র জন্য শীর্ষ ১২ এক-লাইনের উত্তর।** ① CFG = ৪-টাপল, PDA = ৭-টাপল ② বামে একটি ভেরিয়েবল = কনটেক্সট-ফ্রি ③ S → aSb | ε দেয় **n ≥ 0**, ε-সহ ④ টাইপ ৩ গ্রামার দেয় **রেগুলার** ভাষা ⑤ CFL বদ্ধ ∪ · \* — **নয়** ∩ ⑥ CNF-তে কেবল **A → BC বা A → a** ⑦ A → aα হলো **গ্রেবাখ**, A → aB রাইট-লিনিয়ার ⑧ অ্যাম্বিগুয়াস = এক স্ট্রিং, দুটি ডেরিভেশন ⑨ CFL লেমা **পাঁচ** খণ্ডে ভাঙে: uvxyz ⑩ CYK ইনপুট দৈর্ঘ্যের **ঘনঘন** ⑪ CNF-এর স্টেপ গণনা **2n − 1** ⑫ CFL ∩ রেগুলার = CFL।

**প্রশ্ন কোন আকার চাইছে?** **ভেরিয়েবল, প্রোডাকশন, শুরু প্রতীক, ৪-টাপল** উল্লেখ ⇒ CFG · **বাম পাশে একটি ভেরিয়েবল** ⇒ কনটেক্সট-ফ্রি · তীরের ডানে **দুটি ভেরিয়েবল** ⇒ CNF · **টার্মিনাল তারপর ভেরিয়েবল** ⇒ GNF · **টার্মিনাল তারপর একটি ভেরিয়েবল** ⇒ রেগুলার / টাইপ ৩ · **স্ট্যাক, ৭-টাপল, খালি স্ট্যাক** ⇒ PDA।

**শীর্ষ ফাঁদ।** ডানে তিন প্রতীক মানে **CNF নয়** · "ইন্টারসেকশনে বদ্ধ নয়"-এর সাথে রেগুলার-ভাষার যোগসূত্র দরকার · CFL পাম্পিং লেমায় v ও y একই সূচকে পাম্প হয় · লেমা মেনে চললেই কনটেক্সট-ফ্রি প্রমাণ হয় না · PDA প্রোডাকশনের ডান পাশ **বিপরীত** ক্রমে ঢোকায় · n ≥ 0 ভাষায় ε থাকে।

**সব কৌশল একসাথে।** "V–Σ–P–S, চারটি অংশ" · "বাম পাশে একটি ভেরিয়েবলই পুরো সংজ্ঞা" · "SS = পাশাপাশি, (S) = ভিতরে, ε = কিছু নয়" · "পাতা বাম থেকে ডানে = স্ট্রিং" · "CNF = দুই বা এক, GNF = টার্মিনাল দিয়ে শুরু" · "পাঁচ খণ্ড, দুটি সূচক" · "n − 1 ভাগ + n টার্মিনাল = 2n − 1"।

## লিখিত প্রশ্ন (১০ নম্বর)

{a, b}-এর উপর সব প্যালিন্ড্রোমের ভাষার জন্য একটি CFG লেখ; `abba` ও `aba`-র লেফটমোস্ট ডেরিভেশন দেখাও; বলো কেন এটি কনটেক্সট-ফ্রি কিন্তু রেগুলার নয়।

**মডেল উত্তর:**

1. **গ্রামার (৩)** — G = ({S}, {a,b}, P, S), P = { **S → aSa | bSb | a | b | ε** }: দুই প্রান্ত জড়াও, মাঝটা শেষ করো।
2. **ডেরিভেশন (৩)** — abba: S ⇒ aSa ⇒ abSba ⇒ **abba** · aba: S ⇒ aSa ⇒ **aba**।
3. **কেন কনটেক্সট-ফ্রি (২)** — বাম পাশে একটি ভেরিয়েবল; সমতুল্যভাবে একটি NPDA প্রথম অর্ধেক push করে, মাঝ **অনুমান** করে, দ্বিতীয় অর্ধেক pop করে।
4. **কেন রেগুলার নয় (২)** — পাম্পিং দৈর্ঘ্য p নিয়ে w = aᵖ b aᵖ নিলে যেকোনো ভাঙায় y = aᵏ প্রথম a-ব্লকের ভেতরে পড়ে, তাই xy²z প্যালিন্ড্রোম নয় — লেমা ভাঙে।

**মুখস্থের ছক** — প্যালিন্ড্রোম **S → aSa | bSb | a | b | ε** · বন্ধনী **S → SS | (S) | ε** · "দুই প্রান্ত জড়াও, মাঝ শেষ করো"।

**এক লাইনে পুরো চর্চা:** ভাষা → গ্রামার → ডেরিভেশন → পার্স ট্রি → (অস্পষ্টতা?) → CNF → CYK → PDA। প্রতিটি ধাপের প্রশ্ন আলাদা, কিন্তু উত্তর সবসময় একই ধরনের: "কোনো একটি ভেরিয়েবল প্রতি প্রোডাকশনের বাম পাশে"।

**পরীক্ষার আগে যাচাই ✓** (V, Σ, P, S) মেমরি থেকে লিখতে পারি · aⁿbⁿ, প্যালিন্ড্রোম ও বন্ধনীর গ্রামার দিতে পারি · ছোট গ্রামারকে CNF-তে রূপান্তর করতে পারি · জানি পাম্পিং লেমা কেবল কনটেক্সট-ফ্রি প্রমাণ করতে পারে না, খণ্ডনই করতে পারে।
