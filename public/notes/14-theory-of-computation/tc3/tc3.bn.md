## ১. টিউরিং মেশিন কী

**সংজ্ঞা।** **টিউরিং মেশিন (Turing machine, TM)** হলো সবচেয়ে শক্তিশালী গণনা মডেল: একটি **সসীম কন্ট্রোল ইউনিট** চালায় পড়া-লেখা হেডকে কোষে বিভক্ত **সীমাহীন টেপের** উপর দিয়ে। টেপের শেষ নেই, তাই TM যেকোনো অ্যালগরিদম অনুকরণ করতে পারে — আর ঠিক **রিকার্সিভলি এনিউমারেবল** ভাষাই চিনতে পারে।

**৭-টাপল M = (Q, Σ, Γ, δ, q₀, B, F)**

| অংশ | কী | এই মেশিনে |
|---|---|---|
| **Q** | **অবস্থা**র সসীম সেট | Q = {q₀, q₁, q₂} |
| **Σ** | **ইনপুট** অ্যালফাবেট; B ∉ Σ | Σ = {0, 1} |
| **Γ** | **টেপ** অ্যালফাবেট; Σ ⊆ Γ, B ∈ Γ | Γ = {0, 1, B} |
| **δ** | **Q × Γ → Q × Γ × {L, R, S}** | δ(q₀, 0) = (q₁, 1, R) |
| **q₀** | **শুরু অবস্থা**, q₀ ∈ Q | q₀ |
| **B** | **ফাঁকা প্রতীক**, B ∈ Γ \ Σ | B |
| **F** | **গ্রহণকারী** অবস্থার সেট, F ⊆ Q | F = {q₂} |

*স্বাক্ষরের ছবি: টেপ, হেড, সসীম কন্ট্রোল।*

```
   [B] [0] [1] [0] [1] [B] [B] [ ... ]     টেপ উভয় দিকে অসীম
             ^                              হেড, একটি কোষ স্ক্যান করছে
          |  q₂  |                          অবস্থা = কন্ট্রোল ইউনিটের সেটিং
    ---------------------------------------------  কন্ট্রোল ইউনিট: পড়ে · লেখে · চলে
```

**ট্রানজিশন ফরম্যাট।** **δ(অবস্থা, পড়া প্রতীক) = (নতুন অবস্থা, লেখা প্রতীক, দিক)**। তাই **δ(q₀, 0) = (q₁, 1, R)** পড়ে: *q₀ অবস্থায় 0 পড়ে → 1 লেখ, ডানে যাও, q₁-এ ঢোকো*। **এক ট্রানজিশন = এক ধাপ** — পুরো মেশিন এই ছক আর ৭-টাপল, আর কিছু নয়।

- ⚠️ **পরীক্ষার ফাঁদ:** **সাধারণ** রূপে হেড **তিন** দিকে চলতে পারে: {**L**, **R**, **S**}, যেখানে **S** = না গিয়ে লিখে থেকে যাওয়া। কিছু বইয়ে শুধু {L, R} আছে; সেই দ্বিমুখী মেশিনও সর্বজনীন, তবে {L, R}-কে সাধারণ সংজ্ঞা বললে নম্বর কমে।
- 💡 **মনে রাখার কৌশল:** "Q-অবস্থা, Σ-ইনপুট, Γ-টেপ, δ-ধাপ, q₀-শুরু, B-ফাঁকা, F-চূড়ান্ত" — কেবল **টেপ**-ই সীমাহীন, তাই মেমরি আসে অবস্থান থেকে।

## ২. কনফিগারেশন: তাৎক্ষণিক বর্ণনা

**সংজ্ঞা।** **তাৎক্ষণিক বর্ণনা** (instantaneous description, ID) লেখে মেশিনের এক মুহূর্তের **সম্পূর্ণ** অবস্থা, আকারে **(u, q, v)**: **u** = হেডের **বামে** টেপের বিষয়বস্তু, **q** = বর্তমান অবস্থা, **v** = হেড থেকে **ডানে** থাকা বিষয়বস্তু, আর হেড স্ক্যান করছে **v-এর প্রথম প্রতীক**।

| সংকেত | যা পড়ায় |
|---|---|
| (u, q, v) | টেপ … u **q** v …, হেড v-এর প্রথম প্রতীকে |
| (u, q, v) ⊢ (u′, q′, v′) | মেশিন **একটি** ধাপ এগোয় |
| (u, q, v) ⊢\* (u′, q′, v′) | **শূন্য বা তার বেশি** ধাপ — পৌঁছানো যায় |
| q₀w | w ইনপুটে চালানোর **শুরু কনফিগারেশন** |

✍ **সমাধানকৃত সরণ।** `… 0 1 0 [1] 1 …` টেপে, δ(q₂, 1) = (q₃, 1, R) হিসেবে:

```
(010, q₂, 11)  ⊢  (0101, q₃, 1)      যদি  δ(q₂, 1) = (q₃, 1, R)

টেপ ... 0 1 0 [1] 1 ...
        u = 010  ^q₂   v = 11
```

হেড ছিল ডান ব্লকের প্রথম **1**-এর উপর; δ বলছে **1** লেখ, **R** দিকে যাও, **q₃**-এ যাও — তাই লেখা **1**টি **u**-তে ঢুকে যায়, অবস্থা বদলায়, আর পরের প্রতীকই হয় **v**-এর হেড।

*ID (010, q₂, 11)-এর ছবি: হেড v-এর প্রথম প্রতীকে — লেখায় `… 0 1 0 q₂ 1 1 …`।*

- ⚠️ **পরীক্ষার ফাঁদ:** হেডের নিচের প্রতীকটি **v**-এর, কখনো **u**-র নয়। (01, q₂, 011) লিখা **ভুল**, যদিও একই টেপ বর্ণিত হচ্ছে। আর **⊢** মানে এক ধাপ, **⊢\*** মানে অনেক ধাপ — দুটো বদলালে ট্রেসের অর্থই বদলে যায়।
- 💡 **মনে রাখার কৌশল:** **বাম · অবস্থা · ডান** — আর হেড "পড়ার" অংশের। (u, q, v) লিখতে লিখতে জোরে বলে ফেলো, তাহলে হেডের অবস্থান কখনো সরে যায় না।

**ID-র গুরুত্ব।** TM-এর আলাদা ইনপুট টেপ বা মেমরি নেই, তাই টেপই **পুরো** কনফিগারেশন — একই ID-এ দুই চলা সদস্য হলে চিরকাল একই আচরণ করে। ঠিক এভারই **মেশিন লুপ করে প্রমাণ** হয়: পুনরাবৃত্ত ID পৌঁছে গেলেই বাকিটা নিয়মিত।

> ⊢\* মানে পৌঁছানো — "যেতে পারে", কখনো "এক ধাপে যায়" নয়।

## ৩. টিউরিং মেশিন দিয়ে গণনা: aⁿbⁿ মেশিন

✍ **সমাধানকৃত মেশিন: L = {aⁿ bⁿ \| n ≥ 0}**

```
Q = {q0, q1, q2, q3, q4}    Sigma = {a, b}    Gamma = {a, b, X, Y, B}
শুরু q0 (একটি a চিহ্নিত করে, ডানে খোঁজে)   গ্রহণ F = {q4}
```

| δ(অবস্থা, প্রতীক) | এই সরণটি কী করে |
|---|---|
| δ(q₀, a) = (q₁, X, R) | **প্রথম** a-কে **X** চিহ্নিত, ডানে |
| δ(q₁, a) = (q₁, a, R) | বাকি a-গুলো এড়ানো |
| δ(q₁, Y) = (q₁, Y, R) | চিহ্নিত b-গুলো এড়ানো |
| δ(q₁, b) = (q₂, Y, L) | ওই b-কে **Y** চিহ্নিত (এক জোড়া), বামে |
| δ(q₂, Y) = (q₂, Y, L) | ফেরার পথে Y এড়ানো |
| δ(q₂, a) = (q₂, a, L) | ফেরার পথে a এড়ানো |
| δ(q₂, X) = (q₀, X, R) | প্রথম X মিলল ⇒ জোড়া শেষ, আবার শুরু |
| δ(q₀, Y) = (q₃, Y, R) | আর a নেই ⇒ সব মিলেছে, b যাচাই |
| δ(q₃, Y) = (q₃, Y, R) | Y-গুলো এড়ানো |
| δ(q₃, B) = (q₄, B, R) | ফাঁকা, কোনো b বাকি নেই ⇒ **গ্রহণ** |

**"aabb"-এর উপর চালনা**

```
শুরু   B a a b b B
ধাপ ১  B X a b b B   প্রথম a চিহ্নিত
ধাপ ২  B X a Y b B   একটি b-এর সাথে মেলানো
ধাপ ৩  B X a Y b B   X পৌঁছে, আবার শুরু
ধাপ ৪  B X X Y b B   দ্বিতীয় a চিহ্নিত
ধাপ ৫  B X X Y Y B   আরেকটি b-এর সাথে মেলানো
ধাপ ৬  B X X Y Y B   সব a মিলেছে
গ্রহণ  B X X Y Y B   q4-এ থামে
```

প্রতি round trip-এ এটি **একটি a-কে একটি b-এর সাথে** মেলায়, তারপর ফিরে আসে। **ab** বা **ba**-তে চালালে কখনো গ্রহণ করে না।

*"aabb" জোড়া ধরে চিহ্নিত, তারপর গ্রহণ — শুরু · q₀ → এক জোড়া → ফিরে আসা → গ্রহণ · q₄।*

- ⚠️ **পরীক্ষার ফাঁদ:** এই ছকে কোনো **বর্জন-সরণ নেই** — নেই δ(q₀, B), নেই δ(q₃, a)। **abab**-এর মতো সদস্য নয় এমন স্ট্রিং দিলে সেটি পরিষ্কারভাবে বর্জন করে না, বরং **অসংজ্ঞায়িত** সরণে পড়ে যায়। সম্পূর্ণ মেশিনে একটি বর্জন অবস্থা **q_rej** যোগ করে δ(q₃, a) → q_rej ও δ(q₁, B) → q_rej দিতে হয়।
- 💡 **মনে রাখার কৌশল:** **"চিহ্নিত, খোঁজ, মেলাও, ফিরে এসো"** — q₀ চিহ্নিত করে, q₁ b খোঁজে, q₂ ফেরে, q₃ যাচাই করে, q₄ গ্রহণ করে। X a চিহ্নিত করে, Y b চিহ্নিত করে।

## ৪. টিউরিং মেশিনের ভেরিয়েন্ট ও চার্চ-টিউরিং থিসিস

**সমতা (হাই-ইল্ড).** নিচের প্রতিটি ভেরিয়েন্ট এক-টেপ নির্ধারিত TM-এর সঙ্গে **ঠিক একই শ্রেণির ভাষা** চিনে, সবচেয়ে খারাপ ক্ষেত্রে **বহুপদী** ধীরতা — মাল্টি-টেপ মেশিনের খরচ সর্বোচ্চ **বর্গীয়**। **অতিরিক্ত টেপ কেনা হয় গতি ও সুবিধার জন্য, ক্ষমতার জন্য নয়।**

| ভেরিয়েন্ট | কী যোগ করে |
|---|---|
| **মাল্টি-টেপ টিএম** | একাধিক টেপ — ইনপুট, কাজ, আউটপুট |
| **ননডিটারমিনিস্টিক টিএম** | প্রতি অবস্থায় একাধিক সরণ; **কোনো একটি** শাখা গ্রহণ করলেই গ্রহণ |
| **মাল্টি-হেড টিএম** | **এক** টেপে একাধিক হেড |
| **অফলাইন টিএম** | শুধু-পড়া ইনপুট টেপ + কাজের টেপ + আউটপুট |
| **এলবিএ (LBA)** | প্রান্তচিহ্নে সীমাবদ্ধ ননডিটারমিনিস্টিক টিএম |

*মাল্টি-টেপ মেশিন: তিন হেড, তিন টেপ, এক ভাষা-শ্রেণি।*

```
টেপ১ input:  [a][b][B][B][B][B]
টেপ২ কাজ:    [X][Y][Y][B][B][B]
টেপ৩ out:    [B][1][0][B][B][B]        ৩ টেপ ≡ ১ টেপ · একই ভাষা
```

**লিনিয়ার বাউন্ডেড অটোমাটন (LBA)।** একটি ননডিটারমিনিস্টিক টিএম নিয়ে নাও, তার টেপের দুই প্রান্তে **⊢** ও **⊣** বসাও, যাতে টেপে শুধু ইনপুট আর দুটি চিহ্নই থাকে (**\|w\| + 2** কোষ)। হেড সেই সীমার ভিতরে দুদিকেই চলতে পারে, কিন্তু **বাইরে যেতে পারে না**। এটি ঠিক **কনটেক্সট-সেনসিটিভ (টাইপ-১)** ভাষাগুলো চেনে — শ্রেণিবিন্যাসের সিএস স্তর এখান থেকেই আসে।

**চার্চ-টিউরিং থিসিস।** **টিউরিং-গণনাযোগ্য ⇔ অ্যালগরিদমিক্যালি গণনাযোগ্য**: যেকোনো অ্যালগরিদমে গণনাযোগ্য যা কিছু তা একটি টিউরিং মেশিনেও গণনা করা যায়, আর উল্টো। এই থিসিসই TM ব্যবহার করে "গণনাযোগ্য" ভাবনার অনুমতি দেয়।

- ⚠️ **পরীক্ষার ফাঁদ:** "মাল্টি-টেপ টিএম এক-টেপ টিএমের চেয়ে বেশি শক্তিশালী" — এটাই প্রচলিত ভুল অপশন। অতিরিক্ত টেপ কেবল **সুবিধা**, এক টেপে সর্বোচ্চ **বর্গীয়** ধীরতা। আর ননডিটারমিনিস্টিক টিএম গ্রহণ করে তখনই যখন **কোনো একটি** শাখা গ্রহণ করে, সব নয়।
- 💡 **মনে রাখার কৌশল:** ভেরিয়েন্টগুলো মেশিনকে উদার করার চারটি উপায় — বেশি টেপ, বেশি বেছে নেওয়া, বেশি হেড, আলাদা I/O। উদারতা বদলায় **কত দ্রুতে**, কখনো **কী চিনতে পারে** তা নয়।

## ৫. সিদ্ধান্তযোগ্য, আধা-সিদ্ধান্তযোগ্য, অসিদ্ধান্তযোগ্য

**প্রেক্ষাপট।** একটি **সমস্যা** প্রতিটি ইনপুটের জন্য হ্যাঁ-না প্রশ্ন করে — অসীম উদাহরণের জন্য। "তিনটি উদাহরণে হ্যাঁ" দিয়ে কিছু সিদ্ধান্ত হয় না, তাই সমস্যাকে ভাগ করা হয় **উত্তর-দেওয়া মেশিনকে কী করতে দেওয়া হবে** তা দেখে: সবকিছুতে থামতে হবে, নাকি না-উদাহরণে সেটি চিরতরে লুপ করতে পারে।

| শ্রেণি | মেশিনটি কী করে | উদাহরণ |
|---|---|---|
| **সিদ্ধান্তযোগ্য** (রিকার্সিভ) | **প্রতিটি** ইনপুটে থেমে হ্যাঁ বা না বলে | সর্টিং, সার্চিং, PDA দিয়ে {aⁿbⁿ} |
| **আধা-সিদ্ধান্তযোগ্য** (আরই) | **হ্যাঁ**-তে থেমে বলে; না-উদাহরণে **লুপ** করতে পারে | হাল্টিং সমস্যা, হ্যাঁ-উদাহরণগুলোতে |
| **অসিদ্ধান্তযোগ্য** | উত্তর দেওয়ার **কোনো** অ্যালগরিদম নেই | হাল্টিং; ফাঁকা-টেপ হাল্টিং; টিএম সমতা |

**আদর্শ নির্মাণ।** কোনো আরই ভাষা **গ্রহণ** করতে কিছুই উল্টোতে হয় না: w-তে M চালাও, M গ্রহণ করলেই গ্রহণ করো। কোনো ভাষা **সিদ্ধান্ত** করতে একটি বর্জন অবস্থা যোগ করে **সব** অসংজ্ঞায়িত সরণকে সেখানে পাঠাও — তাহলে মেশিন সবকিছুতেই থামে। সিদ্ধান্তযোগ্য আরই-এর একটি কঠোর উপসেট।

- 💡 **মনে রাখার কৌশল:** **ডিসাইডার** দু-দিকী মেশিন: সে "না"-ও বলতে পারে। **রিকানাইজার** এক-দিকী: শুধু নিশ্চিত করে। একটি বর্জন অবস্থা যোগ করাই পুরো পার্থক্য।

**শেষ ছবিটি সত্য কেন।** যদি **L** ও **L′ = Σ\* \ L** দুটোই আরই হয়, তাদের দুই রিকানাইজার পাশাপাশি চালাও, একবারে একটি করে এক ধাপ করে। প্রতিটি ইনপুটে M ও M′-এর **ঠিক একটিই** ঘরোরা পর্যন্ত গ্রহণ করবে — কমপ্লিমেন্টের সম্পর্কই কোনো পলায় না। যে আগে গ্রহণ করে সে-ই উত্তর ঠিক করে, আর অন্যটি তখনই গ্রহণ করবে। ওই মেশিন সবকিছুতেই থামে, তাই **L রিকার্সিভ**।

```
[M for L]  ----বারবার একটি করে ধাপ----\
  L চেনে                              >  ঠিক একটিই গ্রহণ করবে
[M' for L'] --বারবার একটি করে ধাপ---/   L ও L' দুটোই আরই  ⇒  L রিকার্সিভ
```

- ⚠️ **পরীক্ষার ফাঁদ:** **অসিদ্ধান্তযোগ্য মানে "কঠিন" বা "ধীর" নয়** — মানে **কোনো অ্যালগরিদম একেবারে নেই**। আর "আধা-সিদ্ধান্তযোগ্য" দাবিটি কর্মক্ষমতার হালকা বক্তব্য নয়: হাল্টিং সমস্যার হ্যাঁ-পক্ষে নিখুঁত পদ্ধতি আছে, তবু সেটি অসিদ্ধান্তযোগ্য।
- 📌 **প্রচলিত ভুল ধারণা:** "প্রতিটি গণনাযোগ্য ফাংশনের একটি টিএম আছে" — কথাটি অর্ধেক সত্য। বাকি অর্ধেক হলো, প্রতিটি **অগণনাযোগ্য** ফাংশনের প্রমাণিতভাবে কোনো টিএম নেই — টিএম হাল্টিং সিদ্ধান্ত করতে, সব গণনাযোগ্য বাস্তব সংখ্যা গুনতে, কিংবা দুই প্রোগ্রাম একই আচরণ করে কি না বলতে পারে না।

## ৬. হাল্টিং সমস্যা (Halting Problem)

**সমস্যা।** একটি টিউরিং মেশিন **M** ও একটি ইনপুট স্ট্রিং **w** দেওয়া আছে, সিদ্ধান্ত করো **M** w-তে থামে কিনা — লেখা হয় H(M, w) = হ্যাঁ বা না। প্রোগ্রামের ক্ষেত্রে একই প্রশ্ন: **P** ও **I** দিলে **P** কি **I**-তে থামে?

**উপপাদ্য (টিউরিং, ১৯৩৬)।** হাল্টিং সমস্যা **অসিদ্ধান্তযোগ্য** — সব M ও w-এর জন্য কোনো অ্যালগরিদম উত্তর দিতে পারে না। তবু এটি **রিকার্সিভলি এনিউমারেবল**: w-তে M চালাও, M কখনো থামলে হ্যাঁ বলো। না-উদাহরণে কোনো উত্তর আসে না — এটাই "আধা-সিদ্ধান্তযোগ্য"ের অর্থ।

**বিরোধিতার মাধ্যমে প্রমাণ**

1. **ধরো** একটি ডিসাইডার **H(M, w)** আছে যা সবসময় থেমে সবসময় সঠিক উত্তর দেয়।
2. **D(M) বানাও**: এমন একটি মেশিন যা M-কে ইনপুট M দিয়ে চালায় এবং **H(M, M)**-কে জিজ্ঞেস করে।
3. **H বলল "থামে"**, তাহলে D **চিরতরে লুপ করে**।
4. **H বলল "লুপ করে"**, তাহলে D **সঙ্গে সঙ্গে থেমে** যায়।
5. **D-কে তার নিজের বর্ণনায় চালাও:** D(D)। H বলল D থামে, D লুপ করে; H বলল D লুপ করে, D থেমে যায়। **H-এর যেকোনো উত্তরই ভুল।**

মেশিনটি H-কে তার নিজের প্রশ্নের উত্তর দিতে বাধ্য করে, তাই H যেকোনো দিক থেকেই খণ্টিত — অথচ H প্রতিটি জোড়ায় সঠিক ছিল বলে ধরা হয়েছিল। যে কৌশলটি এটা করে তা হলো **ডায়াগোনাল**: সমাধানকারীকে তার নিজের উপরেই চালাও।

```
[ ধরা হয়েছে ডিসাইডার H ] --জিজ্ঞেস করা হয়--> [ D জিজ্ঞেস H(D, D) ]

  H বলল থামবে  ⇒  D লুপ করে        D চালানো হচ্ছে নিজের বর্ণনায়
  H বলল লুপ করবে ⇒  D থামে
  ------------------------------------------------
  H যা-ই বলুক, ভুল
```

**এর মূল্য কত**

- **কোনো সাধারণ প্রোগ্রাম বিশ্লেষক নেই** — আটকে থাকা লুপ আর ধীর গণনা কখনোই আলাদা করা যায় না।
- **নিখুঁত ডিবাগার নেই** — লিন্টার প্রমাণ করতে পারে না যে ফাংশন সব ইনপুটে শেষ হয়।
- **সর্বজনীন কালেক্টর নেই** — "এই মানটা কি এখনো পৌঁছানো যায়?" সাধারণভাবে অসিদ্ধান্তযোগ্য।
- যেকোনো সমস্যা যদি "এটা কি থামে?" **প্রকাশ করতে** পারে, সেটিও অসম্ভবতা উত্তরাধিকার করে।

- ⚠️ **পরীক্ষার ফাঁদ:** হাল্টিং সমস্যা "অসীম হওয়ার জন্য" অসিদ্ধান্তযোগ্য নয় — অনেক অসীম সমস্যা (সর্টিং, {aⁿbⁿ} সদস্যপতা) একদম সিদ্ধান্তযোগ্য। এটি অসিদ্ধান্তযোগ্য **ডায়াগোনালের** কারণে, আকারের কারণে নয়।
- 💡 **মনে রাখার কৌশল:** উল্টে ভাবো। D H-এর অনুমানের **ঠিক উল্টো** কাজ করে, তাই H নিজের উত্তরেই ধরা পড়ে। "প্রত্যাশ কর, তারপর উল্টোটা কর" — পুরো প্রমাণটাই এটুকু।

## ৭. রিডাকশন ও রাইসের উপপাদ্য

**সংজ্ঞা।** সমস্যা **A** সমস্যা **B**-তে **মেনি-ওয়ান রিডিউস** করে, লেখা **A ≤ B**, যদি এমন একটি গণনাযোগ্য ফাংশন f থাকে যাতে প্রতিটি ইনপুট **w**-এর জন্য **w ∈ A ⇔ f(w) ∈ B**। সহজ ভাষায় — B-এর সমাধান পেলে তাকে f(w) দিয়ে A-ও সমাধান করা যায়। অসিদ্ধান্তযোগ্যতার প্রমাণের মূল হাতিয়ার এটাই।

```
[ সমস্যা A: অসিদ্ধান্তযোগ্য ] --f--> [ সমস্যা B: ধরা হলো সিদ্ধান্তযোগ্য ]

   A ≤ B, A অসিদ্ধান্তযোগ্য  ⇒  B-ও অসিদ্ধান্তযোগ্য
```

| যদি | তাহলে |
|---|---|
| A **অসিদ্ধান্তযোগ্য** এবং A ≤ B | **B-ও অসিদ্ধান্তযোগ্য** |
| B **সিদ্ধান্তযোগ্য** এবং A ≤ B | **A-ও সিদ্ধান্তযোগ্য** |

**যে রিডাকশনগুলো আসলে জিজ্ঞেস করা হয়**

| সমস্যা A | যেখানে রিডিউস হয় |
|---|---|
| M, w-তে হাল্টিং | **ফাঁকা টেপে** হাল্টিং — আগে w লিখে দাও |
| M, w-তে হাল্টিং | M কি **কখনো q₅-এ পৌঁছায়** — q₅-কে হল্ট অবস্থা বানাও |
| M, w-তে হাল্টিং | **দুটি টিএম সমতা** — M-কে অনুকরণ করে N চালাও |
| CFG **অ্যাম্বিগুয়াস** | ফাঁকা-টেপ হাল্টিং, তাই অসিদ্ধান্তযোগ্য |

**রাইসের উপপাদ্য।** টিউরিং মেশিন দ্বারা চেনা **ভাষাগুলোর** যেকোনো **অ-সামান্য বৈশিষ্ট্য** P-কে ধরো। তাহলে **P অসিদ্ধান্তযোগ্য**। ঠিক বলা যাক: **P** হলো **L(M)**-এর — অর্থাৎ M যে স্ট্রিংগুলো গ্রহণ করে সেই *সেটের* — বৈশিষ্ট্য, M-এর বর্ণনার নয়। **অ-সামান্য** মানে কোনো মেশিনের ভাষায় আছে আবার কোনো মেশিনের ভাষায় নেই।

**অসিদ্ধান্তযোগ্য — L(M)-এর বৈশিষ্ট্য**

- **L(M) কি খালি**? · **সসীম**? · **রেগুলার**?
- **L(M) = Σ\*** কি?
- **M ও N কি একই ভাষা** চেনে?

**সিদ্ধান্তযোগ্য — মেশিনের বৈশিষ্ট্য**

- M কি কখনো **q₅ অবস্থায়** পৌঁছায়?
- M কি **১০০ ধাপের** মধ্যে থামে?
- M-এর কতগুলো **অবস্থা** আছে?

- ⚠️ **পরীক্ষার ফাঁদ:** রাইসের উপপাদ্য **ভাষার** বৈশিষ্ট্য নিয়ে। "M-এর ঠিক ৭টি অবস্থা আছে কি?" — গণনা করেই সিদ্ধান্ত। "L(M) কি অসীম?" — **অসিদ্ধান্তযোগ্য**, তাই রিডাকশনে **ইনপুটটিকে মেশিনের ভিতরেই ঢোকাতে হয়**।
- 💡 **মনে রাখার কৌশল:** **রাইস প্রশ্ন করে স্ট্রিং-সেটকে, মেশিনকে নয়।** প্রশ্নে **L(M)** বসাও, তারপর ভাবো — এটি কি অ-সামান্য?

## ৮. আরই ভাষা, কো-আরই ও শ্রেণিবিন্যাস

**আরই ভাষা।** যে ভাষা কোনো টিউরিং মেশিন **গ্রহণ** করে — সমতুল্যভাবে, যার সদস্য প্রতিটিকে একটি আধা-সিদ্ধান্ত পদ্ধতি ঘরোরার মধ্যেই নিশ্চিত করে। সদস্য নয় এমন স্ট্রিং কখনো পৌঁছাতে হয় না: মেশিন তার উপর চিরতরে লুপ করতে পারে। প্রতিটি **সিদ্ধান্তযোগ্য** ভাষাই আরই; কিছু আরই ভাষা সিদ্ধান্তযোগ্য নয়।

**আরই-এর বন্ধতার পূর্ণ ছক**

| ক্রিয়া | আরই বদ্ধ? |
|---|---|
| ইউনিয়ন L₁ ∪ L₂ | **হ্যাঁ** — নতুন শুরু অবস্থা, একটি শাখা অনুমান |
| কনক্যাটেনেশন L₁L₂ | **হ্যাঁ** — আগে M₁, তারপর M₂ |
| ক্লিন স্টার L\* | **হ্যাঁ** — ভাগের বিন্দু অনুমান |
| ইন্টারসেকশন L₁ ∩ L₂ | **হ্যাঁ** — দুই মেশিন বারবার চালাও |
| কমপ্লিমেন্ট L′ | **না** — রিকানাইজার লুপ করতে পারে |

*শ্রেণিবিন্যাস — প্রতিটি বাক্স উপরেরটার ভিতরে।*

```
+-------------------- আরই (RE) --------------------+
|  +------------ রিকার্সিভ · সিদ্ধান্তযোগ্য --------+ |
|  |  +--------- কনটেক্সট-সেনসিটিভ ---------+   | |
|  |  |  +-------- কনটেক্সট-ফ্রি --------+    |   | |
|  |  |  |  +----- রেগুলার -----+          |    |   | |
|  |  |  |  |                   |          |    |   | |
|  |  |  |  +-------------------+          |    |   | |
|  |  |  +--------------------------------+    |   | |
|  |  +--------------------------------------+   | |
|  +----------------------------------------------+ |
+--------------------------------------------------+
   রেগুলার ⊂ সিএফ ⊂ সিএস ⊂ রিকার্সিভ ⊂ আরই
```

**প্রতি শ্রেণির একটি উদাহরণ**

| শ্রেণি | উদাহরণ |
|---|---|
| রেগুলার | {w \| w 00 দিয়ে শেষ হয়} |
| কনটেক্সট-ফ্রি | {aⁿbⁿ \| n ≥ 0} — একটি স্ট্যাক |
| কনটেক্সট-সেনসিটিভ | {aⁿbⁿcⁿ \| n ≥ 1} — সীমিত টেপ |
| রিকার্সিভ | {w#w \| w ∈ {0,1}\*} — কপি করে মিলিয়ে দেখা |
| আরই | হাল্টিং সমস্যা (হ্যাঁ-উদাহরণ) |

**আরই বনাম কো-আরই।** **কো-আরই** = আরই ভাষার **কমপ্লিমেন্টের** শ্রেণি — সমস্যা যেগুলোর উত্তর মেশিন কেবল **না**-পক্ষে নিশ্চিত করে। হাল্টিং সমস্যা আরই কিন্তু কো-আরই **নয়**; দুটোই হলে পাতা ৬-এর সমান্তরাল যুক্তিতে সেটি সিদ্ধান্তযোগ্য হয়ে যেত, কিন্তু তা নয়।

- ⚠️ **পরীক্ষার ফাঁদ:** "আরই কমপ্লিমেন্টে বদ্ধ" — এটি **মিথ্যা**, আর সেই একটি তথ্য থেকেই আরও তিনটি ব্যাখ্যা করা যায়: সব আরই ভাষা সিদ্ধান্তযোগ্য নয়, সব আরই ভাষা কো-আরই নয়, আর কিছু ভাষা **দুটোই নয়**। **L ও L′ দুটোই আরই** হলে L **রিকার্সিভ**।
- 💡 **মনে রাখার কৌশল:** প্রতিটি স্তর ঠিক **একটি করে বেশি সম্পদ** কেনে: অটোমাটন → একটি গণনা, স্ট্যাক → একটি নেস্টিং, এলবিএ → সীমিত টেপ, টিএম → **সীমাহীন** টেপ।

বিরোধিতার মাধ্যমে প্রমাণ করো যে হাল্টিং সমস্যা অসিদ্ধান্তযোগ্য। তারপর ফাঁকা-টেপ হাল্টিংকে তার উপর রিডিউস করো, আর আরও দুটি সমস্যার নাম দাও যেগুলো এই অসিদ্ধান্তযোগ্যতা উত্তরাধিকার করে।

**মডেল উত্তর:**

1. **বলো ও ধরো** *(2)* — H(M, w): M w-তে থামে কি? ধরো H প্রতিটি জোড়ায় সঠিক।
2. **D বানাও** *(2)* — D(M) H(M, M)-কে জিজ্ঞেস করে এবং ঠিক **উল্টো**টা করে।
3. **বিরোধ** *(2)* — D(D)-তে D হু-যা H বলেছিল তার উল্টোটা করে।
4. **রিডাকশন** *(2)* — M′ নিজের ফাঁকা টেপে w লিখে তারপর M(w) অনুকরণ করে; তাই ফাঁকা-টেপ হাল্টিং ≤ হাল্টিং, অসিদ্ধান্তযোগ্য।
5. **আরও দুটি** *(2)* — স্টেট-এন্ট্রি (q₅-কে হল্ট অবস্থা বানাও) · টিএম সমতা (M-কে অনুকরণ করে N চালাও)।
