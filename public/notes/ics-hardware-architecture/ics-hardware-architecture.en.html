1What Is a Computer?

MCQ + Written
Definition A computer is a programmable electronic machine that accepts data (input), processes it under the control of a stored program, stores data and results, and produces information (output). Data = raw facts; information = processed, meaningful data.
CharacteristicMeaning
Speedns-level steps (MIPS, FLOPS)
Accuracyerrors are human (GIGO)
Diligenceno fatigue, works 24 × 7
Versatilitymany kinds of tasks
Storagehuge, permanent, fast recall
Automationruns a stored program alone
Speed units
1 ms = 10⁻³ s · 1 µs = 10⁻⁶ s
1 ns = 10⁻⁹ s · 1 ps = 10⁻¹² s
MIPS = million instructions / s
FLOPS = floating-point ops / s
Exam trap Limitations: a computer has no IQ, no common sense and no feelings. GIGO = Garbage In, Garbage Out: wrong input or a wrong program gives wrong output, however "accurate" the machine.

Worked example ✍ Bus bandwidth = width × transfers per second: a 64-bit (8-byte) bus at 100 MHz moves 8 × 100 × 10⁶ = 800 MB/s.
Stored-program concept Program instructions and data are kept in the same read-write memory, so a computer can be re-programmed by loading a new program. Described by John von Neumann in the 1945 "First Draft of a Report on the EDVAC".

7CPU: ALU, Control Unit & Registers

high-yield
ALU Does every calculation: add, subtract (multiply/divide by repeated add/shift), AND, OR, NOT, XOR, compare. Sets the flags (zero, carry, sign, overflow).
Control Unit The "manager": fetches and decodes instructions and sends timing and control signals. It does not process data. Design: hardwired or microprogrammed (Ch 7).
RegisterHolds
PC (Program Counter)address of the next instruction
IR (Instruction Register)the instruction being decoded / executed now
MAR (Memory Address Reg.)address sent to memory (drives the address bus)
MDR / MBR (Memory Data/Buffer)word just read from or about to be written to memory
AC (Accumulator)one ALU operand and the result
Flag / Status, SPcondition bits · top of the stack
  1. Fetch: MAR ← PC; MDR ← M[MAR]; IR ← MDR; PC ← PC + 1
  2. Decode: CU reads the opcode, finds operands
  3. Execute: ALU operates, or data moves, or a jump loads PC
  4. Store (write-back): result to a register or memory; check for interrupts
Memory trick "PC points, MAR asks, MDR carries, IR holds."
Exam trap PC holds the address of the next instruction, not the instruction. The CU never computes.

8Clock Speed & CPU Performance

Clock period T = 1 / f: 1 GHz → 1 ns, 3 GHz → 0.33 ns.

Word size = bits handled at once (32/64-bit). Multi-core = several cores on one chip.

Example ✍ IC = 2 × 10⁹, CPI = 1.5, f = 3 GHz
CPU time = IC × CPI / f = 1 s
MIPS = f / (CPI × 10⁶) = 2000

9Memory Hierarchy

high-yield
LevelAccess
Registers< 1 ns

RAM50 – 100 ns
SSD≈ 0.1 ms

Tapeseconds +

Cache works because of locality of reference: temporal (the same item again soon) and spatial (neighbouring addresses next). Hit ratio h = hits / total accesses.

Worked example ✍ Cache 10 ns, RAM 100 ns, h = 0.9 (simultaneous access): T = h·Tc + (1 − h)·Tm = 9 + 10 = 19 ns, five times faster than RAM alone. (Hierarchical access: miss costs 10 + 100 → T = 20 ns.)

11Memory Units & Capacity Maths

calculation
UnitSize
nibble · byte4 bits · 8 bits
1 KB2¹⁰ = 1024 bytes
1 MB · 1 GB2²⁰ · 2³⁰ bytes
1 TB · 1 PB2⁴⁰ · 2⁵⁰ bytes
EB · ZB · YB2⁶⁰ · 2⁷⁰ · 2⁸⁰
Memory trick K M G T P E Z Y: "Kind Men Give Ten Percent Every Zakat Year"; each step × 1024.
Exam trap Disk makers count in 10³ steps: a "1 TB" disk = 10¹² B ≈ 931 GB in Windows (2³⁰-byte GB, strictly GiB).
Key formula n address lines → 2ⁿ locations · capacity = 2ⁿ × word size · m data lines = word of m bits
Worked examples ✍
  1. 16 address lines, 8-bit word: 2¹⁶ × 1 B = 65,536 B = 64 KB
  2. 8086: 20 address lines → 2²⁰ = 1 MB; a 32-bit address bus → 2³² B = 4 GB
  3. A 1K × 8 chip has 10 address and 8 data lines. Chips for an 8K × 16 memory = (8K / 1K) × (16 / 8) = 16

12Secondary Storage

high-yield

HDD: magnetic platters spinning at 5400 / 7200 rpm. Cylinder = the same track on every surface. Sector = 512 B (4 KB on new disks).

Access time = seek + rotational latency + transfer

SSD: NAND flash, no moving parts: faster, silent, shock-proof; limited write cycles. SATA or NVMe (PCIe, M.2).

Worked example ✍ 7200 rpm → one turn = 60 / 7200 s = 8.33 ms → average rotational latency = half a turn = 4.17 ms. Capacity of 8 surfaces × 1024 tracks × 64 sectors × 512 B = 2²⁸ B = 256 MB.
MediumCapacityNote
CD650 / 700 MB780 nm infrared laser
DVD4.7 GB (1 layer), 8.5 GB (2)650 nm red laser
Blu-ray25 GB (1 layer), 50 GB (2)405 nm blue-violet laser
Magnetic tapeTBs per cartridge (LTO)sequential access, cheapest backup

Access: random (RAM) · direct (disk) · sequential (tape). Old floppy 3.5″ = 1.44 MB.

15Ports, Motherboard & I/O Transfer

  • USB: 2.0 = 480 Mbps, 3.0 = 5 Gbps, USB4 = 40 Gbps
  • HDMI digital audio + video · VGA analog video (15-pin)
  • RJ-45 Ethernet · PS/2 old keyboard/mouse
  • I/O transfer: programmed, interrupt-driven, DMA (block moves without the CPU)

Written question Draw the block diagram of a basic computer system and state the function of each unit. What does the system bus do? 8 marks
  1. Diagram (sheet 5): Input → CPU [CU + ALU + registers] ↔ Memory → Output, with dashed control lines from the CU to every unit. 2
  2. Input converts data/programs to binary; Output gives results in human form; Memory: primary (RAM/ROM) holds the running program, secondary (HDD/SSD) stores permanently. 2
  3. ALU does arithmetic and logic; CU fetches, decodes and issues control signals; registers hold operands and addresses. 2
  4. System bus: address (one-way, picks the location), data (two-way, carries the word), control (RD, WR, interrupt, clock). 2
