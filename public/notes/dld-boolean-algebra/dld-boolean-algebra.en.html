1What Is Boolean Algebra?

MCQ + Written
Definition The algebra of two values, 0 and 1, with three basic operations: AND, OR, NOT. Introduced by George Boole (1854); Claude Shannon (1938) applied it to switching circuits, which made it the mathematics of digital design.
OperationSymbolRuleIn C
AND (logical product)A · B or AB1 only if all inputs are 1&&
OR (logical sum)A + B0 only if all inputs are 0||
NOT (complement)A′ (also Ā)flips 0 ↔ 1!

Precedence: ( ) → NOT → AND → OR

So A + BC′ means A + (B · (C′)), never (A + B)C′.

Counting rules
n variables → 2ⁿ truth-table rows
n variables → 2^(2ⁿ) different functions
(n = 2 → 16 functions; n = 3 → 256)
Exam trap Boolean 1 + 1 = 1 (OR). Binary arithmetic 1 + 1 = 10 (sum 0, carry 1). Same symbol, different meaning: read the question carefully.

2Huntington's Postulates & Duality

  1. Closure under + and ·
  2. Identity: A + 0 = A, A · 1 = A
  3. Commutative: A + B = B + A, AB = BA
  1. Distributive: A(B + C) = AB + AC and A + BC = (A + B)(A + C)
  2. Complement: A + A′ = 1, A · A′ = 0
  3. At least two elements, 0 ≠ 1

Huntington (1904): every other law (associative, absorption, De Morgan …) can be proved from these six.

Duality principle Swap + ↔ · and 0 ↔ 1 (leave every literal as it is). If an identity is true, its dual is also true, so each proof gives you two laws.
ExpressionDual
A + 0 = AA · 1 = A
A + AB = AA(A + B) = A
A + BCA(B + C)
Memory trick Dual = "mirror the operators, keep the letters". Complement = mirror the operators and flip every letter.

n variables: (A + B + C + …)′ = A′B′C′…  ·  (ABC…)′ = A′ + B′ + C′ + …

Columns 3 = 4 and 5 = 6 in every row → proved.

a bar over the whole ≠ a bar over each letter!

Complement of a whole function, F′

  1. Put brackets round every AND term
  2. Swap + ↔ · (and 0 ↔ 1): this is the dual
  3. Complement every literal (A ↔ A′)
  4. Simplify if asked
Memory trick F′ = dual of F with every literal flipped. "Break the long bar, change the sign under the break."
Worked example 1 ✍ F = AB′ + A′C → F′ = (A′ + B)(A + C′)
Expand: A′A + A′C′ + AB + BC′ = A′C′ + AB + BC′ = A′C′ + AB (BC′ is the consensus of A′C′ and AB)
Worked example 2 ✍ F = x(y′z + yz′) → F′ = x′ + (y + z′)(y′ + z) = x′ + yz + y′z′  (= x′ + (y ⊙ z))
Worked example 3 ✍ (A + BC)′ = A′ · (BC)′ = A′(B′ + C′) = A′B′ + A′C′  De Morgan twice, then distributive
Exam trap (A + B)′ ≠ A′ + B′ and (AB)′ ≠ A′B′. Flipping the letters without swapping the operator is the most common mistake.

DLD · Boolean AlgebraSimplification

5Algebraic Simplification

written favourite
Goal Fewest terms, then fewest literals (a literal = a variable or its complement in a term). Fewer literals → fewer gates, less delay, lower cost. Name the law at every step: examiners mark the steps.
Example 1 ✍ F = AB + AB′ + A′B
  1. AB + AB′ = A(B + B′) = A · 1 = A  distributive, complement, identity
  2. F = A + A′B = A + B  redundant literal  (6 literals → 2)
Example 2 ✍ F = (A + B)(A + B′) = A + BB′ = A + 0 = A  distributive (+ over ·), complement, identity
Example 3 ✍ F = A′B′C + A′BC + AB′C
  1. A′B′C + A′BC = A′C(B′ + B) = A′C  distributive, complement
  2. F = A′C + AB′C = C(A′ + AB′) = C(A′ + B′)  redundant literal
  3. F = A′C + B′C (9 literals → 4; factored C(A′ + B′) = 3)
Example 4: consensus ✍ F = XY + X′Z + YZ
  1. YZ = YZ(X + X′) = XYZ + X′YZ  identity, complement, distributive
  2. XY + XYZ = XY and X′Z + X′YZ = X′Z  absorption
  3. F = XY + X′Z
Example 5 ✍ F = A′BC + AB′C′ + ABC′ + ABC
  1. A′BC + ABC = BC(A′ + A) = BC
  2. AB′C′ + ABC′ = AC′(B′ + B) = AC′
  3. F = BC + AC′ (12 literals → 4)
Look for, in this order ① X + X′ pairs (combine) ② a term inside another (absorption) ③ X + X′Y (drop X′) ④ a consensus "bridge" term (delete).

Minterm mi AND of all variables; = 1 for exactly one row. Canonical SOP = OR of minterms = Σm
Maxterm Mi OR of all variables; = 0 for exactly one row. Canonical POS = AND of maxterms = ΠM

Key relation: mi′ = Mi · F = Σm(…) = ΠM(the missing indices) · F′ = Σm(missing) · #m + #M = 2ⁿ

Standard SOP/POS (terms may miss variables, e.g. A + B′C) vs canonical (every term has every variable).

Worked example ✍ Expand F = A + B′C to canonical form.
  1. A = A(B + B′)(C + C′) = m4 + m5 + m6 + m7
  2. B′C = (A + A′)B′C = m5 + m1
  3. F = Σm(1, 4, 5, 6, 7) = ΠM(0, 2, 3)
  4. F′ = Σm(0, 2, 3)
Memory trick Minterm: 1 → plain, 0 → primed. Maxterm: exactly the opposite (0 → plain).
Exam trap 3-variable F = Σm(1, 3, 5) has 8 − 3 = 5 maxterms in its ΠM form.

7Karnaugh Map (K-map): the Rules

high-yield
Definition A K-map (Karnaugh, 1953) is the truth table redrawn as a grid in Gray-code order, so neighbouring cells differ in exactly one variable. Grouping neighbours removes that variable.

cell numbers = minterm indices · columns run 00, 01, 11, 10 (not 10, 11)

  1. Group the 1s for SOP (the 0s for POS); an X (don't-care) may join any group
  2. Group sizes: 1, 2, 4, 8, 16; rectangles only, no L-shapes or diagonals
  3. Make groups as large as possible, and use as few as possible
  4. Groups may overlap; every 1 must be covered
  5. Edges wrap: left ↔ right, top ↔ bottom; the 4 corners are neighbours
  6. Read a group: keep the variables that stay constant

4 cells2

16 cellsF = 1
Prime implicant (PI) a group that cannot be made larger
Essential PI a PI covering a 1 that no other PI covers → it must appear in the answer
Exam trap "Adjacent" means one bit different: m3 (0011) and m2 (0010) are neighbours; m1 (0001) and m2 (0010) are not, though 1 and 2 are consecutive numbers.

8K-map Worked Examples

written favourite

(a) F(A, B, C, D) = Σm(0, 1, 2, 5, 8, 9, 10)

  • B′C′: quad m0, 1, 8, 9 (top and bottom rows wrap)
  • B′D′: the four corners m0, 2, 8, 10
  • A′C′D: pair m1, 5

F = B′C′ + B′D′ + A′C′D

All three are essential: m9, m10 and m5 are each covered by one group only. 7 literals.

(b) With don't-cares: F = Σm(1, 3, 7, 11, 15) + d(0, 2, 5)

  • CD: column CD = 11 (m3, 7, 11, 15)
  • A′B′: row AB = 00, using X at m0 and m2

F = CD + A′B′

CD + A′D (using X at m5) is equally minimal: both have 4 literals. X5 is simply left out of the first answer.

(c) POS by grouping 0s: F(A, B, C) = ΠM(0, 1, 2, 3, 6)

  • Row A = 0 (four 0s) → sum term (A)
  • m2, m6 (B = 1, C = 0) → (B′ + C)
  • In a 0-group: a variable that is 0 stays plain, 1 is primed

F = A(B′ + C)

Memory trick Inside a group, a variable that changes disappears; a variable that stays constant is kept.
Exam trap Use an X only if it makes a group bigger; don't-cares never have to be covered.

9Quine–McCluskey (Tabular) Method

Idea A systematic, computer-friendly version of the K-map (Quine 1952, McCluskey 1956). It works for any number of variables.
  1. Write the minterms in binary and group them by the number of 1s
  2. Combine terms in neighbouring groups that differ in one bit; write – for that bit and tick both
  3. Repeat until nothing combines; unticked terms = prime implicants
  4. PI chart: take the essential PIs, then cover the rest with the fewest PIs (Petrick's method)
Mini example ✍ F = Σm(0, 1, 2, 3, 7)

10From Minimal Form to Gates & Code

SOP → AND-OR → NAND-NAND  ·  POS → OR-AND → NOR-NOR (same two levels; see Logic Gates notes, sheet 7).

Cost ≈ number of gates + gate inputs: that is why we minimize literals first.
