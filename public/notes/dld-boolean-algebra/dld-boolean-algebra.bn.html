১বুলিয়ান বীজগণিত কী?

MCQ + লিখিত
সংজ্ঞা শুধু দুটি মান, 0 ও 1 নিয়ে কাজ করা বীজগণিত, যার মৌলিক অপারেশন তিনটি: AND, OR, NOT। জর্জ বুল (১৮৫৪) এর প্রবর্তক; ক্লদ শ্যানন (১৯৩৮) একে সুইচিং সার্কিটে প্রয়োগ করেন, ফলে এটিই হয়ে ওঠে ডিজিটাল ডিজাইনের গণিত।
অপারেশনপ্রতীকনিয়মC-তে
AND (যৌক্তিক গুণ)A · B বা ABসব ইনপুট 1 হলেই কেবল 1&&
OR (যৌক্তিক যোগ)A + Bসব ইনপুট 0 হলেই কেবল 0||
NOT (পূরক)A′ (বা Ā)0 ↔ 1 উল্টে দেয়!

অগ্রাধিকার ক্রম: ( ) → NOT → AND → OR

তাই A + BC′ মানে A + (B · (C′)), কখনোই (A + B)C′ নয়।

গণনার নিয়ম
n টি চলক (variable) → সত্যক সারণিতে 2ⁿ টি সারি
n টি চলক → 2^(2ⁿ) টি ভিন্ন ফাংশন
(n = 2 → ১৬টি; n = 3 → ২৫৬টি)
পরীক্ষার ফাঁদ বুলিয়ান 1 + 1 = 1 (OR)। বাইনারি পাটিগণিতে 1 + 1 = 10 (যোগফল 0, ক্যারি 1)। চিহ্ন এক, অর্থ ভিন্ন: প্রশ্ন মন দিয়ে পড়ো।

২হান্টিংটনের স্বতঃসিদ্ধ ও দ্বৈততা নীতি

  1. আবদ্ধতা (closure): + ও · এর অধীনে
  2. অভেদ (identity): A + 0 = A, A · 1 = A
  3. বিনিময়: A + B = B + A, AB = BA
  1. বণ্টন: A(B + C) = AB + AC এবং A + BC = (A + B)(A + C)
  2. পূরক: A + A′ = 1, A · A′ = 0
  3. অন্তত দুটি ভিন্ন উপাদান, 0 ≠ 1

হান্টিংটন (১৯০৪): বাকি সব সূত্র (সংযোগ, শোষণ, ডি মরগান …) এই ছয়টি থেকেই প্রমাণ করা যায়।

দ্বৈততা নীতি (duality) + ↔ · এবং 0 ↔ 1 বদলাও, লিটারাল যেমন আছে তেমনই থাকবে। কোনো অভেদ সত্য হলে তার দ্বৈত রূপও সত্য, তাই একটি প্রমাণে দুটি সূত্র মেলে।
রাশিদ্বৈত রূপ
A + 0 = AA · 1 = A
A + AB = AA(A + B) = A
A + BCA(B + C)
মনে রাখার কৌশল দ্বৈত = "অপারেটর উল্টাও, অক্ষর রাখো"। পূরক = অপারেটর উল্টাও এবং প্রতিটি অক্ষরও উল্টাও।

★ = সাধারণ বীজগণিতে এর কোনো মিল নেই (সেখানে 1 + 1 = 2, A + A = 2A)। ৯–১২ নম্বর সূত্রই সরলীকরণের মূল হাতিয়ার।

প্রমাণ: শোষণ ✍
A + AB = A·1 + AB = A(1 + B) = A · 1 = A
অভেদ, বণ্টন, শূন্য, অভেদ
প্রমাণ: অপ্রয়োজনীয় লিটারাল ✍
A + A′B = (A + A′)(A + B) = 1 · (A + B) = A + B
বণ্টন (· এর উপর +), পূরক, অভেদ
মনে রাখার কৌশল: কনসেনসাস AB + A′C-তে A একবার সাধারণ, একবার পূরক রূপে আছে। A বাদ দিয়ে বাকিগুলো AND করো → BC। এই "সেতু" পদটি অপ্রয়োজনীয়, তাই বাদ।
পরীক্ষার ফাঁদ A + BC = (A + B)(A + C) এখানে সত্য, যদিও স্কুলের বীজগণিতে ভুল মনে হয়। A + A = A, কখনো 2A নয়।

পুরো ফাংশনের পূরক, F′

  1. প্রতিটি AND পদের চারপাশে বন্ধনী দাও
  2. + ↔ · (এবং 0 ↔ 1) বদলাও: এটিই দ্বৈত রূপ
  3. প্রতিটি লিটারালের পূরক নাও (A ↔ A′)
  4. চাইলে সরল করো
মনে রাখার কৌশল F′ = F-এর দ্বৈত রূপ, প্রতিটি লিটারাল উল্টানো। "লম্বা দাগ ভাঙো, ভাঙার নিচের চিহ্ন বদলাও।"
সমাধানকৃত উদাহরণ ১ ✍ F = AB′ + A′C → F′ = (A′ + B)(A + C′)
বিস্তার: A′A + A′C′ + AB + BC′ = A′C′ + AB + BC′ = A′C′ + AB (BC′ হলো A′C′ ও AB-এর কনসেনসাস)
সমাধানকৃত উদাহরণ ২ ✍ F = x(y′z + yz′) → F′ = x′ + (y + z′)(y′ + z) = x′ + yz + y′z′  (= x′ + (y ⊙ z))
সমাধানকৃত উদাহরণ ৩ ✍ (A + BC)′ = A′ · (BC)′ = A′(B′ + C′) = A′B′ + A′C′  দুবার ডি মরগান, তারপর বণ্টন
পরীক্ষার ফাঁদ (A + B)′ ≠ A′ + B′ এবং (AB)′ ≠ A′B′। অপারেটর না বদলে শুধু অক্ষর উল্টানোই সবচেয়ে সাধারণ ভুল।

৫বীজগাণিতিক সরলীকরণ

লিখিত পরীক্ষার প্রিয়
লক্ষ্য সবচেয়ে কম পদ, তারপর সবচেয়ে কম লিটারাল (লিটারাল = কোনো পদে একটি চলক বা তার পূরক)। কম লিটারাল → কম গেট, কম বিলম্ব, কম খরচ। প্রতিটি ধাপে সূত্রের নাম লেখো: পরীক্ষক ধাপে ধাপে নম্বর দেন।
উদাহরণ ১ ✍ F = AB + AB′ + A′B
  1. AB + AB′ = A(B + B′) = A · 1 = A  বণ্টন, পূরক, অভেদ
  2. F = A + A′B = A + B  অপ্রয়োজনীয় লিটারাল  (৬টি লিটারাল → ২টি)
উদাহরণ ২ ✍ F = (A + B)(A + B′) = A + BB′ = A + 0 = A  বণ্টন (· এর উপর +), পূরক, অভেদ
উদাহরণ ৩ ✍ F = A′B′C + A′BC + AB′C
  1. A′B′C + A′BC = A′C(B′ + B) = A′C  বণ্টন, পূরক
  2. F = A′C + AB′C = C(A′ + AB′) = C(A′ + B′)  অপ্রয়োজনীয় লিটারাল
  3. F = A′C + B′C (৯টি লিটারাল → ৪টি; উৎপাদকে C(A′ + B′) = ৩টি)
উদাহরণ ৪: কনসেনসাস ✍ F = XY + X′Z + YZ
  1. YZ = YZ(X + X′) = XYZ + X′YZ  অভেদ, পূরক, বণ্টন
  2. XY + XYZ = XY এবং X′Z + X′YZ = X′Z  শোষণ
  3. F = XY + X′Z
উদাহরণ ৫ ✍ F = A′BC + AB′C′ + ABC′ + ABC
  1. A′BC + ABC = BC(A′ + A) = BC
  2. AB′C′ + ABC′ = AC′(B′ + B) = AC′
  3. F = BC + AC′ (১২টি লিটারাল → ৪টি)
এই ক্রমে খোঁজো ① X + X′ জোড়া (একত্র করো) ② এক পদের ভেতরে আরেক পদ (শোষণ) ③ X + X′Y (X′ বাদ) ④ কনসেনসাসের "সেতু" পদ (বাদ দাও)।

মিনটার্ম mi সব চলকের AND; ঠিক একটি সারিতে 1। ক্যানোনিকাল SOP (গুণফলের যোগফল) = মিনটার্মের OR = Σm
ম্যাক্সটার্ম Mi সব চলকের OR; ঠিক একটি সারিতে 0। ক্যানোনিকাল POS (যোগফলের গুণফল) = ম্যাক্সটার্মের AND = ΠM

মূল সম্পর্ক: mi′ = Mi · F = Σm(…) = ΠM(বাদ পড়া সূচক) · F′ = Σm(বাদ পড়া) · #m + #M = 2ⁿ

সূচক = বাইনারিতে সারির নম্বর: ABC = 101 → m5

স্ট্যান্ডার্ড SOP/POS (পদে কোনো চলক বাদ থাকতে পারে, যেমন A + B′C) বনাম ক্যানোনিকাল (প্রতিটি পদে সব চলক)।

সমাধানকৃত উদাহরণ ✍ F = A + B′C-কে ক্যানোনিকাল রূপে প্রকাশ করো।
  1. A = A(B + B′)(C + C′) = m4 + m5 + m6 + m7
  2. B′C = (A + A′)B′C = m5 + m1
  3. F = Σm(1, 4, 5, 6, 7) = ΠM(0, 2, 3)
  4. F′ = Σm(0, 2, 3)
মনে রাখার কৌশল মিনটার্ম: 1 → সাধারণ, 0 → পূরক। ম্যাক্সটার্ম: ঠিক উল্টো (0 → সাধারণ)।
পরীক্ষার ফাঁদ ৩ চলকের F = Σm(1, 3, 5)-এর ΠM রূপে ম্যাক্সটার্ম 8 − 3 = ৫টি।

সংজ্ঞা কার্নো ম্যাপ (কার্নো, ১৯৫৩) হলো গ্রে কোড (Gray code) ক্রমে সাজানো সত্যক সারণি, যাতে পাশাপাশি ঘরগুলো ঠিক একটি চলকে ভিন্ন হয়। পাশাপাশি ঘর একসাথে গ্রুপ করলে সেই চলকটি বাদ পড়ে।

ঘরের সংখ্যা = মিনটার্ম সূচক · কলামের ক্রম 00, 01, 11, 10 (10, 11 নয়)

  1. SOP-এর জন্য 1 গ্রুপ করো (POS-এর জন্য 0); X (ডোন্ট-কেয়ার) যেকোনো গ্রুপে যেতে পারে
  2. গ্রুপের আকার: 1, 2, 4, 8, 16; শুধু আয়তক্ষেত্র, L-আকার বা কোণাকুণি নয়
  3. গ্রুপ যত বড় সম্ভব, আর সংখ্যায় যত কম সম্ভব
  4. গ্রুপ একে অপরের উপর পড়তে পারে; প্রতিটি 1 ঢাকা চাই
  5. কিনারা মোড়ানো: বাম ↔ ডান, উপর ↔ নিচ; চার কোণাও প্রতিবেশী
  6. গ্রুপ পড়া: যে চলক বদলায় না, শুধু সেটিই থাকে

৮কার্নো ম্যাপের সমাধানকৃত উদাহরণ

লিখিত পরীক্ষার প্রিয়

(ক) F(A, B, C, D) = Σm(0, 1, 2, 5, 8, 9, 10)

  • B′C′: m0, 1, 8, 9-এর চতুষ্ক (উপর-নিচ সারি মোড়ানো)
  • B′D′: চার কোণা m0, 2, 8, 10
  • A′C′D: m1, 5-এর জোড়া

F = B′C′ + B′D′ + A′C′D

তিনটিই অপরিহার্য: m9, m10 ও m5 প্রত্যেকে মাত্র একটি গ্রুপে আছে। মোট ৭টি লিটারাল।

(খ) ডোন্ট-কেয়ারসহ: F = Σm(1, 3, 7, 11, 15) + d(0, 2, 5)

  • CD: CD = 11 কলাম (m3, 7, 11, 15)
  • A′B′: AB = 00 সারি, m0 ও m2-এর X ব্যবহার করে

F = CD + A′B′

CD + A′D (m5-এর X ব্যবহার করে) সমান ন্যূনতম: দুটিতেই ৪টি লিটারাল। প্রথম উত্তরে X5 শুধু বাদ থাকে।

(গ) 0 গ্রুপ করে POS: F(A, B, C) = ΠM(0, 1, 2, 3, 6)

  • A = 0 সারি (চারটি 0) → যোগফল-পদ (A)
  • m2, m6 (B = 1, C = 0) → (B′ + C)
  • 0-গ্রুপে: যে চলক 0, সেটি সাধারণ; যে চলক 1, সেটি পূরক

F = A(B′ + C)

মনে রাখার কৌশল গ্রুপের ভেতরে যে চলক বদলায় সেটি বাদ; যে চলক একই থাকে সেটি থাকে।
পরীক্ষার ফাঁদ X তখনই নাও যখন তাতে গ্রুপ বড় হয়; ডোন্ট-কেয়ার ঢাকা বাধ্যতামূলক নয়।
