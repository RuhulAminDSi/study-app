1What Is Software?

MCQ + Written
Definition Software is a set of programs, with their data and documentation, that tells the hardware what to do. It is intangible: it does not wear out, but it can have bugs and become obsolete. The word "software" was first used in print by John W. Tukey (1958).
ComponentWhat it isExamples
Hardwarephysical, tangible parts (see cs2)CPU, RAM, keyboard, SSD
Softwareprograms + data, intangibleWindows, MS Word, Chrome
Firmwaresoftware fixed in ROM/flash of a deviceBIOS/UEFI, router firmware
Humanware (liveware)people who use and run the systemusers, programmers, operators

3Operating System: Role & Functions

high-yield
Definition The operating system (OS) is the system software that manages the hardware resources and gives users and programs an interface and common services. Two views: a resource manager (shares out CPU, memory, devices, files) and an extended machine (hides hardware detail behind simple calls). It is the first major program loaded at boot; its kernel stays in RAM until shutdown.
FunctionWhat the OS does
Processcreate, schedule, end processes; process = a program in execution (Ch 18)
Memoryallocate/free RAM; virtual memory = disk as RAM (pagefile.sys, swap)
Filecreate, read, write, delete files; directories; permissions
Device (I/O)drivers, interrupts, buffering, spooling (print queue)
Storagefree-space tracking, disk scheduling, formatting
Securitylogin, user accounts, access rights; isolates programs
User interfaceCLI or GUI (sheet 4)
Othersnetworking, error detection, accounting (usage logs)
Memory trick "Please Make Friendly Devices Safe & Useful" → Process, Memory, File, Device, Security, User interface.
SPOOL = Simultaneous Peripheral Operations On-Line: jobs wait on disk in a queue so a slow printer never holds up the CPU.

Booting: from power-on to login

BIOS = Basic Input/Output System; UEFI = Unified Extensible Firmware Interface
  1. Power on → BIOS/UEFI (firmware in ROM/flash) runs the POST (Power-On Self-Test)
  2. It finds the boot device (boot order) and loads the bootloader from the MBR (first 512-byte sector) or the EFI partition (GPT)
  3. The bootloader (GRUB, Windows Boot Manager) loads the kernel into RAM
  4. Kernel starts drivers and the first process (init/systemd) → services → login
Exam trap Cold boot = start from power-off; warm boot = restart without cutting power (Restart, Ctrl+Alt+Del). The bootstrap loader lives in ROM/flash, not on the hard disk; BIOS settings are kept in battery-backed CMOS RAM.

4Kernel, Shell & System Calls

high-yield
Kernel The core of the OS: always resident in main memory, runs in privileged kernel mode, manages CPU, memory, devices and files.
Shell The command interpreter: the outer layer that takes the user's commands and passes them to the kernel. Text shells: sh (Bourne), bash (default on most Linux), zsh (macOS default since 2019), cmd.exe, PowerShell. GUI shell: Windows Explorer.
Memory trick Like a nut: the kernel is the seed inside, the shell is the cover outside. You talk to the shell; the shell talks to the kernel.
Kernel typeIdeaExamples
Monolithicall services in kernel space; fastLinux, UNIX, MS-DOS
Microkerneltiny kernel; drivers, file system in user spaceMINIX, QNX, L4
Hybridmicro design + some services in kernelWindows NT, macOS (XNU)

User mode vs kernel mode: apps run in user mode with limited rights. To use hardware they make a system call: a trap (software interrupt) switches the CPU to kernel mode, the kernel does the job, then control returns to user mode.

fd = open("a.txt", O_RDONLY); read(fd, buf, 100); /* kernel */ close(fd); /* back in user mode */

UNIX/Linux calls: fork(), exec(), open(), read(), write(), exit() · Windows: CreateProcess(), ReadFile() · libraries (POSIX, Win32 API) wrap them.

User interface: CLI vs GUI

PointCLI (Command Line)GUI (Graphical)
Interactiontyped commands (dir, ls, cd)WIMP: windows, icons, menus, pointer
Resourceslow; ideal for servers, scriptsmore RAM, CPU, graphics
Learningharder; fast for expertseasy for beginners
ExamplesMS-DOS, Linux terminalWindows, macOS, Android

GUI history: Xerox Alto (PARC, 1973) → Apple Lisa (1983) → Macintosh (1984) → Windows 1.0 (1985).

Exam trap The shell is not the kernel, and a "terminal" is only the window that runs a shell. MS-DOS is a CLI OS; Windows 1.0–3.x were GUIs running on top of DOS.

5Types of Operating Systems

high-yield
TypeKey ideaExamples / use
Batchsimilar jobs grouped and run in sequence; no user interactionearly IBM mainframes
Multiprogrammingmany programs in RAM; CPU switches when one waits for I/O → CPU utilisationIBM OS/360
Time-sharing (multitasking)CPU time cut into slices (quantum) and rotated → fast responseCTSS (1961), Multics, UNIX
Multiprocessing2+ CPUs/cores share memory, run in parallel; SMP or AMPmulti-core PCs, servers
Multithreadingone process split into concurrent threadsbrowsers, web servers
Real-time (RTOS)output within a deadline; hard: a miss = failure; soft: a miss is toleratedVxWorks, QNX, FreeRTOS
Distributednetworked computers appear to the user as one systemAmoeba, clusters, cloud
Network OSa server shares files, printers, users over a LANNetWare, Windows Server
Embedded / mobilebuilt into devices; small footprint; phonesembedded Linux, Android

Hard real-time: airbag, pacemaker, flight control. Soft real-time: video streaming, VoIP, online games.

By users & tasks
Single-user, single-task: MS-DOS
Single-user, multitasking: Windows 11, macOS
Multi-user: UNIX, Linux, Windows Server
Memory trick Multi-programming = many programs in RAM · multi-tasking = time slices · multi-processing = many processors.
Exam trap Goal of multiprogramming = CPU utilisation; goal of time-sharing = response time. Multitasking works on one CPU (concurrency); multiprocessing needs more than one CPU (true parallelism).

7Language Translators

high-yield
Definition A language translator is system software that converts a program in one language (source code) into machine code (object code) the CPU can run. Three kinds: assembler, compiler, interpreter.
Gen.Language levelExampleTranslated by
1GLbinary machine code; fastest10110000nothing
2GLassembly: mnemonicsMOV AL, 61hassembler
3GLhigh-level, proceduralC, Java, Pythoncompiler / interpreter
4GLnon-procedural: say what, not howSQLDBMS engine
5GLlogic / constraints (AI)Prologinference engine
PointCompilerInterpreter
Translateswhole program at once, before runningone statement at a time
Outputseparate object / executable fileno object file
Errorslisted after the whole program is scannedstops at the first error
Speedprogram runs fasterslower (translates every run)
Re-runno compiler neededinterpreter needed every time
ExamplesC, C++, Fortran, GoPython, BASIC, JavaScript, PHP
Linker joins object files and library code into one executable. Loader: copies the executable into RAM and starts it.
Memory trick Compiler = translate the whole book, then read it. Interpreter = a live interpreter at a meeting, sentence by sentence.
Exam trap Java is both: javac compiles to bytecode (.class) and the JVM interprets or JIT-compiles it. An assembler handles assembly only; object code cannot run until it is linked.

UtilityJobExamples

9Device Drivers & Firmware

Device driver A system program that lets the OS talk to one specific device: it turns general I/O requests into that device's own commands. Usually runs in kernel mode (.sys files in Windows). Plug and Play: the OS detects a new device and loads its driver.
Firmware Software stored permanently in non-volatile memory (ROM, EEPROM, flash) inside hardware: BIOS/UEFI, routers, printers, SSD controllers. Updated by "flashing".
PointLegacy BIOSUEFI
Partition tableMBR: disks up to 2 TB, 4 primaryGPT: bigger disks, 128 partitions
Features16-bit, text-only setup32/64-bit, Secure Boot, mouse
Memory trick Utility keeps the PC healthy · driver lets a device talk · firmware lives inside the chip.

11Software Licences

high-yield

Proprietaryowned; source hidden; licence fee (EULA)Windows, MS Office

Free software (Richard Stallman; GNU 1983, FSF 1985) is "free as in freedom, not free beer": the four freedoms to run, study, share and modify. GPL is copyleft: modified versions must stay under the GPL. MIT, BSD and Apache licences are permissive. "Open source" as a term: OSI, 1998.

Memory trick Freeware = free beer (no price) · free software = free speech (freedom) · shareware = taste first, then pay.
Exam trap Freeware ≠ open source: Chrome is freeware, Chromium is open source. Open-source software may still be sold (Red Hat sells subscriptions and support).

Written question What is an operating system? Describe five of its functions and distinguish between multiprogramming and time-sharing. 8 marks
  1. Definition: system software that manages hardware resources and gives users and programs an interface and common services; e.g. Windows, Linux. 1
  2. Process: create, schedule, end · Memory: allocate RAM, virtual memory · File: organise, protect files · Device: I/O via drivers, spooling · Security: login, rights. 5
  3. Multiprogramming keeps several programs in RAM and switches the CPU when one waits for I/O → aim: CPU utilisation. Time-sharing gives each process a fixed time slice in turn → aim: fast response for interactive users. 2
