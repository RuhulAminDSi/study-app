## ১. সেট কী?

**সেট** হলো **স্বতন্ত্র, সু-সংজ্ঞায়িত বস্তুর সংগ্রহ**, যার উপাদানকে **এলিমেন্ট** বা **সদস্য** বলা হয়। "সু-সংজ্ঞায়িত" মানে কোনো বস্তু এতে আছে কি নেই তা নির্দিষ্টভাবে **হ্যাঁ বা না** বলা যায়। উপাদান সংখ্যা, অক্ষর, বিন্দু — এমনকি অন্য সেটও হতে পারে।

| ফর্ম | কী করে | উদাহরণ |
|---|---|---|
| **রোস্টার** (তালিকা) | প্রতিটি উপাদান একে একে তুলে ধরে | A = {2, 4, 6, 8} |
| **সেট-বিল্ডার** | উপাদানগুলোর সাধারণ **বৈশিষ্ট্য** লেখে | A = {x \| x জোড়, x < 10} |

**ক্রম ও পুনরাবৃত্তির কোনো মান নেই:** {1, 2, 3} = {3, 2, 1} = {1, 1, 2, 2}, কিন্তু (1, 2) ≠ (2, 1) — **ক্রমযুক্ত জোড়ে ক্রম গুরুত্বপূর্ণ**। |A| পড়ে "A-র **মূলতা** (কার্ডিনালিটি)": |{a, b}| = 2।

- ⚠️ **ফাঁদ:** **{জোড় সংখ্যা}** সেট **নয়** — কোন জোড় সংখ্যা তা বলা না হওয়া পর্যন্ত সেট সু-সংজ্ঞায়িত নয়। এই "সু-সংজ্থায়িত" অংশটিই পুরো সংজ্ঞা, আর পরীক্ষায় এটি বারবার আসে।
- 💡 **কৌশল:** সেট হলো **লেবেলওয়ালা একটি ঝুড়ি**: লেবেলই ঠিক করে কে ঢুকবে, আর বেরোনার ক্রম ঝুড়ির বিষয়বস্তু বদলায় না।

## ২. উপসেট গণনা: 2ⁿ ও C(n,k)

**গণনার যুক্তি।** <b>n</b> টি উপাদান একে একে দেখো; প্রতিটির জন্য ঠিক **দুটি সিদ্ধান্ত — রাখো, অথবা বাদ দাও**। দুটি সিদ্ধান্ত, n বার ⇒ **2ⁿ** টি উপসেট, যেখানে **∅ এবং A নিজেও** গোনা হয়।

| n | \|P(A)\| = 2ⁿ | সাইজ 2 | প্রকৃত উপসেট |
|---|---|---|---|
| 0 (A = ∅) | **1** | 0 | 0 |
| 2 | 4 | 1 | 3 |
| 3 | 8 | 3 | 7 |
| **4** | **16** | **6** | **15** |
| 5 | 32 | 10 | 31 |

✍ **উদাহরণ.** "সেট A-তে **4 টি উপাদান** আছে। কতটি উপসেট?" → **16**, ৮ নয়, ৪-ও নয়। **প্রকৃত** উপসেট → **15**; শূন্যসেটও বাদ দিলে → **14**। সাইজ k উপসেট = C(n,k) = n!/k!(n−k)!; n = 4 হলে সংখ্যাগুলো 4 + 6 + 4 + 1 = 15, আর ∅ যোগ করলে 16 ✓

*(ছবি: n = 0 … 5-এর জন্য ছয়টি দণ্ড, উচ্চতা 1, 2, 4, 8, 16, 32 — প্রতিটি নতুন উপাদান সংখ্যা দ্বিগুণ করে; 2ⁿ এই অধ্যায়ের আর কোনো গণনার চেয়ে দ্রুত বাড়ে।)*

## ৩. সেটের প্রকার, উপসেট ও পাওয়ার সেট

| নাম | সংজ্ঞা | উদাহরণ |
|---|---|---|
| **সসীম** / **অসীম** | নির্দিষ্ট গণনাযোগ্য সংখ্যক উপাদান, \|A\| = n / উপাদান শেষ হয় না | {1, 2, 3} / ℕ, ℤ, ℚ, ℝ |
| **শূন্য সেট** ∅ | একেবারে **কোনো** উপাদান নেই; { } বা φ লেখা হয় | ∅ = {x \| 1 = 0} |
| **একক সেট** | **ঠিক একটি** উপাদান | {a} |
| **সমান সেট** | একই উপাদান, যেকোনো ক্রমে: A = B | {1, 2, 3} = {3, 2, 1} |
| **উপসেট** A ⊆ B | A-র প্রতিটি উপাদান B-তে আছে | {1, 2} ⊆ {1, 2, 3} |
| **প্রকৃত উপসেট** A ⊂ B | A ⊆ B **এবং** A ≠ B | {1, 2} ⊂ {1, 2, 3} |
| **সার্বজনীন সেট** U | আলোচনার অধীনে প্রতিটি উপাদান এতে আছে | U = {1, 2, 3, 4, 5, 6} |
| **পূরক** A′ | U-তে আছে কিন্তু A-তে নেই: A′ = U − A | U = {1,2,3,4}, A = {1,2} ⇒ {3,4} |

**পাওয়ার সেট।** P(A) = { X | X ⊆ A } — A-র **সব** উপসেটের সংগ্রহ। তাই **|P(A)| = 2^|A|** এবং প্রতিটি সসীম A-র জন্য **|P(A)| > |A|** (কান্টর)। প্রান্তিক উদাহরণ: |P(∅)| = 1 এবং P({a}) = { ∅, {a} }, আর P(A) নিজেও একটি সেট হওয়ায় P(P(A))-ও আছে।

- 💡 **কৌশল:** **⊆ মানে "সবগুলো আছে", ⊂ মানে "সবগুলো আছে আর বাইরে আরও কিছু"**। প্রতিটি সেট নিজের উপসেট (A ⊆ A) আর ∅ প্রতিটি সেটের উপসেট (∅ ⊆ A): ∅ হলো **সবচেয়ে ছোট** উপসেট, U সবচেয়ে বড়।
- ✍ **উদাহরণ (A = {1, 2, 3, 4})।** মোট 16 · ঠিক 2 উপাদান → 6 · ঠিক 3 → 4 · প্রকৃত → 15 · প্রকৃত ও অশূন্য → 14। যেহেতু |P(A)| = 16 > 4, তাই A ⊂ P(A) কঠোরভাবে, আর সবচেয়ে বড় উপসেট হলো A নিজে।
- ⚠️ **ফাঁদ:** (i) ∅ ⊂ {x} সত্য, কিন্তু {x} ⊂ ∅ **মিথ্যা** — ∅-এ বাদ দেওয়ার মতো উপাদানই নেই। (ii) শূন্যসেট {0} বা {∅}-এর সমান **নয়**। (iii) সাধারণ পরীক্ষার ভাষায় "উপসেট" কখনো "প্রকৃত উপসেট" বোঝায় না। (iv) "সমান সেট" মানে ঠিক একই উপাদান, অর্থাৎ A = B — "উপসেট" শব্দটির সঙ্গে গুলিয়ে ফেলবে না।
- 📌 **আইটি সংযোগ:** পাওয়ার সেট কেবল পরীক্ষার বিষয় নয়: **n-বিট ফ্ল্যাগ শব্দের ঠিক 2ⁿ টি সেটিং** থাকে, আর "এই 32 টি পারমিশনের কোনগুলো চালু?" প্রশ্নটি আসলে পাওয়ার সেটের প্রশ্ন। একই গণনা একটি টেবিলে যে n টি boolean শর্ত থাকে তার সর্বোচ্চ 2ⁿ টি আলাদা ফলাফল-আকৃতি দেয়, তাই শর্ত বাড়লে প্রশ্নের সংখ্যা দ্রুত বাড়ে।

*(ছবি: U ⊃ B ⊃ A ধাপে ধাপে বাঁকানো বাক্স, A-র ভেতরে সবুজ বিন্দু — একক সেট {a}; উল্টো দিকে পড়লে লেখা হয় B ⊃ A।)*

## ৪. সেট অপারেশন ও সেট অ্যালজেবরার আইন

| অপারেশন | প্রতীক ও সংজ্ঞা | গণনা করা উদাহরণ |
|---|---|---|
| **ইউনিয়ন** | A ∪ B = {x \| x ∈ A **অথবা** x ∈ B} | {1,2} ∪ {2,3} = {1,2,3} |
| **ইন্টারসেকশন** | A ∩ B = {x \| x ∈ A **এবং** x ∈ B} | {1,2} ∩ {2,3} = {2} |
| **ডিফারেন্স** | A − B = {x \| x ∈ A এবং x ∉ B} | {1,2,3} − {2,3} = {1} |
| **পূরক** | A′ = {x \| x ∈ U এবং x ∉ A} — U − A | U = {1,2,3,4}, A = {1,2} ⇒ {3,4} |
| **কার্টেশিয়ান প্রোডাক্ট** | A × B = {(a, b) \| a ∈ A, b ∈ B} | {1,2} × {x,y} = {(1,x),(1,y),(2,x),(2,y)} |

| আইন | বিবৃতি |
|---|---|
| সমবিন্যাসী | A ∪ B = B ∪ A · A ∩ B = B ∩ A |
| সংযুক্তিমতা | (A ∪ B) ∪ C = A ∪ (B ∪ C) · ∩ একইভাবে |
| বণ্টনমূলক | A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) |
| একক | A ∪ ∅ = A · A ∩ U = A |
| পূরক | A ∪ A′ = U · A ∩ A′ = ∅ |
| অভিজাতা | A ∪ A = A · A ∩ A = A |
| অন্তর্বর্তীতা | (A′)′ = A |
| শোষণ | A ∪ (A ∩ B) = A · A ∩ (A ∪ B) = A |
| **ডি মরগান** | **(A ∪ B)′ = A′ ∩ B′ · (A ∩ B)′ = A′ ∪ B′** |

**মূলতার সূত্র।** **|A ∪ B| = |A| + |B| − |A ∩ B|**। A ∩ B = ∅ হলে (**পৃথক**) এটি সরে যায় এবং হয় **|A| + |B|**। তিন সেটে সাধারণীকরণ করলে অন্তর্ভুক্তি-বিশেষ নিয়ম পাওয়া যায়, যা আলাদা লেসনের বিষয়।

✍ **আইন দিয়ে সরলীকরণ।** ডি মরগান অনুযায়ী (A ∪ B)′ = A′ ∩ B′, আর ((A ∪ B)′)′ অন্তর্বর্তীতা অনুযায়ী ফিরে এসে A ∪ B দেয়। আবার A − B = A ∩ B′, তাই {1,2,3} − {2,3} = {1,2,3} ∩ {1} = {1}।

- ⚠️ **ফাঁদ:** A − B ও B − A **ভিন্ন সেট**, তাই ডিফারেন্স সমবিন্যাসী **নয়**: {1,2,3} − {2,3} = {1} কিন্তু {2,3} − {1,2,3} = ∅। আর A × B ≠ B × A, যদিও |A × B| = |B × A|।

*(ছবি: U-র ভেতরে দুটি বৃত্ত, মাঝের লেন্স অংশটি লাল রঙে ছায়া করা ও লেখা A ∩ B; বাকি অংশে A − B, B − A ও (A ∪ B)′ চিহ্নিত।)*

## ৫. সম্পর্ক হলো A × B-এর একটি উপসেট

A থেকে B-তে একটি **সম্পর্ক R** হলো **A × B-এর যেকোনো উপসেট**, লেখা হয় **R ⊆ A × B**। এর উপাদান হলো **ক্রমযুক্ত জোড়** (a, b), যেখানে a ∈ A, b ∈ B, পড়া হয় "a সম্পর্কিত b-র সঙ্গে"। R ⊆ A × A হলে তা A-র উপর **দ্বিচারি সম্পর্ক**; দুই সেট একই হলে এই পরিস্থিতি তৈরি হয়।

**দুটি গণনার ফলাফল**

- **|A × B| = |A| · |B|** — জোড়গুলো একটি পূর্ণ গ্রিড, m সারি বাই n কলাম।
- **A→B সম্পর্ক সংখ্যা = 2^(|A|·|B|)** — সম্পর্ক যেকোনো উপসেট, আর m·n উপাদানের সেটের উপসেট সংখ্যা 2^(m·n)।
- একটি n-উপাদান সেটে: |A × A| = n², তাই **2^(n²) টি দ্বিচারি সম্পর্ক**।

✍ **যে গণনাগুলো বারবার আসে।** (ক) |A| = 3: |A × A| = 9, তাই A-র উপর **2⁹ = 512** টি সম্পর্ক। (খ) |A| = 3, |B| = 4: |A × B| = 12, তাই 2¹² = **4096** টি সম্পর্ক। (গ) |A| = 4: **2¹⁶ = 65 536**। সংখ্যা বিস্ফোরিত কারণ সূচক n², n নয়।

⚠️ **ফাঁদ:** **প্রতিটি সম্পর্ক ফাংশন নয়**। একই প্রথম উপাদানের জন্য (1, x) **এবং** (1, y) দুটোই থাকতে পারে; আবার ফাংশন কোডোমেইনের একাংশ খালি রাখতে পারে। আর R ⊆ A × B মানে R = A × B **নয়** — সর্বজনীন সম্পর্ক কেবল 2^(m·n) টির একটি।

### একই সম্পর্ক তিনভাবে লেখা যায়

1. **ক্রমযুক্ত জোড়ের সেট** — R = {(1, x), (2, y)}।
2. **ম্যাট্রিক্স** M_R = [m_ij], সারি = A, কলাম = B, m_ij = 1 যদি (a_i, b_j) ∈ R, নয়তো 0।
3. **ডাইগ্রাফ** — A ও B-র প্রতিটি উপাদানে একটি করে শীর্ষবিন্দু, আর R-এর প্রতিটি জোড়ের জন্য নির্দেশিত প্রস্থ a_i → b_j। **A-র উপর** সম্পর্কে একটিই শীর্ষবিন্দু সেট থাকে, আর (a, a) আঁকা হয় **স্ব-লূপ** হিসেবে।

✍ **ম্যাট্রিক্স রূপ।** R = {(1,x), (2,y)}, যেখানে সারিতে 1, 2, 3 এবং কলামে x, y — তবে M_R = [ [1,0], [0,1], [0,0] ]। সারি i, কলাম j-তে 1 মানে ঠিক (a_i, b_j) ∈ R; কোনো ঘরে 1 না থাকলে সেই জোড়টি সম্পর্কে নেই। **A-র উপর** সম্পর্কে একই অ্যারে সারি ও কলাম দুটোর জন্য বসে, তাই **কোণাকার অংশগুলোই রিফ্লেক্সিভতার পরীক্ষা**: সব ঘরে 1 হলে রিফ্লেক্সিভ, একটিও শূন্য হলে নয়।

- 📌 **আইটি সংযোগ:** দুই সেট আলাদা হলে সম্পর্কটি "A থেকে B-তে", আর একই হলে সেটি "A-র উপর" সম্পর্ক — পরীক্ষার ভাষায় এই পার্থক্যই প্রায়ই প্রশ্ন। ডেটাবেসে join শর্ত দুটি টেবিলের মধ্যে একটি সম্পর্ক, আর foreign key সেই সম্পর্ক ঘোষণা করে। একটি functional dependency বলে সম্পর্কটি ইনজেক্টিভ, যার সহজ অর্থ "কোনো দুটি সারি একই key ভাগ করে না"।

*(ছবি: 3 × 2 গ্রিড — A-র সারি 1, 2, 3 বনাম B-র কলাম x, y — R = {(1,x), (2,y)}-এর দুই ঘর সবুজে চিহ্নিত; গ্রিডে 6 ঘর, তাই 2⁶ = 64 টি সম্পর্ক।)*

## ৬. ছয়টি ধর্ম, প্রতিটির প্রত্যাখ্যানসহ

সব উদাহরণ A = {1, 2, 3}-এর উপর।

| ধর্ম | নির্দিষ্ট বিবৃতি | প্রত্যাখ্যান |
|---|---|---|
| **রিফ্লেক্সিভ** | (a, a) ∈ R **প্রতিটি** a ∈ A-র জন্য | R = {(1,2),(2,3)} — (3,3) নেই |
| **রিফ্লেক্সিভ নয়** (ইররিফ্লেক্সিভ) | (a, a) ∉ R প্রতিটি a ∈ A-র জন্য | R = {(1,1)} — (2,2) আছে |
| **প্রতিসম** | (a, b) ∈ R ⇒ (b, a) ∈ R | R = {(1,2),(1,1)} — (2,1) নেই |
| **প্রতিসম-বিরোধী** | (a, b) ∈ R এবং (b, a) ∈ R ⇒ a = b | R = {(1,2),(2,1)} — দুই দিকেই, অথচ 1 ≠ 2 |
| **বিঅন্বয়ী** | (a, b) ∈ R এবং (b, c) ∈ R ⇒ (a, c) ∈ R | R = {(1,2),(2,3)} — (1,3) বাধ্য, নেই |
| **অপ্রতিসম** | (a, b) ∈ R এবং a ≠ b ⇒ (b, a) ∉ R | R = {(1,2),(2,1)} — বরং প্রতিসমতা আছে |

| সম্পর্ক | রিফ্লেক্সিভ | প্রতিসম | প্রতিসম-বিরোধী | বিঅন্বয়ী |
|---|---|---|---|---|
| ∅ (খালি সেটের উপর, খালি নয়) | ✗ | ✓ | ✓ | ✓ |
| A × A (সর্বজনীন) | ✓ | ✓ | ✗ | ✓ |
| {(a, a) \| a ∈ A} (অভিব্যতি) | ✓ | ✓ | ✓ | ✓ |
| {(a, b) \| a < b}, ℕ-এর উপর | ✗ | ✗ | ✓ | ✓ |
| {(a, b) \| a, b-কে ভাগ করে}, ℤ⁺-এর উপর | ✓ | ✗ | ✓ | ✓ |

- ⚠️ **নম্বর কাড়ানো পার্থক্য:** **প্রতিসম** ও **প্রতিসম-বিরোধী** **বিপরীত নয়**, কোনোটিই অপরটিকে ধরে না। R = {(1,2),(2,1)} প্রতিসম-বিরোধিতা ভাঙে কিন্তু **প্রতিসম**। R = {(1,2)} প্রতিসম-বিরোধী, অথচ **প্রতিসম নয়**। "প্রতিসম"-এর প্রকৃত বিপরীত হলো "অপ্রতিসম"।
- 💡 **কৌশল:** **প্রতিসম = তির উল্টে যায়; প্রতিসম-বিরোধী = অক্রম জোড়ায় সর্বোচ্চ একটি তির**। আরও মুখস্থযোগ্য: খালি সেটের উপর ∅ হলো প্রতিসম, প্রতিসম-বিরোধী ও বিঅন্বয়ী, কিন্তু **রিফ্লেক্সিভ নয়**; আর A × A রিফ্লেক্সিভ, প্রতিসম ও বিঅন্বয়ী, কিন্তু **প্রতিসম-বিরোধী নয়**। চারটিই পাস করে একমাত্র সম্পর্ক হলো অভিব্যতি সম্পর্ক।

✍ **ধর্মগুলো ধাপে ধাপে যাচাই।** {1, 2, 3}-এর উপর R = {(1,1),(2,2),(3,3),(1,2),(2,3),(1,3)}। রিফ্লেক্সিভ: তিনটি লূপ আছে ✓। প্রতিসম: (1,2) আছে কিন্তু (2,1) নেই ✗। প্রতিসম-বিরোধী: কোনো জোড় দুই দিকেই নেই ✓। বিঅন্বয়ী: (1,2),(2,3) থেকে (1,3) আছে ✓, আর (1,1),(1,2) থেকে (1,2) আছে ✓। তাই এটি **আংশিক ক্রম**, সমতুত্ব সম্পর্ক নয় (প্রতিসমতা ভাঙে)।

*(ছবি: তিনটি হলুদ শীর্ষবিন্দু 1, 2, 3, প্রতিটিতে লাল স্ব-লূপ এবং নীল তির 1 → 2 ও 2 → 1; ক্যাপশন "সবখানে লূপ + 1↔2 ⇒ সমতুত্ব"। রিফ্লেক্সিভতা মানে প্রতিটি শীর্ষবিন্দুতে লূপ; বিঅন্বয়িতা মানে দুই ধাপের প্রতিটি পথের জন্য সংক্ষিপ্ত তির।)*

## ৭. সমতুত্ব সম্পর্ক ও আংশিক ক্রম

**সমতুত্ব সম্পর্ক** হলো **রিফ্লেক্সিভ + প্রতিসম + বিঅন্বয়ী**, এর বেশি কিছু নয়, কমও কিছু নয়। এর শ্রেণি [a] = { x ∈ A | (a, x) ∈ R } খালি নয়, পরস্পর বিচ্ছিন্ন, এবং সবগুলোর ইউনিয়ন A। **সমতুত্ব সম্পর্ক ⇔ বিভাজন, এক-এক।**

✍ **{1,2,3}-এর উপর R = {(1,1),(2,2),(3,3),(1,2),(2,1)}।** রিফ্লেক্সিভ: তিনটি লূপই আছে। প্রতিসম: (1,2) ও (2,1) দুটোই আছে। বিঅন্বয়ী: (1,2),(2,1) থেকে (1,1) ✓ এবং (2,1),(1,2) থেকে (2,2) ✓। তাই R একটি **সমতুত্ব সম্পর্ক**, শ্রেণি **{1, 2}** ও **{3}** — এবং এটি **আংশিক ক্রম নয়**, কারণ (1,2) ও (2,1) দুটোই থাকায় প্রতিসম-বিরোধিতা ভাঙে।

**কেন শ্রেণিগুলো বিভাজন দেয়।** যেকোনো a ∈ A নিয়ে [a] বানাও। কোনো শ্রেণি খালি হয় না (রিফ্লেক্সিভতা); দুটি শ্রেণি কখনো মেশে না (না হলে (a, b) ও (b, a) দুটোই থাকত, আর প্রতিসমতা ও প্রতিসম-বিরোধিতা একসঙ্গে ভাঙত); প্রতিটি উপাদান অন্তত একটি শ্রেণিতে পড়ে (বিঅন্বয়িতা)। উল্টো দিকে, যেকোনো বিভাজন থেকে "একই খণ্ডে হলে সম্পর্কিত" সম্পর্ক বানালে সেটি সমতুত্ব সম্পর্ক — তাই দুটির সংখ্যা সবসময় সমান।

**ছোট সেটে সমতুত্ব সম্পর্কের সংখ্যা = বেল সংখ্যা।** এগুলো এক-এক বিভাজনের সঙ্গে মেলে, তাই সংখ্যা B_n: **B₁ = 1 · B₂ = 2 · B₃ = 5 · B₄ = 15 · B₅ = 52**। ৪-উপাদান সেটে 15 = 1 (এক খণ্ড) + 7 (দুই) + 6 (তিন) + 1 (চার)।

**আংশিক ক্রম (পসেট)** হলো **রিফ্লেক্সিভ + প্রতিসম-বিরোধী + বিঅন্বয়ী**। "প্রতিটি দুটি উপাদান তুলনীয়" যোগ করলে **পূর্ণ ক্রম** হয়। হাসে ডায়াগ্রামে লূপ বাদ দিয়ে কেবল উপরের দিকের **ঢাকা** তিরগুলো রাখা হয়।

✍ **ℤ-এ 3 মডুলো সাম্যকতা।** a R b যদি ও কেবল যদি 3, (a − b) কে ভাগ করে। রিফ্লেক্সিভ: a − a = 0 = 3·0। প্রতিসম: a − b = 3m ⇒ b − a = 3(−m)। বিঅন্বয়ী: 3m + 3k = 3(m + k)। শ্রেণি [0] = {…, −6, 0, 3, 6, …}, [1] = {…, −2, 1, 4, 7, …}, [2] = {…, −1, 2, 5, 8, …} — পরস্পর বিচ্ছিন্ন, ইউনিয়ন ℤ।

- 💡 **কৌশল:** দুটিই নামের কাজ থেকে এসেছে: সমতুত্ব একে অন্যকে সমান দেখা জিনিসগুলোকে **শ্রেণিতে** জোগ করে; আংশিক ক্রম দেয় **আংশিক ক্রমাঙ্ক**, যেখানে কিছু সাজানো আছে, কিছু তুলনীয় নয়। **P(A)-তে ⊆ সবসময় আংশিক ক্রম** — আদর্শ উদাহরণ।
- ⚠️ **ফাঁদ:** একটি সম্পর্ক **যেকোনো** সময়ই সমতুত্ব সম্পর্ক **এবং** আংশিক ক্রম হয়, যখন প্রতিটি শ্রেণি একক, অর্থাৎ R হলো অভিব্যতি সম্পর্ক। আর "প্রতিসম নয়" বললে সেটি প্রতিসম-বিরোধী হয়ে যায় **না** — প্রতিসম-বিরোধিতা আলাদা পরীক্ষা, নিয়মের অনিচ্ছা নয়।

*(ছবি: পাশাপাশি দুটি সবুজ গোলাকার বাক্স {1, 2} ও {3, 4}, ক্যাপশন "একটি বিভাজন ⇒ ঠিক একটিই সমতুত্ব সম্পর্ক"; আরেকটি ছোট হাসে ডায়াগ্রামে P({1,2})-এর উপরে ∅, নিচে {1} ও {2}, দুটির মধ্যে কোনো তির নেই — ক্যাপশন "{1} ও {2} তুলনীয় নয়"।)*

## ৮. ফাংশন: ডোমেইন, কোডোমেইন, রেঞ্জ

একটি **ফাংশন** f: A → B হলো A থেকে B-র এমন সম্পর্ক যেখানে **A-র প্রতিটি উপাদান জোড়ের প্রথম উপাদান হিসেবে ঠিক একবার** আসে। সমতুলপে, (a₁, b₁), (a₂, b₂) ∈ R এবং a₁ = a₂ হলে b₁ = b₂। B-র কোন উপাদান কতবার হিট হয়, তা বলা হয়নি।

| নাম | এটি কী | কোডে |
|---|---|---|
| **ডোমেইন** | ফাংশনটি ঘোষণা করা পুরো সেট A | যেসব x নিয়ে কাজ করতে হবে |
| **কোডোমেইন** | ঘোষিত লক্ষ্য সেট B | সিগনেচার যা প্রতিশ্রুতি দেয় |
| **রেঞ্জ** / প্রতিচ্ছবি | f(A) = { f(a) \| a ∈ A } ⊆ B — শুধু যে মানগুলো সত্যিই পাওয়া যায় | যে মানগুলো সত্যিই দেখা যায় |
| **ধ্রুব** ফাংশন | প্রতিটি ইনপুটে একটি নির্দিষ্ট মান; রেঞ্জ একক সেট | সবসময় একই ধ্রুব মান |
| **সম্পূর্ণ / আংশিক** | সম্পূর্ণ = ডোমেইনের প্রতিটির প্রতিচ্ছবি আছে; আংশিকে কারও থাকে না | null নেই |

| নাম | পরীক্ষা | সহজ কথায় |
|---|---|---|
| **ইনজেক্টিভ** (এক-এক) | f(a₁) = f(a₂) ⇒ a₁ = a₂ | দুই ইনপুট একই আউটপুট পায় না |
| **সার্জেক্টিভ** (onto) | ∀ b ∈ B ∃ a ∈ A : f(a) = b | কোনো আউটপুট খালি থাকে না |
| **বাইজেক্টিভ** | উপরের দুটোই | নিখুঁত জোড়া |

**সসীম সেটের গণনা-সংক্রান্ত তথ্য**

- **|A| ≤ |B|** ইনজেক্টিভ A→B-এর জন্য **প্রয়োজনীয়**।
- **|A| ≥ |B|** সার্জেক্টিভ A→B-এর জন্য **প্রয়োজনীয়**।
- বাইজেক্টিভের জন্য **|A| = |B|** লাগে, তখন রেঞ্জ = কোডোমেইন।

তাই |A| &gt; |B| হলে ফাংশন থাকে, কিন্তু সে **ইনজেক্টিভ হতে পারে না**; |A| &lt; |B| হলে সে **সার্জেক্টিভ হতে পারে না**।

- ⚠️ **ফাঁদ:** **ইনজেক্টিভ ও সার্জেক্টিভ স্বাধীন**। f: {1,2,3} → {x,y} অবশ্যই সার্জেক্টিভ কিন্তু কখনো ইনজেক্টিভ নয়। ধ্রুব ফাংশন |B| = 1 হলেই সার্জেক্টিভ, আর |A| = 1 হলেই ইনজেক্টিভ।

*(ছবি: দুটি ম্যাপিং ডায়াগ্রাম — A = {1,2} থেকে B = {x,y,z}-তে দুটি সবুজ তির (ইনজেক্টিভ, onto নয়), এবং A = {1,2,3} থেকে B = {x,y}-তে তিনটি তির, যার দুটো x-এ পড়ে (onto, ইনজেক্টিভ নয়)।)*

## ৯. সংযোগ, বিপরীত, সমতবর্তী — ও ফাংশন গণনা

**সংযোগ।** ধরি g: A → B এবং f: B → C। তবে **(f ∘ g)(x) = f(g(x))**, একটি A → C ফাংশন। ডান থেকে বাম পড়ো: **প্রথমে g, পরে f** কাজ করে। f ∘ g-এর ডোমেইন হলো g-এর ডোমেইন। সংযোগ **সংযুক্তিমতা** মেনে চলে, **সমবিন্যাসী নয়**।

**বিপরীত ও সমতবর্তী।** **সমতবর্তী** ম্যাপ I_A(x) = x কিছুই বদলায় না। f: A → B **বিপরীতযোগ্য ⇔ বাইজেক্টিভ**; তখন f⁻¹: B → A থাকে এবং **f⁻¹ ∘ f = I_A এবং f ∘ f⁻¹ = I_B**। আকারে f⁻¹(y) = x যখন f(x) = y।

**|A| = m, |B| = n হলে A → B ফাংশন গণনা**

| ধরন | সংখ্যা |
|---|---|
| সব ফাংশন | **n^m** |
| ইনজেক্টিভ | **n(n−1)···(n−m+1)** = n!/(n−m)! |
| সার্জেক্টিভ | **n! · S(m, n)**, S = দ্বিতীয় ধরনের স্টার্লিং সংখ্যা |
| বাইজেক্টিভ | **n!** (শুধু m = n হলে) |

✍ **|A| = 3, |B| = 4।** ৩ টি ইনপুটের প্রতিটি স্বাধীনভাবে ৪ টি আউটপুটের যেকোনোটি বাছে ⇒ **4³ = 64** টি ফাংশন। (24 = 4·3·2 শুধু ইনজেক্টিভগুলো গোনে; 81 = 3⁴ হতো ফাংশন **B → A**।) সার্জেক্টিভ: 0, কারণ ৩ ইনপুটে ৪ আউটপুট ঢাকে না। বাইজেক্টিভ: 0।

✍ **বিপরীত ও সংযোগ।** f(x) = 2x + 3। ধরি y = 2x + 3 ⇒ x = **(y − 3)/2**, তাই f⁻¹(x) = (x − 3)/2, আর f((x − 3)/2) = x দিয়ে যাচাই হয়। খেয়াল করো 1/(2x + 3) হলো **বিপরীতক**, কখনো বিপরীত ফাংশন নয়। f(x) = 2x + 1 ও g(x) = x² হলে (f ∘ g)(x) = 2x² + 1 কিন্তু (g ∘ f)(x) = (2x + 1)² — **সমান নয়**।

✍ **সংযুক্তিমতা।** (f ∘ g) ∘ h = f ∘ (g ∘ h) সবসময় সত্য, কারণ (f ∘ g)(h(x)) = f(g(h(x)))। কিন্তু f ∘ g ≠ g ∘ f, এমনকি দুটো বাইজেক্টিভ হলেও। f(x) = x + 1 ও g(x) = x² হলো সেই বিশেষ ধরনের ফাংশন, যেগুলো পরস্পরের সঙ্গে বদলায়।

- 💡 **কৌশল:** **∘ মানে "তারপর": f ∘ g মানে "g-এর পরে f"**, ঠিক যেমন বন্ধনও লেখে f(g(x))। g-র কোডোমেইন f-এর ডোমেইনে না বসলে f ∘ g লেখাই অবৈধ।
- ⚠️ **ফাঁদ:** (i) (f ∘ g)(x) হলো **f(g(x))**, g(f(x)) নয় — একটি নির্দিষ্ট x দিয়ে যাচাই করো। (ii) বাইজেক্টিভের সংযোগ বাইজেক্টিভ, ইনজেক্টিভের সংযোগ ইনজেক্টিভ, কিন্তু মিশ্র ক্ষেত্রে নিশ্চয়তা নেই। (iii) কোনো সম্পর্কের বিপরীত ফাংশন থাকে শুধু তখনই, যখন সেটি **বাইজেক্টিভ** — শুধু ইনজেক্টিভ হলে নয়।
- 📌 **আইটি সংযোগ:** **f⁻¹** বিনামূল্যে পাওয়া যায় না: ডেটাবেস join, ইনডেক্স lookup আর একটি ফাংশন কল — সবই সময় খরচ করে। তাই বিপরীত ফাংশন হ্যাশ টেবিলে ক্যাশ করা হয়, আর হ্যাশ ম্যাপের **put** ফাংশন f গড়ে যখন **get** চলায় f⁻¹।

## লিখিত প্রশ্ন (৮ নম্বর)

Integer-এর সেট ℤ-এ a R b যদি ও কেবল যদি 3, (a − b) কে ভাগ করে। প্রমাণ করো R একটি সমতুত্ব সম্পর্ক এবং এর শ্রেণিগুলো লেখো। তারপর A = {1, 2, 3}-এর উপর এমন একটি সম্পর্ক দাও যা রিফ্লেক্সিভ ও প্রতিসম কিন্তু বিঅন্বয়ী নয়।

**মডেল উত্তর:**

1. **রিফ্লেক্সিভ (২)** — a − a = 0 = 3·0, তাই 3, a − a কে ভাগ করে এবং a R a।
2. **প্রতিসম (২)** — a − b = 3m হলে b − a = 3(−m), আর −m একটি integer, তাই b R a।
3. **বিঅন্বয়ী (২)** — a − b = 3m ও b − c = 3k হলে a − c = 3(m + k), তাই a R c; ফলে R একটি **সমতুত্ব সম্পর্ক**।
4. **শ্রেণি (২)** 3 দিয়ে ভাগ করে ভাগশেষ অনুযায়ী: [0] = {…, 0, 3, 6, …}, [1] = {…, 1, 4, 7, …}, [2] = {…, 2, 5, 8, …} (ঋণাত্মকসহ) — পরস্পর বিচ্ছিন্ন, ইউনিয়ন ℤ, অর্থাৎ একটি বিভাজন।
5. **প্রত্যাখ্যান** — {1,2,3}-এর উপর R = {(1,1),(2,2),(3,3),(1,2),(2,1)} নাও। এটি রিফ্লেক্সিভ (তিনটি লূপ) ও প্রতিসম (1 ↔ 2 দুই দিকেই), কিন্তু **বিঅন্বয়ী নয়**: (1,2) ও (2,3) থেকে (1,3) বাধ্য, যা নেই।

**আরও অনুশীলন (লিখিত):** ① ৪-উপাদান সেটের ১৫টি বিভাজন তালিকা করো এবং প্রতিটি থেকে সমতুত্ব সম্পর্ক বানাও ② দেখাও যে "a R b যদি a − b, 5 দ্বারা বিভাজ্য" হলে পাঁচটি শ্রেণি ③ ℕ-এর উপর {(a,b) | a ≤ b} সম্পর্কটি রিফ্লেক্সিভ / প্রতিসম / প্রতিসম-বিরোধী / বিঅন্বয়ী — কোন কোন — বিচার করো ④ দেখাও ℕ থেকে ℤ-এর যথেষ্ট ছোট উপসেটে কোনো বাইজেকশন নেই, ও |A| ≤ |B| শর্তের সঙ্গে যুক্ত করো।
