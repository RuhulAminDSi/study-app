## ১. প্রমাণ কী

**গাণিতিক যুক্তি** হল প্রদত্ত বিবৃতি বা **প্রতিজ্ঞা** থেকে সিদ্ধান্তে পৌঁছানোর যৌক্তিক প্রক্রিয়া। একটি **প্রমাণ** হলো এমন যুক্তি যেখানে প্রতিটি ধাপ **বৈধ**; প্রতিজ্ঞা যেকোনো অবস্থাতেই সত্য হলেও সিদ্ধান্ত টিকে থাকলে তাকে **বৈধ**, আর প্রতিজ্ঞাগুলোও সত্য থাকলে তাকে **সুস্থ** (sound) বলে। **প্রমাণে প্রতিটি প্রযোজ্য ক্ষেত্রই ধরতে হয়, যে কয়েকটি পরীক্ষা করে দেখলেন তা নয়।**

| পদ্ধতি | যুক্তির আকৃতি | কখন লাগে |
|---|---|---|
| **সরাসরি প্রমাণ** | P নিয়ম থেকেই প্রতিজ্ঞা থেকে পাওয়া যায় | বেশিরভাগ উপপাদ্য |
| **অসঙ্গতি প্রমাণ** | **¬P ধরে নিন**, অসম্ভবতায় নিয়ে যান | "এরূপ কিছু নেই" |
| **কন্ট্রাপজিটিভ** | P → Q প্রমাণ করা হয় ¬Q → ¬P হিসেবে — **সমতুল্য** | প্রতিজ্ঞা সরাসরি না বলা যায় |
| **ইন্ডাকশন** | P(1) সত্য, এবং সব k-এর জন্য P(k) ⇒ P(k+1) | ℕ সম্পর্কিত বিবৃতি |
| **বিপরীত উদাহরণ** | একটি ব্যর্থ ক্ষেত্রই সাধারণ বিবৃতি ভাঙে | খণ্ডন, প্রমাণ নয় |

**সুস্থ ⇒ বৈধ, উল্টোটি কখনো নয়।** বৈধতা হলো *ধাপগুলোর* গুণ, সুস্থতা প্রতিজ্ঞাগুলোরও। একটি যুক্তি বৈধ হয়েও মিথ্যা সিদ্ধান্তে পৌঁছাতে পারে, যদি কোনো প্রতিজ্ঞা মিথ্যা হয়।

**কী প্রতিজ্ঞা গণ্য হয়।** **সংজ্ঞা**, যা প্রমাণের ভেতরে খুলে লেখা যায় · **আক্সিওম**, যে শাখার গণিতে তা ধরা নেওয়া আছে · **লেম্মা**, আগেই প্রমাণ করা · বিবৃতির নিজের **অনুকল্প**। যা **গণ্য হয় না**: "এটা সুপরিচিত", "চিত্র থেকে স্পষ্ট", "অল্প ক্ষেত্রে মিলেছে"। প্রমাণ ছাড়া লেম্মার আশ্রয় নেওয়া মান নম্বর চুরিরই নামান্তর।

- ⚠️ **ফাঁদ:** **বিপরীত উদাহরণ খণ্ডন করে, কখনো প্রমাণ করে না**; আর একটি সত্য উদাহরণ কখনো সাধারণ বিবৃতি প্রমাণ করে না। "n = 1 … ১০ পর্যন্ত মিলেছে, তাই সব n-এর জন্য মিলবে" — এটি **প্রমাণ নয়**; ইন্ডাকশন তো এই ফাঁকটাই পূরণ করতেই বানানো।
- 💡 **কৌশল — প্রশ্নের আকৃতি থেকে পদ্ধতি চেনা:** "প্রতিটি n ≥ 1-এর জন্য …" → **ইন্ডাকশন** · "এরূপ কিছু নেই" বা "দেখাও যে … নয়" → **অসঙ্গতি** · "যদি … তবে …" → **কন্ট্রাপজিটিভ** · "এমন কোনো আছে কি?" → **বিপরীত উদাহরণ** খুঁজে বের করো।

**প্রতিটি লেখা প্রমাণের চার অংশ:** (১) **দাবিটি লেখো** — পরিমাণসহ পুরো বিবৃতি ("প্রতিটি পূর্ণসংখ্যা n ≥ 1-এর জন্য") · (২) **প্রতিজ্ঞা লেখো** — সংজ্ঞা, আক্সিওম ও প্রমাণিত লেম্মা · (৩) **ধাপে ধাপে নির্গমন** — প্রতিটি লাইন যাচাইযোগ্য · (৪) **সিদ্ধান্ত দাও** — ব্যবহৃত নীতির নাম উল্লেখ করো।

## ২. গাণিতিক আরোহ: দুটি অংশ

**গাণিতিক আরোহ** প্রাকৃতিক সংখ্যা সম্পর্কিত বিবৃতি প্রমাণের কৌশল, যা নির্ভর করে একটি মাত্র নীতির উপর — **গাণিতিক আরোহের নীতি**: যদি P(1) সত্য হয় **এবং** প্রতিটি পূর্ণসংখ্যা k ≥ 1-এর জন্য P(k) ⇒ P(k+1) হয়, তবে P(n) প্রতিটি n ≥ 1-এর জন্য সত্য। দুটো অংশই অপরিহার্য — কেবল **ভিত্তি ক্ষেত্র** কিছুই প্রমাণ করে না, আর কেবল **আরোহ ধাপ** কিছু থেকেই শুরু হয় না।

| অংশ | যা লিখতে হবে | বাদ পড়লে |
|---|---|---|
| **১. ভিত্তি ক্ষেত্র** (n = 0 বা 1) | "n = 1-এর জন্য P(1) **সত্য**।" সংখ্যায় মিলিয়ে দেখো। | সিঁড়ির নিচতলা নেই |
| **২. আরোহ ধাপ** | "k ≥ 1 **যেকোনো** এবং **P(k) ধরে নিন**; তবে P(k+1) দেখান।" | একটি ক্ষেত্র প্রমাণ |
| **৩. সিদ্ধান্ত** | "গাণিতিক আরোহের নীতি অনুযায়ী P(n) সব n ≥ 1-এর জন্য সত্য।" | নীতির নামই হারায় |

| যে বিবৃতি ইন্ডাকশনে প্রমাণ করতে বলা হতে পারে | ভিত্তি | ধাপের আকৃতি |
|---|---|---|
| 1 + 2 + … + n = n(n+1)/2 | **n = 1** | দুই পাশে (k+1) পদ যোগ |
| 1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1 | **n = 0** | বাম পাশ হুবহু দ্বিগুণ |
| প্রতিটি n ≥ 1-এর জন্য n² ≥ n | **n = 1** | (k+1)² = k² + 2k + 1 ≥ k² + k |
| প্রতিটি n ≥ 1-এর জন্য n(n+1) জোড় | **n = 1** | (k+1)(k+2) = k(k+1) + 2(k+1) |
| প্রতিটি n ≥ 1-এর জন্য n ∣ n! | **n = 1** | (k+1)! = (k+1) · k! |
| প্রতিটি n ≥ 0-এর জন্য 2ⁿ ≥ n + 1 | **n = 0** | 2 · 2ᵏ ≥ 2k + 2 ≥ k + 2 |

**ভিত্তি ক্ষেত্র কীভাবে বুঝবে।** n-এর প্রথম মান টানা হয় সূত্র থেকে, পছন্দমতো নয়। 1 + 2 + … + n শুরু হয় **n = 1** থেকে; 1 + 2 + 2² + … + 2ⁿ শুরু হয় **n = 0** থেকে; n!-এ **n = 0**। বিবৃতিতে "সব n ≥ 0-এর জন্য" থাকলে ভিত্তি ক্ষেত্র **অবশ্যই n = 0** — n = 1 থেকে শুরু করলে n = 0-এর ক্ষেত্র প্রমাণিতই থাকে না।

- 💡 **কৌশল:** "**ভ**িত্তি **ব**ানায় প্রথম ইট, **আ**রোহ ধাপ ভাবনা এক ধাপ এগিয়ে নিয়ে যায় — আর সেটা করতে হবে **প্রতিবার**।" ধাপটি একটি **নিয়ম**, নমুনা নয় — লেখো "k ≥ 1 **যেকোনো** বলে P(k) সত্য ধরে নিন", "ধরি k = 3" নয়।

## ৩. সম্পূর্ণ প্রমাণ: 1 + 2 + 3 + … + n = n(n+1)/2

✍ **পূর্ণ প্রমাণ। P(n) ধরি:** 1 + 2 + 3 + … + n = n(n+1)/2।

**ভিত্তি ক্ষেত্র (n = 1).** বাম = 1, ডান = 1(1+1)/2 = 1, তাই **P(1) সত্য**।
**আরোহ অনুকল্প।** **k ≥ 1 যেকোনো** বলে **P(k) ধরে নিই**: 1 + 2 + … + k = k(k+1)/2।
**আরোহ ধাপ।** P(k+1) দেখাই: 1 + 2 + … + k + (k+1) = k(k+1)/2 + (k+1) *(অনুকল্প অনুযায়ী)* = (k+1)[k/2 + 1] = (k+1)(k + 2)/2 = (k+1)((k+1) + 1)/2 — এটাই P(k+1)-এর ডান পাশ, তাই **P(k+1) সত্য**।
**সিদ্ধান্ত।** P(1) সত্য এবং প্রতিটি k ≥ 1-এর জন্য P(k) ⇒ P(k+1), তাই গাণিতিক আরোহের নীতি অনুযায়ী P(n) প্রতিটি n ≥ 1-এর জন্য সত্য। ∎

- ⚠️ **ফাঁদ — এই পাঠের সবচেয়ে বেশি নম্বর কাড়া ভুল।** আরোহ ধাপে দেখাতে হবে **প্রতিটি পূর্ণসংখ্যা k ≥ 1-এর জন্য P(k) ⇒ P(k+1)**। তিনভাবে ভুল হয় এবং তিনবারই নম্বর শূন্য। (i) **একটি নির্দিষ্ট** মানের জন্য, যেমন k = 3 ধরে ধাপটি যাচাই করা — সেটি নমুনা, প্রমাণ নয়। (ii) **বিপরীত** রূপ লেখা P(k+1) ⇒ P(k), যা সম্পূর্ণ অন্য বিবৃতি। (iii) "ধরি P(k)" কথাটি বাদ দিয়ে সরাসরি k+1-এর ফল বলে দেওয়া।
- 📌 **ধাপটি লিখবেন যাতে পরীক্ষক সন্তুষ্ট হন:** (i) বিবৃতিটিকে নাম দাও "P(n): …" · (ii) ভিত্তি ক্ষেত্র সংখ্যায় দেখাও · (iii) "k ≥ 1 যেকোনো বলে P(k) ধরি" · (iv) k+1-এর পাশ **অনুকল্প থেকে শুরু** করে গোনো এবং কোথায় অনুকল্প ব্যবহার হলো তা চিহ্নিত করো · (v) শেষে "গাণিতিক আরোহের নীতি অনুযায়ী" লেখো। প্রতি লাইনে নম্বর — (v) বাদ দিও না।
- ✍ **অনুকল্প কেন দরকার।** এই প্রমাণে ধাপটি এক লাইনের বদলে দাঁড়ায়, কিন্তু **শুধু তখনই**, যখন "1 + 2 + … + k"-কে তার বন্ধ রূপ k(k+1)/2 দিয়ে বদলে দেওয়া হয়। বদল ছাড়া লাইপটি লিখলে তুমি কেবল k+1-এর জন্য বিবৃতিটাই নতুন করে বলেছ — **আর ইন্ডাকশন ঠিক এটাই করতে বলে না**।
- ✍ **দুটি লাইন যেগুলো প্রমাণ মনে হয়, আসলে নয়।** (i) "n = 1, 2, 3-এ মিলেছে, তাই সব n-এর জন্য মিলবে" — ধাপে k-এর **একটি** মান মাপা হয়েছে। (ii) "P(k+1) ⇒ P(k), তাই ইনডাকশনে প্রমাণিত" — সিঁড়ি **উল্টো দিকে** চড়ায়; k+1 সত্য জানলে কিছুই k সম্পর্কে বলা যায় না। **শুধু P(k) ⇒ P(k+1) চড়ায়।**
- ✍ **বিজোড় সংখ্যার সমষ্টি।** প্রমাণ করো, প্রতিটি n ≥ 1-এর জন্য 1 + 3 + 5 + … + (2n−1) = n²। ভিত্তি n = 1: বাম = 1, ডান = 1² = 1 ✓। ধাপ: ধরি 1 + 3 + … + (2k−1) = k²। তাহলে 1 + 3 + … + (2k−1) + (2k+1) = k² + 2k + 1 = **(k+1)²** — ঠিক P(k+1)।
- 📌 **সরল বীজগণিতের চেয়ে ইন্ডাকশন কখন জেয়ে:** দুই পাশেই **n** থাকা বিবৃতি বিন্যাস করে লাভ নেই, আর বিবৃতির পুনরাবৃত্ত কাঠামো ধাপের আকৃতির সঙ্গে হুবহু মেলে। অন্যথায় "n² + n সবসময় জোড়" — n(n+1) লিখে এক লাইনেই শেষ।

## ৪. দ্বিতীয় সম্পূর্ণ প্রমাণ: 1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1

✍ **লেখা পরীক্ষার আদর্শ উত্তর। P(n) ধরি:** প্রতিটি পূর্ণসংখ্যা n ≥ 0-এর জন্য 1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1।

**ভিত্তি ক্ষেত্র (n = 0).** বাম = 2⁰ = 1, ডান = 2¹ − 1 = 1, তাই **P(0) সত্য**।
**আরোহ অনুকল্প.** k ≥ 0 যেকোনো বলে P(k) ধরি: 1 + 2 + 2² + … + 2ᵏ = 2ᵏ⁺¹ − 1।
**আরোহ ধাপ.** P(k+1) দেখাই: 1 + 2 + … + 2ᵏ + 2ᵏ⁺¹ = (2ᵏ⁺¹ − 1) + 2ᵏ⁺¹ *(অনুকল্প অনুযায়ী)* = 2 · 2ᵏ⁺¹ − 1 = 2ᵏ⁺² − 1 = 2^(k+1)+1 − 1 — এটাই P(k+1), তাই **P(k+1) সত্য**।
**সিদ্ধান্ত।** P(0) সত্য এবং প্রতিটি k ≥ 0-এর জন্য P(k) ⇒ P(k+1), তাই গাণিতিক আরোহের নীতি অনুযায়ী P(n) সব পূর্ণসংখ্যা n ≥ 0-এর জন্য সত্য। ∎

**শক্তিশালী (পূর্ণ) আরোহ।** সব n ≥ 1-এর জন্য P(n) প্রমাণের জন্য যথেষ্ট দেখানো: **(ক)** P(1) সত্য, এবং **(খ)** প্রতিটি k ≥ 1-এর জন্য, যদি **P(1), P(2), …, P(k) সবগুলো সত্য হয়, তবে P(k+1) সত্য**। **শক্তিশালী আরোহ আসলে আরোহের একটি শক্তিশালী অনুকল্প — দুটি পরস্পর সমতুল্য**। ঠিক তখনই এটি লাগে যখন k+1-এর ক্ষেত্রে একাধিক আগের ক্ষেত্র একসঙ্গে দরকার।

✍ **শক্তিশালী আরোহে উদাহরণ।** প্রমাণ করো, প্রতিটি পূর্ণসংখ্যা n ≥ 2-এর একটি মৌল উত্তাধক আছে। ভিত্তি n = 2: 2 মৌল, তাই 2 | 2। ধাপ: ধরি 2 … k-এর প্রতিটি পূর্ণসংখ্যার একটি মৌল উত্তাধক আছে। k+1 প্রস্তিপাদ হলে দাবি সরাসরি; আর যৌগ হলে তার 1 < d < k+1 থাকে এমন একটি উত্তাধক d থাকে, আর শক্তিশালী অনুকল্পে d-ও একটি মৌল উত্তাধক p আছে, যা k+1-কেও বিভাজ্য করে।

✍ **আরেকটি নিয়মিত প্রমাণ।** প্রমাণ করো, 1 + 1/2 + 1/2² + … + 1/2ⁿ = 2 − 1/2ⁿ, n ≥ 0। ভিত্তি n = 0: বাম = 1, ডান = 2 − 1 = 1 ✓। ধাপ: k পর্যন্ত যোগ 2 − 1/2ᵏ ধরি; তাহলে k+1 পর্যন্ত যোগ = (2 − 1/2ᵏ) + 1/2ᵏ⁺¹ = 2 − 2/2ᵏ⁺¹ + 1/2ᵏ⁺¹ = **2 − 1/2ᵏ⁺¹** ✓ — ঠিক P(k+1)। তিনটি বিবৃতি, একই তিন লাইন।

- ⚠️ **ফাঁদ:** (i) ইন্ডাকশন কেবল **ℕ** সম্পর্কিত বিবৃতি প্রমাণ করে · (ii) ধাপে অবশ্যই লিখতে হবে "**প্রতিটি k ≥ 1-এর জন্য**"; "কোনো k-এর জন্য" লিখলে ধাপ প্রমাণিত হয়নি · (iii) অনুকল্প আসলে **ব্যবহার** করতে হবে — k+1-এর লাইপটি তা ছাড়াই এলে যুক্তি বৃত্তাকার · (iv) k+1-এর ক্ষেত্রে দুটি আগের ক্ষেত্র লাগলে **শক্তিশালী** আরোহ ধরো।
- 📌 **কখন ইন্ডাকশন ব্যবহার করা যাবে না:** অসীম বাস্তব মানের উপর দাঁড়ানো দাবি — "বর্গের বর্গ মূলদ" — ইন্ডাকশনে আসে না। আবার একটি প্রাকৃতিক n-তেই বিবৃতিটি খারাপ হলে সেটি **খণ্ডিত**, প্রমাণিত নয়।
- ⚠️ **ভুল ধাপ ধরা পড়া:** পরীক্ষক সবচেয়ে দ্রুত লক্ষ্য করেন সেই লাইপটি, যেখানে k-এর বদলে সরাসরি k+1 বসে দেওয়া হয়েছে অথচ অনুকল্প কোথাও ব্যবহার হয়নি — এটি চক্রাকার যুক্তি (circular reasoning)।

## ৫. অসঙ্গতি প্রমাণ (কন্ট্রাডিকশন)

যাকে **বিরোধাভ্যস (reductio ad absurdum)**-ও বলে। P প্রমাণ করতে: **¬P ধরে নিন** — ধরা নেওয়াটি সাময়িক **অনুকল্প**, দাবি নয় — আর তা থেকে এমন কিছু নির্গমন করান যা অসম্ভব: কোনো বিবৃতি তার নেতিবাচকের সঙ্গে একসঙ্গে, 0 = 1, শূন্য দিয়ে ভাগ, পরস্পর বিরোধী গুণাঙ্কযুক্ত কোনো বস্তু। এই অসম্ভবতাকে **⊥** দিয়ে লেখা হয়। ¬P অসম্ভবতায় নিয়ে গেলে **P অবশ্যই সত্য**।

| কী গণ্য হয় অসঙ্গতি ⊥ | চিরন্দর প্রয়োগ |
|---|---|
| কোনো বিবৃতি তার **নেতিবাচকের** সঙ্গে একসঙ্গে | "p একই সঙ্গে জোড় **ও** বিষম" |
| **0 = 1**, বা যেকোনো মিথ্যা সমীকরণ | √2 মূলদ |
| **শূন্য দিয়ে ভাগ** | 1-এর বিপরীতযোগ্য মূলক অস্তিত্বে নেই |
| বিরোধী গুণাঙ্কযুক্ত বস্তু | "সবচেয়ে বড় মৌল সংখ্যা" |
| একই সঙ্গে **অশূন্য ও খালি** সেট | ℕ থেকে ℕ \ ℕ-এ কোনো এক-একরূপ মানচিত্র নেই |

**যে চার লাইন পরীক্ষক চায়।** **(১)** দাবিটি P পরিষ্কারভাবে লেখো। **(২)** লেখো "ধরি, অসঙ্গতির জন্য, ¬P", এবং নেতিবাচকটিকে **অনুকল্প** হিসেবেই ধরে রাখো। **(৩)** ধাপে ধাপে পরিণতি নির্গমন করে তা অসম্ভবতা ⊥-এ ঠেলাও। **(৪)** শেষে লেখো "অনুকল্প মিথ্যা, অতএব P" — অসঙ্গতি **অনুকল্পের** বিরুদ্ধে, P-এর বিরুদ্ধে নয়।

- 💡 **কৌশল:** "ধা**রি** অশ**কা** ধরে নাও, অসম্ভবতা পর্যন্ত **ঠেল** নাও — তাহলেই আসল দাবিটা বেরিয়ে আসবে।" পদ্ধতির নিশ্চিত লক্ষণ হলো **"ধরি" / "মনে করি"** শব্দটি।
- ⚠️ **ফাঁদ:** "অসঙ্গতি প্রমাণ শুরু হয় ধরে নিয়ে…" — উত্তর হলো **প্রমাণযোগ্য বিবৃতির নেতিবাচকটি**। "বিবৃতিটি সত্য" ধরে নেওয়া (সেটি বৃত্তাকার যুক্তি), "কনভার্স", বা "ভিত্তি ক্ষেত্র P(1)" — কোনোটিই নয়। আর শেষে যা আসে তা অবশ্যই **অসম্ভব** হতে হবে, **অসম্ভাব্য** নয়।
- ⚠️ **ফাঁদ — পূর্ণ নেতিবাচক ধরো।** "প্রতিটি A একটি B" — এর নেতিবাচক হলো **"এমন একটি A আছে যা B নয়"** — "সব A B নয়" ছেড়ে দেওয়া নয়।
- 📌 **কখন অসঙ্গতি ভুল হাতিয়ার:** কোনো দাবি **একটি** মানে খারাপ হলে অসম্ভব অনুকল্প না তৈরি করেই **বিপরীত উদাহরণ** দেখিয়ে কাজ শেষ করা যায়। আর অসীম বাস্তব সংখ্যা সম্পর্কিত দাবি ইন্ডাকশনে মেটে না।

## ৬. অসঙ্গতির প্রয়োগ

✍ **প্রমিত নমুনা: √2 অমূলদ।**

1. **ধরি, অসঙ্গতির জন্য, √2 মূলদ।** তাহলে √2 = p/q, যেখানে p, q পূর্ণসংখ্যা, q ≠ 0 এবং সরলতম রূপে **gcd(p, q) = 1**।
2. উভয় পক্ষ বর্গ করি: 2 = p²/q², অতএব **p² = 2q²**।
3. p² জোড়, তাই **p জোড়** — বিজোড় p-এর বর্গও বিজোড় — লেখি p = 2k।
4. বসিয়ে: (2k)² = 2q² ⇒ 4k² = 2q² ⇒ **q² = 2k²**।
5. q² জোড়, তাই **q জোড়**।
6. তাহলে 2, p ও q দুটোকেই বিভাজ্য করে, অতএব **gcd(p, q) ≥ 2** — যা gcd(p, q) = 1-এর বিরুদ্ধে। **⊥**
7. অতএব অনুকল্প মিথ্যা এবং **√2 অমূলদ**। ∎

✍ **চিরনামন অবতরণ (infinite descent)।** **দাবি:** ধনাত্বিক পূর্ণসংখ্যার ধারা চিরকাল নামতে পারে না। **ধরি** এমন ধারা আছে: *a*₁ > *a*₂ > *a*₃ > …, সবগুলো ধনাত্বিক পূর্ণসংখ্যা। **সুশৃঙ্খলতা নীতি** অনুযায়ী {*a*₁, *a*₂, …}-এর একটি সর্বনিম্ন সদস্য *a*ₘ আছে। কিন্তু *a*ₘ₊₁ < *a*ₘ *ও* একই সেটের সদস্য এবং আরও ছোট — বিরোধ। অসঙ্গতি ⇒ ধনাত্বিক পূর্ণসংখ্যার প্রতিটি সংখ্যাগোষ্ঠীর সর্বনিম্ন সদস্য আছে। এটিই **চিরনামন অবতরণ**, "√2 অমূলদ" প্রমাণের ভিত্তি।

✍ **একটি পরিবার ব্যর্থ।** **দাবি:** f(n) = n² + n + 41 প্রতিটি স্বাভাবিক n-এর জন্য মৌল। **ধরি** সব n-এর জন্য এটি মৌল। **n = 41** নিই: f(41) = 1681 + 41 + 41 = **1763 = 41 × 43**, যা মৌল নয়। **একটিমাত্র বিপরীত উদাহরণই সাধারণ দাবি ভাঙে**। (n = 0 … 39-এ f(n) মৌল, ফলে দাবিটি ভুলে মনে হয়।)

✍ **সবচেয়ে বড় মৌল সংখ্যা নেই।** **দাবি:** মৌল সংখ্যার সীমা নেই। **ধরি** p₁, …, pₘ হলো **সব** মৌল সংখ্যার তালিকা এবং Q = p₁p₂ … pₘ। প্রতিটি pᵢ, Q কে বিভাজ্য করে, তাই Q + 1 কে ভাগ করলে প্রতিটির অবশিষ্ট 1। এখন N = Q + 1 > 1 — N-এর একটি মৌল উত্তাধক আছে, যা তালিকায় নেই। অসঙ্গতি।

✍ **√3 এক লাইনে।** ধরি √3 = p/q সরলতম রূপে। তাহলে p² = 3q², তাই **3 | p²**, তাই **3 | p**; লিখি p = 3k, পাওয়া 9k² = 3q², অতএব q² = 3k² এবং **3 | q**। **3, p ও q দুটোকেই বিভাজ্য করে, তাই gcd ≥ 3 ≠ 1 — অসঙ্গতি; √3 অমূলদ।**

- ⚠️ **ফাঁদ:** √2-এর প্রমাণে **সরলতম রূপে** থাকা gcd(p, q) = 1 অনুকল্পটিই শেষ অসঙ্গতিটিকে দাঁতড়া কোঁক; ছাড়া পা লাগলে যুক্তিটি বৃত্তাকার। আর "p² জোড় ⇒ p জোড়" একটি **লেম্মা** — বলা দরকার: p² = 2q² থেকে সরাসরি পাওয়া যায় কেবল যে p² জোড়, আর p জোড় হওয়া আসে "p বিজোড় হলে p² বিজোড়"-এর **কন্ট্রাপজিটিভ** থেকে।
- 📌 **সাধারণীকরণ:** সব অমূলিক p-এর জন্য √p অমূলদ। প্রমাণে প্রায়ই লাগে একটিই পদক্ষেপ: √p = a/b সরলতম রূপে ধরি ⇒ p b² = a² ⇒ p | a² ⇒ p | a ⇒ a = p m ⇒ b² = p m² ⇒ p | b, অতএব p, a ও b — তিনটোই বিভাজ্য, gcd(a, b) ≠ 1 বিরুদ্ধে। **"p | a² ⇒ p | a" এই একটি লেম্মাই পুরো প্রমাণের ভিত্তি।**
- 📌 **কম্পিউটার বিজ্ঞানের সিলেবাসে অসঙ্গতি:** একই আকৃতিতেই প্রমাণ হয় যে কোনো মোট গণনযোগ্য ফলন টিউরিং মেশিনের থামা-অথবা-না-থামা বিষয়ে সিদ্ধান্ত নিতে পারে না — সিদ্ধান্তকারী D আছে ধরি, D-কে D-এরই জিজ্ঞেস করো, আর D নিজের সম্পর্কেই ভুল হয়। লেখা পরীক্ষায় **অনুকল্পটির নাম** ও **অসঙ্গতির জায়গা** দুটোই দেখাতে বলা হয়।

## ৭. অসঙ্গতি বনাম কন্ট্রাপজিটিভ

**P → Q** প্রমাণের জন্য **কন্ট্রাপজিটিভ** পদ্ধতিতে প্রমাণ করা হয় **¬Q → ¬P**। যুক্তিটি আলাদা, ক্ষমতা সমান, কারণ P → Q **¬Q → ¬P-এর সঙ্গে যুক্তিগতভাবে সমতুল্য**। অসঙ্গতি প্রমাণে ধরা হয় **¬(P → Q)** = **P ∧ ¬Q** — অর্থাৎ অনুকল্প **সত্য**, সিদ্ধান্ত **মিথ্যা** একসঙ্গে। **কনভার্স** Q → P এবং **ইনভার্স** ¬P → ¬Q P → Q-এর সঙ্গে **সমতুল্য নয়**, তবে কনভার্স ও ইনভার্স পরস্পরের সমতুল্য।

| রূপ | কী বলা হয় | P → Q-এর সমতুল্য? | P = "n জোড়", Q = "n² জোড়" উদাহরণ |
|---|---|---|---|
| **P → Q** | বিবৃতিটিই | — | সত্য |
| **¬Q → ¬P** | **কন্ট্রাপজিটিভ** | **সবসময় হ্যাঁ** | "n² বিজোড় ⇒ n বিজোড়" — সত্য |
| **Q → P** | **কনভার্স** | **নয়** | "n² জোড় ⇒ n জোড়" — মিথ্যা, n = 3 |
| **¬P → ¬Q** | **ইনভার্স** | **নয়** (তবে কনভার্স ≡ ইনভার্স) | "n বিজোড় ⇒ n² বিজোড়" — সত্য, তবু সমতুল্য নয় |

✍ **কাজে লাগছে কন্ট্রাপজিটিভ।** প্রমাণ করো: n² 4 দ্বারা বিভাজ্য হলে n জোড়। **কন্ট্রাপজিটিভ:** ধরি n² 4 দ্বারা বিভাজ্য **নয়**; তাহলে n বিজোড়, n = 2k+1, তাই n² = 4k² + 4k + 1, যা 4-এর একটি বহুগুণের চেয়ে 1 বেশি — অতএব **বিভাজ্য নয়**। **অসম্ভব অবশিষ্টাংশ 1-ই ⊥।**

- ⚠️ **ফাঁদ:** (i) **¬Q → ¬P**-কে "কনভার্স" বলা — এটি **কন্ট্রাপজিটিভ**; (ii) সত্য ইনভার্স দেখে ভাবা যে P → Q-ও সত্য। সমতুল্যতা **সব** ক্ষেত্রের বিষয়, একটির নয়।
- ⚠️ **ফাঁদ:** "কনভার্স সত্য হলে কন্ট্রাপজিটিভও সত্য" — এটি ভুল। সমতুল্যতার একমাত্র পরীক্ষা হলো **প্রতিটি মানে** দুটির সত্যতা মিলিয়ে দেখা।
- 📌 **আইটি সংযোগ — একই যন্ত্র, পরের অধ্যায়ে।** অসঙ্গতি একটি **অসিদ্ধান্যতা** ঠিক করে: **halting problem** অসিদ্ধান্য প্রমাণের জন্য ধরা হয় সিদ্ধান্তকারী D আছে এবং D-কে D-এর নিজের সম্পর্কে জিজ্ঞেস করা হয়। সাধারণ **ইন্ডাকশন** একটি **উপপাদ্য** ঠিক করে: n শীর্ষের গাছে ঠিক **n − 1** প্রান্ত থাকে — n-এর উপর ইন্ডাকশন, পাতা-লেম্মা ব্যবহার করে। **একটি পদ্ধতি কিছুর অস্তিত্ব প্রমাণ করে, অন্যটি প্রমাণ করে কিছুই অসম্ভব।**

## ৮. পুনরাবৃত্তি (রিকার্শন)

একটি **পুনরাবৃত্তি** সংজ্ঞা কোনো বস্তুকে **নিজের ছোট উদাহরণের মাধ্যমে** সংজ্ঞায়িত করে; ধারার জন্য একে **পুনরাবৃত্ত সমীকরণ** বলে। প্রতিটি পুনরাবৃত্তি সংজ্ঞায় ঠিক দুটি অংশ থাকে: যেখানে পুনরাবৃত্তি থামে সেখানে **ভিত্তি ক্ষেত্র**, আর এমন একটি **পুনরাবৃত্তি ধাপ** যার যুক্তি **কঠিনভাবে ভিত্তির দিকে কাছাকাছি**। যে ফাংশন নিজেকে এমন যুক্তিতে কল করে যা কমে না, তা পুনরাবৃত্তি নয় — তা **অসীম লুপ**, যা স্ট্যাক উপচে ফেলে।

| বস্তু | ভিত্তি ক্ষেত্র | পুনরাবৃত্তি ধাপ |
|---|---|---|
| **ফ্যাক্টরিয়াল** n! | n! = 1 যদি n = 0 | n! = n × (n−1)! যদি n > 0 |
| **ফিবোনাচ্চি** F(n) | F(0) = 0, F(1) = 1 | F(n) = F(n−1) + F(n−2) যদি n > 1 |
| **ঘাত** aⁿ | a⁰ = 1 | aⁿ = a × aⁿ⁻¹ |
| **যোগ** S(n) | S(0) = 0 | S(n) = S(n−1) + n |
| **ইউক্লিড** gcd(a, b) | gcd(a, 0) = a | gcd(a, b) = gcd(b, a mod b) |

```
function factorial(n):
    if n == 0:            # base case — the recursion stops here
        return 1
    else:                 # step: n − 1 is strictly smaller than n
        return n * factorial(n - 1)
```

```
F(0)=0  F(1)=1  F(2)=1  F(3)=2  F(4)=3  F(5)=5  F(6)=8  F(7)=13  F(8)=21
```

**"ছোট" হওয়াই পুরো শর্ত।** সমাপ্তির কথা একটি **সুপ্রতিষ্ঠিত পরিমাপের** উপর দাঁড়ায়: কোনো পরিমাপ — যুক্তি n, তালিকার দৈর্ঘ্য, গাছের গভীরতা — প্রতিটি কলে **কঠিনভাবে কমতে** হবে এবং তার একটি **নিম্ন সীমা** থাকতে হবে। ℕ-এর তেমন সীমা নেই, তাই বারবার কমতে থাকলে 0 বা 1-এ পৌঁছতেই হবে। তাই ফ্যাক্টরিয়ালের ধাপ **n − 1** ব্যবহার করে, **n + 1** নয়।

- ⚠️ **ফাঁদ:** (i) **0! = 1** — ফ্যাক্টরিয়ালের ভিত্তি ক্ষেত্র n = 0, n = 1 নয়; আর n = 0 ও n = 1 দুটোতেই n! = 1, তাই শুধু n = 1 দেখে ভিত্তি ক্ষেত্র যাচাই হয় না · (ii) রিকার্শন ও লুপ **একই** ফল দেয়; তবে সরল রিকার্শন **চরমঘাতীরূপ** ধীর হতে পারে · (iii) **পুনরাবৃত্ত সমীকরণ** আর **পুনরাবৃত্তিমূলক অ্যালগরিদম** এক জিনিস নয়।
- 📌 **ফিবোনাচ্চির সূচক:** একই ধারা **F(0) = 0, F(1) = 1** অথবা **F(1) = 1, F(2) = 1** — এক সূচকে পার্থক্য। "F(1) = 1, F(2) = 1" বলা প্রশ্নে 7ম পদের মান জিজ্ঞেস করা হয়, তাই উত্তর **13**, 8 নয়।
- ⚠️ **ফাঁদ — স্ট্যাক গভীরতা:** "factorial(5) 5-টি কল করে" — সংখ্যায় 5 বলা ভুল; প্রথম কলসহ মোট **6**টি কল (5!, 4!, …, 0!)।

## ৯. রিকার্শন ↔ ইন্ডাকশন, এবং এর মূল্য

পুনরাবৃত্তি সংজ্ঞা ভিত্তি ক্ষেত্র ও ধাপ **দেয়**; ইন্ডাকশন প্রমাণ ঠিক সেগুলোকেই **যাচাই** করে। তাই **কোনো পুনরাবৃত্তিমূলক ফাংশনের সঠিকতা প্রমাণ করতে তার যুক্তির উপর ইন্ডাকশন চালাও**: ভিত্তি ক্ষেত্রে ভিত্তি যুক্তিতে মান গোনো; ধাপে n-এর সঠিকতা অনুমান করে **n−1**-এর পুনরাবৃত্তি কলটি অনুকল্পে আওতায়, তারপর বীজগণিত শেষ করো। এটিই **অ্যালগরিদম সঠিকতার প্রমাণের** আদর্শ কাঠামো।

✍ **কাঠামো প্রয়োগ।** **দাবি:** উপরের ফাংশনটি প্রতিটি n ≥ 0-এর জন্য n! ফেরতায়। **ভিত্তি:** factorial(0) ফেরতায় 1 = 0!। **ধাপ:** ধরি কোনো k ≥ 0-এর জন্য factorial(k) ফেরতায় k!; তাহলে factorial(k+1) ফেরতায় (k+1) × factorial(k) = (k+1) × k! = (k+1)!. তাই ইন্ডাকশনে সব n ≥ 0-এর জন্য সঠিক।

| সরল অ্যালগরিদম | কল সংখ্যা | মূল্য |
|---|---|---|
| **factorial(5)** | 5!, 4!, 3!, 2!, 1!, 0! = **6** | **O(n)** সময়, **O(n)** স্ট্যাক |
| **fib(5)**, সরল | T(n) = T(n−1)+T(n−2)+1 ⇒ T(n) = **2F(n+1) − 1**; T(5) = **15** | **O(φⁿ)**, φ = (1+√5)/2 ≈ 1.618 |
| **fib(5)**, মেমোইজড | প্রতিটি F(i) একবারই গোনা হয়: **n** কল | **O(n)** সময় |

- ⚠️ **ফাঁদ:** "factorial রিকার্শনমূলক তাই ধীর" — **মিথ্যা**: এটি মাত্র n + 1 কল করে, অর্থাৎ **O(n)**। চরম বৃদ্ধি **ফিবোনাচ্চির**, যার কল-বৃক্ষ দুই দিকে ভাগ হয়। একটি **টেইল** কল লুপে লেখা যায়, তখন স্ট্যাক O(1)।
- 📌 **কোথায় নম্বর আসে:** **ইন্ডাকশনে সঠিকতার প্রমাণ**, **কল-বৃক্ষের জটিলতা**, **প্রোগ্রাম যাচাই** ও **উপপাদ্য প্রমাণ** — সিলেবাসের নির্দিশিত প্রয়োগ। লুপের **invariant** + ইন্ডাকশন দিয়ে লুপের মোট সঠিকতা; গাছ ও তালিকার উপর **কাঠামোগত আরোহ** দিয়ে কম্পাইলার ও ডেটা টাইপের উপপাদ্য; **ডায়াগোনালিজেশন** হলো গণনযোগ্যতার উপর প্রয়োগ করা অসঙ্গতি।
- ⚠️ **ফাঁদ:** সঠিকতা ও সমাপ্তি **দুটি আলাদা দাবি**। একটি প্রোগ্রাম ভুল ফল দিতে পারে না কিন্তু চলতেই নাও পারে (অসীম লুপ), আবার চলতে পারে কিন্তু ভুল ফল দিতে পারে।

## ১০. কোন পদ্ধতি ব্যবহার করব?

| পদ্ধতি | মূল ভাবনা | আপনাকে যা দিতে হবে | কখন ব্যর্থ হয় |
|---|---|---|---|
| **ইন্ডাকশন** | ভিত্তি ক্ষেত্রে সত্য প্রমাণ করো, তারপর **ধাপে ধাপে** | P(b) সত্য, এবং প্রতিটি k-এর জন্য P(k) ⇒ P(k+1) | দাবি ℝ সম্পর্কিত, বা ধাপে একাধিক আগের ক্ষেত্র লাগলে |
| **অসঙ্গতি** | **মিথ্যা ধরে নাও**, অসম্ভব ফল নির্গমন করাও | ¬P, তারপর সত্য ⊥ (P ∧ ¬P, 0 = 1, ÷ 0) | তুমি P ধরে নিলে, বা কেবল **অসম্ভাব্য** কিছু নির্গমন করলে |
| **রিকার্শন** | **ছোট উদাহরণের মাধ্যমে সংজ্ঞায়িত করো** | ভিত্তি ক্ষেত্র, আর কঠিনভাবে কমে যাওয়া একটি ধাপ | যুক্তি কমে না — রিকার্শন কখনোই শেষ হয় না |

**তিনটি এক লাইনে।** **ইন্ডাকশন** — "একবার সত্য, আর k-তে সত্য হলে k+1-এ সত্য", তাই সত্যতা পুরো ℕ-এ ছড়িয়ে পড়ে। **অসঙ্গতি** — "মিথ্যা হলে অসম্ভবতা আসত", তাই মিথ্যা হতে পারে না। **রিকার্শন** — "ছোটগুলো থেকে সংজ্ঞায়িত করো", যা ইন্ডাকশন প্রমাণটি তারপর যাচাই করে। **ইন্ডাকশন আর রিকার্শন একই বস্তুর দুই অর্ধেক।**

- 📌 **প্রয়োগ — সিলেবাসের চারটি নাম:** **অ্যালগরিদম সঠিকতার প্রমাণ** (লুপ কাউন্টার বা রিকার্শনের গভীরতার উপর ইন্ডাকশন) · **জটিলতা বিশ্লেষণ** (পুনরাবৃত্ত সমীকরণ সমাধান করে) · **প্রোগ্রাম যাচাই** (পূর্বশর্ত, উত্তরশর্ত ও invariant) · **গাণিতিক উপপাদ্য প্রমাণ**।
- ⚠️ **ফাঁদ:** তিনটি একই বিষয়ের তিন রূপ নয় — ইন্ডাকশন ও অসঙ্গতি **প্রমাণ-পদ্ধতি**, আর রিকার্শন একটি **সংজ্ঞা ও গণনার কৌশল**। "রিকার্শন দিয়ে প্রমাণ" মানে কেবল "পুনরাবৃত্তিমূলক প্রোগ্রামের সঠিকতা প্রমাণ", আর সেটি **ইন্ডাকশন**।
- 💡 **এক বাক্যে সিদ্ধান্ত:** অস্তিত্ব চাওয়া হয় ও তুমি "কিছু নেই" বলবে, ধরি — **অসঙ্গতি**; "সব" শব্দ থাকলে **ইন্ডাকশন**; "যদি…তবে" থাকলে **কন্ট্রাপজিটিভ**; "সংজ্ঞায়িত করো" বা "যেভাবে গোনা হয়" থাকলে **রিকার্শন**।

## রাতের পাতা

**তথ্য-পত্র:** প্রমাণ = **বৈধ** + সত্য প্রতিজ্ঞা = **সুস্থ** · সুস্থ ⇒ বৈধ, উল্টোটি কখনো নয় · ইন্ডাকশন: **ভিত্তি** P(1) · ইন্ডাকশন: **ধাপ** P(k) ⇒ P(k+1) · ধাপ প্রতিটি **k ≥ 1**-এর জন্য · P(k+1) ⇒ P(k) তো নয় · Σ 1…n = **n(n+1)/2** · Σ 2⁰…2ⁿ = **2ⁿ⁺¹ − 1** · শক্তিশালী আরোহ ≡ সাধারণ আরোহ · অসঙ্গতি: ধরি **¬P** · ⊥ = P∧¬P, 0 = 1, ÷ 0 · √2 অমূলদ: p, q জোড়, তবে gcd ≥ 2 ≠ 1 · কন্ট্রাপজিটিভ **¬Q → ¬P** ≡ P → Q · কনভার্স ও ইনভার্স সমতুল্য নয় · n! = 1 (n = 0) নয়তো n·(n−1)! · F(0) = 0, F(1) = 1, নয়তো F(n−1)+F(n−2) · রিকার্শনে যুক্তি **কমতে** হবে · factorial(5) = **6** কল, O(n) · সরল fib-এ T(n) = **2F(n+1) − 1**, T(5) = **15**, O(φⁿ) · মেমোইজড fib ⇒ **O(n)** · টেইল কল ⇒ O(1) স্ট্যাক · গাছ: n শীর্ষে **n − 1** প্রান্ত (ইন্ডাকশন) · halting অসিদ্ধান্য (অসঙ্গতি)।

## লিখিত প্রশ্ন (১০ নম্বর)

(i) গাণিতিক আরোহের নীতি বলো এবং প্রমাণ করো যে প্রতিটি পূর্ণসংখ্যা n ≥ 0-এর জন্য 1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1। (ii) অসঙ্গতি প্রমাণে দেখাও যে √2 অমূলদ। (iii) ফ্যাক্টরিয়ালের পুনরাবৃত্তি সংজ্ঞা দাও এবং সরল factorial(5)-এ কল সংখ্যা বলো। (iv) "n² জোড় ⇒ n জোড়"-এর কন্ট্রাপজিটিভ কি সত্য?

**মডেল উত্তর:**

1. **আরোহের নীতি (3)** — P(1) সত্য এবং প্রতিটি k ≥ 1-এর জন্য P(k) ⇒ P(k+1) হলে সব n ≥ 1-এর জন্য P(n) সত্য। **ভিত্তি n = 0:** 2⁰ = 1 = 2¹ − 1 ✓। **ধাপ:** 1 + 2 + … + 2ᵏ = 2ᵏ⁺¹ − 1 ধরি; তাহলে 1 + 2 + … + 2ᵏ + 2ᵏ⁺¹ = (2ᵏ⁺¹ − 1) + 2ᵏ⁺¹ = 2 · 2ᵏ⁺¹ − 1 = 2ᵏ⁺² − 1 = 2^(k+1)+1 − 1 ✓। তাই সব n ≥ 0-এর জন্য বিবৃতিটি সত্য।
2. **√2 (3)** — ধরি √2 = p/q সরলতম রূপে। উভয় পক্ষ বর্গ করলে 2 = p²/q², অতএব p² = 2q²। p² জোড় হলে p জোড়; লিখি p = 2k। তাহলে 4k² = 2q², অতএব q² = 2k², তাই q-ও জোড়। **p ও q দুটো জোড় হলে gcd(p, q) ≥ 2 ≠ 1 — অসঙ্গতি।** অতএব √2 অমূলদ। ∎
3. **ফ্যাক্টরিয়াল (2)** — n! = 1 যদি n = 0, এবং n! = n × (n−1)! যদি n > 0। প্রতিটি কলে যুক্তি কঠিনভাবে কমে 0-এ পৌঁছায় বলে এটি সমাপ্তিশীল। সরল factorial(5) মোট **6**টি কল করে: 5!, 4!, 3!, 2!, 1!, 0! — সময় O(n), স্ট্যাক O(n)।
4. **কন্ট্রাপজিটিভ (2)** — কন্ট্রাপজিটিভটি হলো "যদি n² **বিজোড়** হয় তবে n বিজোড়", যা **সত্য** এবং মূল বিবৃতির সঙ্গে যুক্তিগতভাবে সমতুল্য। মূল বিবৃতিটি "n² জোড় হলে n জোড়" **মিথ্যা** (n = 3), তাই সেটির সঙ্গে সমতুল্যতা নিরাপদে যাচাই করতে হয় না — কন্ট্রাপজিটিভ নিজেই সত্য হওয়াই যথেষ্ট।

**আরও অনুশীলন (লিখিত):** ① ইন্ডাকশনে প্রমাণ করো যে প্রতিটি n ≥ 1-এর জন্য 1 + 3 + 5 + … + (2n−1) = n² ② ইনডাকশনে প্রমাণ করো যে প্রতিটি n ≥ 1-এর জন্য n ∣ n! ③ অসঙ্গতি প্রমাণে দেখাও √3 অমূলদ এবং ব্যবহৃত লেম্মাটি উল্লেখ করো ④ অসঙ্গতি প্রমাণে দেখাও সবচেয়ে বড় মৌল সংখ্যা নেই ⑤ ফিবোনাচ্চির পুনরাবৃত্তি সংজ্ঞা লেখো, সরল সংস্করণ চরমঘাতীরূপ কেন তা ব্যাখ্যা করো, এবং fib(5)-এ কল সংখ্যা বলো ⑥ কন্ট্রাপজিটিভ পদ্ধতিতে প্রমাণ করো যে n² 4 দ্বারা বিভাজ্য হলে n জোড়, এবং কেন কনভার্সটি মিথ্যা ⑦ পুনরাবৃত্তিমূলক ফ্যাক্টরিয়ালের সঠিকতা ইন্ডাকশনে প্রমাণ করে লেখা পরীক্ষার উত্তর দাও ⑧ "n সবসময়ই 2 দ্বারা বিভাজ্য নয়" — এই দাবিটি কী ধরে নিয়ে অসঙ্গতি প্রমাণে লেখো।
