Communication Theory: "Information theory: entropy, information rate, Shannon's theorem, channel capacity"। সাথে আছে: সোর্স কোডিং (শ্যানন–ফানো, হাফম্যান), BSC, নাইকুইস্ট সীমা ও ত্রুটি নিয়ন্ত্রণের মূল কথা। স্যাম্পলিং আছে স্পেকট্রাল অ্যানালাইসিস ও স্যাম্পলিং নোটে; PCM, মডুলেশন ও মাল্টিপ্লেক্সিং আছে মডুলেশন, পালস সিগন্যাল ও মাল্টিপল অ্যাক্সেস নোটে।

সংজ্ঞা তথ্য তত্ত্ব (Information Theory) হলো তথ্য পরিমাপ, সংকোচন ও নির্ভরযোগ্যভাবে প্রেরণের গণিত। ভিত্তি: ক্লড ই. শ্যাননের (Claude E. Shannon) প্রবন্ধ "A Mathematical Theory of Communication" (Bell System Technical Journal, ১৯৪৮); তিনি "তথ্য তত্ত্বের জনক"।
মনে রাখার কৌশল "সোর্স কোডিং ছাঁটে, চ্যানেল কোডিং ঢাকে।" সোর্স কোডিং = সংকোচন (হাফম্যান, ZIP: L, η); চ্যানেল কোডিং = সুরক্ষা (প্যারিটি, হ্যামিং, CRC: কোড রেট k/n, dmin)।

২তথ্যের পরিমাপ

হাই-ইল্ড
স্ব-তথ্য (Self-information) p সম্ভাবনার একটি বার্তা বহন করে I = log₂(1/p) = −log₂ p বিট। বার্তা যত কম সম্ভাব্য, তত বেশি তথ্য ("আজ সূর্য উঠেছে" ≈ 0 বিট; "ঢাকায় ভূমিকম্প" = অনেক বিট)।
  • p = 1 (নিশ্চিত ঘটনা) → I = 0; সবসময় I ≥ 0
  • p1 < p2 → I1 > I2
  • স্বাধীন বার্তা: I(x₁x₂) = I(x₁) + I(x₂) (লগ গুণকে যোগে বদলায়)
  • p = ½-এর একটি বাইনারি অঙ্ক → ঠিক 1 বিট
লগের ভিত্তিএকক= বিট
2বিট (shannon)1
eন্যাট (nat)1.443
10ডেসিট / হার্টলি3.322
সমাধানকৃত উদাহরণ ✍ p = 1/8 → I = log₂ 8 = 3 বিট। ৫২ তাসের প্যাকেট থেকে একটি তাস: log₂ 52 = 5.70 বিট; "তাসটি টেক্কা" (p = 4/52 = 1/13): log₂ 13 = 3.70 বিট।
পরীক্ষার ফাঁদ বড (Baud) হলো সিম্বল রেটের একক, তথ্যের নয়। আর log₂ x = 3.322 log₁₀ x: ক্যালকুলেটর ছাড়া MCQ-তে এই রূপান্তর কাজে লাগে।

৩এনট্রপি (Entropy) H: প্রতি প্রতীকে গড় তথ্য

হাই-ইল্ড
সংজ্ঞা M টি প্রতীক ও সম্ভাবনা p1 … pM বিশিষ্ট ডিসক্রিট মেমোরিলেস সোর্সের (DMS) জন্য: H(X) = Σ pi log₂(1/pi) বিট/প্রতীক। এনট্রপি = গড় স্ব-তথ্য = প্রতি প্রতীকে দূর হওয়া গড় অনিশ্চয়তা = লসলেস সংকোচনের সীমা।
সীমা
0 ≤ H ≤ log₂M
H = 0 → একটি প্রতীক নিশ্চিত (p = 1)
H = log₂M → সব সমসম্ভাব্য (p = 1/M)
n-তম এক্সটেনশন: H(Xⁿ) = n·H(X)
বাইনারি সোর্স: H(p) সর্বোচ্চ 1 বিট, p = 0.5-এ
উৎসসম্ভাবনাH (বিট/প্রতীক)
নিরপেক্ষ মুদ্রা½, ½1
পক্ষপাতী মুদ্রা0.9, 0.10.469
4টি সমান প্রতীকপ্রতিটি ¼2 = log₂4
ডায়াডিক সোর্স½, ¼, ⅛, ⅛1.75
নিরপেক্ষ ছক্কাপ্রতিটি 1/62.585 = log₂6
ইংরেজি বর্ণবর্ণের ফ্রিকোয়েন্সি≈ 4.1 (সর্বোচ্চ log₂26 = 4.70)
সমাধানকৃত উদাহরণ ✍ p = ½, ¼, ⅛, ⅛: H = ½(1) + ¼(2) + ⅛(3) + ⅛(3) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 বিট/প্রতীক (< log₂4 = 2, কারণ সমসম্ভাব্য নয়)। সোর্স রিডানড্যান্সি = 1 − H/Hmax = 1 − 1.75/2 = 12.5%।

৪তথ্য হার (Information Rate) R

সংজ্ঞা উৎস প্রতি সেকেন্ডে r টি প্রতীক দিলে: R = r · H বিট/সেকেন্ড।
সমাধানকৃত উদাহরণ ✍ 4 kHz-এর একটি সিগন্যাল নাইকুইস্ট হারে স্যাম্পল করা হলো (r = 8000 স্যাম্পল/s), ৪টি লেভেলে কোয়ান্টাইজ করা হলো, p = ⅛, ⅜, ⅜, ⅛: H = 2 × ⅛ × 3 + 2 × ⅜ × log₂(8/3) = 0.75 + 1.061 = 1.811 বিট → R = 8000 × 1.811 ≈ 14.5 kbit/s (লেভেলগুলো সমসম্ভাব্য হলে: 16 kbit/s)।
মনে রাখার কৌশল "সমান হলে log, নইলে কম": যেকোনো অসমতা H কমায়।
পরীক্ষার ফাঁদ H = 2 বিট/প্রতীক, r = 2000/s → R = 4000 bit/s, 1000 নয়।

৫সোর্স কোডিং: দৈর্ঘ্য, দক্ষতা, ক্রাফট

হাই-ইল্ড
লক্ষ্য তথ্য না হারিয়ে গড় কোডওয়ার্ড দৈর্ঘ্য L যথাসম্ভব কম রাখা: ঘনঘন আসা প্রতীকে ছোট কোড (মোর্স কোডের ধারণা)।
সূত্র

গড় দৈর্ঘ্য: L = Σ pi li বিট/প্রতীক

দক্ষতা: η = H / L (বাইনারি কোড)

রিডানড্যান্সি: γ = 1 − η

D-ary কোড: η = H / (L log₂D)

ক্রাফট (প্রিফিক্স): Σ 2−li ≤ 1

স্থির দৈর্ঘ্যের কোড: l = ⌈log₂M⌉ বিট

শ্যাননের ১ম উপপাদ্য (সোর্স কোডিং) যেকোনো ইউনিকলি ডিকোডেবল কোডে L ≥ H; H ≤ L < H + 1 মেনে একটি প্রিফিক্স কোড সবসময় পাওয়া যায়, আর প্রতীকের লম্বা ব্লক একসাথে কোড করলে প্রতি প্রতীকের L ইচ্ছেমতো H-এর কাছে আনা যায়। η = 100% হয় কেবল তখনই, যখন প্রতিটি pi হলো ½-এর ঘাত (ডায়াডিক)।

৭হাফম্যান কোডিং (বটম-আপ, সর্বোত্তম)

লিখিত পরীক্ষায় প্রিয়
সংজ্ঞা ডি. এ. হাফম্যান (D. A. Huffman, MIT, ১৯৫২)। বারবার সবচেয়ে কম সম্ভাবনার দুটিকে একত্র করে পাতা (leaf) থেকে উপরের দিকে কোড ট্রি তৈরি করে। প্রতীক-ধরে-ধরে কোড করা সব প্রিফিক্স কোডের মধ্যে এটিই দেয় ন্যূনতম গড় দৈর্ঘ্য।
  1. সম্ভাবনাগুলো অবরোহী ক্রমে সাজাও
  2. সবচেয়ে ছোট দুটি একত্র করো: নতুন নোডের সম্ভাবনা = দুটির যোগফল; শাখা দুটিতে 0 ও 1 বসাও
  3. আবার সাজাও, পুনরাবৃত্তি করো যতক্ষণ না সম্ভাবনা 1-এর একটি নোড থাকে (M − 1 বার একত্রীকরণ)
  4. রুট থেকে পাতা পর্যন্ত পড়ে প্রতিটি কোডওয়ার্ড লেখো

  2. B + C = 0.17 + 0.17 = 0.34
  3. 0.31 + 0.34 = 0.65
  4. 0.65 + A 0.35 = 1.00

যৌথ (Joint): H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

ইকুইভোকেশন (Equivocation) H(X|Y): আউটপুট দেখার পরও ইনপুটের যে অনিশ্চয়তা থাকে (নয়েজে হারানো)

মিউচুয়াল ইনফরমেশন (যা আসলে পৌঁছায়):
I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X)

  • I ≥ 0, প্রতিসম · X, Y স্বাধীন → I = 0
  • নয়েজহীন চ্যানেল → H(X|Y) = 0, I = H(X)

১০শ্যাননের চ্যানেল কোডিং উপপাদ্য

হাই-ইল্ড
শ্যাননের ২য় উপপাদ্য তথ্য হার R < C হলে এমন চ্যানেল কোড আছে যা ত্রুটির সম্ভাবনা ইচ্ছেমতো কম করতে পারে (R = C হলো সীমারেখা)। R > C হলে কোনো কোডই তা পারে না: ত্রুটির সম্ভাবনা শূন্যের কাছে নামে না।
মনে রাখার কৌশল "C-এর নিচে কোড করে নিশ্চিন্ত; C-এর ওপরে ভুল অনিবার্য।" ভালো কোড আছে (টার্বো, LDPC, পোলার কাছাকাছি পৌঁছায়)।
পরীক্ষার ফাঁদ "ত্রুটিমুক্ত" মানে ত্রুটির সম্ভাবনা ইচ্ছেমতো কম, শূন্য ত্রুটি নয়; মূল্য দিতে হয় লম্বা কোড / বিলম্বে।

১১শ্যানন–হার্টলি ক্যাপাসিটি উপপাদ্য

হাই-ইল্ড
বিবৃতি ব্যান্ডউইডথ B (Hz), অ্যাডিটিভ হোয়াইট গাউসিয়ান নয়েজ (AWGN) ও গড় সিগন্যাল-টু-নয়েজ পাওয়ার অনুপাত S/N বিশিষ্ট ব্যান্ড-সীমিত চ্যানেলে:
C = B log₂(1 + S/N) bits/s  যেখানে N = N₀B (N₀ = নয়েজ পাওয়ার স্পেকট্রাল ঘনত্ব)।
  • S/N হলো রৈখিক (linear) পাওয়ার অনুপাত, কখনো dB নয়
  • C বাড়ে B-এর সাথে রৈখিকভাবে, S/N-এর সাথে কেবল লগারিদমিকভাবে
  • উচ্চ S/N-এ: +3 dB (×2) যোগ করে ≈ 1 bit/s/Hz
  • দ্রুত অনুমান: C ≈ B × SNRdB/3
  • S/N = 0 → C = 0; S/N → ∞ (B স্থির) → C → ∞
  • এটি ঊর্ধ্বসীমা: বাস্তব মডেম এর নিচে থাকে

১২অসীম ব্যান্ডউইডথ ও শ্যানন সীমা

হাই-ইল্ড

S ও N₀ স্থির: B বাড়ালে নয়েজও বাড়ে (N = N₀B)। B → ∞ হলে, ln(1 + x) ≈ x ধরে:

C∞ = (S/N₀) log₂e ≈ 1.44 S/N₀

ক্যাপাসিটি সম্পৃক্ত (saturate) হয়: অসীম B ≠ অসীম C।

S = Eb·C বসালে: Eb/N₀ ≥ ln 2 = 0.693 = −1.59 ≈ −1.6 dB

ন্যূনতম Eb/N₀ = (2C/B − 1)/(C/B): 1 bit/s/Hz-এ 0 dB, 2-এ 1.76 dB, 4-এ 5.74 dB।

পরীক্ষার ফাঁদ −1.6 dB সীমাটি Eb/N₀-এর (প্রতি বিটে শক্তি), SNR-এর নয়, এবং এর জন্য অসীম ব্যান্ডউইডথ লাগে। এর নিচে কোনো হারেই নির্ভরযোগ্য যোগাযোগ সম্ভব নয়।

১৪নাইকুইস্ট ক্যাপাসিটি (নয়েজহীন চ্যানেল)

নাইকুইস্ট বিট রেট B ব্যান্ডউইডথের নয়েজহীন চ্যানেল সর্বোচ্চ 2B প্রতীক/s (বড) বহন করে; M লেভেলে: C = 2B log₂M bits/s। শ্যানন নয়েজজনিত ঊর্ধ্বসীমা ঠিক করে; নাইকুইস্ট বলে কত লেভেল দিয়ে সেখানে পৌঁছানো যায়।
সমাধানকৃত উদাহরণ ✍ ① B = 3 kHz: M = 2 → 6 kbit/s; M = 4 → 12 kbit/s। ② B = 1 MHz, S/N = 63: শ্যানন C = 10⁶ × log₂64 = 6 Mbit/s; মার্জিন রেখে 4 Mbit/s নিলে → 2 × 10⁶ × log₂M = 4 × 10⁶ → M = 4। ③ নয়েজহীন 20 kHz লাইনে 265 kbit/s: log₂M = 6.625 → M = 98.7 → 128 লেভেল নাও।
মনে রাখার কৌশল নাইকুইস্ট = নয়েজ নেই, লেভেল গোনো (2B log₂M)। শ্যানন = S/N (B log₂(1 + S/N))। নয়েজযুক্ত চ্যানেলে উত্তর দুটির মধ্যে ছোটটি।

প্যারিটি চেক (একক বিট)

জোড় প্যারিটি: মোট 1-এর সংখ্যা (ডেটা + প্যারিটি) জোড়। 1011001-এ চারটি 1 → জোড় প্যারিটি বিট 0, বিজোড় প্যারিটি বিট 1। যেকোনো বিজোড় সংখ্যক ত্রুটি ধরে, জোড় সংখ্যক ধরে না, সংশোধন করতে পারে না (dmin = 2)।

হ্যামিং দূরত্ব

সূত্রের পাতা

I = log₂(1/p) বিট · p = 1 → I = 0

1 nat = 1.443 bit · 1 Hartley = 3.322 bit

H = Σ p log₂(1/p) · 0 ≤ H ≤ log₂M

বাইনারি: H(0.5) = 1 বিট · H(0.1) = 0.469

R = r · H bits/s · H(Xⁿ) = nH

L = Σ p l · η = H/L · γ = 1 − η

ক্রাফট Σ 2−l ≤ 1 · H ≤ L < H + 1

I(X;Y) = H(X) − H(X|Y) · C = max I

BSC: C = 1 − H(p) · p = 0.5 → C = 0

C = B log₂(1 + S/N), S/N রৈখিক

SNRdB = 10 log₁₀(S/N) · 30 dB = 1000

C∞ = 1.44 S/N₀ · Eb/N₀ ≥ −1.6 dB
