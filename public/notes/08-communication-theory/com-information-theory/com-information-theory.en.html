1The Digital Communication System

MCQ + Written
Definition Information theory is the mathematics of measuring, compressing and reliably transmitting information. Founded by Claude E. Shannon in "A Mathematical Theory of Communication" (Bell System Technical Journal, 1948): the "father of information theory".
Memory trick "Source coding Shrinks, Channel coding Covers." Source coding = compression (Huffman, ZIP: L, η); channel coding = protection (parity, Hamming, CRC: code rate k/n, dmin).

2Measure of Information

high-yield
Self-information A message of probability p carries I = log₂(1/p) = −log₂ p bits. The less likely the message, the more information it carries ("sun rose today" ≈ 0 bits; "earthquake in Dhaka" = many bits).
  • p = 1 (certain event) → I = 0; always I ≥ 0
  • p1 < p2 → I1 > I2
  • Independent messages: I(x₁x₂) = I(x₁) + I(x₂) (log turns × into +)
  • Binary digit with p = ½ → exactly 1 bit

Worked example ✍ p = 1/8 → I = log₂ 8 = 3 bits. A card from a 52-card deck: log₂ 52 = 5.70 bits; "it is an ace" (p = 4/52 = 1/13): log₂ 13 = 3.70 bits.
Exam trap Baud is a unit of symbol rate, not of information. And log₂ x = 3.322 log₁₀ x: keep that conversion for calculator-free MCQs.

3Entropy H: Average Information per Symbol

high-yield
Definition For a discrete memoryless source (DMS) with M symbols of probabilities p1 … pM: H(X) = Σ pi log₂(1/pi) bits/symbol. Entropy = average self-information = average uncertainty removed per symbol = the limit of lossless compression.
Bounds
0 ≤ H ≤ log₂M
H = 0 → one symbol certain (p = 1)
H = log₂M → all equiprobable (p = 1/M)
n-th extension: H(Xⁿ) = n·H(X)
Binary source: H(p) max 1 bit at p = 0.5

Worked example ✍ p = ½, ¼, ⅛, ⅛: H = ½(1) + ¼(2) + ⅛(3) + ⅛(3) = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bits/symbol (< log₂4 = 2, since not equiprobable). Source redundancy = 1 − H/Hmax = 1 − 1.75/2 = 12.5%.

4Information Rate R

Definition Source emitting r symbols/s: R = r · H bits/s.
Worked example ✍ A 4 kHz signal sampled at the Nyquist rate (r = 8000 samples/s), quantized to 4 levels with p = ⅛, ⅜, ⅜, ⅛: H = 2 × ⅛ × 3 + 2 × ⅜ × log₂(8/3) = 0.75 + 1.061 = 1.811 bits → R = 8000 × 1.811 ≈ 14.5 kbit/s (equiprobable levels: 16 kbit/s).
Memory trick "Equal → log, else less": any imbalance lowers H.
Exam trap H = 2 bits/symbol, r = 2000/s → R = 4000 bit/s, not 1000.

5Source Coding: Length, Efficiency, Kraft

high-yield
Goal Make the average codeword length L as small as possible without losing information: short codes for frequent symbols (the Morse idea).
Formulas

Average length: L = Σ pi li bits/symbol

Efficiency: η = H / L (binary code)

Redundancy: γ = 1 − η

D-ary code: η = H / (L log₂D)

Kraft (prefix): Σ 2−li ≤ 1

Fixed-length code: l = ⌈log₂M⌉ bits

Shannon's 1st theorem (source coding) For any uniquely decodable code L ≥ H; a prefix code with H ≤ L < H + 1 always exists, and coding long blocks of symbols brings L/symbol as close to H as we like. η = 100% only when every pi is a power of ½ (dyadic).

II001011111not prefix (0 starts 01), still uniquely decodable
III010110ambiguous: "01" = AB or C; Kraft sum = 1.5 > 1

6Shannon–Fano Coding (top-down)

  1. List the symbols in decreasing probability
  2. Split the list into two parts with totals as nearly equal as possible; give 0 to the upper part, 1 to the lower
  3. Repeat inside each part until every part holds one symbol
Worked example ✍ A 0.35, B 0.17, C 0.17, D 0.16, E 0.15

7Huffman Coding (bottom-up, optimal)

written favourite
Definition D. A. Huffman (MIT, 1952). Builds the code tree from the leaves up by repeatedly merging the two least probable entries. It gives the minimum average length of any symbol-by-symbol prefix code.
  1. Arrange the probabilities in decreasing order
  2. Merge the two smallest into one node whose probability is their sum; label the branches 0 and 1
  3. Re-sort and repeat until one node of probability 1 remains (M − 1 merges)
  4. Read each codeword from the root down to the leaf
Worked example ✍ Same source: A 0.35, B 0.17, C 0.17, D 0.16, E 0.15
  1. D + E = 0.15 + 0.16 = 0.31
  2. B + C = 0.17 + 0.17 = 0.34
  3. 0.31 + 0.34 = 0.65
  4. 0.65 + A 0.35 = 1.00
Codes: A = 0, B = 100, C = 101, D = 110, E = 111
L = 0.35 × 1 + 0.65 × 3 = 2.30 bits
η = 2.233/2.30 = 97.1%, γ = 2.9% · Kraft: ½ + 4 × ⅛ = 1 ✓

Exam trap Ties can give different codewords (and code-length variance), but the average length L is always the same. Dyadic source ½, ¼, ⅛, ⅛ → codes 0, 10, 110, 111, L = H = 1.75, η = 100%.
IT link Huffman (lossless) is the last stage of DEFLATE (ZIP, gzip, PNG = LZ77 + Huffman), of JPEG and of MP3 (their loss comes from earlier stages). Entropy explains why random or already-compressed data (H ≈ 8 bits per byte) cannot be zipped further.

8Joint & Conditional Entropy, Mutual Information

Joint: H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

Equivocation H(X|Y): input uncertainty left after seeing the output (lost to noise)

Mutual information (what gets through):
I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X)

  • I ≥ 0, symmetric · independent X, Y → I = 0
  • Noiseless channel → H(X|Y) = 0, I = H(X)

9Channel Models & Channel Capacity

high-yield
Definition A discrete memoryless channel (DMC) is described by its transition matrix P(yj|xi). Its capacity is the largest mutual information over all input distributions: C = max I(X;Y) bits per channel use.

BSC capacity (equiprobable input is optimal): C = 1 − H(p) bits/use

10Shannon's Channel Coding Theorem

high-yield
Shannon's 2nd theorem If the information rate R < C, there exists a channel code that makes the probability of error arbitrarily small. (R = C is the boundary.) If R > C, no code can do so: the error probability stays bounded away from zero.
Memory trick "Below C, code and be free; above C, errors you'll see." Good codes exist (turbo, LDPC, polar come close).
Exam trap "Error-free" means arbitrarily low error probability, not zero errors; the price is long codes / delay.

11Shannon–Hartley Capacity Theorem

high-yield
Statement For a band-limited channel of bandwidth B (Hz) with additive white Gaussian noise (AWGN) and average signal-to-noise power ratio S/N:
C = B log₂(1 + S/N) bits/s  where N = N₀B (N₀ = noise power spectral density).
  • S/N is a linear power ratio, never dB
  • C grows linearly with B, only logarithmically with S/N
  • High S/N: +3 dB (×2) adds ≈ 1 bit/s/Hz
  • Quick estimate: C ≈ B × SNRdB/3
  • S/N = 0 → C = 0; S/N → ∞ (fixed B) → C → ∞
  • An upper limit: real modems stay below it

Worked examples ✍

  2. Telephone line B = 3 kHz, SNR = 30 dB → S/N = 1000: C = 3000 × log₂1001 = 3000 × 9.97 ≈ 29.9 kbit/s (estimate: 3000 × 30/3 = 30 k ✓)

Exam trap Plugging "20 dB" as 20 gives log₂21 = 4.39 instead of log₂101 = 6.66. Convert dB to linear first.

12Infinite Bandwidth & the Shannon Limit

high-yield

Fixed S and N₀: wider B lets in more noise (N = N₀B). As B → ∞, with ln(1 + x) ≈ x:

C∞ = (S/N₀) log₂e ≈ 1.44 S/N₀

Capacity saturates: infinite B ≠ infinite C.

Put S = Eb·C: Eb/N₀ ≥ ln 2 = 0.693 = −1.59 ≈ −1.6 dB

Minimum Eb/N₀ = (2C/B − 1)/(C/B): 0 dB at 1 bit/s/Hz, 1.76 dB at 2, 5.74 dB at 4.

Exam trap −1.6 dB limits Eb/N₀ (energy per bit), not SNR, and needs infinite bandwidth. Below it, reliable communication is impossible at any rate.

For a fixed C, bandwidth can be traded for signal power: more B → less S/N (and less S) needed. Basis of spread spectrum / CDMA and wideband FM.

14Nyquist Capacity (noiseless channel)

Nyquist bit rate A noiseless channel of bandwidth B carries at most 2B symbols/s (baud); with M levels: C = 2B log₂M bits/s. Shannon sets the noise ceiling; Nyquist says how many levels reach it.
Worked examples ✍ ① B = 3 kHz: M = 2 → 6 kbit/s; M = 4 → 12 kbit/s. ② B = 1 MHz, S/N = 63: Shannon C = 10⁶ × log₂64 = 6 Mbit/s; use 4 Mbit/s for margin → 2 × 10⁶ × log₂M = 4 × 10⁶ → M = 4. ③ 265 kbit/s on a noiseless 20 kHz line: log₂M = 6.625 → M = 98.7 → use 128 levels.
Memory trick Nyquist = No noise, Number of levels (2B log₂M). Shannon = S/N (B log₂(1 + S/N)). Noisy channel: the answer is the smaller of the two.

15Error-Control (Channel) Coding Basics

MCQ + Written
Idea The channel coding theorem says reliable transmission needs controlled redundancy. An (n, k) block code maps k data bits to n-bit codewords: n − k check bits, code rate r = k/n (< 1).
ARQ (Automatic Repeat reQuest)FEC (Forward Error Correction)
Receiverdetects, asks for retransmissiondetects and corrects itself
Used inTCP, Wi-Fi MAC, CRC + retransmitsatellite, deep space, CD/DVD, 4G/5G

Parity check (single-bit)

Even parity: total 1s (data + parity) even. 1011001 has four 1s → even parity bit 0, odd parity bit 1. Detects any odd number of errors, misses even numbers, cannot correct (dmin = 2).

Hamming distance

d(a, b) = positions that differ = 1s in a ⊕ b. 10101 ⊕ 11110 = 01011 → d = 3. dmin = smallest distance between any two codewords.

dmin rules
Detect up to s = dmin − 1 errors
Correct up to t = ⌊(dmin − 1)/2⌋ errors
To correct t: dmin ≥ 2t + 1 · detect s: dmin ≥ s + 1

Hamming code (single-error correcting, dmin = 3)

Check bits r: 2r ≥ m + r + 1 (m data bits): m = 4 → r = 3, (7, 4); m = 7 (ASCII) → r = 4, (11, 7). Parity bits at positions 1, 2, 4, 8 …; P1 checks 1, 3, 5, 7 · P2: 2, 3, 6, 7 · P4: 4, 5, 6, 7.

Worked example ✍ Data 1011 (even parity) → positions 3, 5, 6, 7 = 1, 0, 1, 1. P1 = 1 ⊕ 0 ⊕ 1 = 0 · P2 = 1 ⊕ 1 ⊕ 1 = 1 · P4 = 0 ⊕ 1 ⊕ 1 = 0 → codeword 0110011.
Received 0110001: checks C4 C2 C1 = 1 1 0 → syndrome 110 = 6 → flip bit 6 → 0110011 ✓
Memory trick "Detect d − 1, correct half of that" (round down).
Exam trap Parity cannot correct even one error; CRC only detects.
