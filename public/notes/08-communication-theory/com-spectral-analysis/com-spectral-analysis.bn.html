পর্যায়কাল, জোড়/বিজোড় অংশ ও যোগফলের পাওয়ার

যোগফলের পর্যায়কাল: x1 + x2 পর্যায়বৃত্ত হবে কেবল যদি T1/T2 মূলদ সংখ্যা হয়; তখন T0 = LCM(T1, T2)। cos(2πt/3) + sin(2πt/5) → T0 = 15 s; cos t + cos πt → অনুপাত π → পর্যায়বৃত্ত নয়।

জোড়/বিজোড় অংশ: xe = [x(t) + x(−t)]/2, xo = [x(t) − x(−t)]/2। জোড় × জোড় = জোড়, বিজোড় × বিজোড় = জোড়, জোড় × বিজোড় = বিজোড়; ∫−aa (বিজোড়) dt = 0।

মনে রাখার কৌশল "এনার্জি সিগন্যাল মিলিয়ে যায়, পাওয়ার সিগন্যাল চিরকাল থাকে।" সসীম সময়ের বা ক্ষয়িষ্ণু → এনার্জি; পুনরাবৃত্ত বা ধ্রুব → পাওয়ার।
সমাধানকৃত উদাহরণ ✍ x(t) = 3cos(100πt) + 4sin(200πt): f = 50 Hz ও 100 Hz, তাই T0 = 20 ms। ভিন্ন ফ্রিকোয়েন্সির পাওয়ার যোগ হয়: P = 9/2 + 16/2 = 12.5 W

৩ফোরিয়ার সিরিজ (Fourier Series): তিনটি সমতুল্য রূপ

হাই-ইল্ড
সংজ্ঞা পর্যায়কাল T0-এর একটি পর্যায়বৃত্ত সিগন্যাল x(t) (ডিরিখলে শর্ত মানলে) = একটি DC পদ + হারমোনিকসমূহ, যেগুলো nf0 ফ্রিকোয়েন্সিতে থাকে; এখানে f0 = 1/T0 ও ω0 = 2π/T0। এর স্পেকট্রাম কিছু বিচ্ছিন্ন রেখা (লাইন স্পেকট্রাম)।

সম্পর্ক: c0 = a0 · cn = (an − jbn)/2 · বাস্তব x(t): c−n = cn* ⇒ |cn| = Cn/2 (n ≥ 1)

৪ডিরিখলে শর্ত ও প্রতিসাম্য

MCQ-তে প্রিয়

ডিরিখলে শর্ত (Dirichlet conditions) (যথেষ্ট, কিন্তু আবশ্যক নয়), প্রতি পর্যায়কালে:

  1. পরম সমাকলনযোগ্য: ∫T0 |x(t)| dt < ∞
  2. সসীম সংখ্যক গরিষ্ঠ ও লঘিষ্ঠ মান
  3. সসীম সংখ্যক সসীম বিচ্ছিন্নতা (discontinuity)

লাফের (jump) বিন্দুতে সিরিজ মধ্যবিন্দুতে অভিসারী হয়: [x(t⁺) + x(t⁻)]/2।

প্রতিসাম্যকী টিকে থাকে
জোড়: x(−t) = x(t)a0, an; bn = 0
বিজোড়: x(−t) = −x(t)শুধু bn
অর্ধ-তরঙ্গ: x(t ± T0/2) = −x(t)শুধু বিজোড় n
জোড় + অর্ধ-তরঙ্গশুধু বিজোড় কোসাইন
মনে রাখার কৌশল জোড় ↔ cos, বিজোড় ↔ sin (cos জোড়, sin বিজোড় ফাংশন)। "অর্ধ-তরঙ্গ প্রতিসাম্য রাখে বিজোড় হারমোনিক।"
শর্টকাট DC লেভেল যোগ করলে বদলায় শুধু a0। টাইম শিফটে বদলায় শুধু ফেজ θn, |cn| কখনো নয়। সময়ের স্কেল বদলালে f0 বদলায়, সহগ নয়।

৫সমাধানকৃত উদাহরণ: স্কয়ার ওয়েভ

লিখিত পরীক্ষায় প্রিয়

বিজোড় স্কয়ার ওয়েভ (বর্গ তরঙ্গ): 0 < t < T0/2-তে x(t) = +A এবং T0/2 < t < T0-তে −A।

  1. বিজোড় ⇒ a0 = an = 0; অর্ধ-তরঙ্গ প্রতিসম ⇒ শুধু বিজোড় n টিকে থাকে
  2. bn = (2/T0)[∫0T0/2 A sin nω0t dt − ∫T0/2T0 A sin nω0t dt] = (2A/nπ)(1 − cos nπ)
  3. n বিজোড়: bn = 4A/(nπ); n জোড়: bn = 0
ফলাফল x(t) = (4A/π) [sin ω0t + (1/3) sin 3ω0t + (1/5) sin 5ω0t + …]
  • মোট পাওয়ার P = A² (সবসময় |x| = A)
  • মৌলিক হারমোনিক: (4A/π)²/2 = 8A²/π² = P-এর ৮১.১%
  • n = 1, 3, 5 মিলে: ৯৩.৩%
  • লাফ থাকলে বিস্তার কমে 1/n হারে; ত্রিভুজ তরঙ্গে (কোণ বা kink থাকলে) 1/n² হারে (8A/(π²n²)); FT-তে: rect → sinc ∝ 1/f, ত্রিভুজ → sinc² ∝ 1/f²। যত মসৃণ ⇒ তত সরু স্পেকট্রাম
গিবস ফেনোমেনন (Gibbs phenomenon) লাফের কাছে খণ্ডিত (truncated) সিরিজ লাফের ≈ ৯% বেশি ওভারশুট করে (শীর্ষ ≈ 1.18A)। পদ বাড়ালে ঢেউ (ripple) সরু হয়, কিন্তু কখনো ছোট হয় না।

৬আয়তাকার পালস ট্রেন ও সিরিজ থেকে পাওয়ার

উচ্চতা A, প্রস্থ τ, পর্যায়কাল T0-এর পালস; ডিউটি সাইকেল d = τ/T0:

cn = A·d·sinc(n·d)

  • রেখাগুলো প্রতি f0 = 1/T0 পরপর; DC = A·d
  • sinc আবরণী (envelope), যার শূন্য বিন্দু 1/τ-এর গুণিতকে
  • d = 1/4 → n = ±4, ±8 … রেখাগুলো অনুপস্থিত
সিরিজের জন্য পার্সিভ্যাল
P = (1/T0)∫T0|x|² dt = Σ |cn|²
= a0² + Σ (an² + bn²)/2 = C0² + Σ Cn²/2
প্রতিটি হারমোনিকের পাওয়ার আলাদাভাবে যোগ হয় (অর্থোগোনালিটি)
সমাধানকৃত উদাহরণ ✍ x(t) = 1 + 2cos(2π·50t) + 4sin(2π·150t): T0 = 20 ms; a0 = 1, a1 = 2, b3 = 4 → c±1 = 1, c±3 = ∓2j (|c3| = 2); P = 1 + 2²/2 + 4²/2 = 11 W।
পরীক্ষার ফাঁদ τ স্থির রেখে T0 → ∞ করলে রেখাগুলো ঘন হয়ে আসে (ব্যবধান 1/T0 → 0) এবং লাইন স্পেকট্রাম হয়ে যায় অবিচ্ছিন্ন ফোরিয়ার ট্রান্সফর্ম। FT ঠিক এভাবেই জন্ম নেয় (নিচে)।

৭ফোরিয়ার ট্রান্সফর্ম (Fourier Transform)

হাই-ইল্ড

৯ব্যান্ডউইথ (Bandwidth)

  • পরম (absolute): B-এর বাইরে X(f) = 0 (শুধু আদর্শ ব্যান্ড-সীমিত সিগন্যালে)

  • নাল-টু-নাল / প্রথম নাল: মূল লোবের (main lobe) প্রস্থ
  • ৯৯% (ভগ্নাংশ-পাওয়ার): যে ব্যান্ডে মোট পাওয়ারের ৯৯% থাকে

১০কনভোলিউশন (Convolution)

লিখিত পরীক্ষায় প্রিয়
সংজ্ঞা y(t) = x(t) * h(t) = ∫ x(τ) h(t − τ) dτ। ইমপালস রেসপন্স h(t)-বিশিষ্ট রৈখিক সময়-অপরিবর্তী (LTI) সিস্টেমের আউটপুট = ইনপুটের সাথে h(t)-এর কনভোলিউশন। বিচ্ছিন্ন রূপ: y[n] = Σk x[k] h[n − k]।
  1. উল্টাও (flip) h(τ) → h(−τ)
  2. t পরিমাণ সরাও (shift) → h(t − τ)
  3. x(τ) দিয়ে গুণ করো
  4. সমাকলন করো (ক্ষেত্রফল) → y(t); প্রতিটি t-র জন্য পুনরাবৃত্তি

কোরিলেশন: উল্টানো ছাড়া কনভোলিউশন

সংজ্ঞা Rxy(τ) = ∫ x(t) y*(t − τ) dt = x(τ) * y*(−τ): উল্টানো নেই, বিনিময় বিধি খাটে না (Rxy(τ) = Ryx*(−τ)), F{Rxy} = X·Y*। অটোকোরিলেশন (Autocorrelation) Rx(τ): বাস্তব x-এর জন্য জোড়, τ = 0-তে সর্বোচ্চ, R(0) = এনার্জি, F{Rx} = |X(f)|²। IT সংযোগ: রাডার, GPS ও CDMA রিসিভার কোরিলেশনের শীর্ষবিন্দু থেকে বিলম্ব বের করে (ম্যাচড ফিল্টার)।

১৩স্যাম্পলিং উপপাদ্য (Sampling Theorem)

হাই-ইল্ড
বিবৃতি W Hz-এ ব্যান্ড-সীমিত (|f| > W-এ X(f) = 0) সিগন্যালকে fs ≥ 2W হারে নেওয়া স্যাম্পল থেকে (আদর্শ LPF দিয়ে) পুরোপুরি ফিরে পাওয়া যায়। নাইকুইস্ট রেট = 2W (ন্যূনতম fs); নাইকুইস্ট ইন্টারভাল = 1/(2W) (সর্বোচ্চ Ts)। নাইকুইস্ট ১৯২৮, শ্যানন ১৯৪৯।

আদর্শ (ইমপালস) স্যাম্পলিং: xs(t) = x(t) · Σ δ(t − nTs)

⇒ Xs(f) = fs Σ X(f − n fs): fs-এর প্রতিটি গুণিতকে স্পেকট্রামের একটি করে কপি (সময়ে গুণফল = ফ্রিকোয়েন্সিতে কনভোলিউশন)।

পুনরুদ্ধার: LPF কাট-অফ W ≤ fc ≤ fs − W; গার্ড ব্যান্ড = fs − 2W। আদর্শ ইন্টারপোলেশন: x(t) = Σ x(nTs) sinc((t − nTs)/Ts)।

অ্যালিয়াসিং (Aliasing): fs < 2W হলে কপিগুলো একটির ওপর আরেকটি পড়ে; তখন f ফ্রিকোয়েন্সির টোন দেখা দেয় fa = |f − k·fs|-এ (k = নিকটতম পূর্ণসংখ্যা, fa ≤ fs/2)। প্রতিকার: স্যাম্পলারের আগে অ্যান্টি-অ্যালিয়াসিং LPF (কাট-অফ fs/2) + 2W-এর বেশি হারে স্যাম্পলিং।

বাস্তবে: ন্যাচারাল (গেটেড) স্যাম্পলিংয়ে বেসব্যান্ড কপি অবিকৃত থাকে; ফ্ল্যাট-টপ (স্যাম্পল-অ্যান্ড-হোল্ড, PAM) একে sinc(fτ) দিয়ে গুণ করে → অ্যাপারচার ইফেক্ট, যা ইকুয়ালাইজার দিয়ে সারানো হয়।

১৪DFT ও FFT (ডিজিটাল স্পেকট্রাম)

DFT X[k] = Σn=0N−1 x[n] e−j2πkn/N, k = 0 … N − 1 · ইনভার্সে 1/N গুণক থাকে · বিন k ↔ f = k·fs/N · রেজোলিউশন Δf = fs/N
  • র‍্যাডিক্স-2 FFT (কুলি–টুকি, ১৯৬৫, N হবে 2-এর ঘাত): N²-এর বদলে (N/2)log₂Nটি কমপ্লেক্স গুণ
  • N = 1024: 1,048,576 → 5,120, ≈ 205 গুণ দ্রুত
  • fs = 8 kHz, N = 256 → Δf = 31.25 Hz
  • DFT-এর গুণফল ↔ সার্কুলার কনভোলিউশন
  • IT সংযোগ: OFDM (Wi-Fi, 4G/5G) IFFT/FFT ব্যবহার করে
সমাধানকৃত উদাহরণ ✍ x = [1, 1, 0, 0]-এর 4-পয়েন্ট DFT: X[k] = 1 + e−jπk/2 → X = [2, 1 − j, 0, 1 + j]। পার্সিভ্যাল যাচাই: Σ|x|² = 2 = (1/4)(4 + 2 + 0 + 2) ✓। X[0] = Σ x[n] সবসময় DC যোগফল।
