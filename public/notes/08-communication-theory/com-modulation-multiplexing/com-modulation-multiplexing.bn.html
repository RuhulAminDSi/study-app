১কেন মডুলেশন দরকার?

MCQ + লিখিত
সংজ্ঞা মডুলেশন (Modulation) = নিম্ন-কম্পাঙ্কের বার্তা সংকেত (message / baseband signal) অনুযায়ী উচ্চ-কম্পাঙ্কের বাহক তরঙ্গের (carrier) বিস্তার, কম্পাঙ্ক বা দশা পরিবর্তন করা। গ্রাহক প্রান্তে বার্তা ফিরে পাওয়ার প্রক্রিয়া ডিমডুলেশন (ডিটেকশন)।
  1. অ্যান্টেনার আকার: অ্যান্টেনা মোটামুটি λ/4 লম্বা হয়, λ = c/f
  2. মাল্টিপ্লেক্সিং: ভিন্ন ভিন্ন বাহকে অনেক স্টেশন (FDM)
  3. দূরত্ব: অডিওর চেয়ে RF অনেক ভালোভাবে বিকিরিত ও সঞ্চালিত হয়
  4. নয়েজ বনাম ব্যান্ডউইথ: FM ও স্প্রেড স্পেকট্রাম বেশি ব্যান্ডউইথ খরচ করে SNR বাড়ায়
সমাধানকৃত উদাহরণ ✍ 1 kHz টোনের জন্য অ্যান্টেনা: λ = 3×10⁸ / 10³ = 300 km → λ/4 = 75 km (অসম্ভব)। 1 MHz বাহকে λ/4 = 75 m; 100 MHz-এ (FM ব্যান্ড) মাত্র 0.75 m।
মনে রাখার কৌশল নামই বলে কী বদলায়: Amplitude (বিস্তার), Frequency (কম্পাঙ্ক), Phase (দশা); PAM/PWM/PPM = পালসের Amplitude / Width / Position। FM + PM = কোণ মডুলেশন (angle modulation)।
পরীক্ষার ফাঁদ PCM ও DM হলো অ্যানালগ থেকে ডিজিটাল রূপান্তরের (সোর্স কোডিং) পদ্ধতি, বাহক মডুলেশন নয়। এদের বিট পাঠানো হয় বেসব্যান্ডে (লাইন কোড) অথবা বাহকে (ASK/FSK/PSK)।

২অ্যামপ্লিচিউড মডুলেশন (AM)

হাই-ইল্ড
সংজ্ঞা বাহকের বিস্তার বার্তাকে অনুসরণ করে; কম্পাঙ্ক ও দশা স্থির থাকে। একক টোনে: s(t) = Ac[1 + m cos 2πfmt] cos 2πfct, মডুলেশন সূচক (modulation index) m = Am/Ac (m × 100% = শতকরা মডুলেশন)।

CRO-র ছবি থেকে: m = (Vmax − Vmin)/(Vmax + Vmin)। একাধিক টোন: mt = √(m₁² + m₂² + …)। সাধারণ বার্তায় s(t) = [Ac + kam(t)] cos 2πfct; এনভেলপ ঠিক থাকে কেবল 1 + kam(t) ≥ 0 হলে।

সমাধানকৃত উদাহরণ ✍ Vmax = 10 V, Vmin = 2 V → m = 8/12 = 0.67 (67%)। দুটি টোন m₁ = 0.3, m₂ = 0.4 → mt = √(0.09 + 0.16) = 0.5।

কমিউনিকেশন থিওরি · মডুলেশন ও মাল্টিপ্লেক্সিংAM স্পেকট্রাম · পাওয়ার · DSB-SC/SSB/VSB

AM স্পেকট্রাম: বাহক + দুটি সাইডব্যান্ড

cos A cos B দিয়ে বিস্তার করলে: s(t) = Ac cos ωct + (mAc/2) cos(ωc + ωm)t + (mAc/2) cos(ωc − ωm)t

→ বাহক + ঊর্ধ্ব (USB) + নিম্ন সাইডব্যান্ড (LSB); ব্যান্ডউইথ BW = 2fm (বার্তার সর্বোচ্চ কম্পাঙ্ক)।

fc = 1 MHz, fm = 5 kHz → LSB 995 kHz, USB 1005 kHz, BW = 10 kHz।

mনামফল
m < 1আন্ডার-মডুলেশনস্বাভাবিক; এনভেলপ = বার্তা
m = 1১০০% মডুলেশনবিকৃতিহীন সর্বোচ্চ গভীরতা; Vmin = 0
m > 1ওভার-মডুলেশনএনভেলপ বিকৃতি + স্প্ল্যাটার (বাড়তি সাইডব্যান্ড)
পাওয়ার (রোধ R) Pc = Ac²/2R · প্রতিটি সাইডব্যান্ড = m²Pc/4 · PSB = m²Pc/2
Pt = Pc(1 + m²/2)   It = Ic√(1 + m²/2)   η = PSB/Pt = m²/(2 + m²) ≤ 33.3% (m = 1-এও বাহক নেয় ২/৩ অংশ)
সমাধানকৃত উদাহরণ ✍ (ক) Pc = 1 kW, m = 0.6 → Pt = 1000 × 1.18 = 1180 W, PSB = 180 W (প্রতিটিতে 90 W), η = 180/1180 = 15.3%। (খ) Ic = 8 A, It = 8.93 A → m = √(2[(It/Ic)² − 1]) = √(2 × 0.246) = 0.70। (গ) Pc = 100 W, m = 1 → Pt = 150 W, দুই সাইডব্যান্ডে মোট 50 W।

৫FM ও PM (কোণ মডুলেশন)

হাই-ইল্ড
সংজ্ঞা FM: fi = fc + kfm(t)। PM: φ(t) = kpm(t)। বিস্তার স্থির, তাই পাওয়ার Ac²/2R মডুলেশনে বদলায় না।

কারসনের নিয়ম (Carson's rule): BW ≈ 2(Δf + fm) = 2fm(β + 1) · NBFM β ≪ 1 → BW ≈ 2fm (AM-এর মতো) · WBFM β > 1

৮পালস কোড মডুলেশন (PCM)

লিখিতে প্রিয়
PCM-এর সূত্র
L = 2ⁿ লেভেল · ধাপ Δ = Vpp/L
সর্বোচ্চ কোয়ান্টাইজেশন ত্রুটি = ±Δ/2 · নয়েজ পাওয়ার Δ²/12
SQNR ≈ 6.02n + 1.76 dB (পূর্ণ-স্কেল সাইন)
বিট রেট Rb = n · fs (× চ্যানেল সংখ্যা)
ন্যূনতম (নাইকুইস্ট) ব্যান্ডউইথ = Rb/2
মনে রাখার কৌশল "প্রতি বিটে 6 dB": প্রতিটি বাড়তি বিট L দ্বিগুণ করে, Δ অর্ধেক করে এবং SQNR প্রায় 6 dB বাড়ায়; কিন্তু বিট রেটও fs bit/s বাড়ে।

সমাধানকৃত উদাহরণ ও কম্প্যান্ডিং

সমাধানকৃত উদাহরণ ✍
  1. টেলিফোন ভয়েস (≤ 3.4 kHz), fs = 8 kHz, n = 8: Rb = 8000 × 8 = 64 kbps (DS0), L = 256, SQNR = 6.02 × 8 + 1.76 = 49.9 dB
  2. অডিও CD: 44.1 kHz × 16 বিট × 2 চ্যানেল = 1.4112 Mbps; SQNR = 6.02 × 16 + 1.76 = 98.1 dB
  3. SQNR ≥ 40 dB-এর জন্য বিট: n ≥ (40 − 1.76)/6.02 = 6.35 → n = 7; fs = 8 kHz হলে Rb = 56 kbps, ন্যূনতম BW = 28 kHz
  4. Vpp = 2 V, n = 3: L = 8, Δ = 2/8 = 0.25 V, সর্বোচ্চ ত্রুটি = ±0.125 V
কম্প্যান্ডিং প্রেরকে কম্প্রেস + গ্রাহকে এক্সপ্যান্ড = অসম (non-uniform) কোয়ান্টাইজেশন: দুর্বল সংকেতে সূক্ষ্ম ধাপ, ফলে SQNR প্রায় স্থির থাকে। μ-law (μ = 255): উত্তর আমেরিকা, জাপান · A-law (A = 87.6): ইউরোপ, বাংলাদেশ (E1)। দুটিই 8 বিট, 64 kbps (ITU-T G.711)।

PCM-এর সুবিধা: রিজেনারেটিভ রিপিটার (নয়েজ জমে না), এনক্রিপশন, ত্রুটি নিয়ন্ত্রণ, সহজ TDM। ব্যবহার: PSTN, CD, ডিজিটাল TV।

অসুবিধা: বেশি ব্যান্ডউইথ (4 kHz অ্যানালগ চ্যানেলের বদলে 64 kbps), কোয়ান্টাইজেশন নয়েজ, বিট ও ফ্রেম সিঙ্ক লাগে।

পরীক্ষার ফাঁদ n = প্রতি নমুনায় বিট, L = 2ⁿ লেভেল: 8 বিটে 256 লেভেল, 8 নয়। L দ্বিগুণ করলে বিট বাড়ে মাত্র ১টি। PCM-এর উদ্ভাবক অ্যালেক রিভস (Alec Reeves, ১৯৩৭)।

৯ডেল্টা মডুলেশন (DM) ও অ্যাডাপটিভ DM

হাই-ইল্ড
সংজ্ঞা DM প্রতি নমুনায় ১ বিট পাঠায়: সংকেত সিঁড়ি-আকৃতির আসন্নমানের (staircase approximation) ওপরে থাকলে 1 (Δ ধাপ ওপরে), নিচে থাকলে 0 (ধাপ নিচে)। অনেক বেশি ওভারস্যাম্পলিং লাগে (fs ≫ 2fm); বিট রেট = fs। প্রেরক = কম্পারেটর + ১-বিট কোয়ান্টাইজার + ফিডব্যাক লুপে ইন্টিগ্রেটর; গ্রাহক = ইন্টিগ্রেটর (অ্যাকিউমুলেটর) + LPF।
নিয়ম স্লোপ ওভারলোড হবে না যদি Δ · fs ≥ 2πfmAm (Am sin 2πfmt-এর সর্বোচ্চ ঢাল)।
বড় Δ ওভারলোড সারায় কিন্তু গ্র্যানুলার নয়েজ বাড়ায়; ছোট Δ-তে উল্টোটা।
সমাধানকৃত উদাহরণ ✍ Am = 1 V, fm = 1 kHz, fs = 64 kHz → Δmin = 2π × 1000 × 1/64000 = 0.098 V; বিট রেট = 64 kbps।

ADM: ধাপের আকার (step size) নিজে থেকে বদলায়: পরপর একই বিট এলে (খাড়া ঢাল) বাড়ে, বিট পাল্টাপাল্টি হলে (সমতল) কমে → ওভারলোড ও গ্র্যানুলার নয়েজ দুটোই কমে; বিস্তৃত ডাইনামিক রেঞ্জের সংকেতে উপযোগী। CVSD (continuously variable slope DM) ব্লুটুথ ভয়েস ও সামরিক রেডিওতে ব্যবহৃত। DPCM পূর্বানুমিত নমুনা থেকে পার্থক্যকে কয়েক বিটে কোয়ান্টাইজ করে; ADPCM (ITU-T G.726) 32 kbps-এ টোল-মানের ভয়েস দেয় (DECT কর্ডলেস ফোন, VoIP)।
