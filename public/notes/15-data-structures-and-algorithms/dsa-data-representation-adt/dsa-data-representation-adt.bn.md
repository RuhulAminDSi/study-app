## ১. বিট, ডেটা টাইপ ও সাইনড ইন্টিজার

- **অভ্যন্তরীণ ডেটা উপস্থাপন (Internal data representation)** হলো সংখ্যা, অক্ষর ও নির্দেশনাকে *বাইনারি প্যাটার্নে* সংরক্ষণের পদ্ধতি। বিট = একটি 0/1, নিবল = 4 বিট, বাইট = 8 বিট, ওয়ার্ড = CPU-র স্বাভাবিক একক (16/32/64 বিট)। প্যাটার্নের অর্থ ঠিক করে **টাইপ**: `01000001` ইন্টিজার হিসেবে 65, ASCII হিসেবে 'A'।
- n বিটে **2^n প্যাটার্ন**, তাই আনসাইনড n-বিট ইন্টিজারের রেঞ্জ **0 … 2^n − 1** (8-বিট 0…255, 16-বিট 0…65535, 32-বিট 0…4 294 967 295)।
- **প্রিমিটিভ বনাম নন-প্রিমিটিভ।** প্রিমিটিভ (Primitive): ভাষায় অন্তর্নির্মিত — int, char, float, double, boolean, pointer। নন-প্রিমিটিভ: এগুলো দিয়ে তৈরি — **লিনিয়ার** (অ্যারে, লিস্ট, স্ট্যাক, কিউ) ও **নন-লিনিয়ার** (ট্রি, গ্রাফ)। ১টি হেক্স অঙ্ক = 4 বিট।

| C টাইপ | আকার | সাধারণ রেঞ্জ |
|---|---|---|
| char / unsigned char | 1 B | −128…127 / 0…255 |
| short | 2 B | −32768…32767 |
| int / long long | 4 / 8 B | −2^31…2^31−1 / −2^63…2^63−1 |
| float / double | 4 / 8 B | ~7 / ~15–16 গুরুত্বপূর্ণ অঙ্ক |

- **n বিটে ঋণাত্মক সংখ্যা রাখার তিন উপায়।** *সাইন-ম্যাগনিচুড (Sign-magnitude)*: MSB = চিহ্ন (0 +, 1 −), বাকিটা |x|। *1's কমপ্লিমেন্ট*: +x-এর সব বিট উল্টাও। *2's কমপ্লিমেন্ট*: সব বিট উল্টে **1 যোগ** (= 2^n − x)। CPU ব্যবহার করে 2's কমপ্লিমেন্ট: শূন্য একটিই, আর একই অ্যাডারে যোগ-বিয়োগ দুটোই।

| পদ্ধতি | n-বিট রেঞ্জ | 8-বিট রেঞ্জ | শূন্য | −5 (4-বিট) | −5 (8-বিট) |
|---|---|---|---|---|---|
| সাইন-ম্যাগনিচুড | −(2^(n−1)−1) … 2^(n−1)−1 | −127 … 127 | **দুটি** (+0, −0) | 1101 | 10000101 |
| 1's কমপ্লিমেন্ট | −(2^(n−1)−1) … 2^(n−1)−1 | −127 … 127 | **দুটি** | 1010 | 11111010 |
| **2's কমপ্লিমেন্ট** | **−2^(n−1) … 2^(n−1)−1** | **−128 … 127** | একটি | **1011** | **11111011** |

- 💡 **কৌশল:** "**প্রথম 1 পর্যন্ত কপি, বাকিটা উল্টাও।**" ডান দিক থেকে +x পড়ো, প্রথম 1 সহ সেখান পর্যন্ত বিট হুবহু রাখো, বাকিগুলো উল্টাও: 00000101 → 11111011। **ডিকোড** করতে MSB-এর ওজন −2^(n−1): 11111011 = −128 + 123 = −5।
- ⚠ **ফাঁদ:** 2's কমপ্লিমেন্ট **অসম** — 8 বিটে −128 আছে, +128 নেই। "−5-এর 2's কমপ্লিমেন্ট" প্রশ্নে 10000101 (সাইন-ম্যাগনিচুড) ও 11111010 (1's) ভুল বিকল্প। বিট বাড়াতে **সাইন বিট কপি** করো (সাইন এক্সটেনশন): 1011 → 1111 1011।
- **ওভারফ্লো (Overflow)** কেবল তখনই সম্ভব যখন **একই চিহ্নের দুটি সংখ্যা যোগ** করে ফল **বিপরীত চিহ্নের** হয় (MSB-তে ঢোকা ক্যারি ≠ বের হওয়া ক্যারি)। বিপরীত চিহ্নে কখনো ওভারফ্লো হয় না; MSB থেকে শুধু ক্যারি বের হলে তা ফেলে দেওয়া হয়।
- ✍ সমাধানকৃত উদাহরণ — 8-বিট। 100 + 50: `01100100 + 00110010 = 10010110` → দুটি ধনাত্মক থেকে MSB 1: **ওভারফ্লো** (প্যাটার্নটি −106)। 7 − 5 = 7 + (−5): `00000111 + 11111011 = 1 00000010` → ক্যারি বাদ → **2**, ওভারফ্লো নেই।

## ২. IEEE 754 ফ্লোটিং পয়েন্ট ও ক্যারেক্টার কোড

- বাস্তব সংখ্যা রাখা হয় নরমালাইজড রূপে **(−1)^S × 1.M × 2^(E − bias)**, তিনটি ফিল্ডে: **সাইন** S, **বায়াসড এক্সপোনেন্ট** E ও **ম্যান্টিসা** (ভগ্নাংশ) M। শুরুর 1 সংরক্ষিত হয় না (হিডেন বিট)।

| ফরম্যাট | সাইন | এক্সপোনেন্ট | ম্যান্টিসা | বায়াস | নির্ভুলতা |
|---|---|---|---|---|---|
| **সিঙ্গেল (32)** | 1 | 8 | 23 | **127** | ~7 দশমিক অঙ্ক |
| **ডাবল (64)** | 1 | 11 | 52 | **1023** | ~15–16 দশমিক অঙ্ক |

- বিশেষ প্যাটার্ন: এক্সপোনেন্ট সব 0 → ±0 (M = 0) বা ডিনরমাল সংখ্যা; এক্সপোনেন্ট সব 1 → ±∞ (M = 0) বা NaN।
- ✍ সমাধানকৃত উদাহরণ — −6.75 থেকে সিঙ্গেল প্রিসিশন। (১) ঋণাত্মক → S = 1। (২) 6.75 = 110.11₂। (৩) নরমালাইজ: 1.1011 × 2²; হিডেন 1 বাদ, M = 1011 এবং পরে ১৯টি শূন্য। (৪) E = 2 + 127 = 129 = 10000001। (৫) `1 10000001 10110000000000000000000` = **C0D80000** (হেক্স)। যাচাই: 1.1011₂ = 1.6875, × 4 = 6.75 ✓।
- 💡 **কৌশল:** "**1-8-23, 127; 1-11-52, 1023।**" k-বিট এক্সপোনেন্টে বায়াস সবসময় 2^(k−1) − 1। ফিল্ডের ক্রম **S-E-M**।
- ⚠ **ফাঁদ:** 0.1-এর নিখুঁত বাইনারি রূপ নেই (0.000110011… পৌনঃপুনিক), তাই C, Java ও Python-এ `0.1 + 0.2 == 0.3` **মিথ্যা**। ফ্লোট তুলনা করো |a − b| < ε দিয়ে; টাকা রাখো পূর্ণসংখ্যায় (পয়সা)।

| কোড | আকার | পরীক্ষায় যে তথ্য আসে |
|---|---|---|
| **BCD** (8421) | প্রতি দশমিক অঙ্কে 4 বিট | 59 → 0101 1001; 1010–1111 অবৈধ; 59-এর বিশুদ্ধ বাইনারি 111011 |
| **ASCII** | **7 বিট**, 128 অক্ষর | 'A' = 65 (41h), 'a' = 97 (61h), '0' = 48 (30h); বড়-ছোট হাতের পার্থক্য 32 |
| এক্সটেন্ডেড ASCII / EBCDIC | 8 বিট | 256 অক্ষর / IBM মেইনফ্রেম |
| **ইউনিকোড** | একটি অক্ষর-*সেট* | U+0000 … U+10FFFF; বাংলা ব্লক U+0980–U+09FF; 'অ' = U+0985 |
| **UTF-8** · UTF-16 · UTF-32 | 1–4 · 2 বা 4 · 4 বাইট | UTF-8 ASCII-সামঞ্জস্যপূর্ণ; 'অ' = E0 A6 85 |

- ✍ সমাধানকৃত উদাহরণ — এন্ডিয়ানেস। `0x12345678` রাখা হলো অ্যাড্রেস 100-এ। **বিগ-এন্ডিয়ান**: 100→12, 101→34, 102→56, 103→78। **লিটল-এন্ডিয়ান**: 100→78, 101→56, 102→34, 103→12। x86 লিটল-এন্ডিয়ান; **নেটওয়ার্ক বাইট অর্ডার বিগ-এন্ডিয়ান**।
- ⚠ **ফাঁদ:** "ইউনিকোড 16-বিট" কথাটি পুরোনো: ইউনিকোড 1 114 112 কোড পয়েন্টের সেট, আর UTF-8/16/32 তার এনকোডিং। ASCII 7-বিট, 8 নয়। `int`-এর আকার কম্পাইলার-নির্ভর (C-তে কমপক্ষে 16 বিট)।

## ৩. অ্যাবস্ট্রাক্ট ডেটা টাইপ

- **অ্যাবস্ট্রাক্ট ডেটা টাইপ (ADT)** হলো এমন গাণিতিক মডেল যেখানে টাইপকে সংজ্ঞায়িত করা হয় *তার মান ও সেগুলোর ওপর অপারেশন* (ও তাদের নিয়ম) দিয়ে, **কীভাবে ইমপ্লিমেন্ট করা হলো তা দিয়ে নয়**। **ডেটা স্ট্রাকচার** হলো মেমোরিতে ডেটা সাজানোর বাস্তব উপায়, যা কোনো ADT-কে ইমপ্লিমেন্ট করে। "স্ট্যাক" একটি ADT; "`top` ইনডেক্সসহ অ্যারে" তার একটি ডেটা স্ট্রাকচার।

| বিষয় | ADT | ডেটা স্ট্রাকচার |
|---|---|---|
| স্তর | লজিক্যাল, বিমূর্ত | ফিজিক্যাল, বাস্তব |
| বলে | **কী** করে | **কীভাবে** করে |
| ধারণ করে | মান + অপারেশন + নিয়ম | মেমোরি লেআউট + অ্যালগরিদম |
| উদাহরণ | Stack, Queue, List, Map | অ্যারে, লিংকড লিস্ট, হিপ, হ্যাশ টেবিল |
| কোডে | ইন্টারফেস / হেডার | ক্লাস / .c ফাইল |

| ADT | মূল অপারেশন | নিয়ম | যা দিয়ে তৈরি |
|---|---|---|---|
| লিস্ট | insert, delete, get(i), search | অবস্থান | অ্যারে, লিংকড লিস্ট |
| স্ট্যাক | push, pop, peek, isEmpty | **LIFO** | অ্যারে, লিংকড লিস্ট |
| কিউ | enqueue, dequeue, front, rear | **FIFO** | সার্কুলার অ্যারে, লিস্ট |
| ডেক (Deque) | দুই প্রান্তেই insert/delete | দুই প্রান্ত | ডাবলি লিংকড লিস্ট |
| প্রায়োরিটি কিউ | insert, extract-max, peek | অগ্রাধিকার | **বাইনারি হিপ** |
| সেট / ম্যাপ | add, contains · put(k,v), get(k) | ডুপ্লিকেট নেই | হ্যাশ টেবিল, BST |
| ট্রি | insert, delete, search, traverse | এক প্যারেন্ট | লিংকড নোড, অ্যারে |
| গ্রাফ | addVertex, addEdge, adjacent | যেকোনো থেকে যেকোনো | অ্যাডজেসেন্সি ম্যাট্রিক্স / লিস্ট |

- **ADT কেন — তিনটি সুবিধা।** *এনক্যাপসুলেশন (Encapsulation)* বা তথ্য গোপন: ব্যবহারকারী শুধু অপারেশন দেখে, তাই ভেতরের রূপ বদলালেও তার কোড ভাঙে না। *পুনর্ব্যবহারযোগ্যতা (Reusability)*: এক ADT, নানা ইমপ্লিমেন্টেশন, বহু প্রোগ্রাম। *মডিউলারিটি (Modularity)*: প্রতিটি মডিউল আলাদাভাবে লেখা, পরীক্ষা ও ডিবাগ করা যায়। মিলে **ডেটা অ্যাবস্ট্রাকশন**, যা OOP-র ক্লাসের ভিত্তি।
- 💡 **কৌশল:** **ADT = মেনু; ডেটা স্ট্রাকচার = রান্নাঘর।** রান্নাঘর বদলাও, মেনু একই। সুবিধা: "**E-R-M**"।
- ⚠ **ফাঁদ:** BFS ও DFS গ্রাফের ওপর চালানো **অ্যালগরিদম**, গ্রাফ ADT-র অপারেশন নয়। প্রায়োরিটি কিউ **FIFO নয়**। লিংকড লিস্ট ডেটা স্ট্রাকচার; "লিস্ট" হলো ADT। "ADT সংজ্ঞায়িত করে…?" → **আচরণ**, স্টোরেজ নয়।

## ৪. অ্যারে ও অ্যাড্রেস নির্ণয়

- **অ্যারে (Array)** হলো *একই টাইপের উপাদানের নির্দিষ্ট আকারের সংগ্রহ, পাশাপাশি (contiguous) মেমোরিতে*, যা ইনডেক্স দিয়ে পাওয়া যায়। যেকোনো উপাদানের অ্যাড্রেস সূত্রে বের হয়, তাই **অ্যাক্সেস O(1)** (র‍্যান্ডম অ্যাক্সেস); মাঝখানে ইনসার্ট বা ডিলিটে উপাদান সরাতে হয়, **O(n)**।
- **অ্যাড্রেস সূত্র** (B = বেস অ্যাড্রেস, w = প্রতি উপাদানের বাইট, L = নিম্নসীমা):
  - 1-D: LOC(A[i]) = **B + w(i − L)**; উপাদান সংখ্যা = U − L + 1।
  - 2-D, m সারি × n কলাম, **রো-মেজর (Row-major)** (C, C++, Java, Python): LOC(A[i][j]) = **B + w[(i − Lr)·n + (j − Lc)]**।
  - 2-D, **কলাম-মেজর (Column-major)** (Fortran, MATLAB): LOC(A[i][j]) = **B + w[(j − Lc)·m + (i − Lr)]**।
  - রো-মেজরে গুণ হয় **কলাম সংখ্যা n** দিয়ে; কলাম-মেজরে **সারি সংখ্যা m** দিয়ে।
- ✍ সমাধানকৃত উদাহরণ — `int A[20][30]` (0-ভিত্তিক, m = 20, n = 30), B = 1000, w = 4, A[5][10] বের করো। রো-মেজর: 1000 + 4(5 × 30 + 10) = 1000 + 4 × 160 = **1640**। কলাম-মেজর: 1000 + 4(10 × 20 + 5) = 1000 + 4 × 205 = **1820**।
- ✍ সমাধানকৃত উদাহরণ — `A[5..50]`, B = 200, w = 2: উপাদান = 50 − 5 + 1 = **46**; LOC(A[20]) = 200 + 2(20 − 5) = **230**। `A[−5..10]`-এ উপাদান 10 − (−5) + 1 = **16**টি।

| n উপাদানের অ্যারেতে অপারেশন | সময় | কেন |
|---|---|---|
| A[i] অ্যাক্সেস | **O(1)** | সূত্রে অ্যাড্রেস |
| সার্চ (অসাজানো / সাজানো) | O(n) / O(log n) | লিনিয়ার স্ক্যান / বাইনারি সার্চ |
| শেষে ইনসার্ট / ডিলিট | O(1) | সরাতে হয় না (জায়গা থাকলে) |
| k অবস্থানে ইনসার্ট / ডিলিট | **O(n)** | n − k টি উপাদান সরাতে হয় |

- **স্পার্স ম্যাট্রিক্স (Sparse matrix):** বেশিরভাগ উপাদান 0; শুধু অশূন্যগুলো রাখো **ট্রিপলেট (সারি, কলাম, মান)** হিসেবে বা লিংকড লিস্টে। 50টি অশূন্যসহ 100 × 100 ম্যাট্রিক্সে 10 000-এর বদলে লাগে 150 ঘর। n × n লোয়ার-ট্রায়াঙ্গুলার ম্যাট্রিক্সে উপাদান **n(n+1)/2**।
- ⚠ **ফাঁদ:** **নিম্নসীমা** দেখো (1-ভিত্তিক `A[1..m][1..n]` হলে আগে i ও j থেকে 1 বাদ দাও), আর প্রশ্নে রো-মেজর না কলাম-মেজর পড়ে নাও। C বাউন্ড যাচাই করে না: `int A[10]`-এ `A[10]` **অনির্ধারিত আচরণ (undefined behaviour)**, কোনো এরর বার্তা নয়।

## ৫. লিংকড লিস্ট: সিঙ্গলি, ডাবলি, সার্কুলার

- **লিংকড লিস্ট (Linked list)** হলো *নোডের* ধারা; প্রতিটি নোডে ডেটা ও পরের নোডের **পয়েন্টার**, নোডগুলো মেমোরির যেকোনো জায়গায় থাকতে পারে। `head` পয়েন্টার প্রথম নোডে পৌঁছায়, শেষ নোডের `next` হলো NULL। রান-টাইমে আকার বাড়ে-কমে; র‍্যান্ডম অ্যাক্সেস নেই, তাই k-তম নোডে যেতে **O(n)**।

```c
struct Node { int data; struct Node *next; };

/* insert at head: O(1) */
struct Node *n = malloc(sizeof *n);
n->data = x;  n->next = head;  head = n;

/* delete the node after p: O(1) */
struct Node *t = p->next;  p->next = t->next;  free(t);
```

| ধরন | নোড | ব্যবহার |
|---|---|---|
| সিঙ্গলি | data, next | স্ট্যাক, সাধারণ লিস্ট |
| ডাবলি | prev, data, next | ব্রাউজার back/forward, LRU ক্যাশ, ডেক |
| সার্কুলার | শেষ → প্রথম | **রাউন্ড-রবিন শিডিউলিং** |
| সার্কুলার ডাবলি | দুই লিংকই ঘোরে | মিউজিক প্লেলিস্ট, ফিবোনাচি হিপের রুট |
| হেডার লিস্ট | ডামি প্রথম নোড | খালি লিস্টের আলাদা কেস লাগে না |

| বিষয় | অ্যারে | লিংকড লিস্ট |
|---|---|---|
| মেমোরি | পাশাপাশি, নির্দিষ্ট আকার | ছড়ানো, রান-টাইমে বাড়ে |
| k-তম অ্যাক্সেস | **O(1)** | **O(n)** |
| সামনে ইনসার্ট/ডিলিট | O(n) (সরাতে হয়) | **O(1)** |
| শেষে ইনসার্ট | O(1) জায়গা থাকলে | O(n), tail পয়েন্টার থাকলে O(1) |
| বাড়তি জায়গা | নেই (অব্যবহৃত ঘর নষ্ট হতে পারে) | প্রতি নোডে একটি পয়েন্টার (ডাবলিতে দুটি) |

- 💡 **কৌশল:** "**আগে জোড়া, পরে কাটা।**" পুরোনো পয়েন্টার ঘোরানোর আগে নতুন নোডের `next` সেট করো, নইলে লিস্টের বাকিটা হারায়। মাঝের নোড: স্লো/ফাস্ট পয়েন্টার। সাইকেল: ফ্লয়েডের কচ্ছপ-খরগোশ।
- ⚠ **ফাঁদ:** **সিঙ্গলি** লিস্টে নির্দিষ্ট নোড ডিলিট করতে তার **আগের নোড** লাগে (খুঁজতে O(n)); **ডাবলি** লিস্টে **O(1)**। সিঙ্গলি লিস্ট উল্টাতে O(n) সময় ও O(1) জায়গা (prev, curr, next)।

## ৬. স্ট্যাক, ইনফিক্স → পোস্টফিক্স ও পোস্টফিক্স মূল্যায়ন

- **স্ট্যাক (Stack)** *এক প্রান্তে, top-এ* ইনসার্ট (**push**) ও ডিলিট (**pop**) করে: **শেষে ঢুকলে আগে বের (LIFO)**। অ্যারে রূপে `top = −1` মানে খালি; `top == MAX−1` অবস্থায় push হলো **ওভারফ্লো**; `top == −1` অবস্থায় pop হলো **আন্ডারফ্লো**। লিংকড স্ট্যাক head-এ push/pop করে, মেমোরি না ফুরালে ওভারফ্লো নেই। সব অপারেশন **O(1)**।

```c
void push(int x) {
  if (top == MAX-1) { puts("Overflow"); return; }
  s[++top] = x; }
int pop(void) {
  if (top == -1) { puts("Underflow"); return -1; }
  return s[top--]; }
```

- **প্রয়োগ:** ফাংশন কল ও রিকার্শন (কল স্ট্যাকে রিটার্ন অ্যাড্রেস ও লোকাল ভেরিয়েবল) · এক্সপ্রেশন রূপান্তর ও মূল্যায়ন · ব্র্যাকেট মিলানো · undo/redo · ব্রাউজার back · ব্যাকট্র্যাকিং · DFS · স্ট্রিং উল্টানো।
- **ইনফিক্স → পোস্টফিক্সের নিয়ম।** বাম থেকে ডানে পড়ো। অপারেন্ড → আউটপুট। `(` → push। `)` → `(` না আসা পর্যন্ত pop করে আউটপুট। অপারেটর → top-এ বেশি বা সমান অগ্রাধিকারের অপারেটর থাকলে pop (সমান হলে কেবল বাম-সহযোগী হলে), তারপর push। শেষে সব pop। অগ্রাধিকার **^ > * / > + −**; ^ ডান-সহযোগী।

| পড়া | স্ট্যাক | আউটপুট |
|---|---|---|
| A | | A |
| + | + | A |
| B | + | A B |
| * | + * | A B |
| C | + * | A B C |
| − | − | A B C * + |
| D, /, E | − / | A B C * + D E |
| শেষ | | **A B C * + D E / −** |

- ✍ সমাধানকৃত উদাহরণ — পোস্টফিক্স মূল্যায়ন। অপারেন্ড → push; অপারেটর → pop B (top), pop A, push A op B। `2 3 4 * +`: push 2, 3, 4; * → 12; + → 2 + 12 = **14** (ইনফিক্সে 2 + 3 * 4)। `5 6 2 + * 12 4 / −`: 6 + 2 = 8; 5 × 8 = 40; 12 / 4 = 3; 40 − 3 = **37**।
- ✍ সমাধানকৃত উদাহরণ — তিন নোটেশন। ইনফিক্স `(A + B) * (C − D)`; পোস্টফিক্স (রিভার্স পোলিশ) **A B + C D − \***; প্রিফিক্স (পোলিশ) **\* + A B − C D**। পোস্টফিক্সে বন্ধনী বা অগ্রাধিকারের নিয়ম লাগে না।
- 💡 **কৌশল:** "**প্লেটের স্তূপ।**" পোস্টফিক্স মূল্যায়নে **দ্বিতীয় pop হলো বাম অপারেন্ড** — − ও /-এর ক্ষেত্রে জরুরি।
- ⚠ **ফাঁদ:** `2 3 4 * +` = **14, 20 নয়** (20 হতো `2 3 + 4 *`)। 1, 2, 3 ক্রমে push করলে কখনো 3, 1, 2 ক্রমে pop হয় না। বেস কেসে না পৌঁছানো রিকার্শনের শেষ **স্ট্যাক ওভারফ্লো**।

## ৭. কিউ: লিনিয়ার, সার্কুলার, ডেক, প্রায়োরিটি

- **কিউ (Queue)** **rear**-এ ইনসার্ট (enqueue) ও **front** থেকে ডিলিট (dequeue) করে: **আগে ঢুকলে আগে বের (FIFO)**। সাধারণ অ্যারেতে front ও rear শুধু সামনে এগোয়, তাই খালি হওয়া ঘর আর ব্যবহার হয় না (অর্ধেক খালি থেকেও "পূর্ণ"); **সার্কুলার কিউ** ইনডেক্সকে `% n` দিয়ে ঘুরিয়ে আনে।

| সার্কুলার কিউ (n আকারের অ্যারে) | শর্ত |
|---|---|
| Enqueue | `rear = (rear + 1) % n; Q[rear] = x` |
| Dequeue | `x = Q[front]; front = (front + 1) % n` |
| **পূর্ণ** | **(rear + 1) % n == front** |
| **খালি** | `front == −1` (এক-ঘর-খালি রূপে `front == rear`) |
| উপাদান সংখ্যা | `(rear − front + n) % n` (এক-ঘর-খালি রূপে) |

- দুই রীতি: `front = rear = −1` মানে খালি — n ঘরই ব্যবহারযোগ্য; `front = rear = 0` মানে খালি — একটি ঘর ফাঁকা থাকে, ধারণক্ষমতা n − 1।
- ✍ সমাধানকৃত উদাহরণ — ট্রেস। enqueue(1), enqueue(2), enqueue(3) → [1, 2, 3]; dequeue() সরায় 1 → [2, 3]; enqueue(4) → [2, 3, 4]; dequeue() সরায় 2 → [3, 4]। front = **3**, rear = 4। একই push-pop স্ট্যাকে করলে থাকে [1, 2], top-এ 2।

| ধরন | নিয়ম | সাধারণ ব্যবহার |
|---|---|---|
| লিনিয়ার কিউ | FIFO, ইনডেক্স শুধু সামনে এগোয় | সাধারণ বাফার |
| সার্কুলার কিউ | FIFO, ইনডেক্স % n দিয়ে ঘোরে | CPU **রাউন্ড-রবিন**, কিবোর্ড ও নেটওয়ার্ক বাফার |
| ডেক | **দুই** প্রান্তেই ইনসার্ট ও ডিলিট | স্লাইডিং-উইন্ডো সর্বোচ্চ, undo ইতিহাস |
| সীমিত ডেক | ইনপুট-সীমিত: এক প্রান্তে ইনসার্ট · আউটপুট-সীমিত: এক প্রান্তে ডিলিট | — |
| প্রায়োরিটি কিউ | সর্বোচ্চ অগ্রাধিকার আগে; সমান হলে FIFO | ডাইকস্ট্রা, OS জব শিডিউলিং, হাফম্যান |

- 💡 **কৌশল:** "**ব্যাংকের কাউন্টারের লাইন।**" পেছনে দাঁড়াও, সামনে থেকে বের হও। **D**ouble-**E**nded **QUE**ue = ডেক। ব্যবহার: BFS, প্রিন্টার স্পুলিং, CPU শিডিউলিং, দ্রুত ও ধীর ডিভাইসের মাঝে বাফার।
- ⚠ **ফাঁদ:** প্রায়োরিটি কিউ সবচেয়ে ভালো **বাইনারি হিপে** (insert ও delete-max দুটোই O(log n)); অসাজানো অ্যারেতে delete O(n)। **দুটি স্ট্যাক** দিয়ে কিউ বানানো যায় (অ্যামর্টাইজড O(1))। BFS → কিউ; DFS → স্ট্যাক।

## ৮. ট্রি ও বাইনারি ট্রি

- **ট্রি (Tree)** হলো একটি **রুট**সহ সংযুক্ত, চক্রহীন স্তরবিন্যাস; বাকি প্রতিটি নোডের ঠিক একটি প্যারেন্ট, তাই n নোডে **n − 1 এজ**। **বাইনারি ট্রি**: সর্বোচ্চ দুটি চাইল্ড (বাম, ডান)। পরিভাষা: লিফ, ইন্টার্নাল নোড, সিবলিং, ডিগ্রি = চাইল্ড সংখ্যা, লেভেল (রুট = 0), উচ্চতা = রুট থেকে দীর্ঘতম লিফ পর্যন্ত এজ সংখ্যা।
- উদাহরণ ট্রি: A-এর চাইল্ড B ও C; B-এর D ও E; C-এর বাম চাইল্ড F।

| ট্রাভার্সাল | ক্রম | এই ট্রির ফল |
|---|---|---|
| প্রিঅর্ডার | নোড, বাম, ডান | A B D E C F |
| ইনঅর্ডার | বাম, নোড, ডান | D B E A F C |
| পোস্টঅর্ডার | বাম, ডান, নোড | **D E B F C A** |
| লেভেল অর্ডার | স্তরে স্তরে (কিউ) | A B C D E F |

| বাইনারি ট্রির ধর্ম (রুট লেভেল 0, উচ্চতা h) | সূত্র | যাচাই (h = 2) |
|---|---|---|
| লেভেল i-তে সর্বোচ্চ নোড | **2^i** | লেভেল 2: 4 |
| উচ্চতা h-এর ট্রিতে সর্বোচ্চ নোড | **2^(h+1) − 1** | 7 |
| n নোডে ন্যূনতম উচ্চতা | ⌈log2(n + 1)⌉ − 1 | n = 7 → 2 |
| লিফ বনাম ডিগ্রি-2 নোড | **n0 = n2 + 1** | পারফেক্ট h = 2: 4 = 3 + 1 |
| n নোডে ভিন্ন বাইনারি ট্রি | ক্যাটালান: C(2n, n)/(n + 1) | n = 3 → 5 |

- **প্রকার:** *ফুল/স্ট্রিক্ট* — প্রতিটি নোডের 0 বা 2 চাইল্ড; *কমপ্লিট* — শেষটি ছাড়া সব লেভেল পূর্ণ, শেষটি **বাম থেকে** ভরা (হিপের আকার); *পারফেক্ট* — প্রতিটি ইন্টার্নাল নোডের 2 চাইল্ড, সব লিফ এক লেভেলে; *স্কিউড* — প্রতিটির এক চাইল্ড, আসলে লিস্ট।
- **অ্যারে উপস্থাপন:** লেভেল ধরে সাজাও। 0-ভিত্তিক: বাম = **2i + 1**, ডান = 2i + 2, প্যারেন্ট = ⌊(i − 1)/2⌋। 1-ভিত্তিক: বাম = 2i, ডান = 2i + 1, প্যারেন্ট = ⌊i/2⌋। কমপ্লিট ট্রির জন্য আদর্শ; স্কিউডে অপচয়।
- ✍ সমাধানকৃত উদাহরণ — দুই ট্রাভার্সাল থেকে ট্রি গঠন। প্রিঅর্ডার A B D E C F, ইনঅর্ডার D B E A F C। প্রিঅর্ডারের প্রথমটি রুট A; ইনঅর্ডারে D B E তার বাম সাবট্রি, F C ডান সাবট্রি। B বাম অংশের রুট (D, E); C ডান অংশের রুট, F তার বামে। পোস্টঅর্ডার: **D E B F C A**। ইনঅর্ডার + প্রি/পোস্ট মিলে ট্রি অনন্যভাবে নির্ধারিত; শুধু প্রি + পোস্টে নয়।
- 💡 **কৌশল:** নামই বলে **নোড কোথায় বসে** — প্রি = আগে, ইন = মাঝে, পোস্ট = শেষে; বাম সবসময় ডানের আগে। **BST:** বাম < নোড < ডান, তাই এর **ইনঅর্ডার সাজানো**।
- ⚠ **ফাঁদ:** লেভেল গোনা কোথা থেকে শুরু দেখো — রুট লেভেল 1 হলে লেভেল i-তে সর্বোচ্চ 2^(i−1) ও উচ্চতা h-এ 2^h − 1 নোড। BST সার্চ গড়ে O(log n), কিন্তু **স্কিউড হলে O(n)** — তাই AVL ও রেড-ব্ল্যাক ট্রি।

## ৯. গ্রাফ, এবং প্রতিটি অপারেশনের খরচ

- **গ্রাফ (Graph)** G = (V, E) হলো ভার্টেক্সের সেট ও তাদের জোড়া সংযোগকারী এজের সেট: আনডিরেক্টেড বা ডিরেক্টেড (ডাইগ্রাফ), ওয়েটেড বা নয়। ডিগ্রি = এক ভার্টেক্সে এজ সংখ্যা (ডাইগ্রাফে ইন-/আউট-ডিগ্রি)। পাথ এজ দিয়ে ভার্টেক্স জোড়ে; সাইকেল শুরুতে ফেরে; প্রতিটি জোড়া পাথে যুক্ত হলে গ্রাফ কানেক্টেড। **ট্রি হলো সংযুক্ত চক্রহীন গ্রাফ**।
- উদাহরণ: ভার্টেক্স 0–3, এজ 0–1, 0–2, 0–3, 1–3 সহ আনডিরেক্টেড গ্রাফ। অ্যাডজেসেন্সি লিস্ট: 0 → 1, 2, 3; 1 → 0, 3; 2 → 0; 3 → 0, 1। এর অ্যাডজেসেন্সি ম্যাট্রিক্স প্রতিসম।

| বিষয় | অ্যাডজেসেন্সি ম্যাট্রিক্স | অ্যাডজেসেন্সি লিস্ট |
|---|---|---|
| জায়গা | **O(V²)** | **O(V + E)** |
| (u, v) কি এজ? | **O(1)** | O(u-এর ডিগ্রি) |
| u-এর সব প্রতিবেশী | O(V) | O(u-এর ডিগ্রি) |
| উপযুক্ত | ঘন (dense) গ্রাফে | বিরল (sparse) গ্রাফে (বাস্তবের বেশিরভাগ) |

- **গণনার তথ্য:** সিম্পল আনডিরেক্টেড গ্রাফে সর্বোচ্চ এজ **n(n − 1)/2**, ডিরেক্টেডে n(n − 1) — K5-এ 10টি এজ। হ্যান্ডশেকিং: সব ডিগ্রির যোগফল = 2|E|, তাই বিজোড়-ডিগ্রির ভার্টেক্স জোড়-সংখ্যক। n ভার্টেক্সের ট্রিতে n − 1 এজ; DAG হলো চক্রহীন ডিরেক্টেড গ্রাফ; ইনসিডেন্স ম্যাট্রিক্স V × E।

| স্ট্রাকচার | অ্যাক্সেস | সার্চ | ইনসার্ট | ডিলিট |
|---|---|---|---|---|
| অ্যারে (অসাজানো) | O(1) | O(n) | O(n) | O(n) |
| সাজানো অ্যারে | O(1) | O(log n) | O(n) | O(n) |
| সিঙ্গলি লিংকড লিস্ট | O(n) | O(n) | head-এ O(1) | জানা নোডের পরে O(1) |
| স্ট্যাক / কিউ | top/front O(1) | O(n) | O(1) | O(1) |
| BST (গড় / সবচেয়ে খারাপ) | — | O(log n) / O(n) | O(log n) / O(n) | O(log n) / O(n) |
| বাইনারি হিপ | max O(1) | O(n) | O(log n) | O(log n) |

- ⚠ **ফাঁদ:** অ্যাডজেসেন্সি লিস্টের জায়গা **O(V + E)**, O(E) নয়: এজ না থাকলেও প্রতিটি ভার্টেক্সের লিস্ট-হেড লাগে। কমপ্লিট গ্রাফ ঘন, তাই সেখানে ম্যাট্রিক্স ভালো।
- **অধ্যায়ের বাকিটা কোথায়:** হিপ, ফিবোনাচি হিপ, B-ট্রি → অ্যাডভান্সড ডেটা স্ট্রাকচার লেসন; রিকার্শন, সর্টিং, সার্চিং, হ্যাশিং → পরের লেসন; BFS, DFS, টপোলজিক্যাল সর্ট, MST, শর্টেস্ট পাথ → গ্রাফ অ্যালগরিদম লেসন।

## লিখিত প্রশ্ন (১০ নম্বর)

অ্যাবস্ট্রাক্ট ডেটা টাইপ কী? স্ট্যাক ADT এবং ওভারফ্লো ও আন্ডারফ্লোসহ এর অ্যারে ইমপ্লিমেন্টেশন বর্ণনা করো। স্ট্যাক দেখিয়ে `A + B * C − D / E`-কে পোস্টফিক্সে রূপান্তর করো এবং `5 6 2 + * 12 4 / −` এর মান নির্ণয় করো।

**মডেল উত্তর:**
১. **ADT (২):** মান ও অপারেশন দিয়ে সংজ্ঞায়িত টাইপ, ইমপ্লিমেন্টেশন-নিরপেক্ষ; সুবিধা: এনক্যাপসুলেশন, রিইউজেবিলিটি, মডিউলারিটি। ডেটা স্ট্রাকচার একে ইমপ্লিমেন্ট করে।
২. **স্ট্যাক ADT (২):** LIFO লিস্ট; push, pop, peek, isEmpty, isFull, সব O(1)। ব্যবহার: কল স্ট্যাক, এক্সপ্রেশন, undo, ব্যাকট্র্যাকিং।
৩. **অ্যারে ইমপ্লিমেন্টেশন (২):** `top = −1` মানে খালি; push: `top == MAX−1` হলে → **ওভারফ্লো**, নইলে `s[++top] = x`; pop: `top == −1` হলে → **আন্ডারফ্লো**, নইলে `s[top−−]` ফেরত।
৪. **ইনফিক্স → পোস্টফিক্স (২):** A আউট; + push; B আউট; * + এর চেয়ে বড়, push; C আউট; − এলে * ও + pop (≥ অগ্রাধিকার), − push; D আউট; / push; E আউট; / ও − pop → **A B C * + D E / −**।
৫. **মূল্যায়ন (২):** push 5, 6, 2; + → 8; * → 40; push 12, 4; / → 3; − → 40 − 3 = **37**।

## রাতের পরীক্ষার এক-লাইনের কথা

n বিট → 2^n প্যাটার্ন; আনসাইনড 0 … 2^n − 1 · 2's কমপ্লিমেন্ট −2^(n−1) … 2^(n−1) − 1, শূন্য একটি; সাইন-ম্যাগনিচুড ও 1's-এ দুটি · −5 (8-বিট): S-M 10000101, 1's 11111010, **2's 11111011** · প্রথম 1 পর্যন্ত কপি, বাকিটা উল্টাও · ওভারফ্লো কেবল একই চিহ্ন থেকে বিপরীত চিহ্ন এলে; শুধু ক্যারি আউট ওভারফ্লো নয় · IEEE সিঙ্গেল 1-8-23 বায়াস 127, ডাবল 1-11-52 বায়াস 1023, বায়াস = 2^(k−1) − 1 · 0.1 + 0.2 ≠ 0.3 · ASCII 7-বিট, 'A' 65, 'a' 97, '0' 48 · ইউনিকোড সেট; UTF-8 হলো 1–4 বাইট · লিটল-এন্ডিয়ানে ছোট বাইট নিচু অ্যাড্রেসে; নেটওয়ার্ক অর্ডার বিগ-এন্ডিয়ান · ADT = কী (অপারেশন), ডেটা স্ট্রাকচার = কীভাবে · রো-মেজর B + w[(i − Lr)n + (j − Lc)], কলাম-মেজর B + w[(j − Lc)m + (i − Lr)] · অ্যারে অ্যাক্সেস O(1), মাঝে ইনসার্ট O(n) · ডাবলি লিস্টে নির্দিষ্ট নোড ডিলিট O(1) · স্ট্যাক LIFO, ওভারফ্লো top == MAX − 1 · `2 3 4 * +` = 14; A + B * C → A B C * + · অগ্রাধিকার ^ > * / > + −, ^ ডান-সহযোগী · রিকার্শনে স্ট্যাক, BFS-এ কিউ · সার্কুলার কিউ পূর্ণ: (rear + 1) % n == front · প্রায়োরিটি কিউ → বাইনারি হিপ · লেভেল i ≤ 2^i নোড, উচ্চতা h ≤ 2^(h+1) − 1, n0 = n2 + 1, চাইল্ড 2i + 1 ও 2i + 2 (0-ভিত্তিক) · BST-র ইনঅর্ডার সাজানো · ম্যাট্রিক্স O(V²), লিস্ট O(V + E), সর্বোচ্চ এজ n(n − 1)/2।
