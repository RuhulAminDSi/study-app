1Data, Information & IT

MCQ basics
Data raw, unorganised facts (marks, names) with no meaning on their own.
Information data processed into a meaningful, useful form.
IT Information Technology: using computers, storage, networks and software to create, process, store, secure and exchange electronic data.
ICT Information & Communication Technology = IT + communication technology (telephone, mobile, broadcasting, Internet). The wider term, used in Bangladesh policy (ICT Division, ICT Act 2006).

Components of an IT system: hardware · software · data · network · people (+ procedures in some books).

Functions of IT: capture → process → store → retrieve → transmit, plus automation, decision support and security.

Memory trick DIKW pyramid: Data → Information → Knowledge → Wisdom. Each step up adds meaning.

Good information is accurate, timely, relevant, complete and concise. Uses: banking, e-learning, telemedicine, e-commerce (p. 9), government ↓.

3The Internet: a Network of Networks

high-yield
Definition The Internet is the global, public network of networks whose computers exchange data with the TCP/IP protocol suite. Nobody owns it; it is coordinated by ICANN/IANA (names & numbers), IETF (standards, published as RFCs), W3C (web standards) and ISOC.

Web 1.0 read-only static pages → Web 2.0 read-write (blogs, wikis, social media) → Web 3.0 semantic / decentralised.

Memory trick 69-83-89: ARPANET is born (69), it becomes the Internet (83), the Web is proposed on it (89).
Exam trap Internet ≠ WWW. The Internet is the infrastructure (1969/1983); the Web is one service running on it (1989). Email (1971) is older than the Web. "Father of the Internet" = Cerf (& Kahn); "father of the Web" = Berners-Lee.

4How Data Crosses the Internet

Packet switching: a message is cut into packets, each carrying source and destination IP addresses. Routers forward them hop by hop on the best route they know, so packets may take different routes and arrive out of order; TCP reorders them and resends lost ones, while IP only delivers (best effort). Path in Bangladesh: submarine cable / ITC → IIG → NIX / NTTN → ISP → user, all licensed by BTRC.

Memory trick DNS is the Internet's phone book: you know the name, it finds the number. DHCP is the hotel desk that hands out room numbers.
Exam trap DNS translates names → IP; DHCP assigns IPs; ARP finds the MAC for an IP. 127.0.0.1 is not a private-range address: it is loopback.

6World Wide Web (WWW)

MCQ favourite
Definition The Web is a system of interlinked hypertext documents on the Internet. Three inventions by Berners-Lee hold it together: HTML (page language), HTTP (transfer protocol) and URL (address). A browser requests pages from a web server and renders them.
TermMeaningTermMeaning
Web pageone HTML documentWebsitepages under one domain
Home pagea site's first/main pageHyperlinklink to another resource
Web serverserves pages (Apache, IIS)BrowserChrome, Firefox, Edge
Search engineindexes the web (Google)Cookiesmall text file in the browser

HTTP is stateless (cookies/sessions add memory). HTTPS = HTTP over TLS (formerly SSL), padlock, port 443. Static page = same for all; dynamic = built per request. First browser WorldWideWeb (1990); first popular graphical one Mosaic (1993); first search engine Archie (1990).

Memory trick The 20s count up: FTP 21 → SSH 22 → Telnet 23 → (skip) → SMTP 25. Then DNS 53, web 80, POP 110, IMAP 143, secure web 443.

Other services: VoIP calls, video conferencing (Zoom), chat, streaming, social networking, e-learning, IoT (term: Kevin Ashton, 1999).

Cloud: SaaS (Gmail, Google Docs) · PaaS (App Engine) · IaaS (AWS EC2).

Exam trap FTP uses two ports: 21 = control, 20 = data. HTTPS is not a new protocol: it is HTTP carried inside TLS. A domain name is only one part of a URL, and a port is written after a colon (:443).

Exam trap Bcc recipients are invisible to everyone else, and "Reply all" does not reach them. SMTP is for sending only; reading mail needs POP3 or IMAP.
Memory trick SMTP = Send. POP = Pull & Purge. IMAP = In place (mail stays on the server).
Worked example ✍ An officer reads office mail on a desktop and a phone and wants both to show the same read/unread state. Answer: configure IMAP (port 993 with TLS) for receiving and SMTP (587) for sending. POP3 would download each message to one device and remove it from the server.

Worked example ✍ Full mesh of 6 PCs: 6 × 5 / 2 = 15 cables, 5 ports per PC. For 10 PCs: 10 × 9 / 2 = 45.
Memory trick Bus = Backbone, Star = Switch in the centre, Ring = Relay the token, Mesh = Maximum links.
Exam trap A star wired to a hub behaves logically like a bus (every frame goes to all). "Most reliable" = mesh; "most common" = star.

13Ways to Connect

IEEE: 802.3 Ethernet · 802.11 Wi-Fi · 802.15.1 Bluetooth · 802.16 WiMAX. Wired: dial-up (≤ 56 kbps) → ADSL (download > upload) → cable → FTTH. Mobile: 2G GSM (voice, SMS) → 3G (broadband) → 4G LTE (all-IP) → 5G (low latency, IoT).

IT link A typical office or home line: fibre ONU (or modem) → router (NAT, DHCP server, firewall) → switch → PCs, with an access point for Wi-Fi. A home "Wi-Fi router" is router + switch + access point in one box.
Memory trick Hub Hollers to all; Switch Selects by MAC; Router Routes by IP.
Exam trap "Wi-Fi" has no official full form ("Wireless Fidelity" is a slogan). 1 Mbps = 10⁶ bits/s, not 2²⁰.

14Cyber Security Basics

high-yield
Cyber security protecting systems, networks and data from attack and unauthorised access. Goals = CIA triad: Confidentiality (only authorised readers: encryption) · Integrity (no unnoticed change: hashes, digital signatures) · Availability (service up when needed: backups; DDoS attacks it).
MalwareHow it behaves
Virusattaches to a host file; spreads when that file runs
Wormself-replicates over the network, no host or user action
Trojan horselooks useful, hides a harmful payload; does not self-replicate
Ransomwareencrypts files, demands payment (WannaCry, 2017)
Spyware · keylogger · botspies · records keystrokes · zombie PC in a botnet

Attacks: phishing (fake mail/site; vishing = voice, smishing = SMS) · DoS/DDoS (flooding) · man-in-the-middle · SQL injection · social engineering (fake "bank officer" asks for the OTP) · brute force. Defences: firewall, antivirus + patches, strong passwords + 2FA/MFA, HTTPS/VPN encryption, backups, awareness. History: Creeper 1971 · Brain 1986, first PC virus (Pakistan) · Morris worm 1988.

Bangladesh Feb 2016 Bangladesh Bank heist: fraudulent SWIFT orders, about US$81 million lost. Laws: ICT Act 2006 → Digital Security Act 2018 → Cyber Security Act 2023 → Cyber Security Ordinance 2025. National CIRT: BGD e-GOV CIRT (BCC).
Memory trick A virus rides a host, a worm crawls alone, a Trojan wears a disguise.
Exam trap Firewall ≠ antivirus: a firewall filters traffic, antivirus scans files.

15E-commerce

MCQ favourite

E-commerce = buying and selling over electronic networks with online payment (m-commerce on mobiles). B2B wholesaler → retailer (largest by value) · B2C shop → customer (Daraz) · C2C person → person (Bikroy) · C2B freelancer → company · G2C tax return, passport · G2B e-GP tenders. Payment: card via a payment gateway, internet banking, MFS (bKash 2011, Nagad, Rocket), cash on delivery.

Memory trick Read it as seller 2 buyer: the first letter provides, the last receives.

Written question Distinguish between the Internet and the World Wide Web. Explain, step by step, what happens when a user types https://www.example.gov.bd in a browser. 8 marks
  1. Internet = network of networks on TCP/IP (infrastructure); WWW = hypertext service on it (HTML, HTTP, URL). Email and FTP use the Internet but are not the Web. 2
  2. Browser parses the URL: scheme https, host www.example.gov.bd, port 443. 1
  3. DNS: the resolver asks root → .bd TLD → authoritative server and returns the IP. 2
  4. TCP connection to IP:443, then a TLS handshake (certificate checked, keys agreed). 1
  5. HTTP GET; server replies 200 OK with HTML; browser renders the page. 2
