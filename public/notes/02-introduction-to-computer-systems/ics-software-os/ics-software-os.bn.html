সিলেবাসের যে অংশ

"Introduction to Computer Systems: … Major components of a computer; Hardware: processor, memory, I/O devices; Software: Operating system, application software; Basic architecture of a computer …"। এই নোটে সফটওয়্যার অংশ: শ্রেণিবিভাগ, OS (ভূমিকা, কাজ, কার্নেল, প্রকার, বুটিং), অনুবাদক প্রোগ্রাম, ইউটিলিটি, ড্রাইভার, ফার্মওয়্যার, অ্যাপ্লিকেশন সফটওয়্যার ও লাইসেন্স। হার্ডওয়্যার ও আর্কিটেকচার আছে হার্ডওয়্যার উপাদান নোটে (cs2); প্রসেস, শিডিউলিং, মেমরি ব্যবস্থাপনা ও ডেডলক বিস্তারিত আছে অধ্যায় ১৮: অপারেটিং সিস্টেম-এ।

৩অপারেটিং সিস্টেম: ভূমিকা ও কাজ

হাই-ইল্ড
সংজ্ঞা অপারেটিং সিস্টেম (OS) হলো সেই সিস্টেম সফটওয়্যার, যা হার্ডওয়্যার রিসোর্স পরিচালনা করে এবং ব্যবহারকারী ও প্রোগ্রামকে ইন্টারফেস ও সাধারণ সেবা দেয়। দুই দৃষ্টিভঙ্গি: রিসোর্স ম্যানেজার (CPU, মেমরি, ডিভাইস, ফাইল ভাগ করে দেয়) এবং এক্সটেন্ডেড মেশিন (সহজ কলের আড়ালে হার্ডওয়্যারের জটিলতা লুকায়)। বুটের সময় এটি প্রথম বড় প্রোগ্রাম হিসেবে লোড হয়; শাটডাউন পর্যন্ত এর কার্নেল RAM-এ থাকে।
কাজOS কী করে
প্রসেসপ্রসেস তৈরি, শিডিউল ও সমাপ্ত করে; প্রসেস = নির্বাহরত প্রোগ্রাম (অধ্যায় ১৮)
মেমরিRAM বরাদ্দ/মুক্ত করে; ভার্চুয়াল মেমরি = ডিস্ককে RAM হিসেবে ব্যবহার
ফাইলফাইল তৈরি, পড়া, লেখা, মোছা; ডিরেক্টরি; পারমিশন
ডিভাইস (I/O)ড্রাইভার, ইন্টারাপ্ট, বাফারিং, স্পুলিং (প্রিন্ট কিউ)
স্টোরেজখালি জায়গার হিসাব, ডিস্ক শিডিউলিং, ফরম্যাটিং
নিরাপত্তালগইন, ইউজার অ্যাকাউন্ট, অ্যাক্সেস অধিকার; প্রোগ্রামকে আলাদা রাখে
ইউজার ইন্টারফেসCLI বা GUI (পৃ. ৪)
অন্যান্যনেটওয়ার্কিং, ত্রুটি শনাক্তকরণ, অ্যাকাউন্টিং (ব্যবহারের লগ)
মনে রাখার কৌশল "Please Make Friendly Devices Safe & Useful" → Process, Memory, File, Device, Security, User interface।
SPOOL = Simultaneous Peripheral Operations On-Line: কাজগুলো ডিস্কে সারিতে অপেক্ষা করে, ফলে ধীর প্রিন্টার CPU-কে আটকে রাখে না।

বুটিং (Booting): চালু থেকে লগইন

BIOS = Basic Input/Output System; UEFI = Unified Extensible Firmware Interface
  1. পাওয়ার অন → BIOS/UEFI (ROM/ফ্ল্যাশে রাখা ফার্মওয়্যার) চালায় POST (Power-On Self-Test)
  2. বুট ডিভাইস খুঁজে (বুট অর্ডার) MBR (প্রথম 512-বাইট সেক্টর) বা EFI পার্টিশন (GPT) থেকে বুটলোডার লোড করে
  3. বুটলোডার (GRUB, Windows Boot Manager) কার্নেলকে RAM-এ আনে
  4. কার্নেল ড্রাইভার ও প্রথম প্রসেস (init/systemd) চালু করে → সার্ভিস → লগইন
পরীক্ষার ফাঁদ কোল্ড বুট = বন্ধ অবস্থা থেকে চালু; ওয়ার্ম বুট = বিদ্যুৎ না কেটে রিস্টার্ট (Restart, Ctrl+Alt+Del)। বুটস্ট্র্যাপ লোডার থাকে ROM/ফ্ল্যাশে, হার্ডডিস্কে নয়; BIOS-এর সেটিং থাকে ব্যাটারিচালিত CMOS RAM-এ।

৪কার্নেল, শেল ও সিস্টেম কল

হাই-ইল্ড
কার্নেল (Kernel) OS-এর কেন্দ্রীয় অংশ: সবসময় প্রধান মেমরিতে থাকে, সুবিধাপ্রাপ্ত কার্নেল মোডে চলে, CPU, মেমরি, ডিভাইস ও ফাইল পরিচালনা করে।
শেল (Shell) কমান্ড ইন্টারপ্রেটার: বাইরের স্তর, যা ব্যবহারকারীর কমান্ড নিয়ে কার্নেলের কাছে পাঠায়। টেক্সট শেল: sh (Bourne), bash (বেশিরভাগ Linux-এ ডিফল্ট), zsh (২০১৯ থেকে macOS-এ ডিফল্ট), cmd.exe, PowerShell। GUI শেল: Windows Explorer।
মনে রাখার কৌশল বাদামের মতো: কার্নেল ভেতরের শাঁস, শেল বাইরের খোসা। তুমি কথা বলো শেলের সাথে; শেল কথা বলে কার্নেলের সাথে।
কার্নেলের ধরনমূল ধারণাউদাহরণ
মনোলিথিকসব সার্ভিস কার্নেল স্পেসে; দ্রুতLinux, UNIX, MS-DOS
মাইক্রোকার্নেলছোট কার্নেল; ড্রাইভার, ফাইল সিস্টেম ইউজার স্পেসেMINIX, QNX, L4
হাইব্রিডমাইক্রো নকশা + কিছু সার্ভিস কার্নেলেWindows NT, macOS (XNU)

ইউজার মোড বনাম কার্নেল মোড: অ্যাপ সীমিত অধিকারে ইউজার মোডে চলে। হার্ডওয়্যার ব্যবহার করতে সে একটি সিস্টেম কল (system call) করে: একটি ট্র্যাপ (সফটওয়্যার ইন্টারাপ্ট) CPU-কে কার্নেল মোডে নেয়, কার্নেল কাজটি করে, তারপর নিয়ন্ত্রণ ইউজার মোডে ফেরে।

fd = open("a.txt", O_RDONLY); read(fd, buf, 100); /* kernel */ close(fd); /* back in user mode */

UNIX/Linux কল: fork(), exec(), open(), read(), write(), exit() · Windows: CreateProcess(), ReadFile() · লাইব্রেরি (POSIX, Win32 API) এগুলোকে মুড়ে রাখে।

ফ্রি সফটওয়্যার (রিচার্ড স্টলম্যান; GNU ১৯৮৩, FSF ১৯৮৫): "free" মানে স্বাধীনতা, বিনামূল্য নয়: চালানো, পড়া, বিতরণ ও পরিবর্তনের চারটি স্বাধীনতা। GPL হলো কপিলেফট (copyleft): পরিবর্তিত সংস্করণও GPL-এ রাখতে হয়। MIT, BSD, Apache লাইসেন্স পারমিসিভ। "ওপেন সোর্স" শব্দটি: OSI, ১৯৯৮।

মনে রাখার কৌশল ফ্রিওয়্যার = free beer (দাম নেই) · ফ্রি সফটওয়্যার = free speech (স্বাধীনতা) · শেয়ারওয়্যার = আগে চেখে দেখো, পরে দাম দাও।
পরীক্ষার ফাঁদ ফ্রিওয়্যার ≠ ওপেন সোর্স: Chrome ফ্রিওয়্যার, Chromium ওপেন সোর্স। ওপেন সোর্স সফটওয়্যারও বিক্রি করা যায় (Red Hat সাবস্ক্রিপশন ও সাপোর্ট বিক্রি করে)।
