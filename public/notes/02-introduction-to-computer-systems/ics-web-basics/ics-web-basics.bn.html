১HTML: Element ও পেজের গঠন

উচ্চ-yield
HTML HyperText Markup Language: ওয়েব পেজের গঠন (structure) বর্ণনার standard markup ভাষা (programming language নয়); angle bracket-এর ভেতরে ট্যাগ দিয়ে লেখা হয়। স্রষ্টা Tim Berners-Lee (১৯৯১); বর্তমান সংস্করণ HTML5 (W3C Rec. ২০১৪, এখন WHATWG "Living Standard")। ফাইল: .html / .htm।

Element = opening tag + content + closing tag। Attribute = opening tag-এর ভেতরে বাড়তি তথ্য (name="value"): href, src, alt, id, class, style। Void (empty) element-এর closing tag নেই: <br> <hr> <img> <input> <meta> <link>।

প্রতিটি পেজের কাঠামো

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <title>My Page</title> <link rel="stylesheet" href="s.css"> </head> <body> <h1>Welcome</h1> <p>Hello world.</p> </body> </html>
অংশকাজ
<!DOCTYPE html>ট্যাগ নয়, ঘোষণা: browser-কে বলে "HTML5 standards mode"
<head>metadata: <title> (browser tab), meta, CSS link, script
<body>ব্যবহারকারী যা দেখে: heading, লেখা, ছবি, form
<h1>–<h6>৬ স্তরের heading; h1 সবচেয়ে বড়, h6 সবচেয়ে ছোট
মনে রাখার কৌশল HTML = কঙ্কাল, CSS = চামড়া, JS = পেশি। HTML বলে কী আছে, CSS বলে কেমন দেখাবে, JS বলে ব্যবহারকারী কিছু করলে কী ঘটবে।

Table-এর কোড

৩Form ও HTML5 Semantic ট্যাগ

উচ্চ-yield
Form ব্যবহারকারীর ইনপুট নিয়ে server-এ পাঠায়: <form action="/save" method="post">। action = যে URL ডেটা গ্রহণ করবে; method = GET (ডেটা URL-এ) বা POST (ডেটা body-তে)। পাঠাতে হলে প্রতিটি field-এর একটি name লাগে।

৪CSS: ধরন, Selector ও Box Model

উচ্চ-yield
CSS Cascading Style Sheets উপস্থাপন নিয়ন্ত্রণ করে: রং, ফন্ট, ফাঁকা জায়গা, layout, responsiveness। Cascading = নিয়মে সংঘাত হলে অগ্রাধিকার (উৎস, specificity, ক্রম) ঠিক করে কোনটি জিতবে। নিয়ম: selector { property: value; }
ধরনকীভাবেব্যবহার

!important সবাইকে হারায়; সমান হলে → শেষ নিয়ম জেতে।

ঋণাত্মক / auto?নাহ্যাঁ (margin:auto মাঝে আনে)
উদাহরণ p { width:200px; padding:20px; border:2px solid; margin:10px; } → দৃশ্যমান বক্স = 200 + 2×20 + 2×2 = 244 px; মোট জায়গা = 244 + 2×10 = 264 px। box-sizing: border-box দিলে বক্স 200 px-ই থাকে।
মনে রাখার কৌশল "My Big Pink Cat" বাইরে থেকে ভেতরে: Margin → Border → Padding → Content। সংক্ষেপে margin: 10px 5px = উপর/নিচ 10, বাম/ডান 5 (ঘড়ির কাঁটার দিকে TRBL)।

CSS framework = দ্রুত, responsive ডিজাইনের জন্য আগে লেখা class: Bootstrap (grid + component, class="btn btn-primary"), Tailwind CSS (utility-first, class="p-4 text-blue-600"), Foundation, Bulma। Preprocessor: Sass/LESS।

৫JavaScript, DOM ও Event

উচ্চ-yield
JavaScript browser-এর programming language (client-side; Node.js দিয়ে server-এও চলে)। Interpreted/JIT, dynamically typed। ব্যবহার: form validation, event, DOM পরিবর্তন, AJAX/fetch। যোগ করা হয় <script> দিয়ে: inline বা <script src="app.js">। JavaScript ≠ Java।
DOM (Document Object Model): পেজের জন্য browser-এর তৈরি object-এর গাছ (tree); JS তা পড়ে ও বদলায়।
let e = document.getElementById("msg");
e.innerHTML = "Saved!"; লেখা বদলায়
e.style.color = "red"; style বদলায়
document.getElementById("nm").value input পড়া/বসানো
আরও: querySelector, createElement, appendChild।

Event: onclick, onchange, onsubmit, onload, onmouseover, onkeyup। <button onclick="save()"> অথবা btn.addEventListener("click", save)।

function valid(p) { let d = p.replace(/\D/g, ""); return d.length === 10; }

৬HTTP: মেথড ও স্ট্যাটাস কোড

উচ্চ-yield
HTTP HyperText Transfer Protocol: application-layer-এর client–server, request–response protocol, TCP-এর ওপর চলে, default port 80। Stateless: প্রতিটি request স্বাধীন (cookie/session দিয়ে state যোগ হয়)। সংস্করণ: 1.1 (persistent connection), HTTP/2 (multiplexing), HTTP/3 (QUIC/UDP-এর ওপর)।
MethodকাজBody?Idempotent
GETresource পড়া (ডেটা URL query-তে)নাহ্যাঁ (safe-ও)
POSTনতুন তৈরি / ডেটা জমাহ্যাঁনা
PUTপুরো resource প্রতিস্থাপনহ্যাঁহ্যাঁ
PATCHআংশিক হালনাগাদহ্যাঁনিশ্চিত নয়
DELETEresource মুছে ফেলাসাধারণত নাহ্যাঁ
শ্রেণিঅর্থ · সাধারণ কোড
1xxInformational: 100 Continue, 101 Switching Protocols
2xxসফল: 200 OK, 201 Created, 204 No Content
3xxRedirection: 301 Moved Permanently, 302 Found (সাময়িক), 304 Not Modified
4xxClient error: 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found
5xxServer error: 500 Internal Server Error, 502 Bad Gateway, 503 Unavailable, 504 Timeout
পরীক্ষার ফাঁদ 401 = পরিচয় যাচাই হয়নি (আগে login) · 403 = পরিচিত/লগইন করা, কিন্তু অনুমতি নেই · 404 = resource নেই। তিনটিই client error। GET নিরাপদ নয়: ডেটা URL, history ও log-এ দেখা যায়। POST ডেটা URL থেকে লুকায়, কিন্তু HTTPS ছাড়া তা-ও plain text।
মনে রাখার কৌশল 1 একটু দাঁড়ান · 2 এই নিন · 3 অন্য ঠিকানায় যান · 4 আপনার ভুল · 5 আমার (server-এর) ভুল।

৭HTTPS/TLS, URL-এর গঠন, Static বনাম Dynamic

HTTPS = TLS-এর (SSL-এর উত্তরসূরি) ওপর HTTP, default port 443। দেয় গোপনীয়তা (encryption), অখণ্ডতা (MAC) ও প্রমাণীকরণ (CA-স্বাক্ষরিত server-এর X.509 certificate)। Address bar-এ তালার চিহ্ন। Login, ব্যাংকিং, ই-গভর্নমেন্টে বাধ্যতামূলক।

Asymmetric crypto কেবল key ঠিক করে; মূল ডেটা যায় দ্রুত symmetric encryption-এ (AES)। বর্তমান সংস্করণ: TLS 1.3 (২০১৮); SSL 2/3 ও TLS 1.0/1.1 বাতিল।

পরীক্ষার আগের রাতে এক লাইনে HTML = markup, সর্বশেষ HTML5 · পেজ = DOCTYPE → html → head + body · void: br hr img input · বাটন <button>, JS <script> · tr/th/td · radio = একটি বাছাই · CSS: inline (সর্বোচ্চ অগ্রাধিকার) · internal · external (সাইটের জন্য সেরা) · box: content → padding → border → margin · inline > #id > .class > element · == রূপান্তর করে, === করে না · HTTP 80, HTTPS 443 (TLS) · GET পড়া/URL, POST জমা/body · 401 login, 403 নিষিদ্ধ, 404 নেই, 500 server · REST = JSON, SOAP = XML + WSDL · XSS → output encode + HttpOnly + CSP · PHP ≠ web server।
