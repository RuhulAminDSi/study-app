★ 4 exams — the single most-asked ICS question
Q1 What is the difference between system software and application software? / Explain software with examples. / Difference between hardware and software.45th BCS General (Sci & Tech) (2024) · BB AME 2016 · MM AP 2017 · NPCBL JAM 2022 · 40th BCS (2020) · 15th NTRCA Computer Operation (2019)
PointSystem softwareApplication software

Software = instructions that tell the hardware what to do (no physical form); hardware = the physical parts. A utility (antivirus, backup) is system software; firmware = software permanently in ROM (BIOS).

Q2 What is platform-independent software? Discuss with an example.Combined Bank SO(IT) 2023

Platform-independent software runs on any OS/hardware unchanged, because it runs on a virtual machine, not the bare CPU. Java: source → bytecode → the JVM on each platform ("write once, run anywhere"). Also Python and any web page.

Q3 What is version control (e.g. Git)? Explain the difference between committing and pushing code.Bank (name cut off) AP

Version control (Git) tracks code changes and lets teams roll back. commit = save a snapshot to your local repo; push = send local commits to the remote (GitHub). Commit is local, push is network.

Q4 Describe the classification of computer software. / List banking software used in Bangladesh and the features of good banking software.Intl Crimes Tribunal Hardware Technician 2024 · Combined Bank Officer(IT) 2020

Software → system (OS, translators, utilities) + application (Office; custom core-banking, e.g. Flora, Ababil, T24). Good banking software: security, 24×7 uptime, real-time, audit trail, scalable, compliant.

Trap: a compiler/assembler is system software (serves the machine), not an app; antivirus = utility = system software.

Micro-computer system = microprocessor (CPU) + memory (RAM/ROM) + I/O devices + system bus + power supply, in one box. Super vs mainframe: super = max speed on one big job; mainframe = max throughput for many users/transactions.

Exam trap A mainframe serves thousands of users at once; a supercomputer throws all its power at one scientific problem. They are not the same "big computer".

ICS · Solved Past QuestionsBuilding blocks of a computer

4Building blocks & how a computer works

BCS + NTRCA
Q8 What are the building blocks of a digital computer? Describe each unit briefly. / Draw the block diagram and describe each unit. / Explain the steps of a computer's working.38th BCS (2018) · 47th BCS CSE · 17th NTRCA CSE (2023) · 15th NTRCA CSE

Units: Input (keyboard, mouse) feeds data; CPU = Control Unit (fetch–decode–control) + ALU (arithmetic + logic) + registers; Memory holds the program/data being used; Output (monitor, printer) shows results; secondary storage keeps data permanently. Working = IPO(S): Input → Process → Output → Storage; the CPU runs the fetch–decode–execute cycle.

Q9 What are the components of a micro-computer system? Explain the main organisational parts with a diagram.BPSC ADA 2022 · 17th NTRCA CSE (2023) · 15th NTRCA CSE

CPU (microprocessor) + primary memory (RAM, ROM) + I/O devices + storage + the three buses (data, address, control) on the motherboard — see the bus sheet.

Q10 What is the total number of bits in IPv6? What do DIMM, TDP, SSD and HTTP stand for? / What criteria does computer speed depend on?BUET ICT Cell AHE 2025 · BTCL JAM 2024

IPv6 = 128 bits. DIMM Dual In-line Memory Module · TDP Thermal Design Power · SSD Solid State Drive · HTTP HyperText Transfer Protocol. Computer speed depends on: clock speed (GHz), word size/bus width, number of cores, cache, RAM size and storage type (SSD vs HDD).

Fetch–decode–execute cycle: (1) the Control Unit fetches the next instruction from memory (address in the PC); (2) decodes it in the IR; (3) the ALU executes it; (4) the result is written back and the PC advances. This loop, millions/s, is all a computer does.

Memory trick Remember IPO-S: Input → Process (CPU) → Output → Storage. Every "how a computer works" answer is these four units plus the fetch–decode–execute cycle.

ICS · Solved Past QuestionsCPU · GPU · bus · interrupts

5CPU, GPU, system bus, interrupts

hardware core
Q11 What is CPU? Describe the organisation of the CPU. / What is the function of a GPU?17th NTRCA School (2023) · BPSC AP 2022

CPU ("brain") = CU (directs all operations) + ALU (arithmetic + logic/compare) + registers (fastest tiny stores: PC, IR, AC, MAR, MBR). GPU = many small cores for parallel graphics/matrix maths; used for 3D, video and AI/ML training. CPU = few fast general cores; GPU = thousands of simple cores.

Q12 What is a computer bus? What is the unit of its speed? Describe the types of bus. / Show how RAM, ROM and I/O connect to a microprocessor by bus. / Components of a USB bus with block diagram.BKKB AP 2017 · BPSC SAE 2021 · ICT Ministry AP 2017
Buscarriesdirection
Data busthe actual datatwo-way
Address busmemory addressone-way (CPU→)
Control busread/write, clock, interrupt signalstwo-way

A bus is a set of parallel wires carrying bits between CPU, memory and I/O. Speed is measured in MHz/GHz (bus clock) or bytes/s (bandwidth = width × clock). USB (Universal Serial Bus) = serial, hot-pluggable, powers the device; a USB packet = sync + PID + address/endpoint + data + CRC.

Q12b Write down the difference between a serial port and a parallel port.DESCO SAE 2023

Serial port sends 1 bit at a time over one wire (RS-232, USB) — fewer wires, good for long distance; parallel port sends many bits at once over many wires (old LPT/printer) — faster over short runs but bulky and prone to skew. Modern systems are nearly all serial (USB, SATA).

Q13 How can an interrupt be enabled? What steps occur when an interrupt is processed?38th BCS (2018)
  1. Device raises an interrupt request (IRQ) on the control bus (enabled by setting the interrupt-enable flag).
  2. CPU finishes the current instruction, saves PC + registers on the stack.
  3. Jumps to the ISR (interrupt service routine) via the interrupt vector.
  4. ISR services the device, then IRET restores the saved state and resumes.
Q14 Differentiate among Intel Core i3, i5 and i7 processors.Combined Bank SO(IT) 2023

Rising cores/threads, cache and Turbo Boost: i3 entry (2–4 cores, no/low turbo), i5 mid (4–6 cores, turbo), i7 high (6–8+ cores, hyper-threading, big cache). More cores + cache + turbo = faster but costlier/hotter.

Q16 RFID has huge applications in supply-chain and toll collection. Show the basic working principle of RFID.Combined Bank Officer(IT) 2020

The reader sends radio waves; a passive tag draws power from them and transmits its stored ID back; the reader sends it to the system. No line-of-sight needed (unlike barcode). Use: toll (e-toll), library, inventory, access cards.

ICS · Solved Past QuestionsBIOS & booting

10BIOS, booting, POST, CMOS

6 exams
Q22 What is BIOS? What is its main role in a computer? / Explain BIOS in a server and how it affects booting in hardware maintenance.EGCB SAE(ICT) 2023 · 45th BCS General (Sci & Tech) (2024) · RAKUB ANSE 2023

BIOS = Basic Input/Output System — firmware stored in ROM on the motherboard. On power-on it: (1) runs POST (Power-On Self-Test) to check RAM, keyboard, disk; (2) initialises hardware; (3) finds the boot device and loads the bootloader → the OS. Settings (boot order, date, passwords) are stored in CMOS, kept alive by a small battery. On servers, BIOS/UEFI sets RAID, boot order and virtualization flags — wrong settings stop the OS loading.

BIOS vs UEFI: UEFI is the modern replacement — supports disks > 2 TB (GPT), a graphical setup, faster boot and Secure Boot. Cold boot = starting from power-off; warm boot = restarting without cutting power (Ctrl+Alt+Del). Bootstrapping = the small program that "pulls the system up by its bootstraps" to load the OS.

ICS · Solved Past QuestionsVirtualization · VM · container

12Virtual machine, hypervisor, container

★ BB AME + AP 2023, BUET AHE 2025
Q24 Define a virtual machine with a diagram, explain how a VM works, and list its benefits. / What is a hypervisor and its types? / Define virtualization; role of hypervisor; VM vs container.BB AME 2023 · BB AP 2023 · BUET ICT Cell AHE 2025 · Combined Bank AP(SB & Janata) 2026 · RAKUB ANSE 2023 · Parliament Secretariat SAE 2023

VM = a software computer with its own virtual CPU/RAM/disk and its own guest OS, running on a hypervisor (VMM) that shares the real hardware. Benefits: isolation, run many OSes on one box, easy snapshot/backup/recovery, fast provisioning, better utilisation. Hypervisor types: Type 1 (bare-metal) runs directly on hardware (ESXi, Hyper-V, Xen) — fast, for servers; Type 2 (hosted) runs on a host OS (VirtualBox, VMware Workstation) — for desktops.

Docker = container platform; Docker Hub = cloud image repository. Kubernetes (K8s) orchestrates containers (control plane + worker nodes/pods). JVM runs Java bytecode portably — it is not a hypervisor.

Q25b For reliable, efficient data transmission, VMs or containers? / Which architecture for a system monitoring a third-party cloud service through APIs?BSCL AE(CSE) 2026

VMs vs containers: prefer containers — lower overhead, faster start, easy scaling and CI/CD; use VMs only for strong OS-level isolation or a different guest OS. API monitoring: an event-driven microservices design (services subscribing to the APIs + a queue + a dashboard) scales and isolates faults.

Q25 A physical server has 32 CPU cores, 96 GB RAM, 4 TB storage. Each VM needs 4 cores, 16 GB RAM, 500 GB. Max VMs without over-committing? Which resource is the limit?Combined Bank Officer(IT) 2026

CPU: 32/4 = 8 · RAM: 96/16 = 6 · Storage: 4000/500 = 8. Max = min(8, 6, 8) = 6 VMs; RAM is the limiting resource.

Quantum computer uses qubits (superposition + entanglement) → massively parallel, vs a normal computer's definite 0/1 bits.

read in 10 minutes
  1. System vs application software (★ most asked): system runs the machine (OS, compiler, driver, utility); application does a user task (Word, browser). Antivirus = utility = system software.
  2. Generations: tube → transistor → IC → microprocessor (4th) → AI. Each = smaller, faster, cheaper.
  3. CPU = CU + ALU + registers; buses = data (2-way) / address (1-way) / control. IPv6 = 128 bits.
  4. OCR characters · OMR marks · MICR magnetic cheque digits · RFID radio, no line-of-sight.
  5. RAM volatile, read/write · ROM permanent, holds BIOS · SSD no moving parts, fast.
  6. 1 byte = 8 bits; 1 KB = 1024 B (binary) / 1000 (SI). Unicode char = 16 bits. MB = storage, Mbps = speed.
  7. BIOS firmware in ROM → POST → bootloader → OS; settings in CMOS (battery).
  8. Cloud: on-demand resources over the internet. IaaS rent infra · PaaS deploy code only · SaaS ready app. Deploy-only startup ⇒ PaaS.
  9. VM = own guest OS on a hypervisor (Type 1 bare-metal / Type 2 hosted); container shares the host kernel (Docker), lighter. VM count = min over CPU/RAM/storage.
  10. Data centre: cooling is the biggest energy cost; PUE → 1 is ideal. Preventive (before) vs corrective (after) maintenance. DR = RTO + RPO + backups.
  11. Scaling: vertical = bigger box; horizontal = more boxes + load balancer; auto-scaling adds/removes nodes.
  12. HTML element = tags + content; HTML5 semantic: header/footer/section/article. CSS box: content→padding→border→margin; 3 types inline/internal/external.
  13. GET in URL, cacheable, read · POST in body, for login/submit. HTTP: 2xx ok, 4xx client, 5xx server (500 = internal error).
  14. SOAP = XML only; REST = lightweight over HTTP verbs. XSS fix: escape output, CSP, HttpOnly cookies.
  15. Blockchain = block (data + hash + previous hash), immutable chain. IR 4.0 = AI + IoT + Big Data + cloud + robotics.
  16. E-commerce: B2C, B2B, C2C, G2C. EPS flow: customer → gateway → acquirer → network → issuer. WWW ⊂ internet.
