সাবনেট মাস্ক (subnet mask) একটি IP-কে নেটওয়ার্ক (1-বিট) ও হোস্ট (0-বিট) অংশে ভাগ করে; এর জন্যই ডিভাইস বোঝে কোন অ্যাড্রেস "লোকাল"। সাবনেটিং (subnetting) একটি বড় নেটওয়ার্ককে ছোট ছোট নেটওয়ার্কে ভাগ করে: কম ব্রডকাস্ট ট্রাফিক, ভালো নিরাপত্তা/ব্যবস্থাপনা, অ্যাড্রেসের অপচয় নেই। CIDR (Classless Inter-Domain Routing, লেখা হয় /n) নির্দিষ্ট ক্লাস তুলে দেয়, যেকোনো প্রিফিক্স দৈর্ঘ্য চলে; উদ্দেশ্য ছিল IPv4 অ্যাড্রেস ফুরিয়ে যাওয়া ঠেকানো ও (সুপারনেটিং দিয়ে) রাউটিং টেবিল ছোট করা।

AIMD = Additive Increase (সব ঠিক থাকলে প্রতি RTT-তে cwnd + 1), Multiplicative Decrease (লস হলে cwnd অর্ধেক) — ব্যান্ডউইথ খোঁজে, কনজেশনে পিছিয়ে আসে। স্টপ-অ্যান্ড-ওয়েট ARQ: একটি ফ্রেম পাঠিয়ে তার ACK না আসা পর্যন্ত পরেরটি পাঠায় না; ফ্রেম/ACK হারালে টাইমআউটে আবার পাঠায় (সিকোয়েন্স নম্বর ডুপ্লিকেট ঠেকায়)। ফ্রেমিং, ফ্লো কন্ট্রোল, এরর কন্ট্রোল ডেটা-লিংক লেয়ারের কাজ; ট্রান্সপোর্টে আবার নির্ভরযোগ্যতা যোগ হয় (JBL ANE 2022)।

Q23 DNS কেন UDP ব্যবহার করে? www.companybd.com-এর DNS রেজোলিউশন বর্ণনা করুন। / কোন সার্ভিস TCP ও UDP দুটোই ব্যবহার করে?Combined Bank Officer(IT) 2025 · Combined Bank SO(IT) 2021

UDP-তে DNS: একটি ছোট কোয়েরি + একটি উত্তর, হ্যান্ডশেকের খরচ নেই → দ্রুত; শুধু বড় উত্তর/জোন ট্রান্সফারে TCP। রেজোলিউশন: ব্রাউজার → OS রিজলভার → রিকার্সিভ রিজলভার → root → TLD (.com) → authoritative সার্ভার → IP ফেরত আসে ও ক্যাশ হয়। DNS TCP ও UDP দুটোই ব্যবহার করে (Combined Bank SO(IT) 2021)।

TCP কনজেশনের ধাপ: স্লো স্টার্ট (থ্রেশহোল্ড পর্যন্ত প্রতি RTT-তে cwnd দ্বিগুণ), কনজেশন অ্যাভয়ডেন্স (রৈখিক +1), লস হলে → ফাস্ট রিট্রান্সমিট/রিকভারি (cwnd অর্ধেক) বা টাইমআউট (আবার স্লো স্টার্ট)। স্লাইডিং উইন্ডো-তে একসাথে কয়েকটি ACK-বিহীন ফ্রেম চলতে পারে = স্টপ-অ্যান্ড-ওয়েটের চেয়ে লিংকের ভালো ব্যবহার; উইন্ডো দক্ষতা = W·Tt / (Tt + 2·Tp)। ARQ-এর ধরন: স্টপ-অ্যান্ড-ওয়েট (১টি ফ্রেম), গো-ব্যাক-N (হারানোটি থেকে সব আবার), সিলেক্টিভ-রিপিট (শুধু হারানোটি — সবচেয়ে দক্ষ)।

কনজেশনের লক্ষণ ও নিয়ন্ত্রণ: বাড়তি ডিলে, প্যাকেট ড্রপ, টাইমআউট। পদ্ধতি: ওপেন-লুপ (প্রতিরোধ — অ্যাডমিশন কন্ট্রোল, লিকি/টোকেন বাকেট দিয়ে ট্রাফিক শেপিং) ও ক্লোজড-লুপ (প্রতিক্রিয়া — AIMD, চোক প্যাকেট, ECN)। স্থির ও কম এন্ড-টু-এন্ড ল্যাটেন্সি মানে উইন্ডো ব্যান্ডউইথ-ডিলে গুণফলের কাছাকাছি, লস কম।

মনে রাখার কৌশল ফ্লো কন্ট্রোল = রিসিভারকে ডোবাবেন না; কনজেশন কন্ট্রোল = নেটওয়ার্ককে ডোবাবেন না। TCP দুটোই করে; UDP কোনোটাই না। AIMD = ধীরে ওঠা, হঠাৎ নামা।

VLAN = সুইচের ওপর একটি লজিক্যাল LAN, যা অবস্থান নির্বিশেষে পোর্টগুলোকে গ্রুপ করে এবং একটি ফিজিক্যাল সুইচকে আলাদা আলাদা broadcast domain-এ ভাগ করে (static = পোর্ট দিয়ে, dynamic = MAC/পলিসি দিয়ে)। VPN = পাবলিক ইন্টারনেটের ওপর একটি প্রাইভেট, এনক্রিপ্টেড টানেল (BPSC AME 2019: "পাবলিক নেটওয়ার্কের ওপর ভিত্তি করে প্রাইভেট নেটওয়ার্ক")। Link-local (FE80::) শুধু একটি লিংকে চলে; global unicast চলে পুরো ইন্টারনেটে।

IPv4 → IPv6 রূপান্তর: dual stack (দুটি একসাথে চালানো), tunnelling (IPv4-এর ভেতরে IPv6 বহন, যেমন 6to4) ও translation (NAT64)। IPv6 সংক্ষেপের নিয়ম: প্রতিটি গ্রুপের শুরুর শূন্য বাদ দিন; সব-শূন্য গ্রুপের একটি ধারাকে :: দিয়ে লিখুন। যেমন 2001:0db8:0000:0000:0000:0000:0000:0001 → 2001:db8::1। IPv6 কেন দ্রুত: নির্দিষ্ট (fixed) হেডার, প্রতি রাউটারে fragmentation নেই, হেডার checksum নেই।

মনে রাখার কৌশল IPv4 = 32 বিট (৪টি অক্টেট); IPv6 = 128 বিট (৮টি হেক্স গ্রুপ)। IPv6-এ unicast / anycast / multicast আছে, কিন্তু broadcast নেই। NAT হলো IPv4-এর জোড়াতালি সমাধান; IPv6-এ এর দরকার নেই।

Q35 এরর শনাক্তকরণের parity পদ্ধতি ব্যাখ্যা করুন এবং "Delta"-র ASCII লিখুন। / CRC বনাম parity: কোনটি ভালো?BB AME 2023 · RAKUB ANSE 2023 · Combined Bank SO(IT) 2021

Parity ১টি বিট যোগ করে যাতে মোট 1-এর সংখ্যা জোড় (even parity) বা বিজোড় হয়; এটি যেকোনো একক-বিট এরর ধরে, কিন্তু জোড়সংখ্যক এরর ধরতে পারে না। ASCII "Delta" = 68 101 108 116 97 = 01000100 01100101 01101100 01110100 01100001। CRC parity-র চেয়ে ভালো: এটি burst error ধরে (parity শুধু একক-বিট)। Simple ও two-dimensional parity দুটিই parity বিট ব্যবহার করে (Combined Bank SO(IT) 2021 → উত্তর (d) "a and b")।

Q36 CRC: ডেটা 11100, divisor 1001: প্রেরিত codeword বের করুন। / 8-বিটে (3, 9, 7, 12, 4)-এর checksum: আসলে কী পাঠানো হয়?Combined Bank AP 2023 · JBL ANA 2022 · Combined Bank AP 2026 · Bank AP লিখিত (প্রশ্নপত্রে ব্যাংকের নাম কাটা)
CRC 11100 / 1001: append 000 -> 11100000, XOR-divide remainder = 111 -> codeword sent = 11100 111

CRC codeword = 11100111 (ভাগশেষ 111)। প্রাপক 1001 দিয়ে ভাগ করে; ভাগশেষ শূন্য না হলে = এরর। 3+9+7+12+4 = 35 = 00100011; 1's-complement checksum = 11011100; পাঠানো হয় ৫টি ডেটা বাইট + এই checksum, আর প্রাপকের যোগফল হওয়া উচিত সব 1।

Checksum ডেটা ওয়ার্ডগুলো যোগ করে, যোগফলের 1's complement নিয়ে সাথে পাঠায়; প্রাপক সব আবার যোগ করে শূন্য (সব 1) আশা করে। এটি IP/TCP/UDP হেডারে ব্যবহৃত হয় (BPDB AE(CSE) 2021, Combined Bank AP 2026)।

এরর সংশোধন (correction) (শনাক্তকরণের তুলনায়) বিট ঠিক করতে বাড়তি redundancy চায়: Hamming code দুইয়ের ঘাতের অবস্থানে parity বিট বসিয়ে ভুল বিটটি খুঁজে উল্টে দেয়। ARQ (পুনঃপ্রেরণ) = শনাক্তকরণ + আবার পাঠানো; FEC (forward error correction) পুনঃপ্রেরণ ছাড়াই ঠিক করে: নয়েজপূর্ণ/একমুখী লিংকে ব্যবহৃত (স্যাটেলাইট, deep space)।

১০ মিনিটে পড়ুন
  1. IP ক্লাস: A 1–126 (/8), B 128–191 (/16), C 192–223 (/24, 254 হোস্ট), D multicast, E পরীক্ষামূলক। 127 = loopback।

  3. সাবনেটিং: block = 256 − mask octet; network = IP-এর সমান বা ছোট block-এর গুণিতক; broadcast = net + block − 1; ব্যবহারযোগ্য = block − 2। Subnets = 2^borrowed; hosts = 2^hostbits − 2।
  4. মাস্ক: /25 .128 (126) · /26 .192 (62) · /27 .224 (30) · /28 .240 (14) · /30 .252 (2)। VLSM: সবচেয়ে বড় ব্লক আগে।
  5. Supernet = পাশাপাশি নেটওয়ার্ক জোড়া দেওয়া (ছোট প্রিফিক্স)। রাউটিং চলে longest-prefix match-এ।
  6. OSI (৭): Physical, Data-link, Network, Transport, Session, Presentation, Application। PDU: bit→frame→packet→segment→data।
  7. TCP/IP (৪): Network-access, Internet, Transport, Application। ইন্টারনেট চলে TCP/IP-তে, OSI-তে নয়।
  8. লেয়ার অনুযায়ী ডিভাইস: hub/repeater L1, switch/bridge L2, router L3, gateway L7 পর্যন্ত।
  9. TCP connection-oriented, নির্ভরযোগ্য, 20-বাইট হেডার (HTTP/FTP/SMTP); UDP connectionless, দ্রুত, 8-বাইট (DNS/VoIP)। 3-way handshake: SYN → SYN-ACK → ACK।
  10. Flow control = প্রাপককে রক্ষা; congestion control (AIMD) = নেটওয়ার্ককে রক্ষা।
  11. রাউটিং: distance-vector (RIP, Bellman-Ford, ধীর) বনাম link-state (OSPF, Dijkstra, দ্রুত); AS-এর মধ্যে BGP।
  12. টপোলজি: mesh লিংক = n(n−1)/2; star = n; bus = 1। ল্যাবে star।
  13. মাধ্যম: ফাইবার = সর্বোচ্চ ব্যান্ডউইথ, EMI নেই; crosstalk কমাতে UTP পাকানো; straight-through (ভিন্ন ডিভাইস) বনাম crossover (একই ধরনের)।
  14. Delay: transmission = bits ÷ bandwidth; propagation = distance ÷ speed। Nyquist = 2B·log₂L।
  15. IPv4 = 32 বিট; IPv6 = 128 বিট, 40-বাইট নির্দিষ্ট হেডার, IPsec অন্তর্নির্মিত। LAN < MAN < WAN।
  16. এরর: parity (১ বিট), checksum (যোগফল + complement), CRC (polynomial ভাগ, burst ধরে)। Hamming সংশোধন করে।
  17. ওয়্যারলেস: Bluetooth 802.15 (PAN), Wi-Fi 802.11 (LAN), WiMAX 802.16 (MAN)। CD = তারযুক্ত, CA = ওয়্যারলেস।
  18. ডেটা কমিউনিকেশন: simplex/half/full duplex; sync বনাম async; FDM/TDM/WDM মাল্টিপ্লেক্সিং; Nyquist 2B·log₂L।
  19. কাস্টিং: unicast (একজন), multicast (গ্রুপ), broadcast (সবাই), anycast (নিকটতম)। IPv6-এ broadcast নেই।
