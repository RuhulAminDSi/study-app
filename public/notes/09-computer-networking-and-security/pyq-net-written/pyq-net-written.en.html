Private IPs are not routable on the internet; NAT (Network Address Translation) maps many private IPs to one public IP, saving addresses and hiding the internal network. 3Subnet mask, CIDR & why we subnet

foundation for every subnetting problem
Q4 What is a subnet and a subnet mask? Why is it used? / What is CIDR? / Primary motivation for moving from classful to classless (CIDR) addressing?Combined Bank SO(IT) 2024 · Rupali Bank ANE 2023 · BPDB AE(CSE) 2021 · BPSC AP 2021 · Sonali Bank ADBA 2024 · Combined Bank ADA 2024

A subnet mask separates an IP into network (1-bits) and host (0-bits) parts; it is why a device knows which addresses are "local". Subnetting splits one big network into smaller ones — less broadcast traffic, better security/management, no wasted addresses. CIDR (Classless Inter-Domain Routing, written /n) drops fixed classes so any prefix length is allowed — the motivation was to stop IPv4 address exhaustion and shrink routing tables (via supernetting).

Memory trick Block size = 256 − mask octet. For /26 the interesting octet is 192, block = 256−192 = 64; subnets start at 0, 64, 128, 192. Usable = block − 2 (network + broadcast). Subnets = 2^(borrowed bits); hosts = 2^(host bits) − 2.
Exam trap The last mask octet is always one of 128, 192, 224, 240, 248, 252, 254 (the "magic numbers"). /30 gives exactly 2 usable (a router-to-router link); /31 is used point-to-point with no host subtraction.

How to supernet: write the networks in binary, find the longest common prefix, that length is the supernet mask. The networks must be contiguous and the block must start on a valid boundary (e.g. .4/22 not .5/22). Longest-prefix match: when several routes match a destination, the router picks the one with the most 1-bits in the mask (most specific), and a default route (0.0.0.0/0) catches everything else.

Memory trick Subnetting borrows host bits (longer prefix); supernetting gives them back (shorter prefix). Supernetting shrinks the routing table; the match rule is always "longest prefix wins".

Order (top→bottom): All People Seem To Need Data Processing. PDU chain: data → segment (L4) → packet (L3) → frame (L2) → bit (L1) (Combined Bank SO(IT) 2023). Flow control happens at the data-link and transport layers (BB AP 2019). The network layer is where routing and the IP packet live (BPSC AME 2019).

Each layer's one-line job: Application — network services to apps (browser, mail); Presentation — translation, encryption, compression; Session — dialogue control (open/keep/close); Transport — segmentation, ports, reliable end-to-end delivery; Network — logical (IP) addressing + best-path routing; Data link — framing + MAC addressing + error detection; Physical — bits as signals on the medium. Layers 1–3 are "network/media support", 5–7 are "user support", and layer 4 joins them.

Memory trick Top→bottom: All People Seem To Need Data Processing. Bottom→top: Please Do Not Throw Sausage Pizza Away. PDUs: bit → frame → packet → segment → data.
Exam trap A firewall works mainly at L3 (packet filter) — can go up to L7; router at L3; switch/bridge at L2; hub/repeater at L1; access point at L2. End-to-end encryption best fits the presentation layer (L6).

Q23 Why does DNS use UDP? Describe the DNS resolution of www.companybd.com. / Which service uses both TCP and UDP?Combined Bank Officer(IT) 2025 · Combined Bank SO(IT) 2021

TCP congestion phases: slow start (cwnd doubles each RTT until a threshold), congestion avoidance (linear +1), on loss → fast retransmit/recovery (halve cwnd) or timeout (back to slow start). Sliding window lets several unacked frames be in flight = better link use than stop-and-wait; window efficiency = W·Tt / (Tt + 2·Tp). ARQ types: stop-and-wait (1 frame), go-back-N (resend from the lost one), selective-repeat (resend only the lost one — most efficient).

Congestion signs & control: rising delay, dropped packets, timeouts. Approaches: open-loop (prevent — admission control, traffic shaping with leaky/token bucket) and closed-loop (react — AIMD, choke packets, ECN). A stable, low end-to-end latency means the window stays near the bandwidth-delay product with few losses.

Memory trick Flow control = don't drown the receiver; congestion control = don't drown the network. TCP does both; UDP does neither. AIMD = slowly climb, sharply back off.

IPv6 shorthand rules: drop leading zeros in each group; replace one run of all-zero groups with ::. e.g. 2001:0db8:0000:0000:0000:0000:0000:0001 → 2001:db8::1. Why IPv6 is faster: fixed header, no per-router fragmentation, no header checksum.

Memory trick IPv4 = 32 bits (4 octets); IPv6 = 128 bits (8 hex groups). IPv6 has unicast / anycast / multicast — but no broadcast. NAT is an IPv4 workaround; IPv6 doesn't need it.

Q35 Explain the parity method for error detection and write the ASCII of "Delta". / What is CRC vs parity — which is better?BB AME 2023 · RAKUB ANSE 2023 · Combined Bank SO(IT) 2021

Parity adds 1 bit so the total number of 1s is even (even parity) or odd; it catches any single-bit error but misses even numbers of errors. ASCII "Delta" = 68 101 108 116 97 = 01000100 01100101 01101100 01110100 01100001. CRC beats parity: it catches burst errors (parity only single-bit). Simple and two-dimensional parity both use parity bits (Combined Bank SO(IT) 2021 → answer (d) "a and b").

Q36 CRC: data 11100, divisor 1001 — find the transmitted codeword. / Checksum of (3, 9, 7, 12, 4) in 8-bit — what is actually sent?Combined Bank AP 2023 · JBL ANA 2022 · Combined Bank AP 2026 · Bank AP written (bank name cut off on the sheet)
CRC 11100 / 1001: append 000 -> 11100000, XOR-divide remainder = 111 -> codeword sent = 11100 111

CRC codeword = 11100111 (remainder 111). The receiver divides by 1001; a non-zero remainder = error. Checksum of 3+9+7+12+4 = 35 = 00100011; 1's-complement checksum = 11011100; sent = the 5 data bytes + this checksum, and the receiver's total should be all-1s.

Checksum adds the data words, takes the 1's complement, and sends it along; the receiver re-adds everything and expects zero (all-ones). Used in IP/TCP/UDP headers (BPDB AE(CSE) 2021, Combined Bank AP 2026).
