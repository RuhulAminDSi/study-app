1Protocol Hierarchies: Why Layers?

MCQ + Written
Definition A network is a stack of layers; each offers a service to the layer above and hides how. Layer n talks to layer n on the other machine (its peer) by the layer-n protocol. Architecture = layers + protocols; protocol stack = one protocol per layer.
  • Protocol: rules between peers (horizontal)
  • Service: what a layer gives the layer above (vertical)
  • Interface: boundary between adjacent layers
  • SAP (service access point): port, IP, MAC
  • Encapsulation: each layer adds its header going down

OSI 7 vs TCP/IP 4: full comparison in the OSI Model lesson

Connection-oriented (set up → use → release: TCP, ATM) vs connectionless (full address in every unit: IP, UDP, Ethernet). OSI primitives: Request → Indication → Response → Confirm. Design issues: addressing, error and flow control, multiplexing, routing, fragmentation.

2The Data Link Layer: Jobs & Services

high-yield
  • Framing: cut the bit stream into frames
  • Physical addressing: MAC in header
  • Error control: detect (CRC), retransmit
  • Flow control: don't swamp the receiver
  • Access control: who uses a shared link
IEEE sublayers
LLC (802.2): flow/error control, which network protocol
MAC (802.3, 802.5, 802.11 …): access + framing on one medium

Services: unacknowledged connectionless (Ethernet) · acknowledged connectionless (Wi-Fi) · acknowledged connection-oriented (HDLC). DLL delivery is hop-to-hop; transport is end-to-end.

Exam trap The data link layer adds a trailer (the FCS) as well as a header; the layers above add headers only.

Networking · Data Link & LANsCRC & Hamming

5CRC (Cyclic Redundancy Check)

written favourite
Method Generator G(x) of degree r (r + 1 bits): append r zeros, divide by G in modulo-2 (XOR); the r-bit remainder is the CRC; send data + CRC. Receiver divides by G: remainder 0 → accept.
Worked example ✍ Data 100100, G = 1101 (x³ + x² + 1, r = 3)
  1. Dividend 100100000
  2. 1001⊕1101 = 0100 → 1000⊕1101 = 0101
  3. 1010⊕1101 = 0111 → 1110⊕1101 = 0011
  4. 0110 (leading 0: ⊕0000) → 1100⊕1101 = 001 → send 100100 001
CRC catches
all single-bit errors · all odd-count errors if (x + 1) divides G · all bursts ≤ r · burst r + 1: 1 − (½)^(r−1) · longer: 1 − (½)^r
CRC-8 ATM HEC · CRC-16 HDLC, PPP · CRC-32 Ethernet, Wi-Fi
Exam trap Append degree zeros (3 for 1101), not the number of generator bits (4). Modulo-2 subtraction = XOR: no borrows.

6Hamming Distance & Hamming Code

high-yield
Hamming distance d(x, y) = positions where two codewords differ = 1s in x ⊕ y; d(10101, 11110) = 01011 → 3. dmin = smallest distance between any two valid codewords.
Rules detect s: dmin ≥ s + 1 · correct t: dmin ≥ 2t + 1 · check bits: 2r ≥ m + r + 1 → m = 4: 3 (7, 4) · 7: 4 (11, 7) · 8: 4 (12, 8) · 16: 5 · 32: 6
Worked example ✍ Data 1011 into positions 3, 5, 6, 7 (even parity):
  1. P1 = 3⊕5⊕7 = 1⊕0⊕1 = 0
  2. P2 = 3⊕6⊕7 = 1⊕1⊕1 = 1
  3. P4 = 5⊕6⊕7 = 0⊕1⊕1 = 0 → 0110011
  4. Bit 6 flips: 0110001 → checks C4 C2 C1 = 1 1 0 = 6 → flip bit 6
Memory trick Parity bits sit at powers of 2; position k is checked by the ones that sum to k: 6 = 4 + 2.
Exam trap Hamming (7, 4), dmin = 3: corrects 1 or detects 2. An extra parity bit gives SEC-DED (ECC RAM).

Networking · Data Link & LANsFlow control

7Flow Control: Stop-and-Wait

numerical
Definition Flow control stops a fast sender flooding a slow receiver. Error control = ARQ (automatic repeat request): detect, ACK/NAK, timeout, resend. Stop-and-wait: one frame, then wait for its ACK; seq. numbers 0, 1 catch duplicates.
Formulas
Tt = L / B (frame bits ÷ bandwidth)
Tp = d / v (v ≈ 2 × 10⁸ m/s in cable)
a = Tp / Tt
Stop-and-wait: η = 1 / (1 + 2a)
Sliding window: η = W / (1 + 2a), max 1
100% busy needs W ≥ 1 + 2a
Throughput = η × B · BDP = B × RTT
Worked example ✍ B = 1 Mbps, L = 1000 bits, Tp = 20 ms. Tt = 1 ms → a = 20 → stop-and-wait η = 1/41 = 2.4% (24 kbps). Full use needs W ≥ 41 → Go-Back-N: 2ᵐ − 1 ≥ 41 → m = 6; Selective Repeat: 2ᵐ⁻¹ ≥ 41 → m = 7.

9HDLC (High-Level Data Link Control)

high-yield
Definition ISO bit-oriented protocol (from IBM's SDLC), point-to-point or multipoint, half/full duplex: bit stuffing, flag 01111110 (7E), sliding-window ARQ. Family: LAPB (X.25), LAPD (ISDN), LAPM (modems); basis of PPP and 802.2 LLC framing.

Stations: primary sends commands, secondary sends responses, combined does both. Configurations: unbalanced = 1 primary + n secondaries; balanced = 2 combined stations (point-to-point).

Transfer modeConfig.Who may start sending?
NRM Normal Response Modeunbalancedsecondary only when polled (multipoint)
ARM Asynchronous Response Modeunbalancedsecondary without permission (rare)
ABM Asynchronous Balanced Modebalancedeither station, any time (LAPB; most common)

Control field (8-bit, modulo 8)

3-bit N(S)/N(R) → window ≤ 7; extended 16-bit control (SABME) → modulo 128, window ≤ 127. P/F: Poll in a command, Final in a response.

Memory trick I-S-U start with 0, 10, 11. RR/RNR = "Ready / Not Ready", REJ = reject all, SREJ = reject one.
Exam trap ✍ N(R) = the next frame expected, not the last received: an I-frame with N(S) = 3, N(R) = 5 is frame 3 and acknowledges frames up to 4. HDLC is bit-oriented; PPP looks similar but is byte-oriented.

10DLL in the Internet: SLIP & PPP

MCQ + Written

Point-to-point links (dial-up, leased lines, DSL as PPPoE, router-to-router over SONET) use PPP (RFC 1661), the successor of SLIP. On LANs the Internet runs over Ethernet and Wi-Fi.

PointSLIP (RFC 1055)PPP (RFC 1661)
FramingEND byte C0, escape DBflag 7E, escape 7D, byte ⊕ 20
Error detectionnoneFCS (CRC-16 or CRC-32)
Network protocolsIP onlymany (protocol field, NCPs)
IP addressconfigured by handnegotiated (IPCP)
AuthenticationnonePAP or CHAP

PPP phases: Dead → Establish (LCP: link options) → Authenticate (optional) → Network (NCP, e.g. IPCP) → Open → Terminate → Dead. PAP: 2-way, password in clear text, once. CHAP: 3-way challenge–response (MD5 hash of challenge + secret), secret never sent, repeated during the session. Stuffing: 7E → 7D 5E, 7D → 7D 5D.

Exam trap PPP detects errors (FCS) but in its default mode has no sequence numbers, ACKs or flow control: a bad frame is just dropped and upper layers recover.

11Data Link Layer of ATM

MCQ
Idea ATM switches fixed 53-byte cells = 5-byte header + 48-byte payload over virtual circuits (VPI/VCI instead of MAC addresses). The data-link-type work is done by the TC (Transmission Convergence) sublayer under the ATM layer.
  • HEC: CRC-8 (x⁸ + x² + x + 1) over the first 4 header bytes only; corrects 1-bit, detects multi-bit header errors
  • Cell delineation: find cell edges by checking HEC (hunt → presync → sync)
  • Cell-rate decoupling (idle cells), fit cells into SONET/SDH frames
  • CLP = 1: drop this cell first under congestion
Memory trick "5 + 48 = 53". 48 was a compromise between 32 and 64 bytes. Cell tax = 5/53 ≈ 9.4%.
Elsewhere AAL → Transport lesson; ATM network layer (VPI/VCI switching) → IP lesson.

CSMA/CD (classic half-duplex Ethernet)

Listen before and while sending; on a collision send a jam signal, abort, back off. To detect a collision the sender must still be sending when it returns: Tfr ≥ 2 × Tp → Lmin = 2 × Tp × B.

Example ✍ 10 Mbps, worst round trip 51.2 μs → Lmin = 10⁷ × 51.2 × 10⁻⁶ = 512 bits = 64 bytes, the Ethernet minimum frame.
Binary exponential backoff after the n-th collision wait K × 512 bit-times, K random in 0 … 2^min(n,10) − 1; give up after 16 tries.
Exam trap Full-duplex switched Ethernet has no collisions, so CSMA/CD is switched off. Carrier sensing cannot stop all collisions because of propagation delay.
CSMA/CA (wireless) A radio cannot hear a collision while it transmits (its own signal swamps the receiver), and some stations cannot hear each other. So Wi-Fi avoids collisions: interframe spaces, a random contention window and a positive ACK for every frame.

13IEEE 802.11 (Wi-Fi)

high-yield
  • RTS/CTS: sender asks (RTS), receiver grants (CTS); all who hear CTS keep quiet
  • NAV: virtual carrier sense, the "busy until" timer
  • IFS order: SIFS < PIFS < DIFS; ACK/CTS wait only SIFS, so they win
  • DCF (contention, mandatory) · PCF (AP polls, optional)
  • Frame has up to 4 MAC addresses (via the AP)

802.11b 2.4 GHz, 11 Mbps, DSSS · a 5 GHz, 54 Mbps, OFDM · g 2.4 GHz, 54 Mbps, OFDM · n (Wi-Fi 4) 2.4/5 GHz, 600 Mbps, MIMO · ac (Wi-Fi 5) 5 GHz, ≈ 6.9 Gbps, MU-MIMO · ax (Wi-Fi 6/6E) up to 6 GHz, ≈ 9.6 Gbps, OFDMA. BSS = AP + stations; ESS = BSSs on a distribution system; IBSS = ad hoc. Security: WEP (broken) → WPA → WPA2 (802.11i, AES-CCMP) → WPA3.

Memory trick Wired = Detect (CD), wireless = Avoid (CA). "Short waits win": SIFS is shortest.

14Token Passing: Token Ring & FDDI

MCQ
Token Ring (IEEE 802.5) 4 or 16 Mbps; a 3-byte token circulates and only its holder sends; differential Manchester; star-wired ring through an MAU; no collisions, deterministic delay. Token Bus = 802.4.
FDDI (ANSI X3T9.5) 100 Mbps over fibre; dual counter-rotating rings (on a break the ring wraps); timed token; 4B/5B + NRZ-I; ring ≤ 100 km, ≈ 500 stations. Trap: ANSI, not IEEE 802.

16Ethernet Frame & MAC Address

high-yield
  • Preamble 10101010 × 7, SFD 10101011 (not counted); data < 46 B is padded; gap 96 bit-times. Type ≥ 0x0600 → EtherType (0800 IPv4, 0806 ARP, 86DD IPv6); ≤ 1500 → length.
  • MAC address 48 bits: first 24 = OUI (vendor); LSB of byte 1: 0 unicast, 1 multicast; broadcast FF-FF-FF-FF-FF-FF.

Media: 10Base5 thick coax 500 m · 10Base2 thin coax 185 m · 10Base-T UTP 100 m · 10Base-F 2 km (Manchester) · Fast Ethernet 802.3u: 100Base-TX Cat 5, 100 m, 4B/5B + MLT-3 · 100Base-FX fibre 2 km · 100Base-T4 Cat 3, 8B/6T.

Exam trap Minimum frame 64 B, minimum data 46 B; max frame 1518 B, MTU 1500 B. Fast Ethernet keeps the 64-byte minimum.

17Hubs, Bridges, Switches & VLANs

high-yield
DeviceLayerForwards byCollision dom.Broadcast dom.
Repeater / hub1nothing: repeats to all ports1 for all ports1
Bridge / switch2MAC address1 per port1 (per VLAN)

Transparent bridge (802.1D): backward learning of each source MAC → port; then forward to the known port, filter if same port, flood if unknown/broadcast. Switch modes: store-and-forward (CRC checked) · cut-through (after dest. MAC) · fragment-free (first 64 B).

STP (802.1D) Loops cause broadcast storms; STP elects a root bridge (lowest priority + MAC) and blocks ports → one loop-free tree. RSTP = 802.1w.
VLAN (802.1Q) A software broadcast domain. 4-byte tag: TPID 8100, PCP 3, DEI 1, VID 12 bits → 4094; trunks carry tags.
Worked example ✍ Router → switch (4 PCs) and → hub (3 PCs). Collision domains = 5 switch ports + 1 hub = 6; broadcast domains = 2.

Written question A 1 Mbps satellite link has a one-way propagation delay of 270 ms and carries 1000-bit frames. Find (i) the link utilization with stop-and-wait, (ii) the window size for full utilization, (iii) the minimum sequence-number bits for Go-Back-N and for Selective Repeat. 8 marks

  3. Full use: W ≥ 1 + 2a = 541 frames (bandwidth × RTT = 541 000 bits) 2
  4. GBN: 2ᵐ − 1 ≥ 541 → m = 10 (window 1023). SR: 2ᵐ⁻¹ ≥ 541 → m = 11 (window 1024) 3
