১n-চ্যানেল JFET: কাজের নীতি ও অঞ্চল

লিখিত ×২
প্রশ্ন বিভিন্ন মানের VGS ও VDS-এর জন্য n-চ্যানেল JFET-এর কাজের নীতি ব্যাখ্যা করো।
বাংলাদেশ ব্যাংক AME (BIBM) · ০৪.০২.২০২৩ · Q10(b) · "operating regions" নামে অন্যত্রও এসেছে

JFET হলো একটি ভোল্টেজ-নিয়ন্ত্রিত, ইউনিপোলার ডিভাইস। গেট একটি রিভার্স-বায়াসড p–n জাংশন, তাই IG ≈ 0 এবং Rin ≈ 10⁸–10¹⁰ Ω।

  1. VGS = 0, ছোট VDS: চ্যানেল পুরো খোলা; ID রেখা (রেখাৎ) বাড়ে (ohmic অঞ্চল, একটি রেজিস্টর)
  2. VGS = 0, VDS বাড়ছে: ড্রেন প্রান্তে রিভার্স বায়াস সবচেয়ে বেশি, তাই ডিপ্লিশন স্তর ফলার আকারে বাড়ে। VDS = |VP|-এ এরা মিলে যায়: pinch-off; ID স্থির হয়ে যায় IDSS-এ
  3. VGS ঋণাত্মক: সবখানে চ্যানেল সরু; pinch-off হয় VDS = VGS − VP-এ, কম ID স্যাচুরেটেড
  4. VGS ≤ VGS(off) = VP: চ্যানেল বন্ধ, ID ≈ 0: cut-off
  5. খুব বড় VDS: ড্রেন প্রান্তে অ্যাভালাঞ্চ ব্রেকডাউন
অঞ্চল (VP < 0)শর্তআচরণ
Cut-offVGS ≤ VPID ≈ 0, খোলা সুইচ
Ohmic (triode)VDS < VGS − VPভোল্টেজ-নিয়ন্ত্রিত R
স্যাচুরেশন (pinch-off)VDS ≥ VGS − VPID = IDSS(1 − VGS/VP)²
মনে রাখার কৌশল JFET = একটি বাগানের নল: VGS চেপে ধরে, VDS ড্রেন প্রান্তে চিপে ধরে; পুরো চাপ দিলে (VP) প্রবাহ বন্ধ। সাধারণত ON।
পরীক্ষার ফাঁদ JFET-এর গেট আলগা নয় (সেটা MOSFET), আর JFET-এর কোনো Vth নেই: VGS = 0-এও পরিবাহিত হয় এবং VGS(off) = VP-এ বন্ধ হয়।

২BJT: কাট-অফ, অ্যাকটিভ ও স্যাচুরেশন অঞ্চল

লিখিত ×২
প্রশ্ন চিত্রসহ ট্রানজিস্টরের কাজের cut-off, saturation ও active অঞ্চল বর্ণনা করো।
বাংলাদেশ ব্যাংক AME (BIBM) · ০৪.০২.২০২৩ · Q10(a)  ·  CE লোড লাইনসহও একটি নিয়োগ পত্রে এসেছে
  1. লোড লাইন (KVL): VCE = VCC − ICRC, (VCC, 0) থেকে (0, VCC/RC); IB বদলালে Q এই রেখার উপর সরে
  2. Cut-off: রেখা IB = 0 বক্ররেখার সাথে মেলে; কেবল লিকেজ ICEO প্রবাহিত হয়, VCE ≈ VCC: একটি খোলা সুইচ
  3. স্যাচুরেশন: রেখা IB(sat)-এর সাথে মেলে; IC(sat) ≈ VCC/RC, VCE = Vknee ≈ 0.2 V; আর IB বাড়িয়েও IC বাড়ে না: একটি বন্ধ সুইচ
  4. অ্যাকটিভ: এই দুইয়ের মাঝে; IC = βIB, ট্রানজিস্টর পরিবর্ধন করে (পূর্ণ স্কয়িং-এর জন্য Q মাঝখানে)
অঞ্চলB–EC–Bnpn-র মানব্যবহার
Cut-offউল্টোউল্টোIB = 0, IC = ICEOসুইচ OFF
অ্যাকটিভসামনেউল্টোVBE ≈ 0.7 V, IC = βIBপরিবর্ধক
স্যাচুরেশনসামনেসামনেVCE ≈ 0.2 V, IC < βIBসুইচ ON
সমাধানকৃত উদাহরণ ✍ VCC = 12 V, RC = 2 kΩ, β = 100, IB = 43 µA → IC = 4.3 mA, VCE = 3.4 V: অ্যাকটিভ। IB = 215 µA → βIB = 21.5 mA > IC(sat) = 11.8/2k = 5.9 mA: স্যাচুরেটেড।
α ও β (MCQ) IE = IB + IC; α = IC/IE, β = IC/IB = IC/(IE − IC) → β = α/(1 − α), α = β/(1 + β)। অপশন β = α/(1+α), 1 − α, α = β², α/(1 − α) → (ঘ)। α = 0.98 → β = 49।
পরীক্ষার ফাঁদ স্যাচুরেশনে IC = βIB মিথ্যা: সার্কিট IC-কে ≈ VCC/RC-তে সীমাবদ্ধ করে। BJT-র "স্যাচুরেশন" (সুইচ ON) FET-র "স্যাচুরেশন" (সমতল পরিবর্ধন অঞ্চল) নয়।

৩কাউন্টার ধরনের (ডিজিটাল-র্যাম্প) ADC

লিখিত
প্রশ্ন এমন একটি ADC সার্কিট আঁকো যা অ্যানালগ সিগন্যালকে ডিজিটালে রূপান্তর করে, এবং ব্যাখ্যা করো।
পেট্রোবাংলা সহকারী ম্যানেজার (IT) (BUET) · ১৬.০৯.২০২২ · Q6

ADC একটি ভোল্টেজ Vin-কে n-বিট সংখ্যায় বদলে। কাউন্টার ধরনের ADC ঘড়ির পালস গোনে, সেই সংখ্যাকে DAC দিয়ে আবার ভোল্টেজে বদলায়, এবং যখন সেই ভোল্টেজ Vin অতিক্রম করে তখনই থেমে যায়।

  1. শুরু: কাউন্টার মুছে যায়, VDAC = 0 < Vin, কম্প্যারেটর HIGH
  2. HIGH AND গেট খোলে: ঘড়ির পালস কাউন্টারে পৌঁছায়
  3. DAC-এর আউটপুট একটি সিঁড়ির মতো বাড়ে, প্রতি ঘড়িতে 1 LSB
  4. VDAC > Vin → কম্প্যারেটর LOW → ঘড়ি আটকে যায়
  5. কন্ট্রোল সংখ্যাটি ল্যাচ করে (আউটপুট) ও কাউন্টার মুছে দেয়
সমাধানকৃত উদাহরণ ✍ ধাপ = Vref/2ⁿ। 8-bit, Vref = 5.12 V, 1 MHz ঘড়ি, Vin = 3.01 V: ধাপ = 20 mV; গোনা থামে প্রথম N-এ যেখানে 0.02N > 3.01 → N = 151 = 1001 0111 (VDAC = 3.02 V), 151 µs পরে। সর্বোচ্চ (2ⁿ − 1) ঘড়ি = 255 µs।

অন্যান্য ADC: flash = ১ ঘড়ি, 2ⁿ − 1 কম্প্যারেটর (সবচেয়ে দ্রুত) · SAR = n ঘড়ি, নির্দিষ্ট (সবচেয়ে বেশি MCU-তে) · dual-slope = সবচেয়ে ধীর, নয়েজ প্রত্যাখ্যান করে (মাল্টিমিটার)। নমুনায় নেওয়া fs ≥ 2fmax (নাইকুইস্ট)।

মনে রাখার কৌশল কাউন্টার ADC = "সিঁড়ি বেড়ে যাও, ততক্ষণ না মাথা ছাদে ঠেকে যায়" (Vin); SAR = বাইনারি সার্চ, MSB আগে।
পরীক্ষার ফাঁদ কাউন্টার ADC-র রূপান্তর সময় স্থির নয়: এটি Vin-এর সাথে বাড়ে। নির্দিষ্ট n-ঘড়ির সময় SAR-এর।
