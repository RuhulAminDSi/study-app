MCQ + Written
Definition A single-stage amplifier uses one transistor (BJT or FET), biased in its active region (BJT) or saturation / pinch-off region (FET), to make a small AC signal larger. The DC bias sets the Q-point; the AC signal rides on it. Energy comes from the DC supply, not from the transistor.

2Coupling & Bypass Capacitors · DC vs AC Analysis

  • Coupling C (C1, C2): pass AC, block DC, so the source and load do not upset the Q-point. Rule: XC ≤ R/10 at the lowest signal frequency.
  • Bypass C (CE): shorts RE for AC only. RE keeps the DC stability, yet the AC gain rises from ≈ −RC/RE to −RC/re.
  1. DC analysis: capacitors = open; find IE, VCE (bias, lesson 2)
  2. re = 26 mV / IE
  3. AC analysis: capacitors = short, DC supply = AC ground
  4. Replace the transistor by its model; find Zi, Zo, Av, Ai
Memory trick "DC: caps out, AC: caps in, VCC down". For AC, R1 and R2 both end on ground, so they appear in parallel: R′ = R1 ∥ R2.

3The re Model & the Common-Emitter Stage

high-yield
re model The forward-biased BE junction has AC resistance re = 26 mV / IE (room temperature, VT ≈ 26 mV). Seen from the base it looks β times larger: Zb = βre (= hie, also called rπ). The output is a current source βIb (= Ic), with ro = 1/hoe in parallel.

Worked example ✍ VCC = 12 V, R1 = 47 kΩ, R2 = 10 kΩ, RC = 3.3 kΩ, RE = 1 kΩ, β = 100, no load.
  1. βRE = 100 kΩ ≥ 10R2 ✓ → VB = 12 × 10/57 = 2.11 V, VE = 1.41 V, IE = 1.41 mA
  2. re = 26/1.41 = 18.5 Ω; βre = 1.85 kΩ; R1 ∥ R2 = 8.25 kΩ
  3. Bypassed: Zi = 8.25k ∥ 1.85k = 1.51 kΩ, Zo = 3.3 kΩ, Av = −3300/18.5 = −178 (45 dB)
  4. CE removed: Zb = 100 × 1018.5 Ω = 101.9 kΩ → Zi = 7.63 kΩ, Av = −3300/1018.5 = −3.24
Memory trick CE gain = "what's in the collector ÷ what's in the emitter", with a minus sign. Bypassed: only re is left in the emitter.
Exam trap Removing CE lowers the gain (here −178 → −3.24) but raises Zi and makes the gain stable and nearly independent of β (negative feedback).

4Common Base & Common Collector

Common base (CB) Input at E, output at C.
Zi = RE ∥ re ≈ re (very low, ~10–50 Ω)
Zo ≈ RC · Av = +RC/re (no inversion)
Ai = α ≈ 0.98–0.99 (< 1)
Use: RF / high-frequency stages (no Miller effect), low-Z sources.
Common collector (CC) = emitter follower Input at B, output at E.
Zi = RB ∥ β(re + RE) → high
Zo = RE ∥ re ≈ re → very low
Av = RE/(RE + re) ≈ 1 (slightly < 1)
Ai ≈ β + 1. Use: buffer, impedance matching.

Worked example ✍ Emitter follower, IE = 2 mA, RE = 2.2 kΩ: re = 26/2 = 13 Ω; Av = 2200/2213 = 0.994; Zo = 2.2k ∥ 13 = 12.9 Ω. A weak source now sees a high Zi, and the load sees a ~13 Ω source.
Memory trick "CB: Big output, Baby input" · "CC: Copy Cat": the emitter copies the base voltage (minus 0.7 V), so Av ≈ 1.
Exam trap CB has Ai < 1 but a high Av; CC has Av < 1 but a high Ai. Only CE inverts. Darlington = two CC stages: βD ≈ β₁β₂.

Two-port equations (inputs i₁, v₂):

v₁ = h₁₁i₁ + h₁₂v₂
i₂ = h₂₁i₁ + h₂₂v₂

"Hybrid": mixed units (Ω, –, –, S). 2nd subscript = configuration: hie, hib, hic.

Approximate CE (hre, hoe ≈ 0)
Zi = hie · Ai = hfe · Zo = 1/hoe
Av = −hfeRL/hie
hfe = 50, hie = 1.1 kΩ, RL = 2.2 kΩ → Av = −100

Exam trap hfe (small-signal AC) ≈ hFE (= βDC, capitals) but they are not identical. hfb is negative (≈ −0.99).

6Frequency Response, −3 dB Points & Bandwidth

high-yield
  • Low end fL: XC of C1, C2, CE grows; fL = 1/[2π(Rs + Zi)C1]. CE usually sets the highest (dominant) fL.
  • High end fH: Cbe, Cbc, stray C. Miller effect: CMi = (1 + |Av|)Cbc.
  • At fL, fH: gain = 0.707 Amid (−3 dB), power = ½.
Worked examples ✍
① Sheet-3 stage, C1 = 10 μF, Rs ≈ 0: fL = 1/(2π × 1511 × 10⁻⁵) = 10.5 Hz
② Cbc = 4 pF, Av = −178: CMi = 179 × 4 = 716 pF
③ fL = 50 Hz, fH = 20 kHz → BW = 19.95 kHz
Memory trick "Big caps kill the bass, small caps kill the treble": external μF capacitors set fL, internal pF capacitances set fH. Gain × bandwidth ≈ constant.

7The Field-Effect Transistor (FET) Family

MCQ favourite
Definition A FET is a voltage-controlled, unipolar device: VGS sets the width (or existence) of a conducting channel between drain and source; only majority carriers flow (electrons in n-channel). The gate draws almost no current: IG ≈ 0, Zi very high.

8JFET: Construction & Operation

high-yield
  1. VGS = 0, small VDS: channel open, ID rises linearly (ohmic region: a voltage-controlled resistor)
  2. VDS grows: depletion layers meet near the drain = pinch-off; ID levels off at IDSS (max, VGS = 0)
  3. VGS more negative: channel narrower, ID smaller
  4. VGS = VP (= VGS(off)): channel closed, ID ≈ 0 (cut-off)
Region (n-channel, VP < 0)ConditionID
Cut-offVGS ≤ VP≈ 0
Ohmic (triode)VDS < VGS − VP∝ VDS; rd set by VGS
Saturation (pinch-off) ← amplifierVDS ≥ VGS − VPShockley, ~flat in VDS
Memory trick JFET = a garden hose: the gate squeezes it; squeeze fully (VGS = VP) and the flow stops. Open at rest → normally ON, depletion-mode only.
Exam trap n-channel: VGS ≤ 0; p-channel: VGS ≥ 0. A forward-biased gate loses the high Zi. Carriers enter at the source, leave at the drain.

9JFET Characteristics & Shockley's Equation

written favourite
Shockley's equation (saturation) ID = IDSS(1 − VGS/VP)² · inverse: VGS = VP(1 − √(ID/IDSS)) · square law → parabolic transfer curve
Worked examples ✍
① IDSS = 10 mA, VP = −4 V, VGS = −2 V: ID = 10(1 − 0.5)² = 2.5 mA
② IDSS = 8 mA, VP = −4 V, VGS = −1 V: ID = 8(0.75)² = 4.5 mA
③ Same FET, ID = 4.5 mA → VGS = −4(1 − 0.75) = −1 V ✓
Memory trick: 4-point sketch VGS = 0 → IDSS · 0.3VP → IDSS/2 · VP/2 → IDSS/4 · VP → 0. At VGS = 0, saturation starts at VDS = |VP|.

10Transconductance gm

gm = ΔID/ΔVGS at constant VDS: the slope of the transfer curve, in siemens (mS).
gm0 = 2IDSS/|VP|
gm = gm0(1 − VGS/VP) = gm0√(ID/IDSS)
Amplification factor μ = gmrd
Worked example ✍ IDSS = 10 mA, VP = −4 V: gm0 = 20/4 = 5 mS; at VGS = −2 V: gm = 5(1 − 0.5) = 2.5 mS. gm is largest at VGS = 0 and zero at VP.
Exam trap gm is the slope ΔID/ΔVGS, not ID/VGS. A BJT at 1 mA has gm = IC/VT ≈ 38 mS, far above a FET's few mS: FET stages give lower voltage gain.
Practical link In the ohmic region a JFET is a voltage-controlled resistor (AGC circuits, analog switches, choppers). Its tiny gate current makes it the input stage of JFET-input op-amps (e.g. TL071) and of pH-meter / electrometer probes.

11MOSFET: Construction & the Two Types

high-yield
Definition Metal-Oxide-Semiconductor FET: the gate is separated from the channel by a thin SiO₂ insulating layer, so it acts as a capacitor plate: Zi ≈ 10¹⁰–10¹⁵ Ω (JFET ~10⁸–10¹⁰ Ω). Four terminals: G, D, S and substrate (body), usually tied to S. Also called IGFET.
D-MOSFETE-MOSFET
Channeldiffused in (built-in)induced by VGS > VT
At VGS = 0ON, ID = IDSSOFF
Modes (n-ch)depletion (−) and enhancement (+)enhancement only
EquationShockley (VGS may be +)ID = k(VGS − VT)²
E-MOSFET (n-channel)
Cut-off: VGS < VT (threshold, VGS(th))
Triode (VDS < VGS − VT):
ID = k[2(VGS − VT)VDS − VDS²]
Saturation: ID = k(VGS − VT)²
gm = 2k(VGS − VT)
Worked example ✍ ID(on) = 10 mA at VGS(on) = 8 V, VT = 3 V.
k = 10/(8 − 3)² = 0.4 mA/V²
VGS = 6 V: ID = 0.4 × 3² = 3.6 mA; gm = 2 × 0.4 × 3 = 2.4 mS
VGS = 2 V (< VT): ID = 0
Exam trap JFET: depletion only; D-MOSFET: both modes; E-MOSFET: enhancement only. Thin oxide: ESD kills it.
Memory trick "E = Empty": no channel until you Enhance past VT; broken line = empty channel. "D = Done": channel already made, normally ON.
IT link: CMOS CMOS inverter = p-channel E-MOSFET (to VDD) over n-channel E-MOSFET, gates and drains tied: in 0 → out 1, in 1 → out 0. One is always OFF, so static power ≈ 0 (dynamic ≈ CVDD²f): CPUs and memories are CMOS.

Worked example: self bias ✍ IDSS = 8 mA, VP = −4 V, RS = 1 kΩ, RD = 3.3 kΩ, VDD = 16 V.
  1. VGS = −ID (ID in mA) → ID = 8(1 − ID/4)²
  2. ID² − 10ID + 16 = 0 → ID = 2 or 8 mA
  3. 8 mA gives VGS = −8 V, beyond VP: reject → ID = 2 mA, VGS = −2 V
  4. VDS = 16 − 2(3.3 + 1) = 7.4 V ≥ VGS − VP = 2 V ✓
