ELN · BJTConstruction

1Construction: Three Layers, Two Junctions

MCQ favourite
Definition A BJT is three doped regions, emitter (E), base (B), collector (C), forming two p–n junctions: emitter–base (JE) and collector–base (JC). Bipolar = both electrons and holes carry the current (a FET is unipolar). It is a current-controlled device: a small IB controls a large IC.
RegionDopingWidthJob
Emitterheaviestmediuminjects (emits) majority carriers into the base
Baselightestthinnest (µm)passes carriers through with little recombination
Collectormoderatewidestcollects carriers, dissipates most of the heat

Order to memorise: doping E > C > B · width C > E > B. A thin, lightly doped base means few recombinations, so IC ≈ IE.

Normal supplyC +, VBE ≈ +0.7 VC −, VEB ≈ +0.7 V

Memory trick npn = "Not Pointing iN"; pnp = "Points iN Proudly". The arrow is always on the emitter and points p → n.
Exam trap E and C of an npn are both n-type but not interchangeable (doping and size differ). Two separate diodes back to back do not make a transistor: the base must be thin.

History: point-contact transistor, Bardeen & Brattain, Bell Labs, 1947; junction (bipolar) transistor, Shockley, 1948; Nobel Prize 1956. "Transistor" = transfer + resistor. Silicon replaced germanium: lower leakage, works to ≈ 150 °C.

ELN · BJTOperation & currents

2Operation (npn, Active Mode)

written favourite
  1. JE forward-biased: the n⁺ emitter injects electrons into the base → IE
  2. The base is thin and lightly doped: only 1–5% recombine with holes → IB
  3. JC reverse-biased: its field sweeps the other 95–99% into the collector → IC
  4. A small IB controls a large IC: this is amplifying action
Current relations IE = IB + IC · α = IC/IE (0.95–0.995) · β = IC/IB (50–300)
β = α/(1 − α) · α = β/(1 + β) · IE = (1 + β)IB · γ = IE/IB = 1 + β (CC)

Leakage currents

  • ICBO: C–B reverse current with the emitter open (Si: nA, Ge: µA); minority carriers, doubles every 10 °C
  • CB: IC = αIE + ICBO
  • CE: IC = βIB + (1 + β)ICBO = βIB + ICEO
  • ICEO (base open) = (1 + β)ICBO: β times worse
dc vs ac β βdc = hFE = IC/IB · βac = hfe = ΔIC/ΔIB; nearly equal in the active region.
Memory trick α = "Almost 1", β = "Big". β = "a over one-minus-a".
Worked examples 1–2 ✍ IE = 10 mA, IC = 9.9 mA → IB = 0.1 mA, α = 0.99, β = 99 (0.99/0.01 = 99 ✓) · α = 0.98 → β = 0.98/0.02 = 49 · β = 200 → α = 200/201 = 0.995
Worked example 3 ✍ Ge transistor, β = 50, ICBO = 5 µA, IB = 40 µA → ICEO = 51 × 5 = 255 µA; IC = 50 × 40 + 255 = 2255 µA ≈ 2.26 mA. Leakage is 11% of IC, which is why Ge circuits drift with heat.
Worked example 4 ✍ Si, β = 120, IB = 50 µA → IC = 6 mA, IE = 121 × 50 µA = 6.05 mA, α = 120/121 = 0.9917, so IC ≈ IE.
Exam trap β is not a constant: it rises with temperature, varies with IC, and spreads widely between units of one type (e.g. hFE 100–300 on one datasheet). Good bias design must not depend on it.

4CE Characteristics

  • Early effect (base-width modulation): VCE ↑ → C–B depletion widens → effective base narrower → β and IC rise a little. Extended curves meet the VCE axis at −VA (Early voltage, 50–200 V); output resistance ro = VA/IC (VA = 100 V, IC = 1 mA → 100 kΩ).
  • The same effect shifts the input curve right as VCE rises (less IB for the same VBE).
  • CB characteristics: input IE vs VBE (diode); output IC ≈ IE, almost flat, and IC still flows at VCB = 0 (needs a small forward VCB to stop).
  • Breakdown: BVCEO < BVCBO; punch-through when the C–B depletion layer reaches the emitter.
Worked example: active or saturated? ✍ VCC = 10 V, RC = 1 kΩ, β = 100, IB = 0.2 mA. βIB = 20 mA, but IC(sat) = (10 − 0.2)/1 kΩ = 9.8 mA < 20 mA → saturated, VCE ≈ 0.2 V, IC = 9.8 mA.

ELN · BJTLoad line & Q-point

6DC Load Line & Q-point

written favourite
Definition The DC load line is the set of all (VCE, IC) the external circuit allows: VCE = VCC − IC(RC + RE) (RE = 0 if there is none). The Q-point (quiescent point) is where it meets the transistor's IB curve with no signal applied.
  • Saturation end (VCE = 0): IC(sat) = VCC/(RC + RE)
  • Cutoff end (IC = 0): VCE(off) = VCC
  • Slope = −1/(RC + RE)
  • Q near saturation → output clipped at the bottom (VCE(sat)); near cutoff → clipped at the top (VCC)
  • Q in the middle → largest symmetrical swing (class A)
Worked example (fixed bias) ✍ VCC = 12 V, RB = 565 kΩ, RC = 3 kΩ, β = 100, VBE = 0.7 V.
  1. IB = (12 − 0.7)/565 kΩ = 20 µA; IC = βIB = 2 mA
  2. VCE = 12 − 2 mA × 3 kΩ = 6 V → Q = (6 V, 2 mA)
  3. Ends: IC(sat) = 12/3 kΩ = 4 mA, VCE(off) = 12 V → Q exactly mid-line
ChangeEffect on line / Q
RB ↑IB ↓: Q slides down the same line toward cutoff
RC ↑line flatter (IC(sat) ↓); Q moves toward saturation
VCC ↑line shifts outward, parallel (same slope)
β ↑ (heat, new transistor)fixed bias: IC ↑, Q climbs toward saturation
AC load line ✍ With a load RL = 3 kΩ coupled by a capacitor, rac = RC ∥ RL = 1.5 kΩ; the steeper ac line passes through Q: ic(sat) = ICQ + VCEQ/rac = 2 + 6/1.5 = 6 mA, vce(off) = VCEQ + ICQrac = 6 + 3 = 9 V. Largest undistorted peak = min(6, 3) = 3 V.
Exam trap Same circuit, β = 200: βIB = 4 mA would need VCE = 0, so it saturates (IC ≈ 11.8 V/3 kΩ = 3.93 mA). A fixed-bias Q-point depends entirely on β.

ELN · BJTBiasing & stability

7Biasing Methods & Stability Factor

high-yield
Why bias? To place Q in the active region and keep it there while β (unit spread, temperature), ICBO (doubles / 10 °C) and VBE (falls ≈ 2.5 mV/°C) change.
Stability factors S = ∂IC/∂ICBO (β, VBE constant) · S′ = ∂IC/∂VBE · S″ = ∂IC/∂β. Range 1 ≤ S ≤ 1 + β; smaller S = more stable. General: S = (1+β)/(1 − β·∂IB/∂IC)
MethodIBVCES
① Fixed(VCC − VBE)/RBVCC − ICRC1 + β (worst)
② Coll.-feedback(VCC − VBE)/(RB + (1+β)RC)VCC − IERC(1+β)/(1+βRC/(RC + RB))
③ Emitter-stab.(VCC − VBE)/(RB + (1+β)RE)≈ VCC − IC(RC + RE)(1+β)(1+RB/RE)/(1+β+RB/RE)
④ Volt.-divider(VTh − VBE)/(RTh + (1+β)RE)≈ VCC − IC(RC + RE)same, RB → RTh; ≈ 1 + RTh/RE

④: RTh = R1 ∥ R2, VTh = VCCR2/(R1 + R2). Approximate method when βRE ≥ 10R2: VB = VTh, IE = (VB − 0.7)/RE, independent of β. Most stable, most widely used.

Derivation ✍ ③: VCC = IBRB + VBE + (IB + IC)RE → ∂IB/∂IC = −RE/(RB + RE) → S = (1+β)/(1+βRE/(RB + RE)). Fixed bias: IB does not depend on IC, so ∂IB/∂IC = 0 and S = 1 + β.
Memory trick RE looks (1+β) times bigger from the base. Small RB/RE (or RTh/RE) → S → 1.
Exam trap A bypass capacitor across RE removes the AC feedback (gain comes back) but keeps the DC stability. Collector-feedback also cuts the AC gain.

8Bias Worked Examples

written favourite
Example A: voltage-divider ✍ VCC = 18 V, R1 = 39 kΩ, R2 = 8.2 kΩ, RC = 3.3 kΩ, RE = 1 kΩ, β = 120.
  1. Check: βRE = 120 kΩ ≥ 10R2 = 82 kΩ ✓ → approximate method allowed
  2. VB = 18 × 8.2/47.2 = 3.13 V; VE = 2.43 V; IC ≈ IE = 2.43 mA
  3. VCE = 18 − 2.43 × (3.3 + 1) = 7.56 V
  4. Exact: RTh = 6.78 kΩ, IB = 2.43/(6.78 + 121) = 19.0 µA, IC = 2.28 mA, VCE ≈ 8.18 V (approx. is 6% high)
  5. S = 121(1 + 6.78)/(121 + 6.78) ≈ 7.4 (fixed bias would be 121)
Example B: emitter-stabilised ✍ VCC = 20 V, RB = 430 kΩ, RC = 2 kΩ, RE = 1 kΩ, β = 50.
  1. IB = 19.3 V/(430 + 51 × 1) kΩ = 40.1 µA; IC ≈ 2.01 mA; VCE ≈ 20 − 2.01 × 3 = 13.97 V
  2. S = 51(1 + 430)/(51 + 430) ≈ 45.7: better than fixed (51), far worse than Example A

9Thermal Runaway

Definition A self-destroying positive feedback loop: heat raises ICBO (and β) → IC rises → collector dissipation PC = VCEIC rises → the junction heats further, until the transistor burns out.
  • Prevent: RE / low S, heat sink (low thermal resistance θ), diode or thermistor compensation in the bias network
  • No runaway if VCE < VCC/2: PC = IC(VCC − ICR) → dPC/dIC = 2VCE − VCC < 0, so a rise in IC lowers PC (R = RC + RE)

10BJT as a Switch

IT link
VinRegionSwitchVout
0 V (0)cutoffopen5 V (1)
5 V (1)saturationclosed0.2 V (0)
Worked example ✍ IC(sat) = (5 − 0.2)/1 kΩ = 4.8 mA; with β = 100, IB(min) = 4.8 mA/100 = 48 µA. Actual IB = (5 − 0.7)/10 kΩ = 0.43 mA ≈ 9 × IB(min) → hard saturation ✓. RB must stay below 4.3 V/48 µA ≈ 89.6 kΩ. Rule: IB > IC(sat)/β, overdrive 2–10×.
  • Switching times: ton = td (delay) + tr (rise); toff = ts (storage) + tf (fall). ts is the longest: stored base charge must leave. A Schottky clamp (74LS TTL) stops deep saturation.
  • Dissipation is low in both states (IC ≈ 0, or VCE ≈ 0.2 V); it peaks during transitions. Relay coil: add a flyback diode.

Top 12 one-liners for MCQs

  1. Doping E > C > B; width C > E > B
  2. Base: thinnest and lightest doped
  3. Active = JE forward, JC reverse
  4. Saturation = both forward (switch ON)
  5. CE: 180° phase shift, highest power gain
  6. CC: highest Zin, Av ≈ 1, buffer
  1. CB: lowest Zin, Ai = α < 1
  2. Most stable bias: voltage-divider
  3. Least stable: fixed bias, S = 1 + β
  4. npn faster than pnp (electron mobility)
  5. Early effect = base-width modulation
  6. Storage time ts limits switching speed
Top traps E and C are not interchangeable · in saturation IC < βIB · CC current gain = 1 + β, not β · ICEO ≫ ICBO · bypassing RE keeps DC stability · β is not constant
All tricks together npn = Not Pointing iN · α Almost 1, β Big · F-R = For Real gain, F-F fully ON, R-R really OFF · CB Below 1, CE gains Everything, CC Copies · RE looks (1 + β) times bigger from the base
