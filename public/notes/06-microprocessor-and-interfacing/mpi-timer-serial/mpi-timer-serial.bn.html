সংজ্ঞা Intel 8254 PIT হলো ২৪-পিন, +5 V-এর একটি কাউন্টার/টাইমার চিপ, যাতে আছে তিনটি স্বাধীন 16-বিট ডাউন কাউন্টার (কাউন্টার 0, 1, 2)। প্রতিটি কাউন্টারের একটি CLK ইনপুট, একটি GATE ইনপুট ও একটি OUT আউটপুট আছে; এটি ৬টি মোডের (0–5) যেকোনোটিতে চলে, বাইনারি বা BCD-তে গোনে এবং CLK-এর প্রতিটি পতনশীল প্রান্তে (falling edge) এক করে কমায়। সফটওয়্যার ডিলে লুপের বদলে হার্ডওয়্যারে সময় মাপে, তাই CPU মুক্ত থাকে।

প্রতিটি কাউন্টারের ভেতরে: CR (কাউন্ট রেজিস্টার, CPU লেখে) → CE (16-বিট কাউন্টিং এলিমেন্ট) → OL (আউটপুট ল্যাচ, CPU পড়ে)। কাউন্ট লেখার পর পরের CLK পালসে তা CR থেকে CE-তে যায়।

মনে রাখার কৌশল "3-16-6-24": ৩টি কাউন্টার, প্রতিটি 16 বিট, ৬টি মোড, ২৪টি পিন। 8254 = 8253 + রিড-ব্যাক + দ্রুততর ক্লক।
পরীক্ষার ফাঁদ কন্ট্রোল ওয়ার্ড রেজিস্টার শুধু লেখা যায় (write-only); A1A0 = 11 দিয়ে কাউন্ট পড়া যায় না। সর্বোচ্চ কাউন্টের জন্য লোড করতে হয় 0000 = 65,536 (বাইনারি) বা 10,000 (BCD)।

৫কাউন্টের হিসাব ও প্রোগ্রামিং

লিখিতের প্রিয়
সূত্র

মোড 2, 3: N = f_clk ÷ f_out

ডিলে (মোড 0, 1, 4, 5): N = t × f_clk

T_clk = 1 ÷ f_clk (2 MHz → 0.5 µs)

সর্বনিম্ন f_out = f_clk ÷ 65,536

মোড 3, বিজোড় N: HIGH (N+1)/2, LOW (N−1)/2

N > 65,536 → দুটি কাউন্টার ক্যাসকেড

উদাহরণ ১: ক্লাসিক প্রোগ্রাম ✍ কাউন্টার 0 পোর্ট 40H-এ, কন্ট্রোল 43H-এ, CLK0 = 2 MHz; চাই 5 kHz বর্গ তরঙ্গ।
  1. N = 2 MHz ÷ 5 kHz = 400 = 0190H (1 kHz হলে: 2000 = 07D0H)
  2. CW: 00 11 011 0 = 36H (কাউন্টার 0, LSB/MSB, মোড 3, বাইনারি)
  3. 43H-এ CW লেখো, তারপর 40H-এ আগে LSB 90H, পরে MSB 01H
MOV AL, 36H ; কন্ট্রোল ওয়ার্ড OUT 43H, AL MOV AL, 90H ; 0190H-এর LSB OUT 40H, AL MOV AL, 01H ; 0190H-এর MSB OUT 40H, AL
উদাহরণ ২: ডিলে ✍ কাউন্টার 2-এ মোড 0-তে 1 ms ডিলে, CLK = 2 MHz: N = 1 ms × 2 MHz = 2000 (07D0H); CW = 10 11 000 0 = B0H। 2000 + 1 ক্লক ≈ 1 ms পর OUT2 HIGH হয় → এটি ইন্টারাপ্ট ইনপুটে দাও (8259A, লেসন mp4)।
উদাহরণ ৩: BCD ✍ CLK1 = 1 MHz, BCD-তে 1 kHz: N = 1000 → আগে 00H, পরে 10H লেখো (BCD অঙ্ক 1 0 0 0); CW = 01 11 011 1 = 77H।
উদাহরণ ৪: ক্যাসকেড ✍ 2 MHz থেকে 1 Hz পেতে N = 2,000,000 > 65,536, তাই একটি কাউন্টারে সম্ভব নয়। কাউন্টার 0, মোড 2, N = 2000 → 1 kHz; OUT0-কে CLK1-এ দাও; কাউন্টার 1, মোড 3, N = 1000 → 1 Hz। যাচাই: 2000 × 1000 = 2 × 10⁶ ✓
আইটি সংযোগ: IBM PC PC-র 8253/8254 থাকে 40H–43H পোর্টে, CLK = 1.193182 MHz। কাউন্টার 0, মোড 3, কাউন্ট 0 (65,536) → IRQ0-তে 18.2 Hz সিস্টেম টিক (প্রতি 54.9 ms); কাউন্টার 1, মোড 2, কাউন্ট 18 (CW 54H) → প্রতি 15.1 µs-এ DRAM রিফ্রেশ; কাউন্টার 2, মোড 3 (CW B6H) → স্পিকারের সুর (1 kHz-এ N ≈ 1193)।
পরীক্ষার ফাঁদ N হলো ফ্রিকোয়েন্সির অনুপাত; পর্যায়কাল উল্টো ভাগ কোরো না। কাউন্ট লিখতে হয় কাউন্টারের পোর্টে, আগে LSB; কখনো কন্ট্রোল পোর্টে নয়।

বড রেট বনাম বিট রেট বড (baud) = প্রতি সেকেন্ডে সিগন্যাল পরিবর্তন (সিম্বল); বিট রেট = বড × প্রতি সিম্বলে বিট। দুই-লেভেল সিগন্যালে (RS-232, UART) বড = bps।
সমাধানকৃত উদাহরণ ✍ ① 9600 বড, 8N1 (1 + 8 + 1 = 10 বিট) → 960 ক্যারেক্টার/সে.; বিট-সময় = 1 ÷ 9600 = 104.17 µs · ② 9600 বড, 8 ডেটা + প্যারিটি + 2 স্টপ = 12 বিট → 800 ক্যারেক্টার/সে. · ③ 16 লেভেলে (৪ বিট/সিম্বল) 2400 বডের মডেম → 2400 × 4 = 9600 bps · ④ 8N1-এর দক্ষতা = 8 ÷ 10 = ৮০%

  • সিমপ্লেক্স (Simplex): শুধু এক দিকে (রেডিও/টিভি সম্প্রচার, কীবোর্ড → CPU)
  • হাফ ডুপ্লেক্স: দুই দিকেই, তবে একবারে এক দিকে (ওয়াকি-টকি)
  • ফুল ডুপ্লেক্স: দুই দিকে একই সময়ে (টেলিফোন; TxD + RxD সহ RS-232)
মনে রাখার কৌশল ফ্রেম "শুরু নিচে, শেষ উপরে": স্টার্ট = 0, স্টপ = 1; তাই প্রতিটি ক্যারেক্টার নিশ্চিতভাবে একটি 1 → 0 প্রান্ত দিয়ে শুরু হয়।
