1Microprocessor & the Computer Around It

MCQ + Written
Definition A microprocessor (MPU) is a programmable, clock-driven, register-based IC that holds the whole CPU (ALU + control unit + registers) on one chip. It fetches instructions from memory, decodes and executes them; memory and I/O are outside the chip.
BusDirectionIts width decides
Addressunimemory size = 2ⁿ
Databiword length (bits)
ControlmixedRD, WR, M/IO

Instruction cycle = fetch → decode → execute. It has one or more machine cycles, each of several T-states (clock periods). n address lines → 2ⁿ bytes: 16 → 64 KB, 20 → 1 MB, 32 → 4 GB.

4Two Units: BIU and EU

written favourite
BIU (outside work)EU (inside work)
Fetches instruction bytes into the queueTakes opcodes from the queue, executes
Makes the 20-bit physical address (Σ)Computes the 16-bit offset (effective address)
Reads/writes memory & I/O operandsALU work, sets the flags
Holds CS, DS, SS, ES, IPHolds AX–DX, SP, BP, SI, DI, FLAGS
Memory trick BIU = the shopper (goes out on the bus, fills the queue), EU = the cook (never leaves the kitchen, uses what is in the queue).
Exam trap The EU makes the 16-bit offset; the 20-bit physical address is made in the BIU. IP belongs to the BIU, not the EU.

5Queue & Pipelining

While the EU executes, the BIU prefetches the next bytes: fetch and execute overlap (2-stage pipeline).

8086 refills at ≥ 2 free bytes; 8088 at ≥ 1.

On JMP / CALL / RET / INT the queue is flushed and refilled from the new CS:IP.

high-yield

General (data)AX accumulator (MUL, DIV, IN, OUT) · BX base (only general reg. usable as a pointer) · CX count (LOOP, REP, shift count in CL) · DX data (port address, high word of MUL/DIV). Each splits into 8-bit halves: AH/AL …

Default pairs: CS:IP · SS:SP · SS:BP · DS:BX · DS:SI · ES:DI (string destination).

7Flag Register: 9 of 16 Bits Used

very high-yield

PF2low byte has even no. of 1sTF8single-step after each instr.

Memory trick Status flags, bit 0 upward: "Can People Always Zip Safely? OK": CF 0, PF 2, AF 4, ZF 6, SF 7 … OF 11 (bits 0-2-4-6-7, then 11). Control = "T-I-D": TF 8, IF 9, DF 10.
Exam trap Only AX, BX, CX, DX split into 8-bit halves; SP, BP, SI, DI do not (no "SIL" on the 8086). There is no instruction that loads IP directly: JMP, CALL, RET and INT change it.

9Memory Segmentation

very high-yield
Why Registers are 16-bit (max 64 KB) but the address bus is 20-bit (1 MB). The 1 MB is viewed as segments of up to 64 KB, each starting on a 16-byte (paragraph) boundary. A logical address = segment : offset.
Formula PA = Segment × 10H + Offset
× 10H = shift left 4 bits = append one hex 0
  1. CS:IP = 1234:5678 → 12340 + 5678 = 179B8H
  2. CS:IP = 2000:0150 → 20000 + 0150 = 20150H
  3. DS = 3000H → spans 30000H – 3FFFFH
  4. PA 4A3B2H, DS 4000H → offset A3B2H
Many names, one byte ✍
1000:2345 → 10000 + 2345 = 12345H
1234:0005 → 12340 + 0005 = 12345H
1200:0345 → 12000 + 0345 = 12345H
Stack & byte order ✍
SS = 5000H, SP = 1000H, AX = 1234H
PUSH AX → SP = 0FFEH (SP − 2 first)
[50FFEH] = 34H, [50FFFH] = 12H
little-endian: low byte at the lower address
Memory trick "Add a zero, then add": write the segment with a 0 on its right, line up the offset under it, add in hex.
Exam trap FFFF:0010 → 100000H needs 21 bits; the 8086 wraps round to 00000H. The highest FFFF:FFFF = 10FFEFH → 0FFEFH.

Advantages: relocatable programs (change only the segment register), separate code/data/stack, 16-bit pointers within a segment. Limits: 64 KB per segment; 16 non-overlapping segments fill 1 MB.

10Memory Banks: BHE and A0

high-yield
BHEA0Transfer
00whole word (even address)
01odd byte only (D8–D15)
10even byte only (D0–D7)
11none (idle)

Each bank = 512 KB, addressed by A1–A19.

Exam trap A word at an odd address (e.g. 2001H) is unaligned: it needs 2 bus cycles (odd byte first, then the even byte at 2002H). An even-address word needs one. Keep word data on even addresses (EVEN directive).

Reset & timing After RESET: CS = FFFFH, IP = 0000H → first fetch at FFFF0H; DS = SS = ES = 0, flags cleared (IF = 0), queue empty. A bus cycle = 4 T-states (T1 address, T2–T4 data); at 5 MHz, T = 200 ns → 800 ns per cycle. Clock (8284A) and bus controller details: lesson mp2.

14Assembly Programs (MASM / TASM)

written favourite

P1: full program, add two words

.MODEL SMALL .STACK 100H .DATA N1 DW 9ABCH N2 DW 8765H SUM DW ? CY DB 0 .CODE START: MOV AX, @DATA ; DS cannot MOV DS, AX ; take an imm. MOV AX, N1 ADD AX, N2 ; 2221H, CF = 1 MOV SUM, AX ADC CY, 0 ; CY = 1 MOV AX, 4C00H ; exit to DOS INT 21H END START

sum = 12221H → SUM 2221H, CY 1

P2: largest of 5 bytes

LIST DB 25H,7AH,13H,0C4H,56H BIG DB ? LEA SI, LIST MOV CX, 4 ; 4 compares MOV AL, [SI] ; max = 25H NXT: INC SI CMP AL, [SI] JAE SKIP ; unsigned MOV AL, [SI] ; new max SKIP: LOOP NXT MOV BIG, AL ; C4H

AL: 25 → 7A → 7A → C4 → C4 (JGE: 7AH)

P3: count the 1s in a byte

MOV AL, 0B5H ; 1011 0101 MOV CX, 8 XOR BL, BL ; count = 0 AGN: SHL AL, 1 ; MSB → CF JNC ZRO INC BL ZRO: LOOP AGN ; BL = 5
P4: block copy ✍ CLD · LEA SI,SRC · LEA DI,DST · MOV CX,10 · REP MOVSB → 10 bytes copied, CX = 0.

20 address lines → 2²⁰ = 1 MB

Queue: 8086 = 6 B · 8088 = 4 B

BIU: CS DS SS ES IP, Σ, queue

EU: AX–DX, SP BP SI DI, ALU, flags

BP, SP → SS · BX, SI, DI → DS

strings: DS:SI → ES:DI, CX, DF

BHE A0 = 00 word · 01 odd · 10 even

MN/MX = 1 min · 0 max (8288)

Reset → CS:IP = FFFF:0000 = FFFF0H

bus cycle = 4 T-states

MUL BL → AX · MUL BX → DX:AX

DB 1 · DW 2 · DD 4 · DQ 8 · DT 10

Top 12 one-liners for MCQs

  1. First MPU: Intel 4004 (1971), 4-bit
  2. 8085: 8-bit, 64 KB, single +5 V
  3. 8088 has an 8-bit external data bus
  4. Physical address is computed in the BIU
  5. Fetch/execute overlap = pipelining
  6. Queue is flushed on a jump or call
  1. IP cannot be loaded by MOV
  2. PF = 1 for even 1s in the low byte
  3. DF = 1 → strings auto-decrement
  4. TF = 1 → single-step mode
  5. Odd-address word = 2 bus cycles
  6. Directives produce no machine code
Top traps Pentium is 32-bit · CF = unsigned, OF = signed · INC/DEC leave CF alone · [BP…] uses SS, not DS · no [CX], [DX], [BX+BP], [SI+DI] · no PUSH AL, no MOV DS, imm, no memory-to-memory MOV · FFFF:0010 wraps to 00000H · JA/JB unsigned, JG/JL signed
All tricks together "Add a zero, then add" for PA · "C-P-A-Z-S … O" on bits 0-2-4-6-7-11, then "T-I-D" for control flags · "BP lives on the Stack" · Above/Below = unsigned, Greater/Less = signed · stack grows down, PUSH = SP − 2 first · BIU shops, EU cooks

Written question Write an 8086 program that adds ten unsigned bytes stored from offset 0200H of the data segment and stores the 16-bit sum at offset 0300H (DS already set). Explain the addressing modes used. 8 marks
MOV SI, 0200H ; pointer MOV CX, 10 ; counter XOR AX, AX ; sum = 0 NXT: ADD AL, [SI] ; add byte ADC AH, 0 ; keep carry INC SI LOOP NXT MOV [0300H], AX HLT
  1. Set-up: SI pointer, CX count, AX = 0 2
  2. Loop: ADD AL,[SI] (register indirect) + ADC AH,0 turns 8-bit adds into a 16-bit sum 3
  3. INC SI, LOOP (CX − 1, repeat while ≠ 0) 1
  4. MOV [0300H],AX: direct mode; low byte at 0300H, high at 0301H 2
