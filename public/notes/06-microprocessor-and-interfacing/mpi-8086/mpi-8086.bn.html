৯মেমরি সেগমেন্টেশন (Segmentation)

খুব হাই-ইল্ড
কেন রেজিস্টার 16-বিট (সর্বোচ্চ 64 KB) কিন্তু অ্যাড্রেস বাস 20-বিট (1 MB)। তাই 1 MB-কে দেখা হয় সর্বোচ্চ 64 KB-র সেগমেন্ট হিসেবে, প্রতিটি শুরু হয় 16-বাইটের (প্যারাগ্রাফ) সীমানায়। লজিক্যাল অ্যাড্রেস = সেগমেন্ট : অফসেট।
সূত্র PA = Segment × 10H + Offset
× 10H = ৪ বিট বাঁয়ে শিফট = ডানে একটি হেক্স 0 বসানো
  1. CS:IP = 1234:5678 → 12340 + 5678 = 179B8H
  2. CS:IP = 2000:0150 → 20000 + 0150 = 20150H
  3. DS = 3000H → বিস্তার 30000H – 3FFFFH
  4. PA 4A3B2H, DS 4000H → অফসেট A3B2H
অনেক নাম, একই বাইট ✍
1000:2345 → 10000 + 2345 = 12345H
1234:0005 → 12340 + 0005 = 12345H
1200:0345 → 12000 + 0345 = 12345H
স্ট্যাক ও বাইট ক্রম ✍
SS = 5000H, SP = 1000H, AX = 1234H
PUSH AX → SP = 0FFEH (আগে SP − 2)
[50FFEH] = 34H, [50FFFH] = 12H
লিটল-এন্ডিয়ান: নিচের বাইট নিচের ঠিকানায়
মনে রাখার কৌশল "একটা শূন্য বসাও, তারপর যোগ করো": সেগমেন্টের ডানে 0 লেখো, নিচে অফসেট সাজাও, হেক্সে যোগ করো।
পরীক্ষার ফাঁদ FFFF:0010 → 100000H-এ ২১ বিট লাগে; 8086 ঘুরে 00000H-এ যায়। সর্বোচ্চ FFFF:FFFF = 10FFEFH → 0FFEFH।

সুবিধা: স্থানান্তরযোগ্য প্রোগ্রাম (relocatable; শুধু সেগমেন্ট রেজিস্টার বদলালেই হয়), কোড/ডেটা/স্ট্যাক আলাদা, সেগমেন্টের ভেতরে 16-বিট পয়েন্টার। সীমা: প্রতি সেগমেন্ট 64 KB; ওভারল্যাপহীন ১৬টি সেগমেন্টে 1 MB পূর্ণ।
