# বীজগাণিতিক সরলীকরণ, লোয়ার বাউন্ড ও এনপি-সম্পূর্ণতা — রিভিশন নোট

**সরকারি আইটি নিয়োগ পরীক্ষা: রিভিশন নোটবুক** · এগারো পাতায় পরীক্ষার জন্য প্রস্তুত
হর্নার · দ্রুত ঘাত · কারাতসুবা · স্ট্রাসেন · FFT · ডিসিশন ট্রি · অ্যাডভার্সারি · P, NP, NP-হার্ড, NP-কমপ্লিট

একটি বীজগাণিতিক সমস্যাকে নতুন করে লিখলে কীভাবে তা সস্তা হয়, বুলিয়ান সূত্রের সংক্ষিপ্ত রিক্যাপ,
**লোয়ার বাউন্ড** আসলে কী ও তা প্রমাণের তিনটি পথ, প্রমাণিত বাউন্ডের সারণি, তারপর জটিলতা শ্রেণি,
রিডাকশন এবং কোনো সমস্যা NP-কমপ্লিট হলে কী করণীয়।

এখানে আছে। অ্যালগরিদমের সিলেবাসে "বীজগাণিতিক সরলীকরণ" মানে **বীজগাণিতিক অ্যালগরিদম** — বহুপদী, ঘাত ও
গুণফলকে এমনভাবে লেখা যাতে কম অপারেশন লাগে — তাই এটিই মূল ধারা; বুলিয়ান সরলীকরণের জন্য এক পাতার
রিক্যাপ, কারণ কে-ম্যাপ ডিজিটাল লজিক অধ্যায়ের বিষয়। **অ্যাপ্রক্সিমেশন অ্যালগরিদম** এই অধ্যায়ের ফ্লো /
অ্যাপ্রক্সিমেশন / প্যারালাল লেসনে।

## ১. ট্রান্সফর্ম-অ্যান্ড-কনকার ও হর্নারের নিয়ম  *(পৃ. ২)*

### সংজ্ঞা

**বীজগাণিতিক সরলীকরণ / রূপান্তর (Algebraic Simplification / Transformation)** মানে **একটি সমস্যা বা তার
সূত্রকে এমন সমতুল্য রূপে লেখা যা হিসাব করতে সস্তা**: উত্তর একই, অপারেশন কম। এই কৌশলের নাম
**ট্রান্সফর্ম-অ্যান্ড-কনকার (Transform-and-Conquer)**; এর তিনটি রূপ।

| রূপ | ধারণা | ক্লাসিক উদাহরণ |
|---|---|---|
| **ইনস্ট্যান্স সরলীকরণ** | **একই** সমস্যার সহজতর ইনস্ট্যান্স | **প্রিসর্টিং**: element uniqueness O(n²) → সর্ট + স্ক্যান O(n log n); গাউসীয় অপনয়ন |
| **রিপ্রেজেন্টেশন পরিবর্তন** | একই ইনস্ট্যান্স, **নতুন রূপ** | **হর্নারের রূপ**; বাইনারি এক্সপোনেনশিয়েশন; পয়েন্ট-ভ্যালু রূপ; হিপ, AVL ট্রি |
| **প্রবলেম রিডাকশন** | জানা অ্যালগরিদমসহ **ভিন্ন** সমস্যা | `lcm(m,n) = m·n / gcd(m,n)`; `max f = −min(−f)`; k-ধাপের পথ = `A^k` |

### হর্নারের নিয়ম (Horner's Rule)

বারবার x বের করে আনো:

`p(x) = aₙxⁿ + … + a₁x + a₀ = (…((aₙx + aₙ₋₁)x + aₙ₋₂)x + … )x + a₀`

মুখ্য সহগ থেকে একবার চললেই: n ঘাতের জন্য **n গুণ + n যোগ**, কোনো ঘাত আলাদা করে হিসাব করতে হয় না।

**হর্নার = সিনথেটিক ডিভিশন।** p(x) = 2x³ − 6x² + 2x − 1, x = 3 বসিয়ে:

| | 2 | −6 | 2 | −1 |
|---|---|---|---|---|
| গুণফল (× 3) | | 6 | 0 | 6 |
| চলমান মান | 2 | 0 | 2 | **5** |

অতএব **p(3) = 5** (যাচাই: 54 − 54 + 6 − 1 = 5) এবং ভাগফল q(x) = 2x² + 0x + 2 — ঘাত ৩ হলে ৩টি গুণ ও
৩টি যোগ।

```
HORNER(a[0..n], x):
  p = a[n]
  for i = n − 1 downto 0:
      p = p · x + a[i]     // 1 mult, 1 add
  return p                 // Θ(n)
```

| পদ্ধতি (ঘাত n) | গুণ | যোগ |
|---|---|---|
| প্রতিটি পদ aᵢxⁱ আলাদা করে | n(n+1)/2 | n |
| চলমান ঘাত xⁱ রেখে | 2n − 1 | n |
| **হর্নার** | **n** | n |

> **পরীক্ষার ফাঁদ (তিনটি)।** ১. ঘাত n হলে সহগ **n + 1**টি, কিন্তু হর্নারে গুণ **n**টি — n + 1 বা 2n নয়।
> ২. হর্নার **অপটিমাল** প্রমাণিত: কোনো সাধারণ পদ্ধতি n-এর কম গুণে পারে না। ৩. শেষ মানটি **p(x₀)**
> (ভাগশেষ উপপাদ্য); বাকিগুলো ভাগফলের সহগ।

**ইভ্যালুয়েশন ↔ ইন্টারপোলেশন।** n ঘাতের একটি বহুপদী নির্দিষ্ট হয় তার **n + 1টি সহগ** দিয়ে, অথবা
**n + 1টি ভিন্ন বিন্দুতে** তার মান দিয়ে। n + 1 বিন্দুতে হর্নার দিয়ে **ইভ্যালুয়েশন**: O(n²)।
**ইন্টারপোলেশন** (লাগ্রাঞ্জ / নিউটন): **O(n²)**। পয়েন্ট-ভ্যালু রূপে গুণ **O(n)** — এটাই FFT-র ধারণা।

> **মনে রাখার কৌশল।** "**হর্নার = বন্ধনীর ভেতরে বন্ধনী = n আর n।**" বাইনারি 1101 →
> `((1·2 + 1)·2 + 0)·2 + 1 = 13` — এটি x = 2 বসানো হর্নার।

## ২. দ্রুত ঘাত, কারাতসুবা, স্ট্রাসেন ও FFT  *(পৃ. ৩)*

### দ্রুত (বাইনারি) এক্সপোনেনশিয়েশন

`xⁿ = (x^(n/2))²` (n জোড়) বা `x·(x^((n−1)/2))²` (n বিজোড়): প্রতি বিটে একটি বর্গ, সর্বোচ্চ
**2⌊log₂ n⌋টি গুণ**, n − 1টি নয় ⇒ **O(log n)**। x¹³ (13 = 1101₂): x → x² → x³ → x⁶ → x¹² → x¹³ =
**৫**টি গুণ, ১২টি নয়।

**উদাহরণ: মডুলার ঘাত।** 3¹³ mod 7: 3¹ = 3, 3² = 9 ≡ 2, 3⁴ ≡ 4, 3⁸ ≡ 16 ≡ 2। 13 = 8 + 4 + 1 ⇒
3¹³ ≡ 2·4·3 = 24 ≡ **3** (mod 7)। প্রতি ধাপে mod নিলে সংখ্যা ছোট থাকে — **RSA** ও ডিফি–হেলম্যান এভাবেই
বিশাল ঘাত হিসাব করে।

### কারাতসুবা গুণন (১৯৬০)

দুটি n-অঙ্কের সংখ্যা ভাঙো: `x = a·10^m + b`, `y = c·10^m + d`। সাধারণ পদ্ধতিতে চারটি গুণফল ac, ad, bc,
bd লাগে। বীজগাণিতিক কৌশল **`ad + bc = (a + b)(c + d) − ac − bd`** দিয়ে **তিনটিই** যথেষ্ট।
`T(n) = 3T(n/2) + O(n)` ⇒ **Θ(n^log₂3) ≈ Θ(n^1.585)**: রিকার্শন ট্রির k গভীরতায় 3ᵏটি কল, তাই
n^log₂3টি লিফই প্রধান।

**সমাধানকৃত উদাহরণ: 1234 × 5678।** a = 12, b = 34, c = 56, d = 78 (m = 2)। ac = 672, bd = 2652,
(a + b)(c + d) = 46 × 134 = 6164 ⇒ ad + bc = 6164 − 672 − 2652 = 2840।
ফল = 672·10⁴ + 2840·10² + 2652 = **7,006,652** ✓ — তিনটি গুণফলেই।

### স্ট্রাসেন (১৯৬৯)

n × n ম্যাট্রিক্সকে চারটি n/2 ব্লকে ভাঙো। সাধারণ ব্লক-গুণে ৮টি গুণফল; স্ট্রাসেনের অভেদে **৭টি গুণফল**
(সঙ্গে ১৮টি ব্লক-যোগ)। `T(n) = 7T(n/2) + Θ(n²)` ⇒ **Θ(n^log₂7) ≈ Θ(n^2.81)**, Θ(n³)-এর বদলে। কেবল
বড় n-এ লাভ; সংখ্যাগতভাবে কম স্থিতিশীল।

### FFT দিয়ে বহুপদী গুণ

সহগ রূপে: **Θ(n²)**। বদলে উভয়কে 2nটি জটিল একক-মূলে **ইভ্যালুয়েট** করো (FFT), **বিন্দুভিত্তিক গুণ**
(O(n)), তারপর **ইন্টারপোলেট** (ইনভার্স FFT) ⇒ **O(n log n)**। FFT: `T(n) = 2T(n/2) + O(n)`
(কুলি–টুকি, ১৯৬৫)।

| সমস্যা | প্রচলিত | পদ্ধতি | রিকারেন্স | ফল |
|---|---|---|---|---|
| n ঘাতের বহুপদী মান | Θ(n²) | হর্নার | একটি লুপ | Θ(n) |
| ঘাত xⁿ | n − 1 | বর্গ করে | T(n/2) + O(1) | O(log n) |
| n-অঙ্ক × n-অঙ্ক | Θ(n²) | কারাতসুবা | 3T(n/2) + O(n) | **Θ(n^1.585)** |
| n × n ম্যাট্রিক্স | Θ(n³) | স্ট্রাসেন | 7T(n/2) + O(n²) | Θ(n^2.81) |
| বহুপদী × বহুপদী | Θ(n²) | FFT | 2T(n/2) + O(n) | Θ(n log n) |

> **পরীক্ষার ফাঁদ।** স্ট্রাসেনের ঘাতাঙ্ক **log₂ 7 ≈ 2.807**, 2.376 নয় (ওটি অব্যবহারিক
> কপারস্মিথ–উইনোগ্রাড ধারার)। অর্ধ-আকারের ৪টি ও ৮টি গুণফলে ঘাতাঙ্ক ২ ও ৩-ই থাকে — সাশ্রয় হলো বাদ দেওয়া
> **একটি** গুণফল। ম্যাট্রিক্স গুণের তুচ্ছ লোয়ার বাউন্ড **Ω(n²)**।

> **মনে রাখার কৌশল।** "**একটি গুণ বাঁচাও, ঘাতাঙ্ক নামাও।**" a-টি অর্ধ-আকারের উপসমস্যা ও সস্তা জোড়া
> লাগানো ⇒ **n^log₂ a** (মাস্টার থিওরেম): ৪ → ৩ দেয় log₂ 3 ≈ 1.585; ৮ → ৭ দেয় log₂ 7 ≈ 2.807।

## ৩. বুলিয়ান সরলীকরণ: সংক্ষিপ্ত রিক্যাপ  *(পৃ. ৪)*

*পূর্ণ কে-ম্যাপ: ডিজিটাল লজিক অধ্যায়।*

| সূত্র | OR রূপ | AND রূপ (ডুয়াল) |
|---|---|---|
| আইডেনটিটি | A + 0 = A | A · 1 = A |
| নাল (ডমিন্যান্স) | A + 1 = 1 | A · 0 = 0 |
| আইডেম্পোটেন্ট | A + A = A | A · A = A |
| কমপ্লিমেন্ট | A + A′ = 1 | A · A′ = 0 |
| ডিস্ট্রিবিউটিভ | A(B + C) = AB + AC | **A + BC = (A + B)(A + C)** |
| অ্যাবজর্পশন | A + AB = A | A(A + B) = A |
| ডি মরগান | (A + B)′ = A′B′ | (AB)′ = A′ + B′ |
| কনসেনসাস | AB + A′C + BC = AB + A′C | (A+B)(A′+C)(B+C) = (A+B)(A′+C) |

**উদাহরণ: দুটি ক্লাসিক।**

- **F = AB + AB′** = A(B + B′) [ডিস্ট্রিবিউটিভ] = A·1 [কমপ্লিমেন্ট] = **A** [আইডেনটিটি]।
- **G = A + A′B** = (A + A′)(A + B) [OR-ডিস্ট্রিবিউটিভ] = 1·(A + B) = **A + B**।
- কনসেনসাস প্রমাণ: BC = BC(A + A′) = ABC + A′BC, যা AB ও A′C-তে শোষিত।

**আইটি সংযোগ: কম্পাইলার।** অপটিমাইজিং কম্পাইলার কোডে **বীজগাণিতিক সরলীকরণ** করে: `x*1 → x`,
`x+0 → x`, কনস্ট্যান্ট ফোল্ডিং `2*3.14 → 6.28`, আর **স্ট্রেংথ রিডাকশন** `x*2 → x<<1`, `pow(x,2)`-এর বদলে
`x*x`। মিনটার্ম, কে-ম্যাপ, কুইন–ম্যাকক্লাস্কি: ডিজিটাল লজিক অধ্যায়।

> **পরীক্ষার ফাঁদ।** **A + 1 = 1**, A নয়। **A + BC = (A + B)(A + C)** বুলিয়ান বীজগণিতে সত্য, সাধারণ
> বীজগণিতে নয়। **ডুয়ালিটি:** + ↔ · এবং 0 ↔ 1 বদলাও (চলক অপরিবর্তিত), সূত্র সত্যই থাকে।

## ৪. অ্যাসিম্পটোটিক বাউন্ড: O, Ω, Θ সঠিকভাবে  *(পৃ. ৪)*

- **f = O(g):** ∃ c > 0, n₀ যাতে সব n ≥ n₀-এ `f(n) ≤ c·g(n)` (আপার বাউন্ড)।
- **f = Ω(g):** ∃ c > 0, n₀ যাতে সব n ≥ n₀-এ `f(n) ≥ c·g(n)` (**লোয়ার বাউন্ড**)।
- **f = Θ(g):** দুটোই — `c₁g(n) ≤ f(n) ≤ c₂g(n)` (টাইট)। কঠোর রূপ: o ও ω।

ছবি: n₀-এর পরে f(n) থাকে c₁·g(n) ও c₂·g(n)-এর মাঝে।

> **প্রচলিত ভুল ধারণা।** "Ω মানে বেস্ট কেস, O মানে ওয়ার্স্ট কেস" — **ভুল**। O, Ω ও Θ **ফাংশনের** সীমা;
> বেস্ট, অ্যাভারেজ ও ওয়ার্স্ট কেস তিনটি আলাদা ফাংশন, এবং প্রতিটিরই O, Ω বা Θ দেওয়া যায়। ইনসার্শন সর্ট:
> ওয়ার্স্ট কেস **Θ(n²)** (তাই Ω(n²)-ও), বেস্ট কেস **Θ(n)**। **একটি সমস্যার লোয়ার বাউন্ড** হলো **প্রতিটি
> অ্যালগরিদমের ওয়ার্স্ট কেসের** উপর একটি Ω।

## ৫. লোয়ার বাউন্ড তত্ত্ব ও ডিসিশন-ট্রি যুক্তি  *(পৃ. ৫)*

### সংজ্ঞা

একটি সমস্যার **লোয়ার বাউন্ড (Lower Bound)** L(n) হলো এমন খরচ যা একটি নির্দিষ্ট মডেলে (যেমন "শুধু তুলনা")
**প্রতিটি অ্যালগরিদমকে ওয়ার্স্ট কেসে দিতেই হবে**। এটি **সমস্যার** সম্পর্কে বক্তব্য, কোনো একটি
অ্যালগরিদমের নয়। **আপার বাউন্ড** হলো জানা সেরা অ্যালগরিদমের খরচ। দুটি মিললে সেই অ্যালগরিদম
**অপটিমাল** (মার্জ সর্ট, হিপসর্ট: Θ(n log n) তুলনা)। ফাঁক থাকলে তা খোলা প্রশ্ন: ম্যাট্রিক্স গুণে Ω(n²)
বনাম O(n^2.37…)।

| কৌশল | ধারণা | ক্লাসিক ফল |
|---|---|---|
| **তুচ্ছ (I/O আকার)** | প্রতিটি ইনপুট পড়া, প্রতিটি আউটপুট লেখা | ম্যাট্রিক্স গুণ Ω(n²); সব পারমুটেশন Ω(n!) |
| **ডিসিশন ট্রি** | kটি সম্ভাব্য উত্তরে ≥ ⌈log₂ k⌉টি হ্যাঁ/না পরীক্ষা | সর্টিং **Ω(n log n)**; সার্চ ⌈log₂(n+1)⌉ |
| **অ্যাডভার্সারি** | প্রতিটি প্রশ্নের এমন উত্তর যাতে কাজ সর্বাধিক | ম্যাক্স n − 1; ম্যাক্স + মিন ⌈3n/2⌉ − 2 |
| **প্রবলেম রিডাকশন** | কঠিন P সস্তায় Q-তে রূপান্তরিত ⇒ Q-ও কঠিন | সর্টিং ≤ কনভেক্স হাল ⇒ Ω(n log n) |

### a, b, c সাজানোর একটি সঠিক ডিসিশন ট্রি

প্রতিটি অভ্যন্তরীণ নোড একটি তুলনা, প্রতিটি লিফ একটি ক্রম।

```
                        a:b
              a<b /             \ a>b
               b:c               a:c
         b<c /    \ b>c     a<c /    \ a>c
     a<b<c        a:c     b<a<c       b:c
            a<c /    \ a>c       b<c /    \ b>c
          a<c<b      c<a<b     b<c<a      c<b<a
```

৬টি লিফ = 3! · ওয়ার্স্ট কেস = 3 = ⌈log₂ 6⌉টি তুলনা · বেস্ট পথ = ২টি তুলনা।

### প্রমাণ (৪ নম্বর)

n-টি ভিন্ন কি-র যেকোনো তুলনাভিত্তিক সর্ট একটি **বাইনারি ডিসিশন ট্রি**। **n!**টি ক্রমের প্রতিটির জন্য
আলাদা লিফ চাই ⇒ ≥ n! লিফ। h উচ্চতার বাইনারি ট্রিতে ≤ 2ʰ লিফ ⇒ `2ʰ ≥ n!` ⇒ **h ≥ log₂(n!)**। যেহেতু
`n! ≥ (n/2)^(n/2)`, `log₂ n! ≥ (n/2)·log₂(n/2) = Ω(n log n)`। (স্টার্লিং: log₂ n! ≈ n log₂ n − 1.44n।)

| n | n! | ⌈log₂ n!⌉ = ন্যূনতম ওয়ার্স্ট-কেস তুলনা |
|---|---|---|
| 3 | 6 | **3** |
| 4 | 24 | 5 |
| 5 | 120 | 7 (মার্জ-ইনসার্শনে অর্জিত) |
| 10 | 3,628,800 | 22 |

> **পরীক্ষার ফাঁদ।** এই বাউন্ড কেবল **তুলনাভিত্তিক** সর্টের জন্য। **কাউন্টিং সর্ট O(n + k)**, **র‍্যাডিক্স
> সর্ট O(d(n + k))** ও বাকেট সর্ট (গড়ে O(n)) কি-র মানকে অ্যারে ইনডেক্স হিসেবে ব্যবহার করে, তাই এই সীমায়
> বাঁধা নয়। বাউন্ডটি **অ্যাভারেজ** কেসেও খাটে: লিফের গড় গভীরতা ≥ log₂ n!।

## ৬. অ্যাডভার্সারি যুক্তি ও প্রমাণিত লোয়ার বাউন্ড  *(পৃ. ৬)*

### অ্যাডভার্সারি যুক্তি (Adversary Argument)

ধরো অ্যালগরিদম প্রশ্ন করছে ("aᵢ < aⱼ?") আর এক দুষ্ট **প্রতিপক্ষ** উত্তর দিচ্ছে — সবসময় কোনো না কোনো
ইনপুটের সঙ্গে **সামঞ্জস্যপূর্ণ**, কিন্তু এমন উত্তর যা সবচেয়ে কম তথ্য দেয়। প্রতিপক্ষ k − 1টি প্রশ্ন পর্যন্ত
দুটি ভিন্ন উত্তর সম্ভব রাখতে পারলে প্রতিটি অ্যালগরিদমের **k**টি প্রশ্ন লাগবে। **nটির ম্যাক্স:** **ম্যাক্স ছাড়া
বাকি n − 1টি উপাদানকে অন্তত একবার হারতে হবে**, আর একটি তুলনায় মাত্র একজন হারে ⇒ **n − 1**, যা লিনিয়ার
স্ক্যানে অর্জিত।

### ম্যাক্স ও মিন একসঙ্গে: জোড়া পদ্ধতি

আলাদাভাবে করলে `(n − 1) + (n − 1) = 2n − 2`। ভালো উপায়: **উপাদানগুলোকে জোড়ায় জোড়ায় তুলনা করো**
(n/2টি তুলনা); ম্যাক্স থাকবে **বিজয়ীদের** মধ্যে (আরও n/2 − 1), মিন **পরাজিতদের** মধ্যে (আরও n/2 − 1)।
জোড় n-এ মোট `3n/2 − 2`; বিজোড় n-এ প্রথমটিকে ম্যাক্স = মিন ধরে বাকিগুলো জোড়ায় ⇒ সাধারণভাবে
**⌈3n/2⌉ − 2**, এবং অ্যাডভার্সারি যুক্তি প্রমাণ করে এর চেয়ে কম সম্ভব নয়।

৮টি সংখ্যায় জোড়া পদ্ধতি [3, 9, 2, 7, 5, 1, 8, 4]:

- ৪টি জোড়া: (3, 9) (2, 7) (5, 1) (8, 4)
- বিজয়ী 9 · 7 · 5 · 8 → ম্যাক্স = 9, ৩টি তুলনায়
- পরাজিত 3 · 2 · 1 · 4 → মিন = 1, ৩টি তুলনায়
- 4 + 3 + 3 = 10 = 3·8/2 − 2 (আলাদাভাবে: 7 + 7 = 14)

| সমস্যা (তুলনা, nটি উপাদান) | লোয়ার বাউন্ড | অপটিমাল অ্যালগরিদম |
|---|---|---|
| ম্যাক্সিমাম (বা মিনিমাম) | n − 1 | লিনিয়ার স্ক্যান |
| **ম্যাক্সিমাম ও মিনিমাম** | **⌈3n/2⌉ − 2** | জোড়া পদ্ধতি |
| দ্বিতীয় বৃহত্তম | **n + ⌈log₂ n⌉ − 2** | টুর্নামেন্ট + ম্যাক্সের প্রতিপক্ষরা |
| সাজানো অ্যারেতে সার্চ | ⌈log₂(n + 1)⌉ | বাইনারি সার্চ |
| অসাজানো অ্যারেতে সার্চ | n | লিনিয়ার সার্চ |
| nটি করে দুটি সাজানো লিস্ট মার্জ | 2n − 1 | সাধারণ মার্জ |
| তুলনাভিত্তিক সর্টিং | ⌈log₂ n!⌉ | মার্জ সর্ট, হিপসর্ট |
| এলিমেন্ট ইউনিকনেস | Ω(n log n) | সর্ট, তারপর স্ক্যান |
| কানেক্টিভিটি (অ্যাডজেসেন্সি লিস্ট) | Ω(V + E) | BFS / DFS |

**উদাহরণ: n = 100।** ম্যাক্স + মিন: `⌈300/2⌉ − 2 = 148` (৫০ জোড়া + ৪৯ + ৪৯), ১৯৮ নয়। দ্বিতীয়
বৃহত্তম: `100 + ⌈log₂ 100⌉ − 2 = 100 + 7 − 2 = 105`। n = 8 হলে: **৭**টি খেলায় চ্যাম্পিয়ন, যে **৩** জনকে
হারিয়েছে; তাদের সেরাকে পেতে আরও **২**টি ⇒ 9 = 8 + 3 − 2।

> **পরীক্ষার ফাঁদ।** ম্যাক্স + মিনের **2n − 2** (বা 2n − 3) সাধারণ গণনা, বাউন্ড নয়। **⌈3n/2⌉ − 2**
> (ম্যাক্স + মিন) আর **n + ⌈log₂ n⌉ − 2** (দ্বিতীয় বৃহত্তম) গুলিয়ে ফেলো না। "ওয়ার্স্ট কেসে ন্যূনতম তুলনা"
> মানে **লোয়ার বাউন্ড**, ভাগ্যক্রমে পাওয়া বেস্ট কেস নয়।

## ৭. P, NP, co-NP, NP-হার্ড ও NP-কমপ্লিট  *(পৃ. ৭)*

| শ্রেণি | সংজ্ঞা (হ্যাঁ/না ডিসিশন সমস্যা) | উদাহরণ |
|---|---|---|
| **P** | ডিটারমিনিস্টিকভাবে **বহুপদী সময়ে O(nᵏ)** সমাধানযোগ্য | সর্টিং, MST, শর্টেস্ট পাথ, 2-SAT, LP, প্রাইমালিটি |
| **NP** | "হ্যাঁ" উত্তরের একটি **সার্টিফিকেট** আছে যা **বহুপদী সময়ে যাচাইযোগ্য** (= ননডিটারমিনিস্টিক বহুপদী সময়) | P-এর সব; SAT, হ্যামিল্টনিয়ান সাইকেল, সাবসেট সাম, ফ্যাক্টরিং |
| **co-NP** | পরিপূরক: "না" উত্তরের ছোট সার্টিফিকেট আছে | TAUTOLOGY, UNSAT |
| **NP-হার্ড** | **প্রতিটি** NP সমস্যা ≤p এটি; NP-তে বা এমনকি ডিসাইডেবল হওয়াও জরুরি নয় | হল্টিং সমস্যা, TSP-অপটিমাইজেশন |
| **NP-কমপ্লিট** | **NP-তে এবং NP-হার্ড** — NP-র কঠিনতম | SAT, 3-SAT, ক্লিক, ভার্টেক্স কভার, TSP-ডিসিশন |

### সঠিক ছবি

- **যদি P ≠ NP (প্রচলিত বিশ্বাস):** P থাকে NP-র ভেতরে (সর্টিং, MST)। NP-হার্ড একটি আলাদা অঞ্চল যা NP-র
  কিনারা ছুঁয়ে আংশিক মিলে যায়; সেই ছেদই **NP-কমপ্লিট**। হল্টিং ও TSP-অপটিমাইজেশন NP-হার্ড, কিন্তু NP-র
  বাইরে।
- **যদি P = NP:** P = NP = NP-কমপ্লিট একটি অঞ্চল, NP-হার্ড অঞ্চলের ভেতরে; NP-হার্ড তখনও তার বাইরে ছড়িয়ে
  থাকে (হল্টিং)।

NP-কমপ্লিট হলো NP ও NP-হার্ডের ছেদ; দুই অবস্থাতেই NP-হার্ড NP-র বাইরে ছড়িয়ে থাকে।

> **প্রচলিত ভুল ধারণা।** **P ⊂ NP ⊂ NP-কমপ্লিট ⊂ NP-হার্ড** — এমন স্তরে স্তরে আঁকা ছবি ভুল। NP-কমপ্লিট
> NP-র **সুপারসেট নয়**: এটি NP-র সেই অংশ যা NP-হার্ডও, আর NP-হার্ড NP-র **বাইরে** ছড়িয়ে আছে। **P ⊆ NP**
> প্রমাণিত (সমাধানকারী নিজেই যাচাইকারী); **P = NP** কিনা তা খোলা প্রশ্ন।

**ডিসিশন বনাম অপটিমাইজেশন।** **TSP-ডিসিশন**: "খরচ ≤ k এমন ট্যুর আছে কি?" — NP-তে, NP-কমপ্লিট।
**TSP-অপটিমাইজেশন**: "সবচেয়ে সস্তা ট্যুর বের করো" — NP-হার্ড, NP-তে নয় (হ্যাঁ/না সমস্যা নয়)। ন্যাপস্যাক,
ক্লিক, ভার্টেক্স কভারেও একই। অপটিমাইজেশন রূপ সমাধান করলে ডিসিশন রূপও হয়, তাই তা অন্তত সমান কঠিন।

**সার্টিফিকেট দেখতে কেমন।** **SAT:** একটি ট্রুথ অ্যাসাইনমেন্ট — বসিয়ে দেখো, O(সূত্রের দৈর্ঘ্য)।
**হ্যামিল্টনিয়ান সাইকেল:** nটি ভার্টেক্সের একটি ক্রম — nটি এজ আছে কিনা ও কেউ পুনরাবৃত্ত নয় কিনা দেখো।
**সাবসেট সাম:** উপসেটটি — যোগ করে দেখো। খুঁজে পাওয়া কঠিন; **যাচাই** সহজ।

> **মনে রাখার কৌশল।** "**P: দ্রুত সমাধান। NP: দ্রুত যাচাই। NP-হার্ড: পুরো NP-র সমান কঠিন বা বেশি।
> NP-কমপ্লিট: কঠিন *এবং* যাচাইযোগ্য।**" আর **NP = Nondeterministic Polynomial**, কখনো "Non-Polynomial"
> নয় — প্রতিটি P সমস্যাই NP-তে।

**বিখ্যাত সমস্যাগুলো কোথায়।** **P ⊆ NP ∩ co-NP।** **প্রাইমালিটি** P-তে (AKS, ২০০২) — পরীক্ষা সহজ, অথচ
**ফ্যাক্টরিং** NP ∩ co-NP-তে, কিন্তু P-তে বা NP-কমপ্লিট বলে জানা নেই। **গ্রাফ আইসোমরফিজম**: NP-তে,
NP-কমপ্লিট বলে জানা নেই (কোয়াসি-পলিনোমিয়াল, ২০১৫)। P ≠ NP হলে ল্যাডনারের উপপাদ্য বলে এমন মাঝামাঝি
সমস্যা থাকতেই হবে।

## ৮. রিডাকশন ও কুক–লেভিন উপপাদ্য  *(পৃ. ৮)*

**রিডাকশন A ≤p B।** বহুপদী সময়ে নির্ণেয় একটি ফাংশন f, যাতে প্রতিটি ইনস্ট্যান্স x-এর জন্য
**`x ∈ A ⇔ f(x) ∈ B`**। পড়ো "**A, B-র চেয়ে কঠিন নয়**": B-র দ্রুত অ্যালগরিদম A-র জন্যও দ্রুত অ্যালগরিদম
দেয়। দুটি ফল: **B ∈ P ⇒ A ∈ P**, এবং **A NP-হার্ড ⇒ B NP-হার্ড**। রিডাকশন ট্রানজিটিভ: A ≤p B ও
B ≤p C ⇒ A ≤p C।

**কুক–লেভিন উপপাদ্য (Cook–Levin Theorem)।** **SAT NP-কমপ্লিট** — স্টিফেন **কুক (১৯৭১)**, লিওনিড
**লেভিন** স্বাধীনভাবে (১৯৭৩)। এটিই **প্রথম** সমস্যা যা সরাসরি সংজ্ঞা থেকে NP-কমপ্লিট প্রমাণিত: যেকোনো
বহুপদী-সময়ের ননডিটারমিনিস্টিক মেশিনের চলনকে একটি বুলিয়ান সূত্রে লেখা যায়। এরপর **কার্প (১৯৭২)** SAT
থেকে **২১**টি ক্লাসিক সমস্যায় রিডাকশন দেখান।

**X NP-কমপ্লিট প্রমাণ (৪ ধাপ)।**

১. X ∈ NP: একটি সার্টিফিকেট ও বহুপদী-সময়ের যাচাইকারী দাও।
২. একটি **জানা** NP-কমপ্লিট A বাছো।
৩. A-ইনস্ট্যান্স থেকে X-ইনস্ট্যান্সে f বহুপদী সময়ে বানাও।
৪. প্রমাণ করো `x ∈ A ⇔ f(x) ∈ X` (দুই দিকেই)।

কেবল ২–৪ ধাপ X-কে **NP-হার্ড** প্রমাণ করে।

### পাঠ্যবইয়ের মানক রিডাকশন ট্রি (তীর A → B মানে A ≤p B)

```
              SAT (Cook–Levin, 1971)
                       ↓
                     3-SAT
       ↙            ↓             ↓             ↘
    Clique      Ham. cycle    Subset sum     3-colouring
      ↓              ↓          ↓      ↘
 Vertex cover ↔    TSP     0/1 knapsack  Partition
 Indep. set
```

কাঠিন্য তীরের দিকে নিচে নামে: SAT → 3-SAT → ক্লিক → ভার্টেক্স কভার ↔ ইনডিপেন্ডেন্ট সেট; 3-SAT →
হ্যামিল্টন সাইকেল → TSP; 3-SAT → সাবসেট সাম → 0/1 ন্যাপস্যাক ও পার্টিশন; 3-SAT → 3-কালারিং।

**উদাহরণ: ক্লিক ≤p ভার্টেক্স কভার।** S যদি G-র **ইনডিপেন্ডেন্ট সেট** হয় ⇔ V − S হলো G-র **ভার্টেক্স
কভার**; আর S যদি G-র **ক্লিক** হয় ⇔ S পরিপূরক Ḡ-তে ইনডিপেন্ডেন্ট। তাই `(G, k) ↦ (Ḡ, |V| − k)`।
উদাহরণ: V = {1,2,3,4}, এজ 12, 13, 23, 34; ক্লিক {1,2,3} (k = 3)। Ḡ-এর এজ 14, 24 — কভার করে **{4}**,
আকার 4 − 3 = 1 ✓।

**উদাহরণ: হ্যামিল্টন সাইকেল ≤p TSP।** nটি ভার্টেক্সের G থেকে একটি কমপ্লিট গ্রাফ বানাও: G-র এজে ওজন
**1**, অন্যগুলোতে **2**। G-তে হ্যামিল্টনিয়ান সাইকেল আছে ⇔ খরচ **≤ n** এমন ট্যুর আছে। n² ওজন বানানো
বহুপদী, তাই TSP-ডিসিশন NP-হার্ড; ট্যুর যাচাইযোগ্য, তাই NP-কমপ্লিট।

> **পরীক্ষার ফাঁদ: দিক।** X কঠিন দেখাতে একটি **জানা** NP-কমপ্লিট সমস্যাকে **X-এ** রিডিউস করো: **A ≤p X**।
> X-কে SAT-এ রিডিউস করা (X ≤p SAT) কেবল দেখায় X, SAT-এর চেয়ে **কঠিন নয়** (তাই X ∈ NP) — কাঠিন্য
> নিয়ে কিছুই নয়। "কঠিন সমস্যা → নতুন সমস্যা", কখনো উল্টো নয়।

**2-SAT বনাম 3-SAT।** প্রতি ক্লজে **দুটি** লিটারাল: **ইমপ্লিকেশন গ্রাফ** বানাও (a ∨ b থেকে a′ → b ও
b′ → a); স্যাটিসফায়েবল ⇔ কোনো চলক তার নেগেশনের সঙ্গে একই স্ট্রংলি কানেক্টেড কম্পোনেন্টে নেই ⇒
**2-SAT ∈ P, লিনিয়ার সময়ে**। প্রতি ক্লজে **তিনটি** লিটারাল হলে সমস্যাটি NP-কমপ্লিট। একটি বাড়তি লিটারালেই
সীমা পার।

## ৯. সহজ/কঠিন জোড়া, P বনাম NP, মোকাবিলা  *(পৃ. ৯)*

| P-তে (বহুপদী) | দেখতে একই, কিন্তু NP-কমপ্লিট | পার্থক্য |
|---|---|---|
| 2-SAT, হর্ন-SAT | **3-SAT**, SAT | প্রতি ক্লজে ৩ লিটারাল |
| অয়লার সার্কিট (প্রতি **এজ** একবার) | **হ্যামিল্টনিয়ান সাইকেল** (প্রতি **ভার্টেক্স**) | এজ বনাম ভার্টেক্স |
| শর্টেস্ট সিম্পল পাথ | **লংগেস্ট** সিম্পল পাথ | মিন বনাম ম্যাক্স |
| মিনিমাম স্প্যানিং ট্রি | TSP; স্টাইনার ট্রি | ট্রি বনাম ট্যুর |
| 2-কালারিং (বাইপার্টাইট) | **3-কালারিং** | ২ বনাম ৩ রং |
| এজ কভার, ম্যাচিং | ভার্টেক্স কভার, 3-D ম্যাচিং | ভার্টেক্স, ৩টি সেট |
| লিনিয়ার প্রোগ্রামিং | 0-1 ইন্টিজার প্রোগ্রামিং | বাস্তব বনাম পূর্ণসংখ্যা |
| ফ্র্যাকশনাল ন্যাপস্যাক | 0/1 ন্যাপস্যাক (ডিসিশন) | ভাঙা বনাম আস্ত |

**P বনাম NP।** **যেকোনো একটি** NP-কমপ্লিট সমস্যার বহুপদী অ্যালগরিদম পাওয়া গেলে **P = NP**, এবং সব NP
সমস্যারই তা থাকবে। P ≠ NP হলে কোনো NP-কমপ্লিট সমস্যা P-তে নেই (আর ল্যাডনারের উপপাদ্য অনুযায়ী কিছু NP
সমস্যা P-তেও নয়, NP-কমপ্লিটও নয় — ফ্যাক্টরিং ও গ্রাফ আইসোমরফিজম সন্দেহভাজন)। প্রশ্নটি সাতটি **ক্লে
মিলেনিয়াম প্রাইজ প্রবলেমের** একটি (২০০০, ১০ লক্ষ মার্কিন ডলার); বেশিরভাগ গবেষক মনে করেন P ≠ NP।

**আইটি সংযোগ।** পাবলিক-কি ক্রিপ্টোগ্রাফি কঠিন বলে বিশ্বাস করা সমস্যার উপর দাঁড়িয়ে (**RSA**-র জন্য
ফ্যাক্টরিং, ডিফি–হেলম্যানের জন্য ডিসক্রিট লগ)। এগুলো NP-তে, তাই ব্যবহারিক অ্যালগরিদমসহ P = NP প্রমাণ হলে
এরা ভেঙে পড়বে। টাইমটেবিলিং, ভেহিকল রাউটিং, রেজিস্টার অ্যালোকেশন (গ্রাফ কালারিং) ও চিপ লেআউট — NP-হার্ড
সমস্যা যা প্রতিদিন নিচের পদ্ধতিগুলোতে সমাধান হয়।

| মোকাবিলার কৌশল | যা ছাড়তে হয় | উদাহরণ |
|---|---|---|
| **বুদ্ধিদীপ্ত এক্সপোনেনশিয়াল** | বড় n-এ গতি | ব্যাকট্র্যাকিং, ব্রাঞ্চ-অ্যান্ড-বাউন্ড; হেল্ড–কার্প TSP **O(n²2ⁿ)** বনাম O(n!) |
| **সিউডো-পলিনোমিয়াল DP** | বড় সংখ্যা | 0/1 ন্যাপস্যাক **O(nW)**; সাবসেট সাম O(nS) |
| **অ্যাপ্রক্সিমেশন** | অপটিমালিটি (অনুপাত প্রমাণিত) | ভার্টেক্স কভার 2×; মেট্রিক TSP 2× (MST), ক্রিস্টোফাইডস 1.5× |
| **হিউরিস্টিক** | যেকোনো নিশ্চয়তা | গ্রিডি, সিমুলেটেড অ্যানিলিং, জেনেটিক, ট্যাবু সার্চ |
| **বিশেষ ক্ষেত্র** | সাধারণতা | 2-SAT; ট্রিতে ভার্টেক্স কভার; ছোট k: O(2ᵏ·n) |

> **পরীক্ষার ফাঁদ: সিউডো-পলিনোমিয়াল।** ন্যাপস্যাকের DP **O(nW)**, তবু ন্যাপস্যাক NP-কমপ্লিট — বিরোধ নেই।
> W লেখা হয় **log₂ W বিটে**, তাই nW **ইনপুটের দৈর্ঘ্যের সাপেক্ষে এক্সপোনেনশিয়াল**। W-এর বিট দ্বিগুণ করলে
> W বর্গ হয়ে যায়। এমন সমস্যাকে **দুর্বলভাবে (weakly)** NP-কমপ্লিট বলে।

> **মনে রাখার কৌশল।** "**অয়লার এজে, হ্যামিল্টন মাথায়।**" প্রতিটি এজ একবার — সহজ (ডিগ্রি দেখলেই হয়);
> প্রতিটি ভার্টেক্স ("মাথা") একবার — NP-কমপ্লিট। একই ছাঁচ: **শর্টেস্ট সহজ, লংগেস্ট কঠিন; ২ সহজ, ৩
> কঠিন**। অনুপাত-নিশ্চিত পদ্ধতিগুলো অ্যাপ্রক্সিমেশন অ্যালগরিদম লেসনে।

### লিখিত প্রশ্ন  (১০ নম্বর)

(ক) তিনটি কি-র ডিসিশন ট্রি ব্যবহার করে প্রমাণ করো যে প্রতিটি তুলনাভিত্তিক সর্টের ওয়ার্স্ট কেসে
Ω(n log n) তুলনা লাগে। (খ) nটি সংখ্যার ম্যাক্সিমাম ও মিনিমাম দুটোই ⌈3n/2⌉ − 2টি তুলনায় কীভাবে বের করা যায়
দেখাও, এবং n = 100-এর জন্য মান বের করো। (গ) P, NP, NP-হার্ড ও NP-কমপ্লিটের সংজ্ঞা দাও, তাদের সম্পর্ক
আঁকো, এবং কোনো সমস্যাকে NP-কমপ্লিট প্রমাণের ধাপগুলো লেখো।

**নমুনা উত্তর**

১. **(ক) ডিসিশন ট্রি (৪)** — প্রতিটি তুলনা একটি নোড, n!টি ক্রমের প্রতিটির নিজস্ব লিফ চাই; উচ্চতা h ⇒
   ≤ 2ʰ লিফ ⇒ h ≥ log₂ n! ≥ (n/2) log₂(n/2) = Ω(n log n)। ৩টি কি-তে: ৬টি লিফ, ওয়ার্স্ট কেস
   ⌈log₂ 6⌉ = 3।
২. **(খ) জোড়া পদ্ধতি (৩)** — জোড়ায় তুলনা (n/2), বিজয়ীদের ম্যাক্স (n/2 − 1), পরাজিতদের মিন (n/2 − 1) ⇒
   3n/2 − 2; n = 100: 50 + 49 + 49 = 148 (আলাদাভাবে 198)।
৩. **(গ) শ্রেণি (৩)** — P: বহুপদী সময়ে সমাধানযোগ্য; NP: বহুপদী সময়ে যাচাইযোগ্য; NP-হার্ড: প্রতিটি NP
   সমস্যা ≤p এটি; NPC = NP ∩ NP-হার্ড; আঁকো P ⊆ NP, NPC ছেদ হিসেবে, NP-হার্ড বাইরে ছড়ানো। ধাপ: X ∈ NP,
   জানা NPC A বাছাই, বহুপদী সময়ে f, প্রমাণ x ∈ A ⇔ f(x) ∈ X।
