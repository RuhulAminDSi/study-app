## ১. দ্য ব্রয়লি তরঙ্গ (পদার্থ তরঙ্গ)
- লুই দ্য ব্রয়লি (**১৯২৪**, থিসিস; নোবেল পুরস্কার **১৯৩৭**) আইনস্টাইনের যুক্তি উল্টে দিলেন: যদি আলো কণার মতো আচরণ করতে পারে, তবে **কণাও তরঙ্গের মতো আচরণ করে**।
- **λ = h/p = h/mv = h/√(2mK)** (অ-আপেক্ষিক)। h = **6.626 × 10⁻³⁴ J·s** (২০১৯ সালের SI পুনর্নির্ণয়ের পর হুবহু নির্দিষ্ট); ħ = h/2π = **1.0546 × 10⁻³⁴ J·s**।
- λ ∝ 1/p: ভর দ্বিগুণ (একই v) → λ অর্ধেক; v দ্বিগুণ (একই m) → λ অর্ধেক; p দ্বিগুণ → λ অর্ধেক।
- λ_C = h/mc হলো **স্থির** কণার দ্য ব্রয়লি তরঙ্গ দৈর্ঘ্য (ইলেকট্রনের ক্ষেত্রে এটি কম্পটন তরঙ্গদৈর্ঘ্য, 2.43 pm)।

| পরিস্থিতি | λ |
|---|---|
| 1 eV-এ ইলেকট্রন | 1.226 nm |
| 100 V-এর মধ্য দিয়ে ইলেকট্রন | 0.123 nm = 1.23 Å |
| 10 kV-এর মধ্য দিয়ে ইলেকট্রন | 0.123 pm |
| 1 MeV প্রোটন বা নিউট্রন | 28.6 fm |
| 5 MeV α-কণা | 6.4 fm |
| ক্রিকেট বল, 0.1 kg, 10 m/s বেগে | 6.6 × 10⁻³⁴ m |

- 💡 **কৌশল:** "বড় জিনিস → ছোট তরঙ্গ"। কোয়ান্টম আচরণ কেবল হালকা বা দ্রুত বস্তুতেই দেখা যায়।
- ⚠ **ফাঁদ:** λ = h/p, কখনোই hp নয়। h J·s ও p kg·m/s-এ থাকলেই λ মিটারে পাওয়া যায়। ≈ 0.1c-এর বেশি হলে p = γmv।
- ✍ **উদাহরণ ১:** 2.0 × 10⁶ m/s বেগে ইলেকট্রন: p = 1.82 × 10⁻²⁴ kg·m/s → λ = **3.64 × 10⁻¹⁦ m = 0.364 nm**।
- ✍ **উদাহরণ ২:** 1.0 MeV প্রোটন: p = √(2mE) = 2.32 × 10⁻²⁦ → λ = **2.86 × 10⁻¹⁴ m = 28.6 fm**।
- ফোটনও p = h/λ বহন করে, তবে তার বিশ্রাম দ্রবত্ব শূন্য বলে p = E/c।

## ২. ফেজ বেগ ও গ্রুপ বেগ
- একটি মুক্ত কণা একটি **তরঙ্গ প্যাকেট**: প্রায় সমান k-যুক্ত অনেক উপাদান তরঙ্গের সুপারিপোজিশন।

| | ফেজ বেগ v_p | গ্রুপ বেগ v_g |
|---|---|---|
| সংজ্ঞা | ω/k = E/p | dω/dk = **dE/dp** |
| মুক্ত ভরযুক্ত কণা | c²/v (≥ c) | **= v** (কণাটিই) |
| শূন্য মাধ্যমে আলো | c | c |
| বিক্ষিপক মাধ্যম | ω/k | সংকেত ও তথ্যের গতি |
| যা বহন করে | **কোনো তথ্য নয়** | শক্তি **ও** তথ্য |

- **v_p·v_g = c² ঠিকভাবে।** E² = p²c² + m²c⁴ থেকে: ① v_p = E/p, ② v_g = dE/dp = p²c²/E, ③ গুণফল = c²। আলোর ক্ষেত্রে m = 0 এবং E = pc, তাই দুটোই c।
- 💡 **কৌশল:** "একটি শীর্ষ মানে আবিষ্কারণ, প্যাকেটই সত্য"। একা একটি শীর্ষ কোনো সংকেত বহন করে না, তাই তার বেগ অমাপযোগ্য এবং c ছাড়াতেও হতে পারে।
- ⚠ **ফাঁদ:** v_p > c কিছু লঙ্ঘন করে না। v_g হলো **dE/dp**, কখনোই dp/dm নয়। প্যাকেট কখনোই c ছাড়াতে পারে না: পেছনের অংশ সামনেরটিকে ছাড়িয়ে যেত।
- ✍ **উদাহরণ:** 0.8c বেগে ইলেকট্রন → v_g = 0.8c = 2.40 × 10⁸ m/s, v_p = c²/(0.8c) = 1.25c = 3.75 × 10⁸ m/s, গুণফল 0.8 × 1.25 = 1। γ = 1/0.6 = 1.67, তাই p = γmv = 3.64 × 10⁻²⁨ kg·m/s এবং λ = 1.82 pm (শুধু mv ব্যবহার করলে ভুলে 3.03 pm পাওয়া যেত)।

## ৩. তরঙ্গ ফাংশন Ψ ও বর্নের নিয়ম
- **Ψ(x, y, z, t)** হলো অবস্থার সম্পূর্ণ গাণিতিক বর্ণনা: কণা সম্পর্কে সব জানা যায় এমনকিছু। Ψ **জটিল মানযুক্ত** এবং **নিজে পরিমাপযোগ্য নয়**।
- **বর্নের নিয়ম (১৯২৬): |Ψ|² হলো সম্ভাবনার ঘনত্ব।** |Ψ|²dV একটি সম্ভাবনা; |Ψ|² একা একটি ঘনত্ব।
- **নর্মালাইজেশন: ∫|Ψ|²dτ = 1.**

| বস্তু | অর্থ |
|---|---|
| Ψ(x, t) | তরঙ্গ ফাংশন — জটিল, পর্যবেক্ষণযোগ্য নয় |
| \|Ψ\|² = Ψ\*Ψ | **সম্ভাবনার ঘনত্ব** (প্রতি একক আয়তনে) |
| ∫\|Ψ\|²dV | = 1 (ঠিক একটি কণা) |
| \|Ψ(x, t)\|²dV | dV উপাদানে কণাটি পাওয়ার সম্ভাবনা |
| ψ, E | Ĥ-এর আইগেনফাংশন ও আইগেনভ্যালু |

- Ψ-এর উপর শর্ত: একমান, সসীম, অবিচ্ছিন্ন; V যেখানে সসীমা সেখানে Ψ ও ∂Ψ/∂x অবিচ্ছিন্ন; Ψ ≡ 0 কোনো অবস্থা নয়; পরিমাপের পর Ψ ওই পরিমাপিত রাশির আইগেনঅবস্থায় থাকে; Ψ রৈখিক, তাই Ψ = c₁Ψ₁ + c₂Ψ₂।
- 💡 **কৌশল:** "তারকা দাগ, তারপর বর্গ": |Ψ|² = **Ψ\* × Ψ**, কখনোই Ψ × Ψ নয়।
- ⚠ **ফাঁদ:** |Ψ|² একটি ঘনত্ব; সম্ভাবনা পেতে ইন্টিগ্রাল লাগে। Ψ জটিল হতে পারে, তাই Ψ² জটিল ও অর্থহীন হতে পারে।
- ✍ **উদাহরণ:** 0 &lt; x &lt; L-এ ψ = A sin(πx/L) নর্মালাইজ করো: 1 = A²(L/2) ⇒ **A = √(2/L)**, তাই ψ_n = √(2/L) sin(nπx/L)। মাঝের অর্ধেকে (L/4 &lt; x &lt; 3L/4) সম্ভাবনা = **1/2**।

## ৪. শ্রোডিংগার সমীকরণ
- **১৯২৬**, নোবেল পুরস্কার **১৯৩৩**। কোয়ান্টাম মেকানিক্সের মূল সূত্র — এটি বলে কোথায় কণা আছে তা নয়, কীভাবে *অবস্থা* বদলায় তা।
- **সময়-নির্ভর (সবসময় সত্য): iħ ∂Ψ/∂t = −(ħ²/2m)∇²Ψ + VΨ = ĤΨ**
- **সময়-স্বাধীন (স্থির অবস্থা, V সময়-নিরপেক্ষ): −(ħ²/2m)∇²ψ + Vψ = Eψ**
- এক-মাত্রায় ∇²-এর বদলে ∂²/∂x² লেখো।

| শ্রেণিবাচনে আমরা লিখি… | …কোয়ান্টাম মেকানিক্সে তা হয়ে যায় অপারেটর… |
|---|---|
| অবস্থান x · ভরবেগ p | x → x · p → −iħ∇ |
| গতিশক্তি p²/2m | −(ħ²/2m)∇² |
| শক্তি E | E → iħ ∂/∂t |
| মোট শক্তি H | **Ĥ = −(ħ²/2m)∇² + V** (হ্যামিল্টনীয়) |

**চলক-বিচ্ছেদ (Separation of variables)**
1. Ψ(x, t) = **ψ(x) T(t)** ধরো, বসাও, ψT দিয়ে ভাগ করো।
2. বাম পাশ কেবল t-এর উপর, ডান পাশ কেবল অবস্থানের উপর নির্ভরশীল ⇒ দুটোই একটি ধ্রুব, −E/ħ-এর সমান।
3. T(t) = e^(−iEt/ħ); |T| = 1 হওয়ায় |Ψ|² = |ψ|² সময়ের সাথে ধ্রুব।
4. এটিই একটি **স্থির অবস্থা**: ψ আইগেনফাংশন, E আইগেনভ্যালু।

- 💡 **কৌশল:** "শব্দের বদলে টুপি দাও" — প্রতিটি রাশি হয়ে যায় অপারেটর; সমীকরণটি তখন কেবল বলে শক্তি = অবস্থার উপর Ĥ-এর ক্রিয়া।
- ⚠ **ফাঁদ:** V সময়-নির্ভর হলে সময়-স্বাধীন রূপ অবৈধ, আর এতে ছোট হাতের ψ বসে। স্থির অবস্থা মানে কেবল সম্ভাবনাই স্থির।
- ✍ **উদাহরণ:** মুক্ত কণা, V = 0, ψ = Ae^(ikx) ⇒ −(ħ²/2m)(−k²)ψ = Eψ ⇒ **E = ħ²k²/2m = h²/(2mλ²) = p²/2m**। শ্রোডিংগার সমীকরণ আবার λ = h/p ফিরিয়ে দেয়।

## ৫. এক-মাত্রার বক্সে কণা
- বাইরে V(x) = ∞ এবং 0 &lt; x &lt; L-এ V = 0। Ψ-কে সসীম থাকতে হয় এবং V = ∞ যেখানে কণা অসম্ভব, তাই **ψ(0) = ψ(L) = 0**।

| রাশি | ফলাফল |
|---|---|
| নর্মালাইজড আইগেনফাংশন | ψ_n(x) = √(2/L) sin(nπx/L) |
| শক্তির আইগেনভ্যালু | **E_n = n²π²ħ²/2mL² = n²h²/8mL²** |
| অনুমোদিত n | n = 1, 2, 3 … (কখনোই 0); নোড = n − 1 |
| E₁-এর এককে স্তর | 1 : 4 : 9 : 16 … |
| ভরবেগ | ⟨p⟩ = 0, কিন্তু ⟨p²⟩ = (nπħ/L)² |

- 💡 **কৌশল:** বক্সে কণা হলো দুই প্রান্তে বাঁধা একটি সুতোর আবরণ — কেবল 3λ/2, 5λ/2, 7λ/2 … বসে, তাই n শুরু হয় ১ থেকে এবং E ∝ n²।
- ⚠ **ফাঁদ:** E₁ **শূন্য নয়** (শূন্য-বিন্দু শক্তি)। ⟨p⟩ = 0 মানে p = 0 নয়; Δp বড়।
- ✍ **উদাহরণ:** 0.1 nm বক্সে ইলেকট্রন: E₁ = **37.6 eV**, E₂ = 150 eV, E₃ = 338 eV, E₄ = 602 eV। 2 → 1 লাফ দিলে 3E₁ = 113 eV মুক্ত হয় ⇒ ফোটনের λ = 1240/113 = **11.0 nm** (দূর অতিবেগুনি)। L অর্ধেক করলে প্রতিটি স্তর চারগুণ ওঠে।
- **IT সংযোগ:** দুটি বক্সের মাঝের বাধা হলো একটি **কোয়ান্টাম টানেল** — E &lt; V হলেও ইলেকট্রন তা ভেদ করে যায়। এভাবেই NAND ফ্ল্যাশ সেল প্রোগ্রাম ও মোছা হয়, আর স্ক্যানিং টানেলিং মাইক্রোস্কোপ একক পরমাণু দেখায় (কারেন্ট ∝ e^(−2κd), বিনিগ ও রোরার, নোবেল ১৯৮৬)।

## ৬. কোয়ান্টম হার্মোনিক দোলক
- V(x) = ½kx² = ½mω²x², ω = √(k/m)।
- **E_n = (n + ½)ħω = (n + ½)hf**, n = 0, 1, 2, 3 …
- ψ₀ = (mω/πħ)^(1/4) e^(−mωx²/2ħ), ⟨x⟩₀ = 0, ⟨x²⟩₀ = ħ/(2mω), Δx₀ = √(ħ/2mω)।

| | শ্রেণিবাচনীয় দোলক | কোয়ান্টাম দোলক |
|---|---|---|
| শক্তি | ধারাবাহিক, E = ½kA² | বিচ্ছিন্ন, (n + ½)ħω |

- 💡 **কৌশল:** "বক্স ১ থেকে গোনে, দোলক ০ থেকে।" বক্সে n = 0 হলে নিষিদ্ধ ψ ≡ 0 পাওয়া যেত; দোলকে n = 0-ই আসল মূল অবস্থা।
- ⚠ **ফাঁদ:** দোলক কখনোই সম্পূর্ণ স্থির থাকে না (⟨p⟩ = 0 কিন্তু ⟨p²⟩ ≠ 0), আর এর ব্যবধান n-এর সাথে **বাড়ে না**।
- ✍ **উদাহরণ:** ω = 5.0 × 10¹⁴ rad/s-এর আণবিক কম্পন: ħω = 0.329 eV, তাই **E₀ = 0.165 eV** এবং E₁ − E₀ = 0.329 eV পড়ে অবলোহত্তর অঞ্চলে। একই ক্ষেত্রে ইলেকট্রনের জন্য Δx₀ = 0.34 nm — দশটি পরমাণু ব্যাস।

## ৮. প্রত্যাশা-মান, অনিশ্চয়তা ও কোরেসপন্ডেন্স
- **প্রত্যাশা-মান: ⟨A⟩ = ∫Ψ\* Â Ψ dτ** — একইভাবে প্রস্তুত অনেক কপির উপর গড়। Ψ = ΣcᵢΨᵢ হলে অর্থোনর্মাল সেটে ⟨A⟩ = Σ|cᵢ|²⟨Aᵢ⟩ᵢ।

| রাশি | প্রত্যাশা-মান | ছড়ানি (প্রমিত বিচ্যুতি) |
|---|---|---|
| অবস্থান | ⟨x⟩ = ∫Ψ\* x Ψ dτ | Δx = √(⟨x²⟩ − ⟨x⟩²) |
| ভরবেগ | ⟨p⟩ = ∫Ψ\* (−iħ∇)Ψ dτ | Δp = √(⟨p²⟩ − ⟨p⟩²) |
| শক্তি | ⟨E⟩ = ∫Ψ\* ĤΨ dτ | ΔE (স্থির অবস্থায় 0) |

- **হাইজেনবার্গের অনিশ্চয়তা নীতি (১৯২৭): Δx · Δp ≥ ħ/2.** সমতা কেবল ন্যূনতম-অনিশ্চয়তার **গাউসীয়** প্যাকেটে। x̂ ও p̂ কমিউট করে না ([x̂, p̂] = iħ), তাই কোনো অবস্থা দুটোরই আইগেনঅবস্থা হতে পারে না।
- **কোরেসপন্ডেন্স নীতি (বোরহ, ১৯২০):**

| ব্যবস্থা | কোয়ান্টম | বড় n-এর সীমা |
|---|---|---|
| বক্স | E_n = n²h²/8mL² | ΔE/E = (2n+1)/n² → 0 |
| দোলক | E_n = (n+½)ħω | ধ্রুব ħω → মসৃণ |
| বোরহ H পরমাণু | L = nħ, r = n²a₀ | L/ħ → ∞, কক্ষ শ্রেণিবাচনীয় মনে হয় |
| টানেলিং | T ≈ e^(−2κd) | ħ → 0 ⇒ T → 0 |

- 💡 **কৌশল:** "ছোট পেতে পারি **অথবা** ছোট — কখনোই দুটো একসাথে নয়।" Δx একটি দৈর্ঘ্য, Δp একটি ভরবেগ; এদের গুণফল একটি অ্যাকশন (J·s)। ħ = 0 বসালেই শ্রেণিবাচনীয় জগত ফিরে আসে।
- ⚠ **ফাঁদ:** চিহ্নটি **≥**, আর সমতা বিরল। বক্সের মূল অবস্থায় Δx·Δp ≈ 0.57 ħ, ħ/2 নয়। ΔE·Δt ≥ ħ/2 হলো শক্তি–সময় রূপ, যা কম নিশ্চিত।
- ✍ **উদাহরণ:** 0.1 nm বক্সে ইলেকট্রন: ⟨x⟩ = L/2 এবং ⟨x²⟩ = L²(1/3 − 1/2π²) = 0.2827 L², তাই Δx = √(0.2827 − 0.25)L = 0.181L = 1.81 × 10⁻¹¹ m। তারপর Δp ≥ ħ/(2Δx) = **2.9 × 10⁻²⁴ kg·m/s**, অর্থাৎ Δv ≥ 3.2 × 10⁶ m/s, অথচ কণাটির নিজের গতি মাত্র √(2E₁/m) = 3.6 × 10⁶ m/s।
