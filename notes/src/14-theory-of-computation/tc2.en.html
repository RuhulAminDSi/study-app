1Context-Free Languages

high-yield
Definition A language is context-free when a context-free grammar can generate it and a pushdown automaton can recognise it — Chomsky Type 2. A stack holds one nested structure at a time, and no more.

Why each answer union: a new start symbol chooses either grammar · concatenation: S₁ → S₂, then L₂'s rules · star: S → SS | ε, then L's rules · complement: flipping the final states of a PDA yields no CFG · intersection with a regular language: run the PDA, then the finite automaton on top.
Exam trap "Not closed under intersection" needs its proof: L₁ = {aⁿ bⁿ cᵐ} and L₂ = {aᵐ bⁿ cⁿ} are context-free, but L₁ ∩ L₂ = {aⁿ bⁿ cⁿ} is not. So "not closed under ∩" means not in general — yet CFL ∩ regular is always a CFL.
Memory trick Regular = ∪ ∩ ¬ * · CFL = ∪ · *. The only closure regular languages have that CFLs lack is intersection.

2Context-Free Grammar: the 4-Tuple

high-yield
Definition A context-free grammar is G = (V, Σ, P, S) — variables, terminals, productions, start symbol. It generates L(G) by repeatedly replacing a variable with the right-hand side of one of its productions. It is context-free exactly when exactly one variable on the left: nothing ever sits beside it.
PartIsIn the example G
Vfinite set of variables; S ∈ VV = {S, A, B}
Σfinite set of terminals; V ∩ Σ = ∅Σ = {a, b}
Pset of productions A → α, α ∈ (V ∪ Σ)*P = { S → aSb, S → ε }
Sthe start symbol, S ∈ VS = S

The grammar for {aⁿ bⁿ | n ≥ 0}

G = ( {S}, {a, b}, P, S ) P = { S -> a S b , S -> e } leftmost derivation of "aaabbb": S => aSb => aaSbb => aaaSbbb => aaabbb

Each use of S → aSb wraps one more a on the left and one b on the right; S → ε stops it. After n uses you have aⁿbⁿ, and n = 0 gives ε — so the language is {aⁿ bⁿ | n ≥ 0}, not n ≥ 1.

NotationMeans
a, b, 0, 1terminal — a real character
S, A, Tvariable — a placeholder to replace
A → αa production
A ⇒ βone derivation step
A ⇒* wzero or more steps, w all terminals
εthe empty string, |ε| = 0
Memory trick Four letters in order: Variables, the Σymbols they sit on, the Productions, the Start — "V–Σ–P–S".
Exam trap The condition sits on the left, never on the right. A → aSb is context-free; AB → aSb is not, whatever its right side looks like.
IT link Every programming language ships a CFG in BNF as the definition of its syntax; a parser generator turns that grammar into the tables that validate a program.
V ∩ Σ = ∅ — a variable is never also a terminal, so the four parts never collide

3Derivations, Parse Trees and Ambiguity

high-yield
Derivation Start from S, replacing one variable at a time until only terminals remain. A leftmost derivation always replaces the leftmost remaining variable, a rightmost one the rightmost. Both reach the same string — only the order of work differs, which is why parsers are built leftmost.
LEFTMOST RIGHTMOST S S S => aSb S => aSb S => aaSbb S => aSbb S => aaaSbbb S => aaSbb S => aaabbb S => aaabbb
Parse tree = the derivation, drawn Every variable is a node; every applied production is a node whose children are that rule's right-hand symbols, left to right. leaves read left to right give the derived string, so leaves = the string — and for n terminals the tree has exactly n − 1 internal nodes.

Ambiguity: two trees for one string

Definition A grammar is ambiguous if some string has two or more distinct leftmost derivations — equivalently two parse trees. One bad string is enough.
Worked example ✍ the classic ambiguous grammar
E -> E + E | E * E | id tree 1: (id+id)*id tree 2: id+(id*id) * + / \ / \ + id id * / \ / \ id id id id

Same four terminals, two groupings — so id+id*id is ambiguous. Fixing it needs one extra level per operator: E → E + T | T, T → T * F | F, F → id.

Memory trick "Ambiguous = alternative tree". If one string can be built two ways, the parser cannot know what was meant.
Exam trap Ambiguity has nothing to do with ε-productions, with the number of variables, or with an infinite language. And it is not nondeterminism: a PDA is nondeterministic on every CFL.

4Worked Grammar: Balanced Parentheses

written favourite
Definition The language of balanced parentheses over Σ = { (, ) } is { (ⁿ )ⁿ | n ≥ 0 }: every ( is closed by a later ), and the nesting is proper. It is context-free, and it is what the pushdown automaton from the automata lesson accepts by pushing on ( and popping on ).

The grammar

V = {S}, Sigma = { ( , ) }, S = S P = { S -> SS , two groups side by side S -> (S) , one group inside another S -> e } the empty group leftmost derivation of "(())()": S => SS => (S)S => ((S))S => (())S => (())(S) => (())()

Read it as a proof of acceptance: every ( is closed by exactly one ), and no ) comes first. The converse holds too — S → SS builds the first group and appends the rest, S → (S) takes care of one nesting level.

ProductionThe idea it encodesStrings it can finish
S → εthe base case: the empty groupε, and only ε
S → (S)wrap one group in one pair( ), ( () ), ( (()) ) …
S → SSconcatenate two balanced groups()(), (())(), (()()) …
Exam trap Write S → SS, never S → SS | SS. The order of alternatives is irrelevant — a CFG's productions are a set, not a program: any rule may fire at any step. This is also why {aⁿbⁿcⁿ} cannot be built this way: one stack cannot close one bracket while a second count is still open.
Memory trick SS = side by side, (S) = inside, ε = nothing. The same three-rule shape builds balanced {}, balanced [ ], and — with a third pair — balanced { } [ ].
IT link An editor's bracket matcher is a PDA: push on an opening symbol, pop on the matching one, refuse to pop an empty stack. In a compiler the same grammar becomes the parser's production rules.

5Simplifying a CFG: CNF and GNF

high-yield
  1. Remove useless symbols: the non-generating variables, then the unreachable ones.
  2. Remove ε-productions A → ε: find every nullable variable and drop its ε-rule.
  3. Remove unit productions A → B by copying B's productions in their place (repeat — chains occur).
  4. Convert to Chomsky Normal Form — what CYK and the parser generators demand.
  5. Convert to Greibach Normal Form, where every rule starts with a terminal.
Normal formEvery production isBuys
CNFA → BC or A → a; S → ε only when ε ∈ LCYK, yacc/bison
GNFA → aαone-symbol prediction
right-linearA → aBa regular Type 3 grammar
Worked conversion ✍ S → aSb | ε into CNF
original S -> a S b | e step 1 wrap the left terminal, then the right: S -> A S B step 2 THREE symbols on the right, so split the tail: S -> A X , X -> S B , A -> a , B -> b result S -> A X | e , X -> S B , A -> a , B -> b

Why S → ε survives: CNF allows it only when ε ∈ L and S appears on no right-hand side. Here S does, inside X → SB, so the strictly correct form adds a fresh start symbol S₀ → S and keeps the other four rules.

Exam trap S → ASB is not CNF — exactly two variables or one terminal, never three symbols. And A → aα is Greibach, not CNF.
Memory trick CNF = two or one, GNF = starts with a terminal. Count the right-hand symbols: 2 or 1 ⇒ CNF; "a then variables" ⇒ GNF; "aB" ⇒ regular.

6Pumping Lemma for CFLs, CYK and Step Counts

high-yield
Pumping lemma for context-free languages If L is context-free then some length p exists such that every s ∈ L with |s| ≥ p splits as s = uvxyz with |vxy| ≤ p, |vy| ≥ 1 and uvⁱxyⁱz ∈ L for every i ≥ 0. Read it as: inside a short window lies a balanced piece that may be repeated as often as you like. Like the regular version it is a disproof tool only.
ConditionSays
|vxy| ≤ pthe pumpable window is short
|vy| ≥ 1v and y together are non-empty
uvⁱxyⁱz ∈ L, ∀i ≥ 0v and y repeat together
Exam trap The regular lemma pumps xyⁿz; the CFL lemma pumps uvⁱxyⁱz — two exponents, and they are equal. Writing u(vxy)ⁿz is wrong. And satisfying the lemma never proves a language is context-free.
Worked disproof ✍ {aⁿ bⁿ cⁿ | n ≥ 0} is not context-free

Take pumping length p and s = aᵖbᵖcᵖ. Every decomposition with |vxy| ≤ p and |vy| ≥ 1 puts y wholly inside the a-block (y = aᵏ, k ≥ 1) or wholly inside the b-block (y = bᵏ). Pumping y alone breaks the match, and pumping v and y together cannot restore it, because they sit in different blocks. The condition fails ⇒ L is not context-free. In one line: it needs three simultaneous counts, and one stack holds one.

CYK and the step count CYK decides membership for a fixed CNF grammar in O(n³) time (O(n³·|G|) in general): a bottom-up table over O(n²) substrings, trying O(n) split points each. In CNF a string of length n ≥ 1 takes exactly 2n − 1 steps — n − 1 of A → BC to turn one variable into n variables, then n of A → a.
Memory trick "n − 1 splits, then n terminals = 2n − 1 altogether" — and CYK is cubic: three nested loops over substrings, split points and rules.
Unlike the regular lemma, the CFL lemma has no way to prove context-freeness — only to deny it

7CFG ↔ PDA and Where CFGs Are Used

written favourite
Equivalence theorem (high-yield) context-free ⇔ some PDA. "If" is trivial — read the grammar as a leftmost derivation. "Only if" is the surprise: the PDA's states become variables, so the machine writes its own grammar.
  1. Push the start symbol S on the stack above the bottom marker Z₀.
  2. If the stack top is a variable A with A → α in P, pop A and push α in reverse order.
  3. If the stack top is a terminal a, match it with the next input symbol: equal → pop and advance; unequal → reject.
  4. Accept when the input is exhausted and only Z₀ is left on the stack.
  5. Reverse direction: a variable [pXq] for every state pair p, q and stack symbol X, [pXq] → a per transition, S₀ → [q₀ Z₀ q] per accepting state q.
ApplicationHow the CFG is used
Programming languagesC, Java, Pascal syntax is defined in BNF/EBNF — the grammar is the definition
Compilersparser generators (yacc, bison, ANTLR) read the grammar and emit the tables
Markup languagesXML / HTML nesting is a CFG; the validator is a PDA over the tag stream
Natural languagesentence structure as a grammar; parsing opens every NLP pipeline
Query languagesSQL's SELECT … WHERE … is a recursive-descent grammar
Memory trick Push the start symbol, replace the top of stack, accept on a bare stack. The reverse conversion names its variables [pXq] — "from p, on X, to q".
Exam trap In CFG → PDA the right-hand side is pushed reversed: the stack is last-in-first-out. Push α in written order and the PDA builds the string backwards.
IT link Bracket matching, if/for nesting checks and JSON validation are the same PDA of sheet 5.

Written question Write a CFG for all palindromes over {a, b}; derive abba and aba leftmost; say why it is context-free but not regular. 10 marks
Model answer ✍
  1. Grammar 3 — G = ({S}, {a,b}, P, S), P = { S → aSa | bSb | a | b | ε }: wrap both ends, finish the middle.
  2. Derivations 3 — abba: S ⇒ aSa ⇒ abSba ⇒ abba · aba: S ⇒ aSa ⇒ aba.
  3. Why context-free 2 — one variable per left side; an NPDA pushes the first half, guesses the middle and pops the second.
  4. Why not regular 2 — with pumping length p, w = aᵖ b aᵖ splits with y = aᵏ in the first block, so xy²z is not a palindrome.
