১ডেটা, তথ্য ও তথ্য প্রযুক্তি

MCQ-এর ভিত্তি
ডেটা (উপাত্ত) কাঁচা, অসংগঠিত তথ্য-উপাদান (নম্বর, নাম), যার নিজে থেকে কোনো অর্থ নেই।
তথ্য (Information) ডেটাকে প্রক্রিয়াকরণ করে পাওয়া অর্থপূর্ণ, ব্যবহারযোগ্য রূপ।
IT তথ্য প্রযুক্তি (Information Technology): কম্পিউটার, স্টোরেজ, নেটওয়ার্ক ও সফটওয়্যার দিয়ে ইলেকট্রনিক ডেটা তৈরি, প্রক্রিয়াকরণ, সংরক্ষণ, সুরক্ষা ও বিনিময় করা।
ICT তথ্য ও যোগাযোগ প্রযুক্তি = IT + যোগাযোগ প্রযুক্তি (টেলিফোন, মোবাইল, সম্প্রচার, ইন্টারনেট)। এটি বৃহত্তর শব্দ; বাংলাদেশের নীতিতে এটিই চলে (ICT বিভাগ, ICT আইন ২০০৬)।

IT সিস্টেমের উপাদান: হার্ডওয়্যার · সফটওয়্যার · ডেটা · নেটওয়ার্ক · মানুষ (কিছু বইয়ে সাথে কার্যপদ্ধতি বা procedure)।

IT-এর কাজ: সংগ্রহ → প্রক্রিয়াকরণ → সংরক্ষণ → পুনরুদ্ধার → প্রেরণ; সাথে স্বয়ংক্রিয়করণ (automation), সিদ্ধান্তে সহায়তা ও নিরাপত্তা।

মনে রাখার কৌশল DIKW পিরামিড: Data (ডেটা) → Information (তথ্য) → Knowledge (জ্ঞান) → Wisdom (প্রজ্ঞা)। প্রতি ধাপে অর্থ বাড়ে।

ভালো তথ্য হয় নির্ভুল, সময়োপযোগী, প্রাসঙ্গিক, পূর্ণাঙ্গ ও সংক্ষিপ্ত। প্রয়োগ: ব্যাংকিং, ই-লার্নিং, টেলিমেডিসিন, ই-কমার্স (পৃ. ৯), সরকার ↓।

৪ডেটা কীভাবে ইন্টারনেট পাড়ি দেয়

প্যাকেট সুইচিং (Packet switching): বার্তা ছোট ছোট প্যাকেটে ভাগ হয়; প্রতিটিতে থাকে উৎস ও গন্তব্যের IP ঠিকানা। রাউটার জানা সেরা পথে ধাপে ধাপে প্যাকেট পাঠায়, তাই প্যাকেট ভিন্ন ভিন্ন পথে গিয়ে এলোমেলো ক্রমে পৌঁছাতে পারে; TCP সেগুলো সাজায় ও হারানোগুলো আবার আনায়, আর IP শুধু পৌঁছে দেয় (best effort)। বাংলাদেশে পথ: সাবমেরিন ক্যাবল / ITC → IIG → NIX / NTTN → ISP → ব্যবহারকারী; সবার লাইসেন্স দেয় BTRC।

স্ট্যাটিক IP হাতে বসানো; ডায়নামিক IP ভাড়া দেয় DHCP। সাবনেটিং → অধ্যায় ৯।

ডোমেইন নাম IP ঠিকানার পাঠযোগ্য নাম, পড়তে হয় ডান থেকে বামে: রুট (.) → TLD → সেকেন্ড লেভেল → হোস্ট। gTLD: .com .org .net .edu .gov .int · ccTLD: ২ অক্ষরের, .bd (পরিচালনায় BTCL), .in, .uk; .বাংলা হলো বাংলা IDN ccTLD।
মনে রাখার কৌশল DNS হলো ইন্টারনেটের ফোনবুক: নাম জানো, নম্বর খুঁজে দেয়। DHCP হলো হোটেলের রিসেপশন, যে রুম নম্বর বরাদ্দ করে।
পরীক্ষার ফাঁদ DNS নাম → IP অনুবাদ করে; DHCP IP বরাদ্দ করে; ARP IP থেকে MAC বের করে। 127.0.0.1 প্রাইভেট ঠিকানা নয়: এটি লুপব্যাক।

IEEE: 802.3 Ethernet · 802.11 Wi-Fi · 802.15.1 Bluetooth · 802.16 WiMAX। তারযুক্ত: ডায়াল-আপ (≤ 56 kbps) → ADSL (ডাউনলোড > আপলোড) → ক্যাবল → FTTH। মোবাইল: 2G GSM (ভয়েস, SMS) → 3G (ব্রডব্যান্ড) → 4G LTE (সম্পূর্ণ IP-ভিত্তিক) → 5G (খুব কম লেটেন্সি, IoT)।

পরীক্ষার ফাঁদ "Wi-Fi"-র কোনো আনুষ্ঠানিক পূর্ণরূপ নেই ("Wireless Fidelity" একটি স্লোগান)। 1 Mbps = 10⁶ বিট/সেকেন্ড, 2²⁰ নয়।
