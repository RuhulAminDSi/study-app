লিখিত পরীক্ষার প্রিয়
সংজ্ঞা বৈশিষ্ট্যসূচক সারণি (Characteristic table): "ইনপুট দেওয়া আছে, Q⁺ কত?" (বিশ্লেষণ)। এক্সাইটেশন টেবিল (Excitation table) উল্টো প্রশ্নের উত্তর দেয়: "Q থেকে Q⁺-এ যেতে কোন ইনপুট লাগবে?" (কাউন্টার ও স্টেট মেশিন ডিজাইন)।
Q → Q⁺S   RJ   KDT
0 → 00   X0   X00
0 → 11   01   X11
1 → 00   1X   101
1 → 1X   0X   010

JK-তে সবচেয়ে বেশি X (ডোন্ট-কেয়ার), তাই JK দিয়ে ডিজাইনে ইনপুট লজিক সবচেয়ে সরল; D-তে আলাদা টেবিলই লাগে না (D = Q⁺), তবে গেট সাধারণত বেশি লাগে।

মনে রাখার কৌশল D কলাম = Q⁺ কলাম। T কলাম = Q ⊕ Q⁺ (বদলালেই 1)। JK: Q = 0 হলে শুধু J গুরুত্বপূর্ণ (J = Q⁺, K = X); Q = 1 হলে শুধু K (K = Q⁺′, J = X)।
পরীক্ষার ফাঁদ দুটি সারণি গুলিয়ো না: "J = K = 1 → টগল" হলো বৈশিষ্ট্যসূচক; "0 → 1-এ লাগে J = 1, K = X" হলো এক্সাইটেশন (K = X, K = 0 নয়)।

৮রেস-অ্যারাউন্ড ও মাস্টার-স্লেভ ফ্লিপ-ফ্লপ

হাই-ইল্ড

রেস-অ্যারাউন্ড অবস্থা (Race-around): লেভেল-ট্রিগারড JK-তে J = K = 1 থাকলে ক্লক পালসের প্রস্থ tp প্রোপাগেশন ডিলে tpd-এর চেয়ে বেশি হলে এক পালসেই আউটপুট বারবার টগল করে, শেষ অবস্থা অনিশ্চিত।

এড়ানোর শর্ত tp < tpd < T, যা নিশ্চিত করা কঠিন। আসল সমাধান: মাস্টার-স্লেভ বা এজ-ট্রিগারড ফ্লিপ-ফ্লপ।

  1. CLK = 1: মাস্টার J, K অনুসরণ করে; স্লেভ বন্ধ, তাই Q স্থির
  2. CLK → 0: মাস্টার স্থির হয়, স্লেভ তাকে কপি করে → ফলিং এজের পরে Q একবারই বদলায়; পালস চলাকালীন Q বদলাতে পারে না → রেস-অ্যারাউন্ড নেই

অসুবিধা: ওয়ানস-ক্যাচিং (1s-catching): CLK = 1 থাকার সময় J/K-এর ক্ষণিক গ্লিচও মাস্টার ধরে ফেলে; এজ-ট্রিগারড FF (7474 D, 74LS76 JK) এ সমস্যা এড়ায়।

হাই-ইল্ড
সংজ্ঞা কাউন্টার (Counter) ক্লক পালসে একটি নির্দিষ্ট ক্রমে অবস্থা বদলায়। মডুলাস (mod) = ভিন্ন অবস্থার সংখ্যা। n টি FF → সর্বোচ্চ 2ⁿ অবস্থা (গণনা 0 … 2ⁿ − 1); mod-N কাউন্টারে লাগে ⌈log₂N⌉ টি FF, এটি ক্লক ফ্রিকোয়েন্সিকে N দিয়ে ভাগ করে।

রিপল ডিলে: শেষ FF স্থির হয় n · tpd পরে → fmax = 1/(n · tpd)। ৪-বিট, tpd = 10 ns → 40 ns → 25 MHz। রিপলের কারণে ডিকোডিং গ্লিচও হয়।

রিসেট দিয়ে mod-N: একটি NAND অবস্থা N শনাক্ত করে অ্যাসিঙ্ক্রোনাস CLR′ চালায়। mod-6: 110-এ NAND(Q2, Q1)। mod-10 (ডিকেড): 1010-এ NAND(Q3, Q1)। অবস্থা N মাত্র কয়েক ns থাকে।

সিঙ্ক্রোনাস কাউন্টার: সব FF একই CLK পায়। T0 = 1, T1 = Q0, T2 = Q0Q1, T3 = Q0Q1Q2 (নিচের সব বিট 1 হলে বিটটি টগল করে)। ডাউন: Q̄ নাও। fmax = 1/(tpd + tAND + tsu), n-এর ওপর নির্ভর করে না।
