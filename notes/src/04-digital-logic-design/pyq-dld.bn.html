১K-map: পরীক্ষক যে ধাপগুলো দেখেন

৯টি পরীক্ষা
  1. গ্রে ক্রমে 00, 01, 11, 10 ম্যাপ আঁকো; প্রতিটি মিনটার্ম ঘরে 1 (SOP), অথবা প্রতিটি ম্যাক্সটার্ম ঘরে 0 (POS) বসাও
  2. গ্রুপ হবে ১, ২, ৪, ৮, ১৬ ঘরের (2ᵏ), শুধু আয়তাকার, কর্ণ বরাবর নয়; প্রান্ত ঘুরে মেলে, চার কোণও প্রতিবেশী
  3. আগে সেই 1-গুলো ঢাকো যারা কেবল একটি গ্রুপে যেতে পারে (অপরিহার্য প্রাইম ইমপ্লিক্যান্ট), তারপর বাকিগুলো যত কম ও যত বড় গ্রুপে সম্ভব
  4. প্রতিটি গ্রুপ পড়ো: যে চলক বদলায় না সেটি রাখো (1 → সাধারণ, 0 → প্রাইম), তারপর পদগুলো OR করো

K-map কেন? কম লিটারেল → কম গেট, কম খরচ ও শক্তি, দ্রুততর সার্কিট। এটি এমনভাবে ভাঁজ করা সত্যক সারণি যাতে পাশের ঘর এক বিটে আলাদা।

SOP সাম অফ প্রোডাক্টস: আগে AND পদ, তারপর OR। F = AB + AC + BC → AND-OR বা NAND-NAND।
POS প্রোডাক্ট অফ সামস: আগে OR পদ, তারপর AND। F = (A + B)(A + C)(B + C) → OR-AND বা NOR-NOR।
মনে রাখার কৌশল এই দুটি উদাহরণ একই ফাংশন: AB + AC + BC = (A + B)(A + C)(B + C), ৩-ইনপুট মেজরিটি, যা ফুল অ্যাডারের ক্যারিও (পাতা ৯)।

২Σm(0, 2, 6, 7, 8, 10, 14, 15)

দুবার এসেছে
প্রশ্ন F(A, B, C, D) = Σm(0, 2, 6, 7, 8, 10, 14, 15) রাশিটি ৪-চলকের K-map দিয়ে সরল করো।
যেখানে এসেছে: BPSC সহকারী প্রোগ্রামার · ১৯.০৭.২০২৩, আবার ১৯.০৭.২০২৬
  1. চার কোণ m0, 2, 8, 10: B = 0, D = 0 → B′D′
  2. বর্গ m6, 7, 14, 15: B = 1, C = 1 → BC
  3. F = BC + B′D′: দুটিই অপরিহার্য, ৪টি লিটারেল
পরীক্ষার ফাঁদ চার কোণ মিলে একটিই চতুষ্ক (quad)। দুটি জোড়া (A′B′D′ + AB′D′) লিখলে ফল ঠিক, কিন্তু ন্যূনতম নয়।

৩Σm(0, 2, 3, 7, 8, 10)

প্রশ্ন F(A, B, C, D) = Σm(0, 2, 3, 7, 8, 10) ৪-চলকের K-map দিয়ে সরল করো।
যেখানে এসেছে: MRA SCO · ২৪.০২.২০২৩
  1. আবার চার কোণ → B′D′
  2. m7-এর একমাত্র সঙ্গী m3 (m5, m6, m15 শূন্য) → A′CD
  3. F = B′D′ + A′CD

m3 চাইলে m2-এর সাথেও (A′B′C) জোড়া হয়, কিন্তু A′CD আগেই m3 ঢেকেছে: A′B′C যোগ করা বাড়তি।

৪Σm(2, 8, 9, 11, 13, 15)

২টি পরীক্ষা
প্রশ্ন ৩৬ F(A, B, C, D) = Σm(2, 8, 9, 11, 13, 15) ৪-চলকের K-map দিয়ে সরল করো। (একই পরীক্ষায় প্রশ্ন ছিল "K-map দিয়ে ন্যূনতম SOP আকারে মিনিমাইজ করো"।)
যেখানে এসেছে: BPDM AE (CSE) · ১০.০৫.২০২৪; টেলিটক AM (IT) · ২০২৩
  1. m2: চার প্রতিবেশী (m0, m3, m6, m10) সবাই 0 → একাই থাকবে: A′B′CD′
  2. m8: একমাত্র 1-প্রতিবেশী m9 → AB′C′
  3. m9, 11, 13, 15 → চতুষ্ক AD
  4. F = AD + AB′C′ + A′B′CD′ (৯টি লিটারেল)
মনে রাখার কৌশল আক্রমণের ক্রম: একা 1 → এক দিকেই যাওয়ার পথ আছে এমন 1 → বড় গ্রুপ। তাহলে কোনো গ্রুপ আর ভাঙতে হয় না।
পরীক্ষার ফাঁদ m2-কে "বাঁচাতে" কখনো 0-এর ওপর দিয়ে গ্রুপ টেনো না: m2 + m10 (B′CD′) ভুল, কারণ m10 = 0।

৫Σ(3, 5, 7, 9, 13, 14, 15)

৪৭তম BCS
প্রশ্ন ১২৮ F(A, B, C, D) = Σ(3, 5, 7, 9, 13, 14, 15) ৪-চলকের K-map দিয়ে সরল করো।
যেখানে এসেছে: ৪৭তম BCS (ICT)
  1. মাঝের চতুষ্ক m5, 7, 13, 15 → BD
  2. m3-এর সঙ্গী কেবল m7 → A′CD
  3. m14-এর সঙ্গী কেবল m15 → ABC
  4. m9-এর সঙ্গী কেবল m13 → AC′D
  5. F = BD + A′CD + ABC + AC′D
চারটি গ্রুপই অপরিহার্য
পরীক্ষার ফাঁদ BD চোখে পড়ার মতো গ্রুপ, কিন্তু m3, m9, m14 এর কিনারায় বসে থাকে এবং প্রত্যেকের নিজস্ব জোড়া লাগে। F লেখার আগে দেখে নাও প্রতিটি 1 কোনো গ্রুপে আছে।

গুনে যাচাই: BD (৪) + A′CD (২) + ABC (২) + AC′D (২) মিলে ৭টি আলাদা 1 ঢাকে; m7, m13, m15 ভাগাভাগি হয়েছে: ওভারল্যাপ বৈধ।

৬Σm(0, 3, 5, 7, 8, 10, 11, 12, 13, 14, 15)

৩টি পরীক্ষা
প্রশ্ন ৩৬ F(A, B, C, D) = Σm(0, 3, 5, 7, 8, 10, 11, 12, 13, 14, 15) ৪-চলকের K-map দিয়ে সরল করো।
যেখানে এসেছে: ব্যাংক AME · ০৮.০৫.২০২৬; ব্যাংক SO (IT) · ২৫.০৭.২০২৬; ৪৬তম BCS (ICT)
  1. CD = 11 কলাম → CD
  2. মাঝের চতুষ্ক → BD
  3. AB = 11, 10 সারির দুই প্রান্তের কলাম (ঘুরে মেলে) → AD′
  4. m0-এর সঙ্গী কেবল m8 (ওপর-নিচ ঘুরে) → B′C′D′
  5. F = AD′ + BD + CD + B′C′D′
মনে রাখার কৌশল ম্যাপ প্রায় ভরা? 0-গুলো গ্রুপ করো: F′ = Σm(1, 2, 4, 6, 9) = B′C′D + A′BD′ + A′CD′, তাই F = (B + C + D′)(A + B′ + D)(A + C′ + D): দ্রুত POS যাচাই।
পরীক্ষার ফাঁদ AB + AC দিয়েও m10, m12, m14 ঢাকা যায়, কিন্তু দুটি পদ লাগে; প্রান্ত-ঘোরা চতুষ্ক AD′ একাই তা করে।

৭K-map-এ SOP ও POS বসানো

সমাধানকৃত উদাহরণ
প্রশ্ন K-map-এ দেখাও (ক) F(A, B, C, D) = Σm(0, 1, 2, 3, 5, 6, 11, 12) এবং (খ) F = ΠM(0, 1, 2, 3, 5, 6, 11, 12); ন্যূনতম রূপ লেখো।
যেখানে এসেছে: প্লটিংয়ের উদাহরণ (পরীক্ষার নাম নেই)

(ক) SOP: ০, ১, ২, ৩, ৫, ৬, ১১, ১২ নম্বর ঘরে 1। m5, m6, m11-এর একটি করে সঙ্গী; m12-এর কেউ নেই।

F = A′B′ + A′C′D + A′CD′ + B′CD + ABC′D′

(খ) POS: ΠM 0-ঘরগুলোর তালিকা দেয়, তাই একই ঘরে 0, বাকিগুলোতে 1: F = Σm(4, 7, 8, 9, 10, 13, 14, 15)। আঁকা গ্রুপগুলোই 0-গ্রুপ, প্রতিটি যোগফল হিসেবে পড়ো (0 → সাধারণ, 1 → প্রাইম):

F = (A + B)(A + C + D′)(A + C′ + D)(B + C′ + D′)(A′ + B′ + C + D)

মনে রাখার কৌশল একই ঘর, দুবার পড়া: 1 হিসেবে → গুণফল পদ (1 = সাধারণ); 0 হিসেবে → যোগফল পদ (0 = সাধারণ)। প্রতিটি চিহ্ন উল্টে যায়, গ্রুপিং নয়।

৮ক্যানোনিকাল SOP → ক্যানোনিকাল POS

৪৬তম BCS
প্রশ্ন ৯৬ ক্যানোনিকাল SOP f(A, B, C, D) = Σ(1, 3, 5, 8, 11)-কে ক্যানোনিকাল POS-এ রূপান্তর করো।
যেখানে এসেছে: ৪৬তম BCS (ICT)
  1. ৪টি চলক → 2⁴ = ১৬টি সূচক, ০ থেকে ১৫
  2. 1 আছে ১, ৩, ৫, ৮, ১১-তে; বাকি প্রতিটি সূচক 0 (ম্যাক্সটার্ম)
  3. f = ΠM(0, 2, 4, 6, 7, 9, 10, 12, 13, 14, 15)
  4. যাচাই: ৫টি মিনটার্ম + ১১টি ম্যাক্সটার্ম = ১৬ ✓
সূচকABCDম্যাক্সটার্ম
M00000(A + B + C + D)
M20010(A + B + C′ + D)
M91001(A′ + B + C + D′)
M151111(A′ + B′ + C′ + D′)

ম্যাক্সটার্মে 0 বিট সাধারণ, 1 বিট প্রাইম লেখা হয় (মিনটার্মের উল্টো)। এগারোটি ম্যাক্সটার্ম পুরো লিখলেই প্রশ্নের "ক্যানোনিকাল POS"।

৯মিনিমাইজ করো f = Π(2, 3, 7, 12, 13, 14, 15)

প্রশ্ন ৯৫ ফাংশনটি মিনিমাইজ করো: f(A, B, C, D) = Π(2, 3, 7, 12, 13, 14, 15)।
যেখানে এসেছে: ৪৬তম BCS (ICT)
  1. Π দেয় 0-এর তালিকা; 1 আছে Σm(0, 1, 4, 5, 6, 8, 9, 10, 11)-এ
  2. SOP: F = AB′ + A′C′ + A′BD′ (৭ লিটারেল)
  3. POS: F = (A′ + B′)(A + B + C′)(A + C′ + D′) (৮ লিটারেল)
পরীক্ষার ফাঁদ Π-প্রশ্নের উত্তর POS-এ দেওয়াই ভালো; সাথে SOP-ও দাও। m7 চাইলে m3-এর বদলে m15-এর সাথে জোড়া হয়, ফল (B′ + C′ + D′): সমান ন্যূনতম।

১০৩-চলকের ম্যাপ: F = A′B′C + AB′C + ABC′ + ABC

প্রশ্ন ১২৭ F = A′B′C + AB′C + ABC′ + ABC রাশিটি ৩-চলকের K-map দিয়ে সরল করো।
যেখানে এসেছে: ৪৬তম BCS (CSE)

মিনটার্ম ১, ৫, ৬, ৭। BC = 01 কলাম → B′C; A = 1, B = 1 → AB।

F = B′C + AB

বীজগাণিতিক যাচাই: B′C(A′ + A) + AB(C′ + C) = B′C + AB ✓

১৮সর্বজনীন গেট: প্রমাণ + শুধু NAND সার্কিট

২টি পরীক্ষা
প্রশ্ন সর্বজনীন গেট কী? প্রমাণ করো NAND একটি সর্বজনীন গেট। শুধু NAND গেট দিয়ে F = AB + CD + E তৈরি করো।
যেখানে এসেছে: একটি ব্যাংকের সহকারী প্রোগ্রামার লিখিত; ৪৫তম BCS টেকনিক্যাল ক্যাডার (ICT-281) · ৩১.০১.২০২৪

সর্বজনীন গেট শুধু নিজের কপি দিয়ে NOT, AND, OR, অর্থাৎ যেকোনো বুলিয়ান ফাংশন তৈরি করতে পারে: NAND ও NOR।

গেটশুধু NAND রূপNAND
NOT(A · A)′ = A′1
AND((AB)′)′ = AB2
OR(A′ · B′)′ = A + B3
NOR / XOROR + NOT / ৪-গেট সার্কিট4 / 4

NOT, AND, OR একটি সম্পূর্ণ সেট, তাই NAND সর্বজনীন। F-এর জন্য: ডি মরগান দিয়ে F = ((AB + CD + E)′)′ = ((AB)′ · (CD)′ · E′)′ → NAND(A,B), NAND(C,D), NAND(E,E) = E′, তারপর ৩-ইনপুট NAND।

মনে রাখার কৌশল SOP → NAND-NAND: সব AND ও শেষের OR-কে NAND বানাও; সরাসরি OR-এ যাওয়া একক লিটারেলের (E) জন্য একটি ইনভার্টার লাগে।

১৯৪টি NAND দিয়ে XOR · সার্কিট পড়া
