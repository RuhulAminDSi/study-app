1K-map: the Method Examiners Mark

9 papers
  1. Draw the map in Gray order 00, 01, 11, 10; put a 1 in each minterm cell (SOP), or a 0 in each maxterm cell (POS)
  2. Groups of 1, 2, 4, 8, 16 cells (2ᵏ), rectangles only, no diagonals; edges wrap and the 4 corners are neighbours
  3. Cover first the 1s that can join only one group (essential prime implicants), then the leftovers with as few, as large groups as possible
  4. Read each group: keep the variables that stay constant (1 → plain, 0 → primed) and OR the terms

Why a K-map? Fewer literals → fewer gates, lower cost and power, faster circuit. It is the truth table folded so that neighbours differ in one bit.

SOP Sum of Products: AND terms are formed first, then ORed. F = AB + AC + BC → AND-OR, or NAND-NAND.
POS Product of Sums: OR terms are formed first, then ANDed. F = (A + B)(A + C)(B + C) → OR-AND, or NOR-NOR.
Memory trick Those two textbook examples are the same function: AB + AC + BC = (A + B)(A + C)(B + C), the 3-input majority, which is also the full-adder carry (sheet 9).

7Plotting SOP and POS on a K-map

worked example
Q Represent on a K-map (a) F(A, B, C, D) = Σm(0, 1, 2, 3, 5, 6, 11, 12) and (b) F = ΠM(0, 1, 2, 3, 5, 6, 11, 12); give the minimal forms.
Asked: worked example on plotting (no paper named)

(a) SOP: put 1 in cells 0, 1, 2, 3, 5, 6, 11, 12. m5, m6, m11 have one partner each; m12 has none.

F = A′B′ + A′C′D + A′CD′ + B′CD + ABC′D′

(b) POS: ΠM lists the 0 cells, so the same cells get 0 and the rest 1: F = Σm(4, 7, 8, 9, 10, 13, 14, 15). Group the 0s exactly as drawn and read each group as a sum (0 → plain, 1 → primed):

F = (A + B)(A + C + D′)(A + C′ + D)(B + C′ + D′)(A′ + B′ + C + D)

Memory trick Same cells, read twice: as 1s → product terms (1 = plain); as 0s → sum terms (0 = plain). Every symbol flips, the grouping does not.

13Boolean function: definition + simplification

Q20(b) What is a Boolean function? How can we simplify F = A′B′C + A′BC + AB′? 5 marks
Asked: 45th BCS (CSE-971) · 31.01.2024
Boolean function An expression of binary variables, the operators AND, OR, NOT, the constants 0/1 and brackets; for every input combination it is 0 or 1. It can be shown as a truth table, an expression or a gate circuit.
  1. A′B′C + A′BC = A′C(B′ + B) = A′C · 1 = A′C distributive, complement, identity
  2. F = A′C + AB′ = Σm(1, 3, 4, 5); 8 literals → 4

14Algebraic simplification (two questions)

BPSC SAE
Q Simplify (i) F = A′B′C′ + B′CD′ + A′BCD′ + AB′C′ and (ii) F = AB′CD′ + A′B′C′D + A′BC′D + AB′C′D′.
Asked: BPSC Sub-Assistant Engineer · 2021
(i) ✍
  1. A′B′C′ + AB′C′ = B′C′
  2. B′CD′ + A′BCD′ = CD′(B′ + A′B) = CD′(B′ + A′) redundant literal
  3. B′C′ + B′CD′ = B′(C′ + D′)
  4. F = B′C′ + B′D′ + A′CD′
(ii) ✍
  1. AB′CD′ + AB′C′D′ = AB′D′(C + C′) = AB′D′
  2. A′B′C′D + A′BC′D = A′C′D(B′ + B) = A′C′D
  3. F = AB′D′ + A′C′D
Memory trick Pair terms that differ in exactly one letter: that letter vanishes (X + X′ = 1). Check (i) on a K-map: Σm(0, 1, 2, 6, 8, 9, 10) gives the same three groups.

17Why binary? What is Boolean logic?

Q1 Why is binary logic used for digital systems?
Asked: BWDB Assistant Programmer · 2018; "What is Boolean logic?" in a bank IT viva
  • Two-state devices: a transistor is cut off or saturated, a switch open or closed: cheap, tiny and reliable
  • Noise immunity: the circuit only decides HIGH or LOW, so a noisy signal is restored without error
  • Complete mathematics: Boolean algebra (AND, OR, NOT) designs and simplifies any circuit
  • Simplest arithmetic and storage: 1 + 1 = 10; one bit = one flip-flop or one magnetic domain
Boolean logic (viva) Logic with two values, True (1) and False (0), combined by AND, OR, NOT. Boole (1854) gave the algebra; Shannon (1938) applied it to switching circuits.

18Universal gates: proof + NAND-only circuit

2 papers
Q What is a universal gate? Prove that NAND is a universal gate. Implement F = AB + CD + E using NAND gates only.
Asked: a bank Assistant Programmer written; 45th BCS Technical Cadre (ICT-281) · 31.01.2024

A universal gate can build NOT, AND and OR, and therefore any Boolean function, using copies of itself only: NAND and NOR.

GateNAND-only formNAND
NOT(A · A)′ = A′1
AND((AB)′)′ = AB2
OR(A′ · B′)′ = A + B3
NOR / XOROR + NOT / 4-gate circuit4 / 4

NOT, AND, OR form a complete set, so NAND is universal. For F: F = ((AB + CD + E)′)′ = ((AB)′ · (CD)′ · E′)′ by De Morgan → NAND(A,B), NAND(C,D), NAND(E,E) = E′, then a 3-input NAND.

Memory trick SOP → NAND-NAND: turn every AND and the final OR into NAND; a lone literal (E) going straight to the OR needs one inverter.

21Half adder, full adder, encoder

viva + MCQ

Half adder adds 2 bits: S = A ⊕ B, C = AB.

Full adder adds 3 bits (A, B, Cin): Sum = A ⊕ B ⊕ Cin, Cout = AB + Cin(A ⊕ B) = AB + ACin + BCin

MCQ (49th BCS ICT · 2025): carry of x, y, z = xy + xz + yz, the majority function.

Viva (NTRCA · 2023): "Half and full adder?" A full adder adds three bits; "two bits plus a carry out" describes the half adder. "Outputs of an encoder with 10 inputs?" → 4 (⌈log₂10⌉; decimal-to-BCD, 74147).

Exam trap 2¹⁰ = 1024 is the reverse rule: a decoder with n inputs has 2ⁿ outputs; an encoder with 2ⁿ inputs has n outputs.

24Traffic-light FSM: how many flip-flops?

3 sources
Q4(a) A traffic signal cycles GREEN 70 s, YELLOW 5 s, RED 75 s. The only input to the FSM is a clock with a 5-second period. Find the minimum number of flip-flops.
Asked: Petrobangla AM (CSE) · 31.05.2024; BOGMC (Petrobangla) AM · 2024
  1. States = 70/5 + 5/5 + 75/5 = 14 + 1 + 15 = 30
  2. 2⁴ = 16 < 30 ≤ 32 = 2⁵
  3. Minimum = ⌈log₂ 30⌉ = 5 flip-flops
Exam trap Not 2 (for three colours): the clock is the only input, so the FSM must count time in states. One-hot coding would need 30.

MCQ (49th BCS ICT · 2025): a 4-bit BCD ripple counter has 10 states (0000–1001, then reset), not 16.

27Viva rapid-fire

  • Boolean logic? two-valued logic, AND/OR/NOT
  • Why binary? two stable, noise-proof states
  • Half adder? 2 bits: S = A⊕B, C = AB
  • Full adder? 3 bits: 2 HAs + OR
  • Encoder, 10 inputs? 4 outputs
  • Decoder, 3 inputs? 8 outputs
  • Universal gates? NAND and NOR
  • XOR from NAND? 4 gates
  • MUX? data selector, 2ⁿ : 1
  • Flip-flop? 1-bit memory, clocked
  • Race-around? JK with J = K = 1, cure: master–slave
  • Mod-10 counter? 4 flip-flops
