A logic gate is an electronic circuit that produces one binary output from one or more binary inputs by a fixed rule. A truth table lists the output for all 2ⁿ input rows. 3 basic gates: AND, OR, NOT; NAND, NOR universal; XOR, XNOR derived.

Q2 EX-OR gate with truth table. / X-OR and X-NOR truth table and diagram.17th NTRCA CSE (2023) · BCPCL JI 2019 · Cadet College Lecturer(ICT) 2025

XOR is 1 when the inputs differ: A⊕B = A′B + AB′. XNOR is 1 when they are equal: (A⊕B)′ = AB + A′B′ (the coincidence gate). With n inputs XOR = 1 for an odd number of 1s → parity generator.

Q3 Compare TTL and CMOS in speed, noise and power. / Characteristics of digital ICs.Hydrocarbon Unit AD(ICT) 2025 · Combined Bank AME/AHE 2023

TTL (74xx): ~10 ns, noise margin ≈ 0.4 V, mW per gate even when idle. CMOS (74HC/4000): similar speed, noise margin ≈ 30 % of VDD, static power ≈ 0 (power only while switching). IC characteristics: fan-in, fan-out, propagation delay, power dissipation, noise margin.

A universal gate alone builds every Boolean function, since it makes the complete set {NOT, AND, OR}: proof = draw those three. Advantages: one IC type, cheaper stock, fastest/smallest gate in TTL and CMOS.

→ 3 two-input NAND + 1 three-input NAND

Q13 What is the 2's complement method? Subtract 27 from 55 using 2's complement.BTCL JAM 2024

2's complement of an n-bit number = invert every bit (1's complement) + 1 (= 2ⁿ − x). To compute A − B, add A and the 2's complement of B. A carry out of the MSB is discarded; if the MSB of the result is 1 the answer is negative, and its size is the 2's complement of the result.

Q20 Prove: (i) (A ⊕ B)′ = AB + A′B′; (ii) if F = X′Y + XYZ′ then F·F′ = 0; (iii) (A + B)′·(A′ + B)′ = 0 and A + A′B + (AB)′ = 1.16th NTRCA CSE (2019) · 17th NTRCA School (2023) · 15th NTRCA Computer Operation (2019)

10K-map: the most-asked worked problem

31 exams ask K-maps
Q27 Simplify F(A, B, C, D) = Σm(0, 3, 5, 7, 8, 10, 11, 12, 13, 14, 15) using a 4-variable K-map.46th BCS ICT · Combined Bank AME 2026 · Combined Bank AME/AE(IT) 2026(Jan) · Combined Bank SO(IT) 2026
  1. Rows and columns in Gray order 00, 01, 11, 10, so neighbours differ in one bit.
  2. Biggest groups first (8, 4, 2), powers of 2 only; edges wrap.

Q46 Draw a MOD-12 ripple counter and explain it. / Draw a MOD-12 up counter using only T flip-flops.46th BCS CSE · BUET M.Sc. April 2017

2³ < 12 ≤ 2⁴ → 4 flip-flops. Count 0–11; the first state with Q3 = Q2 = 1 is 12 = 1100 → NAND(Q3, Q2) drives every CLR, so 12 lasts a moment and the counter returns to 0000.

3 flip-flops (2² < 6 ≤ 2³); first state with Q2 = Q1 = 1 is 6 = 110 → NAND(Q2, Q1) → CLR. Sequence 000 … 101, then back to 000.
