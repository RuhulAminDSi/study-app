3Nodal Analysis (Node-Voltage Method)

high-yield
Idea Unknowns are the node voltages measured from one reference node (ground). Write KCL at every other node, with each branch current written by Ohm's law as (Vthis − Vother)/R.
  1. Reference = node with most branches
  2. Name the rest V1, V2 … (n − 1 unknowns)
  3. KCL: Σ out via R = Σ source current in
  4. Solve (substitution or Cramer)
  5. Branch currents from node voltages
Memory trick "My node minus my neighbour, over the resistor": write every resistor current as leaving the node you stand on; the signs then take care of themselves.
Worked example ✍ Find V1, V2 and every branch current.
  1. KCL at V1: (V1 − 20)/5 + V1/10 + (V1 − V2)/4 = 0 → ×20: 11V1 − 5V2 = 80
  2. KCL at V2: (V2 − V1)/4 + V2/2 = 2 → ×4: −V1 + 3V2 = 8
  3. V1 = 3V2 − 8 → 11(3V2 − 8) − 5V2 = 80 → 28V2 = 168 → V2 = 6 V, V1 = 10 V
  4. Currents: 5 Ω: (20 − 10)/5 = 2 A · 10 Ω: 1 A · 4 Ω: 1 A · 2 Ω: 3 A. Check KCL at V2: 1 + 2 = 3 ✓
By inspection: [G][V] = [I]
Gkk = Σ conductances at node k; Gkj = −(conductance between k and j); [I] = source currents in (20 V/5 Ω → 4 A):
0.55V1 − 0.25V2 = 4 · −0.25V1 + 0.75V2 = 2
Exam trap A resistor in series with a current source never appears in the nodal equation: the source fixes that branch current. [G] is symmetric only when there are no dependent sources.
IT link Circuit simulators (SPICE and its descendants) use Modified Nodal Analysis: they build this very [G] matrix for thousands of nodes and solve it numerically, like a linear-algebra library.

Supernode: a voltage source between two non-reference nodes

Enclose both nodes and the source. Write one KCL for the whole supernode plus the constraint from the source.

KCL: V1/2 + V2/4 = 9

Constraint: V1 − V2 = 6

→ V1/2 + (V1 − 6)/4 = 9 → 3V1 = 42 → V1 = 14 V, V2 = 8 V

Check: 7 A + 2 A = 9 A ✓. If the V-source touches the reference, that node voltage is simply known.

4Mesh Analysis (Mesh-Current Method)

high-yield
Idea Give every window (mesh) a mesh current, all clockwise. Write KVL round each mesh. An element shared by two meshes carries the difference of their currents. Works for planar circuits only.

Mesh 1: −24 + 2I1 + 8(I1 − I2) = 0

→ 10I1 − 8I2 = 24

Mesh 2: 8(I2 − I1) + 5I2 + 6 = 0

→ −8I1 + 13I2 = −6

Cramer: Δ = 130 − 64 = 66

I1 = 264/66 = 4 A · I2 = 132/66 = 2 A

8 Ω carries I1 − I2 = 2 A downward.

Checks ✍ Power: the 24 V source gives 24 × 4 = 96 W = 32 (2 Ω) + 32 (8 Ω) + 20 (5 Ω) + 12 W absorbed by the 6 V source (I2 enters its + end: it is being charged) ✓. Nodal on the same circuit: one unknown, V = 8 × 2 = 16 V: (16 − 24)/2 + 16/8 + (16 − 6)/5 = −4 + 2 + 2 = 0 ✓, so 1 equation instead of 2.
By inspection: [R][I] = [V]
Rkk = total R round mesh k · Rkj = −(shared R)
Vk = source rises along the mesh current:
10I1 − 8I2 = 24 · −8I1 + 13I2 = −6
Exam trap A mesh current is not always a branch current: in a shared branch the real current is I1 − I2. A resistor in parallel with a voltage source does not change any mesh current outside it.

EC · Analysis & TheoremsSupermesh · Superposition

Supermesh: a current source shared by two meshes

KVL round the outer path (skip the current source): 6I1 + 4I2 = 28

Constraint (2 A upward in the shared branch): I2 − I1 = 2

→ 10I1 + 8 = 28 → I1 = 2 A, I2 = 4 A

A current source on the outer edge of a mesh simply gives that mesh current.

Memory trick: duality Nodal ↔ mesh: KCL ↔ KVL · V ↔ I · G ↔ R · supernode ↔ supermesh · current sources easy ↔ voltage sources easy · open ↔ short · Norton ↔ Thevenin.

5Superposition Theorem

high-yield
Statement In a linear network with several independent sources, any branch current or voltage is the algebraic sum of the responses to each independent source acting alone, with all the other independent sources turned off.
Worked example ✍ Current I in the 3 Ω resistor: 18 V alone → I′ = 18/(6 + 3) = 2 A; 3 A alone → current divider I″ = 3 × 6/(6 + 3) = 2 A; both downward, so I = 4 A. Nodal check: (V − 18)/6 + V/3 = 3 → V = 12 V → I = 12/3 = 4 A ✓.
Exam trap Power does not superpose: P(3 Ω) = 4² × 3 = 48 W, but 2² × 3 + 2² × 3 = 24 W ✗. Power ∝ I² is not linear. Find the total current first, then the power.

Where it is used: a transistor amplifier is analysed twice, DC bias and AC signal separately (superposition); sources at different frequencies are handled one frequency at a time (lesson 3). Not valid for diodes or other non-linear elements.

Linearity = two properties
Homogeneity: k × input → k × output (18 V → 36 V makes I′ = 4 A, so I = 6 A)
Additivity: response to (x1 + x2) = response to x1 + response to x2
Memory trick "One ON, rest OFF, add with signs." Number of sub-circuits = number of independent sources; dependent sources stay ON in every one.

6Thevenin's Theorem

most asked
Statement Any linear two-terminal network, seen from terminals a–b, can be replaced by a voltage source Vth in series with Rth. Vth = open-circuit voltage at a–b; Rth = resistance seen into a–b with all independent sources turned off. (Thévenin, 1883; Helmholtz found it in 1853.)
  1. Remove the load; mark a and b
  2. Vth = Voc across open a–b (any method: divider, nodal, mesh, superposition)
  3. Rth: independent sources off and look into a–b; or Rth = Voc/Isc; or apply a test source (needed with dependent sources)
  4. Reconnect the load: IL = Vth/(Rth + RL)
Worked example ✍ Open a–b: no current in 2 Ω, so Vth = 24 × 3/(6 + 3) = 8 V. Short the 24 V: Rth = (6 ‖ 3) + 2 = 2 + 2 = 4 Ω.

One equivalent, any number of loads: that is why examiners love Thevenin.
IT link A battery, USB port or phone charger is a Thevenin source: EMF = Vth, internal resistance = Rth. Terminal voltage V = Vth − I·Rth sags as the load draws more current.

EC · Analysis & TheoremsNorton · Source transformation

Thevenin with a dependent source (written favourite)

Voc: KCL at a: iₓ + 0.5iₓ = V/4 with iₓ = (10 − V)/2 → 0.75(10 − V) = 0.25V → Voc = 7.5 V

Isc: a–b shorted, V = 0 → iₓ = 5 A, 4 Ω carries 0 → Isc = 1.5 × 5 = 7.5 A

Rth = Voc/Isc = 1 Ω, not 2 ‖ 4 = 1.33 Ω: the dependent source (a CCCS) changes Rth.

Exam trap Never switch off a dependent source when finding Rth; with one, Rth may even be negative. The equivalent is exact only at the terminals, not for power lost inside.

7Norton's Theorem

Statement The same two-terminal network can be replaced by a current source IN in parallel with RN. IN = short-circuit current through a–b; RN = Rth. (E. L. Norton, Bell Labs, 1926.)
Memory trick "TVS · NIP": Thevenin = Voltage in Series; Norton = current (I) in Parallel. The IN arrow points to a, the + end of Vth.

Same network as p. 6: short a–b → R = 6 + (3 ‖ 2) = 7.2 Ω, source current 24/7.2 = 3.33 A, divider into 2 Ω: 3.33 × 3/5 = IN = 2 A = Vth/Rth = 8/4 ✓.

Rule (lesson 1): Vs in series with R ⇄ Is = Vs/R in parallel with the same R. Used repeatedly, it collapses a ladder to its Thevenin form without any equations:

9Maximum Power Transfer Theorem

high-yield
Statement A linear DC network delivers maximum power to a resistive load when RL = Rth. Then Pmax = Vth²/(4Rth) and the efficiency is only 50%.
Derivation ✍
PL = I²RL = Vth²RL/(Rth + RL)²
dPL/dRL = Vth²[(Rth + RL)² − 2RL(Rth + RL)]/(Rth + RL)⁴ = 0
→ Rth + RL = 2RL → RL = Rth
Pmax = Vth²Rth/(2Rth)² = Vth²/4Rth
η = RL/(RL + Rth) = 1/2
RL (Ω)124816
PL (W)2.563.5643.562.56
η (%)2033506780
Memory trick RL and Rth²/RL give the same power (1 Ω and 16 Ω, 2 Ω and 8 Ω). "Match for max, pay a 50% tax."
Exam trap If RL is fixed and the source resistance can be chosen, load power is maximum at Rs = 0, not Rs = RL. AC: ZL = Zth* (conjugate), Pmax = |Vth|²/4Rth; a purely resistive AC load takes RL = |Zth|.
IT link Matching is for signals, never for power grids (50% loss): 50 Ω RF coax and antennas, 75 Ω TV/CCTV coax, 100 Ω Ethernet twisted pair. It also stops reflections on the line.

10Reciprocity & Millman's Theorem

Reciprocity ✍ In a linear, bilateral network with a single source, V at port 1 giving I in a short at port 2 means the same V at port 2 gives the same I at port 1 (fails with dependent sources, diodes, transistors). Check on a ladder 2 Ω (series) – 3 Ω (shunt) – 6 Ω (series). 12 V at port 1: 12/(2 + 3‖6) = 3 A, into 6 Ω: 3 × 3/9 = 1 A. 12 V at port 2: 12/(6 + 3‖2) = 1.67 A, into 2 Ω: 1.67 × 3/5 = 1 A ✓
Millman ✍ Parallel branches (Vk in series with Rk): V = Σ(Vk/Rk) / Σ(1/Rk). 12 V/2 Ω, 6 V/3 Ω and a plain 6 Ω: V = (6 + 2 + 0)/(½ + ⅓ + ⅙) = 8 V, Req = 1 Ω.

11Star–Delta (Y–Δ) Transformation

written favourite
Idea A Δ (delta, π) and a Y (star, T) of resistors are equivalent when the resistance between every pair of terminals is the same. Use it when resistors are neither in series nor in parallel (bridges, lattices).
Δ → Y
Ra = RabRca / (Rab + Rbc + Rca)
Rb = RabRbc / ΣΔ · Rc = RbcRca / ΣΔ
Y → Δ with S = RaRb + RbRc + RcRa:
Rab = S/Rc · Rbc = S/Ra · Rca = S/Rb

Balanced (all equal): RY = RΔ/3, RΔ = 3RY

Memory trick Δ → Y: "the two arms touching the node, multiplied, over the sum of all three" (looks like product/sum of parallel, so Y is smaller). Y → Δ: "sum of the pair-products over the opposite arm" (always bigger).
Worked example ✍ Find Rab.
  1. Δ(a, c, d): 5, 10, 10 → Σ = 25
  2. Ra = 5×10/25 = 2 · Rc = 5×10/25 = 2 · Rd = 10×10/25 = 4 Ω
  3. Now series–parallel: (2 + 6) ‖ (4 + 4) = 8 ‖ 8 = 4 Ω
  4. Rab = 2 + 4 = 6 Ω
Balanced Wheatstone bridge If P/Q = R/S, the middle (galvanometer) arm carries no current: drop it. 10, 20 | 30, 60 → Rab = 30 ‖ 90 = 22.5 Ω, whatever the middle resistor.
Cube of 12 equal RReq
across a body diagonal5R/6
across a face diagonal3R/4
across one edge7R/12
Exam trap Check for a balanced bridge first (then no Y–Δ work). Each Y resistor is smaller than both Δ resistors next to it; a bigger value means a wrong divisor.
