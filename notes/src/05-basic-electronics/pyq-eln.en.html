1n-Channel JFET: Working Principle & Regions

written ×2
Question Explain the working principle of an n-channel JFET for various values of VGS and VDS.
Bangladesh Bank AME (BIBM) · 04.02.2023 · Q10(b) · also asked elsewhere with "operating regions"

A JFET is a voltage-controlled, unipolar device. The gate is a reverse-biased p–n junction, so IG ≈ 0 and Rin ≈ 10⁸–10¹⁰ Ω.

  1. VGS = 0, small VDS: channel fully open; ID rises linearly (ohmic region, a resistor)
  2. VGS = 0, VDS rising: reverse bias is largest at the drain end, so the depletion layers grow wedge-shaped. At VDS = |VP| they meet: pinch-off; ID levels at IDSS
  3. VGS negative: channel narrower everywhere; pinch-off at VDS = VGS − VP, lower saturated ID
  4. VGS ≤ VGS(off) = VP: channel closed, ID ≈ 0: cut-off
  5. Very large VDS: avalanche breakdown at the drain end
Region (VP < 0)ConditionBehaviour
Cut-offVGS ≤ VPID ≈ 0, open switch
Ohmic (triode)VDS < VGS − VPvoltage-controlled R
Saturation (pinch-off)VDS ≥ VGS − VPID = IDSS(1 − VGS/VP)²
Memory trick JFET = a garden hose: VGS squeezes it, VDS pinches the drain end; squeeze fully (VP) and flow stops. Normally ON.
Exam trap A JFET gate is not insulated (that is the MOSFET) and a JFET has no Vth: it conducts at VGS = 0 and cuts off at VGS(off) = VP.

2BJT: Cut-off, Active & Saturation Regions

written ×2
Question Describe the cut-off, saturation and active regions of operation of a transistor with a diagram.
Bangladesh Bank AME (BIBM) · 04.02.2023 · Q10(a)  ·  also asked in a recruitment paper with the CE load line
  1. Load line (KVL): VCE = VCC − ICRC, from (VCC, 0) to (0, VCC/RC); Q slides along it as IB changes
  2. Cut-off: line meets the IB = 0 curve; only leakage ICEO flows, VCE ≈ VCC: an open switch
  3. Saturation: line meets IB(sat); IC(sat) ≈ VCC/RC, VCE = Vknee ≈ 0.2 V; more IB cannot raise IC: a closed switch
  4. Active: in between; IC = βIB, the transistor amplifies (Q mid-way for full swing)
RegionB–EC–Bnpn valuesUse
Cut-offreversereverseIB = 0, IC = ICEOswitch OFF
ActiveforwardreverseVBE ≈ 0.7 V, IC = βIBamplifier
SaturationforwardforwardVCE ≈ 0.2 V, IC < βIBswitch ON
Worked example ✍ VCC = 12 V, RC = 2 kΩ, β = 100, IB = 43 µA → IC = 4.3 mA, VCE = 3.4 V: active. IB = 215 µA → βIB = 21.5 mA > IC(sat) = 11.8/2k = 5.9 mA: saturated.
α and β (MCQ) IE = IB + IC; α = IC/IE, β = IC/IB = IC/(IE − IC) → β = α/(1 − α), α = β/(1 + β). Asked with options β = α/(1+α), 1 − α, α = β², α/(1 − α) → (d). α = 0.98 → β = 49.
Exam trap In saturation IC = βIB is false: the circuit caps IC at ≈ VCC/RC. BJT "saturation" (switch ON) is not FET "saturation" (the flat, amplifying region).

3Counter-Type (Digital-Ramp) ADC

written
Question Draw an ADC circuit which converts an analog signal to a digital signal, and explain it.
Petrobangla Assistant Manager (IT) (BUET) · 16.09.2022 · Q6

An ADC turns a voltage Vin into an n-bit number. The counter-type ADC counts clock pulses, turns the count back into a voltage with a DAC, and stops the moment that voltage passes Vin.

  1. Start: counter cleared, VDAC = 0 < Vin, comparator HIGH
  2. HIGH opens the AND gate: clock pulses reach the counter
  3. DAC output rises as a staircase, 1 LSB per clock
  4. VDAC > Vin → comparator LOW → clock blocked
  5. Control latches the count (the output) and clears the counter
Worked example ✍ Step = Vref/2ⁿ. 8-bit, Vref = 5.12 V, 1 MHz clock, Vin = 3.01 V: step = 20 mV; counting stops at the first N with 0.02N > 3.01 → N = 151 = 1001 0111 (VDAC = 3.02 V), after 151 µs. Worst case (2ⁿ − 1) clocks = 255 µs.

Other ADCs: flash = 1 clock, 2ⁿ − 1 comparators (fastest) · SAR = n clocks, fixed (most MCUs) · dual-slope = slowest, rejects noise (multimeters). Sample at fs ≥ 2fmax (Nyquist).

Memory trick Counter ADC = "climb the stairs until your head hits the ceiling" (Vin); SAR = binary search, MSB first.
Exam trap The counter ADC's conversion time is not constant: it grows with Vin. A fixed n-clock time belongs to SAR.

5Filters

BPSC viva 2023
Viva Can you explain low-pass and band-pass signals / filters? (Asst. Maintenance Engineer)
  • Low-pass (series R, shunt C): passes f < fc; fc = 1/(2πRC). High-pass (series C, shunt R): f > fc
  • −3 dB = half power = 0.707 Vmax; 1st order rolls off 20 dB/decade
  • Band-pass: f1–f2; BW = f2 − f1, f0 = √(f1f2), Q = f0/BW
  • Low-pass signal = baseband (speech); band-pass signal = around a carrier (AM/FM)

7Physics: E vs B Field · Coulomb's Law

45th BCS written
Question Mention the differences between electric field and magnetic field. Two charges Q1 = 5 nC and Q2 = 12 nC are 7 μm apart in vacuum. Find the force exerted on Q2 by Q1.
45th BCS Written Technical Cadre (ICT-281) · 31.01.2024 · Q27(a)
PointElectric field EMagnetic field B
Sourceany charge (at rest too)moving charges, magnets, changing E
Acts onevery charge: F = qEonly moving charges: F = q(v × B)
Workcan do work on qdoes no work (F ⊥ v)
Field linesstart on +, end on −closed loops (∇·B = 0)
UnitN/C = V/mtesla (T) = Wb/m²
Solution ✍ F = kQ1Q2/r², k = 1/(4πε0) = 9 × 10⁹ N·m²/C²
= 9 × 10⁹ × (5 × 10⁻⁹)(12 × 10⁻⁹) / (7 × 10⁻⁶)²
= (9 × 10⁹ × 6 × 10⁻¹⁷) / (4.9 × 10⁻¹¹)
= 5.4 × 10⁻⁷ / 4.9 × 10⁻¹¹ = 1.10 × 10⁴ N, repulsive, along the line from Q1 to Q2.
Exam trap Convert first: nC = 10⁻⁹ C, μm = 10⁻⁶ m → r² = 4.9 × 10⁻¹¹ m². ≈ 11 kN is right (only 7 μm apart). The numerical carries marks: don't stop at the differences.

8Gauss's Law

45th BCS written
Question State and explain Gauss's law. 45th BCS · 31.01.2024 · Q27(b)

Statement: the total electric flux through any closed surface = net enclosed charge ÷ ε0: ∮ E · dA = Qenc/ε0 (∮ D · dA = Qenc).

  • Charges outside the surface add zero net flux (their lines enter and leave)
  • Shape of the surface does not matter: pick one where E is constant and ⊥
  • Point charge: E(4πr²) = Q/ε0 → E = Q/(4πε0r²): Coulomb's law follows
  • Line λ: E = λ/(2πε0r) · sheet σ: E = σ/2ε0

9Maxwell's Equations

45th BCS written
Question Write Maxwell's equations in differential and integral forms for (i) static EM fields, (ii) time-varying EM fields. 45th BCS · 31.01.2024 · Q27(b)
LawDifferential formIntegral form
Gauss (E)∇ · D = ρv∮ D · dS = Qenc = ∫ ρv dv
Gauss (B)∇ · B = 0∮ B · dS = 0
Faraday∇ × E = −∂B/∂t∮ E · dl = −(d/dt) ∫ B · dS
Ampère–Maxwell∇ × H = J + ∂D/∂t∮ H · dl = ∫ (J + ∂D/∂t) · dS

(i) Static fields: drop the highlighted terms → ∇ × E = 0, ∮ E · dl = 0, ∇ × H = J, ∮ H · dl = Ienc · (ii) Time-varying: all four as written

  • Only the two curl laws change; ∂D/∂t = displacement current
  • Media: D = εE, B = μH, J = σE
  • Free space (ρ = 0, J = 0): the equations give a wave at c = 1/√(μ0ε0) ≈ 3 × 10⁸ m/s
Memory trick "Two divs, two curls": div D = charge, div B = nothing; curl E = minus B-dot, curl H = J plus D-dot. Integral form = the same law via the divergence (div) and Stokes (curl) theorems.
Exam trap ∇ × E = 0 holds only for static fields. In the time-varying set, missing ∂D/∂t (Maxwell's own addition, 1865) loses the marks.
