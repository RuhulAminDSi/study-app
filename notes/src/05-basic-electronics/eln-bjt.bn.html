১গঠন: তিন স্তর, দুই জাংশন

MCQ-র প্রিয়
সংজ্ঞা BJT হলো তিনটি ডোপ করা অঞ্চল, ইমিটার (E), বেস (B), কালেক্টর (C), যারা দুটি p–n জাংশন তৈরি করে: ইমিটার–বেস (JE) ও কালেক্টর–বেস (JC)। বাইপোলার (bipolar) = ইলেকট্রন ও হোল দুই ধরনের বাহকই কারেন্ট বহন করে (FET ইউনিপোলার)। এটি কারেন্ট-নিয়ন্ত্রিত ডিভাইস: ছোট IB বড় IC নিয়ন্ত্রণ করে।
অঞ্চলডোপিংপ্রস্থকাজ
ইমিটারসবচেয়ে বেশিমাঝারিবেসে সংখ্যাগুরু বাহক নিঃসরণ (inject) করে
বেসসবচেয়ে কমসবচেয়ে পাতলা (µm)সামান্য পুনর্মিলনে বাহক পার করে দেয়
কালেক্টরমাঝারিসবচেয়ে চওড়াবাহক সংগ্রহ করে, বেশিরভাগ তাপ ছাড়ে

মুখস্থ ক্রম: ডোপিং E > C > B · প্রস্থ C > E > B। পাতলা ও হালকা ডোপড বেসে পুনর্মিলন (recombination) কম, তাই IC ≈ IE।

মনে রাখার কৌশল npn = "Not Pointing iN" (তীর ভেতরে নয়); pnp = "Points iN Proudly"। তীর সবসময় ইমিটারে থাকে এবং p → n দিক দেখায়।
পরীক্ষার ফাঁদ npn-এর E ও C দুটোই n-টাইপ, কিন্তু অদলবদল করা যায় না (ডোপিং ও আকার ভিন্ন)। দুটি আলাদা ডায়োড পিঠাপিঠি জুড়লে ট্রানজিস্টর হয় না: বেস পাতলা হতে হবে।

ইতিহাস: পয়েন্ট-কন্টাক্ট ট্রানজিস্টর, বারডিন ও ব্র্যাটেইন, বেল ল্যাবস, ১৯৪৭; জাংশন (বাইপোলার) ট্রানজিস্টর, শকলি, ১৯৪৮; নোবেল পুরস্কার ১৯৫৬। "Transistor" = transfer + resistor। সিলিকন জার্মেনিয়ামকে সরিয়েছে: লিকেজ কম, ≈ 150 °C পর্যন্ত কাজ করে।

২কার্যপ্রণালী (npn, অ্যাকটিভ মোড)

লিখিতের প্রিয়
  1. JE ফরওয়ার্ড বায়াসড: n⁺ ইমিটার বেসে ইলেকট্রন পাঠায় → IE
  2. বেস পাতলা ও হালকা ডোপড: মাত্র ১–৫% হোলের সাথে পুনর্মিলিত হয় → IB
  3. JC রিভার্স বায়াসড: এর ক্ষেত্র বাকি ৯৫–৯৯% কে কালেক্টরে টেনে নেয় → IC
  4. ছোট IB বড় IC নিয়ন্ত্রণ করে: এটিই বিবর্ধন ক্রিয়া (amplifying action)
কারেন্টের সম্পর্ক IE = IB + IC · α = IC/IE (0.95–0.995) · β = IC/IB (50–300)
β = α/(1 − α) · α = β/(1 + β) · IE = (1 + β)IB · γ = IE/IB = 1 + β (CC)

লিকেজ কারেন্ট

  • ICBO: ইমিটার খোলা রেখে C–B রিভার্স কারেন্ট (Si: nA, Ge: µA); সংখ্যালঘু বাহকের কারণে, প্রতি ১০ °C-এ দ্বিগুণ
  • CB: IC = αIE + ICBO
  • CE: IC = βIB + (1 + β)ICBO = βIB + ICEO
  • ICEO (বেস খোলা) = (1 + β)ICBO: β গুণ বেশি
dc বনাম ac β βdc = hFE = IC/IB · βac = hfe = ΔIC/ΔIB; অ্যাকটিভ অঞ্চলে প্রায় সমান।
মনে রাখার কৌশল α = "Almost 1" (প্রায় ১), β = "Big" (বড়)। β = "α ভাগ (১ − α)"।
উদাহরণ ১–২ ✍ IE = 10 mA, IC = 9.9 mA → IB = 0.1 mA, α = 0.99, β = 99 (0.99/0.01 = 99 ✓) · α = 0.98 → β = 0.98/0.02 = 49 · β = 200 → α = 200/201 = 0.995
উদাহরণ ৩ ✍ Ge ট্রানজিস্টর, β = 50, ICBO = 5 µA, IB = 40 µA → ICEO = 51 × 5 = 255 µA; IC = 50 × 40 + 255 = 2255 µA ≈ 2.26 mA। লিকেজ IC-এর ১১%, তাই Ge সার্কিট তাপে সরে যায়।
উদাহরণ ৪ ✍ Si, β = 120, IB = 50 µA → IC = 6 mA, IE = 121 × 50 µA = 6.05 mA, α = 120/121 = 0.9917, তাই IC ≈ IE।
পরীক্ষার ফাঁদ β ধ্রুবক নয়: তাপমাত্রায় বাড়ে, IC-এর সাথে বদলায়, একই টাইপের ভিন্ন ইউনিটে অনেক পার্থক্য থাকে (যেমন একই ডেটাশিটে hFE 100–300)। ভালো বায়াস নকশা β-এর উপর নির্ভর করে না।

৪CE বৈশিষ্ট্য রেখা (Characteristics)

  • আর্লি প্রভাব (Early effect) বা বেস-প্রস্থ মডুলেশন: VCE ↑ → C–B ডিপ্লিশন চওড়া হয় → কার্যকর বেস সরু হয় → β ও IC একটু বাড়ে। রেখাগুলো বাড়ালে VCE অক্ষের −VA বিন্দুতে মেলে (আর্লি ভোল্টেজ, 50–200 V); আউটপুট রোধ ro = VA/IC (VA = 100 V, IC = 1 mA → 100 kΩ)।
  • একই কারণে VCE বাড়লে ইনপুট রেখা ডানে সরে (একই VBE-তে IB কম)।
  • CB বৈশিষ্ট্য: ইনপুট IE বনাম VBE (ডায়োড); আউটপুট IC ≈ IE, প্রায় সমতল, এবং VCB = 0-তেও IC প্রবাহিত হয় (থামাতে সামান্য ফরওয়ার্ড VCB লাগে)।
  • ব্রেকডাউন: BVCEO < BVCBO; C–B ডিপ্লিশন স্তর ইমিটারে পৌঁছালে পাঞ্চ-থ্রু (punch-through)।
উদাহরণ: অ্যাকটিভ না স্যাচুরেটেড? ✍ VCC = 10 V, RC = 1 kΩ, β = 100, IB = 0.2 mA। βIB = 20 mA, কিন্তু IC(sat) = (10 − 0.2)/1 kΩ = 9.8 mA < 20 mA → স্যাচুরেটেড, VCE ≈ 0.2 V, IC = 9.8 mA।

৬DC লোড লাইন ও Q-পয়েন্ট

লিখিতের প্রিয়
সংজ্ঞা বাইরের সার্কিট যত (VCE, IC) জোড়া অনুমোদন করে তাদের রেখাই DC লোড লাইন: VCE = VCC − IC(RC + RE) (RE না থাকলে 0)। সিগন্যাল ছাড়া এটি ট্রানজিস্টরের IB রেখাকে যেখানে ছেদ করে সেটিই Q-পয়েন্ট (quiescent point)।
  • স্যাচুরেশন প্রান্ত (VCE = 0): IC(sat) = VCC/(RC + RE)
  • কাট-অফ প্রান্ত (IC = 0): VCE(off) = VCC
  • ঢাল = −1/(RC + RE)
  • Q স্যাচুরেশনের কাছে → আউটপুটের নিচের অংশ কাটা পড়ে (VCE(sat)); কাট-অফের কাছে → উপরের অংশ কাটা (VCC)
  • Q মাঝখানে → সবচেয়ে বড় প্রতিসম সুইং (ক্লাস A)
উদাহরণ (ফিক্সড বায়াস) ✍ VCC = 12 V, RB = 565 kΩ, RC = 3 kΩ, β = 100, VBE = 0.7 V।
  1. IB = (12 − 0.7)/565 kΩ = 20 µA; IC = βIB = 2 mA
  2. VCE = 12 − 2 mA × 3 kΩ = 6 V → Q = (6 V, 2 mA)
  3. প্রান্ত: IC(sat) = 12/3 kΩ = 4 mA, VCE(off) = 12 V → Q ঠিক মাঝখানে

হাই-ইল্ড
বায়াস কেন? Q-কে অ্যাকটিভ অঞ্চলে বসানো এবং β (ইউনিটভেদে, তাপে), ICBO (প্রতি ১০ °C-এ দ্বিগুণ) ও VBE (≈ 2.5 mV/°C হারে কমে) বদলালেও সেখানেই রাখা।
স্থিতিশীলতা গুণক S = ∂IC/∂ICBO (β, VBE ধ্রুব) · S′ = ∂IC/∂VBE · S″ = ∂IC/∂β। পরিসর 1 ≤ S ≤ 1 + β; S যত কম, তত স্থিতিশীল। সাধারণ সূত্র: S = (1+β)/(1 − β·∂IB/∂IC)
পদ্ধতিIBVCES
① ফিক্সড(VCC − VBE)/RBVCC − ICRC1 + β (সবচেয়ে খারাপ)
② কালে.-ফিডব্যাক(VCC − VBE)/(RB + (1+β)RC)VCC − IERC(1+β)/(1+βRC/(RC + RB))
③ ইমিটার-স্থিতি.(VCC − VBE)/(RB + (1+β)RE)≈ VCC − IC(RC + RE)(1+β)(1+RB/RE)/(1+β+RB/RE)
④ ভো.-ডিভাইডার(VTh − VBE)/(RTh + (1+β)RE)≈ VCC − IC(RC + RE)একই, RB → RTh; ≈ 1 + RTh/RE

④: RTh = R1 ∥ R2, VTh = VCCR2/(R1 + R2)। βRE ≥ 10R2 হলে আনুমানিক পদ্ধতি: VB = VTh, IE = (VB − 0.7)/RE, β-নিরপেক্ষ। সবচেয়ে স্থিতিশীল, সবচেয়ে বেশি ব্যবহৃত।

প্রতিপাদন ✍ ③: VCC = IBRB + VBE + (IB + IC)RE → ∂IB/∂IC = −RE/(RB + RE) → S = (1+β)/(1+βRE/(RB + RE))। ফিক্সড বায়াসে IB IC-এর উপর নির্ভর করে না, তাই ∂IB/∂IC = 0 এবং S = 1 + β।
মনে রাখার কৌশল বেস থেকে RE-কে (1+β) গুণ বড় দেখায়। RB/RE (বা RTh/RE) ছোট → S → 1।
পরীক্ষার ফাঁদ RE-এর সমান্তরালে বাইপাস ক্যাপাসিটর AC ফিডব্যাক সরায় (গেইন ফেরে) কিন্তু DC স্থিতিশীলতা রাখে। কালেক্টর-ফিডব্যাক AC গেইনও কমায়।
