২কাপলিং ও বাইপাস ক্যাপাসিটর · DC বনাম AC বিশ্লেষণ

  • কাপলিং C (C1, C2): AC পার করে, DC আটকায়, ফলে সোর্স ও লোড Q-পয়েন্ট নষ্ট করে না। নিয়ম: সর্বনিম্ন সংকেত ফ্রিকোয়েন্সিতে XC ≤ R/10।
  • বাইপাস C (CE): শুধু AC-র জন্য RE-কে শর্ট করে। DC স্থিতিশীলতা RE রাখে, অথচ AC গেইন ≈ −RC/RE থেকে বেড়ে হয় −RC/re।
  1. DC বিশ্লেষণ: ক্যাপাসিটর = ওপেন; IE, VCE বের করো (বায়াস, লেসন ২)
  2. re = 26 mV / IE
  3. AC বিশ্লেষণ: ক্যাপাসিটর = শর্ট, DC সাপ্লাই = AC গ্রাউন্ড
  4. ট্রানজিস্টরের জায়গায় মডেল বসাও; Zi, Zo, Av, Ai বের করো
মনে রাখার কৌশল "DC-তে ক্যাপ বাদ, AC-তে ক্যাপ শর্ট, VCC মাটিতে"। AC-তে R1 ও R2 দুটোই গ্রাউন্ডে শেষ হয়, তাই তারা সমান্তরাল: R′ = R1 ∥ R2।

৪কমন বেস ও কমন কালেক্টর

কমন বেস (CB) ইনপুট E-তে, আউটপুট C-তে।
Zi = RE ∥ re ≈ re (খুব কম, ~10–50 Ω)
Zo ≈ RC · Av = +RC/re (উল্টায় না)
Ai = α ≈ 0.98–0.99 (< 1)
ব্যবহার: RF / উচ্চ ফ্রিকোয়েন্সি স্টেজ (মিলার প্রভাব নেই), কম-Z সোর্স।
কমন কালেক্টর (CC) = এমিটার ফলোয়ার ইনপুট B-তে, আউটপুট E-তে।
Zi = RB ∥ β(re + RE) → উচ্চ
Zo = RE ∥ re ≈ re → খুব কম
Av = RE/(RE + re) ≈ 1 (একটু < 1)
Ai ≈ β + 1। ব্যবহার: বাফার, ইম্পিডেন্স ম্যাচিং।

হাই-ইল্ড
  • নিম্ন প্রান্ত fL: C1, C2, CE-এর XC বাড়ে; fL = 1/[2π(Rs + Zi)C1]। সাধারণত CE-ই সর্বোচ্চ (প্রধান) fL ঠিক করে।
  • উচ্চ প্রান্ত fH: Cbe, Cbc, স্ট্রে C। মিলার প্রভাব: CMi = (1 + |Av|)Cbc।
  • fL, fH-এ: গেইন = 0.707 Amid (−3 dB), পাওয়ার = ½।
সমাধানকৃত উদাহরণ ✍
① পৃ. ৩-এর স্টেজ, C1 = 10 μF, Rs ≈ 0: fL = 1/(2π × 1511 × 10⁻⁵) = 10.5 Hz
② Cbc = 4 pF, Av = −178: CMi = 179 × 4 = 716 pF
③ fL = 50 Hz, fH = 20 kHz → BW = 19.95 kHz

স্যাচুরেশন (পিঞ্চ-অফ) ← এমপ্লিফায়ারVDS ≥ VGS − VPশকলি, VDS-এ প্রায় সমতল
মনে রাখার কৌশল JFET = বাগানের পানির পাইপ: গেট পাইপ চেপে ধরে; পুরো চাপলে (VGS = VP) প্রবাহ বন্ধ। বিশ্রামে খোলা → নরমালি ON, শুধু ডিপ্লিশন মোড।
পরীক্ষার ফাঁদ n-চ্যানেল: VGS ≤ 0; p-চ্যানেল: VGS ≥ 0। গেট ফরোয়ার্ড বায়াস হলে উচ্চ Zi হারায়। ক্যারিয়ার ঢোকে সোর্স দিয়ে, বের হয় ড্রেন দিয়ে।

৯JFET বৈশিষ্ট্য রেখা ও শকলি সমীকরণ

লিখিত-প্রিয়
শকলি সমীকরণ (স্যাচুরেশন) ID = IDSS(1 − VGS/VP)² · বিপরীত: VGS = VP(1 − √(ID/IDSS)) · বর্গ নিয়ম → প্যারাবোলিক ট্রান্সফার রেখা
সমাধানকৃত উদাহরণ ✍
① IDSS = 10 mA, VP = −4 V, VGS = −2 V: ID = 10(1 − 0.5)² = 2.5 mA
② IDSS = 8 mA, VP = −4 V, VGS = −1 V: ID = 8(0.75)² = 4.5 mA
③ একই FET, ID = 4.5 mA → VGS = −4(1 − 0.75) = −1 V ✓
মনে রাখার কৌশল: ৪ বিন্দুতে আঁকো VGS = 0 → IDSS · 0.3VP → IDSS/2 · VP/2 → IDSS/4 · VP → 0। VGS = 0 হলে স্যাচুরেশন শুরু VDS = |VP|-এ।

১০ট্রান্সকন্ডাকট্যান্স (Transconductance) gm

gm = ΔID/ΔVGS (VDS স্থির): ট্রান্সফার রেখার ঢাল, একক সিমেন্স (mS)।
gm0 = 2IDSS/|VP|
gm = gm0(1 − VGS/VP) = gm0√(ID/IDSS)
অ্যামপ্লিফিকেশন ফ্যাক্টর μ = gmrd
সমাধানকৃত উদাহরণ ✍ IDSS = 10 mA, VP = −4 V: gm0 = 20/4 = 5 mS; VGS = −2 V-এ: gm = 5(1 − 0.5) = 2.5 mS। gm সর্বোচ্চ VGS = 0-এ, শূন্য VP-তে।
পরীক্ষার ফাঁদ gm হলো ঢাল ΔID/ΔVGS, ID/VGS নয়। 1 mA-তে BJT-এর gm = IC/VT ≈ 38 mS, FET-এর কয়েক mS-এর চেয়ে অনেক বেশি: FET স্টেজের ভোল্টেজ গেইন কম।
ব্যবহারিক সংযোগ ওহমিক অঞ্চলে JFET একটি ভোল্টেজ-নিয়ন্ত্রিত রেজিস্টর (AGC সার্কিট, অ্যানালগ সুইচ, চপার)। গেট কারেন্ট নগণ্য বলে JFET-ইনপুট অপ-অ্যাম্প (যেমন TL071) এবং pH-মিটার / ইলেকট্রোমিটার প্রোবের ইনপুট স্টেজে এটি ব্যবহৃত হয়।

১১MOSFET: গঠন ও দুই প্রকার

হাই-ইল্ড
সংজ্ঞা মেটাল-অক্সাইড-সেমিকন্ডাক্টর FET: গেট ও চ্যানেলের মাঝে পাতলা SiO₂ অন্তরক স্তর, তাই গেট যেন ক্যাপাসিটরের একটি প্লেট: Zi ≈ 10¹⁰–10¹⁵ Ω (JFET ~10⁸–10¹⁰ Ω)। চারটি টার্মিনাল: G, D, S ও সাবস্ট্রেট (বডি), সাধারণত S-এর সাথে যুক্ত। অপর নাম IGFET।

সমাধানকৃত উদাহরণ ✍ ID(on) = 10 mA, VGS(on) = 8 V-এ, VT = 3 V।

পরীক্ষার ফাঁদ JFET: শুধু ডিপ্লিশন; D-MOSFET: দুই মোডেই; E-MOSFET: শুধু এনহান্সমেন্ট। পাতলা অক্সাইড: স্থির বিদ্যুৎ (ESD) সহজেই নষ্ট করে।
মনে রাখার কৌশল "E = Empty" (খালি): VT পেরিয়ে Enhance না করা পর্যন্ত চ্যানেল নেই; ভাঙা রেখা = খালি চ্যানেল। "D = Done": চ্যানেল তৈরি, তাই নরমালি ON।
আইটি সংযোগ: CMOS CMOS ইনভার্টার = p-চ্যানেল E-MOSFET (VDD-র দিকে) ও তার নিচে n-চ্যানেল E-MOSFET, গেট ও ড্রেন যুক্ত: ইন 0 → আউট 1, ইন 1 → আউট 0। একটি সবসময় OFF, তাই স্থির পাওয়ার ≈ 0 (ডায়নামিক ≈ CVDD²f): CPU ও মেমরি CMOS-এ তৈরি।
