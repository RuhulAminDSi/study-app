১বিট, ডেটা টাইপ ও সাইনড ইন্টিজার

সবচেয়ে বেশি আসে ★
সংজ্ঞা অভ্যন্তরীণ ডেটা উপস্থাপন (Internal data representation) হলো সংখ্যা, অক্ষর ও নির্দেশনাকে বাইনারি প্যাটার্নে সংরক্ষণের পদ্ধতি। বিট = একটি 0/1, নিবল = 4 বিট, বাইট = 8 বিট, ওয়ার্ড = CPU-র স্বাভাবিক একক (16/32/64 বিট)। প্যাটার্নের অর্থ ঠিক করে টাইপ: 01000001 ইন্টিজার হিসেবে 65, ASCII হিসেবে 'A'। n বিটে 2n প্যাটার্ন, তাই আনসাইনড n-বিট ইন্টিজারের রেঞ্জ 0 … 2n − 1 (8-বিট 0…255, 16-বিট 0…65535)।
প্রিমিটিভ বনাম নন-প্রিমিটিভ প্রিমিটিভ (Primitive): ভাষায় অন্তর্নির্মিত — int, char, float, double, boolean, pointer। নন-প্রিমিটিভ: এগুলো দিয়ে তৈরি — লিনিয়ার (অ্যারে, লিস্ট, স্ট্যাক, কিউ) ও নন-লিনিয়ার (ট্রি, গ্রাফ)। বেস রূপান্তর সংখ্যা-পদ্ধতির লেসনে; ১টি হেক্স অঙ্ক = 4 বিট।
C টাইপআকারসাধারণ রেঞ্জ
char / unsigned char1 B−128…127 / 0…255
short2 B−32768…32767
int / long long4 / 8 B−231…231−1 / −263…
float / double4 / 8 B~7 / ~15–16 অঙ্ক
n বিটে ঋণাত্মক সংখ্যা রাখার তিন উপায় সাইন-ম্যাগনিচুড (Sign-magnitude): MSB = চিহ্ন (0 +, 1 −), বাকিটা |x|। 1's কমপ্লিমেন্ট: +x-এর সব বিট উল্টাও। 2's কমপ্লিমেন্ট: সব বিট উল্টে 1 যোগ (= 2n − x)। CPU ব্যবহার করে 2's কমপ্লিমেন্ট: শূন্য একটিই, আর একই অ্যাডারে যোগ-বিয়োগ দুটোই।
পদ্ধতিn-বিট রেঞ্জ8-বিট রেঞ্জশূন্য−5 (4-বিট)
সাইন-ম্যাগনিচুড−(2n−1−1) … 2n−1−1−127 … 127দুটি (+0, −0)1101
1's কমপ্লিমেন্ট−(2n−1−1) … 2n−1−1−127 … 127দুটি1010
2's কমপ্লিমেন্ট−2n−1 … 2n−1−1−128 … 127একটি1011
মনে রাখার কৌশল "প্রথম 1 পর্যন্ত কপি, বাকিটা উল্টাও।" ডান দিক থেকে +x পড়ো, প্রথম 1 সহ সেখান পর্যন্ত বিট হুবহু রাখো, বাকিগুলো উল্টাও: 00000101 → 11111011। ডিকোড করতে MSB-এর ওজন −2n−1: 11111011 = −128 + 123 = −5।
পরীক্ষার ফাঁদ 2's কমপ্লিমেন্ট অসম: 8 বিটে −128 আছে, +128 নেই। "−5-এর 2's কমপ্লিমেন্ট" প্রশ্নে 10000101 (S-M) ও 11111010 (1's) হলো ভুল বিকল্প। বিট বাড়াতে সাইন বিট কপি করো: 1011 → 1111 1011 (সাইন এক্সটেনশন)।
ওভারফ্লো (Overflow) কেবল তখনই সম্ভব যখন একই চিহ্নের দুটি সংখ্যা যোগ করে ফল বিপরীত চিহ্নের হয় (MSB-তে ঢোকা ক্যারি ≠ বের হওয়া ক্যারি)। বিপরীত চিহ্নে কখনো ওভারফ্লো হয় না; MSB থেকে শুধু ক্যারি বের হলে তা ফেলে দেওয়া হয়।
সমাধানকৃত উদাহরণ ✍ 8-বিট 100 + 50: 01100100 + 00110010 = 10010110 → দুটি ধনাত্মক থেকে MSB 1: ওভারফ্লো (পড়া যায় −106)। 7 − 5 = 7 + (−5): 00000111 + 11111011 = 1 00000010 → ক্যারি বাদ → 2, ওভারফ্লো নেই।

লেআউট ★
সংজ্ঞা বাস্তব সংখ্যা রাখা হয় নরমালাইজড রূপে (−1)S × 1.M × 2E − bias, তিনটি ফিল্ডে: সাইন S, বায়াসড এক্সপোনেন্ট E ও ম্যান্টিসা (ভগ্নাংশ) M। শুরুর 1 টি সংরক্ষিত হয় না (হিডেন বিট)।
সমাধানকৃত উদাহরণ ✍ −6.75 → সিঙ্গেল ১. ঋণাত্মক → S = 1। ২. 6.75 = 110.11₂। ৩. নরমালাইজ: 1.1011 × 2²; হিডেন 1 বাদ, M = 1011 0…0। ৪. E = 2 + 127 = 129 = 10000001। ৫. 1 10000001 1011000…0 = C0D80000h। যাচাই: 1.1011₂ = 1.6875; × 2² = 6.75 ✓

পরীক্ষার ফাঁদ 0.1-এর নিখুঁত বাইনারি রূপ নেই (0.000110011… পৌনঃপুনিক), তাই C, Java ও Python-এ 0.1 + 0.2 == 0.3 মিথ্যা। ফ্লোট তুলনা করো |a − b| < ε দিয়ে; টাকা রাখো পূর্ণসংখ্যায় (পয়সা)।

সংজ্ঞার প্রশ্ন ★
সংজ্ঞা অ্যাবস্ট্রাক্ট ডেটা টাইপ (ADT) হলো এমন একটি গাণিতিক মডেল যেখানে টাইপকে সংজ্ঞায়িত করা হয় তার মান ও সেগুলোর ওপর অপারেশন (ও তাদের নিয়ম) দিয়ে, কীভাবে ইমপ্লিমেন্ট করা হলো তা দিয়ে নয়। ডেটা স্ট্রাকচার হলো মেমোরিতে ডেটা সাজানোর একটি বাস্তব উপায়, যা কোনো ADT-কে ইমপ্লিমেন্ট করে। "স্ট্যাক" একটি ADT; "top ইনডেক্সসহ অ্যারে" তার একটি ডেটা স্ট্রাকচার।

ADT কেন — তিনটি সুবিধা এনক্যাপসুলেশন (Encapsulation) বা তথ্য গোপন: ব্যবহারকারী শুধু অপারেশন দেখে, তাই ভেতরের রূপ বদলালেও তার কোড ভাঙে না। পুনর্ব্যবহারযোগ্যতা (Reusability): একই ADT নানাভাবে ইমপ্লিমেন্ট করে বহু প্রোগ্রামে ব্যবহার করা যায়। মডিউলারিটি (Modularity): প্রতিটি মডিউল আলাদাভাবে লেখা, পরীক্ষা ও ডিবাগ করা যায়। মিলে তৈরি হয় ডেটা অ্যাবস্ট্রাকশন, যা OOP-র ক্লাসের ভিত্তি।
মনে রাখার কৌশল ADT = মেনু; ডেটা স্ট্রাকচার = রান্নাঘর। মেনুতে লেখা কী অর্ডার করা যায় (push, pop); রান্নাঘর ঠিক করে কীভাবে রান্না হবে (অ্যারে না লিস্ট)। রান্নাঘর বদলাও, মেনু একই। সুবিধা: "E-R-M" — এনক্যাপসুলেশন, রিইউজেবিলিটি, মডিউলারিটি।
পরীক্ষার ফাঁদ BFS ও DFS গ্রাফের ওপর চালানো অ্যালগরিদম, গ্রাফ ADT-র নিজস্ব অপারেশন নয়। প্রায়োরিটি কিউ FIFO নয়: অগ্রাধিকার অনুযায়ী সেবা দেয়। লিংকড লিস্ট একটি ডেটা স্ট্রাকচার; "লিস্ট" হলো ADT। "ADT সংজ্ঞায়িত করে…?" → আচরণ, স্টোরেজ নয়।

সংজ্ঞা স্ট্যাক (Stack) এমন লিস্ট যেখানে ইনসার্ট (push) ও ডিলিট (pop) হয় এক প্রান্তে, top-এ: শেষে ঢুকলে আগে বের (LIFO)। অ্যারে রূপে top = −1 মানে খালি; top == MAX−1 অবস্থায় push হলো ওভারফ্লো; top == −1 অবস্থায় pop হলো আন্ডারফ্লো। লিংকড রূপে head-এ push/pop হয়, মেমোরি না ফুরালে ওভারফ্লো নেই। সব অপারেশন O(1)।
void push(int x) { if (top == MAX-1) { puts("Overflow"); return; } s[++top] = x; } int pop(void) { if (top == -1) { puts("Underflow"); return -1; } return s[top--]; }

সংজ্ঞা কিউ (Queue) rear-এ ইনসার্ট (enqueue) ও front থেকে ডিলিট (dequeue) করে: আগে ঢুকলে আগে বের (FIFO)। সাধারণ অ্যারেতে front ও rear শুধু সামনে এগোয়, তাই খালি হওয়া ঘর আর ব্যবহার হয় না (অর্ধেক খালি থেকেও "পূর্ণ"); সার্কুলার কিউ ইনডেক্সকে % n দিয়ে ঘুরিয়ে আনে।
সার্কুলার কিউ (n আকারের অ্যারে)শর্ত
Enqueuerear = (rear + 1) % n; Q[rear] = x
Dequeuex = Q[front]; front = (front + 1) % n
পূর্ণ(rear + 1) % n == front
খালিfront == −1 (এক-ঘর-খালি রূপে front == rear)
উপাদান সংখ্যা(rear − front + n) % n (এক-ঘর-খালি রূপে)
দুই রীতি front = rear = −1 মানে খালি: n ঘরই ব্যবহারযোগ্য। front = rear = 0 মানে খালি: একটি ঘর ফাঁকা থাকে, ধারণক্ষমতা n − 1।
সমাধানকৃত উদাহরণ ✍ ট্রেস খালি কিউ: enqueue(1), enqueue(2), enqueue(3) → [1, 2, 3]; dequeue() সরায় 1 → [2, 3]; enqueue(4) → [2, 3, 4]; dequeue() সরায় 2 → [3, 4]। front = 3, rear = 4। একই push-pop স্ট্যাকে করলে থাকে [1, 2], top-এ 2।

অ্যারে উপস্থাপন লেভেল ধরে সাজাও। 0-ভিত্তিক: বাম = 2i + 1, ডান = 2i + 2, প্যারেন্ট = ⌊(i − 1)/2⌋। 1-ভিত্তিক: বাম = 2i, ডান = 2i + 1, প্যারেন্ট = ⌊i/2⌋। কমপ্লিট ট্রির জন্য আদর্শ; স্কিউডে অপচয়।
সমাধানকৃত উদাহরণ ✍ দুই ট্রাভার্সাল থেকে ট্রি গঠন প্রিঅর্ডার A B D E C F, ইনঅর্ডার D B E A F C। প্রিঅর্ডারের প্রথমটি রুট A; ইনঅর্ডারে D B E তার বাম সাবট্রি, F C ডান সাবট্রি। B বাম অংশের রুট (D, E); C ডান অংশের রুট, F তার বামে। পোস্টঅর্ডার: D E B F C A। ইনঅর্ডার + প্রি/পোস্ট মিলে ট্রি অনন্যভাবে নির্ধারিত; শুধু প্রি + পোস্টে নয়।
মনে রাখার কৌশল নামই বলে নোড কোথায় বসে: প্রি = নোড আগে, ইন = নোড মাঝে, পোস্ট = নোড শেষে; বাম সবসময় ডানের আগে। BST: বাম < নোড < ডান, তাই এর ইনঅর্ডার সাজানো।
পরীক্ষার ফাঁদ লেভেল গোনা কোথা থেকে শুরু দেখো: রুট লেভেল 1 হলে লেভেল i-তে সর্বোচ্চ 2i−1 ও উচ্চতা h-এ 2h − 1 নোড। BST সার্চ গড়ে O(log n), কিন্তু স্কিউড হলে O(n) — তাই AVL ও রেড-ব্ল্যাক ট্রি।

লিখিত প্রশ্ন অ্যাবস্ট্রাক্ট ডেটা টাইপ কী? স্ট্যাক ADT এবং ওভারফ্লো ও আন্ডারফ্লোসহ এর অ্যারে ইমপ্লিমেন্টেশন বর্ণনা করো। স্ট্যাক দেখিয়ে A + B * C − D / E-কে পোস্টফিক্সে রূপান্তর করো এবং 5 6 2 + * 12 4 / − এর মান নির্ণয় করো। ১০ নম্বর
  1. ADT (২) — মান ও অপারেশন দিয়ে সংজ্ঞায়িত টাইপ, ইমপ্লিমেন্টেশন-নিরপেক্ষ; সুবিধা: এনক্যাপসুলেশন, রিইউজেবিলিটি, মডিউলারিটি। ডেটা স্ট্রাকচার একে ইমপ্লিমেন্ট করে। ২
  2. স্ট্যাক ADT (২) — LIFO লিস্ট; push, pop, peek, isEmpty, isFull, সব O(1)। ব্যবহার: কল স্ট্যাক, এক্সপ্রেশন, undo, ব্যাকট্র্যাকিং। ২
  3. অ্যারে ইমপ্লিমেন্টেশন (২) — top = −1 খালি; push: top == MAX−1 হলে → ওভারফ্লো, নইলে s[++top] = x; pop: top == −1 হলে → আন্ডারফ্লো, নইলে s[top−−] ফেরত। ২
  4. ইনফিক্স → পোস্টফিক্স (২) — A আউট; + push; B আউট; * + এর চেয়ে বড়, push; C আউট; − এলে * ও + pop (≥ অগ্রাধিকার), − push; D আউট; / push; E আউট; / ও − pop → A B C * + D E / −। ২
  5. মূল্যায়ন (২) — push 5, 6, 2; + → 8; * → 40; push 12, 4; / → 3; − → 40 − 3 = 37। ২
