প্রমাণ (লিখিত প্রিয়) Full (proper) binary tree-এ leaf = internal node + ১। ধরি I = internal node, L = leaf। Edge দুইভাবে গুনি: root ছাড়া প্রতিটি node-এর একটি parent edge, তাই edge = I + L − 1; প্রতিটি internal node-এর ২টি child, তাই edge = 2I। অতএব 2I = I + L − 1, অর্থাৎ L = I + 1। ∎
পরীক্ষার ফাঁদ Height-এর রীতি। এখানে height = edge গণনা (একা root = 0)। কিছু বই node গোনে (একা root = 1), তখন “N level” = 2^N − 1। রীতিটি লিখে দিন।
স্মৃতি-কৌশল প্রতি level দ্বিগুণ: 1, 2, 4, 8 …, তাই h+1টি পূর্ণ level = “পরের 2-এর ঘাত বিয়োগ ১”। Perfect ⊂ complete ও perfect ⊂ full, কিন্তু full ⇏ complete।

৩ Binary Search Tree: Search ও Insert ★ Bank ও PSU লিখিত

BST property প্রতিটি node-এর জন্য: left subtree-এর সব key ছোট, right subtree-এর সব key বড় (duplicate নেই, যদি না “সমান হলে ডানে” জাতীয় নিয়ম বলা হয়)। ফল: inorder = sorted।
/* search: iterative */
node* search(node* t, int k) {
  while (t && t->key != k)
    t = (k < t->key) ? t->left
                     : t->right;
  return t;   /* NULL = absent */
}
/* insert: recursive */
node* insert(node* t, int k) {
  if (!t) return newNode(k);
  if (k < t->key)
    t->left = insert(t->left, k);
  else if (k > t->key)
    t->right = insert(t->right, k);
  return t;   /* duplicate ignored */
}
উদাহরণ খালি BST-এ 8 3 10 1 6 14 4 7 13 insert: প্রতিটি key root থেকে নামে, ছোট হলে বামে, বড় হলে ডানে, যতক্ষণ না খালি link পায়।
স্মৃতি-কৌশল “ছোট বামে, বড় ডানে, NULL-এ থামো।” প্রথম key সবসময় root; sorted input-এ BST linked list হয়ে যায়।
পরীক্ষার ফাঁদ BST নিজে থেকে balanced নয়: search O(log n) শুধু balanced হলে, worst case-এ O(n)। Min = সবচেয়ে বামের node, max = সবচেয়ে ডানের।

DSA ▸ ট্রি ওয়ার্কশপBST: Delete

৪ BST Delete: তিনটি Case ★ লিখিত প্রিয়

  1. Leaf: সরাসরি সরান। 13 delete → 14-এর left child থাকে না।
  2. একটি child: child-কে parent-এর সাথে যুক্ত করুন। 10 delete → 14 উপরে ওঠে।
  3. দুটি child: inorder successor (right subtree-এর সবচেয়ে ছোট key) কপি করুন, তারপর সেই successor delete করুন (তার ≤ ১টি child)। Predecessor (বামের সবচেয়ে বড়) দিয়েও চলে।
উদাহরণ ১ Root 8 delete: successor = 10 (left child নেই), তাই 10 উপরে ওঠে ও 14 তার জায়গা নেয় → 10(3(1, 6(4, 7)), 14(13))। Predecessor নিলে 7 root হয়।
উদাহরণ ২: পূর্ণ লিখিত প্রশ্ন (ক) 50, 30, 70, 20, 40, 60, 80 insert। (খ) Postorder লিখুন। (গ) 50 delete করে আবার আঁকুন।
(ক) 50 root; 30, 70; তারপর 20, 40 ও 60, 80।
(খ) Postorder: 20 40 30 60 80 70 50
(গ) Successor = 60: উপরে কপি, leaf সরান।
স্মৃতি-কৌশল Successor = “একবার ডানে, তারপর পুরো বামে”; predecessor = “একবার বামে, তারপর পুরো ডানে”। শেষে inorder sorted কিনা দেখুন।
পরীক্ষার ফাঁদ Case ৩-এ successor-এর key কপি হয়; “right child দিয়ে বদলাও” ভুল, যখন সেই child-এর left subtree আছে (3 delete: 6-এর left child 4)।

৫ Binary Tree-কে Array-তে রাখা ★ লিখিত + BCS MCQ

Sequential representation Root index 1-এ, তারপর level order-এ বাম থেকে ডানে position নম্বর। অনুপস্থিত node-এর ঘর খালি থাকে; pointer-এর কাজ করে index-এর হিসাব।
Rooti-এর left childi-এর right childi-এর parent
1-indexed12i2i + 1⌊i / 2⌋
0-indexed (C, Java)02i + 12i + 2⌊(i − 1) / 2⌋
উদাহরণ: ফাঁকসহ tree শিট ৪-এর BST: 14 = 10-এর right → 2·3+1 = 7; 13 = 14-এর left → 2·7 = 14। ৯টি key-তে ১৪টি ঘর; n node-এর right-skewed tree-তে লাগে 2ⁿ − 1।
উদাহরণ: postorder → array Node a…i, postorder a b f c h d e g i। Tree-কে complete ধরুন (একটি traversal একা অস্পষ্ট): তার position-গুলোর postorder 8 9 4 5 2 6 7 3 1, তাই 8 = a, 9 = b, 4 = f, …
Array বনাম linked Array: parent O(1)-এ, complete tree (heap)-এর জন্য আদর্শ, ফাঁকা tree-তে অপচয়। Linked: n + 1টি NULL pointer, যেকোনো আকৃতি।
স্মৃতি-কৌশল দ্বিগুণ করলে নিচে-বামে, অর্ধেক করলে উপরে (1-indexed)।
পরীক্ষার ফাঁদ Indexing পড়ুন! “Zero-based, i-এর left child?” → 2i + 1, 2i নয়। Complete tree-এর leaf (1-indexed): ⌊n/2⌋+1 … n।

DSA ▸ ট্রি ওয়ার্কশপট্রি পুনর্গঠন ১: Inorder সহ

৬ Inorder + আরেকটি থেকে Tree পুনর্গঠন ★ BUET-ধাঁচের লিখিত

নিয়ম Preorder-এ root প্রথমে; postorder-এ শেষে। Inorder বাকিটাকে left ও right subtree-তে ভাগ করে। Recursion চালান। Inorder + pre বা post = একটিমাত্র tree।
উদাহরণ ১: preorder + inorder Inorder: 4 2 1 7 5 8 3 6 · Preorder: 1 2 4 3 5 7 8 6
  1. Pre[0] = 1 = root। Inorder: বামে {4 2}, ডানে {7 5 8 3 6}।
  2. বাম: root 2; inorder “4 2” → 4 তার left।
  3. ডান, pre 3 5 7 8 6: root 3; inorder “7 5 8 | 3 | 6”।
  4. {7 5 8}, pre 5 7 8: root 5, left 7, right 8; 6 হলো 3-এর right।
Pre ✓ ও in ✓ মিলিয়ে নিন; postorder = 4 2 7 8 5 6 3 1।
উদাহরণ ২: postorder + inorder Inorder: D B E A F C · Postorder: D E B F C A।
  1. Root = শেষটি = A; বামে {D B E}, ডানে {F C}।
  2. বামের post “D E B” → root B, D left, E right।
  3. Post “F C” → root C; inorder “F C” → F তার left।
ফলাফলের preorder: A B D E C F।
উদাহরণ ৩: ছাপার ভুলসহ ক্লাসিক Preorder a b d e c f g, কিন্তু inorder মাত্র ৫ অক্ষরের “d e a f g”: inorder-এ ৭টি key-ই থাকতে হবে। d b e a f c g ধরলে tree a(b(d, e), c(f, g)), postorder d e b f g c a। ধরে নেওয়াটা লিখে দিন।
স্মৃতি-কৌশল “Pre/Post দেখায়, In ভাগ করে।” Pre/post বলে কে root; inorder বলে কে কোথায় যাবে।

DSA ▸ ট্রি ওয়ার্কশপট্রি পুনর্গঠন ২: Pre + Post

৭ Preorder + Postorder, এবং BST শর্টকাট ★ Bank ও BUET

পদ্ধতি (শুধু full tree) Root = pre[0] = post[শেষ]। Preorder-এর পরের key হলো left subtree-এর root; postorder-এ সেটি পর্যন্ত সব left subtree, বাকিটা right। Recursion চালান।
উদাহরণ ১ Pre: 1 2 4 8 9 5 3 6 7 · Post: 8 9 4 5 2 6 7 3 1
  1. Root 1, পরের key 2: post-এ 2 পর্যন্ত → বামে {8 9 4 5 2}, ডানে {6 7 3}।
  2. Root 2, পরের key 4: post-এ 4 পর্যন্ত → {8 9 4}; 5 হলো 2-এর right।
  3. 4(8, 9); ডান অংশ 3(6, 7)।
উদাহরণ ২ Pre: 1 2 4 5 3 6 8 9 7 · Post: 4 5 2 8 9 6 7 3 1
  1. Root 1, পরের key 2: post-এ 2 পর্যন্ত = {4 5 2} → 2(4, 5)।
  2. ডান: pre 3 6 8 9 7 → root 3, পরের key 6 → 6(8, 9); 7 হলো 3-এর right।
পরীক্ষার ফাঁদ কোনো node-এর একটিমাত্র child থাকলে Pre + post অস্পষ্ট: pre “A B”, post “B A”-তে B left বা right দুটোই হতে পারে। Inorder + যেকোনো একটি সবসময় অনন্য; একটি traversal একা কখনো নয়।
BST শর্টকাট BST-এ inorder মানে sorted key, তাই শুধু preorder-ই যথেষ্ট: pre 8 3 1 6 4 7 10 14 13 → sort → পুনর্গঠন (বা ওই ক্রমে insert) → শিট ৪-এর BST।
অনুশীলন Pre 1 5 8 7 4 9 3 · In 8 5 7 1 9 4 3 → 1(5(8, 7), 4(9, 3)): সাধারণ binary tree, BST নয়।

৮ Heap ও B-tree: পরীক্ষার মূল কথা ★ Priority queue · DB index

Heap Array-তে রাখা একটি complete binary tree: max-heap-এ parent ≥ children (root = max), min-heap-এ parent ≤ children। Sibling-দের মধ্যে ক্রম নেই।
  1. 45 insert index 6-এ; parent ⌊6/2⌋ = 3-এ 40 < 45 → swap; parent 50 ≥ 45 → থামুন (sift-up, O(log n))।
  2. Delete max: 50 সরান, শেষ key 40 root-এ আনুন; child 45 > 40 → swap (sift-down, O(log n))।
  3. Build-heap: node ⌊n/2⌋ থেকে 1 পর্যন্ত sift-down: মোট O(n), O(n log n) নয়। Find-max O(1); heapsort O(n log n)।
Order m-এর B-tree একটি self-balancing multi-way search tree: প্রতি node-এ ≤ m child ও ≤ m − 1 key; non-root internal node-এ ≥ ⌈m/2⌉ child; সব leaf একই level-এ। Height = O(logm n)।
Database কেন B-tree নেয় Node = শত শত key-সহ একটি disk block: লক্ষ লক্ষ row মাত্র ৩–৪ level-এ = ৩–৪ বার read। B+ tree: record শুধু linked leaf-এ, তাই range query মানে leaf scan (MySQL InnoDB, PostgreSQL)।
পরীক্ষার ফাঁদ Heap BST নয়: heap-এ search O(n)। “Order m” = সর্বোচ্চ m child (Knuth); CLRS-এ minimum degree t। কোনটি নিচ্ছেন বলুন।
স্মৃতি-কৌশল Heap = priority, BST = search, B-tree = disk। Insert-এ sift up, delete-এ sift down।

৯ Decision Tree: Sorting-এ কেন Ω(n log n) লাগে ★ BCS MCQ

Decision tree model n key-এর যেকোনো comparison sort একটি binary tree: internal node = একটি তুলনা (a ≤ b?), leaf = একটি চূড়ান্ত ক্রম, একটি run = একটি root-to-leaf path। তাই worst-case তুলনা = height।
  1. n টি ভিন্ন key-এর n! ক্রম, প্রতিটির নিজস্ব leaf লাগে → leaf ≥ n!।
  2. Height h-এর binary tree-তে সর্বোচ্চ 2^h leaf → 2^h ≥ n! → h ≥ log₂(n!)।
  3. n! ≥ (n/2)^(n/2) ⇒ log₂(n!) ≥ (n/2)·log₂(n/2) = Ω(n log n)। Merge sort ও heapsort তাই optimal।
পরীক্ষার ফাঁদ Counting/radix sort comparison sort নয়: O(n + k) সম্ভব। ML-এ “decision tree” একটি classifier।
সংখ্যা ⌈log₂ n!⌉: n = 3 → 3, n = 4 → 5, n = 5 → 7। Sorted array-তে search: Ω(log n)।
রাতের আগের শিট
  • n node → n − 1 edge, n + 1 NULL link
  • height h-এ সর্বোচ্চ node = 2^(h+1) − 1; N level = 2^N − 1
  • full tree: L = I + 1; যেকোনো tree: n₀ = n₂ + 1
  • complete tree-এর height = ⌊log₂ n⌋
  • Pre = Root L R · In = L Root R · Post = L R Root
  • BST inorder = sorted; postorder দিয়ে tree মোছা
  • level order-এ queue; DFS-এ stack
  • R-L-Root = উল্টো preorder
  • BST ops O(h): balanced O(log n), skewed O(n)
  • delete, ২ child → inorder successor
  • 1-indexed: 2i, 2i+1, ⌊i/2⌋; 0-indexed: 2i+1, 2i+2
  • inorder + pre/post → অনন্য tree
  • heap: insert/delete O(log n), build O(n)
  • B-tree: সব leaf এক level-এ, node = disk block
  • sorting lower bound: h ≥ log₂ n! = Ω(n log n)
  • ৪টি key-তে ≥ ৫টি তুলনা
স্মৃতি-কৌশল “n! leaf, 2^h জায়গা”: 2^h ঘরের tree-তে n!টি উত্তর ধরাতে হবে, তাই h ≥ log₂ n!।

লিখিত (১০ নম্বর): একটি binary tree-এর inorder D B H E A I F J C G এবং preorder A B D E H C F I J G। Tree-টি আঁকুন ও postorder লিখুন।
মডেল উত্তর:
Root = preorder-এর প্রথম = A; inorder ভাগ করে: বামে {D B H E}, ডানে {I F J C G}। [২]
বাম: pre B D E H → root B; inorder “D | B | H E” → D হলো B-এর left; {H E}, pre E H → E, যার left child H। [২]
ডান: pre C F I J G → root C; inorder “I F J | C | G” → G হলো C-এর right; {I F J}, pre F I J → F(I, J)। [২]
Tree: A(B(D, E(H, –)), C(F(I, J), G))। [২] Postorder: D H E B I J F G C A; আঁকা tree থেকে preorder ও inorder পড়ে মিলিয়ে নিলে ঠিক ✓। [২]
