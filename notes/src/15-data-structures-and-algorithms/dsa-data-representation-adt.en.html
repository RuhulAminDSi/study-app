1Bits, Data Types and Signed Integers

most tested ★
Definition Internal data representation is how numbers, characters and instructions are encoded as binary patterns. Bit = one 0/1, nibble = 4 bits, byte = 8 bits, word = the CPU's natural unit (16/32/64 bits). The type gives a pattern its meaning: 01000001 is 65 as an integer, 'A' as ASCII. n bits give 2n patterns, so unsigned n-bit integers run 0 … 2n − 1 (8-bit 0…255, 16-bit 0…65535).
Primitive vs non-primitive Primitive: built into the language — int, char, float, double, boolean, pointer. Non-primitive: built from them — linear (array, list, stack, queue) and non-linear (tree, graph). Base conversion is in the number-systems lessons; 1 hex digit = 4 bits.

Three ways to store a negative number in n bits Sign-magnitude: MSB = sign (0 +, 1 −), the rest = |x|. 1's complement: invert every bit of +x. 2's complement: invert every bit, then add 1 (= 2n − x). CPUs use 2's complement: one zero, and one adder for both + and −.

Memory trick "Copy up to the first 1, flip the rest." Scan +x from the right, copy bits up to and including the first 1, invert the rest: 00000101 → 11111011. To decode, the MSB weighs −2n−1: 11111011 = −128 + 123 = −5.
Exam trap 2's complement is asymmetric: −128 exists in 8 bits, +128 does not. 10000101 (S-M) and 11111010 (1's) are the distractors for "2's complement of −5". To widen, copy the sign bit: 1011 → 1111 1011 (sign extension).
Overflow Possible only when two numbers of the same sign are added and the result has the opposite sign (carry into MSB ≠ carry out). Opposite signs never overflow; a carry out of the MSB alone is simply discarded.
Worked example ✍ 8-bit 100 + 50: 01100100 + 00110010 = 10010110 → MSB 1 from two positives: overflow (reads −106). 7 − 5 = 7 + (−5): 00000111 + 11111011 = 1 00000010 → drop the carry → 2, no overflow.

2IEEE 754 Floating Point and Character Codes

layout ★
Definition A real number is stored in normalised form (−1)S × 1.M × 2E − bias with three fields: sign S, biased exponent E and mantissa (fraction) M. The leading 1 is not stored (hidden bit).
Worked example ✍ −6.75 → single 1. Negative → S = 1. 2. 6.75 = 110.11₂. 3. Normalise: 1.1011 × 2²; drop the hidden 1, M = 1011 0…0. 4. E = 2 + 127 = 129 = 10000001. 5. 1 10000001 1011000…0 = C0D80000h. Check: 1.1011₂ = 1.6875; × 2² = 6.75 ✓

Memory trick "1-8-23, 127; 1-11-52, 1023." The bias is always 2k−1 − 1 for a k-bit exponent: 27 − 1 = 127, 210 − 1 = 1023. Field order S-E-M: Sign, Exponent, Mantissa.
Exam trap 0.1 has no exact binary form (0.000110011… recurring), so 0.1 + 0.2 == 0.3 is false in C, Java and Python. Compare floats with |a − b| < ε; keep money in integers (paisa).

Exam trap "Unicode is 16-bit" is outdated: Unicode is a set of 1 114 112 code points and UTF-8/16/32 are its encodings. ASCII is 7-bit, not 8. int's size is compiler-dependent (≥ 16 bits in C).

3Abstract Data Types

definition question ★
Definition An abstract data type (ADT) is a mathematical model of a type defined by its values and the operations on them (with their rules), not by how it is implemented. A data structure is a concrete way of arranging data in memory that implements an ADT. "Stack" is an ADT; "array with a top index" is one data structure that implements it.

Why ADTs — three benefits Encapsulation (information hiding): users see only the operations, so the representation can change without breaking them. Reusability: the same ADT can be implemented several ways and reused in many programs. Modularity: each module is written, tested and debugged on its own. Together they give data abstraction, the basis of classes in OOP.
Memory trick ADT = a menu; data structure = the kitchen. The menu lists what you can order (push, pop); the kitchen decides how it is cooked (array or list). Change the kitchen, keep the menu. Benefits: "E-R-M" — Encapsulation, Reusability, Modularity.
Exam trap BFS and DFS are algorithms run on a graph, not operations of the Graph ADT itself. A priority queue is not FIFO: it serves by priority. A linked list is a data structure; "List" is the ADT. Asked "an ADT defines…?" → behaviour, not storage.

4Arrays and Address Calculation

numerical MCQ ★
Definition An array is a fixed-size collection of elements of one type in contiguous memory, reached by index. Because the elements are contiguous and equally sized, the address of any element is computed by a formula, so access is O(1) (random access). Insertion or deletion in the middle shifts elements: O(n).
random access O(1)
Address formulas B = base address, w = bytes per element, L = lower bound.
1-D: LOC(A[i]) = B + w (i − L) · number of elements = U − L + 1.
2-D, m rows × n columns, row-major (C, C++, Java, Python): LOC(A[i][j]) = B + w [ (i − Lr) · n + (j − Lc) ].
2-D, column-major (Fortran, MATLAB): LOC(A[i][j]) = B + w [ (j − Lc) · m + (i − Lr) ].
Row-major multiplies by the number of columns n; column-major by the number of rows m.
Worked example ✍ 2-D, both orders int A[20][30] (0-based, m = 20, n = 30), B = 1000, w = 4. Find A[5][10].
Row-major: 1000 + 4 (5 × 30 + 10) = 1000 + 4 × 160 = 1640.
Column-major: 1000 + 4 (10 × 20 + 5) = 1000 + 4 × 205 = 1820.
Worked example ✍ non-zero lower bound A[5..50], B = 200, w = 2. Elements = 50 − 5 + 1 = 46. LOC(A[20]) = 200 + 2 (20 − 5) = 230.
A[−5..10] holds 10 − (−5) + 1 = 16 elements.

Sparse matrix Most elements are 0. Store only the non-zeros as triplets (row, col, value), or as a linked list. A 100 × 100 matrix with 50 non-zeros needs 3 × 50 = 150 cells instead of 10 000. An n × n lower-triangular matrix has n(n+1)/2 stored elements.
Exam trap Check the lower bound: with 1-based A[1..m][1..n], subtract 1 from i and j first. Read whether the question says row- or column-major. C has no bounds checking: A[10] in int A[10] is undefined behaviour, not an error message.

5Linked Lists: Singly, Doubly, Circular

pointer logic ★
Definition A linked list is a sequence of nodes, each holding data and a pointer to the next node; the nodes may lie anywhere in memory. A head pointer reaches the first node and the last node's next is NULL. Size grows and shrinks at run time; there is no random access, so reaching the k-th node is O(n).
struct Node { int data; struct Node *next; }; /* insert at head: O(1) */ struct Node *n = malloc(sizeof *n); n->data = x; n->next = head; head = n; /* delete the node after p: O(1) */ struct Node *t = p->next; p->next = t->next; free(t);

Memory trick "Link first, then cut." When inserting, set the new node's next before redirecting the old pointer, or the rest of the list is lost. Middle node: slow/fast pointers (fast moves 2, slow 1). Cycle: Floyd's tortoise and hare.
Exam trap Deleting a given node in a singly list needs its predecessor, so it costs O(n) to find it; in a doubly list it is O(1). Reversing a singly list takes O(n) time and O(1) space (three pointers: prev, curr, next).

6Stacks, Infix → Postfix and Postfix Evaluation

highest-yield ★
Definition A stack is a list in which insertion (push) and deletion (pop) happen at one end, the top: Last In, First Out. Array version: top = −1 means empty; push when top == MAX−1 is overflow; pop when top == −1 is underflow. Linked version pushes and pops at the head and never overflows (until memory runs out). All operations O(1).
void push(int x) { if (top == MAX-1) { puts("Overflow"); return; } s[++top] = x; } int pop(void) { if (top == -1) { puts("Underflow"); return -1; } return s[top--]; }
Applications function calls and recursion (the call stack holds return addresses and locals) · expression conversion and evaluation · balanced-parenthesis check · undo/redo · browser back · backtracking (maze, N-queens) · DFS · reversing a string. Every recursive algorithm can be rewritten with an explicit stack.
Infix → postfix rules Scan left to right. Operand → output. ( → push. ) → pop to output until "(". Operator → pop while the top has higher or equal precedence (equal only if left-associative), then push. At the end pop everything. ^ is right-associative.

Postfix needs no parentheses and no precedence rules, which is why compilers and calculators use it.
Memory trick "Stack of plates." The last plate washed is the first one used. For postfix evaluation, the second pop is the left operand: "pop B, pop A, compute A op B" — matters for − and /.
Exam trap 2 3 4 * + is 14, not 20; 20 would be 2 3 + 4 *. Pushing 1, 2, 3 in order can never pop as 3, 1, 2. Recursion that never reaches its base case ends in stack overflow.

7Queues: Linear, Circular, Deque, Priority

condition MCQs ★
Definition A queue inserts at the rear (enqueue) and deletes from the front (dequeue): First In, First Out. In a plain array front and rear only move forward, so freed slots are never reused ("full" while half empty); a circular queue wraps the indices with % n.
Circular queue (array of n)Condition
Enqueuerear = (rear + 1) % n; Q[rear] = x
Dequeuex = Q[front]; front = (front + 1) % n
Full(rear + 1) % n == front
Emptyfront == −1 (or front == rear in the one-slot-free form)
Elements(rear − front + n) % n (one-slot-free form)
Two conventions front = rear = −1 as empty: all n slots usable. front = rear = 0 as empty: one slot stays free, capacity n − 1.
Worked example ✍ trace Empty queue: enqueue(1), enqueue(2), enqueue(3) → [1, 2, 3]; dequeue() removes 1 → [2, 3]; enqueue(4) → [2, 3, 4]; dequeue() removes 2 → [3, 4]. Front = 3, rear = 4. The same pushes and pops on a stack leave [1, 2] with 2 on top.

Memory trick "Bank counter queue." Join at the back (rear), leave from the front. Double-Ended QUEue = deque. Uses: BFS, printer spooling, CPU scheduling, buffers between fast and slow devices.
Exam trap A priority queue is best built on a binary heap: insert and delete-max both O(log n) — an unsorted array makes delete O(n). A queue can be built from two stacks (amortised O(1)). "Which structure for BFS?" → queue; "for DFS?" → stack.

8Trees and Binary Trees

formula + traversal ★
Definition A tree is a connected acyclic hierarchy with one root; every other node has exactly one parent, so n nodes have n − 1 edges. A binary tree: at most two children (left, right). Terms: leaf, internal node, siblings, degree = number of children, level (root = 0), height = edges on the longest root-to-leaf path.

Kinds of binary tree Full / strict: every node has 0 or 2 children. Complete: all levels full except the last, filled from the left (heap shape). Perfect: every internal node has 2 children, all leaves on one level. Skewed: one child each — a list.
Array representation Store level by level. 0-based: left = 2i + 1, right = 2i + 2, parent = ⌊(i − 1)/2⌋. 1-based: left = 2i, right = 2i + 1, parent = ⌊i/2⌋. Ideal for complete trees; wasteful for skewed ones.
Worked example ✍ rebuild from two traversals Preorder A B D E C F, inorder D B E A F C. Preorder's first is the root A; in the inorder, D B E is its left subtree and F C its right. B roots the left part (D, E); C roots the right with F on its left. Postorder: D E B F C A. Inorder + pre/post fixes a tree uniquely; pre + post alone does not.
Memory trick The name says where the Node goes: Pre = node first, In = node in the middle, Post = node last; Left always comes before Right. BST: left < node < right, so its inorder is sorted.
Exam trap Check where the level count starts: with root at level 1, max nodes at level i = 2i−1 and in height h = 2h − 1. BST search is O(log n) on average but O(n) when skewed — hence AVL and red-black trees.
