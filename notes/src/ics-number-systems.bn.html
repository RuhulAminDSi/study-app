১পজিশনাল সংখ্যা পদ্ধতি

MCQ + লিখিত
সংজ্ঞা সংখ্যা পদ্ধতি হলো নির্দিষ্ট কিছু অঙ্ক (digit) ও একটি ভিত্তি বা বেস (base/radix) r দিয়ে সংখ্যা প্রকাশের নিয়ম; r = ব্যবহৃত ভিন্ন অঙ্কের মোট সংখ্যা, 0 সহ। অঙ্কগুলো 0 থেকে r − 1। পজিশনাল (positional) পদ্ধতিতে প্রতিটি অঙ্কের মান = অঙ্ক × rঅবস্থান।
মান N = dn−1rn−1 + … + d1r + d0 + d−1r−1 + d−2r−2 + …  (d = অঙ্ক, r = ভিত্তি)
পদ্ধতিভিত্তিঅঙ্কবড় অঙ্কউদাহরণঅন্য লিখনরীতি

অক্টাল80 – 77(157)8157Q · 0157 (C) · 0o157
দশমিক100 – 99(245)10245D
হেক্সাডেসিমাল160 – 9, A – FF = 15(2F)162FH · 0x2F

হেক্সের অক্ষর: A = 10, B = 11, C = 12, D = 13, E = 14, F = 15

কেন বাইনারি? ইলেকট্রনিক যন্ত্রের দুটি স্থিতিশীল অবস্থা থাকে (অন/অফ, উচ্চ/নিম্ন ভোল্টেজ, চুম্বকিত বা নয়)। দুটি স্তর তৈরি করা সহজ, গুলিয়ে যাওয়ার ভয় কম, আর সরাসরি বুলিয়ান লজিকের সাথে মেলে।
পরীক্ষার ফাঁদ যেকোনো ভিত্তিতে (10)r = r: 102 = 2, 108 = 8, 1016 = 16। রোমান সংখ্যা নন-পজিশনাল, এতে শূন্য নেই।
মনে রাখার কৌশল "ভিত্তি = কয়টি অঙ্ক; সবচেয়ে বড় অঙ্ক = ভিত্তি − 1।" তাই অক্টালে ৮ বা ৯ এবং বাইনারিতে ২ কখনো আসে না: (189)8 অবৈধ।

ডানের মানচিত্রটিই পুরো লেসন: পৃ. ৩ – ৫ প্রতিটি তীর পূর্ণাংশ ও ভগ্নাংশসহ দেখায়।

৩যেকোনো ভিত্তি → দশমিক

লিখিতে প্রিয়
পদ্ধতি প্রতিটি অঙ্কের নিচে তার স্থানীয় মান (place value) লেখো (বিন্দুর বাঁয়ে r0, r1, …; ডানে r−1, r−2, …), তারপর গুণ করে যোগ করো।
সমাধানকৃত উদাহরণ ✍
  1. (1011.101)2 = 8 + 0 + 2 + 1 + 0.5 + 0 + 0.125 = 11.625
  2. (157.4)8 = 1×64 + 5×8 + 7×1 + 4×0.125 = 64 + 40 + 7 + 0.5 = 111.5
  3. (3A7)16 = 3×256 + 10×16 + 7 = 768 + 160 + 7 = 935
  4. (2F.8)16 = 2×16 + 15 + 8/16 = 47.5  ·  (212)3 = 2×9 + 1×3 + 2 = 23
কৌশল: হর্নার "দ্বিগুণ করো, যোগ করো", বাঁ থেকে ডানে। (11001)2: 1 → 3 → 6 → 12 → 25। ভিত্তি r হলে r দিয়ে গুণ করে পরের অঙ্ক যোগ করো।
দ্রুত যাচাই শেষ অঙ্ক 0 হলে বাইনারি সংখ্যাটি জোড়; সবচেয়ে বাঁয়ের 1 আকার বলে দেয়: 1xxxx2 থাকে 16 … 31-এর মধ্যে।

৪দশমিক → যেকোনো ভিত্তি

হাই-ইল্ড
পূর্ণাংশ r দিয়ে বারবার ভাগ করো; প্রতিবার ভাগশেষ লেখো; ভাগফল 0 হলে থামো। ভাগশেষ পড়ো নিচ → উপর (প্রথম ভাগশেষ = LSD)।
ভগ্নাংশ r দিয়ে বারবার গুণ করো; প্রতিবার পূর্ণাংশটি নাও; ভগ্নাংশ 0 হলে (বা যথেষ্ট অঙ্ক পেলে) থামো। পড়ো উপর → নিচ (প্রথমটি = MSD)।
পূর্ণাংশের উদাহরণ ✍
  1. 245 ÷ 8 → ভাগশেষ 5, 6, 3 → (365)8
  2. 245 ÷ 16 → ভাগশেষ 5, 15 = F → (F5)16
  3. 1000 ÷ 16 → ভাগশেষ 8, 14 = E, 3 → (3E8)16
  4. 25 → (11001)2 · যাচাই: 16 + 8 + 1 = 25
শর্টকাট ছোট সংখ্যায় সবচেয়ে বড় ২-এর ঘাত বিয়োগ করো: 100 = 64 + 32 + 4 → (1100100)2।
ভগ্নাংশের উদাহরণ ✍

পরীক্ষার ফাঁদ (0.1)10 = (0.00011 0011 0011 …)2 কখনো শেষ হয় না। কোনো ভগ্নাংশ বাইনারিতে সসীম হয় কেবল তখনই, যখন এর হর ২-এর ঘাত (0.5, 0.25, 0.375 …)। এ কারণেই ফ্লোটিং পয়েন্টে 0.1 + 0.2 != 0.3।
মনে রাখার কৌশল "ভাগ → উপরে পড়ো, গুণ → নিচে পড়ো"। পূর্ণাংশ বিন্দু থেকে বাঁয়ে বাড়ে, ভগ্নাংশ বিন্দু থেকে ডানে।
ভিত্তি r → ভিত্তি s ✍ দশমিকের মাধ্যমে যাও (দুটোই ২-এর ঘাত হলে বাইনারির মাধ্যমে): (212)3 → 23 → (10111)2; (0.6875)10 × 8 → 5.5, 4.0 → (0.54)8।
নির্ভুলতা k টি ভগ্নাংশ-বিট 2−k মাপের ধাপ আলাদা করতে পারে। 0.1 কে 8 বিটে কাটলে = (0.00011001)2 = 0.09765625, তাই সংরক্ষিত মান রাউন্ড হয়।

৫বাইনারি ↔ অক্টাল ↔ হেক্সাডেসিমাল

হাই-ইল্ড
নিয়ম 8 = 23 এবং 16 = 24, তাই একটি অক্টাল অঙ্ক = ৩ বিট এবং একটি হেক্স অঙ্ক = ৪ বিট। র‍্যাডিক্স পয়েন্ট থেকে বাইরের দিকে গ্রুপ করো: পূর্ণাংশের বিট বাঁয়ে, ভগ্নাংশের বিট ডানে; দরকার হলে 0 বসাও শুধু বাইরের প্রান্তে।
সমাধানকৃত উদাহরণ ✍
  1. (10110001)2: 10|110|001 = (261)8; 1011|0001 = (B1)16
  2. (157)8 → 001 101 111 → 0110 1111 = (6F)16 (= 111)
  3. (3FA)16 → 0011 1111 1010 → 001 111 111 010 = (1772)8 (= 1018)
  4. (A5)16 = 1010 0101 = (245)8 = 165
পরীক্ষার ফাঁদ ভগ্নাংশের বিটে প্যাডিং ডানে: .1011 → .101 100 = .548, .001 011 = .138 নয়। অক্টাল ↔ হেক্সে সরাসরি গ্রুপিং নেই: বাইনারির মাধ্যমে যাও।
মনে রাখার কৌশল "অক্টাল-৩, হেক্স-৪": ২-এর ঘাতই গ্রুপের আকার। ভিত্তি 4 = 22 → ২ বিটের গ্রুপ; ভিত্তি 32 = 25 → ৫ বিটের গ্রুপ।

অঙ্কের সংখ্যা: n-বিট সংখ্যায় লাগে ⌈n/3⌉ টি অক্টাল ও ⌈n/4⌉ টি হেক্স অঙ্ক: 32 বিট = ৮টি হেক্স অঙ্ক, ১১টি অক্টাল অঙ্ক।

সমাধানকৃত উদাহরণ ✍ (11010)2 − (01111)2
বিট 0: 0 − 1 → ধার → 10 − 1 = 1
বিট 1: (1 − 1) − 1 → ধার → 1
বিট 2: (0 − 1) − 1 → ধার → 0

৯বাইনারি গুণ ও ভাগ

×-এর নিয়ম = AND: 0×0 = 0×1 = 1×0 = 0, 1×1 = 1। পদ্ধতি: শিফট করে যোগ।

÷ = দীর্ঘ ভাগ; প্রতি ধাপে ভাজক হয় একবার যায়, নয়তো যায় না।

(110110)2 ÷ (110)2 = (1001)2 · 100111 ÷ 101 = 111, ভাগশেষ 100 (39 ÷ 5 = 7, ভাগশেষ 4)

শিফটের নিয়ম k ঘর বাঁয়ে শিফট = × 2k; ডানে শিফট = ÷ 2k (পূর্ণাংশ)। 1011 << 2 = 101100 (11 → 44)।
