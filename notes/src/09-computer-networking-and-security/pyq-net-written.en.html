1Subnetting: One Method for Every Question

asked in 8 papers
  1. Prefix /n → mask. The interesting octet is the one that is neither 255 nor 0.
  2. Block size = 256 − mask octet (the "magic number").
  3. Network = largest multiple of the block ≤ the IP's octet.
  4. Broadcast = network + block − 1; usable = network + 1 … broadcast − 1; hosts = 2h − 2.

Q How many subnets and hosts are supported by the IPv4 address 192.68.25.16/28? · 38th BCS
Answer ✍ 192 lies in 192–223 → class C, default /24. /28 borrows 28 − 24 = 4 bits → 2⁴ = 16 subnets; host bits = 32 − 28 = 4 → 2⁴ − 2 = 14 hosts per subnet (16 × 14 = 224 usable in all). Subnet IDs: .0, .16, .32 … .240.
Exam trap "4" is the number of borrowed bits, not the number of subnets. And 192.68.25.16 is itself the network address of the block .16–.31, so it cannot be given to a host. (The old "2ⁿ − 2 subnets" rule, without subnet zero, would give 14.)
Q Why is a subnet mask used? · recruitment paper

① It marks which bits are network and which are host. ② A host ANDs the destination IP with the mask: same network → deliver directly (ARP), else → send to the default gateway. ③ It lets one block be split into smaller subnets (less broadcast traffic, better security and address use); routers use masks for longest-prefix matching.

Q How many bits are IPv4 and IPv6 addresses, and why is NAT not needed in IPv6? · RPGCL AM (ICT) 2022

32 vs 128 bits (2¹²⁸ ≈ 3.4 × 10³⁸). NAT only shares scarce public IPv4 addresses; in IPv6 every device gets a global unique address, so end-to-end connectivity returns and a firewall, not NAT, gives protection.

4SLAAC and the Routing Table

Q Describe IPv6 SLAAC: RS, RA, prefix info, address generation, DAD. · recruitment paper
  1. Link-local FE80::/64 + interface ID; DAD: Neighbor Solicitation, no reply → unique.
  2. RS (ICMPv6 133) to FF02::2.
  3. RA (134) to FF02::1: prefix info (2001:db8:1::/64, A-flag, lifetimes), M/O flags; router = gateway.
  4. /64 prefix + interface ID → global address; DAD again.

EUI-64: MAC 00:1A:2B:3C:4D:5E → insert FFFE, flip bit 7 → 021A:2BFF:FE3C:4D5E.

Exam trap 163.151 is not in 168.0/23 (168.0 – 169.255): no match → default route, Interface 4, not 2.

5Static Route, OSPF, Topology Maths

written
Q Static route configuration: configure R0 to reach PC1 (any vendor: Cisco, Huawei, Juniper). · Islamic Bank SO (Network) 2025
Cisco: R0(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2 Huawei: [R0] ip route-static 192.168.2.0 24 10.0.0.2 Juniper: set routing-options static route 192.168.2.0/24 next-hop 10.0.0.2 Verify: show ip route static · ping 192.168.2.10

No figure is printed, so state the assumed addressing (above). Syntax: destination network + mask + next hop (or exit interface). Static routes have AD = 1. For the ping reply, R1 needs the return route: ip route 192.168.1.0 255.255.255.0 10.0.0.1.

Q Using IP addressing and routing, explain how packets are delivered across networks with OSPF at the network layer. 10 marks · bank Assistant Programmer
  1. Addressing: the host ANDs the destination with its mask; remote → it ARPs for the default gateway's MAC and sends the frame there.
  2. Neighbours: OSPF routers send Hello to 224.0.0.5 every 10 s (dead 40 s); matching area, mask and timers → adjacency (DR/BDR on Ethernet).
  3. Link-state database: routers flood LSAs, so every router in the area holds the same map of the network.
  4. SPF: each router runs Dijkstra; cost = 10⁸ / bandwidth (100 Mbps → 1, T1 → 64); best routes enter the table (code O, AD 110).
  5. Forwarding: each hop does longest-prefix match, TTL − 1, new header checksum, new frame: MACs change at each hop, IPs stay.
  6. Failure: new LSA → SPF rerun → fast, loop-free convergence; areas (Area 0 = backbone) limit flooding.

Example: R1–R2 cost 10, R2–R3 cost 1, R1–R3 serial cost 64 → R1 reaches R3 via R2 (11 < 64).

Q NOC addressing/connectivity problem: change the subnet mask or install a new switch? Justify. · recruitment paper

Diagnose first. Out of IP addresses (DHCP pool empty, APIPA 169.254.x.x) → widen the mask, e.g. /24 → /23 (510 hosts), and update gateway, DHCP scope and routes. Out of ports or a failed link → add/stack a switch; it adds ports, not addresses. Scalability: VLANs + one subnet per function.

Q What is DNS poisoning and how does it work? · GTCL AE (CSE) 2022

The attacker races the real reply with forged responses (guessing the 16-bit query ID and port). The resolver caches bank.com → attacker IP, and every user of that resolver is sent to a fake site until the TTL expires. Defence: DNSSEC, random ports and IDs, DoT/DoH, no open recursion, HTTPS certificate checks.

Q Why is an edge server needed in modern network architecture? · Petrobangla AM (CSE) 2024

It processes and caches data near users: ① lower latency (real-time, 5G, IoT) ② less backbone bandwidth (CDN caches) ③ offloads and scales the origin ④ keeps working if the core link fails ⑤ absorbs DDoS, keeps data local.

Short answers ✍ recruitment paper UTP twisted? The two wires carry equal and opposite signals; twisting makes noise hit both alike, so it cancels at the receiver (less EMI and crosstalk; each pair has a different twist rate). Multicast vs broadcast: multicast = one-to-group that joined (IGMP, 224.0.0.0/4, crosses routers if enabled); broadcast = one-to-all in the LAN (255.255.255.255, MAC FF:FF:…), stopped by routers; IPv6 has no broadcast.

9Parity, Checksum, Hamming Code

numericals
Q Explain the parity method for error detection and write the ASCII bit string of "Delta". · Bangladesh Bank AME 2023

One extra bit makes the count of 1s even (or odd). 1011 has three 1s → even-parity bit 1 → send 10111. Receive 10110 → three 1s, odd → error. Catches any odd number of flipped bits, misses 2.

Exam trap 10110 has three 1s, not two, so even parity rejects it. "68 65 6C 74 61" are hex codes, not decimal (decimal: 68 101 108 116 97).
Q Explain the logic of a checksum and how it verifies data integrity in file transfer. 10 marks · bank Assistant Programmer
Sender: 1001, 1011, 1100 ✍
1001 + 1011 = 1 0100 → wrap: 0101
0101 + 1100 = 1 0001 → wrap: 0010
sum 0010 → checksum = 1101
Receiver: 1010, 1100, 0110 ✍
1010 + 1100 = 1 0110 → 0111; + 0110 = 1101
so the sender's checksum is 0010
1101 + 0010 = 1111 → complement 0000 → accept

Logic: k-bit words added in one's complement (carry wraps), the complement of the sum is sent; the receiver adds all incl. checksum → all 1s = intact, else resend. Internet checksum = 16-bit (IP, TCP, UDP). Files: compare a published CRC-32/SHA-256; only a hash/HMAC resists tampering.

Hamming corrects 1-bit errors (+ overall parity → SEC-DED). Parity at 1, 2, 4, 8 …; 2ʳ ≥ m + r + 1: m = 4 → r = 3 → 7 bits; m = 7 → 11; m = 8 → 12.

Encode 1011: P1 = D1⊕D2⊕D4 = 0, P2 = D1⊕D3⊕D4 = 1, P4 = D2⊕D3⊕D4 = 0 → 0110011. Bit 6 flips → 0110001: C4C2C1 = 110 → 6 → flip back.

Block: fixed blocks (AES, DES, Blowfish). Stream: a bit/byte at a time (RC4, Salsa20). Classical (Caesar, Vigenère: substitution, transposition, easily broken) vs modern (mathematical: AES, RSA, ECC). RSA = factoring; ECC = smaller keys (mobile, IoT); DH = key exchange only.
Q Identify the type of algorithm: (i) MD5 (ii) AES (iii) RSA (iv) Diffie–Hellman. · BAPEX AGM (ICT) 2023

(i) MD5: hash, 128-bit (collisions found) · (ii) AES: symmetric block cipher · (iii) RSA: asymmetric · (iv) Diffie–Hellman: key exchange (encrypts nothing itself).

Q Describe the high-level design of the Data Encryption Standard (DES). · BPDB AE (CSE) 2023
  1. 64-bit block, 56-bit key (+8 parity), 16 Feistel rounds; IP → rounds → swap → IP⁻¹.
  2. Li = Ri−1; Ri = Li−1 ⊕ F(Ri−1, Ki).
  3. F: expand 32 → 48, ⊕ Ki, 8 S-boxes (6 → 4) → 32, P-box.
  4. Keys: PC-1, shift 1–2 bits per round, PC-2 → 48-bit Ki; decrypt = keys reversed.
Q SHA-256 and SHA-512 in network security; the avalanche effect: desirable? · RPGCL AM (ICT) 2022
SHA-2 hashes with 256/512-bit digests: integrity, signatures, certificates, HMAC, blockchain. Avalanche: 1 flipped input bit changes ~50% of output bits; desirable, so nothing leaks.
Q End-to-end encryption at the transport layer vs the application layer. · recruitment paper
Transport (TLS): transparent and cheap, but the server/proxy sees plaintext. Application (Signal, PGP): only the recipient decrypts; costs more (key management).

Q What are XSS and SQL injection; how do they work and how are they prevented?  ·  What is CSRF: mechanism and prevention? · Islamic Bank SO (Network) 2025
SQL injection: input is pasted into a query: ' OR '1'='1 makes WHERE always true. Fix: prepared statements, input validation, least-privilege DB user.
ps = con.prepareStatement( "SELECT * FROM users WHERE id = ?"); ps.setString(1, userId);
XSS: attacker's script (<script>…) is stored or reflected into a page and runs in victims' browsers (steals cookies). Fix: output encoding, input validation, Content-Security-Policy, HttpOnly cookies.
CSRF: a logged-in victim visits an evil page that silently submits a request to the bank; the browser adds the session cookie, so the bank obeys. Fix: anti-CSRF token, SameSite cookies, Origin/Referer check, re-authenticate for transfers, no state change on GET.
Q Why is a zero-day attack dangerous for ICB? Two reasons. · ICB Securities AP 2026
① No patch or signature exists yet, so antivirus/IDS miss it and the hole stays open until the vendor fixes it. ② ICB holds investor funds, trading data and real-time systems: theft, fraud, downtime, regulatory penalty, lost trust. Mitigate: segmentation, least privilege, behaviour-based EDR, WAF/IPS virtual patching, backups.
Q Blacklisting vs whitelisting: which is more secure, and why? · recruitment paper
Blacklist = allow all, block known bad; whitelist = deny all, allow only approved. Whitelisting is more secure: default-deny stops new and unknown threats. Cost: more admin work.
Exam trap Calling the blacklist "more secure" is wrong: a blacklist can only block what is already known, so a zero-day passes it.

Written question For host 172.16.45.200/20 find the mask, network address, broadcast address, usable range and number of hosts. A router holds 172.16.32.0/20 → G0/0 and 172.16.0.0/16 → G0/1: which interface does it use for this host, and why? 8 marks
  1. /20 = 255.255.240.0; interesting octet = 3rd; block = 256 − 240 = 16 1
  2. 45 → largest multiple of 16 ≤ 45 = 32 → network 172.16.32.0 2
  3. Broadcast = 32 + 15 = 47 → 172.16.47.255; usable 172.16.32.1 – 172.16.47.254 2
  4. Hosts = 2¹² − 2 = 4,094 1
  5. Both routes match, but /20 is longer than /16 → longest-prefix match picks G0/0 2
