১স্ট্রাকচার: ডিক্লারেশন, ডেফিনিশন, ইনিশিয়ালাইজেশন

ভিত্তি ★
সংজ্ঞা স্ট্রাকচার (Structure, struct) হলো একটি ইউজার ডিফাইনড টাইপ, যা সাধারণত ভিন্ন ভিন্ন টাইপের সম্পর্কিত ভেরিয়েবলকে এক নামে একত্র করে। ভেতরের প্রতিটি ভেরিয়েবল একটি মেম্বার (Member, ফিল্ড)। মেম্বারগুলো ডিক্লেয়ার করার ক্রমে সাজানো থাকে এবং প্রতিটি মেম্বারের নিজস্ব মেমোরি থাকে। স্ট্রাকচার টাইপ (টেমপ্লেট) ডিক্লেয়ার করলে কোনো মেমোরি লাগে না; ওই টাইপের ভেরিয়েবল ডিফাইন করলে মেমোরি বরাদ্দ হয়।
#include <stdio.h> #include <string.h> struct Student { /* tag */ int id; char name[50]; float marks; }; /* ; needed */ int main(void) { struct Student s1; s1.id = 101; strcpy(s1.name, "Ruhul"); s1.marks = 85.5f; printf("%d %s %.2f\n", s1.id, s1.name, s1.marks); return 0; /* 101 Ruhul 85.50 */ }
ভেরিয়েবল তৈরির উপায়কোডমন্তব্য
টাইপের পরেstruct Student s1, s2;C-তে struct কিওয়ার্ড লাগবেই
ডিক্লারেশনের সাথেইstruct Student { … } s1, s2;টাইপ ও ভেরিয়েবল একসাথে
নামহীন (anonymous) structstruct { int x, y; } pt;ট্যাগ নেই: পরে আর ভেরিয়েবল নয়
পজিশনাল ইনিশিয়ালাইজার= {101, "Ruhul", 85.5f}মেম্বারের ক্রমে
ডেজিগনেটেড ইনিশিয়ালাইজার (C99)= {.marks = 85.5f, .id = 101}যেকোনো ক্রমে; name[] হয় ""
আংশিক / শূন্য= {101} · = {0}যে মেম্বার দেওয়া নেই সেটি শূন্য
মনে রাখার কৌশল "struct হলো ফাঁকা ফর্ম; ভেরিয়েবল হলো পূরণ করা কপি।" ফাঁকা ফর্মের নকশায় কাগজ লাগে না (মেমোরি নেই); প্রতিটি পূরণ করা কপিতে লাগে।
পরীক্ষার ফাঁদ s1.name = "Ruhul"; কম্পাইল এরর: অ্যারেতে অ্যাসাইন করা যায় না। strcpy() ব্যবহার করো, বা ডেফিনিশনের সময় ইনিশিয়ালাইজ করো। }-এর পরে ; ভুলে গেলেও এরর।
সমাধানকৃত উদাহরণ ✍ sizeof 4-বাইট int/float ধরে: 4 + 50 = 54, marks-এর জন্য 56 পর্যন্ত প্যাড, + 4 → sizeof(struct Student) = 60, 58 নয়।

২মেম্বার অ্যাক্সেস: . বনাম ->; স্ট্রাকচার ও ফাংশন

সবচেয়ে বেশি আসে ★
সংজ্ঞা ডট অপারেটর (Dot operator) . স্ট্রাকচার ভেরিয়েবল থেকে মেম্বার নেয়। অ্যারো অপারেটর (Arrow operator) -> স্ট্রাকচারের পয়েন্টার-এর মাধ্যমে মেম্বার নেয়: p->x হুবহু (*p).x। ব্র্যাকেট জরুরি: ইউনারি *-এর চেয়ে .-এর প্রায়োরিটি বেশি, তাই *p.x মানে *(p.x)।
struct point { int x, y; }; struct point p = {3, 4}; struct point *q = &p; q->x = q->y * 2; printf("%d %d", p.x, p.y); /* Output: 8 4 */ void byVal(struct point a) { a.x = 0; } void byPtr(struct point *a) { a->x = 0; } /* byVal(p): p unchanged (copy) byPtr(&p): p.x becomes 0 */
এক্সপ্রেশনঅর্থএক্সপ্রেশনঅর্থ
p->x(*p).x++p->x++(p->x): মেম্বার বাড়ে
*p.x*(p.x): x-কে পয়েন্টার হতে হবেp++->xx পড়ে, তারপর p এগোয়
&s.x&(s.x): মেম্বারের অ্যাড্রেস*p->nameনামের প্রথম অক্ষর
পুরো স্ট্রাকচারে অপারেশনচলে?কেন / কীভাবে
অ্যাসাইনমেন্ট s2 = s1;হ্যাঁমেম্বার-বাই-মেম্বার কপি, ভেতরের অ্যারেসহ (একই টাইপ হলে)
তুলনা s1 == s2না: কম্পাইল এররমেম্বার ধরে ধরে তুলনা; memcmp প্যাডিংও তুলনা করতে পারে
ফাংশনে পাঠানো / ফেরত দেওয়াহ্যাঁবাই ভ্যালু পুরো struct কপি করে; বড় struct-এ পয়েন্টার পাঠাও
মনে রাখার কৌশল "বাক্স হাতে থাকলে ডট, বাক্সের দিকে আঙুল তুললে অ্যারো।" ভেরিয়েবলের নাম → .; পয়েন্টার → ->।
পরীক্ষার ফাঁদ পাস-বাই-ভ্যালু কাজ করে কপির ওপর: byVal(p)-এর পর p অপরিবর্তিত। আর :: কেবল C++-এর; C-তে মেম্বারের জন্য স্কোপ অপারেটর নেই।
সমাধানকৃত উদাহরণ ✍ struct ফেরত struct point mid(struct point a, struct point b) { struct point m = {(a.x+b.x)/2, (a.y+b.y)/2}; return m; } mid({2,4},{6,8}) → {4, 6}।

৩স্ট্রাকচারের অ্যারে; নেস্টেড ও সেলফ-রেফারেন্সিয়াল স্ট্রাকচার

আউটপুট প্রশ্ন ★
সংজ্ঞা স্ট্রাকচারের অ্যারে (Array of structures) একই টাইপের অনেক রেকর্ড পাশাপাশি রাখে: struct Student st[3]; → st[0].id, st[2].name। অ্যারের পয়েন্টার প্রতি p++-এ একটি পুরো স্ট্রাকচার এগোয় (struct-এর sizeof, ১ বাইট নয়)। নেস্টেড স্ট্রাকচার-এর একটি মেম্বার নিজেই struct; সেলফ-রেফারেন্সিয়াল স্ট্রাকচার-এর একটি মেম্বার নিজের টাইপের পয়েন্টার।
struct pt { int x, y; }; /* 8 B */ struct pt a[3] = {{1,2},{3,4},{5,6}}; struct pt *p = a; /* &a[0] */ p += 2; /* a[2] */ printf("%d %d", p->x, (p-1)->y + a[0].x); /* 5 5; a at 1000 -> p = 1016 */ struct Date { int d, m, y; }; struct Emp { char name[20]; struct Date dob; /* nested */ } e, *pe = &e; e.dob.y = 1995; pe->dob.m = 6;
struct node { int data; struct node *next; /* OK */ /* struct node n; -> error */ }; struct node c = {30, NULL}; struct node b = {20, &c}; struct node a1 = {10, &b}; printf("%d", a1.next->next->data); /* Output: 30 */
ধরনমেম্বারসাইজ (4-বাইট int, 8-বাইট পয়েন্টার)অ্যাক্সেস
স্ট্রাকচারের অ্যারেstruct pt a[3]3 × 8 = 24a[i].x, (p+i)->x
নেস্টেডEmp-এ struct Date dob20 + 12 = 32e.dob.y, pe->dob.y
সেলফ-রেফারেন্সিয়ালstruct node *next4 + 4 প্যাড + 8 = 16 (32-বিটে 8)n->next->data
মনে রাখার কৌশল "বাক্স নিজের মতো বাক্সের ঠিকানা রাখতে পারে, নিজেকে নয়।" নিজেকে ধারণ করা struct অসীম বড় হতো।
পরীক্ষার ফাঁদ struct pt *-এ p++ যোগ করে 8 বাইট (sizeof), ১ নয়। e.dob.y-তে দুটি ডটই লাগবে; pe->dob->y ভুল, কারণ dob পয়েন্টার নয়।
সমাধানকৃত উদাহরণ ✍ হাঁটা for (p = a; p < a + 3; p++) sum += p->y; → 2 + 4 + 6 = 12। (আসল লিস্টে নোড আসে malloc থেকে: পয়েন্টার লেসন।)

৪sizeof, প্যাডিং ও অ্যালাইনমেন্ট

গাণিতিক MCQ ★
সংজ্ঞা CPU অ্যালাইনড (Aligned) অ্যাড্রেস থেকে সবচেয়ে দ্রুত পড়ে, তাই কম্পাইলার প্রতিটি মেম্বারকে তার অ্যালাইনমেন্টের গুণিতক অফসেটে বসায় এবং প্রয়োজনে অব্যবহৃত প্যাডিং বাইট (Padding) ঢোকায়। তারপর পুরো struct-কে তার সবচেয়ে বড় মেম্বার-অ্যালাইনমেন্টের গুণিতকে রাউন্ড আপ করে, যাতে এর অ্যারেও অ্যালাইনড থাকে। তাই sizeof(struct) ≥ মেম্বারের যোগফল।

ধরে নেওয়া (সাধারণ 64-বিট GCC/Clang/MSVC): char 1 · short 2 · int, float 4 · double, long long, পয়েন্টার 8 — প্রত্যেকে নিজের সাইজে অ্যালাইনড।

struct-এর মেম্বার (ক্রমানুসারে)বিন্যাস (অফসেট)sizeof
char c; int i; char d;c@0, প্যাড 3, i@4, d@8, প্যাড 312
int i; char c; char d;i@0, c@4, d@5, প্যাড 28
char c; double d;c@0, প্যাড 7, d@816
char c; short s; int i;c@0, প্যাড 1, s@2, i@48
char a; double b; int c;a@0, প্যাড 7, b@8, c@16, শেষে প্যাড 424
double b; int c; char a;b@0, c@8, a@12, শেষে প্যাড 316
int a; char b[5];a@0, b@4..8, শেষে প্যাড 312
char c; int *p;c@0, প্যাড 7, p@8 (32-বিটে: প্যাড 3, p@4)16 (8)
মনে রাখার কৌশল "বড় পাথর আগে।" মেম্বারগুলো বড় থেকে ছোট অ্যালাইনমেন্টে (double → int → short → char) সাজালে প্যাডিং প্রায় থাকে না।
পরীক্ষার ফাঁদ প্যাডিং ইমপ্লিমেন্টেশন-ডিফাইনড। 32-বিট Linux-এ (i386) struct-এর ভেতরে double 4-অ্যালাইনড, তাই সেখানে {char; double} = 12। অপশনে প্যাডসহ মান না থাকলে প্রশ্নকর্তা প্যাডিং ছাড়া (সরল যোগফল) ধরেছেন।
সমাধানকৃত উদাহরণ ✍ ধাপে ধাপে {char a; double b; int c;}: 1 → 8 পর্যন্ত প্যাড → +8 = 16 → +4 = 20 → 8-এর গুণিতকে = 24।
প্যাকিং #pragma pack(1) (বা GCC __attribute__((packed))) প্যাডিং সরায়: {char c; int i; char d;} হয় 6 বাইট, তবে আনঅ্যালাইনড অ্যাক্সেস ধীর। ফাইল ফরম্যাট ও নেটওয়ার্ক হেডারে ব্যবহৃত।

প্রায়ই আসে
সংজ্ঞা বিট-ফিল্ড (Bit-field) হলো এমন struct মেম্বার যার প্রস্থ বিটে নির্দিষ্ট করা: type name : width;। টাইপ হতে হবে int, signed int, unsigned int বা _Bool (কম্পাইলার অন্যগুলোও দিতে পারে)। পাশাপাশি বিট-ফিল্ডগুলো একটি স্টোরেজ ইউনিটে (সাধারণত একটি int) ঠাসা হয়, ফলে ফ্ল্যাগ, ছোট কাউন্টার ও হার্ডওয়্যার রেজিস্টারে মেমোরি বাঁচে।
struct Date { unsigned day : 5; /* 0-31 */ unsigned month : 4; /* 0-15 */ unsigned year : 12; /* 0-4095 */ }; /* 21 bits -> 4 bytes */ struct Date d = {14, 10, 2026}; printf("%u/%u/%u", d.day, d.month, d.year); /* 14/10/2026; 3 ints: 12 B */ struct { unsigned x : 3; } s; s.x = 9; /* 9 = 1001b, keeps 001 */ printf("%u", s.x); /* 1 */

প্রস্থ ≤ টাইপের বিট-সংখ্যা; প্রস্থ 0 কেবল নামহীন ফিল্ডেint a : 33; (32-বিট int) → এরর
নামহীন : 0 পরের ফিল্ডকে নতুন ইউনিটে ঠেলে দেয়{unsigned a:4; unsigned :0; unsigned b:4;} = 8
ইউনিটের বাকি অংশে না ধরলে ফিল্ড নতুন ইউনিটে যায় (GCC){unsigned a:30; unsigned b:4;} = 8

সাধারণ int ফিল্ড signed না unsigned, তা ইমপ্লিমেন্টেশন-ডিফাইনডint f:1 কেবল 0 ও −1 রাখতে পারে

পরীক্ষার ফাঁদ unsigned ফিল্ডে বড় মান রাখলে কেবল নিচের বিটগুলো থাকে (মান mod 2width): 3 বিটে 9 → 1। signed ফিল্ডে ফল ইমপ্লিমেন্টেশন-ডিফাইনড (GCC: int a:2; a = 3; → −1)।
সমাধানকৃত উদাহরণ ✍ রেঞ্জ unsigned m : 4 রাখে 0 থেকে 24 − 1 = 15; ১২ মাসের জন্য যথেষ্ট। দিনের ফিল্ডে লাগে 5 বিট (31 ≤ 31)।

সবচেয়ে বেশি আসে ★
সংজ্ঞা ইউনিয়ন (Union) স্ট্রাকচারের মতোই ডিক্লেয়ার করা হয়, কিন্তু সব মেম্বার একই অ্যাড্রেস থেকে শুরু হয় (অফসেট 0) এবং একে অপরের ওপর পড়ে। এর সাইজ সবচেয়ে বড় মেম্বার, রাউন্ড আপ করা — কঠোরতম মেম্বার-অ্যালাইনমেন্টের গুণিতকে। একটি মেম্বারে লিখলে অন্যগুলো মুছে যায়, তাই কেবল সর্বশেষ লেখা মেম্বারের মানই অর্থবহ। উদ্দেশ্য: কয়েকটি টাইপের মধ্যে একসাথে একটিই লাগলে মেমোরি বাঁচানো।
union Data { int i; float f; char str[20]; }; /* sizeof = 20 */ union Data d; d.i = 10; printf("%d\n", d.i); d.f = 3.14f; printf("%.2f\n", d.f); strcpy(d.str, "Hello"); printf("%s\n", d.str); /* 10 / 3.14 / Hello: each read comes right after its write */ d.f = 3.14f; printf("%d", d.i); /* 1078523331 */

union { char c[5]; int i; }54 → 5 রাউন্ড আপ8

/* endianness check */ union { int i; char c[4]; } u; u.i = 1; puts(u.c[0] == 1 ? "little-endian" : "big-endian"); /* x86 / ARM default: little */
/* tagged union */ struct Value { enum { INT, FLT } tag; union { int i; float f; } v; }; /* read v.i only if tag == INT */
মনে রাখার কৌশল "struct = দালানের আলাদা ফ্ল্যাট; union = এক ঘর, অনেক ভাড়াটে।" কেবল সর্বশেষ ওঠা ভাড়াটেই আসলে সেখানে থাকে।
পরীক্ষার ফাঁদ union Data d = {10}; কেবল প্রথম মেম্বার (i) ইনিশিয়ালাইজ করে। অন্যটির জন্য {.f = 2.5f} (C99)। ইউনিয়নের সাইজ যোগফল নয়। 1078523331 = 0x4048F5C3, অর্থাৎ 3.14f-এর বিট প্যাটার্ন।
সমাধানকৃত উদাহরণ ✍ বাইট লিটল-এন্ডিয়ান PC-তে u.i = 0x41424344; হলে u.c[0] সবচেয়ে নিচের বাইট 0x44 → printf("%c", u.c[0]) ছাপে D।

৭এনুমারেশন (enum)

আউটপুট প্রশ্ন ★
সংজ্ঞা এনুমারেশন (Enumeration) হলো নামযুক্ত ইন্টিজার কনস্ট্যান্ট (এনুমারেটর) দিয়ে গঠিত ইউজার ডিফাইনড টাইপ। মান না দিলে প্রথম এনুমারেটর 0 এবং পরের প্রতিটি আগেরটি + 1। এনুমারেটর int টাইপের কনস্ট্যান্ট; এতে কোড পড়া সহজ হয় (if (day == 5)-এর বদলে if (day == Friday))।
enum Week { Sunday, Monday, Tuesday, Wednesday, Thursday, Friday, Saturday }; enum Week today = Wednesday; printf("%d", today); /* 3 */ enum Month { Jan = 1, Feb, Mar, Apr }; /* 1 2 3 4 */ enum color { RED, GREEN = 5, BLUE }; printf("%d %d", RED, BLUE); /* 0 6 */ enum { A, B = 5, C, D = 2, E }; /* 0, 5, 6, 2, 3 */
নিয়মউদাহরণ / ফল

ঋণাত্মক মান চলেenum { N = -2, M }; → M = −1
মান হতে হবে ইন্টিজার কনস্ট্যান্ট এক্সপ্রেশনenum { X = 2.5 }; → এরর; C = B + 3 ✓
এনুমারেটর সাধারণ আইডেন্টিফায়ারের নেমস্পেস ভাগ করেএকই স্কোপে enum A {X}; enum B {X}; → এরর
এনুমারেটর কনস্ট্যান্ট, ভেরিয়েবল নয়RED++; বা RED = 3; → এরর

মানকেবল ইন্টিজার; স্বয়ংক্রিয় নম্বরযেকোনো কিছু (float, string); প্রতিটি হাতে লেখা

মনে রাখার কৌশল "শূন্যে শুরু, পরে এক এক করে বাড়ে, দেওয়া মান গোনা নতুন করে শুরু করায়।"
পরীক্ষার ফাঁদ নির্দিষ্ট মানের পর গোনা চলে সেই মান থেকে, অবস্থান থেকে নয়: {RED, GREEN = 5, BLUE}-এ BLUE হলো 6, 2 নয়।

তথ্য পাতা

struct: প্রতি মেম্বারের নিজস্ব মেমোরি

union: সব মেম্বার অফসেট 0-তে

sizeof(struct) = মেম্বার + প্যাডিং

sizeof(union) = সবচেয়ে বড়টি, রাউন্ড আপ

p->x ≡ (*p).x

*p.x ≡ *(p.x)

s2 = s1 ✓ · s1 == s2 ✗

union ইনিশিয়ালাইজ → কেবল প্রথম মেম্বার

enum কনস্ট্যান্টের টাইপ = int

  2. সাইজ (৩) — struct: 4 + 4 + 10 = 18 → 4-এর গুণিতকে = 20; union: সবচেয়ে বড় 10 → 4-এর গুণিতকে = 12। ৩
