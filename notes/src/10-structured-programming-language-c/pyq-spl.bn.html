৫টি পরীক্ষা
প্র১৪ দুটি সংখ্যার গ.সা.গু নির্ণয়ের জন্য অ্যালগরিদম লিখুন। / দুইটি সংখ্যার গ.সা.গু নির্ণয়ের জন্য ফ্লোচার্ট অঙ্কন করুন ও অ্যালগরিদম লিখুন।17th NTRCA School (2023) · 18th NTRCA School (2024)

ইউক্লিডের অ্যালগরিদম: GCD(a, b) = GCD(b, a mod b); b = 0 হলে থামো।

  1. শুরু; A, B পড়ো।
  2. যতক্ষণ B ≠ 0: R ← A mod B; A ← B; B ← R।
  3. A প্রিন্ট করো (এটিই GCD); থামো।
int a, b, r; scanf("%d %d", &a, &b); while (b != 0) { r = a % b; a = b; b = r; } printf("GCD = %d\n", a);

ইনপুট 96 36 → GCD = 12  (96,36 → 36,24 → 24,12 → 12,0)

প্র১৫ দুটি পূর্ণসংখ্যা A ও B ইনপুট দেওয়া আছে; A ও B-এর ল.সা.গু (LCM) নির্ণয়ের প্রোগ্রাম লিখুন।BB AP 2023
long long a, b, x, y, r; scanf("%lld %lld", &a, &b); x = a; y = b; while (y != 0) { r = x % y; x = y; y = r; } /* x = GCD */ printf("LCM = %lld\n", a / x * b);

LCM = a × b / GCD; আগে ভাগ করুন (a / gcd * b), যাতে গুণফল overflow না করে। ইনপুট 12 18 → LCM = 36 (একই প্রশ্নপত্রে দুবার ছাপা, একবার "LCN" নামে)।

প্র১৬ ইনপুটকৃত কোনো সংখ্যার ফ্যাক্টোরিয়াল বের করার এলগরিদম লিখুন, ফ্লোচার্ট অংকন করুন এবং C ভাষায় প্রোগ্রাম লিখুন।15th NTRCA CSE
  1. শুরু; N পড়ো।
  2. F ← 1, I ← 1.
  3. যতক্ষণ I ≤ N: F ← F × I; I ← I + 1।
  4. F প্রিন্ট করো; থামো।

ফ্লোচার্ট: GCD চার্টের লুপটিই, সিদ্ধান্ত "I ≤ N ?" আর প্রক্রিয়া বাক্স "F = F × I; I = I + 1"।

int n, i; long long f = 1; scanf("%d", &n); for (i = 1; i <= n; i++) f = f * i; printf("%d! = %lld\n", n, f);

ইনপুট 5 → 5! = 120

মনে রাখার কৌশল GCD লুপ = "ভাগশেষ, সরাও, আবার": r = a % b; a = b; b = r। LCM = গুণফল ÷ GCD।
