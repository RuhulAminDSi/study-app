Q14 Write an algorithm to find the GCD (গ.সা.গু) of two numbers. / Draw a flowchart and write the algorithm for the GCD of two numbers.17th NTRCA School (2023) · 18th NTRCA School (2024)

Euclid's algorithm: GCD(a, b) = GCD(b, a mod b); stop when b = 0.

  1. Start; read A, B.
  2. While B ≠ 0: R ← A mod B; A ← B; B ← R.
  3. Print A (the GCD); stop.
int a, b, r; scanf("%d %d", &a, &b); while (b != 0) { r = a % b; a = b; b = r; } printf("GCD = %d\n", a);

input 96 36 → GCD = 12  (96,36 → 36,24 → 24,12 → 12,0)

Q15 Given two integers A and B as input, write a program to compute the least common multiple (LCM) of A and B.BB AP 2023
long long a, b, x, y, r; scanf("%lld %lld", &a, &b); x = a; y = b; while (y != 0) { r = x % y; x = y; y = r; } /* x = GCD */ printf("LCM = %lld\n", a / x * b);

LCM = a × b / GCD; divide first (a / gcd * b) so the product cannot overflow. input 12 18 → LCM = 36 (the same paper printed it twice, once as "LCN").

Q16 Write an algorithm, draw a flowchart and write a C program to find the factorial of an input number.15th NTRCA CSE
  1. Start; read N.
  2. F ← 1, I ← 1.
  3. While I ≤ N: F ← F × I; I ← I + 1.
  4. Print F; stop.

Flowchart: the GCD chart's loop with the decision "I ≤ N ?" and the process box "F = F × I; I = I + 1".

int n, i; long long f = 1; scanf("%d", &n); for (i = 1; i <= n; i++) f = f * i; printf("%d! = %lld\n", n, f);

input 5 → 5! = 120

Memory trick GCD loop = "remainder, shift, repeat": r = a % b; a = b; b = r. LCM = product ÷ GCD.

Q17 What is structured programming / a structured programming language? Explain with an example. / What are the main objectives of structured programming? Write two advantages. / Define program, identifier and structured language.38th BCS (2018) · SPARRSO 2020 · 13th NTRCA CSE (2016)
Structured programming writing a program from three control structures only — sequence, selection (if/switch), iteration (loops) — divided top-down into functions (modules) with one entry and one exit each, and no goto. Languages: C, Pascal, ALGOL, Ada.

Objectives: readable, reliable, easy to test and maintain code. Advantages: ① easy to read and debug, because control flows top to bottom; ② modules can be written, tested and reused separately. Definitions: a program is a set of instructions that tells the computer how to solve a problem; an identifier is the name of a variable, function or array (letters, digits, _; not starting with a digit; not a keyword).
