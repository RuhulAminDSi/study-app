Q Define recursion. Write a C program to calculate the factorial of a number using recursion.

asked in a recruitment paper (2025)

Recursion A function that calls itself on a smaller input. It needs a base case (stops the calls) and a recursive case (moves towards the base). Every call gets its own stack frame; without a base case the stack overflows.
unsigned long long fact(int n) { if (n <= 1) return 1; /* base */ return n * fact(n - 1); /* recursive */ } int main(void) { int n; scanf("%d", &n); printf("%d! = %llu\n", n, fact(n)); return 0; }
Trace for n = 5 ✍
fact(5) = 5 × fact(4)
= 5 × 4 × fact(3) = … = 5 × 4 × 3 × 2 × 1
Output: 5! = 120
20! fits in unsigned long long; 21! overflows

4The Digit Loop: Sum, Reverse, Palindrome

high-yield
One loop, three questions n % 10 gives the last digit; n / 10 drops it. Repeat while n ≠ 0. Add the digits → digit sum; build rev = rev × 10 + digit → reverse; compare rev with the original → palindrome.

6Structured Programming

BCS theory
Q What is a structured programming language? Explain with an example.

38th BCS Written · 2018  ·  also a bank IT viva

Definition Structured programming builds a program only from three control structures, sequence, selection (if/switch) and iteration (loops), each with one entry and one exit, organised top-down into functions, and avoids goto. Böhm–Jacopini (1966): these three are enough for any algorithm. Languages: C, Pascal, ALGOL, Ada, FORTRAN 77.
int sumTo(int n) { /* module */ int s = 0; /* sequence */ for (int i = 1; i <= n; i++) /* loop */ if (i % 2 == 0) /* selection */ s += i; return s; /* one exit */ }
  • Top-down: split the problem into functions
  • Modular: each function does one job
  • Readable, easy to test, debug and maintain
  • Data and functions are separate (unlike OOP)

71-D Arrays and Passing Them to Functions

BCS 5 marks
Q How can we initialize a 1-D array? How can we pass the array to a function in C? 5 marks

45th BCS Written (CSE-971) · 31.01.2024

int a[5] = {1, 2, 3, 4, 5}; /* full */ int b[] = {7, 8, 9}; /* size 3 */ int c[5] = {1, 2}; /* 1 2 0 0 0 */ int d[5] = {0}; /* all zero */ void show(int a[], int n); /* or int *a */ show(a, 5); /* call */

An array argument decays to a pointer to its first element: int a[], int a[5] and int *a mean the same parameter. The function can change the caller's elements, and it cannot know the length, so pass n as well.

Exam trap Inside show(), sizeof a = size of a pointer (8 on 64-bit), not 5 × 4 = 20. Use sizeof a / sizeof a[0] only where the array is declared.

10Is the Array Ascending, Descending or Unordered?

Q Write a program in C, C++ or Java that determines whether an integer array is in ascending order, descending order, or unordered: {−3,−2,−1,0,1,2} ascending; {2,1,0,−1,−2,−3} descending; {2,1,−3,0,−2,−1} unordered.

BUET MSc in CSE · 03.10.2026

int order(int a[], int n) { /* 1 asc, -1 desc, 0 */ int asc = 1, desc = 1; for (int i = 1; i < n; i++) { if (a[i] < a[i - 1]) asc = 0; if (a[i] > a[i - 1]) desc = 0; } if (asc) return 1; if (desc) return -1; return 0; }

Compare each neighbour pair once and clear a flag when a pair breaks the order. The three sample arrays give Ascending, Descending, Unordered.

One pass: O(n). Equal neighbours break neither flag, so {1, 1, 2} counts as ascending (non-decreasing).

#include <string.h> void removeSub(char *s, const char *sub) { size_t k = strlen(sub); char *p; if (k == 0) return; while ((p = strstr(s, sub)) != NULL) /* find */ memmove(p, p + k, strlen(p + k) + 1); /* close gap */ } /* char s[] = "programming"; removeSub(s, "gram"); */
  1. strstr finds "gram" at index 3: programming
  2. memmove shifts "ming\0" left by k = 4

RPGCL Assistant Manager (ICT) · 2022 (BUET)

Rule Exactly 4 parts separated by 3 dots; each part is 1–3 digits, value 0–255, no leading zero (0 is fine, 01 is not), nothing else.
#include <ctype.h> int validIPv4(const char *s) { int parts = 0; for (;;) { int val = 0, len = 0; while (isdigit((unsigned char)*s)) { if (len == 1 && val == 0) return 0; /* 0x */ val = val * 10 + (*s++ - '0'); if (++len > 3 || val > 255) return 0; } if (len == 0) return 0; /* empty/letter */ parts++; if (*s == '\0') return parts == 4; if (*s != '.' || parts == 4) return 0; s++; /* skip the dot */ } }

19Prime Check: Algorithm and Code

asked twice
Q Write an algorithm to check whether a number is prime or not. / Write a Java program to determine whether a given integer is prime.

NSDA Assistant Programmer · 04.03.2022  ·  Islamic Bank PLC SQA, Senior Officer (Network) · 14.03.2025

  1. Start; read n
  2. If n < 2 → print "not prime", stop
  3. i ← 2
  4. While i × i ≤ n: if n mod i = 0 → "not prime", stop; else i ← i + 1
  5. Print "prime"; stop
static boolean isPrime(int n) { if (n < 2) return false; // 0, 1, negatives for (int i = 2; i <= n / i; i++) // i*i <= n if (n % i == 0) return false; return true; } // System.out.println(isPrime(29)); true

Why stop at √n: if n = a × b with a ≤ b, then a ≤ √n, so a divisor would already have been found. Cost O(√n) (checking up to n/2 is correct but slower). The same body works in C with int and 0/1. Checks: 29 → prime, 49 → not (7 × 7), 1 → not, 2 → prime.

23Viva Rapid-fire

BPSC · NTRCA · bank

What is code? Instructions written in a programming language that tell the computer what to do.

Why do we code? To make the computer solve a problem: given input → required output, automatically and repeatably.

Steps of coding? Define the problem → analyse → algorithm / flowchart / pseudocode → code → compile, test, debug → document and maintain.

Pseudocode? Algorithm steps in plain, code-like English for humans; no strict syntax, not compiled.

Write a basic program on paper: #include <stdio.h> int main(void){ printf("Hello\n"); return 0; }

Translator for C? A compiler (whole program → machine code). Interpreter: line by line; assembler: assembly → machine code.

Variable (চলক)? A named memory location whose value can change, e.g. int age = 25;

Keyword? A reserved word with fixed meaning (int, if, while, return); cannot be an identifier. C89 has 32.

Local vs global? Local: declared inside a block, visible there, lives during the call. Global: outside all functions, visible to the whole file, lives for the whole run, default 0.

Structured programming language? Top-down, functions + sequence/selection/loops, no goto: C, Pascal (sheet 5).
