C · Functions & RecursionFunctions

1Functions: Prototype, Definition, Call

basics, always asked ★
Definition A function is a named, self-contained block of code that does one job and can be called many times. A C program is a collection of functions; execution starts at main. General form: return_type name(type p1, type p2) { body; return value; }. Gives reuse and modularity. Two kinds: library functions (printf, sqrt) and user-defined functions.
#include <stdio.h> int add(int a, int b); /* prototype */ int main(void) { int s = add(5, 3); /* call */ printf("%d\n", s); /* 8 */ return 0; /* success */ } int add(int a, int b) { /* definition */ return a + b; }
TermMeaning
Prototypedeclaration: name, return type, parameter types; ends with ;, no body
Definitionheader + body; exactly one per function
Calladd(5, 3): jumps in, gets a value back
Actual paramsarguments in the call: 5, 3
Formal paramsvariables in the header: a, b
RuleWhat to remember
Return valueat most one value per call; for more, use pointer parameters or return a struct
void functionreturns nothing; may use a bare return; to leave early
mainreturns int: 0 = success; void main() is non-standard
Prototypenames optional (int add(int, int);); none at all: C89 assumed int, C99+ forbids it
Memory trick "Prototype = visiting card; definition = the person." You may hand out many cards, but there is only one person.
Exam trap The order in which arguments are evaluated is unspecified: f(i++, i++) is undefined behaviour. A function cannot be defined inside another in standard C.
Worked example ✍ output int sq(int x){return x*x;} → printf("%d", sq(3) + sq(4)); prints 25. Actual 3, 4; formal x.

C · Functions & RecursionParameter passing

2Parameter Passing: by Value and by Address

most tested ★
Definition In call by value the callee receives a copy of each argument in its formal parameter, so changes inside never reach the caller. C passes every argument by value. To let a function change the caller's variable, pass its address: the formal parameter is a pointer and the function writes through *p. This is usually called call by reference, but in C it is simulated — the address itself is copied. True references (int &a) exist only in C++.
void byVal(int a) { a = a + 5; } void byPtr(int *a) { *a = *a + 5; } int x = 10; byVal(x); /* x is still 10 */ byPtr(&x); /* x becomes 15 */
void swap(int *p, int *q) { int t = *p; *p = *q; *q = t; } int a = 10, b = 20; swap(&a, &b); /* a = 20, b = 10 */
PointCall by valueBy address (pointer)C++ reference
What is passedcopy of the valuecopy of the addressan alias of the variable
Formal / callint a / f(x)int *a / f(&x)int &a / f(x)
Caller's variable changes?noyes, through *ayes
In C?the only mechanismyes (value of a pointer)no — C++ only
Arrays decay to pointers void f(int a[]) ≡ void f(int *a): only the address of element 0 is passed, the array is not copied, and changes inside are seen by the caller. sizeof(a) inside f = pointer size, so pass the length too. More: next lesson.
Structures are copied A struct argument is copied whole — slow for big ones, so pass const struct T *p; const promises the data will not change. Structures in detail: lesson 4.
Memory trick "Value = photocopy; address = house key." Scribble on the photocopy and the original is safe; use the key and you rearrange the real house.
Common misconception "C has call by reference" — no: the pointer is copied too. Setting p = &y; inside the callee does not move the caller's pointer.
Worked example ✍ swap by value void swap(int a,int b){int t=a;a=b;b=t;}, x=10,y=20; swap(x,y); printf("%d %d",x,y); → 10 20.

3Scope Rules, Linkage and Lifetime

MCQ + output ★
Definition The scope of an identifier is the part of the program text where its name can be used. A local (inside a block, or a parameter) has block scope; a global (outside every function) has file scope to the end of the file. The C standard names four scopes: block, file, function and function prototype.
int global = 100; /* file scope */ void show(void) { int local = 5; /* block scope */ { int local = 7; /* shadows it */ printf("%d ", local); /* 7 */ } printf("%d %d", local, global); } /* prints 7 5 100 */ /* in main(): local is unknown → error */

TermQuestion it answersValues

Memory trick "Scope is the room you can call the name in; lifetime is how long the person lives." A static local lives all program long but answers only in its own room.
Exam trap A shadowed global cannot be named in that block: C has no ::x (C++ only). No use before the declaration line.
Worked example ✍ output int x=1; void f(){int x=2; {x=3;} printf("%d",x);} prints 3: the inner block assigns f's x; the global stays 1.

4Storage Classes: the Big Table

highest-yield ★
Definition A storage class specifier tells the compiler a variable's storage location, default initial value, scope, lifetime and linkage. C has four classic ones: auto, register, static, extern (C11 adds _Thread_local; typedef is one only in grammar). A local variable with no keyword is auto; a global with no keyword has external linkage.
ClassStored inDefaultScopeLifetimeLinkage

void counter(void) { static int count = 0; /* once */ count++; printf("%d ", count); } /* main: counter(); counter(); counter(); prints: 1 2 3 */ /* without static: 1 1 1 */
static local: three facts ① It is created and initialised once, before main starts — the line static int count = 0; does not run again on each call. ② Its initialiser must be a constant expression: static int n = f(); is a compile error in C. ③ It keeps its value between calls, yet its scope stays the block: main cannot name count. A function may return its address safely — it never dies.
Memory trick "A-R die young, S-E live long." Auto and Register die at the block's end with garbage; Static and Extern live the whole run and start at zero.
Exam trap Zero default = static storage only (static, globals). Uninitialised auto and malloc memory hold garbage (calloc gives 0).
Worked example ✍ output int f(){static int s=5; s+=2; return s;} → f(); f(); printf("%d", f()); prints 11 (7, 9, 11).

5extern, static Linkage and register

trap-heavy ★
Definition extern int g; is a declaration: it says "g exists, defined somewhere else" and allocates no storage. The single definition int g = 5; outside all functions allocates the memory and carries the zero default. A program may declare g many times but define it exactly once; the linker joins every extern to that one definition.
Keyword and placeEffect
static on a local variablelifetime becomes the whole program; scope unchanged (block); no linkage
static on a global variableinternal linkage: visible only in its own source file
static on a functionfunction is private to its file (helper functions, name clashes avoided)
extern on a variabledeclaration only; refers to an external definition
extern int g = 5; at file scopean initialiser makes it a definition (legal; compilers warn)
functions with no keywordextern by default: callable from other files through a prototype
register A request to keep the variable in a CPU register for speed (loop counters). The compiler may ignore it, (modern optimisers choose registers themselves). Only for locals and parameters; you cannot take & of it — a compile error even if it ends up in memory; default value garbage.
void loop(void) { register int i; for (i = 0; i < 1000; i++) ; /* fast counter */ int *p = &i; /* ✗ error: address of register */ } register int r; /* ✗ not at file scope */
Common misconceptions — corrected ① "extern creates the variable with value 0" — no: the definition elsewhere owns the storage and the zero default. ② "A static global can be used anywhere" — no: outside a function it means file-private. ③ "register guarantees a register" — no: it is only a hint. ④ "&r works on a register variable" — a compile error. ⑤ Two files both writing int g = 1; → multiple definition link error.
Memory trick "extern = 'lives elsewhere'; static outside = 'Keep Out' sign." Declaration = rumour; definition = birth.
Worked example ✍ legal? One file: extern int n; extern int n; int n = 3; → legal: two declarations, one definition.

6Recursion and the Call Stack

written + output ★
Definition Recursion: a function calls itself, directly (f → f) or indirectly (f → g → f). Every recursive function needs a base case that returns without recursing and a recursive case that moves towards it. Each call gets its own stack frame (activation record: parameters, locals, return address). With no reachable base case the frames pile up until stack overflow (a run-time crash).
long fact(int n) { if (n == 0 || n == 1) /* base case */ return 1; return n * fact(n - 1); /* recursive */ } /* fact(5) = 5*4*3*2*1 = 120 */ int fib(int n) { /* 0 1 1 2 3 5 8 */ if (n <= 1) return n; /* fib(0)=0, fib(1)=1 */ return fib(n - 1) + fib(n - 2); }
KindMeaningExample
Directthe function calls itselffact, fib
Indirect (mutual)A calls B, B calls AisEven ↔ isOdd
Tailthe recursive call is the last action; nothing left to do after itreturn gcd(b, a % b);
Non-tail (head)work remains after the call returnsreturn n * fact(n - 1);
Tree (multiple)more than one recursive call per framefib, Towers of Hanoi
int isOdd(int n); /* prototype */ int isEven(int n) { return n == 0 ? 1 : isOdd(n - 1); } int isOdd(int n) { return n == 0 ? 0 : isEven(n - 1); } /* isEven(4) → 1 (indirect) */
long factT(int n, long acc) { if (n <= 1) return acc; return factT(n - 1, n * acc); /* tail */ } /* factT(5, 1) = 120: the frame has no pending work, so an optimiser can reuse it (a loop in disguise) */
Memory trick "Russian dolls": open dolls on the way down (calls), the smallest is solid (base case), close them on the way up (returns).
Exam trap Tail-call optimisation is something compilers may do (e.g. gcc -O2); the C standard does not require it. main may call itself in C (not in C++).
Worked example ✍ depth fact(5) → frames for n = 5, 4, 3, 2, 1: maximum depth 5; result 120. fact(-1) never reaches the base case → overflow.

7Recursion Tree, Complexity, Recursion vs Iteration

frequently tested ★
Definition A recursion tree draws one node per call. Naive fib(n) makes two calls per frame and recomputes the same values again and again: calls C(n) = C(n−1) + C(n−2) + 1 with C(0) = C(1) = 1, which solves to C(n) = 2·F(n+1) − 1. For fib(5): 2·8 − 1 = 15 calls. Time O(2ⁿ) (tight: Θ(φⁿ), φ ≈ 1.618); stack depth only n.

8Output-Tracing Drill

output questions ★
Method To trace any recursive output question: ① write the call chain going down with each argument; ② mark where the base case fires; ③ carry the return values back up, one frame at a time; ④ a printf before the recursive call prints on the way down, one after it prints on the way up (reversed order).
void p(int n) { if (n == 0) return; printf("%d", n); /* before: down */ p(n - 1); printf("%d", n); /* after: up */ } p(3); /* prints 321123 */
① Sum of digits
int sd(int n) { return n == 0 ? 0 : n % 10 + sd(n / 10); }
sd(1234) = 4 + 3 + 2 + 1 + 0 = 10; 5 calls (1234, 123, 12, 1, 0).
② Power
int pw(int b, int e) { return e == 0 ? 1 : b * pw(b, e - 1); }
pw(2, 10) = 1024 with 11 calls. Halving e (pw(b*b, e/2)) cuts it to O(log e).
③ GCD (Euclid)
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
gcd(48, 18): (48,18) → (18,12) → (12,6) → (6,0) → 6. LCM = 48·18 / 6 = 144.
④ Step of two
int f(int n) { return n <= 1 ? 1 : n * f(n - 2); }
f(7) = 7·5·3·1 = 105, not 7! = 5040: the argument drops by 2.
⑤ Binary by recursion
void bin(int n) { if (n > 1) bin(n / 2); printf("%d", n % 2); }
bin(10) prints 1010: digits come out on the way up.
⑥ static inside recursion
int g(int n) { static int s = 0; s += n; if (n > 0) g(n - 1); return s; }
g(3) → one shared s: 3+2+1+0 = 6; a second g(3) returns 12.
Memory trick "Print before = going down the stairs; print after = climbing back up." Down reads forwards, up reads backwards.
Exam trap A static local is shared by all frames — one copy, not one per call. An auto local gets a fresh copy in every frame.
Worked example ✍ sum int s(int n){return n==0?0:n+s(n-1);} → s(100) = 5050, 101 calls deep.
