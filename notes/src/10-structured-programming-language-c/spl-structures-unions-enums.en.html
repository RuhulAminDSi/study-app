C · Structures, Unions, EnumsStructures

1Structures: Declaration, Definition, Initialisation

foundation ★
Definition A structure (struct) is a user-defined type that groups related variables, usually of different types, under one name. Each variable inside is a member (field). Members are stored in declaration order, and each member has its own memory. Declaring the struct type (the template) allocates nothing; defining a variable of that type allocates memory.
#include <stdio.h> #include <string.h> struct Student { /* tag */ int id; char name[50]; float marks; }; /* ; needed */ int main(void) { struct Student s1; s1.id = 101; strcpy(s1.name, "Ruhul"); s1.marks = 85.5f; printf("%d %s %.2f\n", s1.id, s1.name, s1.marks); return 0; /* 101 Ruhul 85.50 */ }
Way to create variablesCodeNote
after the typestruct Student s1, s2;keyword struct is required in C
with the declarationstruct Student { … } s1, s2;type and variables together
anonymous structstruct { int x, y; } pt;no tag: no more variables later
positional initialiser= {101, "Ruhul", 85.5f}in member order
designated initialiser (C99)= {.marks = 85.5f, .id = 101}any order; name[] becomes ""
partial / zero= {101} · = {0}members not given are zero
Memory trick "The struct is a blank form; a variable is a filled copy." Printing the blank form costs no paper (no memory); every filled copy does.
Exam trap s1.name = "Ruhul"; is a compile error: an array cannot be assigned. Use strcpy(), or initialise at definition. Forgetting the ; after } is also an error.
Worked example ✍ sizeof With 4-byte int/float: 4 + 50 = 54, pad to 56 for marks, + 4 → sizeof(struct Student) = 60, not 58.

2Member Access: . vs ->; Structures and Functions

most tested ★
Definition The dot operator . picks a member from a structure variable. The arrow operator -> picks a member through a pointer to a structure: p->x is exactly (*p).x. The brackets matter: . binds tighter than unary *, so *p.x means *(p.x).
struct point { int x, y; }; struct point p = {3, 4}; struct point *q = &p; q->x = q->y * 2; printf("%d %d", p.x, p.y); /* Output: 8 4 */ void byVal(struct point a) { a.x = 0; } void byPtr(struct point *a) { a->x = 0; } /* byVal(p): p unchanged (copy) byPtr(&p): p.x becomes 0 */
ExpressionMeansExpressionMeans
p->x(*p).x++p->x++(p->x): member increments
*p.x*(p.x): x must be a pointerp++->xread x, then p moves on
&s.x&(s.x): member's address*p->namefirst char of the name
Operation on whole structuresAllowed?Why / how
assignment s2 = s1;yesmember-by-member copy, arrays inside included (same type only)
comparison s1 == s2no: compile errorcompare members one by one; memcmp may also compare padding
pass to / return from functionyesby value copies the whole struct; pass a pointer for big structs
Memory trick "Dot when you hold the box, arrow when you point at it." A variable name → .; a pointer → ->.
Exam trap Pass-by-value works on a copy: after byVal(p), p is unchanged. Also: :: is C++ only; C has no scope operator for members.
Worked example ✍ return a struct struct point mid(struct point a, struct point b) { struct point m = {(a.x+b.x)/2, (a.y+b.y)/2}; return m; } mid({2,4},{6,8}) → {4, 6}.

3Arrays of Structures; Nested and Self-Referential Structures

output questions ★
Definition An array of structures stores many records of one type contiguously: struct Student st[3]; → st[0].id, st[2].name. A pointer to the array moves one whole structure per p++ (sizeof the struct, not 1 byte). A nested structure has a struct member; a self-referential structure has a member that is a pointer to its own type.
struct pt { int x, y; }; /* 8 B */ struct pt a[3] = {{1,2},{3,4},{5,6}}; struct pt *p = a; /* &a[0] */ p += 2; /* a[2] */ printf("%d %d", p->x, (p-1)->y + a[0].x); /* 5 5; a at 1000 -> p = 1016 */ struct Date { int d, m, y; }; struct Emp { char name[20]; struct Date dob; /* nested */ } e, *pe = &e; e.dob.y = 1995; pe->dob.m = 6;
struct node { int data; struct node *next; /* OK */ /* struct node n; -> error */ }; struct node c = {30, NULL}; struct node b = {20, &c}; struct node a1 = {10, &b}; printf("%d", a1.next->next->data); /* Output: 30 */
KindMemberSize (4-byte int, 8-byte pointer)Access
array of structuresstruct pt a[3]3 × 8 = 24a[i].x, (p+i)->x
nestedstruct Date dob in Emp20 + 12 = 32e.dob.y, pe->dob.y
self-referentialstruct node *next4 + 4 pad + 8 = 16 (8 on 32-bit)n->next->data
Memory trick "A box may hold the address of a box like itself, never the box itself." A struct containing itself would be infinitely large.
Exam trap p++ on struct pt * adds 8 bytes (sizeof), not 1. In e.dob.y both dots are needed; pe->dob->y is wrong because dob is not a pointer.
Worked example ✍ walk for (p = a; p < a + 3; p++) sum += p->y; → 2 + 4 + 6 = 12. (Real lists get nodes from malloc: pointers lesson.)

4sizeof, Padding and Alignment

numerical MCQ ★
Definition The CPU reads data fastest at aligned addresses, so the compiler puts each member at an offset that is a multiple of its alignment and inserts unused padding bytes where needed. Then the whole struct is rounded up to a multiple of its largest member alignment, so that arrays of it stay aligned. Hence sizeof(struct) ≥ sum of members.

Assumption (typical 64-bit GCC/Clang/MSVC): char 1 · short 2 · int, float 4 · double, long long, pointer 8 — each aligned to its own size.

struct members (in order)Layout (offsets)sizeof
char c; int i; char d;c@0, pad 3, i@4, d@8, pad 312
int i; char c; char d;i@0, c@4, d@5, pad 28
char c; double d;c@0, pad 7, d@816
char c; short s; int i;c@0, pad 1, s@2, i@48
char a; double b; int c;a@0, pad 7, b@8, c@16, tail pad 424
double b; int c; char a;b@0, c@8, a@12, tail pad 316
int a; char b[5];a@0, b@4..8, tail pad 312
char c; int *p;c@0, pad 7, p@8 (32-bit: pad 3, p@4)16 (8)
Memory trick "Big rocks first." Declare members from largest to smallest alignment (double → int → short → char) and padding nearly disappears.
Exam trap Padding is implementation-defined. On 32-bit Linux (i386) a double inside a struct is 4-aligned, so {char; double} = 12 there. If the options have no padded value, the setter assumed no padding (plain sum).
Worked example ✍ step by step {char a; double b; int c;}: 1 → pad to 8 → +8 = 16 → +4 = 20 → round to 8's multiple = 24.
Packing #pragma pack(1) (or GCC __attribute__((packed))) removes padding: {char c; int i; char d;} becomes 6 bytes, but unaligned access is slower. Used for file formats and network headers.

5Bit-Fields

frequently tested
Definition A bit-field is a struct member declared with an explicit width in bits: type name : width;. The type must be int, signed int, unsigned int or _Bool (compilers may allow others). Adjacent bit-fields are packed into one storage unit (usually an int), which saves memory for flags, small counters and hardware registers.
struct Date { unsigned day : 5; /* 0-31 */ unsigned month : 4; /* 0-15 */ unsigned year : 12; /* 0-4095 */ }; /* 21 bits -> 4 bytes */ struct Date d = {14, 10, 2026}; printf("%u/%u/%u", d.day, d.month, d.year); /* 14/10/2026; 3 ints: 12 B */ struct { unsigned x : 3; } s; s.x = 9; /* 9 = 1001b, keeps 001 */ printf("%u", s.x); /* 1 */
RuleExample
No address: & cannot be applied, so no pointer to it and no scanf into it&d.day → compile error
No arrays of bit-fields; a bit-field cannot be staticunsigned f[4] : 2; → error
Width ≤ bits of its type; width 0 only for unnamed fieldsint a : 33; (32-bit int) → error
Unnamed : 0 pushes the next field to a new unit{unsigned a:4; unsigned :0; unsigned b:4;} = 8
A field that does not fit the rest of a unit starts a new one (GCC){unsigned a:30; unsigned b:4;} = 8
Fields that fit together share one unit{unsigned a:3, b:5, c:8;} = 4
Plain int field: signed or unsigned is implementation-definedint f:1 may hold only 0 and −1
Memory trick "Bits rent rooms in a word." Fields move into the same int until it is full; a :0 tenant says "next field, new house".
Exam trap Storing a value too big for an unsigned field keeps only the low bits (value mod 2width): 9 in 3 bits → 1. For a signed field the result is implementation-defined (GCC: int a:2; a = 3; → −1).
Worked example ✍ range unsigned m : 4 holds 0 to 24 − 1 = 15; enough for 12 months. A day field needs 5 bits (31 ≤ 31).

6Unions: One Memory, Many Views

most tested ★
Definition A union is declared like a structure, but all members start at the same address (offset 0) and overlap. Its size is the largest member, rounded up to the strictest member alignment. Writing one member overwrites the others, so only the last-written member holds a meaningful value. Purpose: save memory when only one of several types is needed at a time.
union Data { int i; float f; char str[20]; }; /* sizeof = 20 */ union Data d; d.i = 10; printf("%d\n", d.i); d.f = 3.14f; printf("%.2f\n", d.f); strcpy(d.str, "Hello"); printf("%s\n", d.str); /* 10 / 3.14 / Hello: each read comes right after its write */ d.f = 3.14f; printf("%d", d.i); /* 1078523331 */
Declaration (4-byte int/float, 8-byte double)Largest memberAlignmentsizeof
union { int i; float f; char str[20]; }20420
union { char c[5]; int i; }54 → round 5 up8
union { double d; char c[9]; }9816
struct { int i; float f; char str[20]; }— (sum)428
/* endianness check */ union { int i; char c[4]; } u; u.i = 1; puts(u.c[0] == 1 ? "little-endian" : "big-endian"); /* x86 / ARM default: little */
/* tagged union */ struct Value { enum { INT, FLT } tag; union { int i; float f; } v; }; /* read v.i only if tag == INT */
Memory trick "Struct = flats in a building; union = one room, many tenants." Only the last tenant to move in actually lives there.
Exam trap union Data d = {10}; initialises only the first member (i). Use {.f = 2.5f} (C99) for another. A union's size is not the sum. 1078523331 = 0x4048F5C3, the bit pattern of 3.14f.
Worked example ✍ bytes u.i = 0x41424344; on a little-endian PC, u.c[0] is the lowest byte 0x44 → printf("%c", u.c[0]) prints D.

7Enumerations (enum)

output questions ★
Definition An enumeration is a user-defined type made of named integer constants (enumerators). Unless a value is given, the first enumerator is 0 and every later one is previous + 1. Enumerators are constants of type int; they make code readable (if (day == Friday) instead of if (day == 5)).
enum Week { Sunday, Monday, Tuesday, Wednesday, Thursday, Friday, Saturday }; enum Week today = Wednesday; printf("%d", today); /* 3 */ enum Month { Jan = 1, Feb, Mar, Apr }; /* 1 2 3 4 */ enum color { RED, GREEN = 5, BLUE }; printf("%d %d", RED, BLUE); /* 0 6 */ enum { A, B = 5, C, D = 2, E }; /* 0, 5, 6, 2, 3 */
RuleExample / result
Duplicate values allowedenum { LOW = 1, MIN = 1 }; ✓
Negative values allowedenum { N = -2, M }; → M = −1
Values must be integer constant expressionsenum { X = 2.5 }; → error; C = B + 3 ✓
Enumerators share the ordinary identifier namespaceenum A {X}; enum B {X}; in one scope → error
An enumerator is a constant, not a variableRED++; or RED = 3; → error
An enum variable is an integer underneath (C)enum Week d = 10; d++; compiles in C (not C++)
sizeof an enum variableimplementation-defined, typically 4 (same as int)
Pointenum#define
Handled bycompiler (real type, debugger shows names)preprocessor: blind text replacement
Valuesintegers only; auto-numberedanything (float, string); each typed by hand
Scopeobeys block scopefrom #define to end of file (or #undef)
Memory trick "Zero to start, plus one to follow, a given value resets the count."
Exam trap After an explicit value the count continues from it, not from the position: in {RED, GREEN = 5, BLUE} BLUE is 6, not 2.
Worked example ✍ enum { P = -1, Q, R = Q + 3, S }; → Q = 0, R = 3, S = 4.

8typedef; struct vs union vs enum

written favourite ★
Definition typedef gives a new name (alias) to an existing type; it creates no new type and no memory. With structures it removes the need to write struct every time. The struct tag (struct Student) and the typedef name (Student) live in different namespaces, so the same word can be used for both.
typedef struct Student { int id; char name[50]; } Student; /* tag = alias */ Student s1; /* no 'struct' */ typedef unsigned char BYTE; typedef int (*Cmp)(const void *, const void *); Cmp f = compareInts; /* for qsort */
typedef char *PTR; PTR a, b; /* a, b: char * */ #define PTR2 char * PTR2 c, d; /* char *c, d; d is a char! */ /* 64-bit: sizeof(b) = 8, sizeof(d) = 1 */

What is the output? (64-bit, little-endian)

① copy, not alias typedef struct { int x; } T; T a = {5}, b; b = a; b.x++; printf("%d %d", a.x, b.x); → 5 6 (a copy).
② struct size struct S { int a; char b; }; sizeof(struct S) → 8 (4 + 1 + 3 tail pad).
Memory trick "typedef renames, #define rewrites." The compiler understands a typedef; the preprocessor just pastes text.
Exam trap Without typedef, C needs struct Student s; — plain Student s; is an error in C (allowed in C++). Writing whole records with fwrite: file I/O lesson.
