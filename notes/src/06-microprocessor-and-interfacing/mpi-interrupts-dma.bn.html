১পোলিং বনাম ইন্টারাপ্ট-চালিত I/O

MCQ + লিখিত
ইন্টারাপ্ট (Interrupt) হার্ডওয়্যার, নির্দেশনা বা CPU নিজেই তৈরি করে এমন একটি সংকেত, যা পেলে CPU চলতি নির্দেশনা শেষ করে প্রোগ্রাম থামায়, একটি ইন্টারাপ্ট সার্ভিস রুটিন (ISR) চালায়, তারপর যেখানে থেমেছিল সেখান থেকে আবার শুরু করে।

পোলিং (Polling, প্রোগ্রামড I/O): ডিভাইস প্রস্তুত না হওয়া পর্যন্ত CPU লুপে স্ট্যাটাস পোর্ট পড়তে থাকে → সহজ, কিন্তু CPU-র সময় নষ্ট, দ্রুত ঘটনা ছুটে যেতে পারে।

ইন্টারাপ্ট-চালিত I/O: ডিভাইস প্রস্তুত হলে নিজেই CPU-কে জানায়; মাঝের সময়ে CPU অন্য কাজ করে। খরচ: সামান্য বাড়তি হার্ডওয়্যার ও সেভ/রিস্টোরের সময় (ইন্টারাপ্ট ল্যাটেন্সি)।

ব্যবহারসহজ, ধীর ডিভাইসকিবোর্ড, টাইমার, UARTডিস্ক, সাউন্ড, নেটওয়ার্ক
মনে রাখার কৌশল পোলিং = প্রতি মিনিটে ফোন চেক করা · ইন্টারাপ্ট = ফোন বেজে ওঠে · DMA = গুদামের চাবি হাতে কুরিয়ার।

৩8086-এর ২৫৬টি ইন্টারাপ্ট টাইপ

হাই-ইল্ড

টাইপ N = 00H–FFH (২৫৬টি): 0–4 নির্দিষ্ট · 5–31 সংরক্ষিত · 32–255 ইউজার।

টাইপনামকখন ঘটেভেক্টর

1সিঙ্গল স্টেপTF = 1: প্রতিটি নির্দেশনার পর (ডিবাগিং)00004H

4ওভারফ্লোOF = 1 অবস্থায় INTO চালালে00010H

INT n = ২ বাইট (CDH, n) · INT 3 = ১ বাইট (CCH) · INTO = CEH · IRET = CFH। TF সরাসরি সেট করার নির্দেশনা নেই: PUSHF → কপিতে বিট 8 সেট → POPF।

৪ইন্টারাপ্ট ভেক্টর টেবিল (IVT)

ভেক্টর একটি ISR-এর ৪ বাইটের ফার অ্যাড্রেস (IP, CS)। IVT = 256 × 4 = 1 KB, অবস্থান 00000H–003FFH।
সূত্র ভেক্টর অ্যাড্রেস = 4 × N
IP ← 4N-এর ওয়ার্ড (নিচে) · CS ← 4N + 2-এর ওয়ার্ড
ISR-এর ফিজিক্যাল অ্যাড্রেস = CS × 10H + IP
সমাধানকৃত উদাহরণ ✍
দেওয়া আছেহিসাবউত্তর
INT 21H (DOS)21H × 4 = 84H00084H–00087H
INT 08H (PC টাইমার, IRQ0)08H × 4 = 20H00020H
ভেক্টর পাওয়া গেল 0002CH-এ2CH ÷ 4 = 0BHটাইপ 0BH (11)
ভেক্টর পাওয়া গেল 000A0H-এA0H ÷ 4 = 28Hটাইপ 28H (40)
00084H-এর বাইটগুলো = 56H 34H 00H 12H → IP = 3456H, CS = 1200H → ISR আছে 12000H + 3456H = 15456H-এ
মনে রাখার কৌশল × 4 = বাঁয়ে ২ বিট শিফট: 0010 0001 → 1000 0100 (21H → 84H)। "I আগে, C পরে": আগে IP, পরে CS।
পরীক্ষার ফাঁদ INT 21H-এর ভেক্টর 84H-এ, 21H-এ নয়। টাইপ নম্বর একটি ইনডেক্স; অ্যাড্রেস তার ৪ গুণ।

MPI · ইন্টারাপ্ট ও DMAইন্টারাপ্ট প্রসেসিং

৫ইন্টারাপ্ট এলে 8086 কী করে

লিখিতে প্রিয়
  1. চলতি নির্দেশনা শেষ করে, তারপর NMI ও INTR দেখে (INTR শুধু IF = 1 হলে)
  2. শুধু INTR: ২টি INTA সাইকেল। ১ম: 8259A অগ্রাধিকার ঠিক করে; ২য়: D0–D7-এ টাইপ N দেয় (NMI, সফটওয়্যার: N আগেই জানা)
  3. FLAGS পুশ করে (SP − 2)
  4. IF ও TF ক্লিয়ার: ISR-এ INTR ও সিঙ্গল-স্টেপ বন্ধ
  5. CS, তারপর IP পুশ (আরও SP − 4: মোট ৬ বাইট)
  6. 4N থেকে IP, 4N + 2 থেকে CS লোড → ISR চলে
  7. ISR রেজিস্টার সেভ করে, ডিভাইসের কাজ করে, EOI পাঠায়, শেষে IRET
  8. IRET পপ করে IP, CS, FLAGS (আগের IF, TF ফেরে)

৭8259A প্রোগ্রামেবল ইন্টারাপ্ট কন্ট্রোলার

হাই-ইল্ড
PIC কেন? 8086-এর মাস্কেবল ইনপুট মাত্র একটি (INTR)। 8259A ৮টি অনুরোধ (IR0–IR7) নেয়, মাস্ক ও অগ্রাধিকার ঠিক করে, INTR তোলে এবং বিজয়ীর টাইপ নম্বর CPU-কে দেয়।
  • 28-পিন DIP, একক +5 V, 8085 ও 8086/88 দুটোতেই চলে
  • ৮টি লেভেল; ১ মাস্টার + ৮ স্লেভ ক্যাসকেডে ৬৪টি লেভেল
  • প্রতিটি IR আলাদাভাবে মাস্ক করা যায় (IMR)
  • এজ- বা লেভেল-ট্রিগারড ইনপুট (LTIM বিট)
  • অগ্রাধিকার মোড: ফুলি নেস্টেড, রোটেটিং, স্পেশাল মাস্ক, পোল
  • ৪টি ICW (শুরুতে) ও ৩টি OCW (চলাকালে) দিয়ে প্রোগ্রাম
রেজিস্টারকী রাখেসেট / ক্লিয়ার হয়
IRR (রিকোয়েস্ট)এখন অনুরোধকারী IR লাইনIR ইনপুটে সেট; ১ম INTA-তে ক্লিয়ার
ISR (ইন-সার্ভিস)যেসব লেভেলের সার্ভিস চলছে১ম INTA-তে সেট; EOI/AEOI-তে ক্লিয়ার
IMR (মাস্ক)মাস্কড লেভেল (1 = মাস্কড)OCW1 দিয়ে লেখা হয়
প্রায়োরিটি রিজলভারসর্বোচ্চ আনমাস্কড IRR বিটমোড ঠিক করে OCW2

একটি অনুরোধ, ধাপে ধাপে (8086 মোড)

  1. IR3 HIGH → IRR বিট 3 সেট; আনমাস্কড ও চলমান সার্ভিসের চেয়ে উঁচু হলে 8259A INT তোলে
  2. CPU (IF = 1) ১ম INTA দেয় → ISR বিট 3 সেট, IRR বিট 3 ক্লিয়ার
  3. ২য় INTA → 8259A D0–D7-এ টাইপ বাইট দেয়: ICW2-এর T7–T3 + 011
  4. ISR EOI না পাঠানো পর্যন্ত ISR বিট 3 সেট থাকে (সমান/নিচু লেভেল আটকায়); AEOI মোডে ২য় INTA-র শেষে নিজেই ক্লিয়ার হয়
পরীক্ষার ফাঁদ 8259A দেয় টাইপ নম্বর (এক বাইট), ISR-এর অ্যাড্রেস নয়। 8085-এর সাথে দেয় CALL অপকোড + ২ বাইট অ্যাড্রেস (৩টি INTA পালস); 8086-এর সাথে ২টি।

MPI · ইন্টারাপ্ট ও DMADMA

১১ডাইরেক্ট মেমরি অ্যাক্সেস (DMA)

MCQ + লিখিত
সংজ্ঞা DMA একটি ডেটা ব্লককে I/O ডিভাইস ও মেমরির মধ্যে (বা মেমরি থেকে মেমরিতে) সরায় প্রতি বাইটে CPU-কে কোনো নির্দেশনা না চালিয়ে: একটি DMA কন্ট্রোলার (DMAC) বাস ধার নেয়, নিজেই অ্যাড্রেস ও স্ট্রোব দেয়, তারপর বাস ফেরত দেয়।
কেন? পোলিং/ইন্টারাপ্ট I/O-তে প্রতিটি বাইট যায় CPU-র ভেতর দিয়ে (IN, MOV, INC, LOOP ≈ কয়েক ডজন ক্লক)। DMAC-এর লাগে বাইটপ্রতি একটি বাস সাইকেল (8237-এ 4 ক্লক)।
খরচ: একটি বাড়তি চিপ, আর ট্রান্সফারের সময় CPU বাসের বাইরে থাকে (কিউ থেকে কিছু কাজ চালাতে পারে)।

HOLD / HLDA হ্যান্ডশেক (8086 মিনিমাম মোড)

  1. ডিভাইস DREQ দিয়ে DMAC-কে বলে; DMAC তোলে HRQ, যা 8086-এর HOLD পিনে যুক্ত
  2. 8086 চলতি বাস সাইকেল শেষ করে, অ্যাড্রেস/ডেটা/কন্ট্রোল লাইন ভাসমান করে, HLDA দেয়
  3. DMAC DACK পাঠায়, অ্যাড্রেস ও MEMR + IOW (বা IOR + MEMW) চালায়
  4. টার্মিনাল কাউন্টে (বা EOP) HRQ নামে → 8086 HLDA নামিয়ে বাস ফিরিয়ে নেয়
DMA মোডবাস কীভাবে ব্যবহৃতপ্রভাব
বার্স্ট (ব্লক)এক মঞ্জুরিতে পুরো ব্লকCPU বাসের বাইরে; দ্রুততম
সাইকেল স্টিলিং (সিঙ্গল)মঞ্জুরিপ্রতি এক বাইট, বাস ফেরতCPU সামান্য ধীর
ট্রান্সপারেন্ট (হিডেন)শুধু CPU-র অলস সাইকেলেCPU ধীর হয় না; সবচেয়ে ধীর
মনে রাখার কৌশল বার্স্ট = পুরো কনভয়ের জন্য রাস্তা দখল · স্টিলিং = একবারে একটি গাড়ি ঢোকানো · ট্রান্সপারেন্ট = রাস্তা ফাঁকা থাকলেই চলা।
পরীক্ষার ফাঁদ IF = 0 হলেও HOLD মঞ্জুর হয় (এটি ইন্টারাপ্ট নয়)। ম্যাক্সিমাম মোডে HOLD/HLDA-র বদলে RQ/GT0 (উচ্চ অগ্রাধিকার) ও RQ/GT1।

লিখিত প্রশ্ন 20H/21H পোর্টে একটি 8259A একটি 8086 সিস্টেমে আছে। এজ-ট্রিগারড ইনপুট, IR0 = টাইপ 40H ও সাধারণ EOI-র জন্য ইনিশিয়ালাইজ করো, তারপর শুধু IR0–IR3 চালু করো। প্রতিটি কন্ট্রোল ওয়ার্ড ও কোড দাও এবং IR3-এর IVT অ্যাড্রেস বের করো। ৮ নম্বর
  1. ICW1 = 0001 0011 = 13H (এজ, একক, ICW4 লাগবে) → পোর্ট 20H ২
  2. ICW2 = 40H → পোর্ট 21H (IR0–IR7 = টাইপ 40H–47H); একক বলে ICW3 নেই ১
  3. ICW4 = 0000 0001 = 01H (8086 মোড, সাধারণ EOI, নন-বাফার্ড) → পোর্ট 21H ১
  4. OCW1 = 1111 0000 = F0H → 21H (IR4–7 মাস্কড); প্রতিটি: MOV AL,w / OUT p,AL ২
  5. IR3 → টাইপ 43H → 43H × 4 = 0010CH–0010FH (IP 0010CH-এ, CS 0010EH-এ); এর ISR শেষ হয় MOV AL,20H / OUT 20H,AL / IRET দিয়ে ২

পরীক্ষার আগে যাচাই ✓

  • টাইপ 0–4 ও তাদের ভেক্টর
  • টাইপ ↔ IVT অ্যাড্রেস, দুই দিকেই
  • INTR রেসপন্সের ধাপ ক্রমানুসারে
  • ICW1/2/4, OCW1/2 বাইনারিতে
  • HOLD/HLDA ও 8237 মোড ওয়ার্ড
