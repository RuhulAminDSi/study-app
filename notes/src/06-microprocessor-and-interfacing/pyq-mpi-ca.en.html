1What a Microprocessor Is and Contains

viva ×3
Q What is a microprocessor? What are its components? · bank IT viva · NTRCA viva 2023

Answer: a microprocessor is a programmable IC that holds a computer's whole CPU on one chip. Driven by a clock, it fetches instructions from memory, decodes them and executes arithmetic, logic and data-transfer operations (first: Intel 4004, 1971).

PartJob
ALUarithmetic & logic, sets flags
Control unitdecodes; timing & control signals
RegistersA, GPRs, PC/IP, SP, flags, IR
Busesaddress, data, control
Exam trap "ALU, registers, cache, output circuit" is wrong: the control unit is missing and an output circuit is I/O. Cache is not a defining CPU part (49th BCS MCQ, p. 8).

Answer: 8-bit μP → data 8, address 16 (64 KB); 16-bit μP → data 16, address 20 (1 MB).

Memory trick Bit-size = data width; memory = 2^(address lines): 2¹⁶ = 64 K, 2²⁰ = 1 M, 2³² = 4 G.
Exam trap Address width is not fixed by bit-size: the 16-bit 80286 has 24 address lines, and the 8088 is internally 16-bit with an 8-bit external data bus.

332-bit Microprocessor

written
Q What is a 32-bit microprocessor? Explain its key characteristics. · BUET MSc (CSE) 2026

Definition: a processor whose ALU, general registers and data path are 32 bits wide, so it handles a 32-bit word in one operation (Intel 80386 of 1985, 80486, ARM Cortex-M3/A, MIPS32).

  1. 32-bit registers (EAX …); range −2³¹ … 2³¹ − 1
  2. 32 address lines → 2³² = 4 GB
  3. 32-bit data bus (Pentium: 64-bit external)
  1. Protected mode: rings 0–3, paging, virtual memory (386: 64 TB), multitasking
  2. Pipelining, on-chip cache and FPU (486)
  3. Real mode still runs 8086 code

7Intel 8086: Five MCQs Asked

MCQ ×5

8086 (1978): 16-bit ALU and data bus, 20-bit address bus → 1 MB, 40 pins, BIU + EU with a 6-byte instruction queue, 14 registers of 16 bits.

MCQ 1 · 49th BCS ICT-281, 2025 Physical address for segment 2000H and offset 0020H? (a) 200200H (b) 20020H × 16 (c) 20020H (d) 20020H + 0020H
PA = segment × 10H + offset = 20000H + 0020H = 20020H → (c)
Memory trick "× 10H = append a 0 in hex": 2000H → 20000H, then add the offset. Check: the answer must have exactly 5 hex digits (20 bits).
MCQ 2 · 49th BCS ICT-281, 2025 How many address lines are multiplexed with the data lines in the 8086? (a) 8 (b) 32 (c) 64 (d) 16
(d) 16: lines AD0–AD15 carry the address in T1 (latched by ALE into 74LS373s) and data in T2–T4. A16–A19 share pins with status S3–S6.
Exam trap 8 is the answer for the 8088 (AD0–AD7, 8-bit external bus), not the 8086.
MCQ 3 · asked in a recruitment paper After RESET the 8086 starts from: (a) FFFFFH (b) FFFFH (c) 00000H (d) 00001H
Reset loads CS = FFFFH, IP = 0000H (DS = SS = ES = flags = 0) → PA = FFFF0H, 16 bytes below the top of memory, where a far JMP to the BIOS sits. No option is exact; (a) FFFFFH is the nearest.
Exam trap CS after reset is FFFFH (16 bits), so the address is FFFF0H. "FFFFF0H" has 24 bits and cannot exist on a 20-bit bus.
MCQ 4 · asked in a recruitment paper MOV AX, BX: (b) copies BX into AX. MOV dest, src: BX is unchanged. Not allowed: memory → memory, immediate → segment register, CS as destination, size mismatch.
MCQ 5 · 49th BCS ICT-281, 2025 Instruction passed from 8086 to 8087: (d) ESC. ESC opcodes start 11011 (D8H–DFH); the 8087 watches the queue (QS0, QS1), and WAIT checks its BUSY via the TEST pin.

8Assembly Language + Add/Multiply Program

written · 5 marks
Q What is assembly language? Write its features. Write a program in assembly language to add and multiply two numbers. 5 marks · 45th BCS Written (CSE-971), 2024
Definition Assembly language is a low-level language that writes each machine instruction as a mnemonic (MOV, ADD, MUL) with symbolic operands. It maps one-to-one onto machine code, is specific to one processor family, and an assembler (MASM, NASM, TASM) translates it.

Features 2

  1. Mnemonics instead of binary opcodes
  2. Symbolic names for data and labels; no raw addresses
  3. Direct access to registers, memory, I/O ports and interrupts
  4. Directives (DB, DW, ORG, SEGMENT) and macros
  5. Fast, compact code: drivers, boot code, ISRs
  6. Machine-dependent: not portable, harder to debug

FormbinarymnemonicsEnglish-like
Translatornoneassemblercompiler

Program (8086, MASM) 3

PROD DD ? ; 32-bit product .CODE MAIN PROC MOV AX, @DATA MOV DS, AX ; point DS at data MOV AX, NUM1 ADD AX, NUM2 ; AX = NUM1 + NUM2 MOV SUM, AX MOV AX, NUM1 MUL NUM2 ; DX:AX = AX × NUM2 MOV WORD PTR PROD, AX MOV WORD PTR PROD+2, DX MOV AH, 4CH ; return to DOS INT 21H MAIN ENDP END MAIN

37 + 18 = 55 = 0037H; 37 × 18 = 666 = 029AH.

Exam trap 8086 MUL takes one operand (AX is implied) and leaves a 32-bit result in DX:AX. "MUL AX, BX" and "MUL 5" are invalid. Use IMUL for signed numbers.
Memory trick Program skeleton = "D-S-E": load DS, do the Sum, Exit with 4CH.

On a 32-bit Linux x86 (NASM) the same task is mov eax,[n1] / add eax,[n2] then mov eax,[n1] / imul eax,[n2], ending with mov eax,1 / int 0x80. Either version earns the marks if it is commented.

9Enabling and Processing an Interrupt

written
Q How can an interrupt be enabled? What are the steps that occur when an interrupt is processed? · 38th BCS Written, 2018
Interrupt A signal that makes the processor suspend the current program, run an interrupt service routine (ISR), then resume. It replaces wasteful polling.

(a) Enabling (8086 system)

  1. STI sets the interrupt flag IF = 1 (CLI clears it); this gates the maskable INTR pin
  2. Unmask the line in the 8259 PIC: write OCW1 with that IMR bit = 0
  3. Enable the interrupt in the device itself (e.g. the 8255 INTE flip-flop)
On an 8051 microcontroller the IE register (A8H) does it: set EA (bit 7, global) and the source's own bit.
EA–ET2ESET1EX1ET0EX0
76543210
MOV IE, #85H → EA, EX1, EX0 on.
Exam trap Say which processor you mean: the IE register is the 8051's; the 8086 uses the IF flag. NMI cannot be disabled by CLI.

(b) Processing steps (8086)

  1. Finish the current instruction
  2. INTR: two INTA pulses; the 8259 puts the type number n on the bus
  3. Push FLAGS; clear IF and TF (no nesting, no single-step)
  4. Push CS, then IP (the return address)
  5. Load IP ← [4n], CS ← [4n + 2] from the vector table
  6. ISR runs: save registers, service, send EOI to the 8259
  7. IRET pops IP, CS, FLAGS → program resumes

12Design: Automatic Street-Light Controller

design · written
Q Design and implement an automated street-light control system that keeps the lights off in daylight and turns them on when ambient light falls below a threshold. · asked in a recruitment paper
  1. Sense: LDR (to VCC) + 10 kΩ (to GND); brighter → lower LDR resistance → higher voltage at A0
  2. Convert: 10-bit ADC gives 0–1023
  3. Decide: lamp ON below 300, OFF above 400: the gap is hysteresis, so the lamp does not flicker at dusk
  4. Drive: the pin cannot switch mains: transistor → relay (or SSR) with a flyback diode
  5. Extras: 1 s sampling to ignore car headlights, RTC schedule, PIR dimming
const int LDR = A0, RELAY = 8; const int ON_TH = 300, OFF_TH = 400; bool lamp = false; void setup() { pinMode(RELAY, OUTPUT); } void loop() { int light = analogRead(LDR); // high = bright if (!lamp && light < ON_TH) lamp = true; if (lamp && light > OFF_TH) lamp = false; digitalWrite(RELAY, lamp ? HIGH : LOW); delay(1000); }
Memory trick Every sensor-control design answer has the same four blocks: Sense → Convert → Decide → Drive. Draw them, then write the threshold logic.

13Computer Architecture: Pipelining

written
Q What is pipelining? How does pipeline implementation make instruction execution faster? · 38th BCS Written, 2018
Definition Pipelining splits instruction processing into k stages (Fetch, Decode, Execute, Write-back) with latches between them, so k different instructions are in different stages at the same time, like an assembly line. Kinds: instruction pipeline and arithmetic pipeline.
Formulas k stages, n instructions, cycle τ
Non-pipelined: n·k·τ
Pipelined: (k + n − 1)·τ
Speed-up S = nk / (k + n − 1) → k as n → ∞
Efficiency = S/k · throughput = n / ((k + n − 1)τ)
Worked: unequal stages ✍ Stages 50, 60, 70, 80 ns, latch 10 ns, 1000 instructions.
Non-pipelined: 1000 × 260 = 260 μs
Clock = slowest + latch = 90 ns
Pipelined: (4 + 999) × 90 = 90.27 μs
S = 260 / 90.27 ≈ 2.88 (not 4)

Why it is faster: the time for one instruction (latency) does not fall (it can even rise by the latch delay), but once the pipe is full one instruction finishes every cycle, so throughput rises up to k times.

15Computer Architecture: Cache Tag, Index, Offset

written
Q 16 KB of data in a direct-mapped cache with 4-word blocks: find the sizes of the tag, index and offset fields on a 32-bit architecture. · Bangladesh Bank AME, 04.02.2023
  1. Word = 32 bits = 4 B → block = 4 × 4 = 16 B = 2⁴
  2. Offset = log₂16 = 4 bits (2 byte + 2 word bits)
  3. Lines = 16 KB / 16 B = 2¹⁴/2⁴ = 2¹⁰ = 1024
  4. Index = log₂1024 = 10 bits
  5. Tag = 32 − 10 − 4 = 18 bits
Follow-up: total bits ✍ Each line = 128 data + 18 tag + 1 valid = 147 bits.
1024 × 147 = 150,528 bits ≈ 18.4 KB to hold 16 KB of data.
Same cache, other mappingsSetsIndexTag
Direct-mapped (1-way)10241018
4-way set-associative256820
Fully associative1028
Memory trick Work right to left: O-I-T. Offset from the block size, index from the number of sets, tag = whatever is left.

16Average Access Time

written
Q A read takes 50 ns on a cache miss and 5 ns on a hit; 80% of reads hit. Find the average read access time. · PGCB Assistant Engineer (CSE) 2021

tavg = h·thit + (1 − h)·tmiss = 0.8 × 5 + 0.2 × 50 = 4 + 10 = 14 ns

Exam trap Read the wording. If 50 ns is the miss penalty (extra time after the cache check), use t = thit + (1 − h) × penalty = 5 + 0.2 × 50 = 15 ns. Here the miss itself "takes 50 ns", so 14 ns.

18Computer Architecture: CPU or RAM Upgrade?

written
Q (a) The CPU is fast but the RAM is slow, so the CPU waits and response time suffers. Upgrade the CPU or the RAM? (b) If RAM speed is doubled, is memory latency halved? · ICB Securities Assistant Programmer, 27.06.2026

(a) Upgrade the RAM. The program is memory-bound (the "memory wall"): a faster CPU only waits more cycles. Fit lower-latency, higher-bandwidth RAM (dual channel), add capacity if the system pages to disk, or use a CPU with a larger cache. By Amdahl's law, speeding the part that is not the bottleneck gains little. Example: 40% compute, 60% waiting.

(b) No. "RAM speed" is the transfer rate (MT/s), i.e. bandwidth. Latency = CAS cycles × cycle time, and faster modules need more cycles: DDR4-3200 CL16 = 16 × 2000/3200 = 10 ns; DDR5-6400 CL32 = 32 × 2000/6400 = 10 ns. Bandwidth doubles (25.6 → 51.2 GB/s per channel), latency stays about the same; the controller, row activation and bus delays do not halve either.

Memory trick Bandwidth = lanes on the highway; latency = travel time of one car. More lanes do not shorten the trip.

19RAID: Recovering From a Drive Failure

written ×3
Q What steps should be taken to resolve a drive failure in a RAID system? · Petrobangla Assistant Manager (CSE), 31.05.2024
  1. Identify: controller alert / mdadm shows the array degraded; note the failed slot and serial
  2. Protect: back up critical data now; never re-initialise the array
  3. Check tolerance of the RAID level (table)
  4. Replace: hot-swap with a drive of equal or larger size
  5. Rebuild: a hot spare starts automatically, or add the disk; data is copied (mirror) or recomputed (parity)
  6. Verify: watch the rebuild, check SMART on the other drives, find the cause
LevelMethodDrives that may failRecovery
RAID 0striping0none: restore from backup
RAID 1mirroring1 (per mirror)copy from the twin
RAID 5striping + parity1XOR rebuild
RAID 6 · RAID 10dual parity · mirror + stripe2 · 1 per pairrebuild / re-mirror
Exam trap RAID is not a backup: it survives a dead disk, not deletion, ransomware or a second failure during a long rebuild.
