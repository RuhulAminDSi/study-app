1What a microprocessor is, contains and does

16 exams
Q1 What is a microprocessor? Explain the basic components of a microprocessor.SPCBL AME 2021 · label the parts of a given block diagram: DESCO AE(CSE) 2016

A microprocessor is a complete CPU on a single IC: it fetches instructions from memory, decodes and executes them. Memory and I/O are outside the chip.

  1. ALU: arithmetic and logic on data
  2. Control unit: decodes, sends timing and control signals
  3. Register array: accumulator, general, PC, SP, flags
  4. Internal buses + bus interface to address, data and control buses
Exam trap A viva answer of "ALU, registers, output circuit" loses marks: the control unit must be named and an output circuit is not a CPU part. Hard disk is never a component BUET IICT April 2021; "built-in memory and I/O" describes a microcontroller, not a microprocessor BUET M.Sc. April 2021.

6Segmentation and the 20-bit physical address

BCS every year
Q11 Why is memory segmentation needed in the 8086? What is the technique to generate a 20-bit physical address in a 16-bit microprocessor? 5 marks45th BCS CSE (2024)

Why: registers are 16-bit (reach only 64 KB) but the address bus is 20-bit (1 MB). Segments let 16-bit registers reach 1 MB; they also separate code, data and stack, make programs relocatable and allow 64 KB blocks to overlap.

How: PA = segment × 10H + offset: shift the 16-bit segment left by 4 bits (append a hex 0) and add the 16-bit offset in the BIU's adder.

CS = 1234H, IP = 0022H → 12340H + 0022H = 12362H

Q14 Write the meaning of this 8086 program status word: S = 0, Z = 0, AC = 1, P = 1, CY = 0. 5 marks45th BCS CSE (2024)

S = 0 → result positive (MSB 0) · Z = 0 → result not zero · AC = 1 → a carry went from bit 3 to bit 4 · P = 1 → even number of 1s · CY = 0 → no carry out of the MSB. Example: 08H + 09H = 11H gives exactly S0 Z0 AC1 P1 CY0.

Instructions that touch flags: STC / CLC / CMC set, clear, complement CF · STD / CLD set/clear DF · STI / CLI set/clear IF · PUSHF / POPF save and restore the whole register · LAHF / SAHF copy the low flag byte to and from AH. There is no instruction to set TF directly: push flags, change bit 8, pop.

Q20 Write the addressing mode of: MOV AX, BX · MOV AX, [SI] · MOV AX, 006H · MOV [AX], [BX].DESCO SAE(Computer) 2026

5 exams
Q21 What is assembly language? Write its features. Write a program in assembly language to add and multiply two numbers. 5 marks45th BCS CSE (2024)

Assembly language is a low-level language that writes each machine instruction as a mnemonic (MOV, ADD) with symbolic operands; an assembler translates it 1 : 1 into machine code.

  • machine-dependent (8086 code ≠ ARM code)
  • direct access to registers, memory, I/O ports
  • fast, compact code; used in drivers, boot code, embedded
  • labels, directives (DB, DW), comments
  • harder to write, debug and port than C
.MODEL SMALL .DATA N1 DB 05H N2 DB 03H SUM DB ? PRD DW ? .CODE MOV AX, @DATA MOV DS, AX ; point DS at data MOV AL, N1 ADD AL, N2 ; AL = 08H MOV SUM, AL MOV AL, N1 MUL N2 ; AX = AL × N2 = 000FH MOV PRD, AX MOV AH, 4CH INT 21H ; return to DOS

→ SUM = 08H (5 + 3) · PRD = 000FH (5 × 3). MUL with a byte operand multiplies by AL and leaves the 16-bit product in AX.

13Interrupts

BCS written
Q24 Define interrupt with an example. Write the types of software interrupts. How is an interrupt enabled, and what are the steps when an interrupt is processed?45th BCS CSE (2024) · 38th BCS (2018)

An interrupt is a signal that makes the CPU pause the current program, run an interrupt service routine (ISR), then resume. Example: a key press interrupts the CPU so it reads the keyboard.

Software interrupts (8086): INT n (n = 0–255, e.g. INT 21H DOS service) · INT 3 breakpoint · INTO on overflow · exceptions: divide error (type 0), single-step (type 1).

Enable: STI sets IF = 1 (maskable INTR accepted), CLI clears it; unmask the line in the 8259 PIC. NMI cannot be masked.

Interrupt controller 36th BCS (2016): the 8259A PIC takes 8 interrupt requests (cascade to 64), resolves priority, masks lines and gives the CPU the vector type. Hardware interrupt pins of the 8086: INTR and NMI BUET M.Sc. April 2021 · interrupt-driven I/O beats polling because it reduces CPU idle time 49th BCS CSE (2025)

14DMA and the 8237 controller

47th BCS · BCPCL
Q25 How does DMA increase system concurrency? List the data transfer modes of the 8237 DMA controller with their specialty. (What does a DMA controller do?)47th BCS ICT · BCPCL JI 2019

DMA lets an I/O device move a block directly to or from memory. The CPU only sets address, count and direction in the DMAC; the DMAC raises HOLD, gets HLDA, drives the bus and interrupts at the end. The CPU keeps computing (from cache/queue) meanwhile, so I/O and computation overlap.

1580386, Pentium and superscalar

BUET favourite
Q26 What are the advantages of the 80386 over the 80286?BUET M.Sc. October 2017

80386: 32-bit registers and buses (80286: 16-bit) · 32-bit address → 4 GB (80286: 24-bit, 16 MB) · paging with segmentation (virtual memory) · virtual-8086 mode to run DOS programs in protected mode · switches back to real mode without reset · 3-stage pipeline.

Q27 What is a superscalar processor? Why is the Pentium superscalar but the 80386 not?BUET M.Sc. October 2017 · BUET M.Sc. April 2017 · BUET M.Sc. May 2016 · BUET M.Sc. October 2015 · MM AP 2017

A superscalar CPU has several execution pipelines and issues more than one instruction per clock (CPI < 1). The Pentium has two integer pipelines, U and V, that run two simple independent instructions together, plus a separate FPU. The 80386 has one pipeline, so at best one instruction per clock: pipelined, not superscalar.

16Cores, threads, hyper-threading

bank & power papers
Q28 What does "2 cores and 4 threads" mean? What is hyper-threading and its use? Difference between Core i3, i5 and i7 (hardware).BTRC AD 2021 · BOF AP 2022 · DESCO SAE 2022 · Combined Bank SO(IT) 2023

Core = a complete execution unit; thread = an instruction stream the OS can schedule. 2 cores / 4 threads = each core runs 2 threads by hyper-threading (Intel SMT): one physical core keeps two register sets and fills idle execution units from the second thread (≈ 15–30 % more throughput, not 2×). i3 → i5 → i7 → i9: more cores/threads, larger L3 cache, higher turbo clock, more features; compare within the same generation.

25Pipelining

17 exams
Q44 What is pipelining? How does it make instruction execution faster? Explain the stages (4-stage / 5-stage, DLX).46th BCS ICT · 38th BCS (2018) · Combined Bank AME/AE(IT) 2024 · BB AME 2019 · BTCL AE(CSE) 2017

Pipelining splits instruction execution into stages and overlaps them, like an assembly line: while one instruction executes, the next is decoded and a third is fetched. Each instruction still takes k cycles (latency unchanged) but one finishes every cycle (throughput up). 4-stage: Fetch, Decode, Execute, Write-back. DLX / MIPS 5-stage: IF · ID · EX · MEM · WB.

Q45 Using a pipeline, calculate the fetch and execution cycles (time for n instructions).BTCL AE(CSE) 2017

k stages, n instructions: pipelined = k + (n − 1) cycles; non-pipelined = n × k. Speedup = nk / (k + n − 1) → k for large n.

4 stages, 10 instructions: 4 + 9 = 13 cycles vs 40 (3.08×) · 5 stages, 100 instructions: 104 vs 500 → 4.81×

Real speedup stays below k: the pipeline must fill (k − 1 cycles), stages are not perfectly balanced (the clock fits the slowest), pipeline registers add delay, and hazards insert stalls.

Q46 Why do modern processors favour a multi-stage pipelined approach over a single-cycle implementation?Combined Bank AME/AE(IT) 2026(Jan) · Combined Bank SO(IT) 2026

Single-cycle: the clock must fit the slowest instruction (load), so every instruction pays that time and most hardware idles. Pipeline: the clock fits one short stage → higher frequency; stages work in parallel → CPI ≈ 1 at a much shorter cycle; hardware is reused. Cost: hazards and pipeline registers.

32Cache memory and locality

53 exams ✦ the top topic
Q58 What is cache memory? Explain locality of reference (spatial and temporal) with examples. Draw the organization of cache in a microprocessor system and explain how it speeds up execution.43rd BCS CSE · BPSC AP 2023 · 46th BCS CSE · Hydrocarbon Unit AD(ICT) 2025

Cache is a small, fast SRAM between the CPU and main memory that keeps copies of recently used blocks. The CPU checks the cache first: hit → data in a few ns; miss → fetch the whole block from RAM into the cache.

Temporal locality: a word used now will be used again soon (loop variable, loop code). Spatial locality: words near it will be used soon (array elements, next instructions). Locality is why a cache of a few MB serves a 16 GB RAM with 95 %+ hits.

Cache vs main memory: SRAM vs DRAM, KB–MB vs GB, ≈ 1–10 ns vs 60–100 ns, managed by hardware vs OS BPSC ANE 2020 · cache vs virtual memory notes MoFood Network/Website Manager 2025 · cache holds what the CPU is likely to reuse (true statement) Combined Bank SO(IT) 2021 · registers are used to accept and transfer data the CPU is using immediately BPSC AP 2022
