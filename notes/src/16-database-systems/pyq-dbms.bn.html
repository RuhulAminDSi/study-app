প্র১ নিচের কোডটি বিশ্লেষণ করুন: এটি কী রিটার্ন করবে?Combined Bank Officer(IT) 2023 · Rupali Bank ANE 2023 · Petrobangla ANE সাজেশন শিটেও আছে
SELECT d.department_name, AVG(e.salary) AS average_salary FROM employees e JOIN department d ON e.department_id = d.department_id WHERE e.salary > (SELECT AVG(salary) FROM employees) GROUP BY d.department_name HAVING COUNT(*) > 2 ORDER BY average_salary DESC;
  1. WHERE রাখে কোম্পানির গড়ের বেশি (59556) বেতনের কর্মী: Karim, Rahim, Nila, Babu, Hasan
  2. বিভাগ অনুযায়ী GROUP BY: IT ৩, HR ১, Accounts ১
  3. HAVING রাখে যে গ্রুপে এমন কর্মী ২ জনের বেশি
  4. তাদের গড় দেখায়, বড় থেকে ছোট

→ IT | 70000 (শুধু IT-তে গড়ের বেশি ৩ জন: 90000 + 60000 + 60000)

পরীক্ষার ফাঁদ ছাপা অবস্থায় কুয়েরিটি ভুল: alias e ব্যবহার করা হয়েছে কিন্তু ঘোষণা নেই (FROM employees-এর পরে e লাগবে), আর সাজেশন শিটের কপিতে COUNT() ফাঁকা। আগে ভুলটি বলুন, ঠিক করুন, তারপর ব্যাখ্যা দিন। সাজেশন শিটের সংস্করণে তুলনা হয় নিজের বিভাগের গড়ের সাথে (correlated subquery): এই নমুনায় কোনো সারি আসে না।
মনে রাখার কৌশল "WHERE আগে, HAVING পরে": WHERE-এ AVG/COUNT চলে না, HAVING-এ চলে। SELECT-এর alias শুধু ORDER BY-তে কাজ করে।

একই ধরন, অন্য স্কিমা: ঠিক ২টি / ২টির বেশি অফারিং আছে এমন কোর্স → GROUP BY c.crscode HAVING COUNT(*) = 2 Petrobangla AM(CSE) 2024 · ভর্তি ≤ ৩০ এমন কোর্স ও শিক্ষার্থী সংখ্যা → HAVING COUNT(*) <= 30 ICB Securities AP 2026

DBMS · বিগত প্রশ্নের সমাধানSQL ১–২: অ্যাগ্রিগেট, সাবকুয়েরি
প্র২ COURSE(Course_ID, Course_name, Chief_ID), INSTRUCTOR(Instructor_ID, Course_ID, Salary, Joining_date): প্রতিটি কোর্সের গড় বেতন বের করুন।NACTAR 2020 · বিভাগ দিয়ে একই প্রশ্ন: NESCO JAM(ICT) 2021
SELECT c.Course_name, AVG(i.Salary) AS avg_salary FROM COURSE c JOIN INSTRUCTOR i ON i.Course_ID = c.Course_ID GROUP BY c.Course_ID, c.Course_name;
প্র৩ Instructor(ID, name, dept_name, salary): (ক) বিভাগভিত্তিক গড় বেতন; (খ) যেসব বিভাগের গড় 42000-এর বেশি; (গ) CSE বিভাগের অন্তত একজন শিক্ষকের চেয়ে বেশি বেতন যাঁদের।NRCC AP 2021
(a) SELECT dept_name, AVG(salary) FROM instructor GROUP BY dept_name; (b) … GROUP BY dept_name HAVING AVG(salary) > 42000; (c) SELECT name FROM instructor WHERE salary > SOME (SELECT salary FROM instructor WHERE dept_name = 'CSE');

২সাবকুয়েরি: গড় বা কোনো ব্যক্তির সাথে তুলনা

লিখিত, প্রতি বছর
প্র৪ EMPLOYEE(id, name, department, salary): যেসব কর্মী এমন বিভাগে কাজ করেন যার গড় বেতন সব বিভাগের গড়ের চেয়ে কম, তাঁদের বের করুন।BPDB AE(CSE) 2023
SELECT name, department_id, salary FROM employees WHERE department_id IN (SELECT department_id FROM employees GROUP BY department_id HAVING AVG(salary) < (SELECT AVG(salary) FROM employees));

→ Babu, Tania, Jamal (HR-এর গড় 49333 < 59556)

প্র৫ (ক) যাঁদের বেতন Rahim-এর সমান কিন্তু পদ আলাদা। (খ) কোম্পানির গড়ের চেয়ে বেশি বেতন যাঁদের।BGDCL AM(CSE) 2024
(a) SELECT name FROM employees WHERE salary = (SELECT salary FROM employees WHERE name = 'Rahim') AND job <> (SELECT job FROM employees WHERE name = 'Rahim'); (b) SELECT name FROM employees WHERE salary > (SELECT AVG(salary) FROM employees);

→ (ক) Nila (60000, Analyst) · (খ) Karim, Rahim, Nila, Babu, Hasan

প্র৬ employees(id, first_name, …, salary, dept_id), department(dept_id, dept_name): সর্বোচ্চ বেতনের কর্মীর first name ও বিভাগের নাম।BIWTA AE(CSE) 2023

-- 2nd highest SELECT MAX(salary) FROM employees WHERE salary < (SELECT MAX(salary) FROM employees); -- Nth highest (N = 3) SELECT DISTINCT salary FROM employees ORDER BY salary DESC LIMIT 1 OFFSET 2;

→ 75000 · 70000

উইন্ডো ফাংশন দিয়ে

SELECT name, salary FROM (SELECT name, salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk FROM employees) x WHERE rnk = 3;
ফাঁদ DISTINCT / DENSE_RANK ছাড়া দুজনের বেতন 60000 হলে "৩য় সর্বোচ্চ" ভুল আসে। Oracle-এ FETCH FIRST, SQL Server-এ TOP।

DBMS · বিগত প্রশ্নের সমাধানSQL ৩: একাধিক টেবিলের জয়েন
প্র১০ Project(Project_id, Project_name, Manager_name), Location(location_id, Location_name, project_id), Employee(Employee_id, Employee_Name, Location_id, Joining_date, Salary): জানুয়ারি ২০২১-এর আগে যোগ দেওয়া কর্মীদের ভিত্তিতে প্রতিটি প্রজেক্টের project_name, Location_name ও মোট বেতন দেখান।APSCL AE(ICT) 2021
SELECT p.Project_name, l.Location_name, SUM(e.Salary) AS Total_salary FROM Project p JOIN Location l ON l.project_id = p.Project_id JOIN Employee e ON e.Location_id = l.location_id WHERE e.Joining_date < '2021-01-01' GROUP BY p.Project_name, l.Location_name;

→ Payroll | Dhaka | 50000 · e-Banking | Ctg | 60000 · e-Banking | Dhaka | 45000

প্র১১ employee(id, name, salary), equipment(id, name, price), hire(employee_id, equipment_id): সবচেয়ে বেশি যন্ত্রপাতি ধার নেওয়া কর্মীর নাম।BAPEX AGM(ICT) 2023
SELECT e.name, COUNT(*) AS items FROM employee e JOIN hire h ON h.employee_id = e.id GROUP BY e.id, e.name HAVING COUNT(*) = (SELECT MAX(cnt) FROM (SELECT COUNT(*) AS cnt FROM hire GROUP BY employee_id) t);

→ Chand | 3 (সমান হলে সবাই আসে: ORDER BY … LIMIT 1-এর চেয়ে নিরাপদ)

প্র১২ Product(pname, price, category, maker), Purchase(buyer, seller, stock), Company(cname, country), Person(per-name, address, phone); maker = cname, buyer/seller = per-name। (ক) আমেরিকান কোম্পানির তৈরি পণ্য কিনেছেন যাঁরা। (খ) দেশভিত্তিক সব পণ্যের ও বিক্রীত পণ্যের যোগফল।NWPGCL AM(ICT) 2024
(a) SELECT DISTINCT pu.buyer FROM Purchase pu JOIN Product p ON p.pname = pu.stock JOIN Company c ON c.cname = p.maker WHERE c.country = 'USA'; (b) SELECT c.country, (SELECT SUM(p2.price) FROM Product p2 JOIN Company c2 ON c2.cname = p2.maker WHERE c2.country = c.country) AS all_products, SUM(p.price) AS sold_value FROM Purchase pu JOIN Product p ON p.pname = pu.stock JOIN Company c ON c.cname = p.maker GROUP BY c.country;

→ নমুনা: Apple iPhone 1000 + Dell XPS 1500 (USA), Walton Primo 200 (Bangladesh), Primo দুবার বিক্রি: (ক) Rafi, Shoeb · (খ) Bangladesh | 200 | 400 · USA | 2500 | 2500

যে অনুমান লিখবেন "American category" মানে ধরা হলো যে কোম্পানির country = USA, তাদের তৈরি; Purchase.stock মানে পণ্যের নাম। এমন অনুমান এক লাইনে লিখে দিন: পরীক্ষক নম্বর দেন।

DBMS · বিগত প্রশ্নের সমাধানSQL ৩–৪: অ্যান্টি-জয়েন, DDL/DML
প্র১৩ Actor(actor_id, name, age), Play(play_id, writer), Role(play_id, actor_id): (ক) Shakespeare-এর ৩ বা তার বেশি নাটকে অভিনয় করেছেন এমন অভিনেতার সংখ্যা; (খ) Chekhov-এর নাটকে আছেন কিন্তু Shakespeare-এর কোনো নাটকে নেই এমন অভিনেতা।Petrobangla ANE সাজেশন শিট (তারিখসহ প্রশ্নপত্র নয়)
(i) SELECT COUNT(*) FROM (SELECT r.actor_id FROM Role r JOIN Play p ON p.play_id = r.play_id WHERE p.writer = 'Shakespeare' GROUP BY r.actor_id HAVING COUNT(DISTINCT r.play_id) >= 3) t; (ii) SELECT name FROM Actor WHERE actor_id IN (… WHERE p.writer = 'Chekhov') AND actor_id NOT IN (… WHERE p.writer = 'Shakespeare');
মনে রাখার কৌশল "A-তে আছে কিন্তু B-তে কখনো নয়" = IN … AND NOT IN … (বা EXCEPT)। "অন্তত n" = GROUP BY + HAVING COUNT ≥ n।

৪Create, insert, update, delete

ছোট লিখিত
প্র১৪ Employee(ID, First_name, Last_name, Joining_date, Salary), Employee_Info(Emp_ID, Designation): (ক) দুটি টেবিল তৈরি; (খ) পদভিত্তিক সর্বনিম্ন, সর্বোচ্চ ও গড় বেতন; (গ) ফেব্রুয়ারি ২০২৩-এর আগে যোগ দেওয়া কর্মী।MRA SCO 2023
CREATE TABLE Employee (ID INT PRIMARY KEY, First_name VARCHAR(30), Last_name VARCHAR(30), Joining_date DATE, Salary DECIMAL(10,2)); CREATE TABLE Employee_Info (Emp_ID INT REFERENCES Employee(ID), Designation VARCHAR(30)); SELECT i.Designation, MIN(e.Salary), MAX(e.Salary), AVG(e.Salary) FROM Employee e JOIN Employee_Info i ON i.Emp_ID = e.ID GROUP BY i.Designation; SELECT * FROM Employee WHERE Joining_date < '2023-02-01';

উত্তর: টেবিল A(a_id, …), B(b_id, …) এবং তৃতীয় টেবিল R(a_id, b_id, R-এর attribute); a_id → A, b_id → B, আর (a_id, b_id) মিলে primary key। A বা B-তে একটি বাড়তি কলামে "অনেক" মান রাখা যায় না।

প্র২২ দুর্বল এনটিটি (weak entity) কী? স্কুল ডেটাবেজে একটি weak entity ও তার identifying relationship বের করুন: Student(student_id, student_name, admission_year), Teacher(…), Course(course_id, subject_name, credit)।BCC AP 2021

দুর্বল এনটিটির নিজস্ব কোনো key নেই; একে শুধু মালিক এনটিটির মাধ্যমে চেনা যায়। এখানে তিনটির কোনোটিই দুর্বল নয় (প্রত্যেকের নিজস্ব id আছে)। একটি যোগ করুন: Guardian(name, relation), যার মালিক Student, identifying relationship HAS_GUARDIAN; এর PK = (student_id, name)।

প্র২৩ লাইব্রেরি: Book–Borrower রিলেশন 1-to-1, 1-to-many না many-to-many? যুক্তি দিন।Bank AP লিখিত (শিটে ব্যাংকের নাম কাটা)এক সময়ে একটি কপির ধারক ≤ ১ জন, একজন ধারকের অনেক কপি: 1 : N। সময়ের হিসাবে (লোন ইতিহাস) এটি M : N, LOAN টেবিলের মাধ্যমে।
