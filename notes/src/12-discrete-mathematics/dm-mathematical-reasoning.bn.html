ভিত্তি ★
সংজ্ঞা গাণিতিক যুক্তি হল প্রদত্ত বিবৃতি বা প্রতিজ্ঞা থেকে সিদ্ধান্তে পৌঁছানোর যৌক্তিক প্রক্রিয়া। একটি প্রমাণ হলো এমন যুক্তি যেখানে প্রতিটি ধাপ বৈধ; প্রতিজ্ঞা যেকোনো অবস্থাতেই সত্য হলেও সিদ্ধান্ত টিকে থাকলে তাকে বৈধ, আর প্রতিজ্ঞাগুলোও সত্য থাকলে তাকে সুস্থ (sound) বলে। প্রমাণে প্রতিটি প্রযোজ্য ক্ষেত্রই ধরতে হয়, যে কয়েকটি পরীক্ষা করে দেখলেন তা নয়।

বিপরীত উদাহরণএকটি ব্যর্থ ক্ষেত্রই সাধারণ বিবৃতি ভাঙেখণ্ডন, প্রমাণ নয়
পরীক্ষার ফাঁদ বিপরীত উদাহরণ খণ্ডন করে, কখনো প্রমাণ করে না; আর একটি সত্য উদাহরণ কখনো সাধারণ বিবৃতি প্রমাণ করে না। "n = 1 … ১০ পর্যন্ত মিলেছে, তাই সব n-এর জন্য মিলবে" — এটি প্রমাণ নয়; ইন্ডাকশন তো এই ফাঁকটাই পূরণ করতেই বানানো।
কী প্রতিজ্ঞা গণ্য হয় সংজ্ঞা, যা প্রমাণের ভেতরে খুলে লেখা যায় · আক্সিওম, যে শাখার গণিতে তা ধরা নেওয়া আছে · লেম্মা, আগেই প্রমাণ করা · বিবৃতির নিজের অনুকল্প। যা গণ্য হয় না: "এটা সুপরিচিত", "চিত্র থেকে স্পষ্ট", "অল্প ক্ষেত্রে মিলেছে"। প্রমাণ ছাড়া লেম্মার আশ্রয় নেওয়া মান নম্বর চুরিরই নামান্তর।
মনে রাখার কৌশল — পদ্ধতি চেনা প্রশ্নের আকৃতি দেখো, বিষয় নয়। "প্রতিটি n ≥ 1-এর জন্য …" → ইন্ডাকশন। "এরূপ কিছু নেই" বা "দেখাও যে … নয়" → অসঙ্গতি। "যদি … তবে …" → কন্ট্রাপজিটিভ। "এমন কোনো আছে কি?" → বিপরীত উদাহরণ খুঁজে বের করো।

  2. প্রতিজ্ঞা লেখো — সংজ্ঞা, আক্সিওম ও প্রমাণিত লেম্মা, যা ব্যবহারের অনুমতি আছে।
  3. ধাপে ধাপে নির্গমন — প্রতিটি লাইন যাচাইযোগ্য; পাঠক বুঝতে পারে না এমন লাইপ কখনো বাদ দিও না।
  4. সিদ্ধান্ত দাও — ব্যবহৃত নীতির নাম উল্লেখ করো: "গাণিতিক আরোহের নীতি অনুযায়ী", "অনুকল্প মিথ্যা হওয়ায়"।

সবচেয়ে বেশি আসে ★
সংজ্ঞা গাণিতিক আরোহ প্রাকৃতিক সংখ্যা সম্পর্কিত বিবৃতি প্রমাণের কৌশল, যা নির্ভর করে একটি মাত্র নীতির উপর — গাণিতিক আরোহের নীতি: যদি P(1) সত্য হয় এবং প্রতিটি পূর্ণসংখ্যা k ≥ 1-এর জন্য P(k) ⇒ P(k+1) হয়, তবে P(n) প্রতিটি n ≥ 1-এর জন্য সত্য। দুটো অংশই অপরিহার্য — কেবল ভিত্তি ক্ষেত্র কিছুই প্রমাণ করে না, আর কেবল আরোহ ধাপ কিছু থেকেই শুরু হয় না।

১. ভিত্তি ক্ষেত্র (n = 0 বা 1)"n = 1-এর জন্য P(1) সত্য।" সংখ্যায় মিলিয়ে দেখো।সিঁড়ির নিচতলা নেই

৩. সিদ্ধান্ত"গাণিতিক আরোহের নীতি অনুযায়ী P(n) সব n ≥ 1-এর জন্য সত্য।"নীতির নামই হারায়
মনে রাখার কৌশল "ভিত্তি বানায় প্রথম ইট, আরোহ ধাপ ভাবনা এক ধাপ এগিয়ে নিয়ে যায় — আর সেটা করতে হবে প্রতিবার।" ধাপটি একটি নিয়ম, নমুনা নয় — লেখো "k ≥ 1 যেকোনো বলে P(k) সত্য ধরে নিন", "ধরি k = 3" নয়।
যে বিবৃতি ইন্ডাকশনে প্রমাণ করতে বলা হতে পারেভিত্তিধাপের আকৃতি
1 + 2 + … + n = n(n+1)/2n = 1দুই পাশে (k+1) পদ যোগ
1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1n = 0বাম পাশ হুবহু দ্বিগুণ
প্রতিটি n ≥ 1-এর জন্য n² ≥ nn = 1(k+1)² = k² + 2k + 1 ≥ k² + k
প্রতিটি n ≥ 1-এর জন্য n(n+1) জোড়n = 1(k+1)(k+2) = k(k+1) + 2(k+1)

ভিত্তি ক্ষেত্র কীভাবে বুঝবে n-এর প্রথম মান টানা হয় সূত্র থেকে, পছন্দমতো নয়। 1 + 2 + … + n শুরু হয় n = 1 থেকে; 1 + 2 + 2² + … + 2ⁿ শুরু হয় n = 0 থেকে; n!-এ n = 0। বিবৃতিতে "সব n ≥ 0-এর জন্য" থাকলে ভিত্তি ক্ষেত্র অবশ্যই n = 0 — n = 1 থেকে শুরু করলে n = 0-এর ক্ষেত্র প্রমাণিতই থাকে না।

৩সম্পূর্ণ প্রমাণ: 1 + 2 + 3 + … + n = n(n+1)/2

প্রমিত নমুনা ★
উদাহরণ ✍ পূর্ণ প্রমাণ P(n) ধরি: 1 + 2 + 3 + … + n = n(n+1)/2. (১) ভিত্তি ক্ষেত্র (n = 1). বাম = 1, ডান = 1(1+1)/2 = 1, তাই P(1) সত্য। (২) আরোহ অনুকল্প. k ≥ 1 যেকোনো বলে P(k) ধরে নিই: 1 + 2 + … + k = k(k+1)/2। (৩) আরোহ ধাপ. P(k+1) দেখাই: 1 + 2 + … + k + (k+1) = k(k+1)/2 + (k+1)  (অনুকল্প অনুযায়ী) = (k+1)[k/2 + 1] = (k+1)(k + 2)/2 = (k+1)((k+1) + 1)/2 — এটাই P(k+1)-এর ডান পাশ, তাই P(k+1) সত্য। (৪) সিদ্ধান্ত. P(1) সত্য এবং প্রতিটি k ≥ 1-এর জন্য P(k) ⇒ P(k+1), তাই গাণিতিক আরোহের নীতি অনুযায়ী P(n) প্রতিটি n ≥ 1-এর জন্য সত্য। ∎
পরীক্ষার ফাঁদ — এই পাঠের সবচেয়ে বেশি নম্বর কাড়া ভুল আরোহ ধাপে দেখাতে হবে প্রতিটি পূর্ণসংখ্যা k ≥ 1-এর জন্য P(k) ⇒ P(k+1)। তিনভাবে ভুল হয় এবং তিনবারই নম্বর শূন্য। (i) একটি নির্দিষ্ট মানের জন্য, যেমন k = 3 ধরে ধাপটি যাচাই করা — সেটি নমুনা, প্রমাণ নয়। (ii) বিপরীত রূপ লেখা P(k+1) ⇒ P(k), যা সম্পূর্ণ অন্য বিবৃতি। (iii) "ধরি P(k)" কথাটি বাদ দিয়ে সরাসরি k+1-এর ফল বলে দেওয়া। কোনো প্রমাণকে "k = 1, 2, 3, 4, 5-এ মিলল" বলে সাজানো যায়, সেটি ইন্ডাকশন নয়।
ধাপটি লিখবেন যাতে পরীক্ষক সন্তুষ্ট হন (i) বিবৃতিটিকে নাম দাও "P(n): …"; (ii) ভিত্তি ক্ষেত্র সংখ্যায় দেখাও; (iii) "k ≥ 1 যেকোনো বলে P(k) ধরি"; (iv) k+1-এর পাশ অনুকল্প থেকে শুরু করে গোনো এবং কোথায় অনুকল্প ব্যবহার হলো তা চিহ্নিত করো; (v) শেষে "গাণিতিক আরোহের নীতি অনুযায়ী" লেখো। প্রতি লাইনে নম্বর — (v) বাদ দিও না।
উদাহরণ ✍ অনুকল্প কেন দরকার এই প্রমাণে ধাপটি এক লাইনের বদলে দাঁড়ায়, কিন্তু শুধু তখনই, যখন "1 + 2 + … + k"-কে তার বন্ধ রূপ k(k+1)/2 দিয়ে বদলে দেওয়া হয়। বদল ছাড়া লাইপটি লিখলে তুমি কেবল k+1-এর জন্য বিবৃতিটাই নতুন করে বলেছ — আর ইন্ডাকশন ঠিক এটাই করতে বলে না। অনুকল্পই হলো যন্ত্র; যন্ত্র না ডাকলে ধাপ কিছুই প্রমাণ করে না।
উদাহরণ ✍ দুটি লাইন যেগুলো প্রমাণ মনে হয়, আসলে নয় (i) "n = 1, 2, 3-এ মিলেছে, তাই সব n-এর জন্য মিলবে।" এতে ধাপে k-এর একটি মান মাপা হয়েছে — নমুনা, প্রমাণ নয়। (ii) "P(k+1) ⇒ P(k), তাই ইনডাকশনে প্রমাণিত।" এটি সিঁড়ি উল্টো দিকে চড়ায়: k+1 সত্য জানলে কিছুই k সম্পর্কে বলা যায় না। শুধু P(k) ⇒ P(k+1) চড়ায়।
সরল বীজগণিতের চেয়ে ইন্ডাকশন কখন জেয়ে দুই পাশেই n থাকা বিবৃতি — n!, ফিবোনাচ্চি, চলমান সমষ্টি, ভাগ্যনির্ধারিততা — বিন্যাস করে লাভ নেই, আর বিবৃতির পুনরাবৃত্ত কাঠামো ধাপের আকৃতির সঙ্গে হুবহু মেলে। অন্যথায় "n² + n সবসময় জোড়" — n(n+1) লিখে এক লাইনেই শেষ, পরীক্ষক দুটোই মানেন। আগের ক্ষেত্র থেকে বিবৃতি গড়ে উঠলেই ইন্ডাকশন ধরো।
উদাহরণ ✍ বিজোড় সংখ্যার সমষ্টি প্রমাণ করো, প্রতিটি n ≥ 1-এর জন্য 1 + 3 + 5 + … + (2n−1) = n²। ভিত্তি n = 1: বাম = 1, ডান = 1² = 1 ✓। ধাপ: ধরি 1 + 3 + … + (2k−1) = k²। তাহলে 1 + 3 + … + (2k−1) + (2k+1) = k² + 2k + 1 = (k+1)² — ঠিক P(k+1)। সিদ্ধান্ত: গাণিতিক আরোহের নীতি অনুযায়ী সব n ≥ 1-এর জন্য বিবৃতিটি সত্য। ∎
চার লাইন কেন যথেষ্ট ধাপটি (1) অনুকল্প ধরে নেয়, (2) k+1-এর পাশ বের করে, (3) ফলাফলকে পুনরাবৃত্ত রূপে সাজায়, (4) লেখে যে তা ঠিক P(k+1)। প্রতিটি লাইন আলাদা নম্বর বহন করে, তাই লেখার পরীক্ষায় ওই চারটি লাইন স্পষ্টভাবে আলাদা করে রাখো — প্যারাগ্রাফ ভেঙে লিখলে নম্বর কাটে না।

Discrete Maths · গাণিতিক যুক্তিদ্বিতীয় প্রমাণ ও শক্তিশালী আরোহ

৪দ্বিতীয় সম্পূর্ণ প্রমাণ: 1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1

ঘনঘন আসে ★
উদাহরণ ✍ লেখা পরীক্ষার আদর্শ উত্তর P(n) ধরি: প্রতিটি পূর্ণসংখ্যা n ≥ 0-এর জন্য 1 + 2 + 2² + … + 2ⁿ = 2ⁿ⁺¹ − 1। (১) ভিত্তি ক্ষেত্র (n = 0). বাম = 2⁰ = 1, ডান = 2¹ − 1 = 1, তাই P(0) সত্য। (২) আরোহ অনুকল্প. k ≥ 0 যেকোনো বলে P(k) ধরি: 1 + 2 + 2² + … + 2ᵏ = 2ᵏ⁺¹ − 1। (৩) আরোহ ধাপ. P(k+1) দেখাই: 1 + 2 + … + 2ᵏ + 2ᵏ⁺¹ = (2ᵏ⁺¹ − 1) + 2ᵏ⁺¹  (অনুকল্প অনুযায়ী) = 2 · 2ᵏ⁺¹ − 1 = 2ᵏ⁺² − 1 = 2^(k+1)+1 − 1 — এটাই P(k+1), তাই P(k+1) সত্য। (৪) সিদ্ধান্ত. P(0) সত্য এবং প্রতিটি k ≥ 0-এর জন্য P(k) ⇒ P(k+1), তাই গাণিতিক আরোহের নীতি অনুযায়ী P(n) সব পূর্ণসংখ্যা n ≥ 0-এর জন্য সত্য। ∎
সংজ্ঞা — শক্তিশালী (পূর্ণ) আরোহ সব n ≥ 1-এর জন্য P(n) প্রমাণের জন্য যথেষ্ট দেখানো: (ক) P(1) সত্য, এবং (খ) প্রতিটি k ≥ 1-এর জন্য, যদি P(1), P(2), …, P(k) সবগুলো সত্য হয়, তবে P(k+1) সত্য। শক্তিশালী আরোহ আসলে আরোহের একটি শক্তিশালী অনুকল্প — দুটি পরস্পর সমতুল্য, তাই একটি দিয়ে যা প্রমাণ হয় না, অন্যটি দিয়েও হয় না। ঠিক তখনই এটি লাগে যখন k+1-এর ক্ষেত্রে একাধিক আগের ক্ষেত্র একসঙ্গে দরকার।
উদাহরণ ✍ শক্তিশালী আরোহ প্রমাণ করো, প্রতিটি পূর্ণসংখ্যা n ≥ 2-এর একটি মৌল উত্তাধক আছে। ভিত্তি n = 2: 2 মৌল, তাই 2 | 2। ধাপ: ধরি 2 … k-এর প্রতিটি পূর্ণসংখ্যার একটি মৌল উত্তাধক আছে। k+1 প্রস্তিপাদ হলে দাবি সরাসরি; আর যৌগ হলে তার 1 < d < k+1 থাকে এমন একটি উত্তাধক d থাকে, আর শক্তিশালী অনুকল্পে d-ও একটি মৌল উত্তাধক p আছে, যা k+1-কেও বিভাজ্য করে। অতএব সব n ≥ 2-এর একটি মৌল উত্তাধক আছে।
পরীক্ষার ফাঁদ (i) ইন্ডাকশন কেবল ℕ সম্পর্কিত বিবৃতি প্রমাণ করে। (ii) ধাপে অবশ্যই লিখতে হবে "প্রতিটি k ≥ 1-এর জন্য"; "কোনো k-এর জন্য" লিখলে ধাপ প্রমাণিত হয়নি। (iii) অনুকল্প আসলে ব্যবহার করতে হবে — k+1-এর লাইপটি তা ছাড়াই এলে যুক্তি বৃত্তাকার। (iv) k+1-এর ক্ষেত্রে দুটি আগের ক্ষেত্র লাগলে শক্তিশালী আরোহ ধরো, নয়তো বিবৃতিটি লেখা অবস্থাতেই মিথ্যা।
উদাহরণ ✍ আরেকটি নিয়মিত প্রমাণ প্রমাণ করো, 1 + 1/2 + 1/2² + … + 1/2ⁿ = 2 − 1/2ⁿ, n ≥ 0। ভিত্তি n = 0: বাম = 1, ডান = 2 − 1 = 1 ✓। ধাপ: k পর্যন্ত যোগ 2 − 1/2ᵏ ধরি; তাহলে k+1 পর্যন্ত যোগ = (2 − 1/2ᵏ) + 1/2ᵏ⁺¹ = 2 − 2/2ᵏ⁺¹ + 1/2ᵏ⁺¹ = 2 − 1/2ᵏ⁺¹ ✓ — ঠিক P(k+1)। তিনটি বিবৃতি, একই তিন লাইন।
কখন ইন্ডাকশন ব্যবহার করা যাবে না ইন্ডাকশন কেবল প্রাকৃতিক সংখ্যা n-এর জন্য P(n) প্রমাণ করে, আর কিছু নয়। অসীম বাস্তব মানের উপর দাঁড়ানো দাবি — "বর্গের বর্গ মূলদ" — ইন্ডাকশনে আসে না, আর ইনডাকশনের চেয়ে অন্য কোনো যুক্তিও তাকে বাঁচায় না। আবার একটি প্রাকৃতিক n-তেই বিবৃতিটি খারাপ হলে সেটি খণ্ডিত, প্রমাণিত নয়।
পরীক্ষার ফাঁদ — অনুকল্প কোনটি ধরা হচ্ছে "n-এর সঙ্গে সম্পর্কিত কোনো বিবৃতি" বললে অনুকল্পটি হতে পারে P(1) নয়, P(k), কিংবা k-এর প্রতিটি মানের জন্য P(k)। তিনটি লিখলে অনুকল্প স্পষ্ট হয় এবং পরীক্ষক সঙ্গে সঙ্গে বুঝতে পারেন তুমি ধাপটি ঠিক ধরেছ কি না।
ভুল ধাপ ধরা পড়া পরীক্ষক সবচেয়ে দ্রুত লক্ষ্য করেন সেই লাইপটি, যেখানে ক-এর বদলে সরাসরি k+1 বসে দেওয়া হয়েছে অথচ অনুকল্প কোথাও ব্যবহার হয়নি। এটি একটি চক্রাকার যুক্তি (circular reasoning): ধাপটি প্রমাণ করে না, কেবল দাবিটি নতুন করে বলে। এড়াতে হলে ধাপের প্রথম লাইপেই অনুকল্পের সমীকরণটি বসাও।

৫অসঙ্গতি প্রমাণ (কন্ট্রাডিকশন)

সবচেয়ে বেশি আসে ★
সংজ্ঞা যাকে বিরোধাভ্যস (reductio ad absurdum)-ও বলে। P প্রমাণ করতে: ¬P ধরে নিন — ধরা নেওয়াটি সাময়িক অনুকল্প, দাবি নয় — আর তা থেকে এমন কিছু নির্গমন করান যা অসম্ভব: কোনো বিবৃতি তার নেতিবাচকের সঙ্গে একসঙ্গে, 0 = 1, শূন্য দিয়ে ভাগ, পরস্পর বিরোধী গুণাঙ্কযুক্ত কোনো বস্তু। এই অসম্ভবতাকে ⊥ দিয়ে লেখা হয়। ¬P অসম্ভবতায় নিয়ে গেলে P অবশ্যই সত্য।

মনে রাখার কৌশল "ধারি অশকা ধরে নাও, অসম্ভবতা পর্যন্ত ঠেল নাও — তাহলেই আসল দাবিটা বেরিয়ে আসবে।" পদ্ধতির নিশ্চিত লক্ষণ হলো "ধরি" / "মনে করি" শব্দটি, তারপর অবিলম্বে যার বিরুদ্ধে আঘাত করা শুরু।
যে চার লাইন পরীক্ষক চায় (১) দাবিটি P পরিষ্কারভাবে লেখো। (২) লেখো "ধরি, অসঙ্গতির জন্য, ¬P", এবং নেতিবাচকটিকে অনুকল্প হিসেবেই ধরে রাখো। (৩) ধাপে ধাপে পরিণতি নির্গমন করে তা অসম্ভবতা ⊥-এ ঠেলাও। (৪) শেষে লেখো "অনুকল্প মিথ্যা, অতএব P" — অসঙ্গতি অনুকল্পের বিরুদ্ধে, P-এর বিরুদ্ধে নয়।
পরীক্ষার ফাঁদ "অসঙ্গতি প্রমাণ শুরু হয় ধরে নিয়ে…" — উত্তর হলো প্রমাণযোগ্য বিবৃতির নেতিবাচকটি। "বিবৃতিটি সত্য" ধরে নেওয়া (সেটি বৃত্তাকার যুক্তি), "কনভার্স", বা "ভিত্তি ক্ষেত্র P(1)" — কোনোটিই নয়। আর শেষে যা আসে তা অবশ্যই অসম্ভব হতে হবে, অসম্ভাব্য নয়।
কখন অসঙ্গতি ভুল হাতিয়ার কোনো দাবি একটি মানে খারাপ হলে অসম্ভব অনুকল্প তৈরির দরকার নেই — বিপরীত উদাহরণ দেখিয়েই কাজ শেষ। আর অসীম বাস্তব সংখ্যা সম্পর্কিত দাবি ইন্ডাকশনে মেটে না: ইন্ডাকশন কেবল ℕ সম্পর্কিত উপপাদ্য।
উদাহরণ ✍ নেতিবাচকটি ঠিকভাবে লেখা "প্রতিটি বিজোড় সংখ্যা অমূলদ" — নেতিবাচক: "এমন একটি বিজোড় মূলদ সংখ্যা আছে"। অথবা "√2 এরূপ সংখ্যা নয়" — নেতিবাচক: "√2 একটি পূর্ণসংখ্যা"। লেখার সময় নেতিবাচকটি পূর্ণ করে লেখো; "√2 মূলদ নয়" লিখে থেমে গেলে পরীক্ষক তোমার ধাপটি আর দেখবেনই না।
পরীক্ষার ফাঁদ — ⊥-এর ধরন অসঙ্গতি যেন শক্তিশালী হওয়া দরকার। "এটা সম্ভবত মিথ্যা" বা "এটা অদ্ভুত" অসঙ্গতি নয়; প্রয়োজন কোনো বিবৃতি যা সত্য হওয়ার অসম্ভব, অথবা প্রতিষ্ঠিত সত্যের সঙ্গে সরাসরি সংঘর্ষ। যুক্তি যত দীর্ঘ হোক, শেষে ⊥ একটি কথায় লেখা থাকতে হবে।

Discrete Maths · গাণিতিক যুক্তি√2 ও আরও অসঙ্গতি

৬অসঙ্গতির প্রয়োগ

লেখার প্রিয় ★
উদাহরণ ✍ প্রমিত নমুনা: √2 অমূলদ
  1. ধরি, অসঙ্গতির জন্য, √2 মূলদ। তাহলে √2 = p/q, যেখানে p, q পূর্ণসংখ্যা, q ≠ 0 এবং সরলতম রূপে gcd(p, q) = 1।
  2. উভয় পক্ষ বর্গ করি: 2 = p²/q², অতএব p² = 2q²।
  3. p² জোড়, তাই p জোড় — বিজোড় p-এর বর্গও বিজোড় — লেখি p = 2k।
  4. বসিয়ে: (2k)² = 2q² ⇒ 4k² = 2q² ⇒ q² = 2k²।
  5. q² জোড়, তাই q জোড়।
  6. তাহলে 2, p ও q দুটোকেই বিভাজ্য করে, অতএব gcd(p, q) ≥ 2 — যা gcd(p, q) = 1-এর বিরুদ্ধে। ⊥
  7. অতএব অনুকল্প মিথ্যা এবং √2 অমূলদ। ∎
উদাহরণ ✍ চিরনামন অবতরণ (infinite descent) দাবি: ধনাত্বিক পূর্ণসংখ্যার ধারা চিরকাল নামতে পারে না। ধরি a₁ > a₂ > a₃ > …। সুশৃঙ্খলতা নীতি অনুযায়ী এই সেটের সর্বনিম্ন সদস্য am আছে, কিন্তু am+1 < am ও সেটেরই সদস্য — বিরোধ। অসঙ্গতি ⇒ প্রতিটি ধনাত্বিক পূর্ণসংখ্যার সংখ্যাগোষ্ঠীর সর্বনিম্ন সদস্য আছে। এটিই চিরনামন অবতরণ।
উদাহরণ ✍ একটি পরিবার ব্যর্থ দাবি: f(n) = n² + n + 41 প্রতিটি স্বাভাবিক n-এর জন্য মৌল। ধরি সব n-এর জন্য এটি মৌল। n = 41 নিই: f(41) = 1681 + 41 + 41 = 1763 = 41 × 43, যা মৌল নয়। একটিমাত্র বিপরীত উদাহরণই সাধারণ দাবি ভাঙে — তাই একটি খারাপ ক্ষেত্রই সবচেয়ে সহজ খণ্ডন। (n = 0 … 39 পর্যন্ত মৌল।)
পরীক্ষার ফাঁদ √2-এর প্রমাণে সরলতম রূপে থাকা gcd(p, q) = 1 অনুকল্পটিই শেষ অসঙ্গতিটিকে দাঁতড়া কোঁক; ছাড়া পা লাগলে যুক্তিটি বৃত্তাকার। আর "p² জোড় ⇒ p জোড়" একটি লেম্মা — বলা দরকার: p² = 2q² থেকে সরাসরি পাওয়া যায় কেবল যে p² জোড়, আর p জোড় হওয়া আসে "p বিজোড় হলে p² বিজোড়"-এর কন্ট্রাপজিটিভ থেকে।
কম্পিউটার বিজ্ঞানের সিলেবাসে অসঙ্গতি একই আকৃতিতেই প্রমাণ হয় যে কোনো মোট গণনযোগ্য ফলন halting সমস্যা নির্ণয় করতে পারে না — সিদ্ধান্তকারী D আছে ধরি, D-কে D-এরই জিজ্ঞেস করো, আর D নিজের সম্পর্কেই ভুল হয়। লেখায় অনুকল্পের নাম ও অসঙ্গতির জায়গা দুটোই দেখাতে হবে।
উদাহরণ ✍ সবচেয়ে বড় মৌল সংখ্যা নেই দাবি: মৌল সংখ্যার সীমা নেই। ধরি p₁, …, pm হলো সব মৌল সংখ্যার তালিকা এবং Q = p₁p₂ … pm। তাহলে N = Q + 1 কে কোনো pi ভাগ করতে পারে না, কারণ প্রতিটির ভাগশেষ 1। তাই N-এর মৌল উত্তাধক তালিকায় নেই — অসঙ্গতি।
পরীক্ষার ফাঁদ — পূর্ণ নেতিবাচক ধরো "প্রতিটি A একটি B" — এর নেতিবাচক হলো "এমন একটি A আছে যা B নয়" — "সব A B নয়" ছেড়ে দেওয়া নয়, "কোনো A C নয়" ও নয়। আংশিক নেতিবাচকের উপর চাপ দেওয়া অসঙ্গতি প্রমাণের শেষ নম্বর হারানোর সবচেয়ে সাধারণ কারণ।
উদাহরণ ✍ √3 এক লাইনে ধরি √3 = p/q সরলতম রূপে। তাহলে p² = 3q², তাই 3 | p², তাই 3 | p; লিখি p = 3k, পাওয়া 9k² = 3q², অতএব q² = 3k² এবং 3 | q। 3, p ও q দুটোকেই বিভাজ্য করে, তাই gcd ≥ 3 ≠ 1 — অসঙ্গতি; √3 অমূলদ। √2-এর হিসাবটাই সাধারণ নীতি।
সাধারণীকরণ: সব অমূলদ সংখ্যা √p (p অমূলিক) সবসময় অমূলদ। প্রমাপ্রতিটি সাধারণ পদক্ষেপ এক: √p = a/b সরলতম রূপে ধরি ⇒ p b² = a² ⇒ p | a² ⇒ p | a ⇒ a = p m ⇒ p b² = p² m² ⇒ b² = p m² ⇒ p | b, অতএব p, a ও b — তিনটোই বিভাজ্য, gcd(a, b) ≠ 1 বিরুদ্ধে। "p | a² ⇒ p | a" এই একটি লেম্মাই পুরো প্রমাণের ভিত্তি।

Discrete Maths · গাণিতিক যুক্তিকন্ট্রাপজিটিভ

৭অসঙ্গতি বনাম কন্ট্রাপজিটিভ

চিরন্দর পার্থক্য ★
সংজ্ঞা P → Q প্রমাণের জন্য কন্ট্রাপজিটিভ পদ্ধতিতে প্রমাণ করা হয় ¬Q → ¬P। যুক্তিটি আলাদা, ক্ষমতা সমান, কারণ P → Q ¬Q → ¬P-এর সঙ্গে যুক্তিগতভাবে সমতুল্য। অসঙ্গতি প্রমাণে ধরা হয় ¬(P → Q) = P ∧ ¬Q — অর্থাৎ অনুকল্প সত্য, সিদ্ধান্ত মিথ্যা একসঙ্গে — আর তা থেকে অসঙ্গতি আনা হয়। কনভার্স Q → P এবং ইনভার্স ¬P → ¬Q P → Q-এর সঙ্গে সমতুল্য নয়, তবে কনভার্স ও ইনভার্স পরস্পরের সমতুল্য।
রূপকী বলা হয়P → Q-এর সমতুল্য?P = "n জোড়", Q = "n² জোড়" উদাহরণ
P → Qবিবৃতিটিই—সত্য
¬Q → ¬Pকন্ট্রাপজিটিভসবসময় হ্যাঁ"n² বিজোড় ⇒ n বিজোড়" — সত্য
Q → Pকনভার্সনয়"n² জোড় ⇒ n জোড়" — মিথ্যা, n = 3
¬P → ¬Qইনভার্সনয় (তবে কনভার্স ≡ ইনভার্স)"n বিজোড় ⇒ n² বিজোড়" — সত্য, তবু সমতুল্য নয়
পরীক্ষার ফাঁদ যে দুটি ভুলে নম্বর যায়: (i) ¬Q → ¬P-কে "কনভার্স" বলা — এটি কন্ট্রাপজিটিভ; (ii) সত্য ইনভার্স দেখে ভাবা যে P → Q-ও সত্য। সমতুল্যতা সব ক্ষেত্রের বিষয়, একটির নয়।
আইটি সংযোগ — একই যন্ত্র, পরের অধ্যায়ে অসঙ্গতি একটি অসিদ্ধান্যতা ঠিক করে: halting problem অসিদ্ধান্য প্রমাণের জন্য ধরা হয় সিদ্ধান্তকারী D আছে এবং D-কে D-এর নিজের সম্পর্কে জিজ্ঞেস করা হয় — D নিজেকে থামবে না এমন মেশিনগুলোকেই গ্রহণ করতে হবে, যা অসঙ্গতি, তাই এমন D নেই। সাধারণ ইন্ডাকশন একটি উপপাদ্য ঠিক করে: n শীর্ষের গাছে ঠিক n − 1 প্রান্ত থাকে — n-এর উপর ইন্ডাকশন, পাতা-লেম্মা ব্যবহার করে। একটি পদ্ধতি কিছুর অস্তিত্ব প্রমাণ করে, অন্যটি প্রমাণ করে কিছুই অসম্ভব।
উদাহরণ ✍ কাজে লাগছে কন্ট্রাপজিটিভ প্রমাণ করো: n² 4 দ্বারা বিভাজ্য হলে n জোড়। কন্ট্রাপজিটিভ: ধরি n² 4 দ্বারা বিভাজ্য নয়; তাহলে n বিজোড়, n = 2k+1, তাই n² = 4k² + 4k + 1, যা 4-এর একটি বহুগুণের চেয়ে 1 বেশি — অতএব বিভাজ্য নয়। অসম্ভব অবশিষ্টাংশ 1-ই ⊥।
চার রূপ, এক লাইনে P → Q দাবি · ¬Q → ¬P কন্ট্রাপজিটিভ, সবসময় সমতুল্য · Q → P কনভার্স, মিথ্যা হতে পারে · ¬P → ¬Q ইনভার্স, মিথ্যা হতে পারে তবে কনভার্সের সমান। সমতুল্যতার পরীক্ষা: দুই পাশে একটি মান বদলে দেখাও যে পার্থক্য হয়।
উদাহরণ ✍ সমতুল্যতা যাচাই দাবি: "n² জোড় হলে n জোড়" — এখানে P = "n² জোড়", Q = "n জোড়"। কনভার্সটি হলো "n জোড় হলে n² জোড়", যা n = 2-এ সত্য; কিন্তু মূল দাবিটি n = 3-এ মিথ্যা। একটি মানেই বিষয়টি ফিরে গেছে, তাই মূল দাবি ও কনভার্স সমতুল্য নয় — অথচ ইনভার্স ("n বিজোড় হলে n² বিজোড়") সত্য হওয়া সত্ত্বেও কিছু বদলায় না।
পরীক্ষার ফাঁদ "কনভার্স সত্য হলে কন্ট্রাপজিটিভও সত্য" — এটি ভুল। কনভার্স সত্য হওয়া নিজে থেকে সমতুল্যতা বোঝায় না; দুটি ভিন্ন বিবৃতি দুটি ভিন্ন মানে সত্য হতে পারে (n বিজোড় হলে n² বিজোড়)। সমতুল্যতার একমাত্র পরীক্ষা হলো প্রতিটি মানে দুটির সত্যতা মিলিয়ে দেখা।

সংজ্ঞা একটি পুনরাবৃত্তি সংজ্ঞা কোনো বস্তুকে নিজের ছোট উদাহরণের মাধ্যমে সংজ্ঞায়িত করে; ধারার জন্য একে পুনরাবৃত্ত সমীকরণ বলে। প্রতিটি পুনরাবৃত্তি সংজ্ঞায় ঠিক দুটি অংশ থাকে: যেখানে পুনরাবৃত্তি থামে সেখানে ভিত্তি ক্ষেত্র, আর এমন একটি পুনরাবৃত্তি ধাপ যার যুক্তি কঠিনভাবে ভিত্তির দিকে কাছাকাছি। যে ফাংশন নিজেকে এমন যুক্তিতে কল করে যা কমে না, তা পুনরাবৃত্তি নয় — তা অসীম লুপ, যা স্ট্যাক উপচে ফেলে।

ফিবোনাচ্চির সূচক একই ধারা F(0) = 0, F(1) = 1 অথবা F(1) = 1, F(2) = 1 — এক সূচকে পার্থক্য। MCQ-তে উত্তর দেওয়ার আগে দেখো কোন রীতি ব্যবহার করা হয়েছে; "F(1) = 1, F(2) = 1" বলা প্রশ্নে 7ম পদের মান জিজ্ঞেস করা হয়, তাই উত্তর 13, 8 নয়।
"ছোট" হওয়াই পুরো শর্ত সমাপ্তির কথা একটি সুপ্রতিষ্ঠিত পরিমাপের উপর দাঁড়ায়: কোনো পরিমাপ — যুক্তি n, তালিকার দৈর্ঘ্য, গাছের গভীরতা — প্রতিটি কলে কঠিনভাবে কমতে হবে এবং তার একটি নিম্ন সীমা থাকতে হবে। ℕ-এর তেমন সীমা নেই, তাই বারবার কমতে থাকলে 0 বা 1-এ পৌঁছতেই হবে। তাই ফ্যাক্টরিয়ালের ধাপ n − 1 ব্যবহার করে, n + 1 নয়।
পরীক্ষার ফাঁদ — স্ট্যাক গভীরতা "factorial(5) 5-টি কল করে" — সংখ্যায় 5 বলা ভুল; প্রথম কলসহ মোট 6টি কল (5!, 4!, …, 0!)। একইভাবে fib(0) এক কল, fib(1) এক কল। যেকোনো "কতবার কল হয়" প্রশ্নে প্রথম কলটি গোনা হয় কি না, আগে ঠিক করে নাও।
রিকার্শন বনাম পুনরাবৃত্ত সমীকরণ — পরীক্ষায় এই পার্থক্যই আসে পুনরাবৃত্ত সমীকরণ বলতে বোঝায় a(n) = a(n−1) + a(n−2) ধরনের লিখিত সম্পর্ক, যেখানে a(0), a(1) প্রদত্ত। এর থেকে বন্ধ রূপ বের করা হয় (characteristic equation r² − 5r + 6 = 0 → r = 2, 3 ধরে a(n) = A·2ⁿ + B·3ⁿ)। পুনরাবৃত্তিমূলক অ্যালগরিদম হলো সেই ফাংশন যা কম্পিউটারে নিজেকে কল করে। দুটি ভিন্ন জিনিস, তবে প্রতিরঙ্গী প্রশ্নে দুটোই আসে।

তিনটি এক লাইনে ইন্ডাকশন — "একবার সত্য, আর k-তে সত্য হলে k+1-এ সত্য", তাই সত্যতা পুরো ℕ-এ ছড়িয়ে পড়ে। অসঙ্গতি — "মিথ্যা হলে অসম্ভবতা আসত", তাই মিথ্যা হতে পারে না। রিকার্শন — "ছোটগুলো থেকে সংজ্ঞায়িত করো", যা ইন্ডাকশন প্রমাণটি তারপর যাচাই করে। ইন্ডাকশন আর রিকার্শন একই বস্তুর দুই অর্ধেক।
প্রয়োগ — সিলেবাসের চারটি নাম অ্যালগরিদম সঠিকতার প্রমাণ (লুপ কাউন্টার বা রিকার্শনের গভীরতার উপর ইন্ডাকশন) · জটিলতা বিশ্লেষণ (পুনরাবৃত্ত সমীকরণ সমাধান করে) · প্রোগ্রাম যাচাই (পূর্বশর্ত, উত্তরশর্ত ও ইনডাকশনে প্রমাণিত invariant) · গাণিতিক উপপাদ্য প্রমাণ (আনুষ্ঠানিক ব্যবস্থায় উপপাদ্য প্রমাণযোগ্য তখনই, যখন তা আক্সিওম থেকে আগের লেসনের অনুমান-নিয়মে বের হয়)।
পরীক্ষার ফাঁদ তিনটি একই বিষয়ের তিন রূপ নয়: ইন্ডাকশন ও অসঙ্গতি প্রমাণ-পদ্ধতি — এরা সত্যতা নিয়ে যুক্তি করে — আর রিকার্শন একটি সংজ্ঞা ও গণনার কৌশল। "রিকার্শন দিয়ে প্রমাণ" বলার অর্থ কেবল "পুনরাবৃত্তিমূলক প্রোগ্রামের সঠিকতা প্রমাণ", আর সেই প্রমাণটি ইন্ডাকশন। সহজ বিপরীত উদাহরণ থাকা দাবি অসঙ্গতি দিয়ে প্রমাণ করা হয় না; সেটি খণ্ডন করা হয়।
উদাহরণ ✍ তিনটিকে একটি প্রশ্নে চেনা "প্রতিটি গাছে n শীর্ষবিন্দু থাকলে n − 1 প্রান্ত থাকে" — এটি ইন্ডাকশন, কারণ "সব" শব্দটা আছে। "halting problem অসিদ্ধান্য" — এটি অসঙ্গতি, কারণ কোনো অ্যালগরিদমই নেই। "F(n) = F(n−1) + F(n−2)" — এটি রিকার্শনের সংজ্ঞা, কোনো দাবিই নয়; এর সঠিকতা প্রমাণ করতে গেলে ইন্ডাকশন লাগবে।
মনে রাখার কৌশল — এক বাক্যে সিদ্ধান্ত "অস্তিত্ব চাওয়া হয় ও তুমি কিছু নেই বলবে, ধরি — অসঙ্গতি। সব শব্দ থাকলে ইন্ডাকশন। "যদি…তবে" থাকলে কন্ট্রাপজিটিভ। "সংজ্ঞায়িত করো" বা "যেভাবে গোনা হয়" থাকলে রিকার্শন। প্রশ্নের শেষ বাক্যটি পড়েই পদ্ধতি ঠিক করা যায়।
তিনটির একটি সাধারণ ভিত্তি তিনটিই একটি সুশৃঙ্খল স্বীকৃতি নিয়ে চলে: আরোহ ধরে নেয় স্বাভাবিক সংখ্যার কোনো মান কমতে পারে না, তাই ক্রমবর্ধমান অনুক্রমে থেমে যেতে হবে; অসঙ্গতি ধরে নেয় একইসঙ্গে সত্য ও মিথ্যা অবস্থা অসম্ভব; রিকার্শন ধরে নেয় নিজের ছোট উদাহরণে নামতে হবে। তিনটিই তাই "সমাপ্তির পরিমাপ" — অসীম পশ্চাৎপাবলন থেকে বাঁচার কৌশল।
