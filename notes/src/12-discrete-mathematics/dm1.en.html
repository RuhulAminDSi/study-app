1What Is a Set?

definition ★
Definition A set is a well-defined collection of distinct objects, its elements or members. "Well-defined" means we can decide unambiguously yes or no whether an object belongs. The objects may be numbers, letters, points, or even other sets.
FormIt does whatExample
Roster (tabular)lists every element one by oneA = {2, 4, 6, 8}
Set-builderstates the property the elements shareA = {x | x even, x < 10}
Order and repetition are irrelevant {1, 2, 3} = {3, 2, 1} = {1, 1, 2, 2}  ·  but (1, 2) ≠ (2, 1) — ordered pairs do care
|A| is read "the cardinality of A": |{a, b}| = 2.
Exam trap {even numbers} is not a set — it is not well defined until you say which evens. That clause is the whole definition and it is asked often.
Memory trick A set is a basket with a label: the label decides who is in, and the order of picking never changes the contents.

Power set P(A) = { X | X ⊆ A } — the set of all subsets of A. Then |P(A)| = 2^|A| and, for every finite A, |P(A)| > |A| (Cantor). Edge cases: |P(∅)| = 1 and P({a}) = { ∅, {a} }, so P(A) itself is a set and P(P(A)) exists too.
Memory trick ⊆ is "all in", ⊂ is "all in and more outside". Every set is a subset of itself (A ⊆ A) and ∅ is a subset of every set (∅ ⊆ A): ∅ is the smallest subset, U the largest.
Worked example ✍ subsets of A = {1, 2, 3, 4} total 16 · exactly 2 elements → 6 · exactly 3 → 4 · proper → 15 · proper and non-empty → 14. Since |P(A)| = 16 > 4, A ⊂ P(A) strictly, and the largest subset is A itself.
Exam trap (i) ∅ ⊂ {x} holds, but {x} ⊂ ∅ is false — ∅ has no elements to miss. (ii) The empty set is not equal to {0} or {∅}. (iii) "Subset" never means "proper subset" in ordinary exam wording.
IT link The power set is not an exam abstraction: an n-bit flag word has exactly 2ⁿ settings, and asking "which of these 32 permissions is on?" is a power-set question in disguise. One bit per permission, every combination legal, nothing missing. The same count gives the number of subsets a table can filter on, which is why a query with n boolean predicates has at most 2ⁿ distinct result shapes.

Worked example ✍ simplify with the laws (A ∪ B)′ = A′ ∩ B′ by De Morgan, and ((A ∪ B)′)′ = A′ ∩ B′ returns to A ∪ B by involution. Also A − B = A ∩ B′, so {1,2,3} − {2,3} = {1,2,3} ∩ {1} = {1}. De Morgan · involution · difference in terms of intersection and complement

5A Relation Is a Subset of A × B

definition ★
Definition Let A and B be two sets. A relation R from A to B is any subset of A × B, written R ⊆ A × B. Its elements are ordered pairs (a, b) with a ∈ A, b ∈ B, read "a is related to b". If R ⊆ A × A it is a binary relation on A; that is the case whenever both sets are the same.
The two counting results |A × B| = |A| · |B| — the pairs form a full grid, m rows by n columns.
Relations A→B = 2^(|A|·|B|), because a relation is any subset and a set of m·n elements has 2^(m·n) subsets.
On a single set with n elements: |A × A| = n², so 2^(n²) binary relations.
Worked example ✍ the counts that always appear (a) |A| = 3: |A × A| = 9, so 2⁹ = 512 relations on A. (b) |A| = 3, |B| = 4: |A × B| = 12, so 2¹² = 4096 relations A→B. (c) |A| = 4: 2¹⁶ = 65 536. The count explodes because the exponent is n², not n.
Exam trap Not every relation is a function. A relation may contain (1, x) and (1, y) for the same first element; a function may leave part of the codomain untouched. And R ⊆ A × B does not mean R = A × B — the universal relation is only one of the 2^(m·n) choices.
IT link A database join condition is a relation between two tables, and a foreign key declares one.

Three ways to write the same relation

  1. Set of ordered pairs — R = {(1, x), (2, y)}
  2. Matrix MR = [mij], rows = A, columns = B, mij = 1 if (ai, bj) ∈ R, else 0
  1. Digraph — one vertex per element of A and one per element of B, with a directed edge ai → bj for every pair in R. For a relation on A there is a single vertex set, and (a, a) is drawn as a self-loop

6The Six Properties, with a Counter-example for Each

most tested ★
PropertyExact statement (on a set A)Counter-example on A = {1, 2, 3}
Reflexive(a, a) ∈ R for every a ∈ AR = {(1,2),(2,3)} — (3,3) is missing
Not reflexive (irreflexive)(a, a) ∉ R for every a ∈ AR = {(1,1)} on {1,2,3} — (2,2) is present
Symmetric(a, b) ∈ R ⇒ (b, a) ∈ RR = {(1,2),(1,1)} — (2,1) is missing
Antisymmetric(a, b) ∈ R and (b, a) ∈ R ⇒ a = bR = {(1,2),(2,1)} — both ways, yet 1 ≠ 2
Transitive(a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ RR = {(1,2),(2,3)} — forces (1,3), missing
Asymmetric(a, b) ∈ R and a ≠ b ⇒ (b, a) ∉ RR = {(1,2),(2,1)} — symmetry holds instead
The distinction that loses marks Symmetric and antisymmetric are not opposites and neither implies the other. R = {(1,2),(2,1)} fails antisymmetry but is symmetric. R = {(1,2)} is antisymmetric yet not symmetric. Only "asymmetric" is the true opposite of "symmetric".
Memory trick Symmetric = the arrow reverses; antisymmetric = at most one arrow per unordered pair. Two more worth memorising: ∅ on a non-empty A is symmetric, antisymmetric and transitive but not reflexive, while A × A is reflexive, symmetric and transitive but not antisymmetric. The identity relation {(a,a)} is the only one that passes all four.
Worked example ✍ matrix form For R = {(1,x), (2,y)} with rows 1,2,3 and columns x,y: MR = [[1,0],[0,1],[0,0]]. On a relation on A rows and columns are the same list, so the diagonal is the reflexivity test.

7Equivalence Relations and Partial Orders

written favourite ★
Equivalence relation reflexive + symmetric + transitive, nothing more. Its classes [a] = { x ∈ A | (a, x) ∈ R } are non-empty, pairwise disjoint, and their union is A. Equivalence relation ↔ partition, one-to-one.
Worked example ✍ R = {(1,1),(2,2),(3,3),(1,2),(2,1)} on {1,2,3} Reflexive: three loops present. Symmetric: (1,2) and (2,1) both present. Transitive: (1,2),(2,1) forces (1,1) ✓ and (2,1),(1,2) forces (2,2) ✓. So R is an equivalence relation with classes {1, 2} and {3} — and it is not a partial order, since (1,2) and (2,1) with 1 ≠ 2 break antisymmetry.
Equivalence relations on a small set = Bell numbers They correspond one-to-one to the partitions, so the count is Bn: B₁ = 1 · B₂ = 2 · B₃ = 5 · B₄ = 15 · B₅ = 52. A 4-element set gives 15 = 1 (one block) + 7 (two) + 6 (three) + 1 (four).
Partial order (poset) reflexive + antisymmetric + transitive. Add "every two elements are comparable" and you get a total order. The Hasse diagram drops the loops and keeps only the covering arrows upward.
Worked example ✍ congruence mod 3 on ℤ a R b iff 3 divides (a − b). Reflexive: a − a = 0 = 3·0. Symmetric: a − b = 3m ⇒ b − a = 3(−m). Transitive: 3m + 3k = 3(m + k). Classes [0] = {…, −6, 0, 3, 6, …}, [1] = {…, −2, 1, 4, 7, …}, [2] = {…, −1, 2, 5, 8, …} — disjoint, union ℤ.
Memory trick Both are named for what they do: Equivalence lumps equal-looking things into classes; a partial order gives Partial Ordering, where some things are ranked and others are not comparable. ⊆ on P(A) is always a partial order — the standard example.
Exam trap A relation is both an equivalence relation and a partial order only when every class is a singleton, i.e. R is the identity relation. And "not symmetric" does not make a relation antisymmetric — antisymmetry is a separate test, not a negation.

8Functions: Domain, Codomain, Range

definition ★
Definition A function f: A → B is a relation from A to B in which every element of A appears exactly once as the first component of a pair. Equivalently, (a₁, b₁), (a₂, b₂) ∈ R with a₁ = a₂ force b₁ = b₂. Nothing is said about how often an element of B is hit.
NameIt isIn code
Domainthe whole set A the function is declared onevery x that must be handled
Codomainthe declared target set Bthe set the signature promises
Range / imagef(A) = { f(a) | a ∈ A } ⊆ B — only the values actually takenthe values you can really observe
Constant functionone fixed value for every input; the range is a singletonthe same constant returned always
Total / partialtotal = every domain element has an image; partial may notno null

Injective, surjective, bijective

NameTestPlain words
Injective
one-to-one		f(a₁) = f(a₂) ⇒ a₁ = a₂no two inputs share an output
Surjective
onto		∀ b ∈ B ∃ a ∈ A : f(a) = bno output is left unused
Bijectiveboth of the abovea perfect pairing
The counting facts for finite sets |A| ≤ |B| is necessary for an injective A→B
|A| ≥ |B| is necessary for a surjective A→B
A bijection needs |A| = |B|, and then range = codomain. So if |A| > |B| a function still exists but it cannot be injective; if |A| < |B| it cannot be surjective.
Exam trap Injective and surjective are independent. f: {1,2,3} → {x,y} must be onto but can never be one-to-one. A constant function is onto only when |B| = 1, and one-to-one only when |A| = 1.

9Composition, Inverse, Identity — and Counting Functions

high-yield ★
Composition Let g: A → B and f: B → C. Then (f ∘ g)(x) = f(g(x)), a function A → C. Read right to left: g acts first, f afterwards. The domain of f ∘ g is the domain of g. Composition is associative but not commutative.
Inverse and identity The identity map IA(x) = x changes nothing. f: A → B is invertible ⇔ bijective; then f⁻¹: B → A exists and f⁻¹ ∘ f = IA and f ∘ f⁻¹ = IB. Formally f⁻¹(y) = x whenever f(x) = y.
Counting functions A → B with |A| = m, |B| = n

All functions: nm

Injective: n(n−1)···(n−m+1) = n!/(n−m)!

Surjective: n! · S(m, n), S = Stirling

Bijections: n! (only when m = n)

Worked example ✍ |A| = 3, |B| = 4 Each of the 3 inputs picks any of 4 outputs independently → 4³ = 64 functions. (24 = 4·3·2 counts only the injective ones; 81 = 3⁴ would be functions B → A.) Surjective: 0, because 3 inputs cannot cover 4 outputs. Bijections: 0.
Worked example ✍ inverse and composition f(x) = 2x + 3. Let y = 2x + 3 ⇒ x = (y − 3)/2, so f⁻¹(x) = (x − 3)/2, and f((x − 3)/2) = x checks it out. Note 1/(2x + 3) is the reciprocal, never the inverse. For f(x) = 2x + 1 and g(x) = x²: (f ∘ g)(x) = 2x² + 1 but (g ∘ f)(x) = (2x + 1)² — not equal.
Memory trick ∘ is a "then" sign: f ∘ g means "f after g", exactly as the brackets f(g(x)) say. The types forbid f ∘ g unless the codomain of g fits the domain of f.
Exam trap (i) (f ∘ g)(x) is f(g(x)), not g(f(x)) — check with a concrete x. (ii) Composition of bijections is bijective and injective ∘ injective is injective, but the mixed cases are not guaranteed. (iii) A relation has an inverse function only if it is a bijection, not merely injective.

Written question On the integers ℤ define a R b iff 3 divides (a − b). Prove R is an equivalence relation, list its classes, then give on A = {1, 2, 3} a relation that is reflexive and symmetric but not transitive. 8 marks
  1. Reflexive — a − a = 0 = 3·0, so 3 divides a − a and a R a. 2
  2. Symmetric — if a − b = 3m then b − a = 3(−m), and −m is an integer, so b R a. 2
  3. Transitive — a − b = 3m and b − c = 3k give a − c = 3(m + k), so a R c; hence R is an equivalence relation. 2
  4. Classes by remainder on division by 3: [0] = {…, 0, 3, 6, …}, [1] = {…, 1, 4, 7, …}, [2] = {…, 2, 5, 8, …} (all negatives included) — disjoint, union ℤ. 2
Counter-example On {1,2,3} take R = {(1,1),(2,2),(3,3),(1,2),(2,1)}. Reflexive and symmetric, but not transitive: (1,2) and (2,3) would force (1,3), which is absent.
