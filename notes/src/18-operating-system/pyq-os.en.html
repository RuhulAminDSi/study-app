2Virtual memory and page faults

5 exams
Q3 What do you mean by virtual memory? Why is it needed? Difference between physical and virtual memory, with its advantages and disadvantages.BPSC AME 2021 · BPSC AP 2021 (need) · Combined Bank AME/AHE 2023 · Kernel, cache, VM and RAID: SPCBL AME 2021

Virtual memory gives each process a large, private logical address space; only the pages in use sit in RAM, the rest stay on disk and are loaded on demand (demand paging). Needed because programs are bigger than RAM, many programs run at once, and each needs protection from the others.

Physical memoryVirtual memory
real RAM chipsRAM + disk (swap) as one space
size = installed RAMsize = address width (2³² = 4 GB)
fast (ns)a miss costs a disk access (ms)
addressed directlyMMU translates every address

Advantages: run programs larger than RAM · more processes at once · isolation and protection · easy sharing of libraries.

Disadvantages: slower on page faults · disk space used · page tables cost memory · thrashing if RAM is too small.

Q4 What is a page fault in computing systems? When does it occur?BCIC AP 2022 · "when does a page fault occur": NTRCA question bank
  1. CPU issues an address; the MMU finds the page's valid bit = 0 → trap to the OS
  2. OS checks the reference is legal (else: segmentation fault, kill)
  3. finds a free frame, or chooses a victim by a replacement algorithm (writes it back if dirty)
  4. reads the page from disk into the frame; updates the page table (valid = 1)
  5. restarts the instruction that faulted
Q5 Define paging and thrashing in the context of OS.BPSC AP 2023 (printed "trashing") · MCQ "thrashing occurs when": BCS MCQ sheet, paper not shown

Paging: memory divided into fixed-size frames, a process into equal pages; any page can go in any frame, so no external fragmentation. Thrashing: so little RAM per process that it spends more time swapping pages than executing; CPU use collapses. Cure: lower the degree of multiprogramming, working-set model, page-fault-frequency control, more RAM.

Q7 Explain the LRU and NRU page-replacement algorithms.Combined Bank AME/AE(IT) 2024 · LRU with an example: NTRCA question bank · GUI, RAID, API, LRU table: BPDB AE(CSE) 2023
LRU (Least Recently Used) Evict the page not used for the longest time; uses the past to predict the future. Implemented by a counter/timestamp per page or a stack of page numbers; costly in hardware, so real systems use approximations (clock / second chance). No Belady's anomaly.
NRU (Not Recently Used) Each page has R (referenced) and M (modified) bits; R is cleared on every clock tick. Pages fall into 4 classes; evict a random page from the lowest class.
ClassRMMeaningEvict?

Exam trap FIFO can show Belady's anomaly (more frames → more faults, e.g. 1 2 3 4 1 2 5 1 2 3 4 5: 9 faults with 3 frames, 10 with 4). LRU and Optimal never do. Optimal (evict the page used farthest in the future) is the lower bound but needs the future.

Q17 What is a process? Describe the process states, with the process state transition diagram.17th NTRCA ICT 2023 · 18th NTRCA College ICT 2024 · EGCB SAE(ICT) 2023 · BPSC AP 2021 (diagram) · program vs process: NTRCA question bank

A process is a program in execution: code + program counter + registers + stack + data + heap + OS bookkeeping (PCB). A program is passive (a file on disk); a process is active, and one program can run as many processes.

StateWhat the process is doing

Q18 What is a PCB? Write the information it keeps about a process (four items).17th NTRCA ICT 2023 · RPGCL AM(ICT) 2022 · four process attributes kept for a thread: BPSC AME 2021
  • Process ID (PID), parent ID
  • Process state
  • Program counter + CPU registers
  • CPU-scheduling info (priority, queue pointers)
  • Memory info (page / segment table, limits)
  • Accounting (CPU time used) and I/O status (open files, devices)
PCB The Process Control Block is the kernel's record of one process; the OS saves the CPU state into it at each switch. For a thread the kernel keeps a smaller TCB: thread ID, PC, registers, stack pointer, state, priority.
Q19 Explain context switching in an operating system.MGMCL AM(ICT) 2022 · BIWTA AE(CSE) 2023 · Combined Bank AME/AE(IT) 2024

Context switch: the CPU moves from process A to B. Steps: interrupt or system call → save A's PC and registers in PCB-A → update A's state → scheduler picks B → load B's state from PCB-B → resume B. It is pure overhead (no useful work), so a very small RR quantum wastes CPU time.

12Deadlock and its four conditions

14 exams ✦ most asked
Q24 What is deadlock in an OS? What are the four necessary conditions behind it? Draw a diagram of a deadlock situation.BPSC AP 2023 · Milk Vita AM(CSE) 2023 · BTCL JAM 2024 · BPSC AP 2022 · 45th BCS CSE 2024 (diagram) · NTRCA question bank

Deadlock: a set of processes in which each waits for a resource held by another in the set, so none can ever proceed. All four Coffman conditions must hold at once:

  1. Mutual exclusion: a resource is held by one process at a time
  2. Hold and wait: a process holds one resource while waiting for another
  3. No preemption: a resource is released only voluntarily
  4. Circular wait: P1 → P2 → … → Pn → P1, each waiting for the next
Memory trick "My Hungry Neighbour Cries": Mutual exclusion, Hold and wait, No preemption, Circular wait. Break any one → no deadlock.
Q25 Can a deadlock involve only a single process? Explain.Combined Bank Officer(IT) 2024Not by the definition: circular wait needs ≥ 2 processes. In practice one thread can block itself forever by locking a non-recursive mutex it already holds ("self-deadlock"), but that is a bug, not the four-condition deadlock.
Q26 Explain circular-wait deadlock.Titas Gas AE(CSE) 2024P1 holds R1 and wants R2, P2 holds R2 and wants R1: the waits form a cycle. Prevent it by resource ordering: number all resources and request them only in increasing order, so a cycle cannot form.
Q27 Resources A and B; processes P1, P2. A free resource is allocated at once, otherwise the requester halts. Sequence: P1 requests A, P2 requests B, P1 requests B, P2 requests A. (i) A is allocated to? (ii) B is allocated to? (iii) Name the situation.DPDC JAM(ICT) 2020

→ (i) A → P1 · (ii) B → P2 · (iii) P1 halts waiting for B, P2 halts waiting for A: deadlock (circular wait)

OS · Solved Past QuestionsDeadlock II: not sufficient, handling, Banker's
Q28 Show by example that mutual exclusion, hold and wait, no preemption and circular wait are not sufficient for a deadlock.DPDC AM(ICT) 2025

R1 and R2 have 2 instances each. Cycle P1 → R1 → P3 → R2 → P1 exists, so all four conditions hold. But P2 holds the other R1 and P4 the other R2, and they wait for nothing: when P2 finishes, R1 goes to P1, and the cycle breaks. No deadlock. With single-instance resources a cycle is a deadlock; with several instances it is necessary but not sufficient.

Q31 A system has P processes, each needing at most m resources, and r resources in total. What condition makes it deadlock-free?BPSC AP 2023

Worst case: every process holds m − 1 and waits for one more. If even then one resource is left over, some process can finish and release all it holds: P(m − 1) + 1 ≤ r. Example: 3 processes need 3 each → 3 × 2 + 1 = 7 resources needed.

Q34 Define FCFS, SJF and RR (quantum = 20).NU AP 2020 (also: turnaround of FCFS and SJF)

FCFS: serve in arrival order (a queue); long first job → convoy effect. SJF: run the shortest next burst; minimum average waiting time, but bursts must be predicted. RR: each process gets at most q = 20 ms, then goes to the back of the queue; q large → FCFS, q tiny → all switching.

Q35 Explain starvation in SJF scheduling and name a starvation-free algorithm.RPGCL AM(ICT) 2022 (printed unclearly)

If short jobs keep arriving, a long job is postponed indefinitely (starvation). Cure: aging, raising priority with waiting time. Round Robin (and FCFS) are starvation-free: every process gets the CPU within (n − 1)q.

Q39 What is an operating system? Why do we need it? What is its relationship with the hardware? Main components and functions.38th BCS 2018 · BCC Programmer 2019 · ICT Ministry AP 2017 · DOS, functions and types: 18th NTRCA School 2024

An operating system is system software that manages hardware and provides services to programs, and an interface to users (Windows, Linux, Android). Relationship: hardware gives raw resources; the OS is the only layer that drives them directly (drivers, interrupts) and offers them to programs through system calls, so applications never touch the hardware.

Functions / components: process management · memory management · file management · I/O and device management · secondary-storage management · security and protection · networking · user interface (CLI / GUI).

DOS (MS-DOS): single-user, single-task, command-line OS. Types: batch · multiprogramming · time-sharing · multiprocessing · distributed · network · real-time · mobile · embedded.

RAID (Redundant Array of Independent / Inexpensive Disks) combines several disks into one logical unit for speed (striping), fault tolerance (mirroring / parity) or both. Servers need it because a disk failure must not stop the service or lose data, and many disks in parallel give more I/O.
