১লজিক গেট কী?

MCQ + লিখিত
সংজ্ঞা লজিক গেট হলো এমন একটি ইলেকট্রনিক সার্কিট, যা এক বা একাধিক বাইনারি ইনপুট নিয়ে একটি নির্দিষ্ট বুলিয়ান ফাংশন অনুযায়ী একটি বাইনারি আউটপুট দেয়। ALU, মেমরি, CPU কন্ট্রোল: সব ডিজিটাল সিস্টেমের মূল একক এই গেট।
গেট = ট্রানজিস্টরে তৈরি বুলিয়ান অপারেটর
বুলিয়ান অপারেশনচিহ্নগেটআউটপুট 1 হয় যখন …
যৌক্তিক গুণA·BANDসব ইনপুট 1
যৌক্তিক যোগA+BORঅন্তত একটি ইনপুট 1
পূরক (complement)A′NOTইনপুট 0
গণনার নিয়ম
n টি ইনপুট → সত্যক সারণিতে 2ⁿ টি সারি
n টি চলক → 2^(2ⁿ) টি ভিন্ন বুলিয়ান ফাংশন
(n = 2 → ৪টি সারি, ১৬টি ফাংশন)
মনে রাখার কৌশল ইনপুট কলাম বাইনারিতে গুনে লেখো: 00, 01, 10, 11। কোনো সারি বাদ পড়বে না।

২লজিক লেভেল: পজিটিভ বনাম নেগেটিভ লজিক

গেট আসলে 0 বা 1 "দেখে" না; দেখে ভোল্টেজের পরিসর।

  • পজিটিভ লজিক: HIGH = 1, LOW = 0 (সাধারণ নিয়ম)
  • নেগেটিভ লজিক: HIGH = 0, LOW = 1

একই সার্কিট, ভিন্ন লেবেল → ভিন্ন ফাংশন।

TTL (5 V) লেভেলইনপুটআউটপুট
LOW (0)VIL ≤ 0.8 VVOL ≤ 0.4 V
HIGH (1)VIH ≥ 2.0 VVOH ≥ 2.4 V

নয়েজ মার্জিন (noise margin) = 2.4 − 2.0 = 0.8 − 0.4 = 0.4 V। CMOS-এর সীমা সাপ্লাই ভোল্টেজের সাথে বদলায় (মোটামুটি VDD-এর ৩০% / ৭০%)।

পরীক্ষার ফাঁদ পজিটিভ লজিকের AND গেট নেগেটিভ লজিকে OR হিসেবে কাজ করে; পজিটিভ NAND = নেগেটিভ NOR (ছদ্মবেশে ডি মরগান)।

বহু-ইনপুট গেট

  • n-ইনপুট AND: শুধু 11…1 হলে 1 (2ⁿ টি সারির একটি)
  • n-ইনপুট OR: শুধু 00…0 হলে 0
  • AND ও OR সহযোজী (associative): (A·B)·C = A·(B·C), তাই ২-ইনপুট গেট পরপর জোড়া যায়
গেটিং (enable / inhibit)
AND: কন্ট্রোল 1 → ডেটা পার হয়, 0 → আউটপুট 0
OR: কন্ট্রোল 0 → ডেটা পার হয়, 1 → আউটপুট 1
XOR: কন্ট্রোল 1 → ডেটা উল্টে যায়
মনে রাখার কৌশল AND = "সবাই", OR = "যেকেউ"। AND একটি 0 পেলেই আউটপুট 0 করে দেয়; OR একটি 1 পেলেই আউটপুট 1।

৪NAND, NOR, XOR, XNOR

হাই-ইল্ড
NAND = NOT + AND

Y = (AB)′ · শুধু সব ইনপুট 1 হলে আউটপুট 0

NOR = NOT + OR

Y = (A+B)′ · শুধু সব ইনপুট 0 হলে আউটপুট 1

XOR (এক্সক্লুসিভ-OR)

A⊕B = A′B + AB′ · ইনপুট ভিন্ন হলে 1

XNOR (সমতা গেট)

A⊙B = AB + A′B′ · ইনপুট সমান হলে 1

XOR-এর ধর্ম

A ⊕ 0 = A (অপরিবর্তিত)

A ⊕ 1 = A′ (উল্টে যায়)

বিনিময় ও সহযোজী নিয়ম মেনে চলে

(A ⊕ B)′ = A′ ⊕ B = A ⊕ B′

n-ইনপুট XOR = 1 যখন 1-এর সংখ্যা বিজোড় → বিজোড় প্যারিটি ফাংশন; ব্যবহার: প্যারিটি জেনারেটর/চেকার, তুলনাকারী (comparator), অ্যাডার, নিয়ন্ত্রিত ইনভার্টার।

পরীক্ষার ফাঁদ NAND ও NOR সহযোজী নয়: (A NAND B) NAND C ≠ A NAND (B NAND C)। ৩-ইনপুট NAND মানে (ABC)′, দুটি ২-ইনপুট NAND পরপর বসানো নয়।
মনে রাখার কৌশল নামের শুরুতে "N" = আউটপুটে বাবল = সেই গেটের কলাম উল্টে দাও। XOR = "ভিন্ন হলে 1", XNOR = "একই হলে 1"।

৫সর্বজনীন গেট (Universal Gate): NAND ও NOR

সংজ্ঞা যে গেট দিয়ে একাই NOT, AND ও OR (অর্থাৎ যেকোনো বুলিয়ান ফাংশন) তৈরি করা যায়, তাকে সর্বজনীন গেট বলে। NAND ও NOR সর্বজনীন; AND, OR, XOR সর্বজনীন নয়।

শুধু NAND দিয়ে

শুধু NOR দিয়ে (আয়নার প্রতিচ্ছবি): NOR(A, A) = A′ (১টি) · NOR-এর পর NOR-ইনভার্টার = OR (২টি) · দুই ইনপুট উল্টে তারপর NOR: (A′ + B′)′ = AND (৩টি)।

NAND আর NOR-এ AND/OR ও XOR/XNOR-এর সংখ্যা অদলবদল হয় (দ্বৈততা)

৪টি NAND দিয়ে XOR (ন্যূনতম)

① P = (AB)′ = A′ + B′

② Q = (A·P)′ = (A(A′+B′))′ = (AB′)′

③ R = (B·P)′ = (A′B)′

④ Y = (Q·R)′ = AB′ + A′B = A ⊕ B

পরীক্ষার ফাঁদ অনেক বইয়ে XOR আঁকা হয় ৫টি NAND বা ৬টি NOR দিয়ে (ইনভার্টার + SOP)। সার্কিট ঠিক, কিন্তু ন্যূনতম নয়। MCQ-তে চাওয়া হয় ন্যূনতম: ৪টি NAND, ৫টি NOR।

সমতুল্য প্রতীক

মনে রাখার কৌশল "দাগ ভাঙো, চিহ্ন বদলাও"। প্রতীকে বাবল পুশিং: আউটপুটের বাবল সব ইনপুটে সরাও (বা উল্টোটা), আর AND ↔ OR বদলাও।

সমাধানকৃত উদাহরণ (লিখিত উত্তরের ধাঁচে)

প্রশ্ন F = (A + B)′ + (A′ + B′)′ সরল করো এবং এটি কোন গেটের সমান তা লেখো। ৪ নম্বর
  1. প্রতিটি পদে ডি মরগান: (A + B)′ = A′B′ এবং (A′ + B′)′ = A″B″ = AB
  2. অতএব F = A′B′ + AB
  3. A = B হলে F = 1 → F = A ⊙ B (XNOR)
  4. ২টি NOR + ২টি NOT + ১টি OR-এর বদলে একটি XNOR → কম গেট, কম বিলম্ব

৭দ্বৈততার নীতি (Duality Principle)

নিয়ম যেকোনো বুলিয়ান অভেদে + ↔ · এবং 0 ↔ 1 বদলালে অভেদটি সত্যই থাকে (চলকগুলোর পূরক নেওয়া হয় না)।
অভেদএর দ্বৈত (dual)
A + 0 = AA · 1 = A
A + A′ = 1A · A′ = 0
A(B + C) = AB + ACA + BC = (A + B)(A + C)
পরীক্ষার ফাঁদ দ্বৈত আর পূরক এক জিনিস নয়। পূরকে প্রতিটি চলকও উল্টে যায় (A → A′); দ্বৈতে যায় না।

৮সত্যক সারণি থেকে গেট সার্কিট

মিনটার্ম (m) সব চলক থাকা AND-পদ, ঠিক একটি সারিতে 1। SOP = মিনটার্মের OR = Σm
ম্যাক্সটার্ম (M) সব চলক থাকা OR-পদ, ঠিক একটি সারিতে 0। POS = ম্যাক্সটার্মের AND = ΠM
  1. সত্যক সারণি লেখো (2ⁿ টি সারি)
  2. F = 1 এমন সারি → মিনটার্ম (SOP)
  3. সরল করো (বুলিয়ান সূত্র বা K-ম্যাপ)
  4. AND-OR (বা NAND-NAND) আঁকো
  5. প্রতিটি সারি আবার যাচাই করো
