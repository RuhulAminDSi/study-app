Periodicity, even/odd parts & the power of a sum

Periodicity of a sum: x1 + x2 is periodic only if T1/T2 is rational; then T0 = LCM(T1, T2). cos(2πt/3) + sin(2πt/5) → T0 = 15 s; cos t + cos πt → ratio π → not periodic.

Even/odd parts: xe = [x(t) + x(−t)]/2, xo = [x(t) − x(−t)]/2. even × even = even, odd × odd = even, even × odd = odd; ∫−aa (odd) dt = 0.

Memory trick "Energy signals die out, power signals live for ever." Finite duration or decaying → energy; repeating or constant → power.
Worked example ✍ x(t) = 3cos(100πt) + 4sin(200πt): f = 50 Hz and 100 Hz, so T0 = 20 ms. Powers add (different frequencies): P = 9/2 + 16/2 = 12.5 W

3Fourier Series: Three Equivalent Forms

high-yield
Definition A periodic signal x(t) with period T0 (meeting Dirichlet's conditions) equals a DC term plus harmonics at nf0, where f0 = 1/T0 and ω0 = 2π/T0. Its spectrum is a set of discrete lines (a line spectrum).
FormSeriesCoefficients
Trigonometrica0 + Σn=1∞ [an cos nω0t + bn sin nω0t]a0, an, bn (box below)
Compact (polar)C0 + Σ Cn cos(nω0t + θn)Cn = √(an² + bn²), θn = −tan⁻¹(bn/an)
ExponentialΣn=−∞∞ cn ejnω0tcn = (1/T0)∫T0 x(t) e−jnω0t dt
Coefficients (∫ over one period) a0 = (1/T0)∫ x(t) dt = DC (average) · an = (2/T0)∫ x(t) cos nω0t dt · bn = (2/T0)∫ x(t) sin nω0t dt
Links: c0 = a0 · cn = (an − jbn)/2 · real x(t): c−n = cn* ⇒ |cn| = Cn/2 (n ≥ 1)
Exam trap In the two-sided (exponential) spectrum each line at ±nf0 is half the one-sided amplitude Cn; only the DC line keeps its height. Negative frequencies are a mathematical bookkeeping device, not a physical band.

4Dirichlet Conditions & Symmetry

MCQ favourite

Dirichlet conditions (sufficient, not necessary), per period:

  1. absolutely integrable: ∫T0 |x(t)| dt < ∞
  2. finite number of maxima and minima
  3. finite number of finite discontinuities

At a jump the series converges to the mid-point [x(t⁺) + x(t⁻)]/2.

SymmetryWhat survives
Even: x(−t) = x(t)a0, an; bn = 0
Odd: x(−t) = −x(t)bn only
Half-wave: x(t ± T0/2) = −x(t)odd n only
Even + half-waveodd cosines only
Memory trick Even ↔ cos, Odd ↔ sin (cos is even, sin is odd). "Half-wave symmetry keeps the odd harmonics."
Shortcuts Adding a DC level changes only a0. A time shift changes only the phases θn, never |cn|. Scaling time changes f0, not the coefficients.

5Worked Example: the Square Wave

written favourite

Odd square wave, x(t) = +A for 0 < t < T0/2 and −A for T0/2 < t < T0.

  1. Odd ⇒ a0 = an = 0; half-wave symmetric ⇒ only odd n survive
  2. bn = (2/T0)[∫0T0/2 A sin nω0t dt − ∫T0/2T0 A sin nω0t dt] = (2A/nπ)(1 − cos nπ)
  3. n odd: bn = 4A/(nπ); n even: bn = 0
Result x(t) = (4A/π) [sin ω0t + (1/3) sin 3ω0t + (1/5) sin 5ω0t + …]
  • Total power P = A² (|x| = A always)
  • Fundamental: (4A/π)²/2 = 8A²/π² = 81.1% of P
  • n = 1, 3, 5 together: 93.3%
  • Amplitudes fall as 1/n (a jump); a triangle wave (a kink) as 1/n² (8A/(π²n²)); FT: rect → sinc ∝ 1/f, triangle → sinc² ∝ 1/f². Smoother ⇒ narrower spectrum
Gibbs phenomenon Near a jump a truncated series overshoots by ≈ 9% of the jump (peak ≈ 1.18A). More terms make the ripple narrower, never smaller.

6Rectangular Pulse Train & Power from the Series

Pulses of height A, width τ, period T0; duty cycle d = τ/T0:

cn = A·d·sinc(n·d)

  • lines every f0 = 1/T0; DC = A·d
  • sinc envelope with nulls at multiples of 1/τ
  • d = 1/4 → lines n = ±4, ±8 … are missing
Parseval for the series
P = (1/T0)∫T0|x|² dt = Σ |cn|²
= a0² + Σ (an² + bn²)/2 = C0² + Σ Cn²/2
each harmonic's power adds independently (orthogonality)
Worked example ✍ x(t) = 1 + 2cos(2π·50t) + 4sin(2π·150t): T0 = 20 ms; a0 = 1, a1 = 2, b3 = 4 → c±1 = 1, c±3 = ∓2j (|c3| = 2); P = 1 + 2²/2 + 4²/2 = 11 W.
Exam trap Keep τ fixed and let T0 → ∞: lines crowd together (spacing 1/T0 → 0) and the line spectrum becomes the continuous Fourier transform. That is exactly how the FT is born (below).

7The Fourier Transform

high-yield
Transform pair X(f) = ∫ x(t) e−j2πft dt  ·  x(t) = ∫ X(f) ej2πft df  (limits −∞ to ∞)
In ω: X(ω) = ∫ x e−jωt dt, x(t) = (1/2π) ∫ X(ω) ejωt dω
  • For aperiodic signals; X(f) is a continuous spectral density (V/Hz): |X(f)| = amplitude spectrum, ∠X(f) = phase spectrum
  • Real x(t) ⇒ X(−f) = X*(f): |X| is even, phase is odd
  • Exists if ∫|x| dt < ∞ (+ Dirichlet); every energy signal has one. Power signals (DC, cos, u(t)) need impulses δ(f)
Sinc & the "sampling function" sinc(x) = sin(πx)/(πx) (normalised) · Sa(x) = sin x / x, the sampling function of the syllabus. sinc(0) = Sa(0) = 1; sinc zeros at x = ±1, ±2 …; Sa zeros at ±π, ±2π … ; sinc(x) = Sa(πx); ∫ sinc(x) dx = 1.

9Bandwidth

  • Absolute: X(f) = 0 outside B (ideal band-limited signals only)
  • 3-dB (half-power): where |X| falls to 1/√2 of peak
  • Null-to-null / first-null: width of the main lobe
  • 99% (fractional-power): band holding 99% of the power
Time-bandwidth product τ·B ≈ constant. A pulse of width τ has first-null bandwidth 1/τ (baseband): 1 µs → 1 MHz, 1 ns → 1 GHz. No signal is both time-limited and band-limited.
Signal / systemBandwidth
pulse, width τfirst null 1/τ

sinc pulses, R symbol/sR/2 (minimum)

Exam trap Baseband bandwidth counts positive frequencies only: nulls at ±1/τ give B = 1/τ, not 2/τ. After modulation the band becomes 2/τ around fc.

RC: R = 1 kΩ, C = 0.1 µF → f3dB ≈ 1.59 kHz.

10Convolution

written favourite
Definition y(t) = x(t) * h(t) = ∫ x(τ) h(t − τ) dτ. For a linear time-invariant (LTI) system with impulse response h(t), the output is the input convolved with h(t). Discrete: y[n] = Σk x[k] h[n − k].
  1. Flip h(τ) → h(−τ)
  2. Shift by t → h(t − τ)
  3. Multiply by x(τ)
  4. Integrate (area) → y(t); repeat for every t
7
Communication Theory · Spectral AnalysisConvolution · Parseval
  • Commutative, associative, distributive
  • x * δ(t) = x(t) (identity) · x * δ(t − t0) = x(t − t0)
  • Width of y = width of x + width of h
  • Area of y = area of x × area of h
  • Discrete length: N + M − 1
Convolution theorem
x * h ↔ X · H  and  x · h ↔ X * H
⇒ H(f) = Y(f)/X(f) = transfer function = FT of h(t). Filters multiply spectra; sampling and windowing (products in time) convolve spectra.
Worked example 1 ✍ [1, 2, 3] * [1, 1]:
y[0] = 1 · y[1] = 2 + 1 = 3 · y[2] = 3 + 2 = 5 · y[3] = 3
y = [1, 3, 5, 3], length 3 + 2 − 1 = 4 ✓
Worked example 2 ✍ u(t) * e−atu(t) = ∫0t e−aτ dτ = (1/a)(1 − e−at) u(t): the step response of an RC low-pass (a = 1/RC).
Exam trap Squaring a signal doubles its bandwidth: x² ↔ X * X, so a 3 kHz signal squared occupies 6 kHz. A product x1x2 occupies W1 + W2.

Correlation: convolution without the flip

Definition Rxy(τ) = ∫ x(t) y*(t − τ) dt = x(τ) * y*(−τ): no flip, not commutative (Rxy(τ) = Ryx*(−τ)), F{Rxy} = X·Y*. Autocorrelation Rx(τ): even for real x, maximum at τ = 0, R(0) = energy, F{Rx} = |X(f)|². IT link: radar, GPS and CDMA receivers find a delay at the correlation peak (matched filter).

11Parseval's Theorem

high-yield
Statement The energy (or power) of a signal is the same whether summed over time or over frequency. Each frequency component contributes independently, because the complex exponentials are orthogonal.
CaseTime domainFrequency domain
FT, energy (Rayleigh) ★E = ∫ |x(t)|² dt= ∫ |X(f)|² df
Fourier series, power ★P = (1/T0) ∫T0 |x(t)|² dt= Σ |cn|² = C0² + Σ Cn²/2
DFTΣ |x[n]|²= (1/N) Σ |X[k]|²
Worked examples ✍
  1. x(t) = 2 + 4cos(2π·100t): c0 = 2, c±1 = 2 → P = 2² + 2² + 2² = 12 W (= 2² + 4²/2 ✓)
  2. ∫ sinc²(t) dt = ∫ rect²(f) df = 1: integrate in whichever domain is easier
  3. e−atu(t): E = ∫0∞ e−2at dt = 1/(2a) = ∫ df/(a² + 4π²f²) ✓; a = 2 → 0.25 J. A rect pulse keeps ≈ 90% of its energy in the main lobe |f| < 1/τ

Periodic: S(f) = Σ |cn|² δ(f − nf0) (lines). White noise: S(f) = N0/2, R(τ) = (N0/2)δ(τ); after an ideal LPF of bandwidth B the noise power is N0B (the N in Shannon’s C = B log₂(1 + S/N)).

Worked examples ✍

  2. White noise N0/2 through an RC low-pass: Sy = (N0/2)/(1 + (2πfRC)²) → Py = N0/(4RC); noise-equivalent bandwidth BN = 1/(4RC) = (π/2) f3dB

13The Sampling Theorem

high-yield
Statement A signal band-limited to W Hz (X(f) = 0 for |f| > W) is fully recovered (ideal LPF) from samples taken at fs ≥ 2W. Nyquist rate = 2W (minimum fs); Nyquist interval = 1/(2W) (maximum Ts). Nyquist 1928, Shannon 1949.

Ideal (impulse) sampling: xs(t) = x(t) · Σ δ(t − nTs)

⇒ Xs(f) = fs Σ X(f − n fs): copies of the spectrum at every multiple of fs (a product in time is a convolution in frequency).

Recovery: LPF cut-off W ≤ fc ≤ fs − W; guard band = fs − 2W. Ideal interpolation: x(t) = Σ x(nTs) sinc((t − nTs)/Ts).

9
Communication Theory · Spectral AnalysisAliasing · Nyquist problems · DFT

Aliasing: if fs < 2W the copies overlap; a tone f appears at fa = |f − k·fs| (k = nearest integer, fa ≤ fs/2). Cure: anti-aliasing LPF (cut-off fs/2) before the sampler + sample above 2W.

Practical: natural (gated) sampling keeps the baseband copy undistorted; flat-top (sample-and-hold, PAM) multiplies it by sinc(fτ) → aperture effect, fixed by an equaliser.

14DFT & FFT (the digital spectrum)

DFT X[k] = Σn=0N−1 x[n] e−j2πkn/N, k = 0 … N − 1 · inverse has the factor 1/N · bin k ↔ f = k·fs/N · resolution Δf = fs/N
  • Radix-2 FFT (Cooley–Tukey, 1965, N a power of 2): (N/2)log₂N complex multiplications instead of N²
  • N = 1024: 1,048,576 → 5,120, ≈ 205× faster
  • fs = 8 kHz, N = 256 → Δf = 31.25 Hz
  • DFT product ↔ circular convolution
  • IT link: OFDM (Wi-Fi, 4G/5G) uses IFFT/FFT
Worked example ✍ 4-point DFT of x = [1, 1, 0, 0]: X[k] = 1 + e−jπk/2 → X = [2, 1 − j, 0, 1 + j]. Parseval check: Σ|x|² = 2 = (1/4)(4 + 2 + 0 + 2) ✓. X[0] = Σ x[n] is always the DC sum.
