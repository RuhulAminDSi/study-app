Q1 What is Object-Oriented Programming (OOP)? Why is it needed? Write its fundamental concepts (pillars). / What do you mean by OOP? Write its primary principles.15th NTRCA · 17th NTRCA · 15th NTRCA ICT · BOF SAE(Computer) 2021 · 37th BCS
OOP a programming paradigm that builds a program from objects: each object bundles data (attributes) with the methods that work on it, and objects cooperate by calling each other's methods (message passing). A class is the blueprint the objects are made from.

Why it is needed: in a big procedural program any function can change the shared data, so bugs spread and code is reused only by copying. OOP protects data inside objects, reuses code by inheritance, keeps a change inside one class, and mirrors real things (account, student), so design and maintenance are easier.

Q3 Explain OOP concepts with proper examples (Java below). / Explain any two features of OOP with examples. / Explain inheritance, polymorphism and encapsulation. / What is encapsulation, inheritance and polymorphism?JBL ANE 2022 · BPSC AP 2021 · 16th NTRCA CSE (2019) · 36th BCS (2016)
abstract class Shape { // abstraction: what, not how private String name; // encapsulation: hidden data Shape(String n) { name = n; } String getName() { return name; } abstract double area(); } class Circle extends Shape { // inheritance: Circle IS-A Shape private double r; Circle(double r) { super("Circle"); this.r = r; } double area() { return Math.PI * r * r; } // polymorphism } class Square extends Shape { private double s; Square(double s) { super("Square"); this.s = s; } double area() { return s * s; } } Shape[] all = { new Circle(1), new Square(2) }; for (Shape x : all) System.out.printf("%s %.2f%n", x.getName(), x.area());

→ Circle 3.14 · Square 4.00  (one call x.area(), two behaviours)

Encapsulation: name, r, s are private. Abstraction: Shape promises area() without saying how. Inheritance: both shapes reuse getName(). Polymorphism: the loop runs the right area() for each object.

Q4 C++ is an object-oriented programming language: explain.15th NTRCA Computer Operation (2019)

C++ supports every pillar: class with private/protected/public (encapsulation), abstract classes with pure virtual functions (abstraction), five kinds of inheritance, and polymorphism by overloading (compile time) and virtual functions (run time). It is a hybrid language: C-style code with no class also compiles, so it is not "pure" OOP like Smalltalk.

Q11 What are objects in C++? / How is a member function of a class defined? / What is a method in OOP, and how is it used?37th BCS · 16th NTRCA ICT

An object is a variable of a class type: it has state (its data members), behaviour (member functions) and identity (its own address). A member function (method) is a function declared inside the class; it is called on an object (c1.area()) and works on that object's data. Q20 Explain encapsulation and inheritance in detail. / Explain how encapsulation and inheritance are advantageous in OOP.38th BCS (2018) · Combined Bank Officer(IT) 2024

Encapsulation binds data to the methods that use it and hides it with private; outsiders use checked public methods. Gains: data integrity, inside can change freely, simpler use. Inheritance lets a derived class acquire the members of a base class and add or override its own (IS-A). Gains: code reuse, less testing, a natural hierarchy, run-time polymorphism.

Q23 What are the various access specifiers in C++? Explain their purpose with an example.BPSC ADA 2022

An access specifier decides who may use a class member. public: everyone · protected: the class, its friends and its derived classes · private: the class and its friends only (the default in a C++ class).

Q25 What is a friend function? Write its characteristics, advantages and disadvantages.16th NTRCA · 16th NTRCA ICT · 18th NTRCA College ICT (2024)
Friend function a non-member function that a class names with the keyword friend inside its body; it may then access that class's private and protected members.
Characteristics
  • declared inside the class, defined outside without friend or ::
  • not a member: no this, not in the class's scope
  • called like a normal function: show(b), not b.show()
  • gets the object as an argument and uses obj.member
  • friendship is not inherited, not mutual, not transitive
Advantages
  • one function can work on the private data of two classes
  • needed for operator<< / >> on objects
  • avoids many getters
Disadvantages
  • breaks encapsulation
  • bypasses the class's own checks
  • more coupling, harder maintenance

Q28 Inheritance is one of the important issues for any object-oriented programming language. Its main advantage is the ability to reuse code. Explain briefly the different types of inheritance.Combined Bank Officer(IT) 2020
Inheritance creating a new class (derived / child) from an existing class (base / parent), so the derived class gets the base members and adds or overrides its own. It models an IS-A relation: a Savings account is an Account.
class A {}; class B : public A {}; // single: A → B class C : public A {}; // hierarchical: A → B and A → C class D : public C {}; // multilevel: A → C → D class E : public B, public C {}; // multiple: B + C → E (Java: only via interfaces) class F : public D, public E {}; // hybrid: two kinds at once
Advantages
  • code reuse: tested code is not rewritten
  • less code, less testing
  • natural hierarchy, easy to extend
  • enables run-time polymorphism
Disadvantages
  • tight coupling: a base change breaks children
  • deep hierarchies are hard to follow
  • multiple inheritance → diamond problem
  • child carries unused base members

Q30 What is the diamond problem of multiple inheritance in C++?BPSC AP 2023

When Student and Teacher both inherit Person, and TA inherits both, a TA object holds two copies of Person. t.id is then ambiguous: the compiler says "non-static member 'id' found in multiple base-class subobjects". Fix: virtual inheritance, which keeps one shared Person.

class Person { public: int id = 7; Person() { cout << "Person "; } }; class Student : virtual public Person { public: Student() { cout << "Student "; } }; class Teacher : virtual public Person { public: Teacher() { cout << "Teacher "; } }; class TA : public Student, public Teacher { public: TA() { cout << "TA\n"; } }; int main() { TA t; cout << t.id; }

→ Person Student Teacher TA
→ 7 (one Person only)

Q31 Write the definitions of inheritance and polymorphism with a coding example. / Explain inheritance and polymorphism in Java; write a Java program to demonstrate method overriding.Combined Bank AP 2021 · Combined Bank Officer(IT) 2026
class Animal { void sound() { System.out.println("Animal makes a sound"); } } class Dog extends Animal { // inheritance @Override void sound() { System.out.println("Dog barks"); } } class Cat extends Animal { @Override void sound() { System.out.println("Cat meows"); } } // main(): Animal[] a = { new Dog(), new Cat(), new Animal() }; for (Animal x : a) x.sound(); // polymorphism

→ Dog barks
→ Cat meows
→ Animal makes a sound

Inheritance: Dog gets everything of Animal. Polymorphism: an Animal reference runs the object's own sound(), decided at run time. @Override makes the compiler check the signature.

Memory trick Constructors build a house from the foundation up (A → B → C); destructors pull it down from the roof.
Exam trap Java has no multiple inheritance of classes, so no diamond of classes; a class may implement many interfaces.

Q72 A Shape interface with Circle, Rectangle, Square; a ShapeMaker class and FacadePatternDemo: name the pattern and implement it.BPDB AE(CSE) 2023

It is the Facade pattern (structural): one simple class (ShapeMaker) in front of a set of classes, so the client calls drawCircle() without knowing which objects do the work.

interface Shape { void draw(); } class Circle implements Shape { public void draw() { System.out.println("Circle::draw()"); } } class Rectangle implements Shape { public void draw() { System.out.println("Rectangle::draw()"); } } class Square implements Shape { public void draw() { System.out.println("Square::draw()"); } } class ShapeMaker { // the facade private Shape circle = new Circle(), rectangle = new Rectangle(), square = new Square(); public void drawCircle() { circle.draw(); } public void drawRectangle() { rectangle.draw(); } public void drawSquare() { square.draw(); } } public class FacadePatternDemo { public static void main(String[] args) { ShapeMaker m = new ShapeMaker(); m.drawCircle(); m.drawRectangle(); m.drawSquare(); } }

→ Circle::draw()
→ Rectangle::draw()
→ Square::draw()
