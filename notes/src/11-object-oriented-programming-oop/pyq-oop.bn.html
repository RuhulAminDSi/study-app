OOP এমন একটি প্রোগ্রামিং পদ্ধতি যেখানে প্রোগ্রাম গড়া হয় object দিয়ে: প্রতিটি object তার ডেটা (attribute) ও সেই ডেটায় কাজ করা method একসঙ্গে রাখে, আর object-গুলো একে অপরের method ডেকে কাজ করে (message passing)। Class হলো যে নকশা থেকে object তৈরি হয়।

কেন দরকার: বড় procedural প্রোগ্রামে যেকোনো function শেয়ার করা ডেটা বদলাতে পারে, তাই bug ছড়িয়ে পড়ে আর কোড পুনর্ব্যবহার হয় শুধু কপি করে। OOP ডেটাকে object-এর ভেতরে সুরক্ষিত রাখে, inheritance দিয়ে কোড পুনর্ব্যবহার করে, পরিবর্তন একটি class-এর ভেতরে রাখে, আর বাস্তব জিনিসের (account, student) মতো গঠন দেয়; ফলে নকশা ও রক্ষণাবেক্ষণ সহজ।

  1. Base class: সাধারণ ডেটা (protected, বা private + getter) ও একটি constructor।
  2. সাধারণ method base-এ; যে method আলাদা হবে তা virtual (C++) / override-যোগ্য (Java)।
  3. প্রতিটি derived class: তার বাড়তি ডেটা, আর এমন constructor যা আগে base-এরটি ডাকে (: Base(...) / super(...))।
  4. শুধু যা আলাদা তা override করুন (override / @Override)।
  5. main: base-type array বা pointer-এ বিভিন্ন object, একটি loop-এ একই method ডাকা।

প্র৪৭ Overloaded, overridden ও hidden superclass method নির্ণয় করুন: class A { public void m1() {} public void m2() {} public void m3(int i) {} public void m4(String i) {} } class B extends A { public static void m1() {} public void m2() {} public void m3(int i) {} public static void m4(String i) {} }BB AP 2023

Overridden: m2(), m3(int) (একই signature, instance method)। Overloaded: নেই (একই নামে ভিন্ন parameter নেই)। Hidden: ছাপা অবস্থায় নেই — কম্পাইলই হয় না: javac বলে "m1() in B cannot override m1() in A", কারণ static method কোনো instance method লুকাতে পারে না। Parent-এর method-ও static হলে তবেই hiding হয়:

Static = hidden, reference-এর type দেখে বাছাই; instance = overridden, object দেখে বাছাই।
