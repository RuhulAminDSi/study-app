MCQ (fill in) File permission is rwxrw---x. If it is changed using chmod 701, the permission will be ____.
BPDB Assistant Engineer (CSE) · 2021 · Q1(v)

7 = 111 → rwx · 0 = 000 → --- · 1 = 001 → --x ⇒ answer rwx-----x

Exam trap A numeric mode is absolute: it replaces all nine bits, so the old value (rwxrw---x) does not matter. Only symbolic modes (u+x, g-w) edit the existing bits.
Question Give a file Read, Write and Execute permission.
Islamic Bank PLC, SQA Senior Officer (Network) · 14.03.2025 · Q2(a)
chmod u+rwx run.sh # owner = 700 chmod a+rwx run.sh # all = 777 ls -l run.sh # verify
Question Change the ownership of a file or directory.
BUET MSc in CSE · 03.10.2026 · Q3(2)
sudo chown rahim:staff a.txt sudo chown -R rahim /data # tree

Only root can give a file away; chgrp changes the group only.

Memory trick "Read Write eXecute = 4 2 1", classes in the order U G O ("you go"). 7 = all, 6 = rw, 5 = rx, 4 = r. On servers grant the least: 755 scripts, 644 files, 600 keys; 777 is a security hole.

3Cloud Computing: IaaS, PaaS, SaaS

written · viva ×7
Question Explain IaaS, PaaS and SaaS with respect to cloud computing.
Bangladesh Bank AME (BIBM) · 04.02.2023 · Q5 · viva: "What are the cloud service models?"

Cloud computing (NIST): on-demand network access to a shared pool of computing resources, provisioned fast and paid per use: self-service, broad network access, resource pooling, rapid elasticity, measured service.

IaaS: rent VMs, storage, networks; you run the OS and up. AWS EC2, Azure VMs.

PaaS: a ready runtime + database, scaling; you deploy only code and data. Google App Engine, Azure App Service, Heroku.

SaaS: a finished application in the browser, paid per user. Gmail, Microsoft 365, Salesforce.

Memory trick: pizza home-made = on-prem · take-and-bake = IaaS · delivery = PaaS · dine out = SaaS.

Deployment: public · private · community · hybrid (private core + public bursts).

Viva block (bank IT vivas)

Examples?AWS, Microsoft Azure, Google Cloud; Google Drive, Dropbox (SaaS)
Benefits?pay-per-use (OPEX), elastic scaling, availability, remote access, managed updates, DR
Challenges?security, privacy, outages, Internet dependency, vendor lock-in, compliance
Solutions?encryption + MFA + least-privilege IAM, multi-zone + SLA, backups / DR plan, open formats, local region
DC vs cloud?DC: own building and hardware, CAPEX, weeks to grow · cloud: rented on demand, OPEX, minutes to grow
Exam trap The cloud still runs in data centres; the difference is who owns them and how you pay. Dropbox and Google Drive are SaaS, not IaaS.

4Scaling, Racks & Edge Servers

written ×3
Question ICB's server traffic increases from 10,000 to 50,000 hits, but ICB does not migrate to the cloud. Discuss the consequences from business and technical perspectives.
ICB Securities Trading Co. Assistant Programmer · 27.06.2026 · Q10(b)

Load rises 5×: a server at 60% CPU today would need ≈ 300%. Near 100% utilisation queueing delay climbs steeply, so pages slow down before the server is "full".

  • Tech: CPU / RAM / bandwidth saturation → timeouts, HTTP 503
  • DB connection pool exhausted, failed order writes
  • No auto-scaling; new hardware takes weeks
  • One server = single point of failure
  • Business: lost / late trade orders → revenue loss
  • Complaints, churn, reputation damage; BSEC risk
  • Big CAPEX for peak capacity, idle off-peak
  • Upside: full control of data and its location
On-premises fix ✍ scale up now → scale out (load balancer + more app servers) → cache + CDN → DB indexes, read replicas → queue orders → monitor; or a hybrid cloud for bursts.
Question Draw a server rack diagram to show horizontal and vertical scaling.
RPGCL Assistant Manager (ICT), BUET-set · 2022 · Q7

Vertical (scale up): a bigger CPU / RAM in the same server; simple, but a hardware ceiling, downtime to upgrade, single point of failure.

Horizontal (scale out): add identical servers behind a load balancer; near-linear, live, survives a node loss.

Rack: 19 in wide, 42U tall, 1U = 1.75 in.

Question What is the need for an edge server?
BOGMC (Petrobangla) Assistant Manager · 2024 · Q5(d)

An edge server processes data near its source (plant, branch, cell tower) instead of a distant cloud: low latency (ms, real-time control), less bandwidth (send summaries), resilience when the WAN drops, privacy (data stays on site). e.g. a gas-field edge box closes a valve in milliseconds; only hourly summaries go to the cloud.

5Virtual Machines & Containers

written ×2
Question Define a virtual machine with a neat diagram, explain the working of a VM. What are the benefits of a VM?
Bangladesh Bank AME (BIBM) · 04.02.2023 · Q6

A virtual machine is a software computer with its own virtual CPU, RAM, disk and NIC, running its own guest OS, created by a hypervisor (VMM) on one physical host.

  1. Working: the hypervisor owns the hardware and gives each VM vCPUs, vRAM, a virtual disk (a .vmdk / .vhdx file) and a vNIC; it schedules vCPUs on real cores
  2. Each guest OS thinks it owns a whole machine; privileged instructions are trapped by the hypervisor (Intel VT-x / AMD-V help); VMs stay isolated
  3. Type 1 (bare-metal: ESXi, Hyper-V, KVM) or Type 2 (hosted: VirtualBox). Benefits: consolidation, isolation, snapshots, live migration, many OSes on one box, quick provisioning

asked in a recruitment paper (2026)

6Data Centres: Energy, Tiers, DRS

written · viva ×10
Question What are the challenges in optimising the energy efficiency of data centres? Explain.
Bangladesh Bank AME (BIBM) · 04.02.2023 · Q7
Metric PUE = total facility power ÷ IT power; ideal 1.0. e.g. 1,500 kW total for 1,000 kW IT → PUE = 1.5 (DCiE = 1/PUE = 67%).
  1. Cooling, the largest overhead: hot spots, hot and cold air mixing, a hot humid climate → aisle containment, in-row cooling, 18–27 °C inlet
  2. Power-distribution losses in UPS, transformers, PDUs → high-efficiency UPS
  3. Low server utilisation: idle servers still draw much of peak power → virtualise, consolidate
  4. Old equipment, and no metering so waste is invisible → refresh, DCIM, track PUE

Viva block (bank IT vivas)

Data centre?secured facility for servers, storage, network gear with power, cooling, monitoring
Hardware?servers, SAN/NAS, routers, switches, firewalls, racks, UPS + generator, PDUs, CRAC cooling
Security?guards, CCTV, biometric / card access, mantrap, fire detection + gas suppression, firewall, IDS/IPS
Why cooling?almost all power becomes heat; heat and humidity cause throttling and failures
DRS? vs DC?Disaster Recovery Site: a replica elsewhere (other flood / quake risk) that takes over; DC = live daily work, DRS = standby

UPS vs IPS? Use an online (double-conversion) UPS: zero transfer time, clean sine wave, bridges to the generator. An IPS (Instant Power Supply) switches over with a delay and regulates poorly.

Exam trap Here IPS = Instant Power Supply, not "Intrusion Prevention System".
TierDesignUptime

Tier II vs III: II has redundant parts but one path, so maintenance needs a shutdown (≈ 22 h/yr down); III has several paths, serviced without shutdown (≈ 1.6 h/yr). RPO = data you may lose; RTO = time to restore.

9Key Press to Screen; ASCII & Unicode

BPSC viva 2023
Viva A key is pressed and it appears on the monitor: what is the process? Computers know only binary: how does a key become a character? What is ASCII?
BPSC viva 2023 (Assistant Maintenance Engineer)
  1. The key closes a switch in the key matrix; the keyboard controller sends a scan code over USB
  2. The OS driver maps the scan code, by keyboard layout, to a character code (ASCII / Unicode)
  3. The application gets the key event; the font engine draws the glyph; the GPU puts it in the frame buffer → monitor

ASCII (American Standard Code for Information Interchange): 7-bit, 128 codes; 'A' = 65, 'a' = 97, '0' = 48, space = 32; extended ASCII = 8 bits. Unicode numbers every script (U+0000 to U+10FFFF; Bangla U+0980–U+09FF, অ = U+0985), stored as UTF-8 (1–4 bytes), UTF-16 or UTF-32.

Memory trick 'a' − 'A' = 32: flip one bit (0x20) to change case. Digits start at 48 ('0'), capitals at 65, small letters at 97.

PC faults & security

PC won't power on? socket / UPS, cable, PSU switch → test PSU → front-panel header, 24/8-pin plugs → board short. No fan/LED ≠ no display (fans run, beeps → RAM/GPU).

Sudden shutdown: why, fix? overheating (dust, dead fan, dry paste), weak PSU, power dips, bad RAM, malware, driver crash → clean, re-paste, check temps, test PSU and RAM, online UPS, Event Viewer, scan.

Protect an office PC? non-admin user, strong password + auto-lock, patches, antivirus, firewall, BitLocker, block USB storage, 3-2-1 backups, BIOS password.

Printer won't print? power, cable / network (ping it), jam, toner, wrong default printer, "offline", stuck queue → restart Print Spooler, reinstall driver; a self-test page splits printer vs PC.

Software

Translator types? 3: assembler, compiler (whole program → object code), interpreter (line by line).

JDK vs JRE? JDK = JRE + javac, jar, debugger (develop); JRE = JVM + libraries (run).

Python, why popular? high-level, interpreted, dynamically typed (Guido van Rossum, 1991); readable, huge libraries, AI/data, automation.

Batch processing? collect transactions, process together at set times (BEFTN, payroll); RTGS settles each in real time.

Android

Current version? numbers only since Android 10 (2019): 14 in 2023, 15 in 2024, 16 in 2025.

Names in order? Cupcake, Donut, Eclair, Froyo, Gingerbread, Honeycomb, Ice Cream Sandwich, Jelly Bean, KitKat, Lollipop, Marshmallow, Nougat, Oreo, Pie: alphabetical C → P.

Why sweets? Google: the devices "make our lives so sweet"; A–Z order made the sequence easy; dropped in 2019 as names did not travel well globally.

Why "apps"? Views? app = application software (App Store era, 2008). TextView shows text; EditText (a TextView subclass) takes input.

Internet & web

Internet / intranet / extranet? public network of networks on TCP/IP · private, staff only · part of an intranet opened to partners (login / VPN).

Domain, types? a name DNS maps to an IP. TLDs: generic (.com, .org), country-code (.bd, .বাংলা), sponsored (.edu, .gov), infrastructure (.arpa).

URL, parts? https:// (scheme) www.bb.org.bd (host) :443 (port) /docs/rate.html (path, file) ?y=2025 (query) #top (fragment).

Web design technologies? Why JavaScript? HTML (structure), CSS (style), JavaScript (behaviour); PHP, Node.js on the server. JS is the only language every browser runs; DOM, fetch, Node.js full stack.

SEO

SEO? raising a site's organic (unpaid) rank: on-page, off-page, technical (speed, mobile, sitemap, HTTPS).

Image SEO / link SEO? descriptive file name, alt text, compression, lazy loading · internal links, quality backlinks, clear anchor text.

Tools? Google Search Console, Analytics, PageSpeed Insights, Ahrefs, SEMrush, Moz.

Blockchain & data

Blockchain? distributed, append-only ledger; each block stores the previous block's hash, so tampering shows; nodes agree by consensus (PoW / PoS).

vs database? decentralised, append-only, trust by consensus · central admin, full CRUD, much faster.

Bitcoin / crypto vs taka? first crypto (Satoshi Nakamoto, 2009; 21 M cap); crypto is decentralised and volatile; taka is legal tender issued by Bangladesh Bank, which warns crypto is not legal tender.

Smart contract? blockchain code that runs itself when conditions are met (Ethereum): escrow, insurance, trade finance.

Big data? too big / fast / varied for normal tools: 5 V (volume, velocity, variety, veracity, value); social media, bank transactions, call records, sensors.

IoT? sensor devices on a network sending data to edge / cloud (smart meters, GPS trackers).

MICR? ISO in hardware? magnetic-ink E-13B line on cheques · ISO 9001 quality, ISO/IEC 7810 card size.
