Version control (Git) কোডের পরিবর্তন ট্র্যাক করে ও টিমকে পুরোনো অবস্থায় ফিরতে দেয়। commit = আপনার লোকাল repo-তে একটি স্ন্যাপশট সংরক্ষণ; push = লোকাল commit গুলো remote (GitHub)-এ পাঠানো। commit লোকাল, push নেটওয়ার্ক।

ফাঁদ: compiler/assembler সিস্টেম সফটওয়্যার (মেশিনকে সেবা দেয়), app নয়; antivirus = utility = সিস্টেম সফটওয়্যার।

মাইক্রো-কম্পিউটার সিস্টেম = microprocessor (CPU) + memory (RAM/ROM) + I/O device + system bus + power supply, এক বাক্সে। Super বনাম mainframe: super = একটি বড় কাজে সর্বোচ্চ গতি; mainframe = বহু ব্যবহারকারী/লেনদেনে সর্বোচ্চ থ্রুপুট।

উদ্দেশ্য অনুসারে: general-purpose (PC) বনাম special-purpose (ATM, embedded)। Workstation = প্রকৌশল/গ্রাফিক্সের শক্তিশালী একক-ব্যবহারকারী PC। Server = নেটওয়ার্কে client-দের সেবা দেয় এমন কম্পিউটার। Embedded system = কোনো যন্ত্রে বসানো কম্পিউটার (গাড়ি, router, smart TV)।

মনে রাখার কৌশল ক্ষমতার ক্রম: Micro < Mini < Mainframe < Super। সিগন্যাল অনুসারে: Analog (ধারাবাহিক) · Digital (0/1) · Hybrid (দুটোই)।

BIOS = Basic Input/Output System — মাদারবোর্ডের ROM-এ রাখা firmware। power-on হলে: (১) POST (Power-On Self-Test) চালিয়ে RAM, keyboard, disk পরীক্ষা করে; (২) হার্ডওয়্যার initialise করে; (৩) boot device খুঁজে bootloader → OS লোড করে। সেটিংস (boot order, তারিখ, password) CMOS-এ থাকে, ছোট ব্যাটারিতে সচল। সার্ভারে BIOS/UEFI RAID, boot order ও virtualization flag সেট করে — ভুল সেটিং হলে OS লোড হয় না।

Blockchain = block-এর একটি distributed, append-only ledger, প্রতিটি block ডেটা + timestamp + আগের block-এর hash ধরে, বহু node-এ কপি করা। একটি block বদলালে পরের সব hash ভাঙে, তাই এটি tamper-evident; consensus (PoW/PoS) নতুন block যোগ করে। সুবিধা: decentralised, স্বচ্ছ, immutable, নিরাপদ, মধ্যস্বত্বভোগী নেই। ব্যবহার: cryptocurrency, smart contract, supply chain, ভূমি রেকর্ড, e-voting।

Nanotechnology = 1–100 nm (পারমাণবিক/আণবিক স্কেল)-এ পদার্থ প্রকৌশল। ব্যবহার: চিকিৎসা (targeted drug delivery), ইলেকট্রনিক্স (ছোট chip), উপাদান (শক্ত/হালকা), শক্তি, পানি পরিশোধন। IR 4.0 (চতুর্থ শিল্প বিপ্লব) ভৌত, ডিজিটাল ও জৈবিক জগৎ একীভূত করে; মূল উপাদান: AI, IoT, Big Data, cloud, robotics/automation, cyber-physical system, 3D printing, AR/VR। IR 1–3 (বাষ্প, বিদ্যুৎ, কম্পিউটার)-এর চেয়ে IR 4.0-এর পরিবর্তন সূচকীয় ও আন্তঃসংযুক্ত। Quantum computer qubit ব্যবহার করে (superposition + entanglement) → ব্যাপক সমান্তরাল, সাধারণ কম্পিউটারের নির্দিষ্ট 0/1 bit-এর বিপরীতে।

ই-গভর্নেন্স = সরকারি সেবা প্রদান ও স্বচ্ছতা/দক্ষতা বাড়াতে ICT ব্যবহার; চার প্রকার: G2C (নাগরিক), G2B (ব্যবসা), G2G (সরকার–সরকার), G2E (কর্মচারী)। Smart Bangladesh (Vision 2041) Digital Bangladesh-এর উপর গড়ে চার স্তম্ভ: Smart Citizen, Smart Economy, Smart Government, Smart Society। Digital Bangladesh চ্যালেঞ্জ: অবকাঠামো ও বিদ্যুৎ, সামর্থ্য, ডিজিটাল সাক্ষরতা, সাইবার নিরাপত্তা, local content, ডিজিটাল বিভাজন।

MIS (Management Information System) ডেটাকে ব্যবস্থাপকদের সিদ্ধান্তের রিপোর্টে রূপান্তর করে। বাংলাদেশে MIS চ্যালেঞ্জ: দুর্বল ডেটা মান, দক্ষ জনবলের অভাব, পরিবর্তনে অনীহা, দুর্বল অবকাঠামো, উচ্চ খরচ, সিস্টেমের মধ্যে integration নেই, ডেটা-নিরাপত্তা ঘাটতি। আধুনিক জীবনে ইন্টারনেট: শিক্ষা, ই-কমার্স, ব্যাংকিং (MFS), স্বাস্থ্য (telemedicine), সরকারি সেবা, যোগাযোগ, remote work/freelancing, বিনোদন।
