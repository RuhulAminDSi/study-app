AI · Modern ML & GenAITypes of Machine Learning

1 Machine Learning & Its Three Types ★ always asked

Definition Machine Learning (ML) is the branch of AI in which a system learns patterns from data and improves with experience, instead of being explicitly programmed with rules. AI ⊃ ML ⊃ Deep Learning.
TypeLearns fromAlgorithmsExamples
Supervisedlabelled (x, y)regression, SVM, tree, KNNspam filter, fraud
Unsupervisedunlabelled xK-means, PCA, Aprioricustomer segments
Reinforcementreward signalQ-learningAlphaGo, robots
Self-supervisedlabels made from datanext-token predictionLLM pre-training
Memory trick Teacher · Explorer · Player: supervised has a teacher (labels), unsupervised is an explorer (groups it finds itself), reinforcement is a game player (score = reward).
Transfer learning Take a pre-trained model (trained on a huge dataset) and fine-tune it on a small task-specific dataset. Saves data, time and GPU cost. e.g. BERT → fine-tuned for Bangla sentiment analysis; an ImageNet CNN → X-ray classifier.
Exam trap Classification & regression = supervised; clustering = unsupervised. K-means ≠ KNN: K-means clusters unlabelled data; KNN classifies using labelled neighbours.
Worked example Classify: (i) house price from size → supervised (regression); (ii) grouping mobile-banking users by behaviour → unsupervised; (iii) traffic-signal timing that learns from queue lengths → reinforcement; (iv) flagging fraud from past labelled cases → supervised (classification).

AI · Modern ML & GenAIArtificial Neural Network

2 ANN, Backpropagation & Gradient Descent ★ top cluster

ANN A computational model inspired by biological neurons: input layer → hidden layer(s) → output layer. Every connection carries a weight; each neuron adds a bias and applies an activation function. Training = finding weights that minimise the loss.
  1. Forward pass: inputs flow layer by layer to give the prediction ŷ.
  2. Loss: compare ŷ with true y (MSE / cross-entropy).
  3. Backpropagation: the chain rule sends the error backwards and gives ∂L/∂w for every weight.
  4. Gradient descent: step each weight against its gradient; repeat for many epochs.
Worked example x₁=1, x₂=0, w₁=0.5, w₂=0.3, b=0.1, sigmoid. z = 0.5×1 + 0.3×0 + 0.1 = 0.6; σ(0.6) = 1/(1+e−0.6) = 1/(1+0.549) ≈ 0.646.
PointANNBNN (brain)
Unitartificial neuron (maths)biological neuron (~86 billion)
Signalnumbers, digitalelectrochemical spikes
Learningbackpropagation updates weightssynaptic plasticity (Hebbian)
Speed / powerfast per op, high energy (GPU)slow neurons, ~20 W, massively parallel
Memory trick F-L-B-U: Forward · Loss · Backward · Update. Backprop finds the gradient; GD uses it. η too large → diverges; too small → slow.
Exam trap "Which model uses backpropagation: MLP / CNN / RNN?" → All of the above.

AI · Modern ML & GenAIActivation Functions

3 Activation Functions ★ written favourite

Why needed An activation function adds non-linearity. Without it every layer is linear and the whole deep net collapses into one linear map: W₂(W₁x) = (W₂W₁)x, so depth gives nothing. It also squashes outputs into a useful range (probability, ±1).
FunctionFormulaRangeBest useWeak point
Sigmoid σ1 / (1 + e−x)(0, 1)binary output (probability)vanishing gradient (σ′ ≤ 0.25)
Tanh(ex − e−x)/(ex + e−x)(−1, 1)hidden layers, RNN; zero-centredstill saturates
ReLUmax(0, x)[0, ∞)default for hidden layers; fast"dying ReLU" (stuck at 0)
Leaky ReLUmax(0.01x, x)(−∞, ∞)fixes dying ReLUextra hyper-parameter
Softmaxezᵢ / Σ ezⱼ(0, 1), Σ = 1multiclass output layeroutput layer only
Linearf(x) = x(−∞, ∞)regression outputno non-linearity
Worked example Softmax of z = [2, 1, 0]: e² = 7.389, e¹ = 2.718, e⁰ = 1, sum = 11.107 → [0.665, 0.245, 0.090], total = 1. ReLU(−3) = 0, ReLU(2.5) = 2.5; σ(0) = 0.5; tanh(0) = 0.
Memory trick Sigmoid = Single yes/no; Softmax = Several classes; Tanh = Two-sided (±1); ReLU = Ramp.
Exam trap Sigmoid range is (0, 1), not (−1, 1), which is tanh. Deep nets prefer ReLU in hidden layers because its gradient is 1 for x > 0, so it largely avoids the vanishing gradient problem.

AI · Modern ML & GenAIDeep Learning Architectures

4 Deep Learning: CNN · RNN · Transformer ★ MCQ magnet

Deep learning ML with many hidden layers that learn features automatically from raw data (pixels, words, audio). Needs large datasets and GPUs. Excels on unstructured data.
ModelDataKey ideaUses
CNNimages, gridsshared filters slide over input; poolingface/object recognition, X-ray
RNNsequences, time-serieshidden state carries memory of past stepsforecasting, speech
LSTMlong sequences3 gates: forget, input, output; fixes vanishing gradientstock series, translation
GRUsequences2 gates: update, reset; lighter LSTMsame as LSTM
Transformertext, also imagesself-attention over all positions at once; parallel; positional encodingBERT, GPT, LLMs
Worked example 32×32 image, 5×5 filter, stride 1, no padding: output = (N − F + 2P)/S + 1 = (32 − 5 + 0)/1 + 1 = 28×28; then 2×2 max-pool → 14×14.
Memory trick CNN = Camera; RNN = Remembers order; Transformer = looks at the whole Text at once. Attention(Q,K,V) = softmax(QKᵀ/√dk)·V.
Exam trap "Best for time-series: CNN / RNN / DNN / ANN?" → RNN (LSTM if offered). Transformers replaced RNNs in NLP because they process tokens in parallel; BERT = encoder, GPT = decoder.

AI · Modern ML & GenAILarge Language Models

5 LLMs, RAG, Hallucination & Prompting ★ rising fast

LLM A Large Language Model is a Transformer-based neural network trained on massive text to understand and generate language. It works on tokens (word pieces) and repeatedly predicts the next token. Examples: GPT (OpenAI), Claude (Anthropic), Gemini (Google), LLaMA (Meta). Uses: chatbots, summarising, translation, code.
  1. Pre-training: self-supervised next-token prediction on web-scale text.
  2. Fine-tuning: instruction / task data.
  3. Alignment: human feedback (RLHF) for helpful, safe answers.
Key terms token = unit of text; context window = max tokens seen at once; temperature = randomness (low = focused); embedding = text as a vector.
Hallucination The model produces fluent, confident but false content (fake citations, wrong dates). Cause: it predicts plausible text, with no built-in fact check. Mitigation: RAG, fine-tuning on verified data, citing sources, confidence flags, human review for high-stakes answers.
Prompting techniqueWhat you giveExample
Zero-shotinstruction only"Classify this complaint as tax / land / other."
Few-shota few solved examples first3 labelled complaints, then the new one
Chain-of-thoughtask for step-by-step reasoning"Work out the VAT step by step."
Role promptingassign a persona"You are an NBR help-desk officer…"
Memory trick Plain LLM = closed-book exam (answers from memory, may bluff). RAG = open-book exam (looks up the page first, then writes).
Exam trap RAG does not retrain the model (fine-tuning changes weights; RAG only adds context), and it reduces, not eliminates hallucination. Hallucination is a by-product of pattern-based generation, not a coding bug.

AI · Modern ML & GenAIGenerative AI & Explainable AI

6 Generative AI: GANs & Diffusion; XAI ★ bank written

Generative AI AI that creates new content: text (LLMs), images (Stable Diffusion, DALL-E, Midjourney), audio, video, code, synthetic data. A discriminative model learns P(y | x) to label data; a generative model learns P(x) to make new samples.
ModelHow it generatesKnown for
GANGenerator vs Discriminator, trained adversariallyfaces, deepfakes
Diffusionstart from noise, denoise step by stepStable Diffusion, DALL-E
VAEencode to latent space, decode samplessmooth variations
LLMTransformer, next-token predictiontext, code, chat
XAI Explainable AI shows why a model gave an output: needed for loans, diagnosis, public services, audit. LIME (Local Interpretable Model-agnostic Explanations) perturbs one input and fits a simple local model. SHAP (SHapley Additive exPlanations) uses game-theory Shapley values to give each feature a signed contribution. Saliency maps / Grad-CAM highlight image regions.
Memory trick GAN = forger vs police. LIME = Local; SHAP = SHapley. Check: 0.50 + 0.15 + 0.10 − 0.30 − 0.05 = 0.40.
Exam trap The Discriminator judges real vs fake; the Generator never sees real data, it learns only from the Discriminator's feedback. Generative AI is not only chatbots.

AI · Modern ML & GenAIAgentic AI · Overfitting

7 Agentic AI vs Chatbot; Over- & Underfitting ★ BUET favourite

Agentic AI An AI system that takes a goal, plans the steps, uses tools (web search, code execution, APIs, databases), observes results, keeps memory and self-corrects until the goal is met, with minimal human help. Core: an LLM as the reasoning engine + tools + memory + an orchestration loop.
DimensionTraditional chatbotAgentic AI
Logicrules / scripts, FAQ matchingLLM reasoning + planning
Turnssingle question → answermulti-step, goal-directed
Memorynone across sessionsshort + long-term memory
Toolsnonesearch, code, APIs, files
Self-correctionnoyes: reflect, retry
Riskwrong canned answerhallucination chains, tool misuse, endless loops
Train errorTest errorRemedies
Overfittingvery lowhighmore data, L1/L2 regularisation, dropout, early stopping, cross-validation, augmentation, simpler model
Underfittinghighhighbigger model, better features, train longer, less regularisation
Memory trick Overfit = student who memorised last year's guide and fails new questions; underfit = student who did not study and fails both.
Exam trap Overfitting = high variance, low bias; underfitting = high bias, low variance. Dropout fights overfitting, never underfitting.

AI · Modern ML & GenAIEvaluation Metrics

8 Confusion Matrix, Precision, Recall, F1 ★ numerical

Confusion matrix A table of predicted vs actual classes. TP = positive predicted positive; FP = negative wrongly flagged (false alarm, Type I); FN = positive missed (Type II); TN = negative correctly left alone.
MetricFormulaQuestion it answers
Accuracy(TP + TN) / totalhow many predictions were right?
PrecisionTP / (TP + FP)of those flagged positive, how many were truly positive?
Recall (sensitivity, TPR)TP / (TP + FN)of the real positives, how many did we catch?
Specificity (TNR)TN / (TN + FP)of the real negatives, how many were left alone?
F1-score2PR / (P + R)harmonic mean: balances P and R
Worked example Fraud model, 1000 transactions: TP = 80, FP = 20, FN = 10, TN = 890.
  • Accuracy = (80 + 890)/1000 = 0.97
  • Precision = 80/(80 + 20) = 0.80; Recall = 80/(80 + 10) = 80/90 = 0.889
  • F1 = 2 × 0.80 × 0.889 / (0.80 + 0.889) = 1.422 / 1.689 ≈ 0.842; Specificity = 890/910 ≈ 0.978
Memory trick Precision looks at the Predicted-positive row; Recall looks at the Real-positive column. Precision matters when false alarms cost (spam filter); recall matters when misses cost (cancer, fraud).
Exam trap Accuracy paradox: a model that always says "not fraud" on the same data gets TP = 0, FN = 90, TN = 910 → accuracy 91% but recall 0. On imbalanced data report precision, recall, F1 or AUC, not accuracy alone.
