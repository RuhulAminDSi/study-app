সংজ্ঞা মেশিন লার্নিং (Machine Learning, ML) হলো AI-এর সেই শাখা যেখানে system নিয়ম দিয়ে explicitly programmed না হয়ে data থেকে pattern শেখে এবং অভিজ্ঞতায় উন্নত হয়। AI ⊃ ML ⊃ Deep Learning।

স্মৃতি-কৌশল শিক্ষক · অভিযাত্রী · খেলোয়াড়: supervised-এর আছে শিক্ষক (লেবেল), unsupervised হলো অভিযাত্রী (নিজেই দল খুঁজে নেয়), reinforcement হলো গেমের খেলোয়াড় (স্কোর = reward)।
Transfer learning বিশাল dataset-এ trained একটি pre-trained model নিয়ে ছোট, নির্দিষ্ট কাজের dataset-এ fine-tune করা। Data, সময় ও GPU খরচ বাঁচে। যেমন: BERT → বাংলা sentiment analysis-এর জন্য fine-tune; ImageNet CNN → X-ray classifier।
পরীক্ষার ফাঁদ Classification ও regression = supervised; clustering = unsupervised। K-means ≠ KNN: K-means লেবেলহীন data-কে cluster করে; KNN লেবেলসহ প্রতিবেশী দেখে classify করে।
উদাহরণ শ্রেণি নির্ণয়: (১) আয়তন থেকে বাড়ির দাম → supervised (regression); (২) আচরণ অনুযায়ী মোবাইল ব্যাংকিং গ্রাহকদের দলে ভাগ → unsupervised; (৩) গাড়ির সারি দেখে শিখে নেওয়া ট্রাফিক সিগন্যাল → reinforcement; (৪) আগের লেবেলসহ ঘটনা থেকে fraud শনাক্ত → supervised (classification)।

AI · আধুনিক ML ও GenAIকৃত্রিম নিউরাল নেটওয়ার্ক

২ ANN, Backpropagation ও Gradient Descent ★ শীর্ষ ক্লাস্টার

ANN জৈব নিউরন দ্বারা অনুপ্রাণিত একটি গাণিতিক মডেল: input layer → hidden layer(s) → output layer। প্রতিটি সংযোগে একটি weight থাকে; প্রতিটি নিউরন একটি bias যোগ করে ও activation function প্রয়োগ করে। Training = loss সর্বনিম্ন করে এমন weight খোঁজা।
  1. Forward pass: input স্তরে স্তরে এগিয়ে prediction ŷ দেয়।
  2. Loss: ŷ-কে আসল y-এর সঙ্গে তুলনা (MSE / cross-entropy)।
  3. Backpropagation: chain rule দিয়ে error পেছনে পাঠিয়ে প্রতিটি weight-এর ∂L/∂w বের করে।
  4. Gradient descent: gradient-এর বিপরীতে প্রতিটি weight একটু সরাও; বহু epoch ধরে চলে।
উদাহরণ x₁=1, x₂=0, w₁=0.5, w₂=0.3, b=0.1, sigmoid। z = 0.5×1 + 0.3×0 + 0.1 = 0.6; σ(0.6) = 1/(1+e−0.6) = 1/(1+0.549) ≈ 0.646।

সংকেতসংখ্যা, digitalelectrochemical spike

স্মৃতি-কৌশল F-L-B-U: Forward · Loss · Backward · Update। Backprop gradient খুঁজে বের করে; GD সেটা ব্যবহার করে। η খুব বড় → diverge; খুব ছোট → ধীর।
পরীক্ষার ফাঁদ "কোন মডেল backpropagation ব্যবহার করে: MLP / CNN / RNN?" → সবগুলো (All of the above)।

৩ Activation Function ★ লিখিত প্রশ্নে প্রিয়

কেন দরকার Activation function non-linearity যোগ করে। এটি না থাকলে প্রতিটি layer linear, ফলে পুরো deep net একটি linear map-এ পরিণত হয়: W₂(W₁x) = (W₂W₁)x, অর্থাৎ গভীরতার কোনো লাভ নেই। এটি output-কে কাজের পরিসরেও আনে (probability, ±1)।
Functionসূত্রপরিসরসেরা ব্যবহারদুর্বলতা
Sigmoid σ1 / (1 + e−x)(0, 1)binary output (probability)vanishing gradient (σ′ ≤ 0.25)
Tanh(ex − e−x)/(ex + e−x)(−1, 1)hidden layer, RNN; zero-centredএটিও saturate করে
ReLUmax(0, x)[0, ∞)hidden layer-এর default; দ্রুত"dying ReLU" (0-তে আটকে)
Leaky ReLUmax(0.01x, x)(−∞, ∞)dying ReLU সারায়বাড়তি hyper-parameter
Softmaxezᵢ / Σ ezⱼ(0, 1), Σ = 1multiclass output layerশুধু output layer-এ

উদাহরণ z = [2, 1, 0]-এর softmax: e² = 7.389, e¹ = 2.718, e⁰ = 1, যোগফল = 11.107 → [0.665, 0.245, 0.090], মোট = 1। ReLU(−3) = 0, ReLU(2.5) = 2.5; σ(0) = 0.5; tanh(0) = 0।
স্মৃতি-কৌশল Sigmoid = Single হ্যাঁ/না; Softmax = Several class; Tanh = Two-sided (±1); ReLU = Ramp (ঢাল)।
পরীক্ষার ফাঁদ Sigmoid-এর পরিসর (0, 1); (−1, 1) হলো tanh-এর। Deep net-এর hidden layer-এ ReLU বেশি চলে, কারণ x > 0 হলে এর gradient 1, তাই vanishing gradient সমস্যা অনেকটা এড়ায়।

৫ LLM, RAG, Hallucination ও Prompting ★ দ্রুত বাড়ছে

LLM Large Language Model হলো বিপুল text-এ trained Transformer-ভিত্তিক neural network, যা ভাষা বোঝে ও তৈরি করে। এটি token (শব্দাংশ) নিয়ে কাজ করে এবং বারবার পরের token অনুমান করে। উদাহরণ: GPT (OpenAI), Claude (Anthropic), Gemini (Google), LLaMA (Meta)। ব্যবহার: chatbot, সারাংশ, অনুবাদ, code।
  1. Pre-training: web-আকারের text-এ self-supervised next-token prediction।
  2. Fine-tuning: instruction / কাজভিত্তিক data।
  3. Alignment: মানুষের feedback (RLHF), যাতে উত্তর সহায়ক ও নিরাপদ হয়।
মূল শব্দ token = text-এর একক; context window = একবারে সর্বোচ্চ কত token দেখে; temperature = এলোমেলোভাব (কম = কেন্দ্রিক); embedding = text-এর vector রূপ।
Hallucination মডেল সাবলীল, আত্মবিশ্বাসী কিন্তু ভুল তথ্য তৈরি করে (ভুয়া উদ্ধৃতি, ভুল তারিখ)। কারণ: এটি সম্ভাব্য text অনুমান করে, নিজস্ব তথ্য-যাচাই নেই। প্রতিকার: RAG, যাচাই করা data-তে fine-tuning, উৎস উল্লেখ, confidence flag, গুরুত্বপূর্ণ উত্তরে মানুষের পর্যালোচনা।
Prompting কৌশলকী দিতে হয়উদাহরণ
Zero-shotশুধু নির্দেশনা"অভিযোগটি কর / ভূমি / অন্যান্য হিসেবে ভাগ করো।"
Few-shotআগে কয়েকটি সমাধান-করা উদাহরণ৩টি লেবেলসহ অভিযোগ, তারপর নতুনটি
Chain-of-thoughtধাপে ধাপে যুক্তি চাওয়া"VAT ধাপে ধাপে হিসাব করো।"
Role promptingএকটি ভূমিকা দেওয়া"তুমি NBR help-desk কর্মকর্তা…"
স্মৃতি-কৌশল সাধারণ LLM = বই-বন্ধ পরীক্ষা (মুখস্থ থেকে লেখে, বানিয়েও ফেলতে পারে)। RAG = বই-খোলা পরীক্ষা (আগে পাতা দেখে, তারপর লেখে)।
পরীক্ষার ফাঁদ RAG মডেলকে নতুন করে train করে না (fine-tuning weight বদলায়; RAG শুধু context যোগ করে), এবং hallucination কমায়, দূর করে না। Hallucination pattern-ভিত্তিক generation-এর স্বাভাবিক ফল, coding bug নয়।

৬ Generative AI: GAN ও Diffusion; XAI ★ ব্যাংক লিখিত

Generative AI যে AI নতুন content তৈরি করে: text (LLM), ছবি (Stable Diffusion, DALL-E, Midjourney), audio, video, code, synthetic data। Discriminative মডেল P(y | x) শিখে data-কে লেবেল দেয়; generative মডেল P(x) শিখে নতুন নমুনা তৈরি করে।
মডেলকীভাবে তৈরি করেপরিচিত যে কাজে

XAI Explainable AI দেখায় মডেল কেন একটি output দিল: ঋণ, রোগনির্ণয়, সরকারি সেবা ও audit-এ জরুরি। LIME (Local Interpretable Model-agnostic Explanations) একটি input একটু বদলে বদলে তার চারপাশে সরল local মডেল বসায়। SHAP (SHapley Additive exPlanations) game theory-র Shapley value দিয়ে প্রতিটি feature-এর ধনাত্মক/ঋণাত্মক অবদান দেয়। Saliency map / Grad-CAM ছবির গুরুত্বপূর্ণ অংশ দেখায়।
স্মৃতি-কৌশল GAN = জালিয়াত বনাম পুলিশ। LIME = Local; SHAP = SHapley। যাচাই: 0.50 + 0.15 + 0.10 − 0.30 − 0.05 = 0.40।
পরীক্ষার ফাঁদ Discriminator আসল-নকল বিচার করে; Generator কখনো আসল data দেখে না, শুধু Discriminator-এর feedback থেকে শেখে। Generative AI শুধু chatbot নয়।

৮ Confusion Matrix, Precision, Recall, F1 ★ গাণিতিক

Confusion matrix অনুমিত বনাম আসল class-এর একটি সারণি। TP = positive-কে positive বলা; FP = negative-কে ভুলে positive বলা (মিথ্যা সতর্কতা, Type I); FN = positive ধরা না পড়া (Type II); TN = negative-কে ঠিকভাবে negative বলা।
মেট্রিকসূত্রযে প্রশ্নের উত্তর দেয়
Accuracy(TP + TN) / totalকতগুলো অনুমান ঠিক হলো?
PrecisionTP / (TP + FP)যাদের positive বলা হলো, তাদের কতজন সত্যি positive?
Recall (sensitivity, TPR)TP / (TP + FN)আসল positive-দের কতজনকে ধরা গেল?
Specificity (TNR)TN / (TN + FP)আসল negative-দের কতজনকে ঠিক ছাড়া হলো?
F1-score2PR / (P + R)harmonic mean: P ও R-এর ভারসাম্য
উদাহরণ Fraud মডেল, ১০০০টি লেনদেন: TP = 80, FP = 20, FN = 10, TN = 890।
  • Accuracy = (80 + 890)/1000 = 0.97
  • Precision = 80/(80 + 20) = 0.80; Recall = 80/(80 + 10) = 80/90 = 0.889
  • F1 = 2 × 0.80 × 0.889 / (0.80 + 0.889) = 1.422 / 1.689 ≈ 0.842; Specificity = 890/910 ≈ 0.978
স্মৃতি-কৌশল Precision দেখে Predicted-positive সারি; Recall দেখে Real-positive কলাম। মিথ্যা সতর্কতা ব্যয়বহুল হলে precision জরুরি (spam filter); কেউ ফসকে গেলে ক্ষতি বেশি হলে recall জরুরি (ক্যান্সার, fraud)।
পরীক্ষার ফাঁদ Accuracy paradox: একই data-তে যে মডেল সবসময় "fraud নয়" বলে, তার TP = 0, FN = 90, TN = 910 → accuracy 91% কিন্তু recall 0। ভারসাম্যহীন data-তে শুধু accuracy নয়, precision, recall, F1 বা AUC দেখাও।
