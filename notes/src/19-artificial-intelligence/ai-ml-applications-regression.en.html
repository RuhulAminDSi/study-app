1ML in Practice: Pipeline & Task

framing ★
Definition A machine-learning system is a function fitted to data, not a bundle of hand-written rules. Given input features X, produce an output y — and the kind of output decides the method: a number is regression, a label is classification, a group is clustering, rewards after actions is reinforcement learning.
TaskOutputTypical methodOne-line example
Regressionreal number ŷlinear / polynomial regression, SVR, GBMtomorrow's sales
Classificationlabel + probabilitylogistic regression, decision tree, SVM, CNNspam or not spam
Clusteringa group idk-means, hierarchical, DBSCANcustomer segments
Reinforcementa policyQ-learning, SARSA, DQNa robot learning to walk
Memory trick One question — "is the answer a ruler or a yes/no?" Ruler → regression. Yes/no → classification. Neither → grouping or rewards after acting.
Exam trap "ML predicts the future" is wrong: ML fits a function to past data and extrapolates. The test set must stay unseen.
Worked example 1 ✍ label the task (i) predict the sale price of a flat → regression; (ii) decide whether a transaction is fraudulent → classification; (iii) group ATMs by usage pattern, no labels → clustering; (iv) an agent trades and is paid or fined → reinforcement learning.
Worked example 2 ✍ same data, two models A bank wants the probability of default (logistic regression → a number in 0…1) and, once the loan is approved, the expected loss in taka (linear regression). One table, two targets.
Why deployment is hard Offline 0.92 can still fail in production once the input distribution moves — that is model drift.
What a feature is One input column — floor area, age, RMS, a word of the text. A numeric input is what a regressor wants.

most asked ★

Memory trick Read the output word in the stem: price, demand, temperature, amount, risk score → regression; spam, fraud, disease, default, defect → classification; segment, group, cluster → unsupervised. The words rank or recommend mean the model sorts rather than predicts.

Worked example ✍ choosing the metric Fraud data: 99 900 normal, 100 fraudulent. A model answering "normal" for everything scores 99.9 % accuracy and finds zero fraud. The honest scores are recall on the fraud class and the false positives an analyst must clear per day.

AI · ML Applications & RegressionRegression

4Regression & the Model y = mx + c

core definition ★
Definition Regression is supervised learning for a continuous numerical output. With one feature it is the simple linear regression line ŷ = m x + c: m is the slope (change in ŷ per unit x), c the intercept (ŷ when x = 0). With p features it becomes multiple linear regression: ŷ = β₀ + β₁x₁ + … + βpxp + ε.
c is ŷ at x = 0, nothing more
Point of comparisonRegressionClassification
Outputany real number, unboundedone of a fixed label set
Typical losssquared error (MSE), MAEcross-entropy, 0–1 loss
Typical scoresMAE, MSE, RMSE, R²accuracy, precision, recall, F1
Baseline to beatpredict the mean of ypredict the majority class
Symbolic formŷ = mx + cP(Y=1|X) = 1/(1 + e−z)
Exampleshouse price, temperaturespam or not spam
Derivation sketch ✍ why the line passes through (x̄, ȳ)
  1. Least squares picks m, c so the vertical errors are smallest
  2. Both derivatives zero ⟹ Σŷ = Σy ⟹ c = ȳ − m x̄, so the line always threads (x̄, ȳ)
The two numbers you need m = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²  ·  c = ȳ − m x̄, and m = r · σy/σx takes the sign of r.
Memory trick "m moves, c anchors." m answers how much does ŷ change when x rises by 1?; c answers what is ŷ at x = 0? The fitted line always threads the mean point (x̄, ȳ) — the fastest way to see whether a candidate answer is plausible.
Exam trap (i) The intercept is ŷ at x = 0, not the mean of y. (ii) Logistic regression is classification despite the name. (iii) A best-fit line is not required to pass through the origin. (iv) Regression needs no balanced class structure.
Worked example ✍ read the model, then predict A flat-price model in lakh BDT is ŷ = 18.5 + 3.2 × (area in m²). For 90 m², ŷ = 18.5 + 288 = 306.5 lakh. Each extra m² adds 3.2 lakh (m = 3.2), while a zero-area plot would be valued at 18.5 lakh (c = 18.5) — really the price of the land and registration.

5Least Squares (OLS)

derivable ★
Definition Ordinary least squares (OLS) chooses the coefficients that minimise the sum of squared residuals: minimise SSE = Σ(yᵢ − ŷᵢ)² over every training point. Counting wrong answers belongs to classification; OLS never counts — it squares and adds.
Derivation ✍ the normal equations
  1. Objective: SSE(a, b) = Σ(yᵢ − a − b xᵢ)²
  2. Partials zero: ∂SSE/∂a = −2Σ(yᵢ − a − b xᵢ) = 0 and ∂SSE/∂b = −2Σxᵢ(yᵢ − a − b xᵢ) = 0
  3. Two normal equations: na + b Σx = Σy and a Σx + b Σx² = Σxy
  4. Solving: b = [nΣxy − (Σx)(Σy)] / [nΣx² − (Σx)²], a = ȳ − b x̄

Answer for (1, 2), (2, 4), (3, 5) n = 3, Σx = 6, Σy = 11, Σxy = 25, Σx² = 14 ⟹ b = [3(25) − 6(11)] / [3(14) − 6²] = (75 − 66) / (42 − 36) = 9/6 = 1.5 and a = 11/3 − 1.5(2) = 2/3 ≈ 0.67, so ŷ = 0.67 + 1.5x.
Memory trick "One line, Least Squares, so the Sum is what shrinks." Check the giveaway: on a correct OLS fit the residuals sum to zero and the fitted values sum to the actuals, because the line passes through (x̄, ȳ).
Exam trap OLS is called ordinary because it weights every point equally — weighted least squares is the variant that does not. Squaring means one huge residual dominates, so with outliers use MAE-fitting, Huber loss or quantile regression.

6MAE, MSE, RMSE and R²

MCQ staple ★
Definition Every metric is built from the residual eᵢ = yᵢ − ŷᵢ. MAE and MSE average the error in two different ways, RMSE is simply MSE brought back into the units of y, and R² compares the model against the "always predict the mean" baseline.
MetricFormulaProperty and when to use it
MAE(1/n) Σ|yᵢ − ŷᵢ|mean absolute error: in the units of y; robust — outliers barely matter
MSE(1/n) Σ(yᵢ − ŷᵢ)²mean squared error: units are y²; punishes large errors much harder; trains the model
RMSE√MSEroot mean squared error: back in the units of y; "off by X units on average"
R²1 − SSres/SStotcoefficient of determination: fraction of variance explained; can be negative; R² = r² for a simple line
Worked example 1 ✍ the OLS fit of sheet 6 residuals −0.167, +0.333, −0.167: MAE = 0.667/3 = 0.222 · MSE = 0.167/3 = 0.0556 · RMSE = √0.0556 = 0.236 in the units of y. SSres = 0.167, SStot = 2.778 + 0.111 + 1.778 = 4.667, so R² = 1 − 0.167/4.667 = 0.964: the line explains 96.4 % of the variation in y.
Relations worth knowing MAE ≤ RMSE always · MSE ≥ MAE², with equality only when every residual has the same size · SStot = SSreg + SSres · R² = SSreg/SStot · adjusted R² = 1 − (1 − R²)(n − 1)/(n − p − 1).
Worked example 2 ✍ one outlier flips MSE Four residuals 10, 10, 10, 10 give MAE = 10, MSE = 100. Change the last to 40: MAE = 17.5, MSE = 475, RMSE = 21.8 — MAE rose 75 %, MSE rose 375 %.
Memory trick "Square, average, root." MSE = average of squares, RMSE = root of that average, so RMSE = √MSE and it shares the units of y. For R²: 1 perfect, 0 = no better than the mean, negative = worse.
Exam trap R² is not a percentage and can be negative. MSE is in y², so only RMSE is readable. MAE is not "more accurate", only differently behaved.

7Overfitting, Bias–Variance, L1/L2

most tested ★
Definition Overfitting is fitting the training data so closely — noise included — that the model fails on unseen data. The symptom is the train–test gap: 99 % on training, 60 % on test, formally high variance. The opposite failure, poor scores on both, is underfitting = high bias.
SymptomTrainTestDiagnosis
memorising noise99%60%overfitting, high variance
model too simple58%55%underfitting, high bias
healthy fit88%86%generalising ✓
MethodPenalty added to the lossEffect on the coefficients
L2 ridgeλ Σβ²shrinks every coefficient, none exactly 0
L1 lassoλ Σ|β|sets some coefficients exactly 0 → feature selection
Elastic Netλ₁Σ|β| + λ₂Σβ²L1's sparsity with L2's stability
Ridge and lasso objective minimise Σ(yᵢ − β₀ − Σβⱼxⱼ)² + λ Σβⱼ² (L2) or + λ Σ|βⱼ| (L1). A bigger λ means heavier shrinkage, more bias and less variance; the intercept β₀ is not penalised.
Memory trick "Lasso zeroes, ridge shrinks." L1's absolute-value penalty is kinked at zero, so a coefficient that is not earning its place is pushed all the way to 0 and its feature is dropped; L2 only ever pulls towards 0.
Exam trap (i) Overfitting is high variance, underfitting is high bias. (ii) A larger λ = more regularisation, more bias, less variance. (iii) Regularisation adds no information. (iv) Only L1 selects features.
Worked example ✍ reading the gap Train 99 %, test 60 % ⟹ a 39-point gap ⟹ overfitting. Fix in order of cost: (1) more data, (2) L2 / L1, (3) cross-validation, (4) a simpler model.
Only a held-out set tells you A test set — or k-fold cross-validation — exposes the gap; a common split is 60 / 20 / 20.

8Polynomial & Correlation ≠ Causation

conceptual ★
Definition Polynomial regression keeps the linear least-squares machinery but adds powers of the feature: ŷ = β₀ + β₁x + β₂x² + … + βnxn. Correlation is the standardised strength of a linear association, Pearson's r = cov(x, y)/(σxσy), and it always lies in [−1, +1].
ModelFormShape and main risk
Linearŷ = mx + cone straight line; cannot bend, so it underfits curved data
Polynomial, degree nŷ = β₀ + β₁x + … + βnxnat most n − 1 turning points; overfits and oscillates between points
Logistic1/(1 + e−z)S-shaped probability in 0…1; classification only, boundary linear in x
Worked example ✍ a line under-fits, a curve nails it Data (0, 1), (1, 3), (2, 7), (3, 13). Second differences are 2, 2 — constant, so the data are exactly quadratic: ŷ = 1 + x + x², SSE = 0. The linear fit gives b = 20/5 = 4, a = 0, so ŷ = 4x with residuals +1, −1, −1, +1: MAE = 1, MSE = 1, R² = 1 − 4/84 = 0.952.
Memory trick A linear fit that is wrong but not random leaves a residual pattern: + − − + is a curve, random signs is noise.
Correlation is not causation r = 0.98 between ice-cream sales and drownings, and neither causes the other: both are driven by a confounding variable — hot weather. r says nothing about direction or non-linearity, and can vanish per individual (Simpson's paradox).
Exam trap (i) r = 0.9 does not prove causation. (ii) r = 0 does not prove independence — it rules out only a linear relation. (iii) For a simple line R² = r² exactly. (iv) A degree-n polynomial bends at most n − 1 times.
Worked example ✍ two coefficients, one data set For the same four points: r = 20/√(5 × 84) = 0.976 and the linear R² = r² = 0.952. Add x² and R² becomes 1.000 while r is unchanged.
