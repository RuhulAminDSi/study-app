2Reinforcement Learning: Policy, Reward, ε-Greedy

The pieces agent · environment · state s · action a · reward r · policy π (state → action: the thing RL learns) · value V(s) and action-value Q(s, a) · discount γ (0 ≤ γ ≤ 1). Goal: maximise the return Gt = rt+1 + γrt+2 + γ²rt+3 + …
MCQ ________ algorithm requires a policy. (supervised learning / fuzzy logic / deep learning / reinforcement learning) → reinforcement learning 49th BCS (ICT-281), 2025
Worked example: one Q-learning update ✍ Rule: Q(s,a) ← Q(s,a) + α[r + γ·maxa′Q(s′,a′) − Q(s,a)]
Q(s, Right) = 2, reward r = 5, in s′ the best Q is 4, α = 0.5, γ = 0.9.
  1. Target = r + γ·max Q(s′) = 5 + 0.9 × 4 = 8.6
  2. TD error = 8.6 − 2 = 6.6
  3. New Q(s, Right) = 2 + 0.5 × 6.6 = 5.3
ε-greedy With probability ε pick a random action (explore); otherwise the action with the highest Q (exploit). With ε = 0.1 and 4 actions the best action is chosen with probability 0.9 + 0.1/4 = 0.925. ε is usually decayed over time.
  • Q-learning: off-policy (learns the greedy policy)
  • SARSA: on-policy (learns the policy it follows)
  • DQN: a neural net approximates Q
  • Uses: games (AlphaGo), robots, trading, ad bidding
Exam trap RL is not unsupervised: the reward grades an action but never states the correct one. Pure exploitation (ε = 0) can lock onto a poor action forever.

3Local Search: Hill Climbing & Random Search

2 MCQs

Hill climbing moves to the best neighbour while it improves; O(1) memory. Drawback: gets stuck in local optima, plateaus and ridges. Fixes: random restarts, simulated annealing (accepts a worse move with probability e−ΔE/T), local beam search.

Random search samples candidates from the whole space and keeps the best one, so it is a global optimisation method: no gradient, cannot be trapped, but slow and never guaranteed optimal. Both MCQs: 49th BCS (ICT-281), 2025.

4Intelligent & Rational Agents

2× written
Q An artificial intelligence agent is an entity that continuously perceives its environment and acts upon it. Explain. BPDB Assistant Engineer (CSE) · 24.02.2023
Agent Anything that perceives its environment through sensors and acts on it through actuators. The agent function maps the percept sequence to an action; agent = architecture + program.
Rational agent For every percept sequence it picks the action expected to maximise its performance measure, given its percepts and built-in knowledge. AI is the study of rational agents.

Rationality depends on: performance measure, prior knowledge, available actions, percept sequence. Rational ≠ omniscient: it maximises expected, not actual, outcome. Task description PEAS, e.g. automated taxi: P = safe, fast, legal trip · E = roads, traffic · A = steering, brake, horn · S = cameras, GPS, speedometer.

Properties: situated in an environment · autonomy (no direct human control) · reactivity (responds to change in time) · pro-activeness (takes initiative toward goals) · social ability (works with humans and agents) · learning.

5Heuristic (A*) vs Blind (BFS) Search

10-mark written
Q Construct a logical argument explaining why a heuristic search (like A*) might be faster than a blind search (like BFS), even if it does not guarantee the absolute perfect path in all cases. 10 marks Bank Assistant Programmer written
  1. Cost = nodes expanded. BFS generates 1 + b + b² + … + bd = O(bd) nodes and stores them all (b = branching factor, d = goal depth).
  2. BFS is blind. It does not know where the goal is, so it expands every node at depth k before depth k + 1: a ripple in all directions.
  3. A* is informed. It expands the node with the smallest f(n) = g(n) + h(n) (g = cost so far, h = estimated cost to goal). Nodes leading away from the goal get a large f and are never expanded.
  1. Smaller effective branching factor. A good h makes b* close to 1, so work ≈ (b*)d, not bd. 8-puzzle, depth 12: blind iterative deepening ≈ 3.6 million nodes; A* (misplaced tiles) 227; A* (Manhattan distance) 73.
  2. Why the path may not be perfect. A* is optimal only if h is admissible (never overestimates; for graph search also consistent: h(n) ≤ c(n, n′) + h(n′)). Practical systems use a stronger, inadmissible h, weighted A* (f = g + w·h, w > 1, cost ≤ w × optimal) or greedy best-first (f = h): far fewer expansions, but the cheapest path may be missed.
  3. Conclusion. The speed comes from the information in h (with h = 0, A* becomes uniform-cost search, i.e. BFS for equal step costs). Trading guaranteed optimality for guidance turns an exponential, unfocused search into a focused one; a near-optimal route in milliseconds (GPS, games, robots) beats a perfect one found too late.
BFSUniform-costGreedy best-firstA*
Orders bydepthg(n)h(n)g(n) + h(n)
Complete?yesyesno (tree search)yes

Exam trap "A* always finds the shortest path" holds only with an admissible h. Its worst case is still exponential and memory is its real limit (hence IDA*, SMA*).
Memory trick g = "gone so far", h = "how far still". Admissible = an optimist: never says the goal is farther than it is.

6High Training, Low Test Accuracy

BUET written
Q What causes high training accuracy but low testing accuracy in a machine learning model, and what are its reasons and mitigation techniques? BUET MSc in CSE · 03.10.2026
Answer: overfitting The model has memorised the training set, noise included, instead of the general pattern: low bias, high variance; the train–test difference is the generalisation gap.
Reasons
  • model too complex (many parameters, deep tree)
  • too little data, or too many features
  • noisy labels and outliers get fitted
  • training for too many epochs
  • test data from a different distribution

Mitigation: ① more data / augmentation ② simpler model, feature selection, tree pruning ③ regularisation: L2 (loss + λΣw²), L1, dropout ④ early stopping on validation loss ⑤ k-fold cross-validation ⑥ ensembles (bagging, random forest) ⑦ clean labels; same distribution for train and test. Underfitting is the opposite: low train and low test accuracy (high bias).

8Agentic AI vs Traditional Chatbots

BUET written
Q What is Agentive AI? Compare Agentive AI with traditional Chatbot AI. BUET MSc in CSE · 03.10.2026
Agentic (agentive) AI An AI system given a goal, not just a prompt, which pursues it with little human supervision: it plans steps, acts through tools (APIs, search, code, databases, e-mail), observes results, keeps memory and corrects itself in a loop until the goal is met. It is usually built around a large language model (LLM).
Building blocks
  • Reasoning: an LLM splits the goal into sub-tasks
  • Planning: steps revised on failure (ReAct: reason → act → observe)
  • Tool use: function calls to APIs, code, databases
  • Memory: context + long-term (vector store)
  • Guardrails: permissions, human approval, audit logs

A traditional chatbot is a reactive question-answer program: rule-based (pattern or intent matching, as in ELIZA, 1966) or an LLM that only replies.

Exam trap Agentic AI is not AGI, and not just "a bigger chatbot": the difference is autonomy + tools + a goal loop.

9Market Basket Analysis: Apriori

DPDC written
Q Which machine learning algorithm is suitable for market basket analysis? Explain the steps involved. DPDC Assistant Manager (ICT) · 27.06.2025
Answer Association-rule mining with the Apriori algorithm (Agrawal & Srikant, 1994), an unsupervised method (FP-Growth is the faster alternative). It finds rules such as {Diaper} → {Beer}: items bought together.
Measures support(X) = count(X) / N · confidence(X → Y) = support(X ∪ Y) / support(X) · lift = confidence / support(Y), > 1 = real association.
Apriori property: every subset of a frequent itemset is frequent, so a candidate with an infrequent subset is pruned without counting.
  1. Fix min_support and min_confidence.
  2. Scan the data, count single items (C1), keep those ≥ min_support → L1.
  3. Join Lk−1 with itself → candidates Ck; prune those with an infrequent (k−1)-subset.
  4. Scan, count Ck, keep ≥ min_support → Lk; repeat 3–4 until Lk = ∅.
  5. From each frequent itemset form rules X → Y; keep confidence ≥ min_confidence, check lift.
Worked example ✍ 5 baskets, min_support = 3 (60%), min_confidence = 70%.
TItems

Memory trick "A rare set makes every bigger set rare": that is the pruning. Uses: shelf layout, cross-selling, bank product bundles.

FP-Growth compresses the baskets into an FP-tree and mines it with only 2 database scans and no candidate generation, so it is faster than Apriori on large data.

11Natural Language Processing

2 MCQs

Pipeline: tokenisation → stop-word removal → stemming / lemmatisation → POS tagging → parsing → semantics.

Word embeddings (Word2Vec, GloVe) map words to dense vectors where similar meanings lie close: king − man + woman ≈ queen.

Main challenge: ambiguity

  • lexical: "bank" (river or money)
  • syntactic: "I saw the man with the telescope"
  • referential: "Rahim told Karim he passed": who?
Memory trick CNN for Camera images, RNN for Recurring sequences; stemming chops ("studies" → "studi"), lemmatisation looks up ("studies" → "study").

13Viva Rapid-Fire (bank IT vivas)

repeats merged

What is AI? → Machines doing tasks that need human intelligence: learning, reasoning, perception, language, decisions. Term: John McCarthy, Dartmouth 1956.

What is ML? → AI that learns patterns from data and improves without explicit programming (shown many bottles, it recognises a new one).

What is deep learning? → ML with many-layer neural networks that learn features themselves.

ML vs DL? → ML: hand-made features, less data, explainable. DL: automatic features, big data + GPU, black box.

Normal vs super AI? → Narrow AI does one task (voice assistant, recommender): all AI today. AGI would match humans; super AI would surpass them in every field: hypothetical.

Autonomous weapons? → Military systems that detect, select and engage targets with little or no human intervention.

How do they work? → Sensors (camera, radar, GPS) → AI/ML recognises the target → decision logic → actuators fire or steer. Issue: accountability, meaningful human control.

Robotics? → Designing, building and programming robots that sense, decide and act with minimal human help.

Robotics in banking? → Cash-sorting machines, document scanning, service robots and chatbots, and RPA bots for rule-based back-office work (KYC checks, reconciliation, reports).

Why Python for AI? → Simple syntax; libraries NumPy, pandas, scikit-learn, TensorFlow, PyTorch, Keras.
