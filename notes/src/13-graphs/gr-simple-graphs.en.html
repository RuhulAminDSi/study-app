Graph · Simple GraphsDefinition & simple vs directed

1What Is a Graph?

definition ★
Definition A graph G is an ordered pair G = (V, E), where V is a non-empty set of vertices (nodes) and E is a set of edges (links). In an undirected graph each edge is an unordered pair {u, v}; in a directed graph (digraph) each edge is an ordered pair (u, v), written u → v.
Simple graph An undirected graph with no loops (an edge from a vertex to itself) and no multiple edges between the same pair of vertices. Every pair of distinct vertices is joined by at most one edge.
Exam trap (i) A loop at vertex v is an edge {v, v} — it breaks simplicity. (ii) Multiple edges between u and v also break simplicity. A graph with either is a multigraph, not a simple graph. (iii) "Simple" does not mean "small" — K₁₀₀ is still a simple graph.
TermUndirectedDirected (digraph)
Edge{u, v} = {v, u}(u, v) ≠ (v, u) in general
Loop{v, v} — forbidden in simple graphs(v, v) — self-loop
Multiple edgeTwo edges {u,v} and {u,v} — forbiddenTwo edges (u,v) and (u,v) — forbidden in simple digraph
Memory trick "Simple = clean." No self-loops, no double edges — just pure connections between distinct vertices. The moment you allow loops or parallel edges, you leave the world of simple graphs and enter multigraphs.
Worked example ✍ is this simple? V={A,B,C}, E={{A,B},{B,C},{C,A},{A,A}}. The edge {A,A} is a loop — so not simple. Remove it and the remaining graph is simple (it is the triangle C₃).

2Subgraphs & Vertex Degrees

foundational ★
Definition A subgraph H of G = (V, E) is a graph H = (V', E') such that V' ⊆ V, E' ⊆ E, and every edge in E' has both endpoints in V'. A spanning subgraph is a subgraph with V' = V (it keeps all vertices but may drop some edges).
ConceptUndirectedDirected
Degree deg(v)# of edges incident to v—
In-degree deg⁻(v)—# of edges entering v
Out-degree deg⁺(v)—# of edges leaving v
Handshaking Lemma — undirected Σ deg(v) = 2|E|. Every edge touches exactly two ends, so it is counted twice in the degree sum. Corollary: the number of odd-degree vertices is always even.
Handshaking Lemma — directed Σ deg⁺(v) = Σ deg⁻(v) = |E|. Every directed edge leaves one vertex and enters another, so total out-degrees = total in-degrees = number of edges.
Memory trick "Every edge has two hands to shake." Count every handshake from each vertex's perspective — each edge is shaken at both ends, so it contributes 2 to the total. Same idea for digraphs: each edge shakes once from the tail and once at the head.
Exam trap (i) Handshaking holds for multigraphs too — the "simple" condition is not needed for the lemma. (ii) A loop in an undirected graph contributes 2 to the degree of its vertex (it touches the vertex at two ends). (iii) Σdeg⁺ = Σdeg⁻ = |E| for digraphs; do not multiply by 2 here.
Worked example ✍ applying Handshaking A simple undirected graph has 12 edges. By the lemma, Σ deg(v) = 2 × 12 = 24. If the graph has 6 vertices, the average degree is 24/6 = 4. Can every vertex have degree 4? Yes — that would be a 4-regular graph on 6 vertices (e.g. the complement of a perfect matching).

Graph · Simple GraphsWalks, trails, paths, cycles

3Walks, Trails, Paths & Cycles

terminology ★
Definition Given a graph G, a walk of length k is a sequence v₀, e₁, v₁, e₂, …, eₖ, vₖ where each eᵢ joins vᵢ₋₁ and vᵢ. Vertices and edges may repeat. A trail is a walk with no repeated edge (vertices may repeat). A path (or simple path) is a walk with no repeated vertex — hence no repeated edge automatically. A cycle is a path that starts and ends at the same vertex; for a simple graph the length must be ≥ 3.

Every path is a trail is a walk. Not every walk is a trail; not every trail is a path.

Exam trap (i) "Path" in everyday language means any route; in graph theory it means no repeated vertex. (ii) A cycle must have length ≥ 3 in a simple graph — two vertices with two edges between them (a multigraph) would be a cycle of length 2, but that is impossible in a simple graph. (iii) A single vertex with a self-loop is not a cycle in a simple graph (loops are forbidden).
Memory trick "No vertex repeated = path; no edge repeated = trail; both allowed = walk; closed path = cycle." Remember: path is the strictest common type; cycle is a path that returns home.

k-Regular graph A graph where every vertex has the same degree k. Kₙ is (n−1)-regular. Cₙ is 2-regular. Kn,n is n-regular. For a k-regular graph on n vertices, |E| = nk/2, so nk must be even.

Memory trick "K gets all connections, C makes a ring, P draws a line." Kₙ: everyone shakes hands with everyone. Cₙ: stand in a circle holding hands. Pₙ: stand in a queue.

5Bipartite & Regular Graphs

Kₘ,ₙ ★
Definition A bipartite graph has its vertices partitioned into two sets V₁ and V₂ such that every edge joins a vertex in V₁ to one in V₂ — no edge joins two vertices within the same set. A complete bipartite graph Km,n joins every vertex of V₁ to every vertex of V₂.
PropertyKm,n
|V|m + n
|E|m × n
Degree of v ∈ V₁n
Degree of v ∈ V₂m
Regular?Only when m = n (then n-regular)
k-Regular graph A graph where every vertex has the same degree k. Kₙ is (n−1)-regular. Cₙ is 2-regular. Kn,n is n-regular. For a k-regular graph on n vertices, |E| = nk/2, so nk must be even.
König's theorem A graph is bipartite if and only if it has no odd cycle. Equivalently: G is bipartite ⟺ every cycle in G has even length. Odd cycle present ⟹ not bipartite; all cycles even ⟹ bipartite.
Exam trap (i) C₄ (square) is bipartite — vertices alternate between the two sets. C₅ (pentagon) is not bipartite — going around forces one vertex into both sets. (ii) K2,3 is bipartite but not regular (degrees are 3 and 2). (iii) Kn is bipartite only for n ≤ 2 — K₃ already contains a 3-cycle.
Memory trick "Even cycle = bipartite; odd cycle = not." Check any cycle: if all are even-length, the graph is bipartite. One odd cycle destroys bipartiteness entirely.

6Graph Representation

practical ★
Definition A graph must be stored in some data structure. Three standard representations trade off space, lookup speed, and ease of traversal. The choice depends on whether the graph is dense (|E| ≈ |V|²) or sparse (|E| ≪ |V|²).

Exam trap (i) For a directed graph, the adjacency matrix need not be symmetric: M[i][j]=1 means i→j, not j→i. (ii) Adjacency matrix uses V² space even for sparse graphs — avoid for large sparse graphs. (iii) Self-loops: matrix diagonal entry = 1 (undirected) or 1 per loop direction (directed). (iv) Multiple edges: adjacency matrix cannot represent them — use adjacency list with counts.
Memory trick "Matrix is square, list is lean." O(V²) space is the matrix's liability; O(V+E) is the list's strength. For dense graphs the difference shrinks; for sparse graphs the list wins hands down.

7Degree Sequences & Handshaking Applications

Havel-Hakimi ★
Definition The degree sequence of a graph is the list of vertex degrees written in non-increasing order, e.g. (3, 3, 2, 2, 1, 1). A sequence that can be realised as the degree sequence of some simple graph is called graphical.
Havel-Hakimi algorithm To test whether a sequence d = (d₁, d₂, …, dₙ) is graphical:
1. Sort in non-increasing order.
2. Remove d₁ and subtract 1 from the next d₁ terms.
3. Re-sort and repeat.
4. If you ever get a negative → not graphical. If you reach all zeros → graphical.
Worked example ✍ Havel-Hakimi on (3, 3, 1, 1)
  1. Remove first 3, subtract 1 from next 3: (3,1,1) → (2, 0, 0).
  2. Remove first 2, subtract 1 from next 2: (0,0) → (-1, -1). Negative → not graphical.
In a simple graph on 4 vertices, a vertex of degree 3 is adjacent to all others. Two such vertices force every other vertex to have degree ≥ 2, contradicting the 1s.
Corollaries of Handshaking (i) Σ deg(v) = 2|E|, so the sum is always even. (ii) The number of odd-degree vertices is always even. (iii) A regular graph of degree k on n vertices has |E| = nk/2, so nk must be even.
Exam trap (i) Same degree sequence ≠ isomorphic. Two graphs can share the same degree sequence yet have different structures. (ii) Havel-Hakimi tests for simple graphs only — it does not apply to multigraphs. (iii) A sequence with an odd sum can never be graphical (violates Handshaking).
IT link Degree-sequence analysis is used in network science to characterise real-world networks (social, biological, infrastructural) and compare them against random-graph models.

Written question State and prove the Handshaking Lemma. Hence show that every undirected graph has an even number of vertices of odd degree. Illustrate with an example. 10
  1. Statement — For any undirected graph G = (V, E), Σv∈V deg(v) = 2|E|. 2
  2. Proof — Each edge {u, v} has two ends. When summing degrees, that edge is counted once at u and once at v (a loop counts twice at its single vertex). So each edge contributes exactly 2 to the sum. Hence Σ deg(v) = 2|E|. 4
  3. Corollary — Split V into V_even (even degree) and V_odd (odd degree). Then ΣV_odd deg(v) = 2|E| − ΣV_even deg(v). The RHS is a difference of two even numbers, hence even. A sum of odd numbers is even only when the number of terms is even. Hence |V_odd| is even. 3
  4. Example — degrees 3, 3, 2, 2, 2: sum = 12 = 2|E|, so |E| = 6. Odd-degree vertices = 2 (even). ✓ 1
